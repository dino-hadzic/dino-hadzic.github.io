Dinamička dohvatljivost

Dynamic Reachability — Ynoi 2024; Moscow Pre-Finals Workshops 2022, dan 5.

Zadan je usmjereni graf s $n$ vrhova i $m$ bridova; vrhovi su označeni brojevima $1, 2, \dots, n$. Svaki je brid obojen crno ili bijelo. Na početku je svih $m$ bridova crno.

Treba izvesti $q$ operacija. Svaka je operacija jednog od sljedećih oblika:

  • „1 k” ($1\le k\le m$): promijeni boju $k$-tog brida iz ulaza iz crne u bijelu i obrnuto.
  • „2 u v” ($1\le u,v\le n$, $u\ne v$): odgovori može li se iz vrha $u$ doći do vrha $v$ bez prolaska ijednim bijelim bridom.

Ulaz

Ulaz sadrži samo jedan test.

U prvom retku nalaze se tri cijela broja $n$, $m$ i $q$ ($2\le n\le 50\,000$, $1\le m,q\le 100\,000$): broj vrhova, broj bridova i broj operacija.

Svaki od sljedećih $m$ redaka sadrži dva cijela broja $u_i$ i $v_i$ ($1\le u_i,v_i\le n$, $u_i\ne v_i$, $1\le i\le m$), što označava usmjereni brid iz vrha $u_i$ u vrh $v_i$.

Svaki od sljedećih $q$ redaka opisuje jednu operaciju u gore opisanom obliku.

Izlaz

Za svaki upit ispiši jedan redak. Ako se iz vrha $u$ može doći do vrha $v$ bez prolaska ijednim bijelim bridom, ispiši „YES”, inače ispiši „NO”.

Pregled zadatka

Dohvatljivost u usmjerenom grafu koji se mijenja nema poznatu „polilogaritamsku” strukturu podataka: već za statički graf ne znamo bitno bolje od bitsetova ($O(nm/64)$ za sve parove). Zato ciljamo na složenost oblika $O\bigl((n+m)\cdot q/64\bigr)$ uz malu konstantu. Ključna ideja je sqrt-dekompozicija po vremenu: operacije dijelimo u blokove po $B$ uzastopnih operacija. Unutar jednog bloka mijenja se najviše $B$ bridova — gotovo cijeli graf je „zamrznut”.

Izravno rješenje

Za svaki upit pokrenemo BFS po crnim bridovima: $O(m)$ po upitu, ukupno $O(qm)=10^{10}$. Presporo, ali korisno kao referenca za provjeru.

Jedan blok: fiksni i posebni bridovi

Promatrajmo blok od $B$ operacija. Bridove dijelimo na:

  • posebne: one čija se boja mijenja barem jednom u bloku (najviše $B$ njih);
  • fiksne: crne bridove koji se u bloku ne mijenjaju. (Bijeli bridovi koji se ne mijenjaju u ovom bloku ne postoje.)

Vrh zovemo ključnim ako je početak (rep) nekog posebnog brida ili odredište $v$ nekog upita u bloku. Ključnih vrhova je $K\le B$ (svaka operacija doda najviše jedan).

Zapažanje. Svaki put $u\rightsquigarrow v$ po crnim bridovima ima oblik: fiksni dio, posebni brid, fiksni dio, posebni brid, …, fiksni dio. Zato je za odgovor dovoljno znati (a) koje ključne vrhove svaki vrh doseže samo fiksnim bridovima i (b) koji su posebni bridovi trenutačno crni.

Predračun: dohvatljivost do ključnih vrhova

Na fiksnom grafu nađemo jake komponente povezanosti (SCC, Tarjanov algoritam) i sažmemo ih u DAG. Za svaku komponentu $c$ računamo bitset $R_c$ od $K$ bitova: $j$-ti bit je $1$ ako se iz $c$ fiksnim bridovima može doći do $j$-tog ključnog vrha. Obrađujemo komponente u obrnutom topološkom poretku:

\[ R_c=\{\text{ključni vrhovi u } c\}\ \cup \bigcup_{c\to d} R_d . \]

Tarjanov algoritam komponente numerira upravo tim redom (komponenta dobije broj tek kad su sve komponente dohvatljive iz nje već numerirane), pa ne treba zasebno topološko sortiranje. Cijena: $O\bigl((n+m)\cdot K/64\bigr)$ po bloku.

Odgovor na upit $(u,v)$

Održavamo bitset $V$ ključnih vrhova za koje znamo da su dohvatljivi iz $u$ i bitset $D$ onih koje smo već „proširili”.

  1. Ako su $u$ i $v$ u istoj jakoj komponenti fiksnog grafa, odgovor je YES.
  2. Inače $V\leftarrow R_{\mathrm{comp}(u)}$.
  3. Dok postoji ključni vrh $x\in V\setminus D$: dodaj ga u $D$ i za svaki trenutačno crni posebni brid $x\to y$ napravi $V\leftarrow V\cup R_{\mathrm{comp}(y)}$.
  4. Odgovor je YES ako i samo ako je $v\in V$ (odredište $v$ je ključni vrh, pa ima svoj bit).

(Zašto je točno.) Indukcijom po broju posebnih bridova na putu: ključni vrhovi dohvatljivi putem s $0$ posebnih bridova su točno $R_{\mathrm{comp}(u)}$. Put s $t+1$ posebnih bridova završava fiksnim dijelom nakon posebnog brida $x\to y$; njegov rep $x$ je ključni vrh dohvatljiv putem s $t$ posebnih bridova, pa je po pretpostavci u $V$, u nekom se trenutku proširi, i tada u $V$ ulazi cijeli $R_{\mathrm{comp}(y)}$. Obrnuto, sve što uđe u $V$ očito je dohvatljivo. $\blacksquare$

Svaki ključni vrh proširi se najviše jednom, a svaki posebni brid pregleda se najviše jednom, pa upit košta $O(K + B\cdot K/64)$. Traženje sljedećeg neproširenog vrha radi se nad riječima bitseta (ctz).

Operacija tipa $1$ unutar bloka samo okrene zastavicu boje brida: $O(1)$.

Složenost i izbor $B$

Blokova je $q/B$; po bloku plaćamo $O\bigl((n+m)B/64\bigr)$ za predračun i $O(B\cdot B^2/64)$ za upite. Ukupno

\[ O\!\left(\frac{q\,(n+m)}{64}+\frac{qB^2}{64}\right), \]

uz dodatnih $O\bigl((q/B)(n+m)\bigr)$ za izgradnju SCC-a. Prvi član ne ovisi o $B$, drugi raste s $B$, a SCC-član pada s $B$; u praksi je dobar izbor $B$ od nekoliko stotina (u kodu $B=400$). Memorija: $n$ bitsetova od $B$ bitova, oko $n\cdot B/8$ bajtova ($2{,}5$ MB).

Na najvećem testu ($n=5\cdot10^4$, $m=q=10^5$) implementacija radi oko $1{,}2$ s (ograničenje je $12$ s).

Implementacija

#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;
const int B = 400;            // velicina bloka operacija
const int W = (2 * B + 63) / 64; // rijeci u bitsetu nad kljucnim vrhovima

int n, m, q;
int eu[100005], ev[100005];
bool white_[100005], special_[100005];
int typ[100005], qa[100005], qb[100005];

// fiksni graf (CSR) i njegov SCC
vector<int> head_, nxt_, to_;
int comp[50005], low_[50005], num_[50005], timer_, ncomp;
vector<int> stk;
void tarjan(int v) {
    low_[v] = num_[v] = ++timer_;
    stk.push_back(v);
    for (int e = head_[v]; e != -1; e = nxt_[e]) {
        int u = to_[e];
        if (!num_[u]) { tarjan(u); low_[v] = min(low_[v], low_[u]); }
        else if (comp[u] == -1) low_[v] = min(low_[v], num_[u]);
    }
    if (low_[v] == num_[v]) {
        while (true) { int u = stk.back(); stk.pop_back(); comp[u] = ncomp; if (u == v) break; }
        ncomp++;
    }
}
int keyId[50005];
vector<array<ull, W>> reach; // reach[c] = kljucni vrhovi dohvatljivi iz komponente c fiksnim bridovima

int main() {
    scanf("%d %d %d", &n, &m, &q);
    for (int i = 1; i <= m; i++) scanf("%d %d", &eu[i], &ev[i]);
    for (int i = 0; i < q; i++) {
        scanf("%d %d", &typ[i], &qa[i]);
        if (typ[i] == 2) scanf("%d", &qb[i]);
    }
    reach.resize(n);
    for (int s = 0; s < q; s += B) {
        int e = min(q, s + B);
        // 1) posebni bridovi i kljucni vrhovi bloka
        vector<int> sp, keys;
        fill(keyId + 1, keyId + n + 1, -1);
        auto addKey = [&](int v) { if (keyId[v] < 0) { keyId[v] = keys.size(); keys.push_back(v); } };
        for (int i = s; i < e; i++) {
            if (typ[i] == 1) { if (!special_[qa[i]]) { special_[qa[i]] = true; sp.push_back(qa[i]); addKey(eu[qa[i]]); } }
            else addKey(qb[i]);
        }
        // 2) fiksni graf = crni bridovi koji se u bloku ne mijenjaju; SCC
        head_.assign(n + 1, -1); nxt_.clear(); to_.clear();
        for (int i = 1; i <= m; i++) if (!white_[i] && !special_[i]) {
            to_.push_back(ev[i]); nxt_.push_back(head_[eu[i]]); head_[eu[i]] = to_.size() - 1;
        }
        fill(comp + 1, comp + n + 1, -1); fill(num_ + 1, num_ + n + 1, 0); timer_ = 0; ncomp = 0;
        for (int v = 1; v <= n; v++) if (!num_[v]) tarjan(v);
        // 3) Tarjan numerira komponente u obrnutom topoloskom poretku: bridovi idu iz veceg u manji (ili isti) broj
        for (int c = 0; c < ncomp; c++) reach[c].fill(0);
        for (int v : keys) reach[comp[v]][keyId[v] >> 6] |= 1ULL << (keyId[v] & 63);
        vector<vector<int>> members(ncomp);
        for (int v = 1; v <= n; v++) members[comp[v]].push_back(v);
        int w = (keys.size() + 63) / 64;
        for (int c = 0; c < ncomp; c++)
            for (int v : members[c])
                for (int ed = head_[v]; ed != -1; ed = nxt_[ed]) {
                    int d = comp[to_[ed]];
                    if (d != c) for (int k = 0; k < w; k++) reach[c][k] |= reach[d][k];
                }
        // 4) posebni bridovi grupirani po kljucnom vrhu iz kojeg izlaze
        vector<vector<int>> out(keys.size());
        for (int id : sp) out[keyId[eu[id]]].push_back(id);
        // 5) operacije bloka
        array<ull, W> vis, done;
        for (int i = s; i < e; i++) {
            if (typ[i] == 1) { white_[qa[i]] = !white_[qa[i]]; continue; }
            int u = qa[i], v = qb[i];
            bool ok = comp[u] == comp[v];
            if (!ok) {
                vis = reach[comp[u]]; done.fill(0);
                int target = keyId[v];
                bool progress = true;
                while (progress && !(vis[target >> 6] >> (target & 63) & 1)) {
                    progress = false;
                    for (int k = 0; k < w; k++) {
                        ull todo = vis[k] & ~done[k];
                        while (todo) {
                            int x = k * 64 + __builtin_ctzll(todo); todo &= todo - 1;
                            done[k] |= 1ULL << (x & 63);
                            for (int id : out[x]) if (!white_[id]) {
                                const auto& r = reach[comp[ev[id]]];
                                for (int t = 0; t < w; t++) vis[t] |= r[t];
                                progress = true;
                            }
                        }
                    }
                }
                ok = vis[target >> 6] >> (target & 63) & 1;
            }
            puts(ok ? "YES" : "NO");
        }
        for (int id : sp) special_[id] = false;
    }
}

Sažetak

  • Operacije dijelimo u blokove po $B$; u bloku se mijenja najviše $B$ „posebnih” bridova, ostali crni bridovi su fiksni.
  • Na fiksnom grafu: SCC + DAG, i za svaku komponentu bitset ključnih vrhova (repovi posebnih bridova, odredišta upita) koje doseže.
  • Upit je BFS po najviše $B$ ključnih vrhova, gdje se „skok” preko crnog posebnog brida svodi na OR dvaju bitsetova.
  • Složenost: $O\bigl(q(n+m)/64+qB^2/64\bigr)$.
