wcirq

Ovo je interaktivni zadatak.

Treba izvesti $n$ izvornih operacija nad nizom koji je na početku prazan.

$i$-ta izvorna operacija zadaje cijele brojeve $x_i, l_i, r_i$: ispred $x_i$-tog elementa niza treba ubaciti element $i$ (ako je $x_i=i$, element se ubacuje na kraj niza), a zatim odgovoriti na upit — odrediti skup koji čine $l_i$-ti, $(l_i+1)$-vi, …, $r_i$-ti element niza.

Da bi odgovorio na upite, na raspolaganju imaš pomoćne skupove. Oni su na početku prazni i označeni su cijelim brojevima od $1$ do $2\cdot10^7$.

  • Uz cijenu od $1$ jedinice prve vrste možeš izvesti ubacivanje: u skup s oznakom $x$ ubaciti element $y$. Prije odgovora na upit $i$-te izvorne operacije mora vrijediti $1\le y\le i$.
  • Uz cijenu od $k$ jedinica druge vrste možeš odgovoriti na upit: odabereš skupove s oznakama $a_1,a_2,\dots,a_k$, koji moraju biti međusobno disjunktni, a njihova unija mora biti odgovor na upit.

Nakon svake izvorne operacije cijena prve vrste (ubacivanja) i cijena druge vrste (odgovor) ne smiju prijeći gornje granice $m_1$, odnosno $m_2$ trenutačnog podzadatka. Cijene se računaju zasebno za svaku izvornu operaciju.

Detalji implementacije

Treba implementirati funkciju

void solve(int x, int l, int r);

koja se poziva jednom za svaku izvornu operaciju; argumenti x, l, r odgovaraju brojevima $x_i,l_i,r_i$.

Smiješ pozivati funkcije

void op1(int x, int y);
void op2(int k);

Poziv op1 izvodi jedno ubacivanje. Uzastopni pozivi op2 za $a_1,\dots,a_k$ predstavljaju odgovor na upit.

U predanom kodu te dvije funkcije moraš deklarirati.

Primjer

Pretpostavimo da ocjenjivač triput pozove solve:

solve(1,1,1);
solve(1,2,2);
solve(2,1,3);

Jedan ispravan niz poziva funkcija op1 i op2 je sljedeći.

op1(1,1);
op2(1);

Niz je sada $(1)$, skup s oznakom 1 je $\{1\}$; prvi poziv solve završava.

op2(1);

Niz je sada $(2,1)$, skup s oznakom 1 je $\{1\}$; drugi poziv solve završava.

op1(1,2);
op1(2,3);
op2(2);
op2(1);

Niz je sada $(2,3,1)$, skup s oznakom 1 je $\{1,2\}$, skup s oznakom 2 je $\{3\}$; treći poziv solve završava.

Ograničenja

Za sve testove vrijedi $1\le n\le 10^6$, $1\le x_i\le i$, $1\le l_i\le r_i\le i$.

Oznake skupova u ubacivanjima i odgovorima moraju biti između $1$ i $2\cdot10^7$, a $y$ u ubacivanju mora biti element koji već postoji u nizu.

Pregled zadatka

Skupovi se mogu samo povećavati — iz skupa se ništa ne može izbrisati. Želimo strukturu u kojoj je svaki interval niza disjunktna unija malo gotovih skupova (najviše $256$), a svako ubacivanje u niz mijenja malo skupova (najviše $64$ ubacivanja) — i to u najgorem slučaju, a ne amortizirano.

Prirodna ideja je uravnoteženo stablo nad nizom u kojem svaki čvor ima skup svih elemenata svojeg podstabla. Upit se rastavi na $O(\log n)$ čvorova, a novi element ubacimo u skupove svih predaka. Problem je preslagivanje: kad se čvor podijeli (ili rotira), za nove čvorove trebaju potpuno novi skupovi, a njihovo punjenje košta koliko je čvor velik. Amortizirano je to u redu, ali ograničenje vrijedi za svaku operaciju zasebno. Rješenje: stablo s čvrsto zadanim veličinama po razinama, u kojem se nove skupove puni unaprijed, malo po malo.

Struktura: stablo s razinama

Elementi su listovi (razina $0$); svaki list ima svoj jednočlani skup. Neka je $W_i=4^{\,i-1}$. Čvor razine $i\ge1$:

  • ima djecu razine $i-1$ (poredanu kao u nizu) i skup svih elemenata svojeg podstabla;
  • ima veličinu (broj elemenata) u $[W_i,\ 4W_i)$.

Budući da je $4^{10}\gt10^6$, dovoljno je $10$ razina sa skupovima; iznad njih je korijen (razina $11$) koji nema skup i nikad se ne dijeli. Na početku napravimo lanac praznih čvorova, po jedan na svakoj razini (oni smiju biti manji od donje granice dok se ne napune).

Dijete čvora razine $i$ ima barem $W_i/4$ elemenata, pa čvor ima najviše $15$ djece (uz početni nedovoljno pun čvor najviše $16$).

Ubacivanje

Spuštamo se od korijena do mjesta ubacivanja; novi element ubacimo u skup svakog čvora na putu ($10$ ubacivanja) i napravimo novi list s vlastitim skupom ($1$ ubacivanje).

Upit

Standardno rastavljanje intervala: ako interval pokriva cijeli čvor, uzmemo njegov skup; inače se spuštamo u djecu koju interval siječe. Na svakoj razini postoje najviše dva čvora koja su djelomično pokrivena, a svaki pridonosi najviše $14$ cijelih djece. Skupovi različitih čvorova koje uzmemo su disjunktni jer su im podstabla disjunktna.

Dijeljenje čvora bez skoka u cijeni

Čvor razine $i$ mora se podijeliti prije nego što dosegne $4W_i$ elemenata. Dva nova čvora trebaju dva nova skupa. Punimo ih unaprijed:

  1. Početak. Kad čvor dosegne veličinu $3W_i$, odlučimo gdje će se podijeliti: granica je između dvoje djece, i to prva za koju lijevi dio ima više od $W_i$ elemenata. Rezerviramo dva nova (prazna) skupa $L$ i $D$ i zapamtimo popis trenutačnih elemenata lijevog i desnog dijela.
  2. Punjenje. Pri svakom sljedećem ubacivanju u taj čvor novi element odmah ubacimo i u $L$ ili $D$ (ovisno o tome s koje je strane granice), a zatim iz zapamćenog popisa prepišemo još četiri stara elementa u njihov novi skup.
  3. Kraj. Kad čvor dosegne $4W_i$ elemenata, u roditelju ga zamijenimo dvama novim čvorovima sa skupovima $L$ i $D$. Stari skup više se ne koristi.

Između veličina $3W$ i $4W$ čvor uz svako ubacivanje prepiše četiri stara elementa u nove skupove.

Tvrdnja 1 (punjenje stigne na vrijeme). U trenutku kad čvor dosegne $4W_i$ elemenata, skupovi $L$ i $D$ sadrže točno elemente lijevog, odnosno desnog dijela.

(Dokaz.) Na početku treba prepisati $3W_i$ elemenata. Do dijeljenja se dogodi $W_i$ ubacivanja, a svako prepiše $4$ stara elementa: $4W_i\ge3W_i$. Elementi ubačeni nakon početka idu izravno u pravi skup. Granica ostaje smislena i kad se djeca u međuvremenu dijele, jer se dijete uvijek zamjenjuje dvama čvorovima na istome mjestu. $\blacksquare$

Tvrdnja 2 (veličine ostaju u granicama). Oba nova čvora imaju veličinu u $[W_i,\,3W_i]$.

(Dokaz.) Djeca imaju manje od $W_i$ elemenata (za $i=1$ točno jedan), pa prva granica s više od $W_i$ elemenata lijevo daje lijevi dio veličine $d\in(W_i,2W_i]$ i desni dio $3W_i-d\ge W_i$. Do dijeljenja stigne još najviše $W_i$ elemenata, pa je svaki dio najviše $2W_i+W_i=3W_i$. $\blacksquare$

Novi čvor koji nastane s točno $3W_i$ elemenata odmah započinje vlastito dijeljenje — i dalje ima punih $W_i$ ubacivanja do granice $4W_i$, pa tvrdnja 1 vrijedi i za njega.

Cijene

Prva vrsta. Po ubacivanju: $1$ za list, a na svakoj od $10$ razina $1$ za skup čvora i, ako se čvor upravo dijeli, još $1+4$ za nove skupove. Ukupno najviše

\[ 1+10\cdot(1+1+4)=61\le 64. \]

Druga vrsta. Čvorova razine $10$ ima najviše $3$, a razine $9$ najviše $15$ u cijelom stablu (svaki ima barem $4^9$, odnosno $4^8$ elemenata); na razini $1$ čvor ima najviše $3$ lista. Na razinama $2$ do $8$ svaki od dva rubna čvora daje najviše $14$ cijelih djece (uz još najviše jedan početni čvor po razini). Ukupno je to najviše oko $3+15+7\cdot 28+4+10=228\le256$ skupova.

U podzadatku 6 granica je $64$, ali su podaci nasumični: čvorovi tada u prosjeku imaju znatno manje od $15$ djece. Lokalno je na nasumičnim testovima s $n=10^6$ prosječna cijena odgovora oko $26$, a najveća opažena (na više sjemena) $62$. To nije jamstvo: u najgorem slučaju odgovor može imati više od $64$ skupa, pa na tom podzadatku rješenje prolazi samo s velikom vjerojatnošću.

Broj skupova. Svaki čvor ikad napravljen troši jednu oznaku. Listova je $n$, a čvorova razine $i$ nastane $O(n/W_i)$; u pokusima se potroši najviše oko $3{,}4\cdot10^6$ oznaka, daleko ispod $2\cdot10^7$.

Složenost

Jedan poziv solve radi $O(16\cdot\log_4 n)$ koraka za spuštanje i upit. Pamćenje popisa elemenata pri početku dijeljenja košta $O(W_i)$ vremena (ne i ubacivanja u skupove!), što je amortizirano $O(1)$ po ubacivanju i razini. Ukupno $O(n\log n)$ vremena; na $n=10^6$ implementacija radi oko $2{,}5$ s uz oko $350$ MB memorije.

Implementacija

Čvor pamti djecu u malom polju. Dok se dijeli, pamti nove čvorove nl, nr, broj djece lijevog dijela sidx, njegovu veličinu lsz i popis pend elemenata koje još treba prepisati. Funkcije op1 i op2 daje ocjenjivač.

#include <bits/stdc++.h>
using namespace std;

void op1(int x, int y);
void op2(int k);

namespace {
const int TOP = 11;          // razina korijena (korijen nema skup i nikad se ne dijeli)
const int MAXC = 20;         // cvor ima najvise 16 djece
struct Node {
    int id = 0;              // broj skupa
    int sz = 0, cnt = 0;
    int ch[MAXC];            // djeca: indeksi cvorova; na razini 1 brojevi skupova listova
    // dijeljenje u tijeku:
    int nl = -1, nr = -1;    // novi cvorovi (lijeva i desna polovica)
    int sidx = 0, lsz = 0;   // broj djece i elemenata u lijevoj polovici
    vector<int> pend;        // elementi koje jos treba prepisati (prvo lijevi)
    int nLeft = 0, pos = 0;
};
vector<Node> T;
vector<int> leafVal;         // leafVal[skup] = element lista
int setCnt = 0, root = -1, done = 0;

inline int W(int lev) { return 1 << (2 * (lev - 1)); } // 4^(lev-1)
int newNode() { T.emplace_back(); T.back().id = ++setCnt; return (int)T.size() - 1; }
inline int childSize(int lev, int c) { return lev == 1 ? 1 : T[c].sz; }

void collect(int x, int lev, vector<int> &out) {
    for (int i = 0; i < T[x].cnt; i++) {
        if (lev == 1) out.push_back(leafVal[T[x].ch[i]]);
        else collect(T[x].ch[i], lev - 1, out);
    }
}

void startSplit(int x, int lev) {
    int a = newNode(), b = newNode();
    Node &n = T[x];
    n.nl = a; n.nr = b;
    int d = 0, k = 0;
    while (d <= W(lev)) d += childSize(lev, n.ch[k++]);
    n.sidx = k; n.lsz = d;
    n.pend.clear(); n.pend.reserve(n.sz);
    for (int i = 0; i < n.cnt; i++) {
        if (i == k) n.nLeft = n.pend.size();
        if (lev == 1) n.pend.push_back(leafVal[n.ch[i]]);
        else collect(n.ch[i], lev - 1, n.pend);
    }
    n.pos = 0;
}

void copyStep(int x, int times) {
    Node &n = T[x];
    while (times-- && n.pos < (int)n.pend.size()) {
        op1(n.pos < n.nLeft ? T[n.nl].id : T[n.nr].id, n.pend[n.pos]);
        n.pos++;
    }
}

// dijete na indeksu k cvora x (razine lev) doseglo je gornju granicu: zamijeni ga polovicama
void finishSplit(int x, int lev, int k) {
    int c = T[x].ch[k];
    int a = T[c].nl, b = T[c].nr;
    T[a].cnt = T[c].sidx; T[a].sz = T[c].lsz;
    copy(T[c].ch, T[c].ch + T[c].sidx, T[a].ch);
    T[b].cnt = T[c].cnt - T[c].sidx; T[b].sz = T[c].sz - T[c].lsz;
    copy(T[c].ch + T[c].sidx, T[c].ch + T[c].cnt, T[b].ch);
    vector<int>().swap(T[c].pend);
    Node &n = T[x];
    for (int i = n.cnt; i > k + 1; i--) n.ch[i] = n.ch[i - 1];
    n.ch[k] = a; n.ch[k + 1] = b; n.cnt++;
    if (n.nl != -1 && k < n.sidx) n.sidx++;
    for (int y : {a, b}) if (T[y].sz >= 3 * W(lev - 1)) startSplit(y, lev - 1);
}

// ubaci element val ispred p-tog (od 0) elementa podstabla x
void insert(int x, int lev, int p, int val) {
    if (lev != TOP) op1(T[x].id, val);
    int k = 0;
    if (lev == 1) {
        Node &n = T[x];
        for (int i = n.cnt; i > p; i--) n.ch[i] = n.ch[i - 1];
        int s = ++setCnt;
        leafVal.resize(s + 1); leafVal[s] = val;
        n.ch[p] = s; n.cnt++; k = p;
        op1(s, val);
    } else {
        while (p > T[T[x].ch[k]].sz) p -= T[T[x].ch[k++]].sz;
        int c = T[x].ch[k];
        insert(c, lev - 1, p, val);
    }
    T[x].sz++;
    bool wasSplitting = T[x].nl != -1;
    if (wasSplitting) {
        Node &n = T[x];
        bool left = k < n.sidx; // na razini 1: list ubacen ispred granice ide lijevo
        if (left) { n.lsz++; op1(T[n.nl].id, val); if (lev == 1) n.sidx++; }
        else op1(T[n.nr].id, val);
        copyStep(x, 4);
    }
    if (lev > 1 && T[T[x].ch[k]].sz >= 4 * W(lev - 1)) finishSplit(x, lev, k);
    if (!wasSplitting && lev != TOP && T[x].sz >= 3 * W(lev)) startSplit(x, lev);
}

// skupovi cija je unija dio [l,r] (od 0) podstabla x
void query(int x, int lev, int l, int r) {
    Node &n = T[x];
    if (lev != TOP && l == 0 && r == n.sz - 1) { op2(n.id); return; }
    int off = 0;
    for (int i = 0; i < n.cnt && off <= r; i++) {
        int s = childSize(lev, n.ch[i]);
        int a = max(l, off), b = min(r, off + s - 1);
        if (a <= b) {
            if (lev == 1) op2(n.ch[i]);
            else query(n.ch[i], lev - 1, a - off, b - off);
        }
        off += s;
    }
}
}

void solve(int x, int l, int r) {
    if (root == -1) {
        T.reserve(3000000);
        root = newNode();
        int cur = root;
        for (int lev = TOP - 1; lev >= 1; lev--) { // pocetni lanac praznih cvorova
            int c = newNode();
            T[cur].ch[0] = c; T[cur].cnt = 1; cur = c;
        }
    }
    done++;
    insert(root, TOP, x - 1, done);
    query(root, TOP, l - 1, r - 1);
}

Sažetak

  • Stablo nad nizom; čvor razine $i$ ima $[4^{i-1},4^i)$ elemenata i skup svojeg podstabla.
  • Ubacivanje: element ide u skupove $10$ predaka; upit: standardno rastavljanje na cijele čvorove.
  • Skupovi se ne mogu smanjivati, pa se dijeljenje čvora priprema unaprijed: od veličine $3W$ do $4W$ svako ubacivanje prepiše $4$ stara elementa u dva nova skupa.
  • Najgori slučaj: $61$ ubacivanje po operaciji i najviše oko $228$ skupova po odgovoru.
