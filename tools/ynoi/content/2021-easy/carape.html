Čarape

袜子 — Ynoi Easy Round 2021 / CTS 2022, drugi dan.

Zadano je $n$ točaka $(x_i,y_i,c_i)$, $i=1,2,\dots,n$, gdje je $c_i$ boja točke. Slijedi $m$ upita. Svaki upit zadaje $A,B,C$, a treba odrediti broj uređenih parova $(i,j)$ za koje vrijedi

\[ Ax_i+By_i+C\lt 0,\qquad Ax_j+By_j+C\lt 0,\qquad c_i=c_j. \]

Ulaz

U prvom su retku dva cijela broja $n$ i $m$.

U sljedećih $n$ redaka nalaze se po tri cijela broja $x_i$, $y_i$, $c_i$.

U sljedećih $m$ redaka nalaze se po tri cijela broja $A$, $B$, $C$.

Izlaz

Ispiši $m$ redaka; u svakom jedan cijeli broj — odgovor na upit.

Primjer

Ulaz:

5 2
2 -1 1
0 -3 5
1 -3 2
1 3 5
3 2 2
1 2 4
1 -2 -9

Izlaz:

2

Objašnjenje. Prvom upitu odgovaraju parovi $(2,2)$ i $(3,3)$. Drugom upitu odgovaraju parovi $(1,1)$, $(2,2)$, $(2,4)$, $(3,3)$, $(3,5)$, $(4,2)$, $(4,4)$, $(5,3)$, $(5,5)$.

Ograničenja

Za sve testove vrijedi:

  • $1\le n\le 50\,000$, $1\le m\le 500\,000$;
  • $A^2+B^2\gt 0$;
  • $-10^9\le x_i,y_i,A,B,C\le 10^9$;
  • $1\le c_i\le n$;
  • svi su brojevi cijeli;
  • sve su točke međusobno različite.

@@ editorial

Pregled zadatka

Ako u poluravnini $Ax+By+C\lt0$ leži $k_c$ točaka boje $c$, odgovor je $\sum_c k_c^2$. Rješenje je offline i ne koristi nasumičnost točaka:

  • za mali skup točaka pratimo kako se mijenja njihov poredak u smjeru $(A,B)$ dok smjer rotira — mijenja se samo zamjenama susjeda;
  • uz poredak održavamo zbroj kvadrata po bojama za svaki prefiks i sufiks;
  • točke dijelimo u blokove veličine oko $\sqrt m$, pazeći da se „male” boje ne lome preko blokova, a „velike” boje brojimo zasebno.

Složenost je $O\bigl(n\sqrt m\log m\bigr)$.

Izravno rješenje

Za svaki upit prođemo sve točke i brojimo po bojama: $O(nm)$. Služi kao referenca za provjeru.

Korak 1: jedan blok točaka, poredak po smjeru

Neka je $T$ skup od $k$ točaka. Za smjer $d=(A,B)$ poredajmo točke po vrijednosti $f(p)=Ax_p+By_p$. Točke upita su one s $f(p)\lt -C$, dakle prefiks tog poretka, a njegovu duljinu nalazimo binarnim pretraživanjem.

Kako se poredak mijenja kad smjer $d$ rotira? Dvije točke $u,v$ mijenjaju međusobni redoslijed točno onda kad $d$ postane okomit na $p_v-p_u$. U tom su trenutku $f(p_u)=f(p_v)$, pa su u poretku susjedne (ili dio skupine jednakih). Dakle poredak se mijenja zamjenama susjeda, a svaki par se tijekom pola okreta zamijeni najviše jednom: ukupno najviše $k(k-1)/2$ događaja.

Točke se projiciraju na smjer $d$; poredak projekcija je $u,v,w$. Kad se $d$ zakrene dovoljno, susjedne projekcije zamijene mjesta.

Samo pola kruga. Smjer $-d$ daje obrnut poredak. Zato svaki upit normaliziramo tako da $(A,B)$ leži u gornjoj poluravnini ($B\gt0$, ili $B=0$ i $A\gt0$); ako smo pritom promijenili predznak, tražene točke nisu prefiks nego sufiks poretka.

Postupak za blok.

  1. Točke sortiramo po $(x,y)$ — to je poredak za smjer netom iznad pozitivne osi $x$.
  2. Za svaki par $u\lt v$ s $x_u\lt x_v$ napravimo događaj sa smjerom $e=(-(y_v-y_u),\ x_v-x_u)$; događaje sortiramo po kutu (usporedbom vektorskim produktom).
  3. Upite sortiramo po kutu (jednom, globalno). Idemo po upitima i prije svakog izvršimo sve zamjene čiji kut nije veći od kuta upita; zatim binarnim pretraživanjem nađemo duljinu prefiksa.

Sve se uspoređuje cjelobrojno: komponente vektora su do $2\cdot10^9$, pa vektorski produkti (do $8\cdot10^{18}$) i vrijednosti $Ax+By$ (do $2\cdot10^{18}$) stanu u 64 bita.

Više parova pod istim kutom. Ako je više točaka na pravcu okomitom na $d$, njihova se skupina u poretku mora cijela obrnuti. Zamjene iz iste skupine izvodimo redom kojim bi ih radilo mjehuričasto sortiranje: događaje s istim kutom sortiramo po (položaj prve točke, položaj druge točke). Tada je svaka zamjena zaista zamjena susjeda.

Upit čiji je smjer točno jednak kutu nekog događaja ne stvara problem: točke koje se tada zamjenjuju imaju jednak $f$, pa su ili sve unutar poluravnine ili sve izvan nje.

Korak 2: zbroj kvadrata na prefiksu

Pretpostavimo da su sve točke pojedine boje u istom bloku. Uz poredak održavamo

  • $\mathit{rk}[p]$ — koliko je točaka iste boje ispred točke $p$ u poretku;
  • $P[j]$ — zbroj $\sum_c k_c^2$ za prvih $j$ točaka poretka; $S[j]$ — isto za točke od $j$-te do kraja.

Dodavanjem točke $p$ na kraj prefiksa broj njezine boje raste s $\mathit{rk}[p]$ na $\mathit{rk}[p]+1$, pa je $P[j+1]=P[j]+2\,\mathit{rk}[p]+1$.

Zamjena susjeda na položajima $j$ i $j+1$ mijenja samo jedan prefiks — onaj duljine $j+1$ — i samo jedan sufiks. Ako su točke iste boje, zamijene im se vrijednosti $\mathit{rk}$; inače se $\mathit{rk}$ ne mijenja. Zatim ponovno izračunamo $P[j+1]$ i $S[j+1]$ po gornjoj formuli. Sve u $O(1)$ po zamjeni.

Odgovor bloka za upit je $P[\ell]$, odnosno $S[\ell]$, gdje je $\ell$ granica nađena binarnim pretraživanjem.

Korak 3: podjela na blokove

Neka je $B\approx\sqrt m$.

  • Male boje (manje od $B$ točaka) pakiramo redom u blokove s najviše $B$ točaka, tako da je svaka boja cijela u jednom bloku. Dva uzastopna bloka zajedno imaju više od $B$ točaka, pa je blokova $O(n/B)$. Zbroj kvadrata je aditivan po blokovima jer blokovi ne dijele boje.
  • Velikih boja (barem $B$ točaka) ima najviše $n/B$. Za svaku zasebno: njezine točke podijelimo u blokove veličine $B$, u svakom bloku (korak 1) samo brojimo točke u poluravnini, zbrojimo po blokovima i na kraju kvadriramo.

Složenost

Blokova je $O(n/B)$. Blok s $k\le B$ točaka košta $O(k^2\log k)$ za događaje i $O(m\log k)$ za upite. Ukupno

\[ O\Bigl(nB\log B+\frac{n}{B}\,m\log B\Bigr)=O\bigl(n\sqrt m\,\log m\bigr)\quad\text{za }B=\sqrt m, \]

uz $O(m+B^2)$ memorije. Na najvećim testovima ($n=5\cdot10^4$, $m=5\cdot10^5$) implementacija radi oko $3{,}5$–$4$ s.

Implementacija

Polja ans i tmp indeksirana su položajem upita u poretku po kutu (radi lokalnosti u memoriji); na kraju se odgovori vrate u izvorni redoslijed.

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int BS = 724;                       // velicina bloka, oko sqrt(m)
int n, m;
vector<ll> px, py; vector<int> pc;
struct Query { ll a, b, c; int id; bool neg; }; // (a,b) u gornjoj poluravnini; neg: smjer je bio obrnut
vector<Query> qs;
vector<ll> ans;
vector<int> tmp;

struct Ev { ll ex, ey; int u, v; };
// vektorski produkt stane u 64 bita: komponente su po apsolutnoj vrijednosti najvise 2e9
static inline bool angLess(ll ax, ll ay, ll bx, ll by) { return ax * by - ay * bx > 0; }

// Obradi jedan blok tocaka. mode 0: dodaj u ans zbroj kvadrata po bojama; mode 1: dodaj u tmp broj tocaka.
void processBlock(vector<int> &pts, int mode) {
    int k = pts.size();
    sort(pts.begin(), pts.end(), [&](int i, int j) { return px[i] != px[j] ? px[i] < px[j] : py[i] < py[j]; });
    vector<ll> X(k), Y(k);
    vector<int> col(k), pos(k), at(k), rk(k), tot;
    {   // lokalne oznake boja
        vector<int> cs(k);
        for (int i = 0; i < k; i++) cs[i] = pc[pts[i]];
        sort(cs.begin(), cs.end()); cs.erase(unique(cs.begin(), cs.end()), cs.end());
        tot.assign(cs.size(), 0);
        for (int i = 0; i < k; i++) {
            X[i] = px[pts[i]]; Y[i] = py[pts[i]];
            col[i] = lower_bound(cs.begin(), cs.end(), pc[pts[i]]) - cs.begin();
            pos[i] = at[i] = i;
            rk[i] = tot[col[i]]++;
        }
    }
    // P[j]: zbroj kvadrata za prvih j tocaka poretka; S[j]: za tocke od j-te do kraja
    vector<int> P(k + 1, 0), S(k + 2, 0);
    for (int j = 0; j < k; j++) P[j + 1] = P[j] + 2 * rk[j] + 1;
    for (int j = k - 1; j >= 0; j--) S[j] = S[j + 1] + 2 * (tot[col[j]] - 1 - rk[j]) + 1;
    vector<Ev> ev; ev.reserve((size_t)k * (k - 1) / 2);
    for (int u = 0; u < k; u++) for (int v = u + 1; v < k; v++) {
        ll dx = X[v] - X[u], dy = Y[v] - Y[u];
        if (dx > 0) ev.push_back({-dy, dx, u, v});
    }
    sort(ev.begin(), ev.end(), [](const Ev &a, const Ev &b) { return angLess(a.ex, a.ey, b.ex, b.ey); });
    // X, Y od sada u trenutacnom poretku
    size_t e = 0;
    auto doSwap = [&](int u, int v) {       // u je neposredno ispred v
        int p = pos[u];
        if (col[u] == col[v]) swap(rk[u], rk[v]);
        at[p] = v; at[p + 1] = u; pos[v] = p; pos[u] = p + 1;
        swap(X[p], X[p + 1]); swap(Y[p], Y[p + 1]);
        P[p + 1] = P[p] + 2 * rk[v] + 1;
        S[p + 1] = S[p + 2] + 2 * (tot[col[u]] - 1 - rk[u]) + 1;
    };
    for (int qi = 0; qi < m; qi++) {
        const Query &q = qs[qi];
        while (e < ev.size() && !angLess(q.a, q.b, ev[e].ex, ev[e].ey)) {
            size_t f = e + 1;
            while (f < ev.size() && !angLess(ev[e].ex, ev[e].ey, ev[f].ex, ev[f].ey)) f++;
            if (f - e > 1)   // vise parova pod istim kutom: redoslijed mjehuricastog sortiranja
                sort(ev.begin() + e, ev.begin() + f, [&](const Ev &a, const Ev &b) {
                    return pos[a.u] != pos[b.u] ? pos[a.u] < pos[b.u] : pos[a.v] < pos[b.v]; });
            for (; e < f; e++) doSwap(ev[e].u, ev[e].v);
        }
        // vrijednosti a*x+b*y rastu duz poretka; lo = broj tocaka s vrijednoscu < lim
        // (bez neg: unutra su tocke s vrijednoscu < -c; uz neg: one s vrijednoscu > -c, tj. sve osim prvih lo uz lim = -c+1)
        ll lim = q.neg ? -q.c + 1 : -q.c;
        int lo = 0, len = k;
        const ll *xs = X.data(), *ys = Y.data();
        while (len > 0) {            // binarno pretrazivanje bez grananja
            int half = len >> 1;
            bool go = q.a * xs[lo + half] + q.b * ys[lo + half] < lim;
            lo = go ? lo + half + 1 : lo;
            len = go ? len - half - 1 : half;
        }
        if (mode == 0) ans[qi] += q.neg ? S[lo] : P[lo];
        else tmp[qi] += q.neg ? k - lo : lo;
    }
}

int main() {
    scanf("%d %d", &n, &m);
    px.resize(n); py.resize(n); pc.resize(n);
    vector<vector<int>> byCol(n + 1);
    for (int i = 0; i < n; i++) { scanf("%lld %lld %d", &px[i], &py[i], &pc[i]); byCol[pc[i]].push_back(i); }
    qs.resize(m);
    for (int i = 0; i < m; i++) {
        ll a, b, c; scanf("%lld %lld %lld", &a, &b, &c);
        bool neg = !(b > 0 || (b == 0 && a > 0));
        if (neg) { a = -a; b = -b; c = -c; }   // uvjet postaje a*x+b*y+c > 0
        qs[i] = {a, b, c, i, neg};
    }
    sort(qs.begin(), qs.end(), [](const Query &p, const Query &q) { return angLess(p.a, p.b, q.a, q.b); });
    ans.assign(m, 0); tmp.assign(m, 0);
    vector<int> cur;
    for (int c = 1; c <= n; c++) {
        vector<int> &v = byCol[c];
        if (v.empty()) continue;
        if ((int)v.size() >= BS) {              // velika boja: samo brojimo tocke, pa kvadriramo
            for (size_t s = 0; s < v.size(); s += BS) {
                vector<int> blk(v.begin() + s, v.begin() + min(v.size(), s + BS));
                processBlock(blk, 1);
            }
            for (int i = 0; i < m; i++) { ans[i] += (ll)tmp[i] * tmp[i]; tmp[i] = 0; }
        } else {                                // male boje pakiramo u blokove
            if (!cur.empty() && cur.size() + v.size() > (size_t)BS) { processBlock(cur, 0); cur.clear(); }
            cur.insert(cur.end(), v.begin(), v.end());
        }
    }
    if (!cur.empty()) processBlock(cur, 0);
    vector<ll> out(m);
    for (int i = 0; i < m; i++) out[qs[i].id] = ans[i];   // ans i tmp su indeksirani poretkom po kutu
    for (int i = 0; i < m; i++) printf("%lld\n", out[i]);
}

Sažetak

  • Odgovor je zbroj kvadrata brojeva točaka po bojama u poluravnini.
  • Točke u poluravnini su prefiks (ili sufiks) poretka po smjeru $(A,B)$; rotacijom smjera poredak se mijenja zamjenama susjeda.
  • Zbroj kvadrata po prefiksima/sufiksima održava se u $O(1)$ po zamjeni pomoću ranga točke unutar boje.
  • Blokovi veličine $\sqrt m$; male boje ne lomimo, velike brojimo zasebno pa kvadriramo.
  • Složenost: $O(n\sqrt m\log m)$.
