title: Introduction to data structures
---

author: HeRaNO, Zhoier, hsfzLZH1

A data structure is a way of storing and organizing data in a computer. Everything from variables and arrays to segment trees and balanced trees is a data structure.

Programs cannot run without data structures. Different structures have different strengths and weaknesses and solve different kinds of problems. Choosing the right data structure for a particular problem can greatly improve a program's efficiency, so learning a variety of data structures is essential.
