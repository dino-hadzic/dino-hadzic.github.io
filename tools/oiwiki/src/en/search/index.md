---
title: Introduction to search
---

Search means enumerating the state space: by exhausting all possibilities we find the optimal solution or count the valid solutions.

Search can be optimized in many ways, e.g. by shrinking the state space, changing the search order, pruning, etc.

Search is the foundation of some advanced algorithms. In OI, plain search is often a way to get partial credit, but very few problems can be fully solved by plain search alone.
