title: Introduction to numeral systems

???+ warning "Warning"
    What is discussed here is not a [number system](https://en.wikipedia.org/wiki/Number#Classification): in mathematics, a number system refers to a class of sets, such as the set of integers $\mathbf{Z}$, the set of complex numbers $\mathbf{C}$, etc.

A **numeral system**, also called a **system of numeration**, is a writing system for expressing numbers, such as the [Hindu–Arabic numeral system](https://en.wikipedia.org/wiki/Hindu%E2%80%93Arabic_numeral_system), [Roman numerals](https://en.wikipedia.org/wiki/Roman_numerals), [Suzhou numerals](https://en.wikipedia.org/wiki/Suzhou_numerals), etc. A numeral system is the tool we use to encode numbers.

Generally speaking, a numeral in a numeral system is a string of symbols, and there is a set of rules that puts such strings in one-to-one correspondence with the corresponding numbers; for example, the Roman numeral $\text{XLII}$, the binary number $101010_{(2)}$, and the decimal number $42$ all correspond to the same number.

In algorithmic competitions we are generally only interested in the conversions between different numeral systems; see [Base](./base.md) for details.
