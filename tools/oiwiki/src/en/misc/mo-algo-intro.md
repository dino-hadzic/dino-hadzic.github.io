---
title: Introduction to Mo's algorithm
---

Mo's algorithm was proposed by Mo Tao (莫涛). Before Mo Tao proposed it, the algorithm had already been circulating in a small circle among top Codeforces competitors, but Mo Tao was the first to summarize it in detail and systematically. When Mo Tao proposed Mo's algorithm, he only analyzed the ordinary Mo's algorithm, but through the collective wisdom of OIers and ACMers, Mo's algorithm has been reworked into several extended versions.

Mo's algorithm can solve a class of offline range query problems and is extremely widely applicable. Moreover, by extending it, one can easily handle path queries on trees and support modification operations.
