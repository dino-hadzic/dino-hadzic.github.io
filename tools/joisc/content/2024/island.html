Otočno skakutanje

Island Hopping — JOI Spring Camp 2024, dan 4.

Nepoznato stablo s $N$ otoka. Upit query(v, k) vraća $k$-ti najbliži otok otoku $v$ (među ostalih $N-1$; poredak po $\mathrm{dist}(v,i)\cdot N+i$, tj. po udaljenosti, a kod jednakih po indeksu). Najviše $L$ upita; pozovi answer(x, y) točno $N-1$ puta, jednom za svaki brid. Ocjenjivač nije adaptivan.

Ograničenja

  • $3\le N\le300$.

Podzadaci

  1. (2) $N=3$, $L=9$.
  2. (4) $L=N^2$, stupnjevi $\le2$ (put).
  3. (7) $L=2N$, put.
  4. (9) $L=N^2$, otok 1 stupnja 3, ostali $\le2$.
  5. (13) $L=3N$, isto.
  6. (15) $L=N^2$.
  7. (22) $L=3N$.
  8. (28) $L=2N$.

Primjer

$N=4$, bridovi $1\text{-}2$, $2\text{-}4$, $4\text{-}3$: query(2,1)$=1$, query(2,2)$=4$ (udaljenosti od 2: $1,2,1$ za otoke $1,3,4$).

Tipična zapažanja kod zadataka određivanja stabla slajdovi 7–24

Četiri tipična pristupa zadacima u kojima treba odrediti nepoznato stablo:

  • A. Vrhove dodajemo redom $1, 2, \dots, N$.
  • B. Pretražujemo redom od vrhova najbližih vrhu $1$.
  • C. Skidamo vrhove počevši od listova.
  • D. Korištenje dijametra.

A. Vrhove dodajemo redom $1, 2, \dots, N$

Na početku je u stablu samo vrh $1$. Dodaje se vrh $2$ (narančasto) i isprekidanom crtom povezuje s vrhom $1$. Dodaje se vrh $3$ (narančasto): pripaja se na vrh $6$ koji leži između vrhova $1$ i $2$. Dodaje se vrh $4$ (narančasto): pripaja se na vrh $9$ koji leži između vrhova $6$ i $3$.

Slajdovi 8–11 nemaju teksta osim naslova. Skica prikazuje ideju pristupa A: u svakom koraku poznat je dio stabla koji povezuje dosad dodane vrhove (isprekidane crte su putovi među njima), a novi vrh pripaja se na neko mjesto tog dijela; pritom se mogu pojaviti i međuvrhovi većeg broja (ovdje $6$ i $9$) koji još nisu „na redu”.

B. Pretražujemo redom od vrhova najbližih vrhu $1$

Pretraživati se može na dva načina: BFS (pretraživanje u širinu) i DFS (pretraživanje u dubinu).

BFS (pretraživanje u širinu): krećemo iz vrha $1$. BFS: otkriva se vrh $6$, susjed vrha $1$. BFS: otkriva se vrh $9$, drugi susjed vrha $1$. BFS: otkriva se vrh $2$, dijete vrha $6$. BFS: otkriva se vrh $4$, dijete vrha $9$. BFS: otkriva se vrh $3$, drugo dijete vrha $9$. Redoslijed otkrivanja: $1, 6, 9, 2, 4, 3$. DFS (pretraživanje u dubinu): iz vrha $1$ otkriva se vrh $6$. DFS: idemo dalje u dubinu, otkriva se vrh $2$, dijete vrha $6$. DFS: vraćamo se do vrha $1$ i otkrivamo vrh $9$. DFS: otkriva se vrh $4$, dijete vrha $9$. DFS: otkriva se vrh $3$, drugo dijete vrha $9$. Redoslijed otkrivanja: $1, 6, 2, 9, 4, 3$.

C. Skidamo vrhove počevši od listova

Najprije na neki način pronađemo jedan list i vrh na koji je on spojen.

→ Taj vrh uklonimo i time zadatak svedemo na zadatak s jednim vrhom manje.

D. Korištenje dijametra

Slajd 24: dijametar

Dijametar stabla je najdulji put između dva vrha stabla (ovdje mjeren brojem bridova). Njegova su oba kraja listovi.

Standardno se nalazi u dva koraka: iz bilo kojeg vrha $a$ nađemo najudaljeniji vrh $b$, zatim iz $b$ nađemo najudaljeniji vrh $c$; put od $b$ do $c$ je dijametar. U ovom zadatku „najudaljeniji vrh od $v$” dobivamo jednim upitom query(v, N - 1).

Svako stablo izgleda kao dijametar o čijim unutarnjim vrhovima vise podstabla; podstablo koje visi o vrhu udaljenom $d$ od bližeg kraja dijametra ima dubinu najviše $d$ (inače bi postojao dulji put).

 stabla je put $2$–$4$–$5$–$1$–$3$–$7$–$6$; o svakom njegovu unutarnjem vrhu (narančasto) visi podstablo (trokut).

void solve(int N, int L) {
    // N = 3, L = N^2
    if (query(1, 1) == 3) {

→ Podzadatak 1 je riješen (AC)!

Stupac $i=1$ tablice razlikuje stablo C (odgovor $3$) od stabala A i B (odgovor $2$). U stablu C bridovi su $1$–$3$ i $2$–$3$. Stabla A i B oba sadrže brid $1$–$2$, a razlikuju se po tome na koji je vrh spojen vrh $3$: to je upravo vrh najbliži vrhu $3$ (stupac $i=3$: u A je to $1$, u B je $2$), pa je drugi brid (query(3, 1), 3). Troše se najviše $2$ upita od dopuštenih $L=9$.

Podzadaci 2 i 3 11 slajdovi 29–34

Ograničenje podzadataka: stablo je put (graf-put).

Slajd 30: graf-put $2$–$4$–$5$–$1$–$3$–$7$–$6$. Za neki proizvoljan vrh (ovdje $5$) pitamo koji mu je vrh najudaljeniji. Za neki proizvoljan vrh pitamo koji mu je vrh najudaljeniji: odgovor je vrh $6$, jedan kraj puta. Iz tog vrha redom pitamo za vrhove od najbližeg prema daljima: dobivamo cijeli put.

Kod sa slajda 34:

void solve(int N, int L){
    // put, L = 2N
    int a = query(1, N - 1), b;
    b = a;
    for(int i = 0; i < N - 1; i++){
        int c = query(a, i + 1);
        answer(min(b, c), max(b, c));
        b = c;
    }
}

→ Podzadaci 2 i 3 su riješeni (AC)!

Na putu je vrh najudaljeniji od bilo kojeg vrha uvijek jedan od dvaju krajeva puta (ako su oba kraja jednako daleko, upit vraća onaj s većim brojem, što je i dalje kraj). Od kraja $a$ na svakoj udaljenosti $d=1,\dots,N-1$ leži točno jedan vrh, pa query(a, d) vraća upravo $d$-ti vrh puta gledano od $a$; uzastopni odgovori su susjedni vrhovi.

Kod kao „proizvoljan vrh” uzima vrh $1$ i troši $1+(N-1)=N$ upita, što stane i u $L=N^2$ (podzadatak 2) i u $L=2N$ (podzadatak 3).

ovdje koristimo pristup B (na slajdu 37 istaknut crveno).

Najprije odredimo brojeve triju vrhova spojenih s vrhom $1$. Radimo DFS (za vrh u kojem se trenutno nalazimo pitamo koja su mu dva najbliža vrha).

Kod sa slajda 40:

void solve(int N, int L){
    vector<int> ok(N + 1, 0);
    vector<int> v = {query(1, 1), query(1, 2), query(1, 3)};
    for(int i = 0; i < 3; i++){
        answer(1, v[i]);
    }
    ok[1] = 1;

    for(int i = 0; i < 3; i++){
        while(true){
            int b = query(v[i], 1);
            int c = query(v[i], 2);
            if(ok[b] == 0){
                ok[v[i]] = 1;
                answer(v[i], b);
                v[i] = b;
            }
            else if(ok[c] == 0){
                ok[v[i]] = 1;
                answer(v[i], c);
                v[i] = c;
            }
            else{
                break;
            }
        }
    }
}

→ Podzadaci 4 i 5 su riješeni (AC)!

Zašto radi. Tri susjeda vrha $1$ jedini su vrhovi na udaljenosti $1$ od njega, pa su to odgovori na query(1, 1), query(1, 2) i query(1, 3). Svaki drugi vrh $x$ ima stupanj najviše $2$. Ako je stupanj $2$, dva najbliža vrha su njegova dva susjeda: onaj iz kojeg smo došli (već označen u ok) i sljedeći vrh kraka (neoznačen) — na njega prelazimo i javljamo brid. Ako je $x$ list na dubini barem $2$, najbliži mu je prethodnik, a drugi najbliži prethodnikov prethodnik; oba su označena, pa se krak završava.

Broj upita. $3$ upita za susjede vrha $1$ i po $2$ upita za svaki od preostalih $N-1$ vrhova: ukupno $2N+1\le 3N$, što zadovoljava i $L=N^2$ (podzadatak 4) i $L=3N$ (podzadatak 5).

Rubni slučaj. Kod je prepisan točno kako stoji na slajdu, ali u njemu tri susjeda vrha $1$ na početku nisu označena u ok. Ako je neki susjed $x$ vrha $1$ list (krak duljine $1$), tada je b$=1$ (označen), a c je drugi susjed vrha $1$ (na udaljenosti $2$ od $x$) koji još može biti neoznačen — kod bi tada javio nepostojeći brid $(x, c)$. To se događa primjerice u zvijezdi $N=4$ s bridovima $1$–$2$, $1$–$3$, $1$–$4$, a i u drugom primjeru iz teksta zadatka vrh $1$ ima susjede-listove. Provjerili smo to simulacijom. Popravak je jedan redak nakon ok[1] = 1;:

for(int i = 0; i < 3; i++) ok[v[i]] = 1;

S tim retkom rješenje je na nasumičnim stablima ovog oblika uvijek točno i troši najviše $2N+1$ upita.

(Drugo rješenje)

Slajd 41: isti graf posebnog oblika — vrh $1$ s tri kraka.

Od tipičnih zapažanja kod zadataka određivanja stabla

  • A. Vrhove dodajemo redom $1, 2, \dots, N$.
  • B. Pretražujemo redom od vrhova najbližih vrhu $1$.
  • C. Skidamo vrhove počevši od listova.
  • D. Korištenje dijametra.

ovaj put koristimo pristup D (na slajdu 42 istaknut crveno).

Pitamo koji je vrh najudaljeniji od vrha $1$ (ovdje $6$).
→ Od tog vrha određujemo vrhove redom od najbližeg. Pitamo koji je vrh najudaljeniji od vrha $1$.
→ Od tog vrha određujemo vrhove redom od najbližeg.
→ Kad se pojavi vrh $1$, prekidamo. Pitamo koji je vrh najudaljeniji od vrha $6$ (ovdje $8$). I od vrha $8$ pitamo na isti način (prekidamo kod vrha $1$). Preostale vrhove povezujemo redom od najbližeg vrhu $1$.

Neka krakovi imaju duljine $\ell_1,\ell_2,\ell_3$ (broj vrhova bez vrha $1$). Vrh $a$ najudaljeniji od vrha $1$ je kraj nekog kraka. Od kraja kraka na svakoj udaljenosti $d\le\ell_1$ leži točno jedan vrh (vrhovi tog kraka i na kraju vrh $1$), pa upiti query(a, 1), query(a, 2), … redom vraćaju vrhove kraka sve do vrha $1$ — to je $\ell_1$ upita i $\ell_1$ bridova.

Vrh najudaljeniji od $a$ je kraj $b$ nekog drugog kraka (svi vrhovi vlastitog kraka su bliži od bilo kojeg vrha drugih krakova), pa isti postupak od $b$ daje drugi krak s $\ell_2$ upita. Put od $a$ do $b$ ujedno je dijametar stabla.

Preostali vrhovi čine treći krak; poredani po udaljenosti od vrha $1$ čine lanac koji počinje u vrhu $1$. Taj poredak dobivamo upitima query(1, k) za $k=1,\dots,N-1$ preskačući već određene vrhove. Ukupno najviše

\[ 1+\ell_1+1+\ell_2+(N-1)\le 2N-1 \]

upita (jer je $\ell_1+\ell_2\le N-2$), što je manje od $3N$. Ovakvu implementaciju provjerili smo simulacijom na nasumičnim stablima ovog oblika.

Pitamo koji je vrh najudaljeniji od vrha $1$.
→ Taj je vrh list, a doznajemo i na koji je vrh spojen.
→ Taj list zanemarimo, a ostatak stabla odredimo rekurzivno. Pitamo koji je vrh najudaljeniji od vrha $1$.
→ Taj je vrh list (ovdje $6$), a doznajemo i na koji je vrh spojen (ovdje $5$).
→ Taj list zanemarimo, a ostatak stabla (unutar elipse) odredimo rekurzivno.

Kod sa slajda 52:

vector<int> used(N, 0);
int a = Q[0][N - 1];

for(int i = 0; i < N - 1; i++){
    for(int j = 1; j < N; j++){
        int b = Q[a][j];
        if(!used[b]){
            used[a] = 1;
            answer(a + 1, b + 1);
            for(int k = N - 1; k >= 0; k--){
                int c = Q[b][k];
                if(!used[c]){
                    a = c;
                    break;
                }
            }
            break;
        }
    }
}

→ Podzadatak 6 je riješen (AC)!

Tablica Q. Slajd ne prikazuje kako nastaje Q. Iz načina uporabe slijedi da su vrhovi u kodu numerirani od $0$ i da je Q[v][k] vrh koji je $k$-ti najbliži vrhu v, uz Q[v][0] = v; tablica se na početku popuni svim mogućim upitima:

vector<vector<int>> Q(N, vector<int>(N));
for(int v = 0; v < N; v++){
    Q[v][0] = v;
    for(int k = 1; k < N; k++) Q[v][k] = query(v + 1, k) - 1;
}

To je $N(N-1)\le N^2$ upita; nakon toga se više ništa ne pita.

Najudaljeniji vrh je list. Neka je $a$ vrh najudaljeniji od vrha $x$ u stablu s barem dva vrha. Kad bi $a$ imao susjeda $w$ koji nije na putu prema $x$, taj bi $w$ bio još dalji od $x$; dakle $a$ ima samo jednog susjeda, tj. list je.

Na koji je vrh list spojen. Uklanjanjem lista stablo ostaje povezano i udaljenosti među preostalim vrhovima se ne mijenjaju. Zato je za list $a$ trenutačnog (preostalog) stabla njegov jedini susjed upravo prvi neuklonjeni vrh u popisu Q[a][1], Q[a][2], … — to je vrh b, i kod javlja brid $(a,b)$.

Sljedeći list. Kod za sljedeći list ne uzima vrh najudaljeniji od vrha $1$, nego neuklonjeni vrh najudaljeniji od b (popis Q[b] čita se unatrag). Po gornjoj tvrdnji i to je list preostalog stabla, pa je postupak ispravan. Kad ostane samo vrh b, petlja po k stiže do Q[b][0] = b, ali tada je vanjska petlja već javila svih $N-1$ bridova. Ovakav kod provjerili smo simulacijom na nasumičnim stablima.

Ograničenja podzadataka: $L=3N$ (podzadatak 7) i $L=2N$ (podzadatak 8).

Od tipičnih zapažanja kod zadataka određivanja stabla

  • A. Vrhove dodajemo redom $1, 2, \dots, N$.
  • B. Pretražujemo redom od vrhova najbližih vrhu $1$.

ovdje ponovno koristimo pristup B (na slajdu 54 istaknut crveno).

Vrh najbliži vrhu $1$ (ovdje $2$) povezujemo s vrhom $1$. Povezujemo sljedeći najbliži vrh vrhu $1$ (ovdje $3$): spojen je ili izravno s vrhom $1$ (lijevo) ili s vrhom $2$ (desno) — ne znamo koja je od dviju mogućnosti točna. Iz vrha $3$ redom pitamo za vrhove od najbližeg i odlučujemo po tome koji se od vrhova $1$ i $2$ pojavi prvi.

Ukratko…

  1. Vrhove dodajemo redom od najbližeg vrhu $1$.
  2. Iz vrha koji želimo dodati redom pitamo za vrhove od najbližeg.
  3. Čim se pojavi vrh koji smo već vidjeli, on je sigurno roditelj.
Slajd 59: vrhovi $1,2,4,5,6,9$ već su dodani (strelice pokazuju prema roditelju). Dodajemo vrh $3$ (narančasto); isprekidane strelice pokazuju već viđene vrhove koji bi mu mogli biti roditelj.

Ukorijenimo stablo u vrhu $1$. Upiti query(1, k) za $k=1,\dots,N-1$ daju sve vrhove poredane po udaljenosti od vrha $1$ (BFS poredak). Svaki vrh $u\ne1$ ima u tom poretku svog roditelja ispred sebe (roditelj je za $1$ bliži vrhu $1$), a svu svoju djecu iza sebe.

Kad dodajemo $u$, „već viđeni” su točno vrhovi ispred njega u poretku. Odgovori na query(u, 1), query(u, 2), … najprije nabrajaju susjede vrha $u$ (udaljenost $1$) po rastućem broju. Među susjedima je viđen jedino roditelj, a nijedan vrh na udaljenosti $2$ ili više ne može doći na red prije roditelja. Dakle prvi viđeni odgovor je roditelj, a svi odgovori prije njega su djeca vrha $u$ s brojem manjim od roditeljeva.

Ukratko… (broj upita)

  1. Vrhove promatramo redom od najbližeg vrhu $1$.
  2. Iz vrha koji želimo dodati redom pitamo za vrhove od najbližeg.
  3. Čim se pojavi vrh koji smo već vidjeli, on je sigurno roditelj.

Prvih $N$ upita $+$ $2N$ upita → ukupno $3N$ upita.

Zašto?

Slajdovi 61–63: stablo sa strelicama od svakog vrha prema roditelju; „ulijevo” je smjer prema roditelju (prema vrhu $1$), „udesno” smjer prema djeci.

Za svaki brid postavit ćemo po dva upita: jedan „ulijevo” i jedan „udesno”.

Odbaciti informaciju dobivenu kad smo pitali za brid „udesno” je rasipanje.

→ Ako je ponovno iskoristimo, ukupno je dovoljno $2N$ upita i dobivaju se puni bodovi.

$3N$. Prva faza (poredak po udaljenosti od vrha $1$) troši $N-1$ upita. U drugoj fazi svaki je odgovor na upit iz vrha $u$ susjed vrha $u$: ili roditelj (upit „ulijevo” po bridu $u$–roditelj) ili dijete (upit „udesno” po bridu $u$–dijete). Svaki se brid tako pita najviše jednom u svakom smjeru, pa druga faza troši najviše $2(N-1)$ upita, a sve zajedno manje od $3N$. To rješava podzadatak 7.

$2N$. Ako se pri obradi vrha $u$ prije roditelja pojavi dijete $c$, već tada znamo brid $u$–$c$, tj. roditelja vrha $c$. Zato taj brid odmah javimo, a vrh $c$ označimo (ok[c] = 1) i kad dođe na red preskočimo ga. Tada svaki upit druge faze otkriva novi brid: brid prema djetetu javlja se samo iz roditelja (dijete se nakon toga preskače), a brid prema roditelju samo iz vrha koji nije preskočen, dakle čiji brid prema roditelju još nije bio javljen. Bridova je $N-1$, pa druga faza troši točno $N-1$ upita, a ukupno

\[ (N-1)+(N-1)=2N-2\le 2N . \]

Ispravnost se ne mijenja: odluku „je li odgovor $a$ roditelj” kod donosi usporedbom položaja u poretku (dist[a] < dist[i]), a ona ne ovisi o tome koji su vrhovi preskočeni.

Kod sa slajda 64:

for(int i = 1; i < N; i++){
    int a = query(1, i) - 1;
    dist[a] = i;
    near[i] = a;
}

for(int t = 1; t < N; t++){
    int i = near[t];
    if(ok[i]){
        continue;
    }
    for(int j = 1; j < N; j++){
        int a = query(i + 1, j) - 1;
        if(dist[a] < dist[i]){
            answer(i + 1, a + 1);
            break;
        }
        else{
            answer(i + 1, a + 1);
            ok[a] = 1;
        }
    }
}

→ 100 bodova!

Vrhovi su u kodu numerirani od $0$ (vrh $1$ iz zadatka je indeks $0$). Polja dist, near i ok veličine $N$ nisu deklarirana na slajdu i moraju biti inicijalizirana nulama. dist[a] nije prava udaljenost nego redni broj vrha a u poretku po udaljenosti od vrha $1$ (za sam vrh $1$ ostaje $0$), a near[t] je $t$-ti vrh tog poretka. Uvjet dist[a] < dist[i] znači „vrh a je u poretku ispred vrha i”, tj. a je roditelj; inače je a dijete, brid se javlja odmah i dijete se označava da se kasnije preskoči. Simulacijom na nasumičnim stablima provjerili smo da kod uvijek javi točno $N-1$ ispravnih bridova uz točno $2N-2$ upita.

Rješenje koje vješto koristi veličinu brojeva vrhova

… pitamo za vrhove susjedne vrhu $N$.

Slajd 65: vrh $N$, njegov susjed $3$ i vrhovi $6$, $1$, $4$ spojeni na vrh $3$ (strelice pokazuju prema vrhu $N$).

→ Uz $L=2{,}5N$ teško je dobiti pune bodove.

Slajd ovu ideju ne razrađuje dalje. Polazište je vjerojatno ovo: budući da se vrhovi na jednakoj udaljenosti vraćaju po rastućem broju, vrh najvećeg broja $N$ pojavljuje se zadnji među susjedima, pa se iz poretka odgovora može iščitati dodatna informacija. Kako točno izgleda rješenje na koje autor misli i na što se odnosi granica $2{,}5N$, iz slajda se ne može pouzdano zaključiti, pa to ovdje ne rekonstruiramo.

Sažetak

  • Kod interaktivnih zadataka isplati se simulirati poznate algoritme (BFS, DFS, skidanje listova, dijametar) i isprobati više pristupa.
  • Mali i posebni slučajevi: $N=3$ rješava se s dva upita; put se čita od jednog kraja ($N$ upita); stablo s tri kraka DFS-om po krakovima ili pomoću dijametra.
  • $L=N^2$: uzastopno skidanje listova — najudaljeniji vrh je list, a spojen je na najbliži neuklonjeni vrh.
  • $L=3N$: vrhove dodajemo po udaljenosti od vrha $1$; prvi već viđeni vrh među najbližima je roditelj.
  • $L=2N$: djecu otkrivenu prije roditelja ne obrađujemo ponovno, pa svaki brid stoji jedan upit — ukupno $2N-2$.
