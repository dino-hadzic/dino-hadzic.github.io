    Rješenje zadatka na natjecanju iz umjetne inteligencije rijetko stane u deset redaka: učitavanje podataka, predobrada, model, vrednovanje i ispis rezultata lako narastu na nekoliko stotina. Ova lekcija pokazuje dijelove Pythona koji takav kod drže čitljivim i brzim – i koje PyTorch i scikit-learn stalno koriste, pa ih moraš prepoznati u tuđem kodu (__getitem__ u Datasetu, generatori u učitavanju podataka, dekoratori poput @torch.no_grad()).

    Klase i objekti

    Klasa je nacrt koji povezuje podatke (atribute) i funkcije koje nad njima rade (metode); objekt (instanca) je jedan konkretan primjerak. Metoda prima objekt kao prvi argument, po dogovoru nazvan self. Posebna metoda __init__ izvršava se pri stvaranju objekta i postavlja početne atribute.

    Klasu pišeš kad više funkcija dijeli isto stanje (npr. vokabular tokenizatora koji koriste encode i decode) ili kad želiš da se tvoj objekt ponaša kao ugrađeni tip. Klasa smije naslijediti drugu (class Moja(Osnovna):) i preuzeti ili nadjačati njezine metode; tako se piše svaki PyTorch model (class Mreza(nn.Module), lekcija D3). Za klase koje su „samo podaci” najkraći je zapis @dataclass iz modula dataclasses: navedeš atribute s tipovima, a __init__, __repr__ i __eq__ dobivaš besplatno.

    Dunder metode

    Metode s dvostrukim podvlakama (engl. double underscore, „dunder”) Python poziva sam kad nad objektom primijeniš ugrađenu operaciju: len(x) poziva x.__len__(), x[i] poziva x.__getitem__(i), for e in x poziva x.__iter__(), a + b poziva a.__add__(b), a == b poziva a.__eq__(b), a print(x) i ispis u konzoli koriste __str__ odnosno __repr__. Zbog toga tvoj objekt može „glumiti” listu: definiraš __len__ i __getitem__ i već radi indeksiranje, for petlja (Python sam poziva __getitem__ od $0$ dok ne dobije IndexError), list(x) i random.shuffle. Upravo to zahtijeva PyTorchov Dataset.

    __repr__ treba vratiti kratak, jednoznačan opis koji ćeš vidjeti pri ispitivanju grešaka; piši ga za svaku klasu koju napišeš. Bez njega ispis objekta je neupotrebljivo <__main__.Skup object at 0x7f…>.

    Iteratori i generatori

    Iterator je objekt koji na poziv next(it) vraća sljedeći element, a kad ih više nema baca StopIteration; for petlja točno to radi. Generator je funkcija koja umjesto return koristi yield: pri svakom yield „zamrzne” se i preda vrijednost, a nastavlja od istog mjesta pri sljedećem next. Generator računa elemente lijeno (engl. lazy), jedan po jedan, pa ne zauzima memoriju za cijeli niz.

    Generatorski izraz (x ** 2 for x in a) izgleda kao list comprehension s običnim zagradama, ali ne stvara listu; sum(x ** 2 for x in a) zato radi i za milijardu elemenata. Generatori su prirodan način za učitavanje podataka u batchevima, čitanje goleme datoteke redak po redak ili beskonačno kruženje po epohama. Cijena: generator se može proći samo jednom; za drugi prolaz pozovi funkciju ponovno.

    Funkcije kao vrijednosti

    Funkcija je objekt kao i svaki drugi: smije se predati drugoj funkciji, vratiti iz nje ili spremiti u rječnik ({"mse": mse, "mae": mae} pa metrike[ime](y, p)). Lambda lambda x: x[1] je anonimna funkcija od jednog izraza, najčešće kao argument key u sorted, min i max. map(f, a) primjenjuje f na svaki element, filter(p, a) zadržava elemente za koje je p istinit; oba vraćaju lijene iteratore. U modernom Pythonu comprehension je obično čitljiviji od map/filter s lambdom, ali ih moraš razumjeti jer ih tuđi kod koristi. Za ključeve poput „po drugom polju” postoji i operator.itemgetter(1).

    Dekoratori

    Dekorator je funkcija koja prima funkciju i vraća novu, obično „omotanu” funkciju. Zapis @dek iznad def f(...) znači točno f = dek(f).

    Omotač prima proizvoljne argumente kao *args, **kwargs i prosljeđuje ih izvornoj funkciji, a prije ili poslije poziva radi nešto korisno: mjeri vrijeme, broji pozive, pamti rezultate (memoizacija), isključuje računanje gradijenata. @functools.wraps(f) unutar dekoratora čuva ime i docstring izvorne funkcije. Ugrađeni @functools.lru_cache je gotov memoizacijski dekorator; @staticmethod, @property i @dataclass također su dekoratori.

    Napiši generator batchevi(skup, velicina, sjeme) koji skup podataka vraća u izmiješanim komadima zadane veličine (zadnji komad smije biti manji) i generator epohe(skup, velicina) koji beskonačno kruži po epohama s novim miješanjem u svakoj. Pokaži kako se iz beskonačnog generatora uzima točno zadani broj koraka.

    Korak 1: jedan prolaz. yield predaje batch i zaustavlja funkciju do sljedećeg zahtjeva. Ništa se ne računa dok netko ne zatraži – batchevi(...) samo stvori generatorski objekt.

    def batchevi(skup, velicina: int, sjeme: int = 0): indeksi = list(range(len(skup))) random.Random(sjeme).shuffle(indeksi) for pocetak in range(0, len(indeksi), velicina): yield [skup[i] for i in indeksi[pocetak:pocetak + velicina]] g = batchevi(skup, 4) print(type(g).__name__) prvi = next(g) print(len(prvi), [u.y for u in prvi]) print("preostali batchevi:", [len(b) for b in g]) print("drugi prolaz:", list(g)) generator 4 [0, 2, 1, 1] preostali batchevi: [4, 4, 3] drugi prolaz: []

    Petnaest uzoraka u batchevima po četiri daje $4,4,4,3$. Nakon što je generator iscrpljen, ponovni prolaz je prazan – to je najčešća greška s generatorima: spremiš ga u varijablu, jednom prođeš, a drugi put dobiješ ništa.

    Napiši klasu Vektor koja čuva listu brojeva i podržava: len, indeksiranje, zbrajanje i oduzimanje dvaju vektora, množenje skalarom s obje strane (2 * v i v * 2), skalarni produkt v @ w, normu abs(v), usporedbu == i čitljiv repr. Zbrajanje vektora različitih duljina neka baci ValueError.

    Za 2 * v Python prvo pita int, koji ne zna množiti Vektor, pa zatim poziva v.__rmul__(2). Skalarni produkt je __matmul__, norma __abs__. class Vektor: def __init__(self, podaci): self.p = list(podaci) def __len__(self): return len(self.p) def __getitem__(self, i): return self.p[i] def __repr__(self): return f"Vektor({self.p})" def _provjeri(self, w): if len(self) != len(w): raise ValueError(f"duljine {len(self)} i {len(w)} se ne slažu") def __add__(self, w): self._provjeri(w) return Vektor(a + b for a, b in zip(self.p, w.p)) def __sub__(self, w): self._provjeri(w) return Vektor(a - b for a, b in zip(self.p, w.p)) def __mul__(self, c): return Vektor(a * c for a in self.p) __rmul__ = __mul__ def __matmul__(self, w): self._provjeri(w) return sum(a * b for a, b in zip(self.p, w.p)) def __abs__(self): return (self @ self) ** 0.5 def __eq__(self, w): return isinstance(w, Vektor) and self.p == w.p v, w = Vektor([3, 4]), Vektor([1, -1]) print(v + w, v - w, 2 * v, v * 0.5) print(v @ w, abs(v), len(v), v[0], v == Vektor([3, 4]), v == w) try: v + Vektor([1, 2, 3]) except ValueError as e: print("greška:", e) Vektor([4, 3]) Vektor([2, 5]) Vektor([6, 8]) Vektor([1.5, 2.0]) -1 5.0 2 3 True False greška: duljine 2 i 3 se ne slažu

    Ovo je, u sićušnom, ono što NumPy-jev ndarray radi u C-u: svaki operator je dunder metoda. Kad u lekciji P3 napišeš X @ w, Python zove X.__matmul__(w).

    Napiši generator prozori(niz, k) koji redom daje sve uzastopne podnizove duljine $k$ (kao n-torke) i pomoću njega izračunaj pomični prosjek (engl. moving average) širine $3$ za niz [4, 8, 6, 2, 10, 12, 8]. Zatim isti pomični prosjek izračunaj „na letu” s deque(maxlen=3), kao da brojevi stižu jedan po jedan.

    from collections import deque def prozori(niz, k: int): for i in range(len(niz) - k + 1): yield tuple(niz[i:i + k]) niz = [4, 8, 6, 2, 10, 12, 8] print(list(prozori(niz, 3))) print([round(sum(p) / 3, 2) for p in prozori(niz, 3)]) prozor = deque(maxlen=3) na_letu = [] for x in niz: prozor.append(x) if len(prozor) == 3: na_letu.append(round(sum(prozor) / 3, 2)) print(na_letu, len(prozor), prozor) [(4, 8, 6), (8, 6, 2), (6, 2, 10), (2, 10, 12), (10, 12, 8)] [6.0, 5.33, 6.0, 8.0, 10.0] [6.0, 5.33, 6.0, 8.0, 10.0] 3 deque([10, 12, 8], maxlen=3)

    deque(maxlen=3) pri svakom append sam izbacuje najstariji element, pa je uvijek u njemu zadnja tri broja. Pomični prosjek izglađuje šumovite krivulje – npr. gubitak po koracima tijekom treniranja (D4).

    (a) Monte Carlo procjena broja $\pi$: generiraj $N$ slučajnih točaka u kvadratu $[0,1]^2$ generatorom random.Random(0) i izbroji koliko ih pada u četvrtinu jediničnog kruga; procjena je $4\cdot\dfrac{\text{broj u krugu}}{N}$. Ispiši procjenu za $N=10^3,10^4,10^5$. (b) Iz liste indeksa range(20) pomoću rng.sample izaberi $5$ za test, ostale za trening; provjeri da su skupovi disjunktni i da pokrivaju sve indekse.

    rng = random.Random(0) for N in (10 ** 3, 10 ** 4, 10 ** 5): u_krugu = sum(1 for _ in range(N) if rng.random() ** 2 + rng.random() ** 2 <= 1) print(f"N = {N:>6}: pi ≈ {4 * u_krugu / N:.4f}") rng = random.Random(1) svi = list(range(20)) test = sorted(rng.sample(svi, 5)) trening = [i for i in svi if i not in set(test)] print(test) print(len(trening), set(test).isdisjoint(trening), sorted(trening + test) == svi) N = 1000: pi ≈ 3.1280 N = 10000: pi ≈ 3.1432 N = 100000: pi ≈ 3.1484 [2, 3, 4, 8, 18] 15 True True

    Greška Monte Carlo procjene pada kao $1/\sqrt N$: sto puta više točaka daje tek jednu decimalu više. U (b) rng.sample bira bez ponavljanja, što je upravo podjela na trening i test; set(test) čini provjeru in brzom.

    Hiperparametri modela zadani su rječnikom {"stopa": [0.1, 0.01, 0.001], "slojevi": [1, 2], "dropout": [0.0, 0.5]}. Pomoću itertools.product prođi sve kombinacije (pretraga po mreži, engl. grid search), za svaku izračunaj „rezultat” zadanom funkcijom rezultat(stopa, slojevi, dropout) = 1 - abs(log10(stopa) + 2) / 4 - 0.05 * abs(slojevi - 2) - 0.1 * dropout i ispiši najbolju kombinaciju. Koliko kombinacija ima? Zatim s combinations ispiši sve parove hiperparametara.

    product(*vrijednosti) raspakira listu listi; zip(imena, kombinacija) vraća parove ime–vrijednost iz kojih se gradi rječnik. from itertools import product, combinations from math import log10, prod mreza = {"stopa": [0.1, 0.01, 0.001], "slojevi": [1, 2], "dropout": [0.0, 0.5]} def rezultat(stopa, slojevi, dropout): return 1 - abs(log10(stopa) + 2) / 4 - 0.05 * abs(slojevi - 2) - 0.1 * dropout imena = list(mreza) kombinacije = [dict(zip(imena, vr)) for vr in product(*mreza.values())] print(len(kombinacije), "=", prod(len(v) for v in mreza.values()), "kombinacija") najbolja = max(kombinacije, key=lambda k: rezultat(**k)) print(najbolja, round(rezultat(**najbolja), 3)) print(list(combinations(imena, 2))) 12 = 12 kombinacija {'stopa': 0.01, 'slojevi': 2, 'dropout': 0.0} 1.0 [('stopa', 'slojevi'), ('stopa', 'dropout'), ('slojevi', 'dropout')]

    Broj kombinacija je umnožak veličina – s pet hiperparametara po pet vrijednosti to je već $3125$ treniranja, zato se u praksi koristi slučajna pretraga (rng.choice za svaki hiperparametar) ili pametnije metode (lekcija M5). rezultat(**k) raspakira rječnik u imenovane argumente.

    Levenshteinova udaljenost dvaju nizova je najmanji broj umetanja, brisanja i zamjena znakova kojima se jedan pretvara u drugi. Rekurzivno: $d(i,j)$ je udaljenost prefiksa duljine $i$ i $j$; $d(i,0)=i$, $d(0,j)=j$, a inače $d(i,j)=\min\big(d(i-1,j)+1,\ d(i,j-1)+1,\ d(i-1,j-1)+[a_i\ne b_j]\big)$. Napiši rekurzivnu funkciju, dekoriraj je s broji_pozive iz Primjera 3 bez i s memoizacijom i usporedi broj poziva za riječi "inteligencija" i "inteligentan". Zatim napiši funkciju ispravi(rijec, rjecnik) koja vraća najbližu riječ iz rječnika.

    Memoiziraj po paru (i, j); nizove a i b drži izvan rekurzivne funkcije (ugniježđena funkcija ih vidi). def levenshtein(a: str, b: str, memo: bool = True) -> tuple[int, int]: """Vraća (udaljenost, broj stvarno izračunanih podproblema).""" @broji_pozive def d(i, j): if i == 0: return j if j == 0: return i zamjena = d(i - 1, j - 1) + (a[i - 1] != b[j - 1]) return min(d(i - 1, j) + 1, d(i, j - 1) + 1, zamjena) if memo: d = memoiziraj(d) udaljenost = d(len(a), len(b)) return udaljenost, d.__wrapped__.pozivi if memo else d.pozivi print("memoizirano: ", levenshtein("inteligencija", "inteligentan")) print("naivno: ", levenshtein("kuća", "kuhar", memo=False)) print("naivno: ", levenshtein("podaci", "podatak", memo=False)) def ispravi(rijec: str, rjecnik: list[str]) -> str: return min(rjecnik, key=lambda r: (levenshtein(rijec, r)[0], r)) rjecnik = ["model", "podaci", "gubitak", "gradijent", "epoha", "mreža"] for r in ["gradjent", "epoja", "modle", "mreza"]: print(r, "->", ispravi(r, rjecnik)) memoizirano: (4, 182) naivno: (2, 1021) naivno: (3, 29737) gradjent -> gradijent epoja -> epoha modle -> model mreza -> mreža

    Memoizirana verzija računa svaki par $(i,j)$ jednom – najviše $(|a|+1)(|b|+1)$ podproblema – dok naivna rekurzija grana u tri smjera i broj poziva eksplodira već za riječi od desetak slova (zato naivnu verziju pozivamo na kraćim riječima). Brojač opet čitamo preko __wrapped__ kao u Primjeru 3. Ispravljanje riječi najbližom iz rječnika osnovni je oblik provjere pravopisa; isti princip (udaljenost do najbližeg poznatog primjera) srest ćeš kao $k$-NN u lekciji M3.

    Napiši klasu Tokenizator s metodama fit(tekstovi, min_pojava=1) (gradi vokabular od riječi koje se pojavljuju barem min_pojava puta, s posebnim tokenima <pad> na indeksu $0$ i <unk> na indeksu $1$, ostale riječi po padajućoj učestalosti pa abecedno), encode(tekst) -> list[int], decode(indeksi) -> str i __len__ (veličina vokabulara). Nepoznate riječi kodiraj kao <unk>. Dodaj metodu encode_batch(tekstovi) koja sve nizove dopuni tokenom <pad> do duljine najduljeg.

    Counter daje učestalosti; sortiraj ključem (-broj, riječ). Za dopunjavanje: niz + [0] * (najdulji - len(niz)). class Tokenizator: def __init__(self): self.rijec_u_id: dict[str, int] = {} self.id_u_rijec: list[str] = [] @staticmethod def tokeni(tekst: str) -> list[str]: return tekst.lower().replace(",", " ").replace(".", " ").split() def fit(self, tekstovi: list[str], min_pojava: int = 1) -> "Tokenizator": brojac = Counter(t for tekst in tekstovi for t in self.tokeni(tekst)) rijeci = sorted((r for r, k in brojac.items() if k >= min_pojava), key=lambda r: (-brojac[r], r)) self.id_u_rijec = ["", ""] + rijeci self.rijec_u_id = {r: i for i, r in enumerate(self.id_u_rijec)} return self def __len__(self) -> int: return len(self.id_u_rijec) def encode(self, tekst: str) -> list[int]: return [self.rijec_u_id.get(t, 1) for t in self.tokeni(tekst)] def decode(self, indeksi: list[int]) -> str: return " ".join(self.id_u_rijec[i] for i in indeksi if i != 0) def encode_batch(self, tekstovi: list[str]) -> list[list[int]]: nizovi = [self.encode(t) for t in tekstovi] najdulji = max(len(n) for n in nizovi) return [n + [0] * (najdulji - len(n)) for n in nizovi] korpus = ["Model uči iz podataka.", "Podataka nikad nije previše, ali loših podataka je uvijek previše.", "Model, podaci, model."] tok = Tokenizator().fit(korpus, min_pojava=2) print(len(tok), tok.id_u_rijec) kod = tok.encode("Model uči iz loših podataka") print(kod, "->", tok.decode(kod)) for n in tok.encode_batch(["model podataka", "previše loših podataka nije model"]): print(n) 5 ['', '', 'model', 'podataka', 'previše'] [2, 1, 1, 1, 3] -> model podataka [2, 3, 0, 0, 0] [4, 1, 3, 1, 2]

    Riječi koje se pojavljuju samo jednom (uči, iz, nikad, …) ispale su iz vokabulara i kodiraju se kao $1$ (<unk>), a <pad> izjednačava duljine da se batch može složiti u matricu. To je točno sučelje tokenizatora iz biblioteke Hugging Face (lekcija V3): encode, decode, pad, posebni tokeni – samo što tamo tokeni nisu riječi nego dijelovi riječi.
