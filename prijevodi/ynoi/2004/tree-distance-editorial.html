Analiza rješenja · Ynoi 2004 · QOJ #5148

Udaljenost u stablu

Tree Distance

O ovom članku

Za Ynoi zadatke na QOJ-u nema službenog pisanog editoriala, pa je ova analiza autorska (izvori: vlastito rješenje (standardna tehnika „dominantnih parova”), provjereno brute-forceom). Opisano rješenje je implementirano i provjereno usporedbom s izravnim (brute-force) rješenjem na nasumičnim testovima. Gumb i otvara karticu s dodatnim objašnjenjem pojma.

Pregled zadatka

Za svaki upit $[l,r]$ tražimo najbliži par vrhova čije su oznake u intervalu $[l,r]$. Parova ima $\Theta(n^2)$, a upita do $10^6$, pa ne možemo gledati sve parove. Rješenje se sastoji od dva koraka:

  1. pokazati da je dovoljno promatrati samo $O(n\log n)$ parova kandidata,
  2. riješiti preostali, čisto „geometrijski” zadatak: zadano je $K$ parova $(i,j,d)$ i upiti $[l,r]$, a traži se najmanji $d$ među parovima s $l\le i\lt j\le r$.

Korak 0: dominacija parova

Kažemo da par $(i',j')$ dominira par $(i,j)$ ako je $i\le i'\lt j'\le j$ i $\mathrm{dist}(i',j')\le \mathrm{dist}(i,j)$. Svaki upit koji sadrži par $(i,j)$ sadrži i par $(i',j')$, a on nije lošiji. Zato dominirani par smijemo izbaciti, a da se nijedan odgovor ne promijeni. Cilj je pronaći malen skup parova koji dominira sve ostale.

Korak 1: kandidati iz centroid dekompozicije

Koristimo centroid dekompozicijuCentroid dekompozicijaCentroid stabla je vrh čijim uklanjanjem svaka preostala komponenta ima najviše pola vrhova. Dekompozicija: nađi centroid $c$ trenutne komponente, obradi sve putove koji prolaze kroz $c$, ukloni $c$ i rekurzivno ponovi u svakoj preostaloj komponenti.Dubina rekurzije je $O(\log n)$, pa je svaki vrh u $O(\log n)$ komponenti i zbroj veličina svih komponenti je $O(n\log n)$. Svaki put $u$–$v$ u stablu prolazi kroz centroid točno jedne komponente koja sadrži oba vrha: one u kojoj se $u$ i $v$ prvi put razdvoje.. Promotrimo jednu komponentu $S$ s centroidom $c$ i označimo s $d_v$ udaljenost vrha $v\in S$ do $c$ (unutar komponente). Za svaka dva vrha $u,v\in S$ vrijedi

\[ \mathrm{dist}(u,v)\le d_u+d_v, \]

a jednakost vrijedi kad put $u$–$v$ prolazi kroz $c$. Za svaki par $(u,v)$ postoji točno jedna komponenta u kojoj njegov put prolazi kroz centroid, pa vrijedi

\[ \mathrm{dist}(u,v)=\min_{S\ni u,v}\bigl(d^{S}_u+d^{S}_v\bigr). \]

Zato u svakoj komponenti smijemo paru $(u,v)$ pripisati „težinu” $d_u+d_v$ (i onda kad je to više od stvarne udaljenosti): odgovor se ne može smanjiti ispod pravog jer je svaka težina barem $\mathrm{dist}(u,v)$, a prava udaljenost se pojavi u barem jednoj komponenti.

Poredajmo vrhove komponente po oznaci: $v_1\lt v_2\lt\dots\lt v_k$.

Lema. Neka su $i\lt j$ vrhovi komponente i neka postoji vrh komponente $t$ s $i\lt t\lt j$ i $d_t\le\max(d_i,d_j)$. Tada postoji par vrhova komponente koji leži strogo unutar $[i,j]$ i čija težina nije veća od $d_i+d_j$.

(Dokaz.) Ako je $d_t\le d_j$, par $(i,t)$ ima težinu $d_i+d_t\le d_i+d_j$ i vrijedi $i\lt t\lt j$. Inače je $d_t\le d_i$, pa par $(t,j)$ ima težinu $d_t+d_j\le d_i+d_j$. $\blacksquare$

Ponavljanjem leme (interval se svaki put strogo smanjuje) zaključujemo: dovoljno je zadržati parove $(i,j)$ za koje svi vrhovi komponente s oznakom između $i$ i $j$ imaju $d$ strogo veći od $\max(d_i,d_j)$. Takav par je jednog od dva oblika:

  • $d_i\le d_j$: tada je $i$ najbliži lijevi vrh od $j$ s $d\le d_j$;
  • $d_i\gt d_j$: tada je $j$ najbliži desni vrh od $i$ s $d\lt d_i$.

Svaki vrh komponente tako daje najviše dva kandidata, a nalazimo ih jednim prolazom monotonim stogom po vrhovima poredanima po oznaci: dok je vrh stoga dublji od trenutnog vrha, skidamo ga (trenutni vrh je njegov najbliži desni s manjim $d$) i bilježimo par; kad skidanje stane, vrh stoga je najbliži lijevi s $d\le$ trenutnog i opet bilježimo par.

Ukupan broj kandidata je najviše $2\cdot\sum|S| = O(n\log n)$ (za $n=2\cdot10^5$ to je najviše oko $7\cdot10^6$). Sortiranje vrhova svake komponente po oznaci daje $O(n\log^2 n)$; može se izbjeći (npr. jednim globalnim sortiranjem i razdjeljivanjem), ali nije nužno.

Tvrdnja (točnost). Za svaki upit $[l,r]$ najmanja težina kandidata s $l\le i\lt j\le r$ jednaka je $\min_{l\le i\lt j\le r}\mathrm{dist}(i,j)$.

(Dokaz.) Svaki kandidat ima težinu $\ge$ stvarne udaljenosti svog para, pa minimum kandidata nije manji od pravog odgovora. Obrnuto, neka je $(i,j)$ optimalan par upita i $S$ komponenta u kojoj put $i$–$j$ prolazi kroz centroid; tamo je težina para točno $\mathrm{dist}(i,j)$. Ako par nije kandidat, lema daje par unutar $[i,j]\subseteq[l,r]$ s težinom ne većom; nastavljajući dolazimo do kandidata unutar $[l,r]$ s težinom $\le\mathrm{dist}(i,j)$. $\blacksquare$

Korak 2: upiti nad kandidatima

Preostaje: zadano je $K=O(n\log n)$ trojki $(i,j,d)$ i $q$ upita; za upit $[l,r]$ treba $\min d$ po trojkama s $i\ge l$ i $j\le r$. To je dvodimenzionalna dominacija koju rješavamo offline:

  • upite grupiramo po $l$, a kandidate sortiramo po $i$ silazno;
  • $l$ smanjujemo od $n$ do $1$; kad $l$ dosegne $i$ nekog kandidata, u Fenwickovo stablo za prefiksni minimum na poziciju $j$ upišemo $d$;
  • odgovor na upit $(l,r)$ je prefiksni minimum na pozicijama $1..r$ (ako je još $+\infty$, ispisujemo $-1$).

Fenwickovo stablo ovdje smije čuvati minimum jer se vrijednosti samo smanjuju, a pitamo isključivo prefikse.

Složenost

Kandidata je $O(n\log n)$, svaki se upiše u Fenwickovo stablo u $O(\log n)$, a svaki upit košta $O(\log n)$: ukupno $O(n\log^2 n+q\log n)$ vremena i $O(n\log n+q)$ memorije. Uz $q=10^6$ važno je brzo čitanje ulaza i ispis.

Implementacija

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll INF = LLONG_MAX;
int n, q;
vector<pair<int,int>> g[200005];
bool removed_[200005];
int sz[200005];
vector<array<ll,3>> cand; // (i, j, d) kandidati, i<j
vector<pair<int,ll>> comp; // (vrh, udaljenost do centroida)

int calc_size(int v, int p) {
    sz[v] = 1;
    for (auto [u, w] : g[v]) if (u != p && !removed_[u]) sz[v] += calc_size(u, v);
    return sz[v];
}
int find_centroid(int v, int p, int total) {
    for (auto [u, w] : g[v])
        if (u != p && !removed_[u] && 2 * sz[u] > total) return find_centroid(u, v, total);
    return v;
}
void collect(int v, int p, ll d) {
    comp.push_back({v, d});
    for (auto [u, w] : g[v]) if (u != p && !removed_[u]) collect(u, v, d + w);
}
void decompose(int v) {
    int c = find_centroid(v, 0, calc_size(v, 0));
    comp.clear();
    collect(c, 0, 0);
    sort(comp.begin(), comp.end()); // po oznaci vrha
    // monotoni stog po dubini: za svaki vrh najblizi lijevi s dubinom <= i najblizi desni s dubinom <=
    vector<int> st;
    for (int i = 0; i < (int)comp.size(); i++) {
        while (!st.empty() && comp[st.back()].second > comp[i].second) {
            // i je prvi desni s manjom dubinom za st.back()
            cand.push_back({comp[st.back()].first, comp[i].first, comp[st.back()].second + comp[i].second});
            st.pop_back();
        }
        if (!st.empty())
            cand.push_back({comp[st.back()].first, comp[i].first, comp[st.back()].second + comp[i].second});
        st.push_back(i);
    }
    removed_[c] = true;
    for (auto [u, w] : g[c]) if (!removed_[u]) decompose(u);
}
ll bit[200005];
void upd(int i, ll v) { for (; i <= n; i += i & -i) bit[i] = min(bit[i], v); }
ll qry(int i) { ll r = INF; for (; i > 0; i -= i & -i) r = min(r, bit[i]); return r; }
int main() {
    scanf("%d", &n);
    for (int i = 1; i < n; i++) {
        int a, b, w; scanf("%d %d %d", &a, &b, &w);
        g[a].push_back({b, w}); g[b].push_back({a, w});
    }
    decompose(1);
    scanf("%d", &q);
    vector<array<int,3>> qs(q);
    for (int i = 0; i < q; i++) { scanf("%d %d", &qs[i][1], &qs[i][0]); qs[i][0] = -qs[i][0]; qs[i][2] = i; }
    // obrada po l silazno: par (i,j) aktivan kad je i >= l; BIT po j cuva prefiksni minimum
    sort(cand.begin(), cand.end(), [](const array<ll,3>& a, const array<ll,3>& b) { return a[0] > b[0]; });
    vector<vector<pair<int,int>>> byL(n + 2);
    for (int i = 0; i < q; i++) byL[qs[i][1]].push_back({-qs[i][0], qs[i][2]});
    fill(bit, bit + n + 1, INF);
    vector<ll> ans(q);
    size_t p = 0;
    for (int l = n; l >= 1; l--) {
        while (p < cand.size() && cand[p][0] >= l) { upd(cand[p][1], cand[p][2]); p++; }
        for (auto [r, id] : byL[l]) { ll v = qry(r); ans[id] = v == INF ? -1 : v; }
    }
    for (int i = 0; i < q; i++) printf("%lld\n", ans[i]);
}

Sažetak

  • Par vrhova koji u svom intervalu oznaka sadrži drugi, ne dulji par može se zanemariti (dominacija).
  • U komponenti centroid dekompozicije paru pripišemo $d_u+d_v$; nakon sortiranja po oznaci samo parovi „bez plićeg vrha između” preživljavaju — najviše dva po vrhu, nalaze se monotonim stogom.
  • Ukupno $O(n\log n)$ kandidata; upiti se rješavaju offline po $l$ silazno, Fenwickovim stablom s prefiksnim minimumom po $j$.
  • Složenost: $O(n\log^2 n+q\log n)$.
