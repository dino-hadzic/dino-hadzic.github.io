O ovom članku

Za Ynoi zadatke na QOJ-u nema službenog pisanog editoriala, pa je ova analiza autorska (izvori: CTS 2022 (Luogu P8257; rješenja juju527, 18Michael, GotoHiotori); vlastita implementacija provjerena brute-forceom). Opisano rješenje je implementirano i provjereno usporedbom s izravnim (brute-force) rješenjem na nasumičnim testovima. Gumb i otvara karticu s dodatnim objašnjenjem pojma.

Pregled zadatka

Treba XOR broja različitih vrijednosti po svim podintervalima zadanog intervala. Rješenje:

  • sweep po desnom rubu pretvara zadatak u „dodaj 1 na intervalu” i „XOR svih dosadašnjih verzija na intervalu” (povijesni XOR);
  • XOR se ne slaže lijepo sa zbrajanjem, pa nema polilogaritamske strukture — koristimo blokove veličine $\sqrt n$;
  • ključni potprogram: za skup $S$ i sve $x\in[0,T)$ izračunati $\bigoplus_{s\in S}(s+x)$ u $O(|S|+T)$.

Složenost je $O\bigl((n+m)\sqrt n\bigr)$ uz $O(n+m)$ memorije.

Izravno rješenje

Za svaki lijevi rub $L$ širimo $R$ i brojimo različite vrijednosti: $O(n^2)$ težina, a upit ih zbraja u $O(n^2)$. Služi samo za provjeru.

Korak 1: sweep po desnom rubu

Idemo po $r=1,2,\dots,n$ i održavamo $A_l$ = broj različitih vrijednosti u $[l,r]$. Neka je $p$ prethodna pojava vrijednosti $a_r$ (ili $0$). Prelaskom na $r$ vrijednost $a_r$ je nova točno za $l\in(p,r]$:

\[ A_l\leftarrow A_l+1\quad\text{za } p\lt l\le r. \]

Uvedimo $H_l=\bigoplus_{R=l}^{r}w(l,R)$, XOR svih dosadašnjih vrijednosti $A_l$. Nakon ažuriranja niza $A$ radimo povijesni korak: $H_l\leftarrow H_l\oplus A_l$ za sve $l$ (za $l\gt r$ je $A_l=0$, pa ne smeta). Odgovor na upit $(l,r)$ je, nakon koraka $r$,

\[ H_l\oplus H_{l+1}\oplus\dots\oplus H_r. \]

Trebaju nam dakle tri operacije: (1) $+1$ na intervalu niza $A$, (2) $H_l\mathrel{\oplus}=A_l$ za sve $l$, (3) XOR intervala niza $H$.

Svojstvo niza $A$. $A_l$ ne raste po $l$ i susjedni se članovi razlikuju najviše za $1$ (interval $[l,r]$ ima najviše jednu vrijednost više od $[l+1,r]$). Zato je unutar bloka od $T$ uzastopnih položaja $\max A-\min A\lt T$.

Korak 2: blokovi

Niz dijelimo u blokove veličine $T=2^k\approx\sqrt n$ (u kodu $T=512$). Za blok pamtimo:

  • $a_i$ i $H_i$ — vrijednosti elemenata bez odgođenih promjena;
  • $\mathit{tag}\lt T$ — broj još neprovedenih „$+1$ cijelom bloku”;
  • $F[x]=\bigoplus_i(a_i+x)$ za sve $x\in[0,T)$;
  • $\mathit{HS}$ — XOR stvarnih vrijednosti $H_i$ bloka;
  • $\mathit{pend}[x]$ — paritet broja povijesnih koraka koji su se dogodili uz $\mathit{tag}=x$, a još nisu upisani u $H_i$.

Povijesni korak za cijeli blok: stvarne vrijednosti su $a_i+\mathit{tag}$, pa je $\mathit{HS}\mathrel{\oplus}=F[\mathit{tag}]$ i $\mathit{pend}[\mathit{tag}]\mathrel{\oplus}=1$. To je $O(1)$ po bloku, $O(n/T)$ po koraku. Dva koraka s istom oznakom se u $H_i$ poništavaju — zato je dovoljan paritet.

$+1$ cijelom bloku: $\mathit{tag}\leftarrow\mathit{tag}+1$; ako dosegne $T$, blok obnavljamo.

Djelomično zahvaćen blok (rub ažuriranja ili upita) obnavljamo:

  1. provođenje u $H$: $H_i\mathrel{\oplus}=\bigoplus_{x:\,\mathit{pend}[x]=1}(a_i+x)$, pa brišemo $\mathit{pend}$;
  2. provođenje oznake: $a_i\leftarrow a_i+\mathit{tag}$, $\mathit{tag}\leftarrow0$, zatim eventualni $+1$ na dijelu bloka;
  3. ponovno računanje $F$.

Upitu treba samo prvi dio (na rubnim blokovima), a za pune blokove koristi $\mathit{HS}$ preko prefiksnih XOR-ova po blokovima.

Obnova ima $O(n+m)$ zbog rubova i $O(n^2/T^2)=O(n)$ zbog prelijevanja oznake (blok primi najviše $n$ puta $+1$). Preostaje svaku obaviti u $O(T)$.

Korak 3: obje obnove su isti problem

Potprogram. Za multiskup $S$ nenegativnih brojeva izračunaj $G[x]=\bigoplus_{s\in S}(s+x)$ za sve $x\in[0,T)$.

  • Računanje $F$: $S=\{a_i\}$, $x$ je oznaka.
  • Provođenje u $H$: neka je $\mu=\min a_i$ i $d_i=a_i-\mu\in[0,T)$ (svojstvo niza $A$). Tada je $a_i+x=(x+\mu)+d_i$, pa uzmemo $S=\{x+\mu:\mathit{pend}[x]=1\}$ i $H_i\mathrel{\oplus}=G[d_i]$. Uloge elemenata i oznaka su se zamijenile.

Korak 4: potprogram u $O(|S|+T)$

Svaki $s$ rastavimo na $s=\mathit{hi}\cdot T+\mathit{lo}$, $0\le\mathit{lo}\lt T$. Tada je

\[ s+x=\bigl(\mathit{hi}+[\mathit{lo}+x\ge T]\bigr)\cdot T+\bigl((\mathit{lo}+x)\bmod T\bigr). \]

Viši dio. Za $x\lt T-\mathit{lo}$ doprinos je $\mathit{hi}$, inače $\mathit{hi}+1$. Krenemo od $\bigoplus\mathit{hi}$ i u razliku na položaju $T-\mathit{lo}$ upišemo $\mathit{hi}\oplus(\mathit{hi}+1)$; prefiksni XOR daje viši dio za sve $x$. Cijena $O(|S|+T)$.

Niži dio. Treba $L[x]=\bigoplus_s\bigl((\mathit{lo}_s+x)\bmod T\bigr)$. Bit $j$ broja $(\mathit{lo}+x)\bmod T$ ovisi samo o $\mathit{lo}\bmod 2^{j+1}$ i $x\bmod 2^{j+1}$: jednak je $1$ točno kad je $(\mathit{lo}+x)\bmod 2^{j+1}\ge 2^j$. Zato za svaki $j$:

  1. imamo paritete $f_j[v]$ broja elemenata s $\mathit{lo}\equiv v\pmod{2^{j+1}}$; dobivaju se „preklapanjem”: $f_{j-1}[v]=f_j[v]\oplus f_j[v+2^j]$;
  2. za $x\in[0,2^{j+1})$ bit $j$ je paritet elemenata čiji ostatak leži u cikličkom prozoru $[2^j-x,\,2^{j+1}-x)$ modulo $2^{j+1}$ — očitamo ga iz prefiksnih pariteta u $O(1)$;
  3. rezultat za donjih $j+1$ bitova, $M_j[x]$ za $x\in[0,2^{j+1})$, je $M_{j-1}[x\bmod 2^j]$ s dodanim bitom $j$.

Razina $j$ košta $O(2^{j+1})$, ukupno $2+4+\dots+T=O(T)$. Na kraju je $L=M_{k-1}$ i $G[x]=\text{viši}[x]\cdot T+L[x]$.

Složenost

  • povijesni koraci i $+1$ punim blokovima: $O(n\cdot n/T)$;
  • obnove: $O(n+m)$ puta po $O(T)$;
  • upiti: $O(T)$ za rubove i $O(1)$ za pune blokove, uz $O(n/T)$ po koraku za prefiksne XOR-ove.

Uz $T\approx\sqrt n$ ukupno $O\bigl((n+m)\sqrt n\bigr)$ vremena. Tablice $F$ i $\mathit{pend}$ imaju $n/T$ blokova po $T$ članova, dakle $O(n)$ memorije. Za $n=m=4\cdot10^5$ implementacija radi oko 6 s (nasumični niz), unutar ograničenja od 15 s.

Implementacija

Indeksi su od $0$. Kad je neprovedenih oznaka najviše četiri, provođenje u $H$ radi se izravno — to je čest slučaj kod bloka koji sadrži $r$.

// Prohorovka (QOJ 4405): XOR broja razlicitih vrijednosti po svim podintervalima upita.
// Sweep po desnom rubu + korijenska dekompozicija s "povijesnim XOR-om".
#include <bits/stdc++.h>
using namespace std;

const int K = 9, T = 1 << K;          // velicina bloka i granica oznake (tag) su T = 2^K
const int MAXN = 400005, MAXB = MAXN / T + 2;

int n, m, nb;
int a[MAXN + T];       // a[l]: broj razlicitih u [l, r], bez oznake bloka
int H[MAXN + T];       // H[l]: XOR vrijednosti a[l] kroz sve dosadasnje korake, bez neprovedenih
int tagv[MAXB];        // neprovedena dodavanja +1 cijelom bloku (uvijek < T)
int HS[MAXB];          // XOR stvarnih povijesnih vrijednosti bloka
int F[MAXB][T];        // F[b][x] = XOR_i (a_i + x) po elementima bloka
unsigned char pend[MAXB][T]; // paritet: koliko je puta korak zavrsio uz oznaku x, a da nije proveden u H
int pcnt[MAXB];

// G[x] = XOR_{s u vals} (s + x) za sve x u [0, T), u O(cnt + T)
int cpar[T], D[T + 1], Mlow[2][T], G[T], vals[T + 5];
void computeG(int cnt) {
    memset(cpar, 0, sizeof cpar);
    memset(D, 0, sizeof D);
    int base = 0;
    for (int i = 0; i < cnt; i++) {
        int lo = vals[i] & (T - 1), hi = vals[i] >> K;
        cpar[lo] ^= 1;
        base ^= hi;
        if (lo) D[T - lo] ^= hi ^ (hi + 1);   // za x >= T - lo dolazi prijenos u visi dio
    }
    // nizi bitovi: f[j] = pariteti ostataka modulo 2^(j+1)
    static int f[K][T], R[T + 1];
    memcpy(f[K - 1], cpar, sizeof cpar);
    for (int j = K - 1; j >= 1; j--) {
        int h = 1 << j;
        for (int v = 0; v < h; v++) f[j - 1][v] = f[j][v] ^ f[j][v + h];
    }
    int cur = 0;
    for (int j = 0; j < K; j++) {
        int h = 1 << j, sz = h << 1;
        // R[v] = paritet broja elemenata s ostatkom < v
        R[0] = 0;
        for (int v = 0; v < sz; v++) R[v + 1] = R[v] ^ f[j][v];
        int *nw = Mlow[cur ^ 1], *od = Mlow[cur];
        for (int x = 0; x < sz; x++) {
            // bit j od (v + x) je 1 za v u ciklickom prozoru [h - x, 2h - x) modulo 2h
            int bit;
            if (x <= h) bit = R[sz - x] ^ R[h - x];
            else bit = R[sz - x] ^ R[sz] ^ R[sz + h - x];
            nw[x] = (j ? od[x & (h - 1)] : 0) | (bit << j);
        }
        cur ^= 1;
    }
    int *lowp = Mlow[cur];
    int acc = base;
    for (int x = 0; x < T; x++) {
        acc ^= D[x];
        G[x] = (acc << K) | lowp[x];
    }
}

inline int bl(int b) { return b * T; }
inline int br(int b) { return min(n, (b + 1) * T) - 1; }

// provedi neprovedene korake u H elemenata bloka
void pushH(int b) {
    if (!pcnt[b]) return;
    int l = bl(b), r = br(b);
    int mn = a[l];
    for (int i = l + 1; i <= r; i++) mn = min(mn, a[i]);
    int cnt = 0;
    unsigned char *p = pend[b];
    for (int x = 0; x < T; x++) if (p[x]) { vals[cnt++] = x + mn; p[x] = 0; }
    pcnt[b] = 0;
    if (cnt == 0) return;
    if (cnt <= 4) {     // malo razlicitih oznaka: izravno
        for (int i = l; i <= r; i++) {
            int d = a[i] - mn, g = 0;
            for (int j = 0; j < cnt; j++) g ^= vals[j] + d;
            H[i] ^= g;
        }
        return;
    }
    computeG(cnt);
    for (int i = l; i <= r; i++) H[i] ^= G[a[i] - mn];   // a[i] - mn < T
}
void rebuildF(int b) {
    int l = bl(b), r = br(b), cnt = 0;
    for (int i = l; i <= r; i++) vals[cnt++] = a[i];
    computeG(cnt);
    memcpy(F[b], G, sizeof G);
}
// potpuna obnova: H i a postaju stvarni, oznaka 0; zatim +1 na [x, y] unutar bloka
void rebuildAdd(int b, int x, int y) {
    pushH(b);
    int l = bl(b), r = br(b), t = tagv[b];
    if (t) for (int i = l; i <= r; i++) a[i] += t;
    tagv[b] = 0;
    for (int i = x; i <= y; i++) a[i]++;
    rebuildF(b);
}

int main() {
    if (scanf("%d %d", &n, &m) != 2) return 0;
    vector<int> col(n), last(n + 1, -1);
    for (int i = 0; i < n; i++) scanf("%d", &col[i]);
    vector<int> ql(m), qhead(n, -1), qnext(m, -1), ans(m);
    for (int i = 0; i < m; i++) {
        int l, r;
        scanf("%d %d", &l, &r);
        l--; r--;
        ql[i] = l; qnext[i] = qhead[r]; qhead[r] = i;
    }
    nb = (n + T - 1) / T;
    vector<int> pre(nb + 1);
    for (int r = 0; r < n; r++) {
        // 1) a[l]++ za l u (prethodna pojava, r]
        int lo = last[col[r]] + 1, hi = r;
        last[col[r]] = r;
        int b1 = lo / T, b2 = hi / T;
        if (b1 == b2) rebuildAdd(b1, lo, hi);
        else {
            if (lo == bl(b1)) b1--; else rebuildAdd(b1, lo, br(b1));
            for (int b = b1 + 1; b < b2; b++)
                if (++tagv[b] == T) rebuildAdd(b, 0, -1);
            rebuildAdd(b2, bl(b2), hi);
        }
        // 2) povijesni korak: H[l] ^= a[l] za sve l (desno od r je a = 0)
        for (int b = 0; b <= b2; b++) {
            int t = tagv[b];
            HS[b] ^= F[b][t];
            pend[b][t] ^= 1;
            pcnt[b]++;
        }
        // 3) upiti s desnim rubom r
        if (qhead[r] < 0) continue;
        pre[0] = 0;
        for (int b = 0; b <= b2; b++) pre[b + 1] = pre[b] ^ HS[b];
        pushH(b2);
        for (int q = qhead[r]; q >= 0; q = qnext[q]) {
            int l = ql[q], c1 = l / T, res = 0;
            if (c1 == b2) {
                for (int i = l; i <= r; i++) res ^= H[i];
            } else {
                for (int i = bl(b2); i <= r; i++) res ^= H[i];
                res ^= pre[b2] ^ pre[c1 + 1];
                if (l == bl(c1)) res ^= HS[c1];
                else {
                    pushH(c1);
                    for (int i = l; i <= br(c1); i++) res ^= H[i];
                }
            }
            ans[q] = res;
        }
    }
    string out;
    for (int i = 0; i < m; i++) { out += to_string(ans[i]); out += '\n'; }
    fputs(out.c_str(), stdout);
}

Sažetak

  • Sweep po $r$: $+1$ na $(p,r]$, zatim $H_l\mathrel{\oplus}=A_l$; upit je XOR od $H_l,\dots,H_r$.
  • Blok pamti oznaku, tablicu $F[x]=\bigoplus(a_i+x)$ i paritete neprovedenih koraka po oznaci.
  • Obje obnove svode se na $\bigoplus_{s\in S}(s+x)$ za sve $x\lt T$.
  • Viši bitovi: prefiksni XOR po pragu prijenosa; niži bitovi: razina po razina s tablicama veličine $2^{j+1}$.
  • Složenost: $O((n+m)\sqrt n)$ vremena, $O(n+m)$ memorije.
