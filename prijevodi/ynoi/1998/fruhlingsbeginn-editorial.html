Analiza rješenja · Ynoi 1998 · QOJ #11283

Frühlingsbeginn

O ovom članku

Za Ynoi zadatke na QOJ-u nema službenog pisanog editoriala, pa je ova analiza autorska (izvori: Luogu P12082 (rješenje xuyifei1599); vlastita implementacija provjerena brute-forceom). Opisano rješenje je implementirano i provjereno usporedbom s izravnim (brute-force) rješenjem na nasumičnim testovima. Gumb i otvara karticu s dodatnim objašnjenjem pojma.

Pregled zadatka

Interval $[l,r)$ promatramo kao skup ćelija $l, l+1,\dots,r-1$, tj. zatvoreni interval $[l,r-1]$ na ćelijama $1,\dots,n-1$. U nastavku su svi intervali zatvoreni intervali ćelija.

Zapažanje 1. Odgovor na upit $[l,r]$ je „da” ako i samo ako unija svih trenutačno prisutnih intervala koji su sadržani u $[l,r]$ pokriva cijeli $[l,r]$.

(Dokaz.) U podskup smiju ući samo intervali sadržani u $[l,r]$ (inače unija izlazi van). Uzeti ih sve daje najveću moguću uniju, pa ako ni ona nije cijeli $[l,r]$, nijedan podskup nije. $\blacksquare$

Zadatak rješavamo offline. Svaki ubačeni interval dobije „životni vijek” $(s,e)$: $s$ je redni broj operacije koja ga je ubacila, $e$ redni broj operacije koja ga je izbrisala (ili $m+1$). Upit postavljen u operaciji $t$ vidi interval ako je $s\lt t\lt e$. Tako dobivamo statički problem s tri uvjeta — lijevi rub, desni rub i vrijeme — koji rješavamo tehnikom podijeli pa vladaj po koordinati. Složenost: $O(m\log^2 m)$ (uz $O(m\log n\log m)$ kao precizniju ocjenu).

Izravno rješenje

Za svaki upit prođemo sve žive intervale, označimo ćelije onih koji su unutar $[l,r]$ i provjerimo je li sve pokriveno: $O(m\cdot(m+n))$. Koristimo ga kao referencu.

Podijeli pa vladaj po koordinati

Rekurzija $\mathrm{solve}(L,R)$ dobije sve intervale i sve upite sadržane u $[L,R]$. Neka je $\mathit{mid}=\lfloor(L+R)/2\rfloor$. Upite koji ne prelaze sredinu proslijedimo djeci, zajedno s intervalima sadržanima u odgovarajućoj polovici. Upite s $l\le\mathit{mid}\lt r$ rješavamo ovdje. Za takav upit korisni intervali su triju vrsta:

  • srednji: prelaze sredinu (sadrže ćelije $\mathit{mid}$ i $\mathit{mid}+1$);
  • lijevi: sadržani u $[L,\mathit{mid}]$;
  • desni: sadržani u $[\mathit{mid}+1,R]$.

Svaki je upit obrađen u točno jednom čvoru, a svaki interval sudjeluje u $O(\log n)$ čvorova (na putu do čvora u kojem je srednji).

1) Srednji intervali: unija je jedan interval $[f,g]$

Svi srednji intervali sadrže $\mathit{mid}$, pa je unija onih koji su živi i sadržani u upitu povezana: jednaka je $[f,g]$, gdje je $f$ najmanji lijevi rub, a $g$ najveći desni rub među njima. Ako takvih nema, stavimo $f=\mathit{mid}+1$, $g=\mathit{mid}$ (prazno).

Za svaki lijevi rub $x$ neka je $A_x$ najmanji desni rub živog srednjeg intervala koji počinje u $x$ (ili $+\infty$). Tada je

\[ f=\min\{x\ge l : A_x\le r\}. \]

Naime, ako ijedan interval s lijevim rubom $x$ stane u upit, stane i onaj s najmanjim desnim rubom. Simetrično, $B_y$ je najveći lijevi rub živog srednjeg intervala koji završava u $y$ i $g=\max\{y\le r: B_y\ge l\}$.

Prolazimo vrijeme (sweep po $t$): događaji „interval se rodio / umro” mijenjaju $A_x$ i $B_y$, a upit u trenutku $t$ pita za $f$ i $g$. Vrijednosti $A_x$ držimo u segmentnom stablu s minimumom nad (sažetim) lijevim rubovima; traženje „prvog $x\ge l$ s $A_x\le r$” je spuštanje po stablu. Budući da više intervala može imati isti rub, za svaki $x$ držimo gomilu s lijenim brisanjem.

2) Lijevi intervali: dokle seže pokrivanje od $l$

Lijevi intervali moraju pokriti ćelije $l,\dots,f-1$. Definiramo $h$ kao prvu ćeliju koju živi lijevi intervali s lijevim rubom $\ge l$ ne pokrivaju kad krenemo od $l$ udesno. Uvjet je $h\ge f$.

Računamo $h$ za sve upite čvora odjednom, prolazeći koordinatu $a$ slijeva nadesno. Upiti su poredani po vremenu i čine listove segmentnog stabla; list pamti trenutačni $h$ svog upita.

  • Kad $a$ dosegne $l$ nekog upita, upit se „aktivira” s $h=l$.
  • Lijevi interval $[a,b]$ sa životnim vijekom $(s,e)$ svim aktivnim upitima s vremenom u $(s,e)$ radi $h\leftarrow\max(h,b+1)$ — to je chmax na intervalu listova.
  • Prije obrade koordinate $a$ iz stabla izvadimo sve upite s $h\lt a$: ćelija $h$ im je ostala nepokrivena, a svi budući intervali počinju desno od nje, pa im je $h$ konačan.

Zašto je chmax smije primijeniti na sve aktivne upite. U trenutku obrade intervala $[a,b]$ svaki aktivni upit ima $l\le a$ (aktiviran je ranije) i $h\ge a$ (inače bi bio izvađen). Dakle interval je unutar upita s lijeve strane i nadovezuje se na već pokriveni dio $[l,h-1]$ bez rupe.

Stablo pamti minimum podstabla (da brzo nađemo upite za vađenje) i lijenu chmax oznaku. Neaktivni i izvađeni listovi imaju vrijednost $+\infty$, pa na njih chmax ne djeluje; pri aktivaciji lista prvo spustimo oznake na putu do njega da stare oznake ne bi djelovale na novi upit.

3) Desni intervali

Zrcalno: krećemo od $r$ ulijevo i tražimo prvu nepokrivenu ćeliju $k$; uvjet je $k\le g$. U kodu se koristi ista procedura na koordinatama pomnoženima s $-1$.

Tvrdnja. Odgovor na upit je „da” ako i samo ako je $h\ge f$ i $k\le g$.

(Dokaz.) Unija svih korisnih intervala je $U_L\cup[f,g]\cup U_D$, gdje su $U_L\subseteq[l,\mathit{mid}]$ i $U_D\subseteq[\mathit{mid}+1,r]$ unije lijevih, odnosno desnih. Ćelije $l,\dots,f-1$ mogu pokriti samo lijevi intervali, i pokrivene su sve upravo kad je $h\ge f$. Ako je $[f,g]$ prazan, uvjet $h\ge\mathit{mid}+1$ znači da lijevi sami pokrivaju cijelu lijevu polovicu upita. Analogno za desnu stranu. Po zapažanju 1 to je traženi uvjet. $\blacksquare$

List rekurzije

Ako je $L=R$, upit i intervali su jedna te ista ćelija, pa samo treba znati je li u trenutku $t$ živ barem jedan interval: broj rođenih prije $t$ minus broj umrlih prije $t$.

Složenost

Svaki interval sudjeluje u $O(\log n)$ čvorova, a u svakom košta $O(\log m)$ (sortiranje, binarno pretraživanje vremena, operacija nad stablom). Chmax s prekidom „ako je minimum već $\ge v$” i vađenje upita amortizirano su $O(\log m)$ po operaciji, odnosno po izvađenom upitu. Ukupno

\[ O(m\log n\log m) \]

vremena i $O(n+m)$ memorije (popisi se oslobađaju prije rekurzije). Rekurzija ulazi samo u čvorove koji imaju upita. Implementacija na najvećim testovima radi ispod $0{,}5$ s.

Implementacija

#include <bits/stdc++.h>
using namespace std;

const int INF = INT_MAX;
struct Itv { int a, b, s, e; };   // celije [a,b], zivi u trenucima s < t < e
struct Qry { int l, r, t; };
vector<Itv> I;
vector<Qry> Q;
vector<char> ok;

// ---- stablo po vremenu: chmax na intervalu, minimum, vadjenje ----
vector<int> mn, tg, hres;
void tpush(int o) {
    if (tg[o] != -INF) {
        for (int c = 2 * o; c <= 2 * o + 1; c++) {
            if (mn[c] != INF) mn[c] = max(mn[c], tg[o]);
            tg[c] = max(tg[c], tg[o]);
        }
        tg[o] = -INF;
    }
}
void tset(int o, int l, int r, int p, int v) {
    if (l == r) { mn[o] = v; return; }
    tpush(o);
    int m = (l + r) / 2;
    if (p <= m) tset(2 * o, l, m, p, v); else tset(2 * o + 1, m + 1, r, p, v);
    mn[o] = min(mn[2 * o], mn[2 * o + 1]);
}
void tchmax(int o, int l, int r, int a, int b, int v) {
    if (mn[o] >= v) return;            // nista se ne mijenja (ukljucuje prazno podstablo)
    if (a <= l && r <= b) { mn[o] = max(mn[o], v); tg[o] = max(tg[o], v); return; }
    tpush(o);
    int m = (l + r) / 2;
    if (a <= m) tchmax(2 * o, l, m, a, b, v);
    if (b > m) tchmax(2 * o + 1, m + 1, r, a, b, v);
    mn[o] = min(mn[2 * o], mn[2 * o + 1]);
}
// izvadi sve listove s vrijednoscu < lim, zapisi im rezultat
void tpop(int o, int l, int r, int lim) {
    if (mn[o] >= lim) return;
    if (l == r) { hres[l] = mn[o]; mn[o] = INF; return; }
    tpush(o);
    int m = (l + r) / 2;
    tpop(2 * o, l, m, lim); tpop(2 * o + 1, m + 1, r, lim);
    mn[o] = min(mn[2 * o], mn[2 * o + 1]);
}

struct SI { int a, b, lo, hi; };   // interval celija i raspon indeksa upita (po vremenu)
struct SQ { int start, idx; };
// za svaki upit: prva nepokrivena celija kad krenemo od start udesno
void sweep(vector<SI> &its, vector<SQ> &qs, int K) {
    sort(its.begin(), its.end(), [](const SI &x, const SI &y) { return x.a < y.a; });
    sort(qs.begin(), qs.end(), [](const SQ &x, const SQ &y) { return x.start < y.start; });
    mn.assign(4 * K, INF); tg.assign(4 * K, -INF); hres.assign(K, 0);
    size_t pi = 0, pq = 0;
    while (pi < its.size() || pq < qs.size()) {
        int a = INF;
        if (pi < its.size()) a = min(a, its[pi].a);
        if (pq < qs.size()) a = min(a, qs[pq].start);
        tpop(1, 0, K - 1, a);     // upiti zapeli prije a
        while (pq < qs.size() && qs[pq].start == a) { tset(1, 0, K - 1, qs[pq].idx, a); pq++; }
        while (pi < its.size() && its[pi].a == a) { tchmax(1, 0, K - 1, its[pi].lo, its[pi].hi, its[pi].b + 1); pi++; }
    }
    tpop(1, 0, K - 1, INF);
}

// ---- stablo za intervale koji prelaze sredinu: minimum po sazetim koordinatama ----
struct MinTree {
    int n; vector<int> t;
    void init(int n_) { n = 1; while (n < n_) n *= 2; t.assign(2 * n, INF); }
    void set(int p, int v) { p += n; t[p] = v; for (p >>= 1; p; p >>= 1) t[p] = min(t[2 * p], t[2 * p + 1]); }
    // najmanji indeks >= from s vrijednoscu <= lim, ili -1
    int first(int from, int lim) {
        if (from >= n) return -1;
        int p = from + n;
        if (t[p] > lim) {
            while (true) {
                while (p & 1) { p >>= 1; if (p == 0) return -1; }
                if (p == 1) return -1;       // from je bio u lijevom rubu, nema desnog brata
                p++;
                if (t[p] <= lim) break;
            }
            while (p < n) p = t[2 * p] <= lim ? 2 * p : 2 * p + 1;
        }
        return p - n;
    }
};

void solve(int L, int R, vector<int> &iv, vector<int> &qs) {
    if (qs.empty()) return;
    if (L == R) {
        vector<int> st, en;
        for (int id : iv) { st.push_back(I[id].s); en.push_back(I[id].e); }
        sort(st.begin(), st.end()); sort(en.begin(), en.end());
        for (int id : qs) {
            int t = Q[id].t;
            int alive = int(lower_bound(st.begin(), st.end(), t) - st.begin()) - int(lower_bound(en.begin(), en.end(), t) - en.begin());
            ok[id] = alive > 0;
        }
        return;
    }
    int mid = (L + R) / 2;
    vector<int> here, ql, qr, il, ir, ic;
    for (int id : qs) {
        if (Q[id].r <= mid) ql.push_back(id);
        else if (Q[id].l > mid) qr.push_back(id);
        else here.push_back(id);
    }
    for (int id : iv) {
        if (I[id].b <= mid) il.push_back(id);
        else if (I[id].a > mid) ir.push_back(id);
        else ic.push_back(id);
    }
    if (!here.empty()) {
        int K = here.size();
        sort(here.begin(), here.end(), [](int x, int y) { return Q[x].t < Q[y].t; });
        vector<int> ts(K), f(K, mid + 1), g(K, mid);
        for (int i = 0; i < K; i++) ts[i] = Q[here[i]].t;
        // 1) intervali preko sredine: unija onih unutar upita je [f,g]
        if (!ic.empty()) {
            vector<int> xs, ys;
            for (int id : ic) { xs.push_back(I[id].a); ys.push_back(-I[id].b); }
            sort(xs.begin(), xs.end()); xs.erase(unique(xs.begin(), xs.end()), xs.end());
            sort(ys.begin(), ys.end()); ys.erase(unique(ys.begin(), ys.end()), ys.end());
            typedef priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> PQ;
            vector<PQ> ha(xs.size()), hb(ys.size());
            MinTree ta, tb; ta.init(xs.size()); tb.init(ys.size());
            vector<array<int,3>> ev; // (vrijeme, tip: 0 dodaj / 1 makni, id)
            for (int id : ic) { ev.push_back({I[id].s, 0, id}); ev.push_back({I[id].e, 1, id}); }
            sort(ev.begin(), ev.end());
            static vector<char> dead; if (dead.size() < I.size()) dead.assign(I.size(), 0);
            size_t pe = 0;
            for (int i = 0; i < K; i++) {
                while (pe < ev.size() && ev[pe][0] < ts[i]) {
                    int id = ev[pe][2];
                    int px = lower_bound(xs.begin(), xs.end(), I[id].a) - xs.begin();
                    int py = lower_bound(ys.begin(), ys.end(), -I[id].b) - ys.begin();
                    if (ev[pe][1] == 0) { ha[px].push({I[id].b, id}); hb[py].push({-I[id].a, id}); }
                    else dead[id] = 1;
                    while (!ha[px].empty() && dead[ha[px].top().second]) ha[px].pop();
                    while (!hb[py].empty() && dead[hb[py].top().second]) hb[py].pop();
                    ta.set(px, ha[px].empty() ? INF : ha[px].top().first);
                    tb.set(py, hb[py].empty() ? INF : hb[py].top().first);
                    pe++;
                }
                const Qry &q = Q[here[i]];
                int px = ta.first(lower_bound(xs.begin(), xs.end(), q.l) - xs.begin(), q.r);
                if (px >= 0) {
                    f[i] = xs[px];
                    int py = tb.first(lower_bound(ys.begin(), ys.end(), -q.r) - ys.begin(), -q.l);
                    g[i] = -ys[py];
                }
            }
            for (int id : ic) dead[id] = 0;
        }
        // 2) lijevo: pokrivanje od l udesno; 3) desno: zrcalno
        vector<char> good(K, 1);
        for (int side = 0; side < 2; side++) {
            vector<SI> its; vector<SQ> sq(K);
            for (int id : (side ? ir : il)) {
                int lo = upper_bound(ts.begin(), ts.end(), I[id].s) - ts.begin();
                int hi = int(lower_bound(ts.begin(), ts.end(), I[id].e) - ts.begin()) - 1;
                if (lo > hi) continue;
                if (side == 0) its.push_back({I[id].a, I[id].b, lo, hi});
                else its.push_back({-I[id].b, -I[id].a, lo, hi});
            }
            for (int i = 0; i < K; i++) sq[i] = {side ? -Q[here[i]].r : Q[here[i]].l, i};
            sweep(its, sq, K);
            for (int i = 0; i < K; i++) {
                if (side == 0) { if (hres[i] < f[i]) good[i] = 0; }
                else { if (hres[i] < -g[i]) good[i] = 0; }
            }
        }
        for (int i = 0; i < K; i++) ok[here[i]] = good[i];
    }
    vector<int>().swap(here); vector<int>().swap(ic); vector<int>().swap(iv); vector<int>().swap(qs);
    solve(L, mid, il, ql);
    solve(mid + 1, R, ir, qr);
}

static char buf[1 << 25];
int main() {
    size_t len = fread(buf, 1, sizeof(buf) - 1, stdin); buf[len] = 0;
    char *p = buf;
    auto rd = [&]() { while (*p && (*p < '0' || *p > '9')) p++; int x = 0; while (*p >= '0' && *p <= '9') x = x * 10 + *p++ - '0'; return x; };
    int n = rd(), m = rd();
    vector<int> idOf(m + 1, -1);
    for (int t = 1; t <= m; t++) {
        int op = rd();
        if (op == 1) { int l = rd(), r = rd(); idOf[t] = I.size(); I.push_back({l, r - 1, t, m + 1}); }
        else if (op == 2) { int x = rd(); I[idOf[x]].e = t; }
        else { int l = rd(), r = rd(); Q.push_back({l, r - 1, t}); }
    }
    ok.assign(Q.size(), 0);
    vector<int> iv(I.size()), qs(Q.size());
    iota(iv.begin(), iv.end(), 0); iota(qs.begin(), qs.end(), 0);
    solve(1, max(1, n - 1), iv, qs);
    string out;
    for (size_t i = 0; i < Q.size(); i++) { out += ok[i] ? 'Y' : 'N'; out += '\n'; }
    fwrite(out.data(), 1, out.size(), stdout);
}

Sažetak

  • Upit je „da” točno kad svi živi intervali unutar $[l,r]$ zajedno pokrivaju $[l,r]$.
  • Offline: interval ima životni vijek; podijeli pa vladaj po koordinati, upit se rješava u čvoru čiju sredinu prelazi.
  • Intervali preko sredine daju povezanu uniju $[f,g]$ (sweep po vremenu + stablo minimuma).
  • Lijevo i desno od toga: sweep po koordinati sa stablom po vremenu (chmax, minimum, vađenje zapelih upita).
  • Složenost: $O(m\log n\log m)$.
