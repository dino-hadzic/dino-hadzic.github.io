Analiza rješenja · Ynoi 2025 Hard Round · QOJ #9534

Razumijevanje (boja)

运筹帷幄 / 《十字神名的预言者》理解（色彩）

O ovom članku

Za Ynoi zadatke na QOJ-u nema službenog pisanog editoriala, pa je ova analiza autorska (izvori: službeni izvještaj autora (赵海鲲, 集训队互测 2024, 5. kolo); vlastita implementacija provjerena brute-forceom). Opisano rješenje je implementirano i provjereno usporedbom s izravnim (brute-force) rješenjem na nasumičnim testovima. Gumb i otvara karticu s dodatnim objašnjenjem pojma.

Pregled zadatka

Za svaki korijen treba pohlepno „povući” žetone prema korijenu i zbrojiti udaljenosti. Rješenje ima tri dijela:

  • pohlepni postupak za jedan korijen i njegov zapis nizom $E_x(j)$ = broj žetona na udaljenosti barem $j$;
  • dugi lanci: nizovi $E_x$ za jedan korijen u $O(n)$, uz mogućnost poništavanja;
  • promjena korijena: stanje „izvan podstabla” čuvamo kao eksplicitan niz blizu čvora plus zamrznute „daleke komade”, a rez nalazimo binarnim pretraživanjem.

Složenost je $O(n\log n)$ vremena i $O(n)$ memorije.

Korak 1: pohlepno za jedan korijen

Budući da je $a_i\ge 1$, žeton se može provući i kroz pun čvor (pun čvor prvo pošalje svoj žeton gore, pa primi novi). Zato je potez zapravo „premjesti žeton u bilo kojeg pretka koji ima mjesta”.

Pohlepni postupak. Čvorove obrađujemo odozdo prema gore. Kad dođemo do čvora $x$, njegova su podstabla već obrađena; u $x$ povlačimo najdublje žetone iz podstabla dok $x$ ima mjesta ($a_x-b_x$ slobodnih mjesta) i dok ispod njega ima žetona.

Zašto. Poredajmo udaljenosti žetona u podstablu do $x$. Povlačenjem bilo kojeg žetona u $x$ novi je sortirani niz po članovima manji ili jednak starom, pa se isplati povlačiti. Ako povučemo najdalji, dobiveni niz je po članovima manji ili jednak nizu koji bi nastao povlačenjem bilo kojeg drugog — dakle najdalji je najbolji izbor za sve što slijedi.

Korak 2: zapis nizom $E$

Neka je $c_x=a_x-b_x$ broj slobodnih mjesta, $T(x)$ ukupan broj žetona u podstablu i

\[ E_x(j)=\text{broj žetona na udaljenosti}\ \ge j\ \text{od } x \text{ u obrađenom podstablu čvora } x. \]

Prije povlačenja u $x$, na udaljenosti $\ge j$ (za $j\ge1$) nalazi se $\sum_{c}E_c(j-1)$ žetona, zbroj po djeci $c$. Čvor $x$ uzima $c_x$ najdubljih, pa je

\[ E_x(0)=T(x),\qquad E_x(j)=\max\Bigl(0,\ \sum_{c}E_c(j-1)-c_x\Bigr)\quad (j\ge 1). \]

Odgovor za korijen $k$ je $\sum_{j\ge1}E_k(j)$ (žeton na udaljenosti $t$ broji se u $E(1),\dots,E(t)$).

Niz $E_x$ je nerastući, pa „$-c_x$ i odreži na nuli” znači: oduzmi konstantu i odbaci rep. To je ključno svojstvo cijelog rješenja.

Korak 3: jedan korijen u $O(n)$ — dugi lanci

Ukorijenimo stablo u čvoru $1$. Teški sin čvora je sin s najvećom visinom; teški bridovi tvore lance. Niz $E_x$ dijeli memoriju s nizom teškog sina $h$:

  1. dodaj novi element na početak (pomak indeksa za 1);
  2. pribroji nizove lakih sinova (svaki košta svoju duljinu, a to je najviše duljina njegova lanca);
  3. lijena oznaka: $\mathit{TAG}\mathrel{+}=c_x$ (stvarna vrijednost je $\mathit{raw}-\mathit{TAG}$);
  4. odbaci s kraja elemente koji su pali na $\le 0$ (pomak granice $\mathit{lo}$).

Zbroj duljina lanaca je $n$, pa je sve $O(n)$. Dodatno održavamo prefiksne zbrojeve $\mathit{PS}$ od daljeg kraja; promjene su uvijek pri bližem kraju, pa se $\mathit{PS}$ popravlja u istoj cijeni.

Detalj. Lak sin može imati dulji niz od trenutno preživjelog dijela niza teškog sina. Tada se odrezani dio „oživljava”: vrijednost se postavlja na $\mathit{TAG}$ (stvarna nula) pa joj se pribraja. Prebrisane stare vrijednosti spremamo jer će trebati pri poništavanju.

Poništavanje. U drugom prolazu, kad stignemo u $x$, korak čvora $x$ poništimo (oduzmemo lake sinove, vratimo $\mathit{TAG}$, $\mathit{lo}$ i prebrisane vrijednosti). Niz lanca tada sadrži točno $E_h$. Nizovi lakih sinova su netaknuti dok u njih ne uđemo.

Korak 4: promjena korijena — što nam treba

Za čvor $z$ neka je $U_z(j)$ broj žetona izvan podstabla čvora $z$ na udaljenosti $\ge j$ od $z$, nakon što je taj vanjski dio obrađen prema $z$ (kao da je roditelj od $z$ sin čvora $z$). Uz

\[ W_z(j)=U_z(j)+\sum_{c\ \text{sin od}\ z}E_c(j-1) \]

vrijedi

\[ \mathit{odg}(z)=\sum_{j\ge1}\max\bigl(0,\ W_z(j)-c_z\bigr),\qquad U_y(j)=\max\bigl(0,\ W_z(j-1)-E_y(j-2)-c_z\bigr)\ \ (j\ge2) \]

za sina $y$ čvora $z$, uz $U_y(1)=T_{\text{uk}}-T(y)$. Nizovi $U$ mogu biti dugi ($\Theta(n)$ za svaki čvor), pa ih ne smijemo graditi iznova.

Korak 5: prikaz vanjskog stanja

Koristimo koordinatu $g=j-\mathit{dubina}(z)$. Silaskom u sina indeks $j$ svakog elementa raste za 1, a dubina također — dakle $g$ se ne mijenja i podatke ne treba pomicati; silazak samo dodaje jedan novi element na bližem kraju.

Stanje čine:

  • globalni niz $G[g]$ s prefiksnim zbrojevima i dnevnikom promjena (pri povratku iz sina sve se vraća);
  • lijena konstanta $C$ (zbroj svih dosad oduzetih $c$);
  • rez $\mathit{cut}$: za $g\ge\mathit{cut}$ vrijednost je $0$;
  • stog dalekih komada: zamrznuti odsječci nizova $E_h$ (vidi dolje).

Vrijednost je $U(g)=G[g]+P(g)-C$ za $g\lt\mathit{cut}$, gdje je $P(g)$ vrijednost komada koji pokriva $g$ (ako postoji).

U čvoru $z$:

  1. u $G$ pribrojimo sve lake sinove (indeksi $j\le$ njihova duljina) i poništimo korak lanca, pa je dostupan $E_h$;
  2. za odgovor privremeno dodamo cijeli $E_h$ kao komad, povećamo $C$ za $c_z$, nađemo rez i zbrojimo; zatim to vratimo;
  3. za teškog sina: $C\mathrel{+}=c_z$, dodamo novi element $T_{\text{uk}}-T(h)$, nađemo rez;
  4. za lakog sina $y$: iz $G$ oduzmemo $E_y$, pribrojimo bliski dio niza $E_h$ (indeksi $j\lt\mathit{visina}(y)$), a daleki dio ($j\ge\mathit{visina}(y)$) stavimo na stog kao komad; dalje kao za teškog sina. Cijena je $O(\mathit{visina}(y))$, a zbroj visina lakih sinova je najviše $n$.

Zašto su komadi sigurni. Sve što se kasnije događa unutar podstabla čvora $y$ dira samo koordinate $g\le\mathit{visina}(y)-\mathit{dubina}(y)$: svaki čvor $w$ u tom podstablu pribraja nizove duljine najviše $\mathit{visina}(w)$, a $\mathit{visina}(w)-\mathit{dubina}(w)\le\mathit{visina}(y)-\mathit{dubina}(y)$. Komad počinje tek iza te granice. Zato se u području komada više ništa ne pribraja — ondje se vrijednosti samo smanjuju za konstantu i režu, a to opisuju $C$ i $\mathit{cut}$.

Iz istog razloga komadi na stogu pokrivaju disjunktne raspone, i to tako da je stariji komad dalje od novijeg. Kako je $U$ nerastući, komadi „umiru” redom od najstarijeg.

Korak 6: pažnja — rezanje pa pribrajanje

Lijeni zapis $\max(0,\ \text{zbroj}-C)$ vrijedi samo dok se pribraja unutar reza. Ako se pribraja iza reza (ondje je stvarna vrijednost $0$, a zapisana „negativna”), moramo to ispraviti:

  • eksplicitno pribrajanje iza reza: element se najprije postavi na $G[g]=C$ (stvarna nula), rez se pomakne, pa se pribroji;
  • komad koji viri iza reza: iza reza vrijedi samo komad. Pamtimo granicu $\mathit{gl}$ do koje je $G$ eksplicitan i konstantu $\mathit{vc}$ koja zamjenjuje $G[g]$ za $g\ge\mathit{gl}$; u tom trenutku stavimo $\mathit{vc}=C$. Tako ne moramo ispunjavati dugačak dio niza.

Oba se slučaja mogu dogoditi samo kad nema živog starijeg komada (živi stariji komad znači da je rez daleko iza svega što se sada pribraja), pa je jedna konstanta $\mathit{vc}$ dovoljna.

Korak 7: novi rez i zbroj

Nakon povećanja $C$ tražimo prvi $g$ s vrijednošću $\le0$:

  1. binarno po stogu komada nađemo prvi živi komad (živ je ako mu je vrijednost na početku raspona pozitivna — svojstvo je monotono);
  2. rez je tada između početka tog komada i početka prethodnog (mrtvog) komada; u tom rasponu sudjeluje samo jedan komad, pa se vrijednost računa u $O(1)$ i rez nalazimo binarnim pretraživanjem.

Zbroj $\sum_{g\lt\mathit{cut}}U(g)$ dobivamo iz prefiksnih zbrojeva niza $G$, prefiksnih zbrojeva nizova lanaca (za djelomično živ komad) i prefiksnih zbrojeva ukupnih vrijednosti komada na stogu (za potpuno žive).

Složenost

  • prvi prolaz: $O(n)$;
  • eksplicitne promjene niza $G$ i dnevnik: $O(\text{zbroj visina lakih sinova})=O(n)$;
  • po čvoru $O(1)$ binarnih pretraživanja: $O(n\log n)$.

Memorija je $O(n)$. Drugi je prolaz napisan bez rekurzije (dubina može biti $5\cdot10^5$). Za $n=5\cdot10^5$ program radi $0{,}2$–$0{,}8$ s na lancu, zvijezdi, gusjenici, češlju, binarnom i nasumičnom stablu.

Implementacija

// Ynoi 2025 "Razumijevanje (boja)" / QOJ 9534: za svaki korijen najmanji zbroj udaljenosti zetona.
// E_x(j) = broj zetona na udaljenosti >= j u obradjenom podstablu; dugi lanci + promjena korijena.
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef unsigned long long ull;

int n;
vector<int> adjStart, adjList, par, dep, hgt, heavy, topIdx, chainOf, loh;
vector<ll> T, cz, ans;
ll Ttot;

// --- nizovi lanaca: E_x(j) = raw[topIdx[x] - j] - TAGc[lanac], zivi indeksi >= LOc[lanac]
vector<ll> raw_;
vector<ull> PS;            // PS[q] - PS[q-1] = raw[q] na zivom dijelu
vector<ll> TAGc;
vector<int> LOc;
// vrijednosti koje je ozivljavanje prebrisalo (za vracanje u 2. prolazu)
vector<ll> revRaw; vector<ull> revPS; vector<int> revStart, revCnt;

// --- vanjsko stanje: koordinata g = j - dubina; G[n - g]
vector<ll> G;
vector<ull> PSG_;          // pomaknuto za 1
ll C, vc;
int cut_, gl, alive, np;
vector<int> pK, pS, pE;
vector<ll> pTag, PT;
struct LogE { int idx; int kind; ull old; };
vector<LogE> lg;
int pminW;

inline ull &PSG(int p) { return PSG_[p + 1]; }
inline void writeG(int p, ll v) {
    lg.push_back({p, 0, (ull)G[p]});
    G[p] = v;
    if (p < pminW) pminW = p;
}
inline void psRecompute(int plo, int phi) {
    for (int p = plo; p <= phi; p++) {
        lg.push_back({p, 1, PSG(p)});
        PSG(p) = PSG(p - 1) + (ull)G[p];
    }
}
inline void undoTo(size_t pos) {
    while (lg.size() > pos) {
        LogE &e = lg.back();
        if (e.kind == 0) G[e.idx] = (ll)e.old; else PSG(e.idx) = e.old;
        lg.pop_back();
    }
}
// eksplicitni dio prosiri do g < ghi; iza reza vrijednosti su 0
inline void ensureExplicit(int ghi) {
    while (gl < ghi) {
        if (gl == cut_) { writeG(n - gl, C); cut_++; alive = np; }
        else writeG(n - gl, vc);
        gl++;
    }
}
inline ll val(int g, int pi) {
    ll v = (g < gl ? G[n - g] : vc) - C;
    if (pi >= 0 && g >= pS[pi] && g < pE[pi]) v += raw_[pK[pi] - g] - pTag[pi];
    return v;
}
inline void pushPiece(int K, ll tag, int s, int e) {
    pK[np] = K; pTag[np] = tag; pS[np] = s; pE[np] = e;
    PT[np + 1] = PT[np] + (ll)(PS[K - s] - PS[K - e]) - tag * (ll)(e - s);
    if (e > cut_) { vc = C; alive = np; cut_ = e; }   // komad viri iza reza: svi stariji su mrtvi
    np++;
}
// novi rez: prvi g s vrijednoscu <= 0
inline void recut(int gmin) {
    int lo = alive, hi = np;
    while (lo < hi) {
        int mid = (lo + hi) >> 1;
        if (val(pS[mid], mid) > 0) hi = mid; else lo = mid + 1;
    }
    int a = lo, L, H, pi;
    if (a < np) { L = pS[a] + 1; H = (a > alive ? pS[a - 1] : cut_); pi = a; }
    else { L = gmin; H = (np > alive ? pS[np - 1] : cut_); pi = -1; }
    if (H < L) H = L;
    while (L < H) {
        int mid = (L + H) >> 1;
        if (val(mid, pi) > 0) L = mid + 1; else H = mid;
    }
    cut_ = L; alive = a;
    if (gl > cut_) gl = cut_;
}
inline ll sumAll(int gmin) {
    int cnt = cut_ - gmin;
    if (cnt <= 0) return 0;
    int g2 = min(gl, cut_);
    ll s = (ll)(PSG(n - gmin) - PSG(n - g2)) + vc * (ll)(cut_ - g2);
    if (alive < np) {
        int a = alive, e = min(pE[a], cut_);
        if (e > pS[a]) s += (ll)(PS[pK[a] - pS[a]] - PS[pK[a] - e]) - pTag[a] * (ll)(e - pS[a]);
        s += PT[np] - PT[a + 1];
    }
    return s - C * (ll)cnt;
}

struct Scal { ll C, vc; int cut, gl, alive, np; };
inline Scal getS() { return {C, vc, cut_, gl, alive, np}; }
inline void setS(const Scal &s) { C = s.C; vc = s.vc; cut_ = s.cut; gl = s.gl; alive = s.alive; np = s.np; }

inline int lenOf(int x) { return topIdx[x] - LOc[chainOf[x]] + 1; }

// dolazak u cvor z: dodaj lake sinove u G, vrati niz lanca na stanje teskog sina, izracunaj odgovor
void enterNode(int z) {
    int d = dep[z], h = heavy[z];
    if (h < 0) {
        Scal s0 = getS();
        C += cz[z]; recut(1 - d); ans[z] = sumAll(1 - d);
        setS(s0);
        return;
    }
    int ch = chainOf[z], tz = topIdx[z], maxlen = 0;
    for (int e = adjStart[z]; e < adjStart[z + 1]; e++) {
        int c = adjList[e];
        if (c == par[z] || c == h) continue;
        int len = lenOf(c);
        if (len <= 0) continue;
        maxlen = max(maxlen, len);
        ensureExplicit(len + 1 - d);
        ll tg = TAGc[c]; int tc = topIdx[c];
        for (int j = 0; j < len; j++) {
            ll v = raw_[tc - j] - tg;
            int p = n + d - 1 - j;
            writeG(p, G[p] + v);
            int q = tz - 1 - j;
            if (q >= loh[z]) raw_[q] -= v;
        }
    }
    if (maxlen) psRecompute(n + d - maxlen, n + d - 1);
    TAGc[ch] -= cz[z]; LOc[ch] = loh[z];
    for (int i = 0; i < revCnt[z]; i++) {   // prebrisane mrtve vrijednosti
        int q = loh[z] - 1 - i;
        raw_[q] = revRaw[revStart[z] + i]; PS[q] = revPS[revStart[z] + i];
    }
    for (int q = max(loh[z], tz - maxlen); q <= tz - 1; q++) PS[q] = PS[q - 1] + (ull)raw_[q];
    Scal s0 = getS();
    int lh = lenOf(h);
    if (lh > 0) pushPiece(topIdx[h] + 1 - d, TAGc[ch], 1 - d, lh + 1 - d);
    C += cz[z]; recut(1 - d); ans[z] = sumAll(1 - d);
    setS(s0);
}
// pripremi stanje za sina y cvora z
void prepChild(int z, int y) {
    int d = dep[z], h = heavy[z];
    pminW = n + d;
    if (y != h) {
        int len = lenOf(y);
        ll tg = TAGc[y]; int ty = topIdx[y];
        for (int j = 0; j < len; j++) { int p = n + d - 1 - j; writeG(p, G[p] - (raw_[ty - j] - tg)); }
        int ch = chainOf[z], lh = lenOf(h), th = topIdx[h];
        ll tgh = TAGc[ch];
        int m = min(lh, hgt[y] - 1);
        if (m > 0) {
            ensureExplicit(m + 1 - d);
            for (int j = 0; j < m; j++) { int p = n + d - 1 - j; writeG(p, G[p] + (raw_[th - j] - tgh)); }
        }
        int sj = max(1, hgt[y]);
        if (lh + 1 > sj) {
            ensureExplicit(sj - d);
            pushPiece(th + 1 - d, tgh, sj - d, lh + 1 - d);
        }
    }
    C += cz[z];
    writeG(n + d, C + (Ttot - T[y]));
    psRecompute(pminW, n + d);
    recut(-d);
}

int main() {
    if (scanf("%d", &n) != 1) return 0;
    vector<ll> a(n), b(n);
    for (auto &x : a) scanf("%lld", &x);
    for (auto &x : b) scanf("%lld", &x);
    vector<int> eu(n - 1), ev(n - 1);
    adjStart.assign(n + 2, 0);
    for (int i = 0; i < n - 1; i++) {
        scanf("%d %d", &eu[i], &ev[i]); eu[i]--; ev[i]--;
        adjStart[eu[i] + 1]++; adjStart[ev[i] + 1]++;
    }
    for (int i = 0; i < n; i++) adjStart[i + 1] += adjStart[i];
    adjList.resize(2 * (n - 1));
    { vector<int> fill(adjStart.begin(), adjStart.begin() + n);
      for (int i = 0; i < n - 1; i++) { adjList[fill[eu[i]]++] = ev[i]; adjList[fill[ev[i]]++] = eu[i]; } }
    par.assign(n, -1); dep.assign(n, 0); hgt.assign(n, 0); heavy.assign(n, -1);
    T.assign(n, 0); cz.assign(n, 0); ans.assign(n, 0);
    vector<int> order; order.reserve(n); order.push_back(0);
    for (int i = 0; i < n; i++) {
        int x = order[i];
        for (int e = adjStart[x]; e < adjStart[x + 1]; e++) {
            int c = adjList[e];
            if (c != par[x]) { par[c] = x; dep[c] = dep[x] + 1; order.push_back(c); }
        }
    }
    for (int i = 0; i < n; i++) { T[i] = b[i]; cz[i] = a[i] - b[i]; }
    for (int i = n - 1; i >= 1; i--) {
        int x = order[i], p = par[x];
        T[p] += T[x];
        if (heavy[p] < 0 || hgt[x] + 1 > hgt[p]) { heavy[p] = x; hgt[p] = hgt[x] + 1; }
    }
    Ttot = T[0];
    // raspored lanaca
    topIdx.assign(n, 0); chainOf.assign(n, 0); loh.assign(n, 0);
    int cur = 0;
    for (int i = 0; i < n; i++) {
        int x = order[i];
        if (i == 0 || heavy[par[x]] != x) { chainOf[x] = x; topIdx[x] = cur + 1 + hgt[x]; cur += hgt[x] + 2; }
        else { chainOf[x] = chainOf[par[x]]; topIdx[x] = topIdx[par[x]] - 1; }
    }
    revStart.assign(n, 0); revCnt.assign(n, 0);
    raw_.assign(cur + 1, 0); PS.assign(cur + 1, 0); TAGc.assign(n, 0); LOc.assign(n, 0);
    // 1. prolaz: nizovi E odozdo prema gore
    for (int i = n - 1; i >= 0; i--) {
        int x = order[i], ch = chainOf[x], tx = topIdx[x], h = heavy[x];
        if (h < 0) {
            raw_[tx] = T[x]; LOc[ch] = T[x] > 0 ? tx : tx + 1;
            PS[tx] = PS[tx - 1] + (ull)raw_[tx];
            continue;
        }
        int lo = LOc[ch], qmin = tx;
        loh[x] = lo; revStart[x] = (int)revRaw.size();
        ll tg = TAGc[ch];
        for (int e = adjStart[x]; e < adjStart[x + 1]; e++) {
            int c = adjList[e];
            if (c == par[x] || c == h) continue;
            int len = lenOf(c);
            ll tgc = TAGc[c]; int tc = topIdx[c];
            for (int j = 0; j < len; j++) {
                int q = tx - 1 - j;
                if (q < lo) {                              // ozivljavanje izrezanog dijela
                    revRaw.push_back(raw_[q]); revPS.push_back(PS[q]); revCnt[x]++;
                    raw_[q] = tg; lo = q;
                }
                raw_[q] += raw_[tc - j] - tgc;
            }
            if (len) qmin = min(qmin, tx - len);
        }
        tg += cz[x]; TAGc[ch] = tg;
        while (lo < tx && raw_[lo] - tg <= 0) lo++;
        raw_[tx] = T[x] + tg;
        if (T[x] == 0) lo = tx + 1;
        LOc[ch] = lo;
        for (int q = qmin; q <= tx; q++) PS[q] = PS[q - 1] + (ull)raw_[q];
    }
    // 2. prolaz: promjena korijena
    G.assign(2 * n + 5, 0); PSG_.assign(2 * n + 6, 0);
    pK.assign(n + 2, 0); pS.assign(n + 2, 0); pE.assign(n + 2, 0); pTag.assign(n + 2, 0); PT.assign(n + 3, 0);
    C = 0; vc = 0; cut_ = 1; gl = 1; alive = 0; np = 0;
    struct Fr { int z, e; bool heavyDone, active; Scal s; size_t lp; };
    vector<Fr> st; st.reserve(n);
    enterNode(0);
    st.push_back({0, adjStart[0], false, false, getS(), lg.size()});
    while (!st.empty()) {
        Fr &f = st.back();
        if (f.active) { undoTo(f.lp); setS(f.s); f.active = false; }
        int z = f.z, y = -1;
        while (f.e < adjStart[z + 1]) {
            int c = adjList[f.e++];
            if (c != par[z] && c != heavy[z]) { y = c; break; }
        }
        if (y < 0 && !f.heavyDone && heavy[z] >= 0) { y = heavy[z]; f.heavyDone = true; }
        if (y < 0) { st.pop_back(); continue; }
        f.s = getS(); f.lp = lg.size(); f.active = true;
        prepChild(z, y);
        enterNode(y);
        st.push_back({y, adjStart[y], false, false, getS(), lg.size()});
    }
    string out;
    for (int i = 0; i < n; i++) { out += to_string(ans[i]); out += i + 1 < n ? ' ' : '\n'; }
    fputs(out.c_str(), stdout);
}

Sažetak

  • Pohlepno: svaki čvor odozdo prema gore povlači najdublje žetone iz svog podstabla.
  • $E_x(j)=\max(0,\sum_cE_c(j-1)-c_x)$; odgovor je $\sum_{j\ge1}E_k(j)$.
  • Dugi lanci daju sve $E_x$ u $O(n)$; u drugom se prolazu koraci poništavaju.
  • Vanjsko stanje: eksplicitan niz u koordinati $g=j-\text{dubina}$, lijena konstanta, rez i zamrznuti daleki komadi teških podstabala.
  • Komadi su disjunktni i poredani po udaljenosti, pa se rez nalazi s dva binarna pretraživanja.
  • Složenost: $O(n\log n)$ vremena, $O(n)$ memorije.
