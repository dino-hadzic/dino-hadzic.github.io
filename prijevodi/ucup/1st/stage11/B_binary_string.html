ZADATAK B: Binary String

Binarni niz — The 1st Universal Cup, Stage 11: Shanghai (The 2022 ICPC Asia East Continent Final Contest, EC-Final 2022). Vremensko ograničenje: 2 s, memorijsko ograničenje: 1024 MB.

Dan je binarni niz $a_0 a_1 \dots a_{n-1}$ raspoređen u krug. Svake sekunde istodobno se svaki par $01$ zamijeni u $10$: ako je $a_i = 0$ i $a_{(i+1) \bmod n} = 1$, ta se dva znaka zamijene. Primjerice, $100101110$ prelazi u $001010111$.

Koliko će se različitih nizova pojaviti tijekom beskonačno mnogo sekundi (uključujući početni)? Odgovor ispiši modulo $998244353$. Nizovi se uspoređuju po pozicijama, pa ciklički pomaci niza mogu biti međusobno različiti nizovi.

Ulaz

Prvi redak sadrži broj testnih primjera $T$ ($1 \le T \le 10^6$). Svaki testni primjer je jedan binarni niz. Zbroj duljina svih nizova ne prelazi $10^7$.

Izlaz

Za svaki testni primjer ispiši traženi broj u zasebnom retku.

Primjer

Za nizove $1$, $001001$ i $0001111$ odgovori su redom $1$, $3$ i $9$.

NAPUTCI

Naputak 1klikni za prikaz

Promatraj blokove — maksimalne segmente jednakih znakova duljine barem $2$. Usporedi gdje je blok nula nakon jedne sekunde: $\dots 0101\underline{000000}101 \dots \to \dots 1010\underline{000000}1010 \dots$ — cijeli se blok pomaknuo za jedno mjesto ulijevo. Blok jedinica se pomiče udesno. Sve između blokova je „pozadina” $0101\dots$ koja se samo pomiče.

Naputak 2klikni za prikaz

Što se dogodi kad blok jedinica neposredno slijedi blok nula ($\dots 0\underline{1111}\underline{0000}1 \dots$)? Oba se svake sekunde skrate za $1$, dok kraći ne postane duljine $1$ i „nestane” u pozadini. Uvedi masu bloka (duljina $-1$): razlika ukupne mase jedinica i nula se čuva, pa bez smanjenja općenitosti (komplement + obrat) nestanu svi blokovi nula.

Naputak 3klikni za prikaz

Blokovi ne mogu mijenjati redoslijed, pa se sudari odvijaju kao uparivanje zagrada: blok nula udara u najbliži živi blok jedinica lijevo od sebe. Odaberi početak kruga nakon kojeg svaki prefiks ima masu jedinica $\ge$ masi nula i simuliraj stogom — trenutak svakog dodira računa se iz početnih položaja i dosad izgubljenih masa. Kad nestane posljednji blok nula, niz se samo rotira: odgovor je taj trenutak plus najmanji ciklički period niza u njemu.

TRENERSKI NAČIN: logički put do rješenja

Logički put do rješenja: svaki je korak pitanje koje bi si iskusan natjecatelj postavio. Pokušaj na njega odgovoriti sam, pa tek onda otvori odgovor i usporedi – cilj je uvježbati način razmišljanja, a ne zapamtiti rješenje.

  1. Što se u jednoj sekundi dogodi s maksimalnim segmentom nula duljine barem $2$, a što sa segmentom jedinica? Zašto je ostatak niza „dosadan”?

    Neka je $0^L$, $L \ge 2$, maksimalan segment nula: neposredno lijevo od njega je $1$, neposredno desno također $1$. Na desnom kraju imamo par $01$ koji se zamjenjuje, pa segment gubi krajnju desnu nulu. Lijevo od segmenta stoji jedinica; ako je ispred nje $0$, par $01$ se zamijeni i ta nula dolazi tik do segmenta — segment dobiva novu nulu slijeva. Dakle blok nula putuje ulijevo brzinom $1$ zadržavajući duljinu (dokle god je ispred njegove lijeve jedinice nula, tj. dok ta jedinica nije dio bloka jedinica). Zrcalno, blok jedinica $1^L$ putuje udesno: uvijek gubi krajnju lijevu jedinicu (ispred nje je $0$), a dobiva jednu zdesna kad iza njega slijedi $01$. Segmenti duljine $1$ čine izmjeničnu pozadinu $\dots 0101 \dots$ u kojoj se svaki par $01$ zamijeni u $10$, što je samo pomak. Blok ne može nastati „ni iz čega”: dva jednaka znaka postanu susjedna jedino ako je jedan od njih već bio u bloku, pa je svaki blok u trenutku $t$ potomak nekog početnog bloka.

  2. Što se događa kad blok jedinica neposredno slijedi blok nula, $\dots 1111\,0000 \dots$? Koja se veličina pritom čuva i zašto smijemo pretpostaviti da nestanu baš blokovi nula?

    Na spoju stoji par $10$, koji se ne mijenja: blok jedinica ne može dobiti novu jedinicu zdesna, a blok nula ne može dobiti nulu slijeva. Njihovi „slobodni” krajevi ipak se i dalje miču (lijevi kraj bloka jedinica udesno, desni kraj bloka nula ulijevo), pa se oba bloka svake sekunde skrate za $1$. Blok duljine $2$ tako postaje jedan znak — dio pozadine — i kažemo da je nestao. Definirajmo masu bloka kao duljinu umanjenu za $1$: slobodno gibanje masu ne mijenja, a sudar oduzima po $1$ objema stranama, pa je $M_1 - M_0$ (ukupna masa blokova jedinica minus nula) invarijanta. Proces sudara traje dok postoje i jedni i drugi, dakle ako je $M_1 \ge M_0$, nestanu svi blokovi nula. U suprotnom niz komplementiramo i obrnemo: komplement pretvara pravilo $01 \to 10$ u $10 \to 01$, obrat vraća smjer, pa kompozicija komutira s jednim korakom procesa i ne mijenja broj različitih nizova, a zamjenjuje uloge nula i jedinica.

  3. Koji blok jedinica „pojede” zadani blok nula, i kako to odrediti jednim prolazom po krugu?

    Blokovi su maksimalni segmenti, pa ne mogu jedan drugoga preskočiti: njihov ciklički poredak je očuvan. Blok nula putuje ulijevo, a blok jedinica udesno; blok nula se stoga uvijek sudari s najbližim živim blokom jedinica lijevo od sebe (svi blokovi između njih moraju već biti nestali da bi se dodirnuli). To je točno pravilo uparivanja zagrada: blok jedinica je otvorena zagrada s masom, blok nula zatvorena. Da bi se na krugu sve uparilo unutar jednog prolaza, krenimo od bloka iza kojeg prefiksni zbroj $\sum(\pm \text{masa})$ postiže minimum — tada svaki prefiks ima masu jedinica $\ge$ masi nula (jer je $M_1 \ge M_0$), pa pri obradi bloka nula stog živih blokova jedinica uvijek ima dovoljno mase da ga proguta: skidamo s vrha stoga dok se masa bloka nula ne potroši.

  4. Kako iz početnih položaja izračunati trenutak dodira para (blok jedinica $P$, blok nula $Q$) bez simulacije sekundu po sekundu?

    Lijevi kraj bloka jedinica $P$ pomiče se udesno svake sekunde: $x_P(t) = x_P(0) + t$. Desni kraj $e_P$ pomiče se udesno u svakoj sekundi osim onih u kojima je $P$ u sudaru, a takvih je sekundi točno onoliko koliko je mase $P$ dosad izgubio: $e_P(t) = e_P(0) + t - \ell_P$. Zrcalno, lijevi kraj bloka nula $Q$ je $f_Q(t) = f_Q(0) - t + \ell_Q$. Blokovi se dodiruju kad je $f_Q - e_P = 1$, pa je trenutak dodira $T = \bigl(f_Q(0) - e_P(0) - 1 + \ell_P + \ell_Q\bigr)/2$, gdje su $\ell_P, \ell_Q$ mase izgubljene u ranijim sudarima (svi su ranije završili, jer su se odvijali s blokovima koji su stajali između $P$ i $Q$). Sudar traje $\min(a, b)$ sekundi (preostale mase); ako je $b \le a$, $Q$ nestaje u trenutku $T + b$, inače $P$ nestaje, a $Q$ nastavlja s masom $b - a$ prema sljedećem bloku na stogu. Trenutak stabilizacije $t^*$ je najveći trenutak nestanka nekog bloka nula.

  5. Zašto je odgovor točno $t^* + $ (najmanji ciklički period niza u trenutku $t^*$)?

    Nakon $t^*$ niz čine blokovi jedinica i izmjenične praznine $010\dots10$ između njih; jedan korak pomiče sve za jedno mjesto udesno (lijevi kraj svakog bloka napreduje, desni kraj napreduje jer iza bloka slijedi $01$, a u pozadini se svaki par $01$ zamijeni). Stanja od $t^*$ nadalje su dakle rotacije istog niza i ima ih točno onoliko koliki je najmanji ciklički period $p$ tog niza (prefiksna funkcija). Sva ranija stanja sadrže barem jedan blok nula, a nijedna rotacija završnog niza ga ne sadrži, pa rep i ciklus nemaju zajedničkih stanja; stanja repa su međusobno različita jer bi ponavljanje značilo da se deterministički proces zauvijek vrti među nizovima s blokom nula. Ukupno: $t^* + p$.

Opći savjeti i prečaci

  • Kad pravilo lokalno zamjenjuje susjedne znakove, promotri maksimalne segmente (blokove): često se translatiraju konstantnom brzinom, a sva „prava” dinamika su sudari blokova suprotnog tipa. Prije toga iskoristi simetrije (komplement, obrat, rotacija) — ali provjeri da doista komutiraju s jednim korakom procesa.
  • Sudare objekata koji putuju u suprotnim smjerovima i ne mogu se preteći obradi stogom kao uparivanje zagrada; na krugu prvo odaberi početak iza najmanjeg prefiksnog zbroja, pa se sve upari u jednom prolazu bez posebnog rukovanja „omatanjem”.
  • Broj različitih stanja determinističkog procesa je duljina repa plus duljina ciklusa; ciklus čistih rotacija ima duljinu jednaku najmanjem cikličkom periodu niza — računaj ga prefiksnom funkcijom: $p = n - \pi[n-1]$ ako $p \mid n$, inače $n$.
  • Za ulaze od $10^7$ znakova čitaj cijeli ulaz jednim fread i piši izlaz u vlastiti međuspremnik; standardni cin po znaku lako probije limit.
RJEŠENJEklikni za prikaz cijelog rješenja

Savjet: prije čitanja rješenja prođi kroz korake trenerskog načina iznad.

Promotrimo neprekinuti blok nula duljine veće od $1$, primjerice $\dots 0101000000101 \dots$. Nakon jedne sekunde on prelazi u $\dots 1010000001010 \dots$, što znači da se cijeli blok nula pomaknuo za jedno mjesto ulijevo. Analogno se blok jedinica duljine veće od $1$ pomiče za jedno mjesto udesno.

Ako su blok jedinica i blok nula susjedni, npr. $\dots 0111100001 \dots \to \dots 1011100010 \dots$, dva bloka se sudaraju i svakom se duljina smanji za $1$.

Taj se proces nastavlja dok postoje i blokovi nula i blokovi jedinica (duljine barem $2$). Bez smanjenja općenitosti pretpostavimo da je ukupna duljina blokova jedinica barem tolika kao ukupna duljina blokova nula (duljine se ovdje broje umanjene za $1$ — blok duljine $2$ nestaje nakon jednog sudara). Tada postoji početna pozicija na krugu takva da u svakom prefiksu ukupna duljina blokova jedinica nije manja od ukupne duljine blokova nula. Krenuvši od te pozicije možemo za svaki blok nula izračunati u kojem trenutku nestaje, a time i niz koji nastaje nakon što nestanu svi blokovi nula. Od tog trenutka niz se samo ciklički pomiče, pa je preostalo izračunati najmanji period završnog niza: broj različitih nizova jednak je broju sekundi do stabilizacije uvećanom za taj najmanji period.

Vremenska složenost je $O(n)$.

DETALJNO RJEŠENJE

Blokovi i pozadina

Niz je raspoređen u krug; rastavimo ga na maksimalne segmente jednakih znakova. Segment duljine barem $2$ zovemo blok (blok nula ili blok jedinica), a njegovu duljinu umanjenu za $1$ njegovom masom. Segmenti duljine $1$ čine izmjeničnu pozadinu $\dots 0101 \dots$ između blokova. Ako je niz konstantan (svi znakovi jednaki), ništa se ne mijenja i odgovor je $1$; nadalje pretpostavljamo da nije.

Lema 1 (gibanje blokova). Lijevi kraj bloka jedinica svake se sekunde pomakne za $1$ udesno; desni kraj se pomakne za $1$ udesno točno onda kad iza bloka slijedi $01$, a ostaje na mjestu kad iza bloka slijedi $00$ (tj. blok nula). Zrcalno, desni kraj bloka nula uvijek se pomiče za $1$ ulijevo, a lijevi kraj se pomiče ulijevo točno kad ispred bloka stoji $01$.

Dokaz. Ispred bloka jedinica $1^L$ stoji $0$ (maksimalnost), pa se par $01$ na njegovu lijevom kraju zamijeni u $10$: krajnja lijeva jedinica odlazi za jedno mjesto ulijevo i više nije susjedna ostatku bloka, tj. lijevi kraj bloka se pomaknuo udesno (za $L \ge 2$ ostatak bloka je i dalje neprazan). Iza bloka stoji $0$; ako je iza te nule $1$, par $01$ se zamijeni i jedinica dolazi tik uz blok — desni kraj napreduje. Ako je iza te nule opet $0$, par $00$ se ne mijenja i desni kraj stoji. Za blokove nula argument je zrcalan. $\square$

Posljedice: slobodan blok jedinica (iza kojega ne stoji blok nula) translatira se udesno brzinom $1$ zadržavajući masu; slobodan blok nula translatira se ulijevo. Blok jedinica neposredno iza kojega slijedi blok nula ($\dots 1111\,0000 \dots$) i taj blok nula sudaraju se: oba svake sekunde gube po $1$ masu (lijevi kraj bloka jedinica i desni kraj bloka nula se i dalje miču, a spoj $10$ stoji). Blok mase $0$ (duljine $1$) postaje dio pozadine — kažemo da je nestao. Konačno, blok ne može nastati ni iz čega: jedinica dolazi na novo polje samo pomakom ulijevo, pa dvije jedinice postanu susjedne jedino ako je lijeva od njih mirovala — a jedinica miruje točno kad je i lijevo od nje jedinica, tj. kad je već u bloku jedinica (zrcalno za nule). Zato svaki blok u trenutku $t$ nastaje produljenjem nekog postojećeg bloka i ukupan broj blokova ne raste.

Praznine između blokova, invarijanta mase i simetrija

Između bloka jedinica $P$ i prvog sljedećeg bloka $Q$ (u smjeru udesno) stoji komad pozadine. Ako je $Q$ blok nula, taj komad počinje nulom i završava jedinicom, pa je parne duljine $g \ge 0$; $P$ putuje udesno, $Q$ ulijevo, i $g$ se svake sekunde smanjuje za $2$ dok ne postane $0$ — tada počinje sudar. Ako je $Q$ blok jedinica, komad između je neparne duljine i ne mijenja se (oba bloka putuju istom brzinom u istom smjeru). Praznina između bloka nula i sljedećeg bloka jedinica raste za $2$ po sekundi.

Neka je $M_1$ ukupna masa blokova jedinica, a $M_0$ blokova nula. Slobodno gibanje masu ne mijenja, a svaki sudar oduzima po $1$ objema stranama, pa je $M_1 - M_0$ invarijanta. Dok postoje blokovi obaju tipova, postoji blok nula čiji je prvi lijevi susjedni blok blok jedinica; njihova se praznina smanjuje za $2$ svake sekunde, pa sudar nastupa u konačnom vremenu. Stoga ako je $M_1 \ge M_0$, svi blokovi nula nestanu nakon konačno mnogo sekundi, a ostane ukupna masa jedinica $M_1 - M_0$.

Simetrija. Ako je $M_1 < M_0$, komplementiramo i obrnemo niz. Komplement prevodi pravilo „$01 \to 10$” u „$10 \to 01$”, a obrat zamjenjuje lijevo i desno, pa kompozicija tih dviju bijekcija prevodi jedan korak procesa na izvornom nizu u jedan korak istog procesa na transformiranom nizu. Broj različitih nizova je stoga isti, a uloge nula i jedinica su zamijenjene, pa možemo pretpostaviti $M_1 \ge M_0$. Isto vrijedi za rotaciju niza, pa smijemo rotirati tako da niz počinje na početku nekog segmenta.

Lema 2 (nakon nestanka blokova nula niz se samo rotira). Ako u nizu nema bloka nula, sljedeći niz je njegov ciklički pomak za jedno mjesto udesno.

Dokaz. Niz se sastoji od blokova jedinica i praznina između njih oblika $0\,1\,0 \dots 1\,0$ (neparne duljine, počinju i završavaju nulom); ako blokova jedinica nema, niz je čista izmjena $0101\dots$ (parne duljine $n$). Po lemi 1 svaki blok jedinica se pomiče udesno za $1$ (desni kraj napreduje jer iza bloka slijedi $01$), a u prazninama se svaki par $01$ zamijeni u $10$, što je pomak za jedno mjesto udesno. Sve zajedno je upravo rotacija niza udesno. $\square$

Redoslijed sudara: stog

Blokovi su maksimalni segmenti, pa nikad ne mijenjaju ciklički poredak. Blok nula $Q$ putuje ulijevo i sudara se s najbližim živim blokom jedinica lijevo od sebe — da bi se dva bloka dodirnula, svi blokovi između njih moraju već biti nestali. Ako je masa bloka jedinica $P$ veća, $Q$ nestaje i $P$ nastavlja (s manjom masom) prema sljedećem bloku nula; ako je masa $Q$ veća, nestaje $P$ i $Q$ nastavlja prema prvom živom bloku jedinica dalje ulijevo; kod jednakih masa nestanu oba. To je točno pravilo uparivanja zagrada: blok jedinica je otvorena zagrada s masom, blok nula zatvorena zagrada s masom, a sudari se odvijaju u LIFO redoslijedu.

Na krugu treba odabrati početak. Pridružimo blokovima u cikličkom poretku vrijednosti $+\text{masa}$ (jedinice) i $-\text{masa}$ (nule) te promotrimo prefiksne zbrojeve; ukupan zbroj je $M_1 - M_0 \ge 0$. Krenemo li od bloka iza položaja na kojemu prefiksni zbroj postiže minimum, svaki prefiks od tog početka ima zbroj $\ge 0$ (standardni argument: prefiksni zbroj od novog početka jednak je razlici starog prefiksnog zbroja i minimuma, uvećanoj za ukupan zbroj kad prijeđemo preko kraja). Tada pri linearnom prolasku s lijeva na desno stog živih blokova jedinica u trenutku obrade bloka nula uvijek sadrži barem toliko mase koliko taj blok ima: skidamo s vrha stoga (i smanjujemo mase) dok masa bloka nula ne padne na $0$. Time smo za svaki blok nula odredili s kojim se blokovima jedinica sudara i koliko mase pritom razmijeni — a to je fizički ispravan redoslijed sudara, jer je svaki sudar određen samo time koji su blokovi između dva bloka već nestali.

Trenutak dodira i trenutak nestanka

Uvedimo linearne koordinate od odabranog početka (blokovi koji se u cikličkom poretku nalaze „iza” početka dobivaju položaje uvećane za $n$). Za blok jedinica $P$ neka je $x_P(0)$ položaj lijevog, a $e_P(0)$ desnog kraja u trenutku $0$; za blok nula $Q$ neka je $f_Q(0)$ položaj lijevog kraja. Po lemi 1:

  • $x_P(t) = x_P(0) + t$ — lijevi kraj bloka jedinica napreduje svake sekunde;
  • $e_P(t) = e_P(0) + t - \ell_P(t)$, gdje je $\ell_P(t)$ masa koju je $P$ izgubio do trenutka $t$ — desni kraj stoji točno u sekundama sudara, a svaka takva sekunda odnosi $1$ masu;
  • $f_Q(t) = f_Q(0) - t + \ell_Q(t)$, zrcalno.

Blokovi $P$ (na vrhu stoga) i $Q$ dodiruju se kad je $f_Q(T) - e_P(T) = 1$, dakle

$$T = \frac{f_Q(0) - e_P(0) - 1 + \ell_P + \ell_Q}{2},$$

gdje su $\ell_P$ i $\ell_Q$ mase izgubljene u ranijim sudarima. Svi raniji sudari bloka $P$ bili su s blokovima nula koji su stajali između $P$ i $Q$, a raniji sudari bloka $Q$ s blokovima jedinica između njih; svi su završili prije nego što su se $P$ i $Q$ dodirnuli, pa su $\ell_P$ i $\ell_Q$ u trenutku $T$ upravo vrijednosti koje stog već zna (početna masa minus preostala). Brojnik je paran: broj polja između $P$ i $Q$ u trenutku $0$ jednak je (paran broj segmenata između njih) $+$ (ukupna masa blokova između njih), a ta se masa poništila dijelom na $P$ ($\ell_P$), dijelom na $Q$ ($\ell_Q$) i dijelom međusobno (paran doprinos), pa je $f_Q(0) - e_P(0) - 1 + \ell_P + \ell_Q \equiv 2(\ell_P + \ell_Q) \equiv 0 \pmod 2$.

Sudar traje $d = \min(a, b)$ sekundi, gdje su $a$ i $b$ preostale mase; nakon njega $P$ ima masu $a - d$ (ako je $0$, skidamo ga sa stoga), a $Q$ masu $b - d$. Ako je $b - d = 0$, blok $Q$ nestaje u trenutku $T + d$; inače nastavlja sa sljedećim blokom na vrhu stoga (s $\ell_Q$ uvećanim za $d$). Trenutak stabilizacije je $t^* = \max_Q (\text{trenutak nestanka } Q)$; ako blokova nula uopće nema, $t^* = 0$.

Završni niz i odgovor

U trenutku $t^*$ svi su blokovi nula nestali, a blokovi jedinica preostali na stogu imaju lijevi kraj na $x_P(0) + t^*$ (modulo $n$) i duljinu $1 + (\text{preostala masa})$; svi njihovi sudari završili su najkasnije u $t^*$, pa su te vrijednosti točne. Sva ostala polja pripadaju pozadini: iza svakog bloka jedinica slijedi $0$, zatim se znakovi izmjenjuju do idućeg bloka, a ispred bloka jedinica stoji $0$. Da je duljina praznine neparna (pa se izmjena „slaže” s oba kraja) slijedi iz istog računa parnosti kao gore: udaljenost lijevih krajeva dvaju uzastopnih preživjelih blokova nepromijenjena je od trenutka $0$; u trenutku $0$ između njih je stajao neparan broj segmenata, a masa između njih poništila se dijelom na prvom bloku (koji je zato izgubio isto toliko) i dijelom međusobno (parno). Ako stog ostane prazan ($M_1 = M_0$), završni je niz čista izmjena $0101\dots$, $n$ je paran i period je $2$.

Po lemi 2 stanja $a(t^*), a(t^*+1), \dots$ su rotacije udesno istog niza, pa ih je različitih točno $p$ = najmanji ciklički period niza $a(t^*)$; računamo ga prefiksnom funkcijom: $p = n - \pi[n-1]$ ako $p \mid n$, inače $p = n$. Svako stanje $a(t)$ za $t < t^*$ sadrži barem jedan blok nula (posljednji nestaje tek u $t^*$), a nijedna rotacija niza $a(t^*)$ ga ne sadrži — rep i ciklus su disjunktni. Stanja repa su međusobno različita: kad bi $a(t_1) = a(t_2)$ za $t_1 < t_2 < t^*$, deterministički bi se proces zauvijek vrtio među nizovima koji sadrže blok nula, u suprotnosti s time da svi blokovi nula nestanu. Odgovor je dakle

$$t^* + p \pmod{998244353},$$

iako je zbroj uvijek manji od $2n$: $p \le n$, a $t^* < n$ jer je blok jedinica koji dovršava posljednji sudar cijelo vrijeme lijevo od bloka nula, a njihovi se „slobodni” krajevi približavaju brzinom $2$ s početne udaljenosti manje od $2n$.

Algoritam

  1. Ako je niz konstantan, ispiši $1$. Rotiraj niz tako da počinje na početku segmenta i odredi blokove (položaj, duljina) te $M_1$, $M_0$; ako je $M_1 < M_0$, obrni i komplementiraj niz i ponovi.
  2. Izračunaj prefiksne zbrojeve $\pm$ masa po blokovima i kreni od bloka iza minimuma; blokovima iza početka dodaj $n$ na položaje.
  3. Prolazi blokove redom sa stogom: blok jedinica stavi na stog; za blok nula ponavljaj — uzmi vrh $P$, izračunaj $T$ po gornjoj formuli, $d = \min$ preostalih masa, ažuriraj mase i izgubljene mase, skini $P$ ako mu je masa $0$; kad masa bloka nula padne na $0$, $t^* \leftarrow \max(t^*, T + d)$.
  4. Sastavi niz u trenutku $t^*$: upiši preživjele blokove jedinica na $x_P(0) + t^* \pmod n$, a praznine popuni izmjenom $0, 1, 0, \dots$ počevši nulom iza svakog bloka (ako stog ostane prazan, niz je $0101\dots$).
  5. Prefiksnom funkcijom izračunaj najmanji period $p$ i ispiši $t^* + p$.

Svaki je korak linearan (svaki blok uđe na stog i siđe s njega najviše jednom; svaka iteracija unutarnje petlje ili skida blok sa stoga ili završava blok nula), pa je složenost $O(n)$ po nizu, ukupno $O(\sum n) = O(10^7)$. Memorija je $O(n)$; ulaz od $10^7$ znakova i do $10^6$ redaka izlaza traže vlastito čitanje (fread) i pisanje u međuspremnik.

Provjera na primjerima

$0001111$: blokovi su $Q = 000$ (položaji $0$–$2$, masa $2$) i $P = 1111$ (položaji $3$–$6$, masa $3$); $M_1 = 3 \ge M_0 = 2$. Prefiksni zbrojevi $-2, +1$ imaju minimum iza $Q$, pa krećemo od $P$; $Q$ dobiva linearni položaj $7$–$9$. Za par $(P, Q)$: $f_Q(0) - e_P(0) - 1 = 7 - 6 - 1 = 0$, $T = 0$, $d = \min(3, 2) = 2$, pa $Q$ nestaje u trenutku $2$ i $t^* = 2$. Preživjeli $P$ ima masu $1$ (duljinu $2$) i lijevi kraj na $3 + 2 = 5$: polja $5, 6$ su jedinice, a praznina $0$–$4$ je $01010$. Završni niz $0101011$ ima period $7$; odgovor $2 + 7 = 9$. (Izravna simulacija: $0001111 \to 0010111 \to 0101011$.)

$001001$: blokovi su dva bloka nula mase $1$, $M_1 = 0 < M_0 = 2$, pa obrat i komplement daju $011011$ s dva bloka jedinica i bez blokova nula: $t^* = 0$, period niza $011011$ je $3$, odgovor $3$. Niz $1$ je konstantan: odgovor $1$.

Zamke

  • Masa bloka je duljina $-1$, a ne duljina: blok duljine $2$ nestaje već nakon jedne sekunde sudara. Uvjet „ukupna duljina blokova jedinica $\ge$ ukupna duljina blokova nula” iz službenog rješenja treba čitati s tako umanjenim duljinama.
  • Krug obavezno linearizirati od pravog početka (iza minimuma prefiksnih zbrojeva) i blokovima iza početka dodati $n$; niz prije toga rotirati tako da segment ne prelazi preko granice indeksa $n - 1 \to 0$.
  • Ne zaboravi slučaj praznog stoga ($M_1 = M_0$: čista izmjena, period $2$) i konstantan niz ($1$).
  • Period računaj na nizu u trenutku $t^*$, a ne na početnom.

// UCup 1, Stage 11 (EC-Final 2022), B. Binary String
// Službeni pristup preko "blokova": maksimalni segmenti duljine >= 2 su blokovi, sve ostalo je izmjenična
// pozadina 0101... Blok nula svake sekunde putuje ulijevo, blok jedinica udesno (duljina im se ne mijenja);
// kad blok jedinica sustigne blok nula, oba se svake sekunde skrate za 1 dok kraći ne nestane (postane
// duljine 1, tj. dio pozadine). "Masa" bloka duljine L je L - 1. BSO ukupna masa blokova jedinica je
// veća ili jednaka od mase blokova nula (inače komplement + obrat, što komutira s procesom); tada svi
// blokovi nula nestanu. Biramo početak tako da je masa jedinica u svakom prefiksu >= mase nula, pa se
// sudari odvijaju po stogu (kao zagrade): blok nula uvijek udara u najbliži živi blok jedinica lijevo.
// Trenutak dodira para (P, Q) čita se iz početnih položaja i dosad izgubljenih masa:
//     T = (razmak(P, Q) u t = 0 + izgubljeno_P + izgubljeno_Q) / 2 .
// Kad nestane posljednji blok nula (t*), niz se samo ciklički pomiče udesno; odgovor = t* + period(a(t*)).
#include <bits/stdc++.h>
using namespace std;

static char buf[1 << 25];
int bufLen = 0, bufPos = 0;
inline int gc() {
    if (bufPos == bufLen) { bufLen = fread(buf, 1, sizeof(buf), stdin); bufPos = 0; if (bufLen <= 0) return -1; }
    return buf[bufPos++];
}
bool readToken(string &s) {
    s.clear();
    int c = gc();
    while (c != -1 && (c == ' ' || c == '\n' || c == '\r' || c == '\t')) c = gc();
    if (c == -1) return false;
    while (c != -1 && c != ' ' && c != '\n' && c != '\r' && c != '\t') { s.push_back((char)c); c = gc(); }
    return true;
}

const long long MOD = 998244353;

struct Block {
    int start, len;                         // početni položaj i duljina u t = 0 (linearne koordinate)
    int lost;                               // masa izgubljena u dosadašnjim sudarima
};

long long solve(string &s) {
    int n = s.size();
    int m = count(s.begin(), s.end(), '1');
    if (m == 0 || m == n) return 1;                        // konstantan niz: ništa se ne mijenja

    // Rotiramo niz tako da na položaju 0 počinje segment (rotacija komutira s procesom).
    {
        int i = 1;
        while (s[i] == s[i - 1]) i++;
        rotate(s.begin(), s.begin() + i, s.end());
    }
    auto runs = [&](vector<Block> &bl, long long &mass1, long long &mass0) {
        bl.clear(); mass1 = mass0 = 0;
        for (int i = 0; i < n;) {
            int j = i;
            while (j < n && s[j] == s[i]) j++;
            if (j - i >= 2) {
                bl.push_back({i, j - i, 0});
                (s[i] == '1' ? mass1 : mass0) += j - i - 1;
            }
            i = j;
        }
    };
    vector<Block> bl;
    long long mass1, mass0;
    runs(bl, mass1, mass0);
    if (mass1 < mass0) {                                    // komplement + obrat: uloge 0 i 1 se zamjenjuju
        reverse(s.begin(), s.end());
        for (char &c : s) c ^= 1;
        runs(bl, mass1, mass0);
    }
    int k = bl.size();

    // Početak: nakon najmanjeg prefiksnog zbroja (+masa za blok jedinica, -masa za blok nula)
    // svaki prefiks ima masu jedinica >= masi nula, pa je stog uvijek dovoljno "težak".
    int k0 = 0;
    {
        long long pref = 0, best = 0;
        for (int i = 0; i < k; i++) {
            pref += (s[bl[i].start] == '1' ? 1 : -1) * (long long)(bl[i].len - 1);
            if (pref < best) { best = pref; k0 = i + 1; }
        }
        if (k0 == k) k0 = 0;
    }

    long long tstar = 0;
    vector<Block> st; st.reserve(k);                        // stog živih blokova jedinica
    for (int idx = 0; idx < k; idx++) {
        Block b = bl[(k0 + idx) % k];
        if (k0 + idx >= k) b.start += n;                    // blokovi "iza" početka: linearne koordinate
        if (s[bl[(k0 + idx) % k].start] == '1') { st.push_back(b); continue; }
        int bcur = b.len - 1;                               // preostala masa bloka nula Q
        while (bcur > 0) {
            Block &p = st.back();                           // najbliži živi blok jedinica lijevo
            int pcur = p.len - 1 - p.lost;
            long long gap = (long long)b.start - (p.start + p.len - 1) - 1;   // polja između P i Q u t = 0
            long long T = (gap + p.lost + b.lost) / 2;      // trenutak dodira (uvijek cijeli broj)
            int d = min(pcur, bcur);
            p.lost += d; b.lost += d; bcur -= d;
            if (p.lost == p.len - 1) st.pop_back();
            if (bcur == 0) tstar = max(tstar, T + d);       // Q nestaje u trenutku T + d
        }
    }

    // Niz u trenutku t*: preživjeli blokovi jedinica pomaknuti za t*, između njih izmjenična pozadina.
    string fin(n, '?');
    for (const Block &p : st) {
        int L = p.len - p.lost;                             // trenutna duljina bloka
        long long x = (p.start + tstar) % n;
        for (int c = 0; c < L; c++) fin[(x + c) % n] = '1';
    }
    if (st.empty()) {                                       // sve mase su se poništile: čisti 0101... (n paran)
        for (int i = 0; i < n; i++) fin[i] = (i & 1) ? '1' : '0';
    } else {
        for (const Block &p : st) {                         // praznina iza bloka: 0 1 0 1 ... 0 (neparna)
            long long x = (p.start + tstar + p.len - p.lost) % n;
            char v = '0';
            while (fin[x] == '?') { fin[x] = v; v ^= 1; x = (x + 1) % n; }
        }
    }

    // najmanji ciklički period niza fin (prefiksna funkcija)
    vector<int> pi(n, 0);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && fin[i] != fin[j]) j = pi[j - 1];
        if (fin[i] == fin[j]) j++;
        pi[i] = j;
    }
    int per = n - pi[n - 1];
    if (n % per != 0) per = n;
    return (tstar + per) % MOD;
}

int main() {
    string tok;
    readToken(tok);
    int T = stoi(tok);
    string out;
    string s;
    while (T-- && readToken(s)) {
        out += to_string(solve(s));
        out.push_back('\n');
        if (out.size() > (1 << 22)) { fwrite(out.data(), 1, out.size(), stdout); out.clear(); }
    }
    fwrite(out.data(), 1, out.size(), stdout);
    return 0;
}

2. RJEŠENJE: Jedinice kao čestice i (max, +) rekurzija

Za razliku od službenog pristupa, koji prati blokove i njihove sudare stogom, ovdje svaku jedinicu promatramo kao česticu koja putuje ulijevo i dinamiku zapisujemo jednom zatvorenom formulom u $(\max, +)$ algebri; trenutak stabilizacije i završni niz tada se čitaju iz jednog pomoćnog niza $W$ monotonim stogom i prozorskim maksimumom, bez eksplicitnog praćenja blokova. Pristup je zgodan kad se traži formula za položaj pojedine čestice u proizvoljnom trenutku $t$ (npr. za upite), a sudari blokova su u njemu skriveni u maksimumu.

Model: jedinice kao čestice

Zamjena $01 \to 10$ pomiče jedinicu za jedno mjesto ulijevo. Sve se zamjene izvode istodobno prema stanju u trenutku $t$, pa se jedinica na položaju $y$ pomiče točno onda kad je polje $y - 1$ u trenutku $t$ prazno (nula). Ako je ondje druga jedinica, ona ostaje na mjestu, pa makar se ta druga jedinica u istoj sekundi pomaknula. Jedinice su dakle čestice koje se gibaju ulijevo brzinom najviše $1$ i nikad se ne pretječu; poredak čestica po krugu je očuvan.

Ako je $m$ broj jedinica i $m = 0$ ili $m = n$, niz se ne mijenja i odgovor je $1$. Ako je $2m > n$, primijenimo komplement i obrat: komplement pretvara pravilo „$01 \to 10$” u „$10 \to 01$” (nule postaju čestice koje putuju udesno), a obrat vraća smjer. Obje su operacije bijekcije koje komutiraju s jednim korakom procesa, pa je broj različitih nizova isti. Nadalje pretpostavljamo $2m \le n$.

Rekurzija položaja i njezino rješenje

Neka su $Y_0 < Y_1 < \dots < Y_{m-1}$ početni položaji čestica u $[0, n)$ i produžimo ih ciklički: $Y_{i - m} = Y_i - n$ za sve cijele $i$. Označimo s $y_j(t)$ položaj čestice $j$ u trenutku $t$ (isto produženo). Čestica $j$ se pomiče točno kad je $y_j(t) - y_{j-1}(t) \ge 2$; inače je razmak točno $1$ i ostaje. Zato

$$y_j(t+1) = \max\bigl(y_j(t) - 1,\ y_{j-1}(t) + 1\bigr),$$

jer je pri razmaku $\ge 2$ prvi član veći, a pri razmaku $1$ drugi član jednak $y_j(t)$. Rekurzija je linearna u $(\max, +)$ algebri i razmotava se kao „najdulji put”: u $t$ koraka $d$ puta biramo drugi član (prelazak na prethodnu česticu, $+1$) i $t - d$ puta prvi ($-1$), pa je

$$y_j(t) = \max_{0 \le d \le t} \bigl( Y_{j-d} + d - (t - d) \bigr) = -t + 2j + \max_{j - t \le i \le j} W_i, \qquad W_i := Y_i - 2i.$$

Niz $W$ ima dva svojstva: $W_i - W_{i-1} = (Y_i - Y_{i-1}) - 2 \ge -1$ (pada najviše za $1$ po koraku) i $W_{i+m} = W_i + (n - 2m) \ge W_i$ (zbog $2m \le n$).

Kada je čestica zaglavljena i kada proces postaje rotacija

Neka je $M_j(t) = \max_{[j-t, j]} W$. Razmak je $y_j(t) - y_{j-1}(t) = 2 + M_j(t) - M_{j-1}(t)$. Prozori $[j-t, j]$ i $[j-1-t, j-1]$ razlikuju se samo u krajnjim indeksima, pa je $M_{j-1}(t) > M_j(t)$ točno kad je $W_{j-1-t} > \max(W_{j-t}, \dots, W_j)$; tada je zbog pada od najviše $1$ razlika točno $1$, a razmak točno $1$ — čestica $j$ je zaglavljena. Definirajmo $\mathrm{nxt}_i = \min\{ d \ge 1 : W_{i+d} \ge W_i \}$ (postoji i $\le m$ jer je $W_{i+m} \ge W_i$). Indeks $i$ uzrokuje zaglavljivanje (čestice $j = i + 1 + t$) u svim trenucima $t < \mathrm{nxt}_i - 1$, i ni u jednom kasnijem. Zato je

$$t^* = \max_i \bigl(\mathrm{nxt}_i - 1\bigr) \le m - 1$$

prvi trenutak u kojem su sve čestice slobodne; skup „zaglavljenih trenutaka” je početni odsječak $\{0, \dots, t^* - 1\}$. Kad su sve čestice slobodne, svi se razmaci čuvaju, pa je svaki sljedeći niz ciklički pomak prethodnog za jedno mjesto ulijevo.

Broj različitih nizova

Proces je deterministički, pa je niz stanja „rep pa ciklus”. Stanja $a(t^*), a(t^*+1), \dots$ su rotacije istog niza; njihov broj je najmanji ciklički period $p$ niza $a(t^*)$ ($a$ pomaknut za $p$ jednak je $a$). Stanja $a(0), \dots, a(t^*-1)$ imaju barem jednu zaglavljenu česticu, dok su sva stanja na ciklusu slobodna, pa se rep i ciklus ne sijeku. Stanja repa su međusobno različita: kad bi $a(t_1) = a(t_2)$ za $t_1 < t_2 < t^*$, proces bi se zauvijek vrtio među zaglavljenim stanjima i nikad ne bi postao slobodan. Dakle odgovor je $t^* + p$ (modulo $998244353$, iako je zbroj $\le n + m < 2 \cdot 10^7$).

Algoritam

  1. Ako je niz konstantan, ispiši $1$. Ako je $2m > n$, obrni i komplementiraj.
  2. Izračunaj $W_i$ za $i \in [-m, m)$: $W_0 = Y_0$, $W_i = W_{i-1} + (Y_i - Y_{i-1}) - 2$, $W_{i-m} = W_i - (n - 2m)$.
  3. Monotonim stogom zdesna nalijevo nađi za svaki $i \in [-m, 0)$ prvi indeks desno s $W \ge W_i$; $t^* = \max(\mathrm{nxt}_i - 1)$. (Dovoljan je jedan period indeksa jer je $\mathrm{nxt}_{i+m} = \mathrm{nxt}_i$.)
  4. Niz u trenutku $t^*$: $y_j = -t^* + 2j + \max_{[j - t^*, j]} W$ za $j \in [0, m)$, prozorski maksimum dequeom; položaje svedi modulo $n$.
  5. Prefiksnom funkcijom izračunaj najmanji period $p$ ($p = n - \pi[n-1]$ ako dijeli $n$, inače $p = n$) i ispiši $t^* + p$.

Sve faze su linearne, dakle $O(n)$ po nizu, ukupno $O(\sum n) = O(10^7)$. Memorija je $O(n)$; ulaz od $10^7$ znakova i do $10^6$ redaka izlaza zahtijevaju vlastito čitanje (fread) i pisanje.

Provjera na primjerima

$001001$: $m = 2$, $Y = (2, 5)$, $W = (2, 3)$, $W_{-2} = 0$, $W_{-1} = 1$. Odmah je $\mathrm{nxt} = 1$ za oba, $t^* = 0$; period od $001001$ je $3$, odgovor $3$.

$0001111$: $m = 4 > 3.5$, pa obrat i komplement daju $0000111$, $m = 3$, $Y = (4, 5, 6)$, $W = (4, 3, 2)$ i $W_{-3..-1} = (3, 2, 1)$. Vrijednosti $\mathrm{nxt}_{-3} = 3$, $\mathrm{nxt}_{-2} = 2$, $\mathrm{nxt}_{-1} = 1$ daju $t^* = 2$. Položaji u trenutku $2$: $y_j = -2 + 2j + \max_{[j-2, j]} W = 2, 4, 6$, niz $0010101$ ima period $7$; odgovor $2 + 7 = 9$.

Veza sa službenim (blokovskim) rješenjem

Unutar bloka jedinica samo prva (lijeva) čestica napreduje, a zaglavljene čestice su upravo one koje čekaju iza nje; blok nula je praznina duljine $\ge 2$ između dviju čestica. Sudar blokova u jeziku čestica znači da se čestice iz bloka jedinica jedna za drugom odvajaju i „popunjavaju” prazninu; $t^*$ je trenutak zadnjeg sudara, a uvjet $W_{i+d} \ge W_i$ odgovara tome da je blok jedinica koji počinje česticom $i$ do udaljenosti $d$ potrošio svu prazninu ispred sebe. Formulacija preko $W$ i $\mathrm{nxt}$ zamjenjuje eksplicitni stog blokova monotonim stogom nad $W$.

Zamke

  • Ne zaboravi slučaj $2m > n$; bez transformacije $\mathrm{nxt}_i$ ne mora postojati unutar $m$ indeksa.
  • Indekse $W$ pomakni za $+m$ pri pohrani (negativni indeksi), a položaje $y_j$ svedi na $[0, n)$ s pravilnim rukovanjem negativnih ostataka.
  • Period niza računaj na nizu u trenutku $t^*$, a ne na početnom.

Provjera koda: uzorak 1/1 (3 niza); 300 slučajnih testova (nizovi duljine $\le 12$) protiv brute forcea koji simulira proces do prvog ponavljanja; dodatno iscrpno svi binarni nizovi duljine $\le 13$; 3 velika testa (jedan niz od $10^7$ znakova, odnosno $10^6$ nizova) do $0.28$ s; ručni veliki testovi ($n = 10^7$) daju iste odgovore kao službeni pristup, najviše $0.65$ s i $213$ MB.

// UCup 1, Stage 11 (EC-Final 2022), B. Binary String
// (2. rješenje na stranici; službeni pristup preko blokova i stoga je u sol.cpp.)
// Jedinice su "čestice" koje se pomiču ulijevo ako je lijevo polje prazno (paralelni TASEP / pravilo 184).
// Ako jedinica ima najviše koliko i nula (inače primijenimo komplement + obrat, što komutira s procesom),
// položaji čestica zadovoljavaju max-plus rekurziju y_j(t+1) = max(y_j(t) - 1, y_{j-1}(t) + 1), čije je
// rješenje y_j(t) = -t + 2j + max_{j-t <= i <= j} W_i, gdje je W_i = Y_i - 2i, a Y_i početni položaj
// i-te čestice (indeksi se produžuju ciklički: Y_{i-m} = Y_i - n).
// Proces postane čisto ciklički pomak u trenutku t* = max_i nxt_i - 1, gdje je nxt_i najmanji d >= 1 s
// W_{i+d} >= W_i. Odgovor = t* + (najmanji period niza u trenutku t*).
#include <bits/stdc++.h>
using namespace std;

static char buf[1 << 25];
int bufLen = 0, bufPos = 0;
inline int gc() {
    if (bufPos == bufLen) { bufLen = fread(buf, 1, sizeof(buf), stdin); bufPos = 0; if (bufLen <= 0) return -1; }
    return buf[bufPos++];
}
bool readToken(string &s) {
    s.clear();
    int c = gc();
    while (c != -1 && (c == ' ' || c == '\n' || c == '\r' || c == '\t')) c = gc();
    if (c == -1) return false;
    while (c != -1 && c != ' ' && c != '\n' && c != '\r' && c != '\t') { s.push_back((char)c); c = gc(); }
    return true;
}

const long long MOD = 998244353;

long long solve(string &s) {
    int n = s.size();
    int m = count(s.begin(), s.end(), '1');
    if (m == 0 || m == n) return 1;                        // konstantan niz: ništa se ne mijenja
    if (2 * m > n) {                                        // komplement + obrat: uloge 0 i 1 se zamjenjuju
        reverse(s.begin(), s.end());
        for (char &c : s) c ^= 1;
        m = n - m;
    }
    vector<int> q; q.reserve(m);
    for (int i = 0; i < n; i++) if (s[i] == '1') q.push_back(i);

    // W na indeksima [-m, m) -> pohranjeno kao W[i + m]
    vector<long long> W(2 * m);
    W[m] = q[0];                                            // W_0 = Y_0 - 0
    for (int i = 1; i < m; i++) W[m + i] = W[m + i - 1] + (q[i] - q[i - 1]) - 2;
    for (int i = 0; i < m; i++) W[i] = W[i + m] - (n - 2 * m); // W_{i-m} = W_i - (n - 2m)

    // nxt_i: prvi indeks desno s W >= W_i (postoji unutar m koraka jer je W_{i+m} >= W_i);
    // računamo za i u [-m, 0) po kopiji [0, m) -> potrebni indeksi u [-m, m)
    long long tstar = 0;
    {
        vector<int> st; st.reserve(2 * m);
        for (int i = 2 * m - 1; i >= 0; i--) {
            while (!st.empty() && W[st.back()] < W[i]) st.pop_back();
            if (i < m) tstar = max(tstar, (long long)(st.back() - i) - 1);
            st.push_back(i);
        }
    }

    // položaji u trenutku t*: y_j = -t* + 2j + max W na [j - t*, j], j u [0, m) -> indeksi [m - t*, 2m)
    string fin(n, '0');
    {
        deque<int> dq;
        int t = (int)tstar;
        for (int idx = m - t; idx < 2 * m; idx++) {
            while (!dq.empty() && W[dq.back()] <= W[idx]) dq.pop_back();
            dq.push_back(idx);
            int j = idx - m;                                // prozor [j - t, j] završava u idx
            if (j >= 0) {
                while (dq.front() < idx - t) dq.pop_front();
                long long y = -tstar + 2LL * j + W[dq.front()];
                y %= n; if (y < 0) y += n;
                fin[y] = '1';
            }
        }
    }

    // najmanji ciklički period niza fin (prefiksna funkcija)
    vector<int> pi(n, 0);
    for (int i = 1; i < n; i++) {
        int k = pi[i - 1];
        while (k > 0 && fin[i] != fin[k]) k = pi[k - 1];
        if (fin[i] == fin[k]) k++;
        pi[i] = k;
    }
    int p = n - pi[n - 1];
    if (n % p != 0) p = n;
    return (tstar + p) % MOD;
}

int main() {
    string tok;
    readToken(tok);
    int T = stoi(tok);
    string out;
    string s;
    while (T-- && readToken(s)) {
        out += to_string(solve(s));
        out.push_back('\n');
        if (out.size() > (1 << 22)) { fwrite(out.data(), 1, out.size(), stdout); out.clear(); }
    }
    fwrite(out.data(), 1, out.size(), stdout);
    return 0;
}
