ZADATAK A: The Best Problem of 2021

Najbolji zadatak 2021. — The 1st Universal Cup, Stage 13: Iberia (44th Petrozavodsk Programming Camp, Day 6: Um_nik mod 998 244 353 Contest). Vremensko ograničenje: 2 s, memorijsko ograničenje: 512 MiB.

Dan je niz $B$ od $n$ brojeva i broj $X$; svi su zadani kao binarni nizovi duljine točno $m$. Brojeve promatramo kao vektore nad $\mathbb{Z}_2$ s bitovnim XOR-om kao zbrajanjem. Izračunaj, modulo $998244353$, broj podskupova $S \subseteq \{1, 2, \dots, X\}$ kojima je $B$ jedna od baza: $B$ je baza skupa $S$ ako je to niz najmanje veličine takav da se svaki element skupa $S$ može zapisati kao XOR nekih elemenata iz $B$.

Ulaz

$n$ i $m$ ($1 \le n, m \le 2000$), zatim $n$ binarnih nizova duljine $m$ (elementi $B$) i binarni niz duljine $m$ ($X$).

Izlaz

Traženi broj.

Primjer

Za $B = \{0001, 0010, 0100, 1000\}$ i $X = 1101$ odgovor je $7364$. Za $B=\{00,00,00\}$ i $X=11$ odgovor je $0$; za $B=\{110,101\}$ i $X=101$ odgovor je $1$; za $B=\{1111100110,0011110100,0101100001\}$ i $X=1110000001$ odgovor je $38$.

NAPUTCI

Naputak 1klikni za prikaz

Što točno znači „$B$ je jedna od baza skupa $S$”? $B$ mora biti niz najmanje veličine čiji raspon sadrži $S$. Ako je $B$ linearno zavisan, neki manji podniz razapinje isti potprostor — odgovor je $0$. Ako je nezavisan, uvjet glasi: $S\subseteq V=\operatorname{span}(B)$ i $\operatorname{span}(S)=V$. Dakle brojimo podskupove skupa $T=V\cap[1,X]$ koji razapinju cijeli $V$.

Naputak 2klikni za prikaz

Zapiši $V$ u reduciranoj stupnjevitoj bazi (pivoti = najviši bitovi, svaki pivot-bit ima samo jedan redak). Tada je usporedba dvaju elemenata od $V$ kao brojeva jednaka leksikografskoj usporedbi njihovih vektora koeficijenata. Zato je $V\cap[0,X]$ točno $t$ najmanjih elemenata od $V$, a u koordinatama koeficijenata zadatak postaje: koliko podskupova od $\{1,\dots,Y\}\subseteq\mathbb Z_2^n$, $Y=t-1$, razapinje cijeli $\mathbb Z_2^n$? Za „razapinje cijeli prostor” koristi Möbiusovu inverziju po rešetki potprostora: treba $A_k=\sum_{\dim U=k}2^{|U\cap[0,Y]|}$.

Naputak 3klikni za prikaz

Broj $|U\cap[0,Y]|$ dobiva se hodanjem po bitovima $Y$ odozgo: svaki pivot $p$ s $Y_p=1$ iznad točke razilaženja $D$ doda $2^{(\text{broj pivota ispod }p)}$. Zato je $2^{|U\cap[0,Y]|}$ produkt faktora po bitovima, pa se $\sum_U$ računa DP-om po bitovima odozdo prema gore (tada je broj pivota ispod poznat). Slobodne bitove reduciranih baza broji na pivotima ($2^{c-j}$), a uvjete na ne-pivot bitovima zamijeni faktorom $\tfrac12$: ako je najviši bit pivot, bit „trenutnog vektora” na svakom ne-pivot mjestu uniformno je $0$ ili $1$.

TRENERSKI NAČIN: logički put do rješenja

Logički put do rješenja: svaki je korak pitanje koje bi si iskusan natjecatelj postavio. Pokušaj na njega odgovoriti sam, pa tek onda otvori odgovor i usporedi – cilj je uvježbati način razmišljanja, a ne zapamtiti rješenje.

  1. Zašto zadatak uopće govori o „jednoj od baza”, a ne o rasponu — i što to znači za $B$ koji je linearno zavisan?

    Baza je po definiciji najmanji niz koji razapinje zadani skup. Ako je $B$ zavisan, izbacivanjem jednog elementa raspon se ne mijenja, pa $B$ nikad nije najmanji i odgovor je $0$ (drugi primjer: tri nul-vektora). Ako je $B$ nezavisan, $|B|=\dim V$, a najmanji niz za $S$ ima veličinu $\dim\operatorname{span}(S)$; jednakost $|B|=\dim\operatorname{span}(S)$ uz $S\subseteq V$ znači točno $\operatorname{span}(S)=V$. Prvi korak svakog zadatka s „bazom” je Gaussova eliminacija nad $\mathbb Z_2$ — bitsetovi daju $O(n^2m/64)$.

  2. Skup $T=V\cap[1,X]$ ima do $2^{2000}$ elemenata — kako ga uopće opisati?

    Ne po elementima, nego po strukturi. Pitaj se: kako se uspoređuju dva elementa od $V$? U reduciranoj stupnjevitoj bazi redak s pivotom $p$ jedini je s jedinicom na mjestu $p$, pa dva elementa prvi put (odozgo) mogu različiti baš na pivotu — onome najvišem na kojem im se razlikuju koeficijenti. To znači da je numerički poredak na $V$ isti kao poredak vektora koeficijenata čitanih kao binarni brojevi. Prema tome $V\cap[0,X]$ je početni komad $\{0,1,\dots,t-1\}$ u koordinatama koeficijenata: cijeli $B$ smijemo zamijeniti standardnom bazom od $\mathbb Z_2^n$, a $X$ brojem $Y=t-1$. Dovoljno je jednim prolaskom po bitovima $X$ izračunati $t$.

  3. Kako se broje podskupovi koji razapinju cijeli prostor kad znamo samo brojati podskupove unutar potprostora?

    Isto kao i s uključivanjem–isključivanjem, samo na rešetki potprostora. Za svaki potprostor $U$ lako je prebrojati podskupove od $T\cap U$ — ima ih $2^{|T\cap U|}$ — a svaki od njih razapinje točno jedan $W\le U$. Inverzija te relacije daje broj podskupova s rasponom točno $V$: $\sum_{U}\mu(U,V)\,2^{|T\cap U|}$ s $\mu(U,V)=(-1)^k2^{\binom k2}$, $k=\dim V-\dim U$ ($q$-analogon binomne inverzije uz $q=2$). Vrijedi zapamtiti: broj podskupova $S\subseteq\mathbb Z_2^n\setminus\{0\}$ koji razapinju sve je $\sum_k(-1)^{n-k}2^{\binom{n-k}2}\genfrac[]{0pt}{}{n}{k}_2\,2^{2^k-1}$ — a ovdje je $T$ samo „odrezan” skup $[1,Y]$, pa Gaussov binom zamjenjuje težinska suma $A_k=\sum_{\dim U=k}2^{|U\cap[0,Y]|}$.

  4. Što određuje $|U\cap[0,Y]|$ i zašto se to lijepo rastavlja po bitovima?

    Hodaj bitovima $Y$ odozgo i gradi element od $U$ koji se slaže s $Y$. Na pivotu $p$ imaš dva izbora koeficijenta: ako je $Y_p=1$, izbor koji daje bit $0$ čini sve $2^{j_p}$ nastavaka manjima od $Y$ ($j_p$ = broj pivota ispod $p$), a drugi izbor nastavlja; ako je $Y_p=0$, jedan izbor je prevelik, drugi nastavlja. Na ne-pivot mjestu $c$ bit je prisiljen: ako se razlikuje od $Y_c$, to je točka razilaženja $D$ — doda se $2^{j_D}$ ako je naš bit manji, inače ništa — i hodanje staje. Dakle $|U\cap[0,Y]|=\sum_{p>D,\;Y_p=1}2^{j_p}+[\text{bit}_Dispod, DP mora ići odozdo.

  5. DP odozdo ne zna kakvi su slobodni bitovi redaka iznad — kako onda nametnuti uvjet „bit na ne-pivot mjestu $c$ jednak je $Y_c$”?

    Ne nameći ga pojedinačno, nego prebroji koliko reduciranih baza ga zadovoljava. Bit „trenutnog vektora” na mjestu $c$ je XOR slobodnih bitova na mjestu $c$ onih redaka iznad koji su uključeni. Ako $U$ ima pivot na najvišem bitu $n-1$ (a $Y_{n-1}=1$, inače je odgovor $0$), taj je redak uvijek uključen, a njegov slobodni bit na mjestu $c$ pojavljuje se samo u uvjetu za $c$. Zato svaki uvjet na ne-pivot mjestu zadovoljava točno polovica konfiguracija — faktor $\tfrac12$ — a ukupan broj slobodnih bitova prebrojiš na pivotima: redak s pivotom $c$ ima $c-j$ slobodnih mjesta ispod sebe. Potprostore bez pivota na najvišem bitu riješi odvojeno: svi su im elementi $\le Y$, pa daju $\genfrac[]{0pt}{}{n-1}{k}_2\,2^{2^k}$.

Opći savjeti i prečaci

  • U zadatcima nad $\mathbb Z_2$ prvo prevedi sve u koordinate koeficijenata reducirane stupnjevite baze: tamo je potprostor cijeli $\mathbb Z_2^r$, a mnogi „numerički” uvjeti (npr. $\le X$) postaju uvjeti na početne komade $\{0,\dots,Y\}$.
  • „Koliko podskupova razapinje cijeli prostor / ima rang točno $r$” gotovo uvijek znači Möbiusovu inverziju po rešetki potprostora s $\mu=(-1)^k2^{\binom k2}$; ostaje izračunati težinske sume po potprostorima zadane dimenzije, a potprostore prebrojavaj kao reducirane stupnjevite baze (skup pivota + slobodni bitovi).
  • Kad je težina potprostora oblika $2^{\sum_{\text{bitova}}(\dots)}$, pretvori je u produkt po bitovima i piši DP po bitovima; smjer DP-a odaberi tako da veličine o kojima faktori ovise (ovdje broj pivota ispod) budu već poznate.
  • Uvjet na XOR slobodnih bitova nikad ne nameći eksplicitno: ako u XOR ulazi barem jedan slobodan bit koji se nigdje drugdje ne pojavljuje, točno polovica konfiguracija ga zadovoljava — faktor $\tfrac12$ (modularni inverz).
  • Eksponenti poput $2^{2^j}$ ili $2^{\binom{d}{2}}$ brzo prerastu tablice potencija: eksponent smanji modulo $p-1$ (Fermat) i računaj brzim potenciranjem, a ne indeksiranjem.
RJEŠENJEklikni za prikaz cijelog rješenja

Savjet: prije čitanja rješenja prođi kroz korake trenerskog načina iznad.

Napomena: u službenom tutorialu rješenje ovog zadatka označeno je kao „TBD” (0 od 263 ekipa riješilo ga je na natjecanju). Ovdje je izloženo rješenje složenosti $O(n^2m/64+n^2)$ koje slijedi pristup iz javnih objašnjenja zadatka (zapis Rainbow_qwq, 2023.) i provjereno je vlastitom implementacijom.

$B$ je „jedna od baza” skupa $S$ točno kad je $B$ linearno nezavisan, $S\subseteq V=\operatorname{span}(B)$ i $\operatorname{span}(S)=V$; ako je $B$ zavisan, odgovor je $0$. U reduciranoj stupnjevitoj bazi od $V$ numerički poredak elemenata jednak je poretku vektora koeficijenata, pa je $V\cap[0,X]$ skup $t$ najmanjih elemenata od $V$ ($t$ se dobije jednim hodom po bitovima $X$). U koordinatama koeficijenata treba prebrojati podskupove skupa $\{1,\dots,Y\}\subseteq\mathbb Z_2^n$, $Y=t-1$, koji razapinju $\mathbb Z_2^n$; ako $Y$ nema najviši bit, odgovor je $0$.

Möbiusova inverzija po rešetki potprostora daje $\text{odgovor}=\tfrac12\sum_{k}(-1)^{n-k}2^{\binom{n-k}2}A_k$, gdje je $A_k=\sum_{\dim U=k}2^{|U\cap[0,Y]|}$ (faktor $\tfrac12$ jer $U$ sadrži $0$). Potprostore brojimo kao reducirane stupnjevite baze. Za $U$ bez pivota na bitu $n-1$ svi su elementi $\le Y$, pa je doprinos $\genfrac[]{0pt}{}{n-1}{k}_2\,2^{2^k}$. Za ostale, $|U\cap[0,Y]|=\sum_{p>D,\,Y_p=1}2^{j_p}+[\text{bit}_D=0]2^{j_D}+[D\text{ ne postoji}]$, gdje je $j_p$ broj pivota ispod $p$, a $D$ prvo ne-pivot mjesto na kojem se vektor sastavljen od redaka s $Y_p=1$ razlikuje od $Y$. Taj je izraz zbroj po bitovima, pa je $2^{|U\cap[0,Y]|}$ produkt faktora $2^{2^{j}}$ po bitovima i cijelu sumu računa DP po bitovima odozdo prema gore sa stanjem (broj pivota $j$ ispod, faza ispod/iznad $D$): pivot na mjestu $c$ donosi $2^{c-j}$ slobodnih bitova i faktor $2^{2^j}$ ako je $Y_c=1$ i iznad smo $D$; ne-pivot mjesto iznad $D$ (ili samo $D$) donosi faktor $\tfrac12$, jer je bit trenutnog vektora ondje uniforman čim je redak s pivotom $n-1$ uključen. Ukupno $O(n^2)$ nakon eliminacije bitsetovima.

DETALJNO RJEŠENJE

Napomena: službeni tutorial za ovaj zadatak sadrži samo „TBD”, a na natjecanju ga nije riješila nijedna od 263 ekipe. Rješenje u nastavku slijedi ideju iz javnih objašnjenja zadatka (blog Rainbow_qwq, svibanj 2023.: inverzija po potprostorima + DP po bitovima odozdo), izvedeno je samostalno u svim koracima i provjereno vlastitom implementacijom protiv brute forcea.

1. Što znači „$B$ je jedna od baza skupa $S$”

Baza skupa $S$ je niz najmanje veličine čiji raspon sadrži $S$; najmanja takva veličina je $\dim\operatorname{span}(S)$. Ako je $B$ linearno zavisan, izbacivanjem jednog elementa raspon se ne mijenja, pa $B$ nije najmanji ni za koji $S$ — odgovor je $0$ (drugi primjer). Ako je $B$ nezavisan i $V=\operatorname{span}(B)$, onda je $|B|=n=\dim V$ i uvjet glasi: $S\subseteq V$ (svaki element se zapisuje preko $B$) i $\dim\operatorname{span}(S)=n$, tj. $\operatorname{span}(S)=V$. Dakle:

$$\text{odgovor}=\#\{S\subseteq T:\ \operatorname{span}(S)=V\},\qquad T=V\cap[1,X].$$

Nezavisnost provjeravamo Gaussovom eliminacijom nad $\mathbb Z_2$ s bitsetovima: redak po redak eliminiramo već postojeće pivote (najviši bit), što stoji $O(n\cdot n\cdot m/64)\approx1.25\cdot10^8$ operacija nad riječima. Pritom dobivamo stupnjevitu bazu $\{r_p\}$ indeksiranu pivotom $p$ (najvišim bitom retka); $n>m$ automatski daje zavisnost.

2. Redukcija na standardnu bazu: $V\cap[0,X]$ je početni komad

Neka je baza od $V$ reducirana stupnjevita: redak $r_p$ ima najviši bit $p$, a nijedan drugi redak nema jedinicu na mjestu $p$. Svaki $v\in V$ jedinstveno je $v=\bigoplus_{p\in P}c_p r_p$; vektor koeficijenata $c=(c_p)_{p\in P}$ čitamo kao binarni broj s najvišim pivotom kao najznačajnijom znamenkom.

Lema. Za $u,v\in V$ vrijedi $u

Dokaz. Neka je $p$ najviši pivot na kojem se $c(u)$ i $c(v)$ razlikuju. Redci s pivotom većim od $p$ u $u$ i $v$ imaju iste koeficijente, redci s pivotom manjim od $p$ imaju nule na svim mjestima $\ge p$, a jedini redak s jedinicom na mjestu $p$ je $r_p$. Zato se $u$ i $v$ slažu na svim bitovima iznad $p$, a na bitu $p$ imaju redom $c_p(u)$ i $c_p(v)$. Dakle veći je onaj s $c_p=1$ — isto kao kod usporedbe vektora koeficijenata. $\square$

Posljedica: $V\cap[0,X]$ čini točno $t=|V\cap[0,X]|$ najmanjih elemenata od $V$, a u koordinatama koeficijenata to je skup $\{0,1,\dots,t-1\}\subseteq\mathbb Z_2^n$. Linearna (ne)zavisnost i raspon ne ovise o izboru koordinata, pa je zadatak ekvivalentan ovome:

Reducirani zadatak. Zadan je $Y=t-1$ ($n$-bitni broj). Koliko podskupova skupa $\{1,\dots,Y\}\subseteq\mathbb Z_2^n$ razapinje cijeli $\mathbb Z_2^n$?

Prvi primjer je već u tom obliku ($B$ je standardna baza, $Y=X=1101_2=13$). Ako je $Y<2^{n-1}$, nijedan element nema najviši bit i odgovor je $0$.

Računanje $t$. Hodamo bitovima $X$ odozgo i održavamo vektor $\mathit{now}\in V$ koji se slaže s $X$ na svim dosad viđenim bitovima (ne treba potpuno reducirana baza — dovoljna je stupnjevita, jer je $t$ svojstvo potprostora). Neka je $j_c$ broj pivota na mjestima $0=X_c$, svi su veći i stajemo. Dođemo li do kraja, $X\in V$ i $t\mathrel{+}=1$. Broj $t$ može biti do $2^n$, pa ga držimo kao binarni niz od $n+2$ bita i zbrajamo s prijenosom; $Y=t-1$ oduzimanjem s posudbom (uvijek $t\ge1$ jer $0\in V$).

3. Möbiusova inverzija po rešetki potprostora

Neka je $T_0=\{0,1,\dots,Y\}$ (uključili smo $0$ — to udvostručuje svaki broj podskupova, pa ćemo na kraju podijeliti s $2$). Za potprostor $U\le\mathbb Z_2^n$ označimo $F(U)=2^{|U\cap T_0|}$ = broj podskupova od $T_0\cap U$, i $E(U)$ = broj podskupova od $T_0$ čiji je raspon točno $U$. Svaki podskup od $T_0\cap U$ razapinje točno jedan $W\le U$, pa je $F(U)=\sum_{W\le U}E(W)$. Möbiusova inverzija na rešetki potprostora daje

$$E(\mathbb Z_2^n)=\sum_{U\le\mathbb Z_2^n}\mu(U,\mathbb Z_2^n)\,F(U),\qquad \mu(U,V)=(-1)^{k}\,2^{\binom k2},\ k=\dim V-\dim U .$$

(To je $q$-analogon binomne inverzije za $q=2$: interval $[U,V]$ u rešetki potprostora izomorfan je rešetki potprostora od $V/U$, a Möbiusova funkcija rešetke potprostora $\mathbb Z_2^k$ od najmanjeg do najvećeg elementa iznosi $(-1)^k2^{\binom k2}$.) Grupiramo li potprostore po dimenziji,

$$\text{odgovor}=\frac12\sum_{k=0}^{n}(-1)^{n-k}2^{\binom{n-k}2}A_k,\qquad A_k=\sum_{\dim U=k}2^{|U\cap[0,Y]|}.$$

Provjera na prvom primjeru ($n=4$, $Y=13$): $A_0=2$, $A_1=56$, $A_2=452$, $A_3=2240$, $A_4=2^{14}=16384$, pa je $\frac12\,(16384-2240+2\cdot452-8\cdot56+64\cdot2)=\frac12\cdot14728=7364$. Ostaje izračunati $A_k$ bez nabrajanja potprostora — njih je oko $2^{n^2/4}$.

4. Koliko je elemenata potprostora $U$ najviše $Y$

Svaki potprostor $U$ ima jedinstvenu reduciranu stupnjevitu bazu: skup pivota $P\subseteq\{0,\dots,n-1\}$ i za svaki pivot $p$ slobodne bitove retka $r_p$ na ne-pivot mjestima $c

Isti hod kao u odjeljku 2 primijenjen na $U$ i $Y$ daje: neka je $\mathit{now}=\bigoplus_{p\in P,\ Y_p=1}r_p$ (u reduciranoj bazi koeficijent na pivotu $p$ koji „slijedi $Y$” je točno $Y_p$) i neka je $D$ najviše ne-pivot mjesto na kojem se $\mathit{now}$ razlikuje od $Y$ (ako postoji). Tada

$$|U\cap[0,Y]|=\sum_{p\in P,\ p>D,\ Y_p=1}2^{j_p}\;+\;[\mathit{now}_D=0]\,2^{j_D}\;+\;[D\text{ ne postoji}].$$

Posebno: ako $n-1\notin P$, svi elementi od $U$ imaju najviši bit $0$, pa su svi $\le Y$ (jer je $Y_{n-1}=1$) i $|U\cap[0,Y]|=2^k$. Takvih potprostora dimenzije $k$ ima $\genfrac[]{0pt}{}{n-1}{k}_2$ (Gaussov binom — broj $k$-dimenzionalnih potprostora od $\mathbb Z_2^{n-1}$), pa je njihov doprinos $A_k$ jednak $\genfrac[]{0pt}{}{n-1}{k}_2\,2^{2^k}$. Gaussove binome računamo iz $\genfrac[]{0pt}{}{N}{k+1}_2=\genfrac[]{0pt}{}{N}{k}_2\frac{2^{N-k}-1}{2^{k+1}-1}$.

5. Ključna lema: uvjeti na ne-pivot mjestima prepolavljaju

Ostaju potprostori s $n-1\in P$. Formula iz odjeljka 4 ovisi o konfiguraciji slobodnih bitova samo kroz bitove $\mathit{now}_c$ na ne-pivot mjestima $c$, i to samo kroz pitanje „na kojem je prvom mjestu odozgo $\mathit{now}_c\ne Y_c$”.

Lema. Fiksirajmo skup pivota $P\ni n-1$ i bilo koji skup ne-pivot mjesta $C$ s propisanim vrijednostima $b_c\in\{0,1\}$. Broj konfiguracija slobodnih bitova za koje je $\mathit{now}_c=b_c$ za sve $c\in C$ iznosi $2^{F-|C|}$.

Dokaz. $\mathit{now}_c$ je XOR slobodnih bitova $r_{p,c}$ po pivotima $p>c$ s $Y_p=1$. Budući da je $Y_{n-1}=1$ i $n-1\in P$, redak $r_{n-1}$ uvijek sudjeluje, a njegov slobodni bit $r_{n-1,c}$ pojavljuje se u izrazu za $\mathit{now}_c$ i ni u jednom drugom. Za svaku vrijednost ostalih slobodnih bitova postoji točno jedan $r_{n-1,c}$ koji daje $\mathit{now}_c=b_c$; uvjeti za različite $c$ koriste različite bitove $r_{n-1,c}$, pa su neovisni. $\square$

Prema tome, u sumi po svim konfiguracijama s pivotima $P$ konfiguracije s točkom razilaženja baš u $D$ (uvjeti: $\mathit{now}_c=Y_c$ za sve ne-pivot $c>D$ i $\mathit{now}_D\ne Y_D$) čine udio $2^{-(\#\text{ne-pivot mjesta}>D)-1}$, a one bez točke razilaženja udio $2^{-\#\text{ne-pivot mjesta}}$. Upravo to omogućuje da DP ne pamti slobodne bitove: svaki ne-pivot bit iznad $D$ (uključivo $D$) nosi faktor $\tfrac12$, svaki pivot nosi faktor $2^{c-j}$ za svoje slobodne bitove, a bitovi ispod $D$ ne nose ništa.

6. DP po bitovima odozdo prema gore

Formula za $|U\cap[0,Y]|$ je zbroj po bitovima, pa je $2^{|U\cap[0,Y]|}$ produkt faktora po bitovima: pivot $p>D$ s $Y_p=1$ nosi $2^{2^{j_p}}$, mjesto $D$ nosi $2^{2^{j_D}}$ ako je $Y_D=1$ (tada je $\mathit{now}_D=0ispod, pa bitove obrađujemo od $c=0$ prema $c=n-1$ i pamtimo $j$ = broj dosad odabranih pivota, te fazu:

  • $f_j$ — nalazimo se ispod točke razilaženja (ona tek dolazi iznad; dosadašnji pivoti ne doprinose eksponentu),
  • $g_j$ — nalazimo se iznad točke razilaženja ili ona ne postoji (ova dva slučaja imaju iste prijelaze, razlikuju se samo početnom težinom).

Početno $f_0=1$, $g_0=2$ (faktor $2$ za $Y\in U$ u slučaju bez razilaženja). Za $c=0,\dots,n-1$ i svaki $j$:

  1. $c$ je pivot: $f'_{j+1}\mathrel{+}=f_j\cdot2^{c-j}$ i $g'_{j+1}\mathrel{+}=g_j\cdot2^{c-j}\cdot\bigl(2^{2^j}\bigr)^{[Y_c=1]}$. Za $c=n-1$ ovo je jedini dopušteni prijelaz.
  2. $c$ nije pivot ($c

Nakon zadnjeg koraka $f$ je besmislen (razilaženje iznad najvišeg bita ne postoji) i doprinos potprostora s pivotom $n-1$ dimenziji $k$ je $g_k$. Ukupno $A_k=g_k+\genfrac[]{0pt}{}{n-1}{k}_2\,2^{2^k}$, a odgovor daje formula iz odjeljka 3. Mala provjera: $n=1$, $Y=1$: $g_1=2\cdot2^0\cdot2^{2^0}=4$, $A_0=2$, odgovor $\frac12(4-2)=1$ — jedini podskup je $\{1\}$.

7. Složenost

Eliminacija: $O(n^2m/64)\approx1.25\cdot10^8$ operacija nad 64-bitnim riječima. Hod za $t$: $O(m\cdot(m/64+n))$. DP: $O(n^2)=4\cdot10^6$ prijelaza. Gaussovi binomi i $2^{2^j}$: $O(n\log p)$. Referentna implementacija radi oko $0.05$ s za $n=m=2000$ uz limit od $2$ s; memorija $O(nm/8)$ za bitsetove.

8. Zamke u implementaciji

  • $2^{2^j}\bmod p$: eksponent $2^j$ smanji modulo $p-1$ (Mali Fermatov teorem), pa brzo potenciraj; nikako $2^j\bmod p$.
  • $2^{\binom{n-k}2}$ ima eksponent do $\approx2\cdot10^6$ — ne indeksiraj tablicu potencija duljine $O(n)$ (to je bio uzrok jednog segfaulta pri testiranju), nego potenciraj.
  • $t$ može biti $2^n$ (npr. $X$ veći od svih elemenata od $V$), pa mu treba $n+1$ bit; zbrajanja $2^{j}$ mogu imati prijenos (pivot neposredno iznad $D$ ima isti $j$ kao $D$). $Y=t-1$ tada je $11\ldots1$.
  • Faktor $\tfrac12$ je modularni inverz $(p+1)/2$; na kraju još jedno dijeljenje s $2$ zbog uključenog $0$.
  • Zavisan $B$ (uključujući nul-retke i $n>m$) daje $0$ odmah nakon eliminacije — ne smije se nastaviti s rangom manjim od $n$, jer bi reducirani zadatak brojao nešto drugo.
  • Pivot na mjestu $c$ ima točno $c-j$ slobodnih bitova (ne-pivot mjesta ispod njega), gdje je $j$ broj pivota ispod — koristi vrijednost $j$ prije uvećanja.

Provjera koda: uzorci 4/4; 400 slučajnih testova ($m\le6$, $n\le6$: nasumične nezavisne reducirane baze, nasumični redci sa zavisnostima, $X$ nasumičan ili s najvišim bitom ili $11\ldots1$) protiv Python brute forcea koji ide po elementima skupa $T=\operatorname{span}(B)\cap[1,X]$ s DP-om čije je stanje kanonska (reducirana stupnjevita) baza razapetog potprostora; 4 velika testa s $n=m=2000$ (nasumična matrica, standardna baza, gornjotrokutasta baza, rang $

KOD (C++)klikni za prikaz izvornog koda 
// UCup 1, Stage 13, A: The Best Problem of 2021
// 1) Gaussova eliminacija nad Z_2 (bitsetovi): ako B nije nezavisan -> 0.
// 2) t = |span(B) ∩ [0,X]|; u koordinatama koeficijenata skup span(B) ∩ [0,X] je točno {0,1,...,t-1},
//    pa se zadatak svodi na: koliko podskupova od {1,...,Y}, Y = t-1, razapinje cijeli Z_2^n.
// 3) Möbiusova inverzija po potprostorima: odgovor = (1/2) * sum_k (-1)^{n-k} 2^{C(n-k,2)} A_k,
//    A_k = sum po potprostorima U dimenzije k od 2^{|U ∩ [0,Y]|}.
// 4) A_k računamo DP-om po bitovima odozdo prema gore preko reduciranih stupnjevitih baza
//    (stanje: broj pivota ispod, faza "ispod/iznad točke razilaženja D").
#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;
typedef long long ll;
const ll MOD = 998244353;

ll pw(ll b, ll e) { ll r = 1; b %= MOD; if (b < 0) b += MOD; while (e) { if (e & 1) r = r * b % MOD; b = b * b % MOD; e >>= 1; } return r; }

int main() {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;
    int W = (m + 63) / 64;
    vector<string> rows(n);
    static char buf[2100];
    for (int i = 0; i < n; i++) { if (scanf("%s", buf) != 1) return 0; rows[i] = buf; }
    if (scanf("%s", buf) != 1) return 0;
    string xs = buf;
    auto toBits = [&](const string& s) {
        vector<ull> v(W, 0);
        for (int i = 0; i < m; i++) if (s[m - 1 - i] == '1') v[i >> 6] |= 1ULL << (i & 63);
        return v;
    };
    // stupnjevita baza: row[p] = redak s najvišim bitom p
    vector<vector<ull>> row(m);
    vector<char> has(m, 0);
    for (int i = 0; i < n; i++) {
        vector<ull> v = toBits(rows[i]);
        for (int p = m - 1; p >= 0; p--) {
            if (!((v[p >> 6] >> (p & 63)) & 1)) continue;
            if (!has[p]) { has[p] = 1; row[p] = v; break; }
            for (int w = 0; w < W; w++) v[w] ^= row[p][w];
        }
        bool zero = true;
        for (int w = 0; w < W; w++) if (v[w]) zero = false;
        if (zero) { puts("0"); return 0; }   // B nije linearno nezavisan
    }
    // cntBelow[c] = broj pivota na pozicijama < c
    vector<int> cntBelow(m + 1, 0);
    for (int c = 0; c < m; c++) cntBelow[c + 1] = cntBelow[c] + has[c];
    // t = |span(B) ∩ [0,X]| kao binarni broj (n+2 bita)
    vector<int> t(n + 2, 0);
    auto addPow = [&](int j) { for (int k = j; ; k++) { if (t[k] == 0) { t[k] = 1; break; } t[k] = 0; } };
    vector<ull> now(W, 0);
    vector<ull> X = toBits(xs);
    bool ended = false;
    for (int c = m - 1; c >= 0; c--) {
        int xb = (X[c >> 6] >> (c & 63)) & 1;
        int nb = (now[c >> 6] >> (c & 63)) & 1;
        if (has[c]) {
            if (xb) addPow(cntBelow[c]);          // izbor koji daje bit 0: svih 2^{j} nastavaka je < X
            if (nb != xb) for (int w = 0; w < W; w++) now[w] ^= row[c][w];
        } else if (nb != xb) {
            if (nb == 0) addPow(cntBelow[c]);     // now < X na ovom bitu: svi nastavci su manji
            ended = true; break;
        }
    }
    if (!ended) addPow(0);                        // sam X pripada span(B)
    // Y = t - 1
    vector<int> Y(n + 2, 0);
    { int borrow = 1; for (int k = 0; k < n + 2; k++) { int v = t[k] - borrow; if (v < 0) { v += 2; borrow = 1; } else borrow = 0; Y[k] = v; } }
    if (!Y[n - 1]) { puts("0"); return 0; }      // nijedan element nema najviši bit -> ne razapinju
    // pomoćne tablice
    vector<ll> p2(2 * n + 5, 1);
    for (int i = 1; i < (int)p2.size(); i++) p2[i] = p2[i - 1] * 2 % MOD;
    vector<ll> big(n + 1);                       // big[j] = 2^{2^j} mod p (eksponent mod p-1)
    { ll e = 1; for (int j = 0; j <= n; j++) { big[j] = pw(2, e); e = e * 2 % (MOD - 1); } }
    const ll inv2 = (MOD + 1) / 2;
    // DP: f = ispod točke razilaženja D (D postoji iznad), g = iznad D ili D ne postoji
    vector<ll> f(n + 2, 0), g(n + 2, 0), nf(n + 2), ng(n + 2);
    f[0] = 1; g[0] = 2;
    for (int c = 0; c < n; c++) {
        fill(nf.begin(), nf.end(), 0); fill(ng.begin(), ng.end(), 0);
        for (int j = 0; j <= c; j++) {
            if (!f[j] && !g[j]) continue;
            ll fac = p2[c - j];                    // slobodni bitovi retka s pivotom c
            ll mul = Y[c] ? big[j] : 1;            // doprinos pivota c skupu U ∩ [0,Y]
            // c je pivot
            nf[j + 1] = (nf[j + 1] + f[j] * fac) % MOD;
            ng[j + 1] = (ng[j + 1] + g[j] * fac % MOD * mul) % MOD;
            if (c < n - 1) {                       // c nije pivot (najviši bit mora biti pivot)
                nf[j] = (nf[j] + f[j]) % MOD;                         // još ispod D
                ng[j] = (ng[j] + f[j] * inv2 % MOD * mul) % MOD;      // c je točno D
                ng[j] = (ng[j] + g[j] * inv2) % MOD;                  // iznad D: now_c = Y_c
            }
        }
        swap(f, nf); swap(g, ng);
    }
    vector<ll> A(n + 1, 0);
    for (int k = 0; k <= n; k++) A[k] = g[k];
    // potprostori bez pivota na najvišem bitu: svi elementi su <= Y
    {
        ll gb = 1;                                 // [n-1 choose k]_2
        for (int k = 0; k <= n - 1; k++) {
            A[k] = (A[k] + gb * big[k]) % MOD;
            // prijelaz na [n-1 choose k+1]
            ll num = (p2[n - 1 - k] - 1 + MOD) % MOD, den = (p2[k + 1] - 1 + MOD) % MOD;
            gb = gb * num % MOD * pw(den, MOD - 2) % MOD;
        }
    }
    ll ans = 0;
    for (int k = 0; k <= n; k++) {
        int d = n - k;
        ll mu = pw(2, (ll)d * (d - 1) / 2);     // |mu(U,V)| = 2^{C(n-k,2)}
        if (d & 1) mu = (MOD - mu) % MOD;
        ans = (ans + mu * A[k]) % MOD;
    }
    ans = ans * inv2 % MOD;
    printf("%lld\n", ans);
    return 0;
}
