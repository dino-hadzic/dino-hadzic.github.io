ZADATAK D: Flower's Land 2

Cvjetna zemlja 2 — The 1st Universal Cup, Stage 17: Guangzhou (The 2022 CCPC Final (Guangzhou), May 20-21, 2023). Vremensko ograničenje: 6 s, memorijsko ograničenje: 1024 MiB.

Igra na nizu znamenki iz $\{0, 1, 2\}$: dok postoji $i$ sa $s_i = s_{i+1}$, igrač bira takav $i$ i briše $s_i$ i $s_{i+1}$. Igrač pobjeđuje ako se niz može potpuno izbrisati.

Dan je niz $s$ duljine $n$ i $q$ upita dviju vrsta: 1 l r — za sve $l \le i \le r$ postavi $s_i \leftarrow (s_i + 1) \bmod 3$; 2 l r — može li igrač pobijediti igrajući na $t = s[l..r]$?

Ulaz

$n, q$ ($1 \le n, q \le 5 \cdot 10^5$), niz $s$ i $q$ upita s $1 \le l \le r \le n$.

Izlaz

Za svaki upit vrste 2: Yes ili No.

Primjer

$s = 01211012$: $s[4..5] = 11$ → Yes; $s[3..6] = 2110$ → No. Nakon dvije operacije 1 6 8 niz je $01211201$; $s[3..6] = 2112$ → Yes ($2112 \to 22 \to \varepsilon$).

NAPUTCI

Naputak 1klikni za prikaz

Brisanje susjednog para jednakih znakova podsjeća na poništavanje $g \cdot g^{-1}$ u grupi. Kako niz pretvoriti u umnožak elemenata tako da se susjedni jednaki znakovi ponište, a različiti ne?

Naputak 2klikni za prikaz

Susjedne pozicije uvijek su različitog pariteta. Uzmi tri slučajne invertibilne matrice $M_0, M_1, M_2$ i znak na parnoj poziciji pretvori u $M_{s_i}$, a na neparnoj u $M_{s_i}^{-1}$: susjedni jednaki znakovi daju $M M^{-1} = I$ ili $M^{-1} M = I$. Umnožak nad intervalom održavaj segmentnim stablom; za operaciju $+1 \bmod 3$ u svakom čvoru čuvaj umnoške za sva tri pomaka.

TRENERSKI NAČIN: logički put do rješenja

Logički put do rješenja: svaki je korak pitanje koje bi si iskusan natjecatelj postavio. Pokušaj na njega odgovoriti sam, pa tek onda otvori odgovor i usporedi – cilj je uvježbati način razmišljanja, a ne zapamtiti rješenje.

  1. Ovisi li ishod igre o tome koje parove igrač briše, ili je „pobjeda” svojstvo samog niza?

    Ne ovisi o izboru. Brisanje susjednog para jednakih znakova je sustav prepisivanja $xx \to \varepsilon$, i on je konfluentan: dva različita brisanja koja se preklapaju ($xxx \to x$ na dva načina) daju isti rezultat, a disjunktna brisanja komutiraju. Zato svaki redoslijed vodi do iste normalne forme – niza bez susjednih jednakih znakova. Igrač pobjeđuje ako i samo ako je normalna forma prazna. Pitanje je dakle svojstvo niza, i to svojstvo podsjeća na redukciju riječi u grupi: susjedni par $g g^{-1}$ se poništava.

  2. Kako postići da se susjedni jednaki znakovi ponište kao $g g^{-1}$, a da segmentno stablo i dalje može množiti?

    Ključno opažanje: susjedne pozicije $i$ i $i+1$ uvijek su različitog pariteta. Odaberimo tri slučajne invertibilne matrice $M_0, M_1, M_2$ nad $\mathbb{Z}_p$ i definirajmo $A_i = M_{s_i}$ za parni $i$, $A_i = M_{s_i}^{-1}$ za neparni $i$. Ako je $s_i = s_{i+1}$, tada je $A_i A_{i+1} = M M^{-1}$ ili $M^{-1} M$ – u oba slučaja $I$. Brisanje para jednakih susjeda ne mijenja produkt $A_l A_{l+1} \cdots A_r$, a izbrisiv niz zato ima produkt točno $I$. Obrat (neizbrisiv niz $\Rightarrow$ produkt $\ne I$) vrijedi samo s velikom vjerojatnošću, kao kod svakog hashiranja; nekomutativnost matrica je ključna, jer bi u komutativnoj grupi npr. $0101$ (neizbrisiv) i $0011$ (izbrisiv) imali isti produkt.

  3. Zašto brisanje ne pokvari paritet preostalih znakova – nije li nakon brisanja para „parni” znak postao „neparni”?

    Paritet dodjeljujemo prema izvornoj poziciji u $s$ i nikad ga ne mijenjamo. Produkt $A_l \cdots A_r$ je fiksan broj; brisanje para $A_i A_{i+1} = I$ samo uklanja dva susjedna faktora iz umnoška, a ostali faktori (s već dodijeljenim paritetima) ostaju gdje jesu. Nakon brisanja novi susjedi $A_{i-1}$ i $A_{i+2}$ opet su različitog pariteta (razlika indeksa $3$), pa i njihov jednaki znak daje $M M^{-1}$ ili $M^{-1} M$. Indukcijom po broju brisanja: izbrisiv interval $\Rightarrow$ produkt $I$.

  4. Što operacija „$+1 \bmod 3$ na intervalu” radi s produktom i kako je učiniti lijenom?

    Ciklički permutira znakove $0 \to 1 \to 2 \to 0$, pa na parnim pozicijama $M_0 \to M_1 \to M_2 \to M_0$, a na neparnim $M_0^{-1} \to M_1^{-1} \to M_2^{-1} \to M_0^{-1}$. Produkt nakon pomaka nije izvediv iz produkta prije pomaka, ali pomaka ima samo tri: u svakom čvoru čuvamo tri produkta $P_0, P_1, P_2$ ($P_k$ = produkt segmenta ako svakom znaku dodamo $k$). Pomak za $d$ na cijelom čvoru je samo rotacija: novi $P_k$ = stari $P_{k+d}$. Lijena oznaka čvora je pomak $\in \{0,1,2\}$, a spajanje djece je $P_k = P_k^{L} P_k^{R}$ za svaki $k$.

  5. Zašto je vjerojatnost lažnog Yes zanemariva i koliko košta jedno množenje?

    Za fiksni neizbrisivi niz produkt je fiksna matrica racionalnih funkcija u slučajnim elementima matrica $M_c$ koja nije identički jednaka $I$ (postoje konkretne invertibilne matrice za koje nije – npr. one koje generiraju slobodnu grupu). Po Schwartz–Zippelu vjerojatnost da slučajna točka poništi netrivijalan polinom stupnja $\le r-l+1$ je najviše $(r-l+1)/p$; uz $p = 2^{61}-1$ i $5 \cdot 10^5$ upita to je ispod $10^{-6}$. Množenje $2\times 2$ matrica je $8$ množenja modulo $2^{61}-1$ (brzo množenje preko __int128), tri produkta po čvoru; ukupno $O((n+q)\log n)$ s malom konstantom.

Opći savjeti i prečaci

  • „Brisanje susjednih jednakih/inverznih parova” je redukcija riječi u grupi; pitanje „može li se sve izbrisati” je „je li produkt jedinica”. Hashiraj slučajnim nekomutativnim matricama – komutativni hash (zbroj, XOR) ne razlikuje $abab$ od $aabb$.
  • Kad se trebaju poništavati jednaki susjedi, iskoristi paritet pozicije: $M$ na parnim, $M^{-1}$ na neparnim mjestima pretvara $xx$ u $M M^{-1}$ bez ikakvih dodatnih uvjeta na $M$.
  • Ako operacija na intervalu permutira alfabet iz malog skupa permutacija (ovdje $3$ ciklička pomaka), u čvoru segmentnog stabla čuvaj agregat za svaku permutaciju; lijeno ažuriranje postaje puko preslagivanje polja.
  • Randomizirani algoritam sjemeni satom, a za stress-test brute force redukcijom stogom – konfluentnost jamči da je stog jedini potreban „igrač”.
RJEŠENJEklikni za prikaz cijelog rješenja

Savjet: prije čitanja rješenja prođi kroz korake trenerskog načina iznad.

Konstruiramo tri slučajne invertibilne matrice $M_0, M_1, M_2$.

Za svaki $i$: ako je $i \bmod 2 = 0$, stavimo $A_i = M_{s_i}$, inače $A_i = M_{s_i}^{-1}$.

Ako se interval može potpuno izbrisati, tada je $\prod_{i=l}^{r} A_i = I$ (svako brisanje para jednakih susjednih znakova uklanja umnožak matrice i njezina inverza). Obratno vrijedi s velikom vjerojatnošću.

Segmentnim stablom održavamo operaciju „dodaj $1$ modulo $3$ na intervalu” i umnožak matrica na intervalu (u čvoru čuvamo umnožak za svaki od tri moguća pomaka). Vremenska složenost je $O(n \log n \cdot k^3)$, gdje je $k$ dimenzija matrica.

Službeno rješenje ostavlja pitanje: bi li umjesto matrica poslužile afine funkcije $ax + b$ i $a^{-1}x - ba^{-1}$? (Primjer $02021210202121$ naveden je kao ilustracija za promišljanje.)

DETALJNO RJEŠENJE

1. Igra ne ovisi o izboru poteza

Potez briše dva susjedna jednaka znaka. Tvrdimo: bez obzira na redoslijed poteza, konačni niz (u kojem više nema susjednih jednakih znakova) uvijek je isti. To je konfluentnost sustava prepisivanja $xx \to \varepsilon$; dovoljno je provjeriti lokalnu konfluentnost (Newmanova lema, sustav očito završava jer se duljina smanjuje):

  • dva disjunktna brisanja komutiraju – rezultat je isti u oba redoslijeda;
  • dva preklapajuća brisanja mogu se preklapati samo u jednom znaku, tj. na bloku $xxx$; brisanje prvog ili drugog para daje isti niz $x$.

Dakle igrač pobjeđuje ako i samo ako je normalna forma niza $s[l..r]$ prazna. Normalnu formu računa stog: prolazimo znakove; ako je znak jednak vrhu stoga, skinemo vrh, inače ga stavimo na stog. Ovo je ujedno brute force za male testove.

2. Poništavanje jednakih susjeda kao $M M^{-1}$

U grupi se poništava par inverznih elemenata $g g^{-1}$, a mi trebamo poništavati par jednakih znakova. Službeno rješenje to rješava paritetom pozicije: susjedne pozicije $i$ i $i+1$ uvijek su različitog pariteta. Odaberimo tri slučajne invertibilne matrice $M_0, M_1, M_2 \in GL_2(\mathbb{Z}_p)$, $p = 2^{61}-1$, i definirajmo

$$A_i = \begin{cases} M_{s_i}, & i \text{ paran},\\ M_{s_i}^{-1}, & i \text{ neparan}. \end{cases}$$

Za interval $[l, r]$ promatramo produkt $\Pi(l, r) = A_l A_{l+1} \cdots A_r$ (redoslijed je bitan – matrice ne komutiraju).

Lema 1. Ako je $s[l..r]$ izbrisiv, tada je $\Pi(l, r) = I$.

Dokaz. Indukcijom po broju poteza. Pariteti se dodjeljuju prema izvornim pozicijama i ne mijenjaju se brisanjem. Ako igrač briše susjedne jednake znakove na izvornim pozicijama $i \lt j$ (susjedne u trenutnom nizu), svi znakovi između njih već su izbrisani; njih je paran broj (svaki potez briše dva), pa su $i$ i $j$ različitog pariteta i $A_i A_j$ je $M M^{-1}$ ili $M^{-1} M$, dakle $I$. Faktori između $A_i$ i $A_j$ u produktu su već izbrisani parovi koji (po induktivnoj pretpostavci primijenjenoj na taj podinterval) daju $I$, pa uklanjanje $A_i$ i $A_j$ ne mijenja vrijednost produkta. Nakon svih poteza produkt je prazan, tj. $I$. $\square$

Lema 2 (obrat, s velikom vjerojatnošću). Ako $s[l..r]$ nije izbrisiv, tada je $\Pi(l, r) \ne I$ s vjerojatnošću barem $1 - (r-l+1)/p$ po izboru $M_0, M_1, M_2$.

Skica dokaza. Neizbrisiv niz ima nepraznu normalnu formu $w$ (bez susjednih jednakih znakova), a $\Pi(l, r)$ jednak je produktu matrica koje odgovaraju $w$ (Lema 1 primijenjena na izbrisane dijelove). Pomnožimo li sve s $\det(M_0 M_1 M_2)^{L}$, elementi matrice $\Pi - I$ postaju polinomi stupnja $\le 3L$ u $12$ slučajnih elemenata matrica ($L = r - l + 1$). Ti polinomi nisu identički nula: postoje konkretne invertibilne matrice $M_0, M_1, M_2$ koje generiraju slobodnu grupu (npr. „ping-pong” matrice $\begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix}$, $\begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix}$ nad $\mathbb{Z}$ i njihove kombinacije), a u slobodnoj grupi reducirana riječ $w$ s naizmjeničnim $M$ i $M^{-1}$ različitih indeksa nije jedinica (dva susjedna faktora $M_a^{\pm1} M_b^{\mp1}$ s $a \ne b$ nikad se ne krate). Polinom koji nije identički nula nad $\mathbb{Z}$ ostaje takav modulo $p$ za sve osim konačno mnogo $p$, a Schwartz–Zippel daje vjerojatnost nule $\le 3L/p \le 1.5 \cdot 10^6 / 2^{61} \approx 7 \cdot 10^{-13}$ po upitu. Kroz $5 \cdot 10^5$ upita: $\lesssim 10^{-6}$. $\square$

Zašto je nekomutativnost bitna: u komutativnoj grupi bi $0101$ ($M_0 M_1^{-1} M_0 M_1^{-1}$) i $0011$ ($M_0 M_0^{-1} M_1 M_1^{-1}$) imali isti produkt (prvi niz je neizbrisiv, drugi izbrisiv). Baš zato službeno rješenje postavlja pitanje bi li afine funkcije $ax+b$ (koje čine nekomutativnu, ali „premalu” grupu) bile dovoljne – primjer $02021210202121$ služi kao protuprimjer za promišljanje.

Umjesto parova $M, M^{-1}$ mogu se uzeti i matrice s $A_c^2 = I$ bez ikakvog pariteta – to je drugi pristup razrađen ispod (2. rješenje). Službena konstrukcija ima prednost da od matrica ne traži ništa osim invertibilnosti.

3. Operacija $+1 \bmod 3$ na intervalu

Ta operacija zamjenjuje znak $c$ znakom $(c+1) \bmod 3$, dakle matricu $M_c$ matricom $M_{(c+1) \bmod 3}$ (odnosno $M_c^{-1}$ matricom $M_{(c+1) \bmod 3}^{-1}$) – paritet pozicije ostaje. Produkt segmenta nakon pomaka nije funkcija produkta prije pomaka, ali skup mogućih pomaka ima samo $3$ elementa. Zato u svakom čvoru segmentnog stabla čuvamo tri matrice $$P_k[v] = \prod_{i \in \text{segment}(v)} A_i^{(k)}, \qquad A_i^{(k)} = \begin{cases} M_{(s_i + k) \bmod 3}, & i \text{ paran},\\ M_{(s_i + k) \bmod 3}^{-1}, & i \text{ neparan},\end{cases} \qquad k = 0, 1, 2,$$ uz lijenu oznaku $\mathrm{lz}[v] \in \{0,1,2\}$ (pomak koji još treba proslijediti djeci). Operacije:

  • izgradnja: list na poziciji $i$ ima $P_k = M_{(s_i + k) \bmod 3}$ ili njezin inverz, ovisno o paritetu $i$; unutarnji čvor $P_k[v] = P_k[2v] \cdot P_k[2v+1]$ (redoslijed množenja slijeva nadesno!);
  • primjena pomaka $d$ na čvor: $P_k \leftarrow P_{(k+d) \bmod 3}$ za sve $k$ (rotacija triju matrica) i $\mathrm{lz} \leftarrow (\mathrm{lz} + d) \bmod 3$;
  • ažuriranje intervala: standardno lijeno – potpuno pokriven čvor dobiva pomak $1$, inače proslijedi oznaku djeci, spusti se, ponovno izračunaj $P_k$;
  • upit: produkt $P_0$ pokrivenih čvorova slijeva nadesno; odgovor Yes ako je jednak $I$.

Ispravnost rotacije: ako segment dobije pomak $d$, novi znakovi su $(s_i + d) \bmod 3$, pa je novi $P_k$ produkt matrica za znakove $(s_i + d + k) \bmod 3$ – to je upravo stari $P_{(k+d) \bmod 3}$.

4. Složenost

Segmentno stablo ima $O(\log n)$ dubine; svaka operacija dotiče $O(\log n)$ čvorova, a u čvoru radimo najviše tri množenja $2 \times 2$ matrica ($3 \cdot 8 = 24$ modularnih množenja). Ukupno $O((n + q) \log n \cdot k^3)$ s $k = 2$, tj. $O((n+q) \log n)$ vremena; memorija $3 \cdot 4 \cdot 8$ bajta po čvoru, $\approx 100$ MB za $2^{20}$ čvorova – daleko unutar $1024$ MiB. Uz $6$ s vremensko ograničenje je vrlo komotno (lokalno $\lt 1$ s za $n = q = 5 \cdot 10^5$).

5. Primjer

$s = 01211012$, upit $(4, 5)$: $s[4..5] = 11$, pozicije $4$ (parna) i $5$ (neparna), produkt $M_1 M_1^{-1} = I$ → Yes. Upit $(3, 6)$: $s[3..6] = 2110$; normalna forma je $20$ (nije prazna), produkt $M_2^{-1} (M_1 M_1^{-1}) M_0 = M_2^{-1} M_0 \ne I$ → No. Nakon dvije operacije 1 6 8 niz postaje $01211201$: $s[3..6] = 2112 \to 22 \to \varepsilon$, produkt $M_2^{-1} (M_1 M_1^{-1}) M_2 = I$ → Yes.

6. Zamke

  • Množenje matrica nije komutativno: pri spajanju djece i pri upitu strogo lijevo pa desno.
  • Paritet je paritet izvorne pozicije u $s$ – ne pozicije unutar upita $[l, r]$; lijevi kraj $l$ može biti bilo kojeg pariteta i to ne smeta (Lema 1).
  • Množenje modulo $2^{61}-1$: produkt dvaju 61-bitnih brojeva ne stane u 64 bita – koristi __uint128_t i redukciju $(x \,\&\, M) + (x \gg 61)$.
  • Inverz $2 \times 2$ matrice: $\frac{1}{\det}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$; slučajnu matricu ponovno biraj dok je $\det = 0$ (vjerojatnost $\approx 1/p$).
  • Sjeme generatora iz sata (ne fiksno) da bi hash bio nepredvidiv.
  • Veličina stabla: $n \le 5 \cdot 10^5$ zahtijeva $2^{20}$ čvorova pri indeksiranju $2v, 2v+1$.
  • Izlaz od $5 \cdot 10^5$ redaka skupljaj u buffer pa ispiši jednom.

Provjera koda: uzorci 1/1; 300 slučajnih testova ($n, q \le 10$, alfabet veličine $1$–$3$) protiv brute forcea koji eksplicitno ažurira niz i redukciju radi stogom; 3 velika testa ($n = q = 5 \cdot 10^5$, uključujući niz oblika $ww^R$ s mnogo izbrisivih intervala, najsporiji $0{,}84$ s).

KOD (C++)klikni za prikaz izvornog koda 
// UCup 1, Stage 17, D - Flower's Land 2
// Brisanje susjednih jednakih znakova je poništavanje para g * g^{-1}.
// Službena konstrukcija: tri slučajne invertibilne 2x2 matrice M_0, M_1, M_2
// modulo 2^61-1; znak s_i na PARNOJ poziciji postaje A_i = M_{s_i}, a na
// NEPARNOJ A_i = M_{s_i}^{-1}. Susjedni jednaki znakovi su uvijek različitog
// pariteta, pa se brišu kao M M^{-1} = I ili M^{-1} M = I. Izbrisiv interval
// zato uvijek daje produkt I; neizbrisiv daje I samo uz zanemarivu
// vjerojatnost (hash u nekomutativnoj grupi).
// Operacija +1 mod 3 rotira znakove 0->1->2->0, pa u čvoru segmentnog stabla
// čuvamo produkt za sva tri pomaka; lijeni pomak samo rotira ta tri produkta.
#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;
const ull MOD = (1ULL << 61) - 1;

inline ull mulm(ull a, ull b) {
    __uint128_t c = (__uint128_t)a * b;
    ull r = (ull)(c & MOD) + (ull)(c >> 61);
    if (r >= MOD) r -= MOD;
    return r;
}
inline ull addm(ull a, ull b) { ull r = a + b; return r >= MOD ? r - MOD : r; }
inline ull subm(ull a, ull b) { return a >= b ? a - b : a + MOD - b; }

struct Mat {
    ull a[4];  // [0 1; 2 3]
};
inline Mat mul(const Mat &x, const Mat &y) {
    Mat r;
    r.a[0] = addm(mulm(x.a[0], y.a[0]), mulm(x.a[1], y.a[2]));
    r.a[1] = addm(mulm(x.a[0], y.a[1]), mulm(x.a[1], y.a[3]));
    r.a[2] = addm(mulm(x.a[2], y.a[0]), mulm(x.a[3], y.a[2]));
    r.a[3] = addm(mulm(x.a[2], y.a[1]), mulm(x.a[3], y.a[3]));
    return r;
}
inline bool isId(const Mat &x) { return x.a[0] == 1 && x.a[1] == 0 && x.a[2] == 0 && x.a[3] == 1; }

ull pw(ull a, ull e) {
    ull r = 1;
    while (e) { if (e & 1) r = mulm(r, a); a = mulm(a, a); e >>= 1; }
    return r;
}
// inverz 2x2 matrice: det^{-1} * [d -b; -c a]
Mat inverse(const Mat &m) {
    ull det = subm(mulm(m.a[0], m.a[3]), mulm(m.a[1], m.a[2]));
    ull id = pw(det, MOD - 2);
    return {{mulm(m.a[3], id), mulm(subm(0, m.a[1]), id), mulm(subm(0, m.a[2]), id), mulm(m.a[0], id)}};
}

const int MAXN = 500005;
int n, q;
char s[MAXN];
Mat M[3], Minv[3];          // M_c i M_c^{-1} za znakove c = 0, 1, 2
Mat tr[1 << 20][3];         // tr[v][k] = produkt segmenta s pomakom k
unsigned char lz[1 << 20];  // lijeni pomak (0,1,2)

void build(int v, int l, int r) {
    lz[v] = 0;
    if (l == r) {
        int c = s[l] - '0';
        // parna pozicija -> M, neparna -> M^{-1}
        for (int k = 0; k < 3; k++) tr[v][k] = (l % 2 == 0) ? M[(c + k) % 3] : Minv[(c + k) % 3];
        return;
    }
    int m = (l + r) / 2;
    build(2 * v, l, m);
    build(2 * v + 1, m + 1, r);
    for (int k = 0; k < 3; k++) tr[v][k] = mul(tr[2 * v][k], tr[2 * v + 1][k]);
}
inline void applyShift(int v, int d) {
    if (d == 0) return;
    // novi produkt s pomakom k = stari s pomakom k+d
    Mat t[3];
    for (int k = 0; k < 3; k++) t[k] = tr[v][(k + d) % 3];
    for (int k = 0; k < 3; k++) tr[v][k] = t[k];
    lz[v] = (lz[v] + d) % 3;
}
inline void push(int v) {
    if (lz[v]) { applyShift(2 * v, lz[v]); applyShift(2 * v + 1, lz[v]); lz[v] = 0; }
}
void update(int v, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) { applyShift(v, 1); return; }
    push(v);
    int m = (l + r) / 2;
    update(2 * v, l, m, ql, qr);
    update(2 * v + 1, m + 1, r, ql, qr);
    for (int k = 0; k < 3; k++) tr[v][k] = mul(tr[2 * v][k], tr[2 * v + 1][k]);
}
Mat query(int v, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[v][0];
    push(v);
    int m = (l + r) / 2;
    if (qr <= m) return query(2 * v, l, m, ql, qr);
    if (ql > m) return query(2 * v + 1, m + 1, r, ql, qr);
    return mul(query(2 * v, l, m, ql, qr), query(2 * v + 1, m + 1, r, ql, qr));
}

int main() {
    mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    for (int c = 0; c < 3; c++) {
        // slučajna invertibilna matrica (ponavljaj dok determinanta nije 0)
        do {
            for (int t = 0; t < 4; t++) M[c].a[t] = rng() % MOD;
        } while (subm(mulm(M[c].a[0], M[c].a[3]), mulm(M[c].a[1], M[c].a[2])) == 0);
        Minv[c] = inverse(M[c]);
    }
    scanf("%d %d", &n, &q);
    scanf("%s", s + 1);
    build(1, 1, n);
    string out;
    while (q--) {
        int t, l, r;
        scanf("%d %d %d", &t, &l, &r);
        if (t == 1) update(1, 1, n, l, r);
        else out += isId(query(1, 1, n, l, r)) ? "Yes\n" : "No\n";
    }
    fputs(out.c_str(), stdout);
    return 0;
}

2. RJEŠENJE: Involutorne matrice bez pariteta (hash u grupi $\mathbb{Z}_2 * \mathbb{Z}_2 * \mathbb{Z}_2$)

Ovaj pristup razlikuje se od službenog samo u izboru grupe u kojoj hashiramo: umjesto da paritet pozicije bira između $M_c$ i $M_c^{-1}$, svakom znaku pridružimo involutornu matricu $A_c$ ($A_c^2 = I$), pa se jednaki susjedi krate bez obzira na položaj. Prednost mu je jednostavnija izgradnja (list ne ovisi o paritetu, nema računanja inverza), a cijena je da matrice moraju zadovoljavati dodatni uvjet – biraju se iz posebne familije, a ne posve slučajno.

1. Igra kao redukcija riječi u slobodnom produktu

Kao i u glavnom rješenju, redoslijed poteza nije bitan (konfluentnost pravila $xx \to \varepsilon$), pa je interval izbrisiv točno kad mu je normalna forma prazna. Promotrimo grupu $\Gamma = \langle x_0, x_1, x_2 \mid x_0^2 = x_1^2 = x_2^2 = 1 \rangle$, slobodni produkt triju kopija grupe $\mathbb{Z}_2$. Niz $s[l..r]$ preslikamo u element $x_{s_l} x_{s_{l+1}} \cdots x_{s_r} \in \Gamma$. Pravilo igre je upravo relacija $x_c x_c = 1$, pa izbrisiv interval daje jedinicu. Obratno, u slobodnom produktu svaki element ima jedinstvenu reduciranu riječ (bez dvaju jednakih susjednih generatora) i ta riječ je jedinica samo ako je prazna; normalna forma neizbrisivog intervala je neprazna reducirana riječ, dakle netrivijalan element. Pripadnost intervala je stoga točno odlučena time je li produkt u $\Gamma$ jednak $1$.

2. Vjerna slučajna reprezentacija matricama

Elemente grupe $\Gamma$ ne možemo čuvati eksplicitno, pa je „hashiramo” homomorfizmom u $GL_2(\mathbb{Z}_p)$, $p = 2^{61} - 1$: znaku $c$ pridružimo matricu $A_c$ s $A_c^2 = I$. Takve su matrice oblika $$A = \begin{pmatrix} a & b \\ c' & -a \end{pmatrix}, \qquad a^2 + b c' = 1,$$ jer je tada $A^2 = (a^2 + bc') I = I$ (Cayley–Hamilton: trag $0$, determinanta $-1$). Biramo slučajne $a$ i $b \ne 0$ i računamo $c' = (1 - a^2) b^{-1}$. Preslikavanje $x_c \mapsto A_c$ proširuje se do homomorfizma $\Gamma \to GL_2(\mathbb{Z}_p)$ upravo zato što su relacije $x_c^2 = 1$ zadovoljene. Izbrisiv interval sigurno daje $I$. Za neizbrisiv interval reducirana riječ $w$ duljine $L' \le r - l + 1$ ima naizmjenične različite generatore; elementi matrice $\prod_{i} A_{w_i} - I$ su polinomi stupnja $\le L'$ u slučajnim parametrima, a nisu identički nula jer postoje konkretne involucije (npr. zrcaljenja ravnine u tri pravca s racionalnim smjerovima) koje generiraju vjernu kopiju $\Gamma$ u $GL_2$. Schwartz–Zippelova lema daje vjerojatnost lažnog Yes najviše $L'/p \le 5 \cdot 10^5 / 2^{61} \approx 2 \cdot 10^{-13}$ po upitu, zanemarivo i za $5 \cdot 10^5$ upita.

Nekomutativnost je i ovdje nužna: komutativni hash ne razlikuje $0101$ (neizbrisiv) od $0011$ (izbrisiv).

3. Segmentno stablo s tri pomaka

Operacija $+1 \bmod 3$ na intervalu zamjenjuje $A_c$ s $A_{(c+1) \bmod 3}$. Kao u glavnom rješenju, u svakom čvoru čuvamo tri produkta $P_k = \prod A_{(s_i + k) \bmod 3}$, $k = 0, 1, 2$, i lijenu oznaku pomaka; pomak $d$ na čvoru samo rotira $P_k \leftarrow P_{(k + d) \bmod 3}$. Jedina razlika u odnosu na glavno rješenje je list: $P_k = A_{(s_i + k) \bmod 3}$ neovisno o paritetu pozicije $i$. Upit vraća produkt $P_0$ pokrivenih čvorova slijeva nadesno i odgovara Yes ako je jednak $I$.

4. Složenost i zamke

$O((n + q) \log n)$ množenja $2 \times 2$ matrica modulo $2^{61} - 1$ (uz __uint128_t), memorija $96$ bajta po čvoru. Zamke: množenje matrica nije komutativno (strogo lijevo pa desno); $b$ mora biti različit od nule da bi $b^{-1}$ postojao; sjeme generatora uzmi iz sata. Paritet pozicije ovdje se uopće ne koristi, pa je nemoguće pogriješiti s parnošću lijevog kraja upita – to je jedna od prednosti pristupa.

Provjera koda: uzorci 1/1; 300 slučajnih testova ($n, q \le 10$) protiv istog brute forcea sa stogom (stress.py stage17/D --sol sol_alt.cpp); 3 velika testa ($n = q = 5 \cdot 10^5$), najsporiji $0{,}86$ s.

KOD (C++) – 2. rješenjeklikni za prikaz izvornog koda 
// UCup 1, Stage 17, D - Flower's Land 2 (2. rješenje: involutorne matrice, bez pariteta)
// Brisanje susjednih jednakih znakova je redukcija riječi u grupi
// Z2 * Z2 * Z2 (slobodni produkt): svaki znak je involucija (x^2 = 1), a
// reducirana riječ je jedinstvena (sustav je konfluentan). Niz se može
// izbrisati točno kad je produkt jednak jedinici grupe. Grupu "hashiramo"
// slučajnim 2x2 matricama A_c s A_c^2 = I (npr. [[a,b],[c,-a]] s a^2+bc=1)
// modulo 2^61-1: izbrisiv niz uvijek daje I, a neizbrisiv daje I samo uz
// zanemarivu vjerojatnost.
// Operacija +1 mod 3 rotira znakove 0->1->2->0, pa u čvoru segmentnog stabla
// čuvamo produkt za sva tri pomaka; lijeni pomak samo rotira ta tri produkta.
#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;
const ull MOD = (1ULL << 61) - 1;

inline ull mulm(ull a, ull b) {
    __uint128_t c = (__uint128_t)a * b;
    ull r = (ull)(c & MOD) + (ull)(c >> 61);
    if (r >= MOD) r -= MOD;
    return r;
}
inline ull addm(ull a, ull b) { ull r = a + b; return r >= MOD ? r - MOD : r; }

struct Mat {
    ull a[4];  // [0 1; 2 3]
};
inline Mat mul(const Mat &x, const Mat &y) {
    Mat r;
    r.a[0] = addm(mulm(x.a[0], y.a[0]), mulm(x.a[1], y.a[2]));
    r.a[1] = addm(mulm(x.a[0], y.a[1]), mulm(x.a[1], y.a[3]));
    r.a[2] = addm(mulm(x.a[2], y.a[0]), mulm(x.a[3], y.a[2]));
    r.a[3] = addm(mulm(x.a[2], y.a[1]), mulm(x.a[3], y.a[3]));
    return r;
}
const Mat ID = {{1, 0, 0, 1}};
inline bool isId(const Mat &x) { return x.a[0] == 1 && x.a[1] == 0 && x.a[2] == 0 && x.a[3] == 1; }

ull pw(ull a, ull e) {
    ull r = 1;
    while (e) { if (e & 1) r = mulm(r, a); a = mulm(a, a); e >>= 1; }
    return r;
}

const int MAXN = 500005;
int n, q;
char s[MAXN];
Mat gen[3];                 // matrice znakova 0,1,2
Mat tr[1 << 20][3];         // tr[v][k] = produkt segmenta s pomakom k
unsigned char lz[1 << 20];  // lijeni pomak (0,1,2)

void build(int v, int l, int r) {
    lz[v] = 0;
    if (l == r) {
        int c = s[l] - '0';
        for (int k = 0; k < 3; k++) tr[v][k] = gen[(c + k) % 3];
        return;
    }
    int m = (l + r) / 2;
    build(2 * v, l, m);
    build(2 * v + 1, m + 1, r);
    for (int k = 0; k < 3; k++) tr[v][k] = mul(tr[2 * v][k], tr[2 * v + 1][k]);
}
inline void applyShift(int v, int d) {
    if (d == 0) return;
    // novi produkt s pomakom k = stari s pomakom k+d
    Mat t[3];
    for (int k = 0; k < 3; k++) t[k] = tr[v][(k + d) % 3];
    for (int k = 0; k < 3; k++) tr[v][k] = t[k];
    lz[v] = (lz[v] + d) % 3;
}
inline void push(int v) {
    if (lz[v]) { applyShift(2 * v, lz[v]); applyShift(2 * v + 1, lz[v]); lz[v] = 0; }
}
void update(int v, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) { applyShift(v, 1); return; }
    push(v);
    int m = (l + r) / 2;
    update(2 * v, l, m, ql, qr);
    update(2 * v + 1, m + 1, r, ql, qr);
    for (int k = 0; k < 3; k++) tr[v][k] = mul(tr[2 * v][k], tr[2 * v + 1][k]);
}
Mat query(int v, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[v][0];
    push(v);
    int m = (l + r) / 2;
    if (qr <= m) return query(2 * v, l, m, ql, qr);
    if (ql > m) return query(2 * v + 1, m + 1, r, ql, qr);
    return mul(query(2 * v, l, m, ql, qr), query(2 * v + 1, m + 1, r, ql, qr));
}

int main() {
    mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    for (int c = 0; c < 3; c++) {
        // A = [[a, b], [cc, -a]] s a^2 + b*cc = 1  =>  A^2 = I
        ull a = rng() % MOD, b = rng() % (MOD - 1) + 1;
        ull cc = mulm((1 + MOD - mulm(a, a)) % MOD, pw(b, MOD - 2));
        gen[c] = {{a, b, cc, (MOD - a) % MOD}};
    }
    scanf("%d %d", &n, &q);
    scanf("%s", s + 1);
    build(1, 1, n);
    string out;
    while (q--) {
        int t, l, r;
        scanf("%d %d %d", &t, &l, &r);
        if (t == 1) update(1, 1, n, l, r);
        else out += isId(query(1, 1, n, l, r)) ? "Yes\n" : "No\n";
    }
    fputs(out.c_str(), stdout);
    return 0;
}
