ZADATAK G: Recover the String

Rekonstrukcija niza — The 1st Universal Cup, Stage 17: Guangzhou (The 2022 CCPC Final (Guangzhou), May 20-21, 2023). Vremensko ograničenje: 8 s, memorijsko ograničenje: 1024 MiB.

Za niz $s$ malih slova zapisani su svi njegovi različiti podnizovi kao vrhovi; iz podniza $s_1$ ide usmjereni brid u $s_2$ ako je $s_2 = s_1 + c$ ili $s_2 = c + s_1$ za neko slovo $c$ (dvostruki bridovi uklonjeni). Nastaje DAG. Dan je samo taj DAG (bez oznaka vrhova); rekonstruiraj leksikografski najmanji mogući niz $s$.

Ulaz

$T \le 10^5$ testova; $n, m$ ($1 \le n \le 10^6$, $0 \le m \le 2 \cdot 10^6$) i $m$ bridova $u_i \to v_i$. Jamči se da rješenje postoji; $\sum n \le 10^6$, $\sum m \le 2 \cdot 10^6$.

Izlaz

Traženi niz.

Primjer

Za DAG s $5$ vrhova i bridovima $2 \to 4$, $2 \to 5$, $5 \to 3$, $4 \to 3$, $1 \to 5$, $1 \to 4$ odgovor je aba (vrhovi: a, b, ab, ba, aba). Za treći primjer iz zadatka ($8$ vrhova, $11$ bridova) odgovor je aaba.

NAPUTCI

Naputak 1klikni za prikaz

Vrhovi ulaznog stupnja $0$ su pojedinačna slova (koja ne možemo razlikovati — dodijeli ih proizvoljno), a jedini vrh izlaznog stupnja $0$ je cijeli niz. Duljine svih vrhova slijede iz toga topološkim obilaskom.

Naputak 2klikni za prikaz

Pokušaj dokazati: za svaki vrh $u$ postoji niz $S(u)$ takav da $u$ predstavlja $S(u)$ ili $\mathrm{rev}(S(u))$. Prethodnici od $u$ su $S(u)$ bez posljednjeg znaka i bez prvog znaka; ta dva prethodnika u pravilu imaju točno jednog zajedničkog prethodnika — iz njega se vidi kako se „lijepe”.

Naputak 3klikni za prikaz

Posebni slučajevi: jedan prethodnik → niz od jednog ponovljenog slova; dva prethodnika s istim skupom prethodnika → niz koji alternira dva slova (ne zna se kojim redom). Klasificiraj vrhove u tri tipa i za treći tip održavaj koji je prethodnik lijevi, a koji desni dio.

TRENERSKI NAČIN: logički put do rješenja

Logički put do rješenja: svaki je korak pitanje koje bi si iskusan natjecatelj postavio. Pokušaj na njega odgovoriti sam, pa tek onda otvori odgovor i usporedi – cilj je uvježbati način razmišljanja, a ne zapamtiti rješenje.

  1. Što o nizu znamo odmah iz oblika grafa, prije ikakvih oznaka?

    Vrhovi ulaznog stupnja $0$ su jedini podnizovi bez kraćeg podniza – pojedinačna slova. Koji je vrh koje slovo ne može se razlučiti (graf je isti za bilo koje imenovanje), pa slova dodijelimo proizvoljno. Jedini vrh izlaznog stupnja $0$ je cijeli niz, jer je svaki drugi podniz pravi podniz nekog duljeg. Bridovi vode iz duljine $\ell$ u duljinu $\ell + 1$, pa je duljina svakog vrha jednaka duljini najduljeg puta do njega plus $1$ – topološki obilazak.

  2. Koliko prethodnika vrh može imati i što ti prethodnici znače?

    Najviše dva: niz bez posljednjeg znaka, $L(S(u))$, i niz bez prvog znaka, $R(S(u))$. Ako bismo za svaki vrh znali koji je prethodnik lijevi, a koji desni, znali bismo prvi znak (prvi znak lijevog prethodnika) i zadnji znak (zadnji znak desnog), a cijeli niz pročitali bismo spuštajući se lancem lijevih prethodnika od ponora do slova. Dakle sve se svodi na orijentaciju svakog vrha – i ključno pitanje postaje koliko je ta orijentacija određena grafom.

  3. Zašto je niz svakog vrha određen do na obrat, tj. jednak $S(u)$ ili $\mathrm{rev}(S(u))$?

    Indukcijom po duljini. Prethodnici $v_1 = L(S(u))$ i $v_2 = R(S(u))$ preklapaju se u sredini $c = R(L(S(u))) = L(R(S(u)))$, a to je (u općem slučaju) njihov jedini zajednički prethodnik. Ako znamo $v_1$ i $v_2$ do na obrat i znamo preko kojeg se prethodnika lijepe, dobivamo $S(u)$ do na obrat. Posebni slučajevi kad zajednički prethodnik nije jedinstven upravo su vrhovi u kojima nastaju dodatne simetrije.

  4. Koji su to posebni slučajevi i kako ih prepoznati iz grafa?

    Tip 1: $|G(u)| = 1$, tj. $L(S(u)) = R(S(u))$; to znači $s_i = s_{i+1}$ za sve $i$ – niz od jednog slova. Tip 2: $G(u) = \{v_1, v_2\}$ i $G(v_1) = G(v_2)$; kako je $R(v_1) = L(v_2)$ uvijek, dodatno slijedi $L(v_1) = R(v_2)$, tj. $s_i = s_{i+2}$ – niz alternira dva različita slova, a graf ne kaže kojim redom ($S(u)$ ili $\mathrm{flip}(S(u))$). Nizove duljine $2$ s dva različita slova također tretiramo kao tip 2 (oba prethodnika su slova s praznim skupom prethodnika). Tip 3: svi ostali – tada $v_1$ i $v_2$ imaju točno jednog zajedničkog prethodnika, sredinu $c$.

  5. Kako iz tipova dobiti orijentacije svih vrhova u linearnom vremenu?

    Za vrh tipa 3 uvjet „$c$ je desni prethodnik od $L(u)$ i lijevi prethodnik od $R(u)$” povezuje orijentaciju vrha $u$ s orijentacijama njegovih prethodnika: koji god prethodnik proglasimo lijevim, njemu $c$ mora biti desni prethodnik, a drugome lijevi. To je jednadžba oblika $\mathrm{ori}(v) \oplus \mathrm{ori}(u) = \text{konst}$. Za vrh tipa 2 uvjet $R(v_1) = L(v_2)$ povezuje orijentacije $v_1$ i $v_2$, dok je orijentacija samog $u$ slobodna (to je upravo $\mathrm{flip}$). Sve jednadžbe skupimo u DSU s paritetom (službeno rješenje isti podatak – „koja je strana alternirajuća i kako” – prosljeđuje odozgo prema dolje); rješenje postoji, pa je sustav konzistentan, a svaka komponenta dobiva proizvoljnu orijentaciju korijena. Preostale slobode su točno obrat i $\mathrm{flip}$, koje preimenovanje slova po prvom pojavljivanju svodi na dva kandidata: $S$ i $\mathrm{rev}(S)$. Uzmemo manjega; ukupno $O(n + m)$.

Opći savjeti i prečaci

  • Kad su vrhovi grafa neoznačeni, prvo pronađi invarijante koje graf ipak određuje (stupnjevi, duljine najduljih puteva, presjeci skupova susjeda) i iz njih klasificiraj vrhove.
  • Ako je struktura određena „do na simetriju” (obrat, zamjena slova), ne pokušavaj je odrediti apsolutno – rješavaj relativne uvjete (paritete) i simetrije ukloni tek na kraju kanonizacijom.
  • Uvjete oblika $x_a \oplus x_b = \delta$ na milijun varijabli rješava DSU s paritetom u gotovo linearnom vremenu; ako netko jamči postojanje rješenja, provjere konzistentnosti služe samo kao assert.
RJEŠENJEklikni za prikaz cijelog rješenja

Savjet: prije čitanja rješenja prođi kroz korake trenerskog načina iznad.

Radi jednostavnosti u nastavku ponekad ne razlikujemo „vrh” i „niz koji vrh predstavlja” — npr. „duljina vrha” znači „duljina niza koji vrh predstavlja”.

Najprije, vrhovi ulaznog stupnja $0$ sigurno predstavljaju pojedinačna slova, ali se ne može razlučiti koje slovo predstavlja koji vrh, pa im slova dodijelimo proizvoljno. Zatim iz tih vrhova izvedemo duljinu svakog drugog vrha, uključujući duljinu izvornog niza (izvorni niz je jedini vrh izlaznog stupnja $0$).

Jednostavnom simulacijom može se naslutiti da je niz koji vrh predstavlja „prilično jedinstven”. Formalno: za svaki vrh $u$ postoji niz $S(u)$ takav da je niz koji $u$ stvarno predstavlja jednak $S(u)$ ili $\mathrm{rev}(S(u))$, gdje $\mathrm{rev}(s)$ označava obrnuti niz. Dokažimo tu tvrdnju induktivno.

Ulazni stupanj svakog vrha je najviše $2$: prethodnici su nizovi $S(u)$ bez posljednjeg odnosno bez prvog znaka. Neka $L(s)$ označava $s$ bez posljednjeg znaka, $R(s)$ niz $s$ bez prvog znaka, a $G(u)$ skup prethodnika vrha $u$.

U općem slučaju je $|G(u)| = 2$, a dva prethodnika imaju točno jednog zajedničkog prethodnika.

Analizirajmo najprije posebne slučajeve koji ne zadovoljavaju to svojstvo.

  • Ako je $|G(u)| = 1$, tada je $L(S(u)) = R(S(u))$, tj. $S(u)$ se sastoji od jednog jedinog slova, koje možemo odrediti. Takve vrhove zovemo vrhovima prvog tipa. Prethodnici vrha prvog tipa također su prvog tipa.
  • Ako je $G(u) = \{v_1, v_2\}$, ali $G(v_1) = G(v_2)$, tada $S(u)$ nužno nastaje alterniranjem dvaju različitih slova. Ta dva slova možemo odrediti, ali ih samo pomoću vrhova iz kojih se može doći do $u$ ne možemo razlikovati. Niz takvog vrha je $S(u)$ ili $\mathrm{flip}(S(u))$, gdje $\mathrm{flip}(s)$ zamjenjuje dva slova u $s$. Pozor: ako je $|S(u)|$ neparan, tada je $\mathrm{rev}(S(u)) \ne \mathrm{flip}(S(u))$. Takve vrhove zovemo vrhovima drugog tipa; njihovi prethodnici također su drugog tipa. Posebno, pojedinačna slova smatramo prvim tipom, a nizove duljine $2$ drugim tipom.
  • Ostale vrhove zovemo vrhovima trećeg tipa; njihov niz ima oblik $S(u)$ ili $\mathrm{rev}(S(u))$.

Za vrhove trećeg tipa, osim $S(u)$, održavamo i koji dio od $S(u)$ predstavlja koji prethodnik. Formalno, za $v \in G(u)$ održavamo informaciju oblika: „[$S(v)$ ili $\mathrm{rev}(S(v))$] predstavlja [$L(u)$ ili $R(u)$]”.

Za vrh $u$ trećeg tipa neka je $G(u) = \{v_1, v_2\}$.

  • Slučaj 1: ni $v_1$ ni $v_2$ nisu drugog tipa. Tada informaciju za $u$ izračunamo pomoću zajedničkog prethodnika skupova $G(v_1)$ i $G(v_2)$.
  • Slučaj 2: inače je točno jedan od $v_1, v_2$ drugog tipa; neka je to $v_1$. Tada je $v_2$ trećeg tipa i točno jedan od $L(S(v_2))$, $R(S(v_2))$ je alternirajući niz koji se može uskladiti sa $S(v_1)$. Ako je $|S(v_2)| \gt 3$, točno jedan od $L(v_2)$, $R(v_2)$ je alternirajući, pa je i $v_2$ sam u obliku slučaja 2 — možemo održavati koja je strana od $v_2$ alternirajuća i kako alternira. Ako je $|S(v_2)| = 3$, izravno pamtimo niz koji $v_2$ predstavlja i provjeravamo grubom silom.

Tako je dovoljno održavati $O(n)$ informacija. Na kraju dobivamo dva moguća kandidata za izvorni niz; u svakom preimenujemo slova tako da niz bude leksikografski najmanji i uzmemo manji od dvaju. Ukupna složenost je $O(n)$.

DETALJNO RJEŠENJE

1. Što graf otkriva bez oznaka

Vrhovi su svi različiti podnizovi nepoznatog niza $s$, a brid $x \to y$ postoji kad je $y$ dobiven dodavanjem jednog znaka na početak ili kraj niza $x$. Odmah slijedi:

  • bridovi vode iz podniza duljine $\ell$ u podniz duljine $\ell + 1$, pa je graf acikličan i duljina vrha jednaka je duljini najduljeg puta do njega uvećanoj za $1$ – izračunamo je topološkim obilaskom (Kahnov algoritam);
  • vrhovi ulaznog stupnja $0$ su podnizovi duljine $1$, tj. pojedinačna slova. Graf ne razlikuje koji je vrh koje slovo (bilo koja permutacija imena slova daje isti graf), pa slova dodijelimo proizvoljno: a, b, … redom otkrivanja;
  • točno jedan vrh ima izlazni stupanj $0$ – sam niz $s$, jer je svaki drugi podniz pravi podniz nekog duljeg podniza.

Radi kratkoće ne razlikujemo vrh i niz koji predstavlja. Za niz $t$ neka je $L(t)$ niz bez posljednjeg znaka, $R(t)$ niz bez prvog znaka, a $G(u)$ skup prethodnika vrha $u$. Prethodnici vrha $u$ su upravo $L(u)$ i $R(u)$, dakle ulazni stupanj je najviše 2, a jednak je $1$ točno kad je $L(u) = R(u)$.

2. Sve se svodi na orijentaciju

Zamislimo da za svaki vrh $u$ ulaznog stupnja $2$ znamo koji je od dvaju prethodnika $L(u)$, a koji $R(u)$ – tu informaciju zovemo orijentacijom $\mathrm{ori}(u) \in \{0, 1\}$. Tada je sve određeno: prvi znak vrha jednak je prvom znaku od $L(u)$, posljednji znak posljednjem znaku od $R(u)$, a cijeli niz $s$ pročitamo spuštajući se od ponora lancem $u, L(u), L(L(u)), \dots$ do slova: $k$-ti znak od kraja jest posljednji znak $k$-tog vrha na tom lancu. Zato je pravo pitanje: koliko je orijentacija određena grafom i kako je izračunati.

3. Ključna tvrdnja: niz vrha je određen do na obrat

Tvrdnja. Za svaki vrh $u$ postoji niz $S(u)$ takav da je niz koji $u$ predstavlja jednak $S(u)$ ili $\mathrm{rev}(S(u))$; u posebnom slučaju alternirajućih nizova dodatno se pojavljuje i zamjena dvaju slova $\mathrm{flip}$.

Dokaz (indukcija po duljini). Za slova je tvrdnja trivijalna. Neka je $|G(u)| = 2$, $G(u) = \{v_1, v_2\}$, i neka je $v_1 = L(u)$, $v_2 = R(u)$. Nizovi $v_1$ i $v_2$ preklapaju se u sredini $c = R(v_1) = L(v_2)$ (niz $u$ bez oba kraja), koja je zajednički prethodnik od $v_1$ i $v_2$. Ako je $c$ njihov jedini zajednički prethodnik, tada iz $S(v_1)$, $S(v_2)$ (poznatih do na obrat) i podatka da se lijepe upravo preko $c$ jednoznačno slijedi $S(u)$ do na obrat: ako je $c$ desni prethodnik od $v_1$, onda je $v_1$ lijevi dio; ako je lijevi, onda je $v_1$ desni dio, a to je zrcalna slika iste situacije. Ostaje razmotriti kad $c$ nije jedini zajednički prethodnik. $\square$

4. Tri tipa vrhova

Tip 1: $|G(u)| = 1$. Tada je $L(u) = R(u)$, tj. $u_i = u_{i+1}$ za sve $i$ – niz se sastoji od jednog ponovljenog slova. Orijentacija je nebitna (prethodnik je i lijevi i desni), a prethodnici vrha tipa 1 opet su tipa 1.

Tip 2: $G(u) = \{v_1, v_2\}$ i $G(v_1) = G(v_2)$. Uvijek je $R(v_1) = L(v_2) = c$; jednakost skupova prethodnika povlači još i $L(v_1) = R(v_2)$, tj. $u_i = u_{i+2}$ za sve $i$. Niz je dakle periodičan s periodom $2$, a kako nije tipa 1, alternira dva različita slova. Koja su to slova vidimo (izvori do kojih vodi lanac), ali graf ne kaže kojim redom: nizovi $S(u)$ i $\mathrm{flip}(S(u))$ (zamjena dvaju slova) daju isti graf. Napomena: za neparnu duljinu $\mathrm{rev}(S(u)) = S(u) \ne \mathrm{flip}(S(u))$, pa je to zaista nova simetrija. Nizove duljine $2$ s dva različita slova ubrajamo u tip 2 (oba prethodnika su slova s praznim skupom prethodnika, dakle jednakim). Uvjet tipa 2 iz grafa se prepoznaje tako da $v_1$ i $v_2$ imaju dva zajednička prethodnika (ili nijednoga, u slučaju duljine $2$).

Tip 3: svi ostali. Tada $v_1$ i $v_2$ imaju točno jednog zajedničkog prethodnika – sredinu $c$. Naime, zajednički prethodnik je ili $R(v_1) = L(v_2) = c$ ili bi morao biti $L(v_1) = R(v_2)$, a to je upravo uvjet tipa 2. Za vrh tipa 3 tvrdnja iz odjeljka 3 daje niz do na obrat; posebno, orijentacija vrha $u$ određuje orijentacije prethodnika.

5. Uvjeti na orijentacije su jednadžbe pariteta

Pogledajmo što točno „lijepljenje preko $c$” govori o orijentacijama. Neka je $u$ tipa 3 s prethodnicima $p_0, p_1$ i sredinom $c$.

  • Ako je $p_0 = L(u)$, onda je $c = R(p_0)$ i $c = L(p_1)$;
  • ako je $p_0 = R(u)$, onda je $c = L(p_0)$ i $c = R(p_1)$.

Dakle za svaki prethodnik $p$ ulaznog stupnja $2$ vrijedi $\mathrm{ori}(p) \oplus \mathrm{ori}(u) = \delta$, gdje $\delta \in \{0,1\}$ ovisi samo o tome na kojem se mjestu u popisu prethodnika od $p$ nalazi $c$. Prethodnik ulaznog stupnja $1$ (tip 1) ne daje uvjet. Za vrh $u$ tipa 2 s prethodnicima $v_1, v_2$ i $G(v_1) = G(v_2) = \{x, y\}$ uvjet je $R(v_1) = L(v_2)$ (ekvivalentno $L(v_1) = R(v_2)$), što je opet jednadžba $\mathrm{ori}(v_1) \oplus \mathrm{ori}(v_2) = \delta$, dok je $\mathrm{ori}(u)$ slobodna: oba izbora daju alternirajući niz, jedan je $\mathrm{flip}$ drugoga. Vrhovi duljine $2$ ne daju nikakav uvjet.

Sve jednadžbe skupimo u DSU s paritetom (svaki element pamti paritet prema roditelju; unija dvaju elemenata s traženim paritetom u $\alpha(n)$). Budući da rješenje postoji, sustav je konzistentan. Na kraju u svakoj komponenti korijen dobije orijentaciju $0$, a ostali paritet prema korijenu.

Zašto je bilo koje konzistentno rješenje ispravno? Neka $\mathrm{str}(u)$ označava niz koji vrh dobiva iz odabranih orijentacija, $\mathrm{str}(u) = \mathrm{str}(L(u)) + \mathrm{last}(R(u))$. Treba provjeriti da je ujedno $\mathrm{str}(u) = \mathrm{first}(L(u)) + \mathrm{str}(R(u))$, tj. $R(\mathrm{str}(L(u))) = L(\mathrm{str}(R(u)))$, jer tada svaki vrh zaista ima za prethodnike točno svoje $L$ i $R$ i svi su nizovi podnizovi ponora. Za tip 3 obje strane jednake su $\mathrm{str}(c)$ – to je upravo naša jednadžba. Za tip 2 s $L(u) = v_1$, $R(u) = v_2$, $R(v_1) = L(v_2) = z$ i $L(v_1) = R(v_2) = w$ imamo $R(\mathrm{str}(v_1)) + \mathrm{last}(v_2) = \mathrm{str}(z) + \mathrm{last}(v_2) = \mathrm{str}(v_2)$ i $\mathrm{first}(v_2) + L(\mathrm{str}(v_1)) = \mathrm{first}(v_2) + \mathrm{str}(w) = \mathrm{str}(v_2)$, pa se slažu (isti račun vrijedi i za suprotni izbor $\mathrm{ori}(u)$). Za tip 1 nema što provjeravati. Indukcijom po duljini svi vrhovi dobivaju međusobno usklađene nizove, a po tvrdnji iz odjeljka 3 ti se nizovi od pravih razlikuju samo za obrat i $\mathrm{flip}$ alternirajućih dijelova.

6. Odgovor

Pročitamo niz ponora duž lanca lijevih prethodnika (odjeljak 2). Slobode koje graf ne određuje su: imena slova, globalni obrat i $\mathrm{flip}$ alternirajućih dijelova. Preimenovanje slova po redoslijedu prvog pojavljivanja ($\mathrm{canon}$) uklanja imena i, budući da je $\mathrm{flip}$ zamjena dvaju imena, i $\mathrm{flip}$; obrat ne uklanja. Zato su kandidati $\mathrm{canon}(S)$ i $\mathrm{canon}(\mathrm{rev}(S))$ i odgovor je leksikografski manji od njih. Primjer: za $s = $ aaba kandidati su aaba i $\mathrm{canon}($abaa$) = $ abaa; odgovor aaba.

7. Algoritam i složenost

  1. Učitaj bridove; za svaki vrh spremi do dva prethodnika i izgradi CSR popis sljedbenika.
  2. Kahnov topološki poredak; izvori dobivaju slova redom.
  3. Za svaki vrh $u$ ulaznog stupnja $2$ prebroji zajedničke prethodnike njegovih dvaju prethodnika (najviše $2 \times 2$ usporedbe): jedan → tip 3, dodaj jednadžbu za svaki prethodnik ulaznog stupnja $2$; dva → tip 2, dodaj jednadžbu između prethodnika; nijedan → duljina $2$, ništa.
  4. Riješi DSU s paritetom, očitaj $\mathrm{ori}$, zatim u topološkom poretku prvi i zadnji znak svakog vrha.
  5. Pročitaj niz ponora, izračunaj oba kandidata i ispiši manji.

Svaki korak je linearan u $n + m$ (uz $\alpha(n)$ za DSU), memorija $O(n + m)$. Duljina niza jednaka je duljini lanca lijevih prethodnika, najviše $n$, a broj slova je broj izvora (najviše $26$).

8. Zamke

  • Do $10^5$ testova: inicijaliziraj samo prvih $n$ polja, ne cijele nizove maksimalne veličine.
  • Ulaz do $3 \cdot 10^6$ brojeva – brzo čitanje (fread) i skupljanje izlaza u jedan buffer.
  • Tip 2 duljine $2$ (ab) ima $|G(v_1) \cap G(v_2)| = 0$, a ne $2$: taj slučaj ne smije ući u granu tipa 3.
  • Prethodnik ulaznog stupnja $1$ (tip 1) nema orijentaciju – ne stvaraj jednadžbu za njega, ali zajednički prethodnik i dalje računaj (npr. aab: $G($aa$) = \{$a$\}$, $G($ab$) = \{$a, b$\}$).
  • DSU s paritetom: pri kompresiji puta paritet se akumulira duž puta (iterativno, bez rekurzije – lanci mogu biti duljine $10^6$).
  • Kandidate uspoređuj tek nakon kanonskog preimenovanja; rev nakon preimenovanja obično mijenja imena slova.

Provjera koda: uzorci 1/1; 300 slučajnih malih testova (nizovi duljine $\le 8$ nad $\le 3$ slova, uključujući alternirajuće i jednoslovne blokove, 1–3 testa po ulazu) protiv brute forcea koji isprobava sve kanonske nizove i uspoređuje DAG-ove podnizova provjerom izomorfizma; dodatno iscrpna provjera svih kanonskih nizova duljine $\le 9$ nad $\le 3$ slova i duljine $\le 7$ nad $4$ slova te 600 slučajnih nizova duljine $10$–$12$ (ukupno 7151 nizova, sve točno); 3 velika testa ($n \approx 10^6$: alternirajući niz duljine $330\,000$ + jedno slovo, $20\,000$ malih testova, slučajan binarni niz duljine $1000$ i jednoslovni niz duljine $400\,000$), najsporiji $0{,}26$ s.

// UCup 1, Stage 17, G - Recover the String
// Vrhovi ulaznog stupnja 0 su pojedinačna slova (dodijelimo ih proizvoljno),
// jedini vrh izlaznog stupnja 0 je cijeli niz; duljine slijede topološki.
// Svaki vrh u ima najviše dva prethodnika: L(u) (bez zadnjeg znaka) i R(u)
// (bez prvog znaka). Tvrdnja iz službenog rješenja: niz vrha je određen do na
// obrat, S(u) ili rev(S(u)); jedino što treba znati jest ORIJENTACIJA – koji
// je prethodnik L(u), a koji R(u). Tri tipa vrhova:
//  * tip 1: jedan prethodnik  -> niz od jednog slova, orijentacija nebitna;
//  * tip 2: dva prethodnika s istim skupom prethodnika -> alternirajući niz;
//    slova su međusobno zamjenjiva (S(u) ili flip(S(u)));
//  * tip 3: ostali; L(u) i R(u) imaju točno jednog zajedničkog prethodnika
//    c = sredina niza, i vrijedi R(L(u)) = c = L(R(u)).
// Uvjet "R(L(u)) = L(R(u))" je uvjet PARITETA između orijentacija vrhova, pa
// sve uvjete skupljamo u DSU s paritetom (umjesto eksplicitnog čuvanja S(u),
// što bi bilo prekvadratno). Kod tipa 3 orijentacija je time određena do na
// globalni obrat; kod tipa 2 svaka dosljedna orijentacija daje isti niz do
// na flip. Iz orijentacije čitamo prvi/zadnji znak svakog vrha, a niz se
// čita duž lanca L(korijen), L(L(korijen)), ... Dva kandidata (S i rev S)
// preimenujemo po redoslijedu prvog pojavljivanja i uzmemo manjega. O(n+m).
#include <bits/stdc++.h>
using namespace std;

static char buf[1 << 25];
int bufpos = 0, buflen = 0;
inline int gc() {
    if (bufpos == buflen) { buflen = fread(buf, 1, sizeof(buf), stdin); bufpos = 0; if (buflen <= 0) return -1; }
    return buf[bufpos++];
}
inline int readInt() {
    int c = gc();
    while (c != '-' && (c < '0' || c > '9')) c = gc();
    int x = 0;
    while (c >= '0' && c <= '9') { x = x * 10 + (c - '0'); c = gc(); }
    return x;
}

const int MAXN = 1000005, MAXM = 2000005;
int n, m;
int eu[MAXM], ev[MAXM];
int indeg[MAXN], outdeg[MAXN], pred[MAXN][2];
int adjStart[MAXN], adjList[MAXM];  // sljedbenici (CSR)
int order_[MAXN];                    // topološki poredak
int dsuP[MAXN], dsuX[MAXN];          // DSU s paritetom: dsuX = paritet prema roditelju
int ori[MAXN];                       // 1 = pred[u][0] je L(u), 0 = pred[u][1] je L(u)
int firstC[MAXN], lastC[MAXN];

int findp(int x, int &par) {
    // iterativno nalaženje korijena s kompresijom puta i paritetom
    int r = x, p = 0;
    while (dsuP[r] != r) { p ^= dsuX[r]; r = dsuP[r]; }
    // kompresija
    int cur = x, cp = p;
    while (dsuP[cur] != r) {
        int nxt = dsuP[cur], nx = dsuX[cur];
        dsuP[cur] = r; dsuX[cur] = cp;
        cp ^= nx; cur = nxt;
    }
    par = p;
    return r;
}
// uvjet ori[a] xor ori[b] = d
void unite(int a, int b, int d) {
    int pa, pb;
    int ra = findp(a, pa), rb = findp(b, pb);
    if (ra == rb) { assert((pa ^ pb) == d); return; }
    dsuP[ra] = rb;
    dsuX[ra] = pa ^ pb ^ d;
}

inline int Lp(int u) { return indeg[u] == 1 ? pred[u][0] : (ori[u] ? pred[u][0] : pred[u][1]); }
inline int Rp(int u) { return indeg[u] == 1 ? pred[u][0] : (ori[u] ? pred[u][1] : pred[u][0]); }

string canon(const string &s) {
    int mp[26];
    memset(mp, -1, sizeof mp);
    int nxt = 0;
    string r = s;
    for (char &ch : r) {
        int c = ch - 'a';
        if (mp[c] < 0) mp[c] = nxt++;
        ch = 'a' + mp[c];
    }
    return r;
}

string out;

void solve() {
    n = readInt(); m = readInt();
    for (int i = 1; i <= n; i++) { indeg[i] = outdeg[i] = 0; dsuP[i] = i; dsuX[i] = 0; ori[i] = 0; }
    for (int i = 0; i < m; i++) {
        eu[i] = readInt(); ev[i] = readInt();
        outdeg[eu[i]]++;
        pred[ev[i]][indeg[ev[i]]++] = eu[i];
    }
    // CSR sljedbenika
    adjStart[1] = 0;
    for (int i = 1; i <= n; i++) adjStart[i + 1] = adjStart[i] + outdeg[i];
    {
        static int fillp[MAXN];
        for (int i = 1; i <= n; i++) fillp[i] = adjStart[i];
        for (int i = 0; i < m; i++) adjList[fillp[eu[i]]++] = ev[i];
    }
    // topološki poredak (Kahn); izvori dobivaju slova a, b, c, ...
    int qh = 0, qt = 0, letters = 0, sink = -1;
    static int rem[MAXN];
    for (int i = 1; i <= n; i++) {
        rem[i] = indeg[i];
        if (indeg[i] == 0) { order_[qt++] = i; firstC[i] = lastC[i] = letters++; }
        if (outdeg[i] == 0) sink = i;
    }
    while (qh < qt) {
        int u = order_[qh++];
        for (int e = adjStart[u]; e < adjStart[u + 1]; e++) {
            int v = adjList[e];
            if (--rem[v] == 0) order_[qt++] = v;
        }
    }
    // uvjeti pariteta
    for (int idx = 0; idx < n; idx++) {
        int u = order_[idx];
        if (indeg[u] != 2) continue;
        int p0 = pred[u][0], p1 = pred[u][1];
        // zajednički prethodnici od p0 i p1
        int common = 0, c = -1;
        for (int a = 0; a < indeg[p0]; a++)
            for (int b = 0; b < indeg[p1]; b++)
                if (pred[p0][a] == pred[p1][b]) { common++; c = pred[p0][a]; }
        if (common == 1) {
            // tip 3: c = R(L(u)) = L(R(u)).
            // ako je p0 = L(u): c je R-prethodnik od p0 i L-prethodnik od p1
            if (indeg[p0] == 2) unite(p0, u, pred[p0][0] == c ? 1 : 0);
            if (indeg[p1] == 2) unite(p1, u, pred[p1][0] == c ? 0 : 1);
        } else if (common == 2) {
            // tip 2: R(p0) = L(p1)  (ekvivalentno L(p0) = R(p1)), neovisno o ori[u]
            int e = (pred[p0][0] == pred[p1][0]) ? 1 : 0;
            unite(p0, p1, e);
        }
        // common == 0: duljina 2, dva različita slova – bez uvjeta
    }
    // orijentacija: korijeni komponenata dobivaju 0
    for (int i = 1; i <= n; i++)
        if (indeg[i] == 2) { int p; findp(i, p); ori[i] = p; }
    // prvi i zadnji znak svakog vrha
    for (int idx = 0; idx < n; idx++) {
        int u = order_[idx];
        if (indeg[u] == 0) continue;
        firstC[u] = firstC[Lp(u)];
        lastC[u] = lastC[Rp(u)];
    }
    // niz duž lanca L-prethodnika od korijena
    int len = 0;
    for (int u = sink; ; u = Lp(u)) { len++; if (indeg[u] == 0) break; }
    string s(len, 'a');
    {
        int u = sink;
        for (int k = len - 1; k >= 0; k--) { s[k] = 'a' + lastC[u]; if (k) u = Lp(u); }
    }
    string a = canon(s);
    reverse(s.begin(), s.end());
    string b = canon(s);
    out += min(a, b);
    out += '\n';
}

int main() {
    int T = readInt();
    while (T--) solve();
    fwrite(out.data(), 1, out.size(), stdout);
    return 0;
}
