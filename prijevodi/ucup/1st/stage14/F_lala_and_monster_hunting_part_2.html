ZADATAK F: LaLa and Monster Hunting (Part 2)

LaLa i lov na čudovište (2. dio) — The 1st Universal Cup, Stage 14: Ranoa (Osijek Competitive Programming Camp Winter 2023, Day 9: Magical Story of LaLa). Vremensko ograničenje: 6 s, memorijsko ograničenje: 1024 MB.

Čudovište je graf $G$ sa $6$ vrhova prikazan u izvorniku: trokut s pridruženim „repom” — putem duljine $3$ (ukupno $6$ bridova). Mreža grana je jednostavan graf $H$. Prebroji, modulo $998244353$, podgrafe grafa $H$ izomorfne grafu $G$ (podgraf: izbriši neke bridove, zatim izolirane vrhove).

Ulaz

$N, M$ ($2 \le N \le 10^5$, $0 \le M \le 10^5$) i $M$ bridova $u_i < v_i$, bez ponavljanja. Graf nije nužno povezan.

Izlaz

Broj kandidata modulo $998244353$.

Primjer

Dva trokuta $\{0,1,2\}$, $\{3,4,5\}$ spojena bridom $(2,3)$: odgovor $4$. Za $K_6$ odgovor je $360$.

NAPUTCI

Naputak 1klikni za prikaz

Trokute kroz svaki vrh i kroz svaki brid prebroji u $O(M\sqrt{M})$ (orijentacija bridova po stupnju). Zatim rep gradi vrh po vrh: neka je $L_k(u)$ broj parova (trokut s istaknutim vrhom $c$, jednostavan rep duljine $k$ iz $c$ koji završava u $u$ i ne dira trokut). Odgovor je $\sum_u L_3(u)$.

Naputak 2klikni za prikaz

Prijelaz $L_k(u) = \sum_{v \sim u} L_{k-1}(v)$ broji i „loše” repove u kojima se $u$ vraća u trokut ili u sam rep. Za $k \le 3$ svaki je loši slučaj mali podgraf: trokut kroz vrh ili brid, „kvadrat s dijagonalom” ($4$ vrha, $5$ bridova) ili „kuća” ($4$-ciklus s krovnim vrhom, $5$ vrhova, $6$ bridova).

Naputak 3klikni za prikaz

Kvadrate s dijagonalom broji po usmjerenom bridu drugim prolaskom po trokutima; kuće preko težinskih $4$-ciklusa (svaki $4$-ciklus nabroji iz vrha najvećeg ranga, težina brida je broj trokuta na njemu) uz odbijanje dvaju degeneriranih slučajeva koji su sami kvadrati s dijagonalom. Sve staje u $O(M\sqrt{M})$.

TRENERSKI NAČIN: logički put do rješenja

Logički put do rješenja: svaki je korak pitanje koje bi si iskusan natjecatelj postavio. Pokušaj na njega odgovoriti sam, pa tek onda otvori odgovor i usporedi – cilj je uvježbati način razmišljanja, a ne zapamtiti rješenje.

  1. Što jednoznačno određuje jednu kopiju čudovišta i zašto ništa ne dijelimo brojem automorfizama?

    $G$ je trokut $\{a, b, c\}$ s repom $c - d - e - f$. Podgraf $S \subseteq H$ izomorfan $G$ ima točno jedan trokut $T$, točno jedan vrh trokuta stupnja $3$ u $S$ (to je $c$) i točno jedan jednostavan put duljine $3$ iz $c$ izvan trokuta, koji čitamo od $c$: $(d, e, f)$. Jedini netrivijalni automorfizam $G$ je zamjena $a \leftrightarrow b$, a ona ne mijenja ni $T$, ni $c$, ni $(d, e, f)$. Zato je broj kopija jednak broju četvorki $(T, c, (d, e, f))$ s $c \in T$, $c \sim d \sim e \sim f$, $d, e, f$ različiti i izvan $T$ — svaka kopija broji se točno jednom. Provjera: u $K_6$ ima $\binom63 = 20$ trokuta, $3$ izbora $c$ i $3! = 6$ repova, ukupno $360$, kao u primjeru.

  2. Kako organizirati brojanje tako da nikad ne gledamo cijelu šestorku odjednom?

    Rep gradimo po duljini, kao dinamičko programiranje po zadnjem vrhu repa. Neka je $L_k(u)$ broj parova (trokut $T$ s istaknutim vrhom $c$, jednostavan put $c = v_0, v_1, \dots, v_k = u$ s $v_1, \dots, v_k \notin T$). Tada je $L_0$ „trokuti s istaknutim vrhom”, tj. $L_0(c) = \mathrm{tri}(c)$, a odgovor je $\sum_u L_3(u)$. Naivni prijelaz $\sum_{v \sim u} L_{k-1}(v)$ produlji svaki dobar rep duljine $k-1$ za jedan brid, ali među produljenjima su i ona u kojima novi vrh $u$ pada u $T$ ili se podudara s nekim ranijim vrhom repa. Ključ je da za $k \le 3$ svih takvih „loših” konfiguracija ima samo nekoliko tipova i svaka je mali podgraf koji se broji lokalno: upravo to su veličine koje službeno rješenje računa redom.

  3. Koje loše konfiguracije nastaju pri produljenju s $1$ na $2$ i kako ih izraziti lokalnim veličinama?

    $L_1(u) = \sum_{c \sim u} \bigl(\mathrm{tri}(c) - \mathrm{tri}(cu)\bigr)$: trokuti kroz $c$ koji ne sadrže $u$ — trokuti kroz brid $cu$ točno su oni trokuti kroz $c$ koji sadrže $u$. U $L_2(u) = \sum_{d \sim u} L_1(d) - (\ldots)$ novi vrh $e = u$ ne može biti $d$ (graf nema petlji), pa su loši slučajevi: (i) $u = c$: par $(T \ni u, d)$ s $d \sim u$, $d \notin T$, ukupno $\sum_{d \sim u} (\mathrm{tri}(u) - \mathrm{tri}(ud)) = (\deg u - 2)\,\mathrm{tri}(u)$; (ii) $u \in T \setminus \{c\}$: $T = \{u, c, z\}$ i $d$ je zajednički susjed od $u$ i $c$ različit od $z$ — po trokutu $\{u, c, z\}$ ima ih $\mathrm{tri}(uc) - 1$. Ta je veličina broj „kvadrata s dijagonalom”: dva trokuta $\{x, y, z\}$, $\{y, z, w\}$ sa zajedničkim bridom $yz$ (4 vrha, 5 bridova). Definiramo $D(x \to y) = \sum_{z : \{x,y,z\} \text{ trokut}} (\mathrm{tri}(yz) - 1)$ — broj takvih kvadrata u kojima je $x$ vrh izvan dijagonale, a $y$ njegov susjed na dijagonali; slučaj (ii) je onda $\sum_{z \sim u} D(z \to u)$. $D$ se računa drugim prolaskom po svim trokutima nakon što su poznati $\mathrm{tri}$ po bridu.

  4. Što se dodatno događa pri produljenju s $2$ na $3$ i odakle „kuća”?

    $L_3(u) = \sum_{e \sim u} L_2(e) - B_c(u) - B_d(u) - B_T(u)$. (i) $u = c$: $d, e \notin T$ i $\{u, d, e\}$ je trokut, pa za svaki trokut $\{u, d, e\}$ brojimo trokute $T \ni u$ koji ne sadrže ni $d$ ni $e$: $\mathrm{tri}(u) - \mathrm{tri}(ud) - \mathrm{tri}(ue) + 1$, puta $2$ za poredak $(d, e)$. (ii) $u = d$: rep $c, u, e, u$ — $e$ je susjed od $u$ izvan $T$; zbroj po $(T, c)$ s $c \sim u$, $u \notin T$ daje $(\deg u - 1) L_1(u)$ minus broj slučajeva u kojima je $e$-kandidat neki drugi vrh trokuta susjedan s $u$: $\sum_{c \sim u} D(u \to c)$. (iii) $u \in T \setminus \{c\}$: $T = \{u, c, w\}$, a rep $c, d, e, u$ zatvara $4$-ciklus $e\,u\,c\,d$ kojemu je $w$ „krov” — susjed od $u$ i $c$ različit od $d$ i $e$. To je točno „kuća” iz službenog rješenja: $4$-ciklus $0\,1\,2\,3$ i vrh $4$ spojen s $1$ i $2$, s $e$ na mjestu $0$ i $u$ na mjestu $1$. S $K(x \to y)$ = broj kuća u kojima je $x$ vrh $0$ i $y$ vrh $1$ slučaj (iii) iznosi $\sum_{e \sim u} K(e \to u)$.

  5. Kako u $O(M\sqrt{M})$ dobiti kvadrate s dijagonalom i kuće po usmjerenom bridu?

    Orijentiraj bridove od vrha manjeg ranga (stupanj, pa indeks) prema većem; izlazni stupanj je $O(\sqrt{M})$, pa se svi trokuti nabroje u $O(M\sqrt{M})$ i to točno jednom. Prvi prolazak daje $\mathrm{tri}$ po vrhu i bridu, drugi prolazak za svaki trokut $\{x, y, z\}$ doda $\mathrm{tri}(yz) - 1$ na $D(x \to y)$ i $D(x \to z)$ (i simetrično za $y$, $z$). Za kuće prvo izračunaj $W(x \to y) = \sum_{4\text{-ciklus } x\,y\,z\,w} \mathrm{tri}(yz)$: krov je zajednički susjed $t$ od $y$ i $z$, ali $t = x$ i $t = w$ nisu kuće nego kvadrati s dijagonalom, i njihov je broj točno $D(y \to x)$ odnosno $D(x \to y)$. Dakle $K(x \to y) = W(x \to y) - D(x \to y) - D(y \to x)$. Sam $W$ dobiva se nabrajanjem svakog $4$-ciklusa iz njegova vrha $h$ najvećeg ranga: putevi $h - y - z$ s rangovima od $y, z$ manjima od ranga $h$ grupiraju se po $z$, a svaki par puteva $(y, y')$ do istog $z$ je jedan $4$-ciklus $h\,y\,z\,y'$. Doprinose svih osam usmjerenih bridova ciklusa zbrajamo agregirano po grupi (s $\mathrm{cnt} - 1$ i zbrojevima $\sum \mathrm{tri}(hy')$, $\sum \mathrm{tri}(zy')$), pa je cijena $O(\text{broj puteva } h\,y\,z) = O(M\sqrt{M})$.

Opći savjeti i prečaci

  • Kod brojanja malih podgrafa prvo odredi što jednoznačno određuje kopiju (koji su vrhovi razlikovani, koji su automorfizmi) — tako se brojanje svodi na zbroj lokalnih veličina bez korekcije faktorom, ili s jasnim faktorom.
  • Put ili rep koji visi na strukturi gradi po duljini: $L_k(u) = \sum_{v \sim u} L_{k-1}(v)$ minus loše konfiguracije. Za kratke repove loših tipova je malo i svaki je mali podgraf — ispiši ih sve sustavno (s kojim se ranijim vrhom novi vrh podudara).
  • Orijentacija bridova po stupnju (od manjeg prema većem) daje izlazni stupanj $O(\sqrt{M})$ i standardno $O(M\sqrt{M})$ brojanje trokuta i 4-ciklusa; 4-cikluse broji „od vrha najvećeg ranga” grupiranjem puteva duljine $2$ po krajnjem vrhu, a težinske varijante (težina = trokuti na bridu) agregiraj po grupi da ne prolaziš parove.
  • Na malim testovima uvijek imaj brute force koji doslovno nabraja injekcije vrhova i dijeli brojem automorfizama — to je najbrži način da uhvatiš pogrešan faktor $2$ ili zaboravljeni slučaj.
RJEŠENJEklikni za prikaz cijelog rješenja

Savjet: prije čitanja rješenja prođi kroz korake trenerskog načina iznad.

Modelno rješenje uzastopno računa sljedeće vrijednosti:

  1. Za svaki vrh $u$, broj $3$-ciklusa koji prolaze kroz $u$.
  2. Za svaki neusmjereni brid $e$, broj $3$-ciklusa koji prolaze kroz $e$.
  3. Za svaki usmjereni brid $e = (u, v)$, broj podgrafa s $4$ vrha $0, 1, 2, 3$ i $5$ bridova $(0,1), (1,2), (2,3), (3,0), (1,3)$ takvih da $u$ i $v$ odgovaraju vrhovima $0$ i $1$.
  4. Za svaki usmjereni brid $e = (u, v)$, broj podgrafa s $5$ vrhova $0, 1, 2, 3, 4$ i $6$ bridova $(0,1), (1,2), (2,3), (3,0), (1,4), (4,2)$ takvih da $u$ i $v$ odgovaraju vrhovima $0$ i $1$.
  5. Za svaki vrh $u$, broj kandidata s repom duljine $1$, $2$ i $3$ takvih da $u$ leži na kraju repa.

Vremenska složenost: $O(n + m\sqrt{m})$.

DETALJNO RJEŠENJE

1. Što jednoznačno određuje jednog kandidata

Čudovište $G$ je trokut $\{a, b, c\}$ s repom $c - d - e - f$: $6$ vrhova, $6$ bridova. Podgraf $S$ grafa $H$ izomorfan $G$ ima točno jedan trokut $T$, točno jedan vrh trokuta stupnja $3$ u $S$ (to je $c$) i točno jedan jednostavan put duljine $3$ koji iz $c$ vodi izvan trokuta; taj put čitamo od $c$: $(d, e, f)$. Automorfizmi $G$ su samo identiteta i zamjena $a \leftrightarrow b$, i oboje čuvaju $T$, $c$ i $(d, e, f)$. Zato je

$\#\text{kandidata} = \#\bigl\{(T, c, (d, e, f)) : T \text{ trokut u } H,\ c \in T,\ c \sim d \sim e \sim f,\ d, e, f \text{ različiti},\ d, e, f \notin T\bigr\}$,

i svaki podgraf $S$ pribrojen je točno jednom (kod svog trokuta, svog $c$ i svog repa). Provjera na $K_6$: trokuta je $\binom63 = 20$, za svaki od $3$ izbora $c$ rep je permutacija preostala $3$ vrha: $20 \cdot 3 \cdot 3! = 360$ — kao u primjeru.

2. Rep gradimo po duljini

Definiramo, za $k = 0, 1, 2, 3$ i vrh $u$,

$L_k(u) = \#\bigl\{(T, c, (v_1, \dots, v_k)) : c \in T,\ c = v_0 \sim v_1 \sim \dots \sim v_k = u,\ v_1, \dots, v_k \notin T \text{ različiti}\bigr\}$,

broj „kandidata s repom duljine $k$” čiji rep završava u $u$. Tada je $L_0(u) = \mathrm{tri}(u)$ (broj trokuta kroz $u$; istaknuti vrh je $u$ sam) i odgovor je $\sum_u L_3(u)$. Produljenje repa za jedan brid daje

$L_k(u) = \sum_{v \sim u} L_{k-1}(v) - (\text{broj loših produljenja})$,

gdje je produljenje loše ako novi vrh $u$ leži u $T$ ili se podudara s nekim od $v_1, \dots, v_{k-2}$ (s $v_{k-1}$ se ne može podudarati jer graf nema petlji). Dobra produljenja su u bijekciji s dobrim repovima duljine $k$, pa formula vrijedi. Ostaje prebrojati loša produljenja — i tu je poanta: za $k \le 3$ svaki tip lošeg produljenja je mali podgraf grafa $H$ s jednim ili dva istaknuta vrha, i svi se broje u $O(M\sqrt{M})$. To su redom veličine koje službeno rješenje računa: trokuti po vrhu i po bridu, „kvadrat s dijagonalom” i „kuća”.

3. Trokuti po vrhu i po bridu

Rang. Poredaj vrhove po stupnju (pa po indeksu) i orijentiraj svaki brid od manjeg ranga prema većem. Izlazni stupanj svakog vrha je $O(\sqrt{M})$: ako $u$ ima $k$ izlaznih susjeda, svi imaju stupanj $\ge \deg u \ge k$, pa je $k^2 \le \sum \deg \le 2M$.

Nabrajanje. Za svaki $u$ označi izlazne susjede; za svaki izlazni $v$ i svaki izlazni $w$ od $v$ s oznakom, $\{u, v, w\}$ je trokut s $\mathrm{rang}(u) < \mathrm{rang}(v) < \mathrm{rang}(w)$ — nađen točno jednom. Uvećaj $\mathrm{tri}(u), \mathrm{tri}(v), \mathrm{tri}(w)$ i $\mathrm{tri}$ triju bridova. Cijena $\sum_u \sum_{v \in \mathrm{out}(u)} |\mathrm{out}(v)| = O(M\sqrt{M})$. Isti prolazak ponavljamo kasnije još jednom (kad su $\mathrm{tri}$ po bridu poznati), pa trokute ne moramo pamtiti — memorija ostaje $O(N + M)$.

4. Rep duljine $1$

Produljenje s $k = 0$: $(T, c)$ s $c \sim u$, loše ako $u \in T$. Trokuti kroz $c$ koji sadrže $u$ točno su trokuti kroz brid $cu$, pa je

$L_1(u) = \sum_{c \sim u} \bigl(\mathrm{tri}(c) - \mathrm{tri}(cu)\bigr)$.

5. Rep duljine $2$ i kvadrat s dijagonalom

Produljenje $(T, c, d) \to (T, c, d, u)$ s $d \sim u$ loše je ako $u \in T$:

  • $u = c$: brojimo parove $(T \ni u, d)$ s $d \sim u$, $d \notin T$: $\sum_{d \sim u} \bigl(\mathrm{tri}(u) - \mathrm{tri}(ud)\bigr) = \deg u \cdot \mathrm{tri}(u) - 2\,\mathrm{tri}(u) = (\deg u - 2)\,\mathrm{tri}(u)$, jer svaki trokut kroz $u$ sadrži točno dva brida kroz $u$.
  • $u \in T \setminus \{c\}$: $T = \{u, c, z\}$, $d \sim c$, $d \sim u$, $d \ne z$ — za trokut $\{u, c, z\}$ takvih $d$ ima $\mathrm{tri}(uc) - 1$. Zbroj po svim trokutima kroz $u$ (s izborom koji je od druga dva vrha $c$) jest $\sum_{z \sim u} D(z \to u)$ uz definiciju ispod.

Kvadrat s dijagonalom. Za usmjereni brid $(x, y)$ neka je

$D(x \to y) = \sum_{z : \{x, y, z\} \text{ trokut}} \bigl(\mathrm{tri}(yz) - 1\bigr)$.

To je broj podgrafa s $4$ vrha $x, y, z, w$ i $5$ bridova $xy, xz, yz, yw, zw$ — dva trokuta sa zajedničkim bridom (dijagonalom) $yz$, gdje je $x$ vrh izvan dijagonale i $y$ njegov susjed na njoj; to je točno podgraf iz 3. točke službenog rješenja s $x$ na mjestu $0$ i $y$ na mjestu $1$ (vrhovi $0, 1, 2, 3$, bridovi $01, 12, 23, 30, 13$: dijagonala $13$, vrh $0$ izvan nje). Slučaj $u \in T \setminus \{c\}$ gore traži, za trokut $\{u, c, z\}$, zajedničke susjede $d$ od $u$ i $c$ različite od $z$, tj. $\mathrm{tri}(uc) - 1$ — a to je pribrojnik u $D(z \to u)$ za trokut $\{z, u, c\}$ (dijagonala $uc$, $z$ izvan nje). Dakle

$L_2(u) = \sum_{d \sim u} L_1(d) - (\deg u - 2)\,\mathrm{tri}(u) - \sum_{z \sim u} D(z \to u)$.

$D$ računamo drugim prolaskom po trokutima: svaki trokut $\{x, y, z\}$ doda $\mathrm{tri}(yz) - 1$ na $D(x \to y)$ i $D(x \to z)$, $\mathrm{tri}(xz) - 1$ na $D(y \to x)$ i $D(y \to z)$, te $\mathrm{tri}(xy) - 1$ na $D(z \to x)$ i $D(z \to y)$. Usmjereni brid pamtimo kao $2\cdot\mathrm{id} + [\text{polazi iz drugog kraja}]$.

6. Rep duljine $3$ i kuća

Produljenje $(T, c, d, e) \to (T, c, d, e, u)$ s $e \sim u$ loše je ako $u \in T$ ili $u = d$. Tri disjunktna slučaja:

  • $u = c$ ($B_c$): tada su $d, e \notin T$, $d \sim u$, $e \sim d$, $e \sim u$, pa je $\{u, d, e\}$ trokut. Za svaki trokut $\{u, d, e\}$ brojimo trokute $T \ni u$ koji ne sadrže ni $d$ ni $e$: po uključivanju–isključivanju $\mathrm{tri}(u) - \mathrm{tri}(ud) - \mathrm{tri}(ue) + 1$ (trokut $\{u, d, e\}$ sam odbijen je dvaput). Poredak $(d, e)$ daje faktor $2$: $B_c(u) = \sum_{\{u,d,e\} \text{ trokut}} 2\bigl(\mathrm{tri}(u) - \mathrm{tri}(ud) - \mathrm{tri}(ue) + 1\bigr)$ — također se skuplja u drugom prolasku po trokutima.
  • $u = d$ ($B_d$): rep $c, u, e, u$ s $e \sim u$, $e \notin T$, $e \ne c$. Za fiksni par $(T, c)$ s $c \sim u$, $u \notin T$ takvih je $e$ točno $\deg u - 1 - \#\{x \in T \setminus \{c\} : x \sim u\}$. Zbroj prvog člana je $(\deg u - 1)\,L_1(u)$; zbroj drugog broji trojke $(T, c, x)$ s $T = \{c, x, z\}$, $c, x \sim u$, $z \ne u$: za svaki trokut $\{u, c, x\}$ (uređeni par $(c, x)$) ima $\mathrm{tri}(cx) - 1$ izbora $z$, što je $\sum_{c \sim u} D(u \to c)$. Dakle $B_d(u) = (\deg u - 1)\,L_1(u) - \sum_{c \sim u} D(u \to c)$.
  • $u \in T \setminus \{c\}$ ($B_T$): $T = \{u, c, w\}$, a rep $c, d, e, u$ s $d, e \notin T$ zatvara $4$-ciklus $e\,u\,c\,d$ (svi vrhovi različiti: $e \ne c$ i $d \ne u$ jer $d, e \notin T$). Vrh $w$ je zajednički susjed od $u$ i $c$ različit od $d$ i $e$ — „krov” nad bridom $uc$. Podgraf s vrhovima $e, u, c, d, w$ i bridovima $eu, uc, cd, de, uw, cw$ ($5$ vrhova, $6$ bridova) upravo je podgraf iz 4. točke službenog rješenja (vrhovi $0..4$, bridovi $01, 12, 23, 30, 14, 42$: $4$-ciklus $0\,1\,2\,3$ i krov $4$ nad bridom $12$) s $e$ na mjestu $0$, $u$ na $1$, $c$ na $2$, $d$ na $3$ i $w$ na $4$. Neka je $K(x \to y)$ broj takvih „kuća” u kojima je $x$ vrh $0$ i $y$ vrh $1$; obratno, svaka kuća s $x = e$, $y = u$ daje točno jednu lošu konfiguraciju ($c$ je vrh $2$, $d$ vrh $3$, $T = \{u, c, w\}$). Dakle $B_T(u) = \sum_{e \sim u} K(e \to u)$.

$L_3(u) = \sum_{e \sim u} L_2(e) - B_c(u) - B_d(u) - B_T(u)$.

7. Brojanje kuća u $O(M\sqrt{M})$

Težinski $4$-ciklusi. Za usmjereni brid $(x, y)$ neka je $W(x \to y) = \sum \mathrm{tri}(yz)$ po svim $4$-ciklusima $x\,y\,z\,w$ (ciklus prolazi $x, y, z, w$ tim redom; $z$ je susjed od $y$ na ciklusu različit od $x$). Član $\mathrm{tri}(yz)$ broji krovove $t$ nad bridom $yz$, tj. zajedničke susjede od $y$ i $z$; kuća je to točno kad je $t \notin \{x, w\}$. Degenerirani slučajevi: $t = x$ znači da je $\{x, y, z\}$ trokut, a $w$ zajednički susjed od $x$ i $z$ različit od $y$ — po trokutu $\{x, y, z\}$ ima ih $\mathrm{tri}(xz) - 1$, ukupno $D(y \to x)$; $t = w$ znači da je $\{x, y, w\}$ trokut, a $z$ zajednički susjed od $y$ i $w$ različit od $x$ — ukupno $D(x \to y)$. Zato

$K(x \to y) = W(x \to y) - D(x \to y) - D(y \to x)$.

Nabrajanje $4$-ciklusa. Svaki $4$-ciklus obrađujemo kod svog vrha $h$ najvećeg ranga. Za fiksni $h$ prođi puteve $h - y - z$ s $\mathrm{rang}(y), \mathrm{rang}(z) < \mathrm{rang}(h)$ i grupiraj ih po $z$ (pamteći $y$ i identifikatore bridova $hy$, $yz$). Dva različita puta $h\,y\,z$ i $h\,y'\,z$ iz iste grupe čine $4$-ciklus $h\,y\,z\,y'$, i svaki $4$-ciklus s maksimumom $h$ i vrhom $z$ nasuprot $h$ nastaje točno jednom. Ciklus $h\,y\,z\,y'$ ima $8$ usmjerenih bridova; onima koji „polaze iz $y$-strane” doprinosi ovako: $W(h \to y) \mathrel{+}= \mathrm{tri}(yz)$, $W(y \to h) \mathrel{+}= \mathrm{tri}(hy')$, $W(y \to z) \mathrel{+}= \mathrm{tri}(zy')$, $W(z \to y) \mathrel{+}= \mathrm{tri}(yh)$, a simetrično za $y'$. Umjesto po parovima, zbrajamo po grupi veličine $\mathrm{cnt}$ sa $S_h = \sum_{y'} \mathrm{tri}(hy')$ i $S_z = \sum_{y'} \mathrm{tri}(zy')$: za svaki put $(y)$ iz grupe

$W(h \to y) \mathrel{+}= (\mathrm{cnt} - 1)\,\mathrm{tri}(yz),\quad W(y \to h) \mathrel{+}= S_h - \mathrm{tri}(hy),\quad W(y \to z) \mathrel{+}= S_z - \mathrm{tri}(yz),\quad W(z \to y) \mathrel{+}= (\mathrm{cnt} - 1)\,\mathrm{tri}(hy)$.

Broj trojki $(h, y, z)$ ograničen je zbrojem $\min(\deg h, \deg y)$ po bridovima $hy$, što je $O(M\sqrt{M})$; obrada grupa je linearna u broju puteva.

8. Algoritam i složenost

  1. Učitaj graf, izračunaj stupnjeve, rang, liste susjeda i izlazne liste — $O(N + M)$.
  2. Prvi prolazak po trokutima: $\mathrm{tri}$ po vrhu i po bridu — $O(M\sqrt{M})$.
  3. Drugi prolazak po trokutima: $D$ po usmjerenom bridu i $B_c$ po vrhu — $O(M\sqrt{M})$.
  4. Težinski $4$-ciklusi $W$ iz vrha najvećeg ranga, zatim $K = W - D - D^{\mathrm{T}}$ — $O(M\sqrt{M})$.
  5. $L_1$, $L_2$, $L_3$ po formulama iz točaka 4–6 — svaka $O(N + M)$.
  6. Odgovor $\sum_u L_3(u) \bmod 998244353$.

Ukupno $O(N + M\sqrt{M})$ vremena i $O(N + M)$ memorije. Najgori slučaj (gotovo potpun graf na $\approx 450$ vrhova s $10^5$ bridova, $\approx 1.5 \cdot 10^7$ trokuta koji se prolaze dvaput) radi oko $0.75$ s.

9. Prelijevanje, indeksi, primjer

  • Sve veličine ($\mathrm{tri}$, $D$, $W$, $K$, $L_k$ i djelomični zbrojevi u prijelazima) broje stvarne konfiguracije u grafu, pa su nenegativne i ograničene brojem četvorki $(T, c, d, e)$, tj. s $3 \cdot \#\text{trokuta} \cdot N^2 \le 3 \cdot 1.5 \cdot 10^7 \cdot 10^{10} < 2^{63}$; držimo ih u long long bez modula, a modul primjenjujemo tek na konačni zbroj.
  • Ulaz je $0$-indeksiran, bridovi bez ponavljanja; $M = 0$ ili graf bez trokuta daje $0$ ($L_0 \equiv 0$).
  • Primjer: dva trokuta $\{0,1,2\}$, $\{3,4,5\}$ i brid $(2,3)$. $\mathrm{tri}(2) = \mathrm{tri}(3) = 1$, $\mathrm{tri}(23) = 0$, pa je $L_1(3) = \mathrm{tri}(2) - \mathrm{tri}(23) = 1$ i simetrično $L_1(2) = 1$, ostali $L_1 = 0$ (npr. $L_1(0) = (\mathrm{tri}(1) - \mathrm{tri}(01)) + (\mathrm{tri}(2) - \mathrm{tri}(02)) = 0$). $L_2(4) = L_1(3) - 0 - D(3 \to 4) = 1$ ($D \equiv 0$, nema dva trokuta s zajedničkim bridom), isto $L_2(5) = 1$, $L_2(1) = L_2(0) = 1$; $L_2(2) = L_1(3) + L_1(0) + L_1(1) - (\deg 2 - 2)\,\mathrm{tri}(2) - 0 = 1 - 1 = 0$. $L_3(5) = L_2(3) + L_2(4) - B_c(5) - B_d(5) - B_T(5)$: $L_2(3) = L_1(2) + L_1(4) + L_1(5) - (3 - 2) \cdot 1 = 0$, $L_2(4) = 1$, $B_c(5) = 2(\mathrm{tri}(5) - \mathrm{tri}(53) - \mathrm{tri}(54) + 1) = 0$, $B_d(5) = 1 \cdot L_1(5) = 0$, $K \equiv 0$ (nema $4$-ciklusa), pa je $L_3(5) = 1$; jednako $L_3(4) = L_3(0) = L_3(1) = 1$ i $L_3(2) = L_3(3) = 0$. Ukupno $4$.

KOD (C++)klikni za prikaz izvornog koda 
// F. LaLa and Monster Hunting (Part 2) – službeni pristup
// Čudovište: trokut {a,b,c} + rep c-d-e-f. Redom računamo:
//   1. tri(u)      – broj trokuta kroz vrh u
//   2. tri(e)      – broj trokuta kroz brid e
//   3. Dm(u->v)    – "romb": dva trokuta sa zajedničkim bridom (dijagonalom) v-w,
//                    u je vrh izvan dijagonale susjedan s v   (4 vrha, 5 bridova)
//   4. Hs(u->v)    – "kuća": 4-ciklus u-v-z-w + vrh t susjedan s v i z  (5 vrhova, 6 bridova)
//   5. L1(u), L2(u), L3(u) – broj (trokut, rep duljine 1/2/3) čiji rep završava u u.
// Odgovor je sum_u L3(u).  Složenost O(n + m sqrt m).
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const ll MOD = 998244353;

int main() {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;
    vector<int> eu(m), ev(m), deg(n, 0);
    for (int i = 0; i < m; i++) { scanf("%d %d", &eu[i], &ev[i]); deg[eu[i]]++; deg[ev[i]]++; }

    // usmjereni brid id "iz vrha from": indeks 2*id + (from == ev[id])
    auto dir = [&](int id, int from) { return 2 * id + (from == ev[id] ? 1 : 0); };

    // poredak po stupnju; brid usmjeravamo od manjeg prema većem ranku -> izlazni stupanj O(sqrt m)
    vector<int> ord(n), rnk(n);
    iota(ord.begin(), ord.end(), 0);
    sort(ord.begin(), ord.end(), [&](int a, int b) { return deg[a] != deg[b] ? deg[a] < deg[b] : a < b; });
    for (int i = 0; i < n; i++) rnk[ord[i]] = i;

    vector<vector<pair<int, int>>> adj(n), out(n);   // (susjed, id brida)
    for (int i = 0; i < m; i++) {
        adj[eu[i]].push_back({ev[i], i}); adj[ev[i]].push_back({eu[i], i});
        if (rnk[eu[i]] < rnk[ev[i]]) out[eu[i]].push_back({ev[i], i}); else out[ev[i]].push_back({eu[i], i});
    }

    // 1.+2. trokuti po vrhu i po bridu (svaki trokut nađen točno jednom: u < v < w po ranku)
    vector<ll> triV(n, 0), triE(m, 0);
    vector<int> mark(n, -1);
    for (int u = 0; u < n; u++) {
        for (auto [v, id] : out[u]) mark[v] = id;
        for (auto [v, idUV] : out[u])
            for (auto [w, idVW] : out[v])
                if (mark[w] >= 0) {
                    int idUW = mark[w];
                    triV[u]++; triV[v]++; triV[w]++;
                    triE[idUV]++; triE[idVW]++; triE[idUW]++;
                }
        for (auto [v, id] : out[u]) mark[v] = -1;
    }

    // 3. rombovi po usmjerenom bridu: Dm(x->y) = sum po trokutima {x,y,z} od (tri(yz) - 1).
    //    Usput badC(u) = broj (trokut T kroz u, trokut {u,d,e} disjunktan s T osim u), uređeno po (d,e).
    vector<ll> Dm(2 * m, 0), badC(n, 0);
    for (int u = 0; u < n; u++) {
        for (auto [v, id] : out[u]) mark[v] = id;
        for (auto [v, idUV] : out[u])
            for (auto [w, idVW] : out[v])
                if (mark[w] >= 0) {
                    int idUW = mark[w];
                    Dm[dir(idUV, u)] += triE[idVW] - 1;  Dm[dir(idUW, u)] += triE[idVW] - 1;
                    Dm[dir(idUV, v)] += triE[idUW] - 1;  Dm[dir(idVW, v)] += triE[idUW] - 1;
                    Dm[dir(idUW, w)] += triE[idUV] - 1;  Dm[dir(idVW, w)] += triE[idUV] - 1;
                    badC[u] += 2 * (triV[u] - triE[idUV] - triE[idUW] + 1);
                    badC[v] += 2 * (triV[v] - triE[idUV] - triE[idVW] + 1);
                    badC[w] += 2 * (triV[w] - triE[idUW] - triE[idVW] + 1);
                }
        for (auto [v, id] : out[u]) mark[v] = -1;
    }

    // 4. kuće. Prvo W(x->y) = sum po 4-ciklusima x-y-z-w od tri(yz)  (težinski 4-ciklusi po
    //    usmjerenom bridu), zatim Hs(x->y) = W(x->y) - Dm(x->y) - Dm(y->x) (izbacivanje
    //    slučajeva u kojima se peti vrh podudara s x odnosno s w).
    //    4-cikluse nabrajamo iz vrha najvećeg ranka h: putevi h-y-z s rank(y), rank(z) < rank(h),
    //    grupirani po z; svaki par puteva do istog z je jedan 4-ciklus.
    vector<ll> W(2 * m, 0);
    {
        vector<vector<array<int, 3>>> paths(n);   // paths[z] = (y, id hy, id yz)
        vector<int> touched;
        for (int h = 0; h < n; h++) {
            for (auto [y, idHY] : adj[h]) {
                if (rnk[y] >= rnk[h]) continue;
                for (auto [z, idYZ] : adj[y]) {
                    if (rnk[z] >= rnk[h]) continue;
                    if (paths[z].empty()) touched.push_back(z);
                    paths[z].push_back({y, idHY, idYZ});
                }
            }
            for (int z : touched) {
                auto &P = paths[z];
                ll cnt = P.size();
                if (cnt >= 2) {
                    ll Sh = 0, Sz = 0;
                    for (auto &p : P) { Sh += triE[p[1]]; Sz += triE[p[2]]; }
                    for (auto &p : P) {
                        int y = p[0], idHY = p[1], idYZ = p[2];
                        W[dir(idHY, h)] += (cnt - 1) * triE[idYZ];   // h->y, sljedeći z
                        W[dir(idHY, y)] += Sh - triE[idHY];          // y->h, sljedeći y'
                        W[dir(idYZ, y)] += Sz - triE[idYZ];          // y->z, sljedeći y'
                        W[dir(idYZ, z)] += (cnt - 1) * triE[idHY];   // z->y, sljedeći h
                    }
                }
                P.clear();
            }
            touched.clear();
        }
    }
    vector<ll> Hs(2 * m);
    for (int id = 0; id < m; id++) {
        ll both = Dm[2 * id] + Dm[2 * id + 1];
        Hs[2 * id] = W[2 * id] - both;
        Hs[2 * id + 1] = W[2 * id + 1] - both;
    }

    // 5. repovi duljine 1, 2, 3 koji završavaju u u
    vector<ll> L1(n, 0), L2(n, 0), L3(n, 0);
    for (int u = 0; u < n; u++)
        for (auto [c, id] : adj[u]) L1[u] += triV[c] - triE[id];
    for (int u = 0; u < n; u++) {
        ll s = 0, dmIn = 0;
        for (auto [d, id] : adj[u]) { s += L1[d]; dmIn += Dm[dir(id, d)]; }
        L2[u] = s - triV[u] * (deg[u] - 2) - dmIn;
    }
    ll ans = 0;
    for (int u = 0; u < n; u++) {
        ll s = 0, dmOut = 0, hsIn = 0;
        for (auto [e, id] : adj[u]) { s += L2[e]; dmOut += Dm[dir(id, u)]; hsIn += Hs[dir(id, e)]; }
        ll badD = (ll)(deg[u] - 1) * L1[u] - dmOut;   // u = d: put c-u-e-u nije jednostavan
        L3[u] = s - badC[u] - badD - hsIn;             // badC: u = c; hsIn: u in trokutu \ {c}
        ans = (ans + L3[u]) % MOD;
    }
    printf("%lld\n", (ans % MOD + MOD) % MOD);
    return 0;
}

2. RJEŠENJE: Uključivanje–isključivanje po vrhu trokuta

Za razliku od službenog pristupa, koji rep gradi po duljini i loše repove oduzima kao male podgrafe („kvadrat s dijagonalom”, „kuća”), ovaj pristup za svaki trokut i svaki izbor vrha $c$ izravno prebroji sve jednostavne puteve duljine $3$ iz $c$ i uključivanjem–isključivanjem izbaci one koji dotiču druga dva vrha trokuta. Prednost mu je da nema dinamike po duljini ni „kuća”: dovoljne su tri lokalne veličine (stupnjevi, trokuti po bridu, $4$-ciklusi po bridu), pa je izvod kraći i lakše ga je provjeriti ručno; cijena je zbroj po svim trokutima (do $1.5 \cdot 10^7$) i, u ovoj implementaciji, pamćenje popisa trokuta.

1. Što jednoznačno određuje jednog kandidata

Kao i u službenom rješenju: kopija je određena trokutom $T = \{a, b, c\}$, vrhom $c$ i uređenim jednostavnim putem $(d, e, f)$ izvan $T$, pa je

$\#\text{kandidata} = \sum_{\{a,b,c\} \text{ trokut}} \ \sum_{c \in \{a,b,c\}} \#\{\text{jednostavni putevi } c\,d\,e\,f \text{ u } H:\ d, e, f \notin \{a, b\}\}$.

2. Jednostavni putevi duljine $3$ iz vrha

Za vrh $c$ tražimo $P(c)$, broj nizova $(d, e, f)$ različitih vrhova, različitih od $c$, s $c \sim d \sim e \sim f$. Biramo $d \sim c$, zatim $e \sim d$, $e \ne c$; $f$ je susjed od $e$ osim $d$ i osim $c$ (ako je $c \sim e$). Dakle

$P(c) = \sum_{d \sim c} \ \sum_{e \sim d,\ e \ne c} \bigl(\deg e - 1 - [c \sim e]\bigr) = \sum_{d \sim c} \Bigl( Q(d) - (\deg c - 1) - \mathrm{tri}(cd) \Bigr)$,

gdje je $Q(d) = \sum_{e \sim d} (\deg e - 1)$ (iz čega izbacujemo član $e = c$ vrijednosti $\deg c - 1$), a $\mathrm{tri}(cd) = \#\{e : e \sim c, e \sim d\}$ je broj trokuta na bridu $cd$ — točno broj $e \sim d$ sa svojstvom $c \sim e$. $Q$ se računa u $O(M)$, $P$ u $O(M)$ kad znamo $\mathrm{tri}$ po bridu.

3. Izbacivanje puteva koji dotiču $a$ ili $b$

Neka je $T = \{a, b, c\}$ trokut i $c$ izabran. Traženi broj je, po uključivanju–isključivanju, $P(c) - A - B + AB$, gdje je $A$ broj puteva kroz $a$, $B$ kroz $b$, $AB$ kroz oba. Vrh $a$ može u putu $(d,e,f)$ zauzeti točno jedno mjesto, pa je $A$ zbroj triju disjunktnih slučajeva:

  • $d = a$: preostaje jednostavan put $a, e, f$ koji izbjegava $c$. Ista formula kao za $P$, samo za jednog konkretnog susjeda: $Q(a) - (\deg c - 1) - \mathrm{tri}(ca)$.
  • $e = a$: $d$ je zajednički susjed $c$ i $a$ (ima ih $\mathrm{tri}(ca)$), a $f$ je susjed od $a$ različit od $c$ i $d$: ukupno $\mathrm{tri}(ca) \cdot (\deg a - 2)$.
  • $f = a$: put $c, d, e, a$ s $d, e \notin \{c, a\}$, $d \ne e$, zajedno s bridom $ac$ čini 4-ciklus koji sadrži brid $ca$; obratno, svaki takav 4-ciklus daje točno jedan put. Broj je $\mathrm{c4}(ca)$, broj 4-ciklusa na bridu $ca$.

$B$ je isto s $b$. Za $AB$ vrhovi $a$ i $b$ zauzimaju dva od tri mjesta; treće je slobodno:

  • $(d, e) = (a, b)$: put $c, a, b, f$, $f \sim b$, $f \notin \{c, a\}$: $\deg b - 2$; simetrično $(d,e) = (b,a)$: $\deg a - 2$.
  • $(d, f) = (a, b)$: put $c, a, e, b$, $e$ zajednički susjed od $a$ i $b$ različit od $c$: $\mathrm{tri}(ab) - 1$; i simetrično još $\mathrm{tri}(ab) - 1$.
  • $(e, f) = (a, b)$: put $c, d, a, b$, $d$ zajednički susjed od $c$ i $a$ različit od $b$: $\mathrm{tri}(ca) - 1$; simetrično $(e,f) = (b,a)$: $\mathrm{tri}(cb) - 1$.

Sve su to $O(1)$ izrazi po trokutu, pa je zbrajanje $O(\#\text{trokuta})$.

4. Trokuti i 4-ciklusi po bridu u $O(M\sqrt{M})$

Rang. Poredaj vrhove po stupnju (pa po indeksu) i orijentiraj svaki brid od manjeg ranga prema većem. Izlazni stupanj svakog vrha je $O(\sqrt{M})$: ako $u$ ima $k$ izlaznih susjeda, svi imaju stupanj $\ge \deg u \ge k$, pa je $k^2 \le \sum \deg \le 2M$.

Trokuti. Za svaki $u$ označi izlazne susjede; za svaki izlazni $v$ i svaki izlazni $w$ od $v$ s oznakom, $\{u, v, w\}$ je trokut s $\mathrm{rang}(u) < \mathrm{rang}(v) < \mathrm{rang}(w)$ — nađen točno jednom. Za svaki uvećaj $\mathrm{tri}$ triju bridova i zapamti trokut. Cijena $\sum_u \sum_{v \in \mathrm{out}(u)} |\mathrm{out}(v)| = O(M\sqrt{M})$.

4-ciklusi na bridu. Svaki 4-ciklus obrađujemo kod svog vrha $u$ najvećeg ranga. Za fiksni $u$ prođi puteve $u - v - w$ sa $\mathrm{rang}(v), \mathrm{rang}(w) < \mathrm{rang}(u)$ i broji ih po $w$ u $\mathrm{cnt}[w]$. Dva različita takva puta $u\,v\,w$ i $u\,v'\,w$ čine 4-ciklus $u\,v\,w\,v'$ (svi 4-ciklusi s maksimumom $u$ i vrhom $w$ nasuprot $u$ nastaju tako, svaki jednom). Brid $uv$ leži u $\mathrm{cnt}[w] - 1$ takvih ciklusa (uparen sa svakim drugim putom do istog $w$), a isto i brid $vw$; bridovi $uv'$ i $v'w$ dobivaju svoje kad obradimo put $u\,v'\,w$. Nakon obrade $u$ poništi $\mathrm{cnt}$ samo za dirane $w$. Broj trojki $(u, v, w)$ ograničen je zbrojem $\min(\deg u, \deg v)$ po bridovima, što je $O(M\sqrt{M})$.

5. Algoritam i složenost

  1. Učitaj graf, izračunaj stupnjeve, rang, liste susjeda i izlazne liste.
  2. $Q(v)$ za sve vrhove — $O(M)$.
  3. Trokuti: $\mathrm{tri}$ po bridu i popis trokuta — $O(M\sqrt{M})$.
  4. $\mathrm{c4}$ po bridu — $O(M\sqrt{M})$.
  5. $P(c)$ za sve vrhove — $O(M)$.
  6. Za svaki trokut i svaki od tri izbora $c$: $P(c) - A - B + AB$, zbroj modulo $998244353$.

Ukupno $O(N + M\sqrt{M})$; najgori slučaj (gotovo potpun graf na $\approx 450$ vrhova s $10^5$ bridova) ima $\approx 1.5 \cdot 10^7$ trokuta i radi oko $1$ s, uz $\approx 360$ MB za popis trokuta (unutar $1024$ MB; moglo bi se i bez pamćenja, računajući odgovor odmah pri pronalasku trokuta).

6. Prelijevanje, indeksi, primjer

  • $Q(d) \le \deg d \cdot 10^5 \le 10^{10}$, $P(c) \le 10^{15}$ — sve u long long, bez modula do konačnog zbrajanja; izraz $P - A - B + AB$ je nenegativan (broji nešto), pa modulo primjenjujemo tek na zbroj.
  • Ulaz je $0$-indeksiran, bridovi bez ponavljanja; $M = 0$ ili graf bez trokuta daje $0$.
  • Primjer: dva trokuta $\{0,1,2\}$, $\{3,4,5\}$ i brid $(2,3)$. Za trokut $\{0,1,2\}$ i $c = 2$: $P(2)$ broji puteve iz $2$: $2,3,4,5$ i $2,3,5,4$ te puteve kroz $0$ ili $1$ (npr. $2,0,1,\cdot$ — nema nastavka; $2,1,0,\cdot$ — nema), pa je $P(2) = 2$, $A = B = AB = 0$ i doprinos je $2$; za $c = 0$ ili $1$ nema puteva izvan trokuta. Simetrično drugi trokut daje $2$; ukupno $4$.

// F. LaLa and Monster Hunting (Part 2)
// Uzorak: trokut {a,b,c} + rep c-d-e-f (jednostavan put duljine 3 iz c).
// Za svaki trokut i svaki izbor vrha c zbrajamo broj puteva c-d-e-f koji
// izbjegavaju a i b: P(c) - (putevi kroz a) - (putevi kroz b) + (putevi kroz oba).
// Sve potrebne veličine su lokalne: stupnjevi, broj trokuta po bridu tri(uv),
// broj 4-ciklusa po bridu c4(uv) i Q(v) = sum_{e~v} (deg(e)-1).
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const ll MOD = 998244353;

int main() {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;
    vector<int> eu(m), ev(m), deg(n, 0);
    for (int i = 0; i < m; i++) { scanf("%d %d", &eu[i], &ev[i]); deg[eu[i]]++; deg[ev[i]]++; }

    // poredak po stupnju: rank[v]; brid usmjeravamo od manjeg prema većem ranku
    vector<int> ord(n), rnk(n);
    iota(ord.begin(), ord.end(), 0);
    sort(ord.begin(), ord.end(), [&](int a, int b) { return deg[a] != deg[b] ? deg[a] < deg[b] : a < b; });
    for (int i = 0; i < n; i++) rnk[ord[i]] = i;

    vector<vector<pair<int, int>>> adj(n), out(n);   // (susjed, id brida)
    for (int i = 0; i < m; i++) {
        adj[eu[i]].push_back({ev[i], i}); adj[ev[i]].push_back({eu[i], i});
        if (rnk[eu[i]] < rnk[ev[i]]) out[eu[i]].push_back({ev[i], i}); else out[ev[i]].push_back({eu[i], i});
    }

    // Q(v) = sum_{e ~ v} (deg(e) - 1)
    vector<ll> Q(n, 0);
    for (int v = 0; v < n; v++) for (auto [e, id] : adj[v]) Q[v] += deg[e] - 1;

    // tri(id): broj trokuta koji sadrže brid id; usput popis trokuta (bridovi)
    vector<ll> tri(m, 0);
    vector<array<int, 3>> triangles;   // (id ab, id bc, id ca) s vrhovima u, v, w
    vector<array<int, 3>> triV;
    vector<int> mark(n, -1);
    for (int u = 0; u < n; u++) {
        for (auto [v, id] : out[u]) mark[v] = id;
        for (auto [v, idUV] : out[u])
            for (auto [w, idVW] : out[v])
                if (mark[w] >= 0) {
                    int idUW = mark[w];
                    tri[idUV]++; tri[idVW]++; tri[idUW]++;
                    triangles.push_back({idUV, idVW, idUW});
                    triV.push_back({u, v, w});
                }
        for (auto [v, id] : out[u]) mark[v] = -1;
    }

    // c4(id): broj 4-ciklusa koji sadrže brid id.
    // Za svaki vrh u i sve puteve u-v-w s rank(v), rank(w) < rank(u): cnt[w] = broj
    // takvih puteva; svaki par puteva do istog w je 4-ciklus s maksimumom u,
    // pa bridovi uv i vw dobivaju cnt[w]-1 ciklusa iz tog puta.
    vector<ll> c4(m, 0), cnt(n, 0);
    vector<int> touched;
    for (int u = 0; u < n; u++) {
        for (auto [v, idUV] : adj[u]) {
            if (rnk[v] >= rnk[u]) continue;
            for (auto [w, idVW] : adj[v]) {
                if (rnk[w] >= rnk[u]) continue;
                if (cnt[w] == 0) touched.push_back(w);
                cnt[w]++;
            }
        }
        for (auto [v, idUV] : adj[u]) {
            if (rnk[v] >= rnk[u]) continue;
            for (auto [w, idVW] : adj[v]) {
                if (rnk[w] >= rnk[u]) continue;
                c4[idUV] += cnt[w] - 1;
                c4[idVW] += cnt[w] - 1;
            }
        }
        for (int w : touched) cnt[w] = 0;
        touched.clear();
    }

    // P(c) = broj jednostavnih puteva c-d-e-f
    //      = sum_{d ~ c} ( Q(d) - (deg(c) - 1) - tri(cd) )
    vector<ll> P(n, 0);
    for (int c = 0; c < n; c++)
        for (auto [d, id] : adj[c]) P[c] += Q[d] - (deg[c] - 1) - tri[id];

    // putevi c-d-e-f koji prolaze kroz a (a ~ c): d = a, e = a ili f = a
    auto through = [&](int c, int a, int idCA) -> ll {
        ll dA = Q[a] - (deg[c] - 1) - tri[idCA];   // c-a-e-f
        ll eA = tri[idCA] * (deg[a] - 2);           // c-d-a-f, d zajednički susjed
        ll fA = c4[idCA];                           // c-d-e-a: 4-ciklus kroz brid ca
        return dA + eA + fA;
    };

    ll ans = 0;
    for (size_t t = 0; t < triangles.size(); t++) {
        int vs[3] = {triV[t][0], triV[t][1], triV[t][2]};
        // bridovi: e01 = (v0,v1), e12 = (v1,v2), e02 = (v0,v2)
        int e01 = triangles[t][0], e12 = triangles[t][1], e02 = triangles[t][2];
        for (int k = 0; k < 3; k++) {
            int c = vs[k], a = vs[(k + 1) % 3], b = vs[(k + 2) % 3];
            auto eid = [&](int x, int y) {
                if ((x == vs[0] && y == vs[1]) || (x == vs[1] && y == vs[0])) return e01;
                if ((x == vs[1] && y == vs[2]) || (x == vs[2] && y == vs[1])) return e12;
                return e02;
            };
            int idCA = eid(c, a), idCB = eid(c, b), idAB = eid(a, b);
            ll both = (deg[a] - 2) + (deg[b] - 2)          // c-a-b-f, c-b-a-f
                    + 2 * (tri[idAB] - 1)                   // c-a-e-b, c-b-e-a
                    + (tri[idCA] - 1) + (tri[idCB] - 1);    // c-d-a-b, c-d-b-a
            ll cur = P[c] - through(c, a, idCA) - through(c, b, idCB) + both;
            ans = (ans + cur) % MOD;
        }
    }
    printf("%lld\n", (ans % MOD + MOD) % MOD);
    return 0;
}
