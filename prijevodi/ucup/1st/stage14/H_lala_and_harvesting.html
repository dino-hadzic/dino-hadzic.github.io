ZADATAK H: LaLa and Harvesting

LaLa i žetva — The 1st Universal Cup, Stage 14: Ranoa (Osijek Competitive Programming Camp Winter 2023, Day 9: Magical Story of LaLa). Vremensko ograničenje: 4 s, memorijsko ograničenje: 1024 MB.

Graf usjeva s vrhovima $0..N-1$ (težine $T_u$) nastaje u tri faze: (1) kaktus (povezan jednostavan graf u kojem svaki brid leži na najviše jednom ciklusu) s $M$ bridova; (2) uzmi DFS-stablo kaktusa iz vrha $0$ (susjedi u redoslijedu ulaza), neka su $c_0, \dots, c_{l-1}$ listovi DFS-stabla u DFS-poretku — dodaju se bridovi ciklusa $(c_0, c_1), \dots, (c_{l-1}, c_0)$; (3) dodaje se još $K$ bridova koji čine stablo u kojem svaki vrh stupnja $> 1$ ima stupanj $\ge 12$. Nađi nezavisan skup najveće ukupne težine i ispiši ga.

Ulaz

$N, M$ ($2 \le N \le 500$, $N - 1 \le M \le 2N$), težine $T_u \le 200\,000$, $M$ bridova kaktusa, $K$ ($1 \le K \le \min(N-1, 100)$) i $K$ bridova treće faze. Mogu postojati višestruki bridovi.

Izlaz

$W$, $L$ i rastući popis odabranih vrhova.

NAPUTCI

Naputak 1klikni za prikaz

Bez treće faze, stablo s ciklusom kroz listove je Halinov graf, a kaktus s ciklusom kroz listove DFS-stabla „gotovo” Halinov — oba imaju malu širinu stabla (treewidth). Nezavisan skup najveće težine na grafu ograničene širine stabla rješava se dinamičkim programiranjem po stablastoj dekompoziciji: stanje je podskup vreće.

Naputak 2klikni za prikaz

Dekompoziciju gradi eksplicitno po DFS-stablu: za vrh $v$ vreća $\{v, \mathrm{rod}(v), a_v, b_v\}$, gdje su $a_v, b_v$ prvi i zadnji list podstabla vrha $v$ u DFS-poretku, a susjednu djecu povezuju vreće $\{v, b_{c_i}, a_{c_{i+1}}, b_v\}$. Za kaktus u svaku vreću vrha $v$ dodaj još vrh ciklusa (najbliži korijenu) kojem pripada brid $(v, \mathrm{rod}(v))$.

Naputak 3klikni za prikaz

Stablo iz treće faze ima vrhovni pokrivač veličine $\max(1, \lfloor (K-1)/11 \rfloor) \le 9$ (svi nelistovi imaju stupanj $\ge 12$). Ubaci pokrivač u svaku vreću: širina postaje $\le 4 + 9 = 13$, pa DP s $2^{14}$ stanja po vreći lako prolazi.

TRENERSKI NAČIN: logički put do rješenja

Logički put do rješenja: svaki je korak pitanje koje bi si iskusan natjecatelj postavio. Pokušaj na njega odgovoriti sam, pa tek onda otvori odgovor i usporedi – cilj je uvježbati način razmišljanja, a ne zapamtiti rješenje.

  1. Zašto je graf bez treće faze „gotovo Halinov” i što nam to daje?

    Halinov graf je stablo bez vrhova stupnja $2$ plus ciklus kroz sve njegove listove (u ravninskom poretku). Ovdje je druga faza točno to: ciklus kroz listove DFS-stabla u DFS-poretku, a DFS-poredak listova jest „ravninski” poredak, jer listovi podstabla svakog vrha čine uzastopni komad ciklusa. Halinovi grafovi imaju širinu stabla $\le 3$, tj. postoji stablasta dekompozicija s vrećama od najviše $4$ vrha. Kaktus dodaje još povratne bridove DFS-a; pokazat ćemo da oni povećavaju širinu za najviše $1$. Zašto je to korisno: na grafu s dekompozicijom širine $w$ nezavisan skup najveće težine računa se u $O(\text{broj vreća} \cdot 2^{w+1} \cdot (w+1))$ — svaka vreća je separator, a stanje je „koji su vrhovi vreće uzeti”.

  2. Kako eksplicitno izgleda dekompozicija Halinova grafa širine $3$ i zašto vrijede sva tri svojstva?

    Za vrh $v$ DFS-stabla neka su $a_v$ i $b_v$ prvi i zadnji list njegova podstabla u DFS-poretku (list koji je i sam korijen računa se kao prvi). Vreće: $Z_v = \{v, \mathrm{rod}(v), a_v, b_v\}$; ako $v$ ima djecu $c_1, \dots, c_k$ (u DFS-poretku), još $W_i = \{v, a_{c_i}, b_{c_i}, b_v\}$ i $M_i = \{v, b_{c_i}, a_{c_{i+1}}, b_v\}$, povezane u lanac $Z_v - W_1 - M_1 - W_2 - \dots - W_k$, a $Z_{c_i}$ visi na $W_i$. Pokrivanje bridova: brid stabla $(v, \mathrm{rod}(v))$ je u $Z_v$; brid ciklusa između uzastopnih listova $b_{c_i}$ i $a_{c_{i+1}}$ (uzastopni listovi iz podstabala susjedne djece istog vrha) je u $M_i$; brid $(b_{\text{korijen}}, a_{\text{korijen}})$ koji zatvara ciklus je u $Z_{\text{korijen}}$. Povezanost (svojstvo tekućeg presjeka): $v$ je u svojim vrećama, u $W_i$-vrećama roditelja i u $Z$ djece — sve susjedno; $b_v$ je u svim vrećama od $v$, u $Z_{c_k}$ (jer $b_v = b_{c_k}$) i u $W_j, M_j$ roditelja — opet povezano; slično $a_v$. Provjera je rutinska, a program to i doslovno provjerava u testovima. Sve vreće imaju $\le 4$ vrha, dakle širina $3$.

  3. Što se mijenja kad je prva faza kaktus, a ne stablo?

    DFS-stablo kaktusa ima povratne bridove $(x, y)$, $y$ predak od $x$; svaki zatvara ciklus s putem $x \to y$ u stablu, a zbog svojstva kaktusa svaki brid stabla leži na najviše jednom takvom ciklusu. Za vrh $v \ne$ korijen neka je $t(v)$ „vrh ciklusa najbliži korijenu” (tj. $y$) ako brid $(v, \mathrm{rod}(v))$ leži na ciklusu, inače ništa. U sve vreće vrha $v$ ($Z_v$, $W_i$, $M_i$) dodamo $t(v)$. Povratni brid $(x, y)$ tada je pokriven u $Z_x \ni x, t(x) = y$. Povezanost za $y$: vrhovi $v$ s $t(v) = y$ čine putove u stablu koji završavaju u djeci od $y$; vreće vrha $v$ su povezane s vrećama roditelja preko $Z_v - W_j$, a sve one sadrže $y$, pa je skup vreća s $y$ i dalje povezan. Vreće sada imaju $\le 5$ vrhova: širina $\le 4$. Napomena: DFS ide po redoslijedu ulaza, točno kako zadatak definira listove — dekompozicija se gradi na istom DFS-stablu na kojem je definiran ciklus.

  4. Kako se stablo treće faze uklapa i zašto je njegov pokrivač malen?

    Ako graf $G_1$ ima dekompoziciju širine $A$, a $G_2$ vrhovni pokrivač $C$ veličine $B$, onda $G_1 \cup G_2$ ima dekompoziciju širine $\le A + B$: dodaj $C$ u svaku vreću. Svaki brid od $G_2$ ima kraj $c \in C$, pa je pokriven u bilo kojoj vreći koja sadrži drugi kraj; povezanost za $c$ je trivijalna (u svim vrećama). Stablo treće faze s $K$ bridova ima $K + 1$ vrhova; ako ima $I$ unutarnjih vrhova (stupanj $\ge 12$) i $K + 1 - I$ listova, zbroj stupnjeva daje $12 I + (K + 1 - I) \le 2K$, tj. $I \le (K - 1)/11 \le 9$. Unutarnji vrhovi su pokrivač (svaki brid ima barem jedan nelisni kraj) kad je $K \ge 2$; za $K = 1$ pokrivač je jedan kraj tog brida. Ukupno: širina $\le 4 + 9 = 13$, vreće do $14$ vrhova.

  5. Kako ide dinamika po dekompoziciji i rekonstrukcija?

    Za vreću $B$ i nezavisan podskup $S \subseteq B$ neka je $f(B, S)$ najveća težina nezavisnog skupa u uniji svih vreća podstabla od $B$ čiji je presjek s $B$ točno $S$. Tada $f(B, S) = w(S) + \sum_{\text{dijete } C} \max\{ f(C, S') - w(S' \cap B) : S' \cap B = S \cap C \}$ — dijete smije birati bilo što izvan zajedničkih vrhova, a zajednički se broje jednom. Vrhovi iz različitih podstabala koji nisu u $B$ nisu susjedni (svojstvo separatora), pa je unija nezavisna. Implementacija: podskupovi kao bitmaske pozicija u vreći; nezavisnost i težina maske računaju se inkrementalno (maska bez najnižeg bita), projekcija $S' \mapsto S' \cap B$ također inkrementalno; za dijete napuni tablicu $g[\text{projekcija}] = \max(\dots)$ i dodaj $g[S \cap C]$ svakom $S$. Rekonstrukcija odozgo: u korijenu uzmi najbolji $S$, za svako dijete najbolji $S'$ s odgovarajućom projekcijom; vrh je odabran ako je u odabranom podskupu bilo koje vreće (dosljedno zbog povezanosti). Ukupno $O(\sum_B 2^{|B|} |B|) \le O(3N \cdot 2^{14} \cdot 14)$.

Opći savjeti i prečaci

  • Kad zadatak sumnjivo precizno opisuje strukturu grafa (kaktus, ciklus kroz listove, stablo s velikim stupnjevima), autor ti govori da graf ima malu širinu stabla ili mali vrhovni pokrivač — traži eksplicitnu dekompoziciju, ne generalni algoritam.
  • Halinov graf ima širinu stabla $3$; dekompozicija se gradi po stablu s vrećama „vrh, roditelj, prvi i zadnji list podstabla”. Isto vrijedi i za neke srodne strukture (ciklus kroz listove DFS-stabla kaktusa) uz dodavanje po jednog vrha.
  • Graf s malim vrhovnim pokrivačem $C$ „besplatno” se lijepi na graf male širine stabla: ubaci $C$ u sve vreće. Širina $A + |C|$, bez ikakve promjene ostatka dekompozicije.
  • DP po stablastoj dekompoziciji ne treba „lijepu” (nice) dekompoziciju: dovoljno je stanje $f(\text{vreća}, \text{podskup})$ i projekcija podskupa djeteta na zajedničke vrhove. Pri testiranju eksplicitno provjeri tri svojstva dekompozicije (pokrivanje vrhova, pokrivanje bridova, povezanost) — greške u konstrukciji inače daju tiho krive odgovore.
RJEŠENJEklikni za prikaz cijelog rješenja

Savjet: prije čitanja rješenja prođi kroz korake trenerskog načina iznad.

  • Da nema treće faze i da je graf iz prve faze stablo, ovaj graf bio bi poznat kao Halinov graf, koji ima širinu stabla $\le 3$.
  • Da nema treće faze, u svaku vreću dekompozicije Halinova grafa ubacimo korijen DFS-stabla relevantnih ciklusa. Dobivena dekompozicija ima širinu $\le 4$.
  • Spajanje grafa širine stabla $\le A$ s grafom čiji je vrhovni pokrivač $\le B$ daje graf širine stabla $\le A + B$.
  • Budući da stablo iz treće faze ima vrhovni pokrivač veličine $\max(1, (K-1)/11)$, možemo konstruirati dekompoziciju ulaznog grafa širine $\le 13$. Odgovor se tada nalazi u $O\!\left(N \cdot 2^{5 + (K-1)/11} \cdot (5 + (K-1)/11)\right)$.

DETALJNO RJEŠENJE

1. Stablasta dekompozicija i zašto rješava nezavisan skup

Stablasta dekompozicija grafa $G$ je stablo čiji su čvorovi vreće $B \subseteq V(G)$ takve da: (i) svaki vrh je u nekoj vreći; (ii) za svaki brid $uv$ postoji vreća koja sadrži oba kraja; (iii) za svaki vrh $v$ vreće koje sadrže $v$ čine povezan podgraf stabla (svojstvo tekućeg presjeka). Širina je $\max |B| - 1$. Ključna posljedica (iii) i (ii): ako je vreća $B$ na putu između dviju drugih vreća, svaki vrh koji se pojavljuje na obje strane je u $B$, pa vrhovi „s različitih strana” od $B$ koji nisu u $B$ nisu susjedni — $B$ je separator. Zato za nezavisan skup najveće težine radi dinamika po ukorijenjenoj dekompoziciji: za vreću $B$ i nezavisan $S \subseteq B$ neka je $f(B, S)$ najveća težina nezavisnog skupa $I$ unutar unije vreća podstabla od $B$ s $I \cap B = S$. Tada

$f(B, S) = w(S) + \sum_{C \text{ dijete od } B} \max\bigl\{ f(C, S') - w(S' \cap B) : S' \subseteq C \text{ nezavisan},\ S' \cap B = S \cap C \bigr\}.$

Dokaz: neka je $I$ optimalan za $(B, S)$ i $I_C$ njegov dio u podstablu djeteta $C$; $I_C \cap C =: S'$ zadovoljava $S' \cap B = S \cap C$ (vrhovi zajednički $B$ i $C$ su ili u oba ili ni u jednom), pa je $w(I) = w(S) + \sum_C \bigl(w(I_C) - w(S' \cap B)\bigr) \le$ desna strana. Obratno, unija optimalnih izbora po djeci i $S$ je nezavisna: vrh iz podstabla $C$ koji nije u $B$ ne pojavljuje se ni u jednom drugom podstablu (svojstvo (iii)) i nema susjeda izvan podstabla od $C$ osim u $B$ (svojstvo (ii) + separator), a susjedstvo s $B$ je provjereno unutar $C$ jer je $S' \supseteq S \cap C$ i $S'$ nezavisan. Vrijeme: $O(\sum_B 2^{|B|} \cdot |B|)$ uz bitmaske.

2. Halinov graf: dekompozicija širine $3$

Neka je prva faza stablo $T$ ukorijenjeno u $0$, s djecom u redoslijedu ulaza; druga faza dodaje ciklus kroz listove $c_0, \dots, c_{l-1}$ u DFS-poretku (list je vrh stupnja $1$ u stablu; korijen s jednim djetetom je list i tada je $c_0 = 0$). Listovi podstabla vrha $v$ čine uzastopni komad DFS-poretka, dakle i ciklusa. Neka su $a_v$ i $b_v$ prvi i zadnji list podstabla vrha $v$ (za list $v \ne 0$ je $a_v = b_v = v$; za korijen-list $a_0 = 0$).

Vreće. Za svaki vrh $v$ vreća $Z_v = \{v, \mathrm{rod}(v), a_v, b_v\}$ (za korijen bez roditelja). Ako $v$ ima djecu $c_1, \dots, c_k$ u DFS-poretku, dodatno $W_i = \{v, a_{c_i}, b_{c_i}, b_v\}$ za $i = 1..k$ i $M_i = \{v, b_{c_i}, a_{c_{i+1}}, b_v\}$ za $i = 1..k-1$, povezane u lanac $Z_v - W_1 - M_1 - W_2 - M_2 - \dots - W_k$; vreća $Z_{c_i}$ djeteta visi na $W_i$. Korijen dekompozicije je $Z_0$. Sve vreće imaju $\le 4$ vrha.

Pokrivanje bridova. Brid stabla $(v, \mathrm{rod}(v))$: u $Z_v$. Brid ciklusa $(c_j, c_{j+1})$: uzastopni listovi $c_j, c_{j+1}$ leže u podstablima dvoje susjedne djece $c_i, c_{i+1}$ nekog vrha $v$ (najniži zajednički predak), pri čemu je $c_j = b_{c_i}$ i $c_{j+1} = a_{c_{i+1}}$ — to je vreća $M_i$; ako je $c_j = 0$ korijen-list, tada je $c_{j+1} = a_{c_1}$ za jedino dijete $c_1$ korijena, a $\{0, a_{c_1}\} \subseteq W_1$ korijena. Brid $(c_{l-1}, c_0)$ koji zatvara ciklus: $c_0 = a_0$, $c_{l-1} = b_0$, oba u $Z_0$.

Povezanost. Vrh $v$: u svim svojim vrećama (lanac), u $Z_{c_i}$ svoje djece (susjedno s $W_i$) i u $W_j$ roditelja (susjedno sa $Z_v$) — povezano. Vrh $x = b_v$: u svakoj vreći vrha $v$ (zato smo $b_v$ stavili u sve $W_i, M_i$), u $Z_{c_k}$ jer $b_{c_k} = b_v$, te — ako je $v = c_j$ dijete od $u$ — u $W_j(u)$ i $M_j(u)$ (susjedne) i, ako je usto $b_u = x$, u svim vrećama od $u$; induktivno prema gore skup vreća s $x$ je povezan, a prema dolje lanac $Z_v - W_k(v) - Z_{c_k} - \dots$ vodi do $Z_x$. Vrh $x = a_v$: u $Z_v$ i $W_1(v)$, u $Z_{c_1}$, a prema gore u $W_j(u), M_{j-1}(u)$ i eventualno $Z_u$ ako je $a_u = x$ — povezano. Dakle imamo dekompoziciju širine $3$; to je standardni dokaz da Halinovi grafovi imaju širinu stabla $\le 3$.

3. Kaktus: još jedan vrh po vreći

Prva faza je kaktus; njegovo DFS-stablo (iz $0$, susjedi u redoslijedu ulaza — točno onako kako zadatak definira listove) ima uz bridove stabla i povratne bridove $(x, y)$ s $y$ pretkom od $x$ (u neusmjerenom DFS-u svaki nestablasti brid spaja vrh s pretkom). Povratni brid zatvara ciklus s putem od $x$ do $y$ u stablu; u kaktusu svaki brid stabla leži na najviše jednom takvom ciklusu. Za $v \ne 0$ definiramo $t(v) = y$ ako brid $(v, \mathrm{rod}(v))$ leži na ciklusu povratnog brida $(x, y)$, inače $t(v)$ nije definirano; računa se jednim prolaskom po povratnim bridovima ($x \to \mathrm{rod}(x) \to \dots$ do djeteta od $y$), ukupno $O(N)$ jer se svaki brid stabla obiđe najviše jednom.

U sve vreće vrha $v$ ($Z_v$, $W_i$, $M_i$) dodamo $t(v)$. Povratni brid $(x, y)$ pokriven je u $Z_x$ jer je $t(x) = y$. Povezanost za $y$: skup vrhova $v$ s $t(v) = y$ je unija putova u stablu koji završavaju u djeci od $y$; za takav $v$ sve njegove vreće sadrže $y$, a $Z_v$ je susjedna s $W_j(\mathrm{rod}(v))$ koja također sadrži $y$ (bilo jer $t(\mathrm{rod}(v)) = y$, bilo jer je $\mathrm{rod}(v) = y$). Sve ostale vreće koje sadrže $y$ — vreće od $y$ samog, vreće roditelja od $y$, one gdje je $y$ neki $a$ ili $b$ — bile su povezane i prije. Vreće sada imaju $\le 5$ vrhova: širina $\le 4$.

4. Treća faza: vrhovni pokrivač u svakoj vreći

Lema. Ako $G_1$ ima dekompoziciju širine $A$, a $G_2$ vrhovni pokrivač $C$ s $|C| = B$, tada $G_1 \cup G_2$ ima dekompoziciju širine $\le A + B$: dodaj $C$ u svaku vreću. Svaki brid od $G_2$ ima kraj $c \in C$; drugi kraj $u$ je u nekoj vreći, a $c$ je u svakoj — pokriveno. Vrhovi iz $C$ su u svim vrećama pa je (iii) trivijalno; za ostale se ništa nije promijenilo.

Pokrivač stabla treće faze. Stablo s $K$ bridova ima $K + 1$ vrhova; neka ih je $I$ unutarnjih (stupanj $\ge 12$ po uvjetu zadatka) i $K + 1 - I$ listova. Zbroj stupnjeva je $2K \ge 12 I + (K + 1 - I)$, odakle $11 I \le K - 1$, tj. $I \le \lfloor (K-1)/11 \rfloor \le 9$ za $K \le 100$. Za $K \ge 2$ unutarnji vrhovi čine pokrivač (brid s oba lisna kraja postojao bi samo u stablu s jednim bridom); za $K = 1$ pokrivač je jedan kraj tog brida. Dakle ulazni graf ima dekompoziciju širine $\le 4 + 9 = 13$, s vrećama od najviše $14$ vrhova. Višestruki bridovi (brid treće faze koji se podudara s bridom kaktusa ili ciklusa) ne smetaju — susjedstvo je isto.

5. Algoritam

  1. Učitaj kaktus i bridove treće faze; susjedstvo drži u matrici (bitsetovima) $N \times N$. Odredi stupnjeve u stablu treće faze i pokrivač $C$ (unutarnji vrhovi, ili $\{x_0\}$ za $K = 1$).
  2. DFS iz $0$ po redoslijedu ulaza: roditelj, dubina, preorder, djeca u DFS-poretku, te $t(v)$ pri susretu povratnog brida. Listovi u preorderu $\Rightarrow$ bridovi ciklusa u matricu susjedstva.
  3. $a_v, b_v$ obrnutim preorderom: $a_v = v$ ako je $v$ list, inače $a_{c_1}$; $b_v = b_{c_k}$ ako ima djece, inače $v$.
  4. Vreće $Z_v$ za sve $v$, zatim lanci $W_i, M_i$ s poveznicama; svaka vreća je $\{v, \mathrm{rod}(v), a, b, t(v)\} \cup C$ bez ponavljanja (duplikati se brišu, pa su stvarne vreće često manje od $14$). Ukupno $\le N + 2(N-1) < 3N$ vreća.
  5. BFS-poredak vreća od $Z_0$; obrnutim poretkom za svaku vreću: conf[i] = maska pozicija susjednih poziciji $i$; ind[mask] i wt[mask] inkrementalno preko maske bez najnižeg bita; $f = $ wt za nezavisne maske. Za svako dijete: projekcija proj[mask] (također inkrementalno, preko tablice bit-u-bit), tablica $g$ indeksirana projekcijom, $f[S] \mathrel{+}= g[S \cap C]$.
  6. Rekonstrukcija odozgo: u korijenu argmax; za dijete najbolja maska s projekcijom jednakom odabranom presjeku; svaki vrh odabrane maske označi. Ispiši zbroj težina, broj vrhova i rastući popis.

Složenost. $\sum_B 2^{|B|} (|B| + \text{broj djece})$ — najviše oko $1500 \cdot 2^{14} \cdot 15 \approx 4 \cdot 10^8$ elementarnih operacija u teoriji, u praksi znatno manje (vreće rijetko dosegnu $14$ vrhova): najveći testovi rade $< 0.1$ s. Memorija: tablice $f$ za sve vreće, $\le 1500 \cdot 2^{14}$ cijelih brojeva $\approx 100$ MB u najgorem slučaju (izmjereno $84$ MB), unutar $1024$ MB; težine su $\le 500 \cdot 2 \cdot 10^5 = 10^8$, pa dostaje int.

6. Zamke

  • Korijen kao list. Ako $0$ ima točno jedno dijete, $0$ je list i to prvi ($c_0 = 0$): $a_0 = 0$, dok $b_0$ dolazi iz djeteta. Ciklus kroz listove tada sadrži bridove $(0, c_1)$ i $(c_{l-1}, 0)$ — oba pokrivena ($W_1(0)$, $Z_0$).
  • Dva lista. Ako je DFS-stablo put, $l = 2$ i „ciklus” su dva jednaka brida — samo jedan brid u matrici susjedstva.
  • Redoslijed DFS-a. Susjede treba obrađivati po redoslijedu ulaza (liste susjedstva pune se pri čitanju bridova), inače dobiješ drugo DFS-stablo i drugi ciklus od onoga koji zadatak definira; brute force i checker moraju koristiti istu definiciju.
  • Povratni brid samo jednom. U neusmjerenom DFS-u nestablasti brid $(v, w)$ vidi se s obje strane; bilježi ga samo kad je $w$ predak od $v$ ($\mathrm{dub}(w) < \mathrm{dub}(v)$, $w \ne \mathrm{rod}(v)$).
  • Tekući presjek. Zaboraviš li $b_v$ ili $t(v)$ u vrećama $W_i, M_i$, dekompozicija tiho prestaje biti valjana i DP daje prevelik odgovor — provjeri tri svojstva programski na testovima.
  • Više rješenja. Bilo koji skup najveće težine je točan; checker provjerava nezavisnost, zbroj i optimalnost (usporedbom $W$ s brute forceom).

7. Primjer

$N = 6$, sve težine $1$, kaktus $01, 12, 23, 24, 15, 14, 05$, treća faza $K = 1$: brid $25$. DFS iz $0$: $0 \to 1 \to 2 \to 3$ (list), $2 \to 4$ (povratni brid $4 \to 1$, ciklus $1\,2\,4$, pa $t(4) = t(2) = 1$), $1 \to 5$ (povratni brid $5 \to 0$, ciklus $0\,1\,5$, $t(5) = t(1) = 0$). Preorder $0, 1, 2, 3, 4, 5$; korijen ima jedno dijete pa je list: listovi $0, 3, 4, 5$, ciklus $03, 34, 45, 50$. Pokrivač $C = \{2\}$. Puni graf ima bridove $01, 12, 23, 24, 14, 15, 05, 03, 34, 45, 25$. Vreće (bez $C$): $Z_0 = \{0, 0, 5\} = \{0, 5\}$, $W_1(0) = \{0, a_1 = 3, b_1 = 5\}$, $Z_1 = \{1, 0, 3, 5, t = 0\}$, $W_1(1) = \{1, 3, 4, 5, 0\}$, $M_1(1) = \{1, 4, 5, 5, 0\}$, $W_2(1) = \{1, 5, 5, 5, 0\}$, $Z_2 = \{2, 1, 3, 4, 1\}$, $W_1(2) = \{2, 3, 3, 4, 1\}$, $M_1(2) = \{2, 3, 4, 4, 1\}$, $W_2(2) = \{2, 4, 4, 4, 1\}$, $Z_3 = \{3, 2, 3, 3\}$, $Z_4 = \{4, 2, 4, 4, 1\}$, $Z_5 = \{5, 1, 5, 5, 0\}$; s dodanim $2$ najveća vreća ima $6$ vrhova. Nezavisan skup najveće težine ima $2$ vrha (npr. $\{0, 4\}$ ili $\{3, 5\}$): $3$ vrha nije moguće jer $0$ nije susjedan samo s $2$ i $4$, a $2$–$4$ je brid; slično za ostale. Ispis: 2 2 i 0 4.

Provjera koda: uzorak 1/1 (checker: nezavisnost, zbroj težina i $W$ jednak očekivanom); 300 (stress.py) $+$ dodatnih 1000 slučajnih testova ($N \le 16$, slučajni kaktusi s bridovno disjunktnim ciklusima i permutiranim oznakama, treća faza jedan brid ili zvijezda s $\ge 12$ listova) protiv brute forcea po svim podskupovima vrhova; 300 srednjih testova ($20 \le N \le 150$, treća faza s do $9$ unutarnjih vrhova) na kojima je programski provjereno da su sve tri svojstva stablaste dekompozicije zadovoljena (najveća vreća $14$) i da je izlaz valjan; 3 velika testa $N = 500$, $M \approx 540$, $K = 100$ ($9$ unutarnjih vrhova, zvijezda, kaktus s dugim ciklusima; najviše 0.09 s, 84 MB).

KOD (C++)klikni za prikaz izvornog koda 
// H. LaLa and Harvesting – službeni pristup
// Graf = kaktus + ciklus kroz listove DFS-stabla + "gusto" stablo s K bridova.
// 1. Kaktus + ciklus listova ima stablastu dekompoziciju širine <= 4:
//    Halinova dekompozicija (vrh, roditelj, prvi i zadnji list podstabla) u koju
//    za svaki vrh dodamo vrh ciklusa kaktusa najbliži korijenu (t(v)).
// 2. Unutarnji vrhovi stabla treće faze (stupanj >= 12) čine vrhovni pokrivač
//    tog stabla veličine <= (K-1)/11 <= 9; dodamo ih u svaku vreću -> širina <= 13.
// 3. Najteži nezavisan skup dinamikom po vrećama (bitmaske podskupova vreće)
//    uz rekonstrukciju.  Složenost O(N * 2^14 * 14).
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<vector<int>> cadj;              // susjedi u kaktusu, u redoslijedu ulaza
vector<int> par, dep, pre, topOf;      // topOf[v] = vrh najbliži korijenu na ciklusu brida (v, par v), ili -1
vector<vector<int>> ch;                // djeca u DFS-stablu, u DFS-redoslijedu
vector<char> vis;

void dfs(int v) {
    vis[v] = 1; pre.push_back(v);
    for (int w : cadj[v]) {
        if (!vis[w]) { par[w] = v; dep[w] = dep[v] + 1; ch[v].push_back(w); dfs(w); }
        else if (w != par[v] && dep[w] < dep[v])
            for (int x = v; x != w; x = par[x]) topOf[x] = w;   // povratni brid v -> predak w
    }
}

struct Bag { vector<int> v; vector<int> kids; };
vector<Bag> bags;
int newBag(vector<int> vs) {
    vs.erase(remove(vs.begin(), vs.end(), -1), vs.end());
    sort(vs.begin(), vs.end()); vs.erase(unique(vs.begin(), vs.end()), vs.end());
    bags.push_back({vs, {}});
    return (int)bags.size() - 1;
}

int main() {
    if (scanf("%d %d", &n, &m) != 2) return 0;
    vector<int> T(n);
    for (auto &t : T) scanf("%d", &t);
    cadj.assign(n, {});
    vector<bitset<500>> adj(n);
    for (int i = 0; i < m; i++) {
        int u, v; scanf("%d %d", &u, &v);
        cadj[u].push_back(v); cadj[v].push_back(u);
        adj[u][v] = adj[v][u] = 1;
    }
    int k; scanf("%d", &k);
    vector<int> deg3(n, 0), x0(1, -1);
    for (int i = 0; i < k; i++) {
        int x, y; scanf("%d %d", &x, &y);
        adj[x][y] = adj[y][x] = 1; deg3[x]++; deg3[y]++;
        if (i == 0) x0[0] = x;
    }

    // DFS-stablo kaktusa iz vrha 0
    par.assign(n, -1); dep.assign(n, 0); topOf.assign(n, -1); ch.assign(n, {}); vis.assign(n, 0);
    dfs(0);

    // listovi (stupanj 1 u stablu; korijen s jednim djetetom je list) u DFS-poretku -> ciklus
    vector<int> leaves;
    for (int v : pre)
        if ((v == 0 && ch[v].size() == 1) || (v != 0 && ch[v].empty())) leaves.push_back(v);
    int l = leaves.size();
    for (int i = 0; i < l; i++) {
        int a = leaves[i], b = leaves[(i + 1) % l];
        adj[a][b] = adj[b][a] = 1;
    }

    // a[v], b[v] = prvi i zadnji list u podstablu vrha v (list je i sam korijen ako je list)
    vector<int> A(n), B(n);
    for (int i = n - 1; i >= 0; i--) {
        int v = pre[i];
        bool leaf = (v == 0 && ch[v].size() == 1) || (v != 0 && ch[v].empty());
        A[v] = leaf ? v : A[ch[v].front()];
        B[v] = ch[v].empty() ? v : B[ch[v].back()];
    }

    // vrhovni pokrivač stabla treće faze: unutarnji vrhovi (ili x0 ako je K = 1)
    vector<int> cover;
    for (int v = 0; v < n; v++) if (deg3[v] >= 2) cover.push_back(v);
    if (cover.empty()) cover = x0;

    // stablasta dekompozicija
    vector<int> Z(n);
    for (int v = 0; v < n; v++) {
        vector<int> vs = {v, par[v], A[v], B[v], topOf[v]};
        vs.insert(vs.end(), cover.begin(), cover.end());
        Z[v] = newBag(vs);
    }
    for (int v = 0; v < n; v++) {
        int kc = ch[v].size();
        if (kc == 0) continue;
        int prev = Z[v];
        for (int i = 0; i < kc; i++) {
            int c = ch[v][i];
            vector<int> vs = {v, A[c], B[c], B[v], topOf[v]};
            vs.insert(vs.end(), cover.begin(), cover.end());
            int W = newBag(vs);
            bags[prev].kids.push_back(W);
            bags[W].kids.push_back(Z[c]);
            if (i + 1 < kc) {
                vector<int> ms = {v, B[c], A[ch[v][i + 1]], B[v], topOf[v]};
                ms.insert(ms.end(), cover.begin(), cover.end());
                int Mb = newBag(ms);
                bags[W].kids.push_back(Mb);
                prev = Mb;
            }
        }
    }
    int root = Z[0];
    int nb = bags.size();

    // BFS-poredak vreća, dinamika odozdo prema gore
    vector<int> order, bpar(nb, -1);
    order.push_back(root);
    for (size_t i = 0; i < order.size(); i++)
        for (int c : bags[order[i]].kids) { bpar[c] = order[i]; order.push_back(c); }

    const int NEG = -1000000000;
    vector<vector<int>> f(nb), wt(nb);
    vector<vector<char>> ind(nb);
    vector<int> posIn(n, -1);

    auto prepare = [&](int b) {
        auto &vs = bags[b].v; int s = vs.size();
        vector<int> conf(s, 0);
        for (int i = 0; i < s; i++) for (int j = 0; j < s; j++) if (i != j && adj[vs[i]][vs[j]]) conf[i] |= 1 << j;
        ind[b].assign(1 << s, 1); wt[b].assign(1 << s, 0);
        for (int mask = 1; mask < (1 << s); mask++) {
            int low = __builtin_ctz(mask), rest = mask ^ (1 << low);
            ind[b][mask] = ind[b][rest] && !(conf[low] & rest);
            wt[b][mask] = wt[b][rest] + T[vs[low]];
        }
    };
    // projekcija podskupova djeteta c na pozicije roditelja b: proj[mask], sharedC
    auto projection = [&](int b, int c, vector<int> &proj, int &sharedC) {
        auto &vb = bags[b].v; auto &vc = bags[c].v;
        for (int i = 0; i < (int)vb.size(); i++) posIn[vb[i]] = i;
        int sc = vc.size(); vector<int> mapbit(sc, 0); sharedC = 0;
        for (int j = 0; j < sc; j++) if (posIn[vc[j]] >= 0) { mapbit[j] = 1 << posIn[vc[j]]; sharedC |= 1 << j; }
        for (int i = 0; i < (int)vb.size(); i++) posIn[vb[i]] = -1;
        proj.assign(1 << sc, 0);
        for (int mask = 1; mask < (1 << sc); mask++) {
            int low = __builtin_ctz(mask);
            proj[mask] = proj[mask ^ (1 << low)] | mapbit[low];
        }
    };

    for (int idx = nb - 1; idx >= 0; idx--) {
        int b = order[idx];
        prepare(b);
        int s = bags[b].v.size();
        f[b].assign(1 << s, NEG);
        for (int mask = 0; mask < (1 << s); mask++) if (ind[b][mask]) f[b][mask] = wt[b][mask];
        vector<int> g(1 << s), proj;
        for (int c : bags[b].kids) {
            int sharedC; projection(b, c, proj, sharedC);
            fill(g.begin(), g.end(), NEG);
            int sc = bags[c].v.size();
            for (int mask = 0; mask < (1 << sc); mask++) if (ind[c][mask])
                g[proj[mask]] = max(g[proj[mask]], f[c][mask] - wt[c][mask & sharedC]);
            int sharedB = proj[sharedC];
            for (int mask = 0; mask < (1 << s); mask++) if (ind[b][mask]) f[b][mask] += g[mask & sharedB];
        }
    }

    // rekonstrukcija odozgo prema dolje
    vector<int> chosenMask(nb, 0);
    {
        int best = 0;
        for (int mask = 0; mask < (int)f[root].size(); mask++) if (f[root][mask] > f[root][best]) best = mask;
        chosenMask[root] = best;
    }
    vector<char> take(n, 0);
    for (int idx = 0; idx < nb; idx++) {
        int b = order[idx];
        auto &vs = bags[b].v;
        for (int i = 0; i < (int)vs.size(); i++) if (chosenMask[b] >> i & 1) take[vs[i]] = 1;
        vector<int> proj;
        for (int c : bags[b].kids) {
            int sharedC; projection(b, c, proj, sharedC);
            int target = chosenMask[b] & proj[sharedC];
            int best = -1, bestVal = NEG;
            for (int mask = 0; mask < (int)f[c].size(); mask++)
                if (ind[c][mask] && proj[mask] == target) {
                    int val = f[c][mask] - wt[c][mask & sharedC];
                    if (val > bestVal) { bestVal = val; best = mask; }
                }
            chosenMask[c] = best;
        }
    }

    long long W = 0; vector<int> res;
    for (int v = 0; v < n; v++) if (take[v]) { W += T[v]; res.push_back(v); }
    printf("%lld %d\n", W, (int)res.size());
    for (size_t i = 0; i < res.size(); i++) printf("%d%c", res[i], i + 1 == res.size() ? '\n' : ' ');
    if (res.empty()) printf("\n");
    return 0;
}
