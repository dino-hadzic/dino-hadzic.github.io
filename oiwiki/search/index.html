Pretraživanje (search) je nabrajanje prostora stanja: iscrpnim prolaskom kroz sve mogućnosti pronalazi se optimalno rješenje ili se prebrojavaju dopuštena rješenja.

Pretraživanje se može optimizirati na mnogo načina, npr. smanjivanjem prostora stanja, promjenom redoslijeda pretraživanja, rezanjem (pruning) itd.

Pretraživanje je temelj nekih naprednijih algoritama. U OI-ju je čisto pretraživanje često način da se dobije dio bodova, ali zadataka koje se čistim pretraživanjem može riješiti za sve bodove vrlo je malo.

Search means enumerating the state space: by exhausting all possibilities we find the optimal solution or count the valid solutions.

Search can be optimized in many ways, e.g. by shrinking the state space, changing the search order, pruning, etc.

Search is the foundation of some advanced algorithms. In OI, plain search is often a way to get partial credit, but very few problems can be fully solved by plain search alone.
