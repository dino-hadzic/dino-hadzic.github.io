Opis problema

Zadan je niz od \(n\) elemenata za koji je zajamčeno da postoji element \(a\) koji se pojavljuje strogo više od \(n/2\) puta; pronađite taj element.

Rješenja

Offline algoritam

Ako od početka znamo cijeli niz, prirodna je ideja prebrojati pojavljivanja svakog elementa u nizu; onaj koji se pojavljuje više od \(n/2\) puta većinski je element. Možemo napraviti bucket (polje brojača) za brojanje pojavljivanja svake vrijednosti i ispisati element s više od \(n/2\) pojavljivanja.

No gornje rješenje za brojanje uvodi bucket i nije prostorno učinkovito. Očito, ako u nizu postoji većinski element, onda je nakon sortiranja element niza na položaju \(\lfloor n/2\rfloor+1\) sigurno većinski element, a pomoću nth_element možemo ga pronaći. Tako većinski element dobivamo u linearnoj vremenskoj složenosti bez uvođenja dodatnog prostora.

Online algoritam

U nekim situacijama podatke moramo obrađivati online, kao tok (stream); tada nam treba algoritam koji ne zahtijeva poznavanje svih podataka unaprijed, nego odgovor postupno izračunava samo iz dosad zadanih podataka. Algoritam većinskog glasanja (Boyer–Mooreov algoritam) 1 jedan je takav algoritam koji problem većinskog elementa rješava online.

Budući da se većinski element pojavljuje više od \(n/2\) puta, ako iz cijelog niza neprestano poništavamo par koji čine jedan većinski element i jedan element različit od njega, na kraju nužno preostaje većinski element. Na temelju tog zapažanja možemo oblikovati online algoritam koji provodi takvo poništavanje. Neka varijable val i cnt redom označavaju trenutačnog kandidata za većinski element i koliko bi primjeraka tog kandidata preostalo kad bismo proveli opisano poništavanje. Na početku je cnt postavljen na \(0\). Svaki put iz toka uzmemo jedan element; ako je trenutačni cnt jednak \(0\), kandidat je u potpunosti poništen i trenutačno zabilježeni val sigurno nije većinski element, pa trenutačni element postavimo za kandidata. Zatim provjerimo je li trenutačni element jednak kandidatu: ako jest, cnt uvećamo za \(1\), a ako nije, taj se element poništava zajedno s jednim kandidatom pa cnt umanjimo za \(1\). Ponavljamo dok ne pročitamo cijeli tok; val je tada većinski element.

Napomena

Kad u izvornim podacima ne postoji većinski element, rezultat ovog algoritma je pogrešan. Ako treba provjeriti postoji li u nizu većinski element, tok podataka treba pročitati još jednom, prebrojati pojavljivanja vrijednosti val i provjeriti prelazi li broj \(n/2\).

Za ponovno čitanje toka možemo vratiti pokazivač položaja ulaza, npr. bibliotečnim funkcijama std::basic_istream<CharT,Traits>::seekg (ulaz preko tokova) ili rewind, fseek (ulaz u stilu C-a).

#include <cstdio>

int main() {
  int n;
  scanf("%d", &n);
  int val, cnt = 0;
  while (n--) {
    int x;
    scanf("%d", &x);
    if (!cnt) val = x;
    (val == x) ? ++cnt : --cnt;
  }
  printf("%d\n", val);
  return 0;
}
LeetCode 229. Majority Element II

Zadan je niz od \(n\) cijelih brojeva; pronađite sve elemente koji se pojavljuju više od \(\lfloor n/3\rfloor\) puta.

Primjer koda 
class Solution {
 public:
  vector<int> majorityElement(vector<int>& nums) {
    // „poništavanje 2 različita elementa” iz algoritma većinskog glasanja mijenjamo u „poništavanje 3 međusobno različita elementa”
    int maj1, maj2;
    int cnt1 = 0, cnt2 = 0;
    for (int num : nums) {
      if (num == maj1) {
        ++cnt1;
      } else if (num == maj2) {
        ++cnt2;
      } else if (cnt1 == 0) {
        maj1 = num;
        ++cnt1;
      } else if (cnt2 == 0) {
        maj2 = num;
        ++cnt2;
      } else {
        --cnt1;
        --cnt2;
      }
    }

    // zadatak ne jamči da postoje 2 elementa s više od ⌊ n/3 ⌋ pojavljivanja, pa treba provjeriti
    vector<int> ans;
    cnt1 = 0, cnt2 = 0;
    for (int num : nums) {
      if (num == maj1)
        ++cnt1;
      else if (num == maj2)
        ++cnt2;
    }
    int n = nums.size();
    if (cnt1 > n / 3) ans.push_back(maj1);
    if (cnt2 > n / 3) ans.push_back(maj2);

    return ans;
  }
};

Problem description

Given a sequence of \(n\) elements, it is guaranteed that there is an element \(a\) that appears strictly more than \(n/2\) times; find this element.

Solutions

Offline algorithm

If the whole sequence is known from the start, a natural idea is to count the occurrences of each element in the sequence; the one that appears more than \(n/2\) times is the majority element. We can create a bucket to count the occurrences of each value and output the element that appears more than \(n/2\) times.

But the above approach introduces a bucket for counting, which is not space efficient. Obviously, if the sequence has a majority element, then after sorting, the element at position \(\lfloor n/2\rfloor+1\) of the sequence must be the majority element, and it can be found with nth_element. This way we find the majority element in linear time without introducing extra space.

Online algorithm

In some situations we need to process streaming data online; then we need an algorithm that does not require knowing all the data in advance, but gradually computes the answer using only the data given so far. The majority vote algorithm (Boyer–Moore) 1 is such an algorithm that solves the majority element problem online.

Since the majority element appears more than \(n/2\) times, for a complete sequence, after repeatedly canceling one majority element together with one element different from it, the majority element must remain at the end. Using this observation, we can design an online algorithm that performs such cancellations. Let two variables val and cnt represent the current majority candidate and how many copies of the candidate would remain if such cancellations were performed so far. Initially cnt is set to \(0\). Each time we take an element from the data stream: if the current cnt is \(0\), the majority candidate has been completely canceled and the currently recorded val is certainly not the majority element, so we set the current element as the majority candidate. Then we check whether the current element equals the majority candidate; if so, cnt increases by \(1\), and if not, this element should be canceled together with one majority candidate, so cnt decreases by \(1\). Repeat the above until the data stream is fully read; val is then the majority element.

Note

When the original data has no majority element, the result given by this algorithm is wrong. To determine whether a majority element exists in the sequence, the data stream must be read again, counting the occurrences of val and checking whether it exceeds \(n/2\).

To read the data stream again, you can reset the input position indicator using library functions such as std::basic_istream<CharT,Traits>::seekg (stream input) or rewind, fseek (C-style input).

LeetCode 229. Majority Element II

Given an integer array of size \(n\), find all elements that appear more than \(\lfloor n/3\rfloor\) times.

Reference code 
class Solution {
 public:
  vector<int> majorityElement(vector<int>& nums) {
    // change "cancel 2 different elements" of the majority vote algorithm into "cancel 3 pairwise different elements"
    int maj1, maj2;
    int cnt1 = 0, cnt2 = 0;
    for (int num : nums) {
      if (num == maj1) {
        ++cnt1;
      } else if (num == maj2) {
        ++cnt2;
      } else if (cnt1 == 0) {
        maj1 = num;
        ++cnt1;
      } else if (cnt2 == 0) {
        maj2 = num;
        ++cnt2;
      } else {
        --cnt1;
        --cnt2;
      }
    }

    // the problem does not guarantee that 2 elements with more than ⌊ n/3 ⌋ occurrences exist, so we must verify
    vector<int> ans;
    cnt1 = 0, cnt2 = 0;
    for (int num : nums) {
      if (num == maj1)
        ++cnt1;
      else if (num == maj2)
        ++cnt2;
    }
    int n = nums.size();
    if (cnt1 > n / 3) ans.push_back(maj1);
    if (cnt2 > n / 3) ans.push_back(maj2);

    return ans;
  }
};
