Uvod

Diskretizacija je tehnika obrade podataka koja se u suštini može promatrati kao vrsta hasha koja jamči da podaci nakon hashiranja i dalje zadržavaju izvorni potpuni/parcijalni uređaj.

Jednostavno rečeno, kad se neki podaci, zato što su sami po sebi veliki ili zato što im tip to ne podržava, ne mogu izravno upotrijebiti kao indeksi niza radi praktične obrade, a na konačan rezultat utječu samo odnosi relativne veličine među elementima, možemo problem obraditi tako da izvorne podatke zamijenimo njihovim rangom, što se zove diskretizacija.

Diskretizirati se mogu veliki cijeli brojevi, brojevi s pomičnim zarezom, stringovi itd.

Implementacija

Diskretizacija niza i zatim upiti nad njim razmjerno je čest scenarij primjene.

Prva metoda

Obično u izvornom nizu postoje ponovljeni elementi i jednaki se elementi u pravilu diskretiziraju u istu vrijednost.

Postupak je sljedeći:

  1. Napravi kopiju izvornog niza.

  2. Sortiraj vrijednosti u kopiji od najmanje do najveće.

  3. Iz sortirane kopije ukloni duplikate.

  4. Za svaki element izvornog niza pronađi njegov položaj u kopiji; položaj je rang, koji postaje diskretizirana vrijednost.

// arr[i] je početni niz, raspon indeksa je [1, n]

for (int i = 1; i <= n; ++i)  // korak 1
  tmp[i] = arr[i];
std::sort(tmp + 1, tmp + n + 1);                          // korak 2
int len = std::unique(tmp + 1, tmp + n + 1) - (tmp + 1);  // korak 3
for (int i = 1; i <= n; ++i)                              // korak 4
  arr[i] = std::lower_bound(tmp + 1, tmp + len + 1, arr[i]) - tmp;

Za STL algoritme upotrijebljene u referentnoj implementaciji pogledajte STL algoritme.

Na isti način možemo diskretizirati i std::vector:

// std::vector<int> arr;
std::vector<int> tmp(arr);  // tmp je kopija niza arr
std::sort(tmp.begin(), tmp.end());
tmp.erase(std::unique(tmp.begin(), tmp.end()), tmp.end());
for (int i = 0; i < n; ++i)
  arr[i] = std::lower_bound(tmp.begin(), tmp.end(), arr[i]) - tmp.begin();

Druga metoda

Ovisno o zahtjevima zadatka, jednaki se elementi ponekad diskretiziraju u različite vrijednosti prema redoslijedu unosa.

Tada je implementacija funkcijom std::lower_bound() nešto teža i treba promijeniti pristup:

  1. Napravi kopiju izvornog niza i ujedno zabilježi položaj pojavljivanja svakog elementa.

  2. Sortiraj kopiju po vrijednosti od najmanje do najveće; kad su vrijednosti jednake, sortiraj po redoslijedu pojavljivanja od manjeg do većeg.

  3. Vrati diskretizirane brojeve u izvorni niz.

struct Data {
  int idx, val;

  bool operator<(const Data& o) const {
    if (val == o.val)
      return idx < o.idx;  // kad su vrijednosti jednake, element koji se pojavio ranije dobiva manju diskretiziranu vrijednost
    return val < o.val;
  }
} tmp[MAXN];  // može se upotrijebiti i std::pair

for (int i = 1; i <= n; ++i) tmp[i] = Data{i, arr[i]};
std::sort(tmp + 1, tmp + n + 1);
for (int i = 1; i <= n; ++i) arr[tmp[i].idx] = i;

Složenost

Kod prve metode složenost uklanjanja duplikata je \(O(n)\), složenost sortiranja je \(O(n \log n)\), a složenost završnih \(n\) pretraživanja je \(O(n \log n)\).

Kod druge metode složenost sortiranja je \(O(n \log n)\).

Stoga je ukupna vremenska složenost obiju metoda \(O(n \log n)\).

Prostorna složenost je \(O(n)\).

Introduction

Discretization is a data-processing technique that can essentially be viewed as a kind of hashing which guarantees that the data still preserves its original total/partial order after hashing.

Put simply, when some data cannot conveniently be used directly as array indices, either because the values are very large or because their type does not support it, and only the relative order between elements affects the final result, we can process the problem using the ranks of the original data instead; this is discretization.

Large integers, floating-point numbers, strings, and so on can all be discretized.

Implementation

Discretizing an array and then performing queries on it is a fairly common use case.

Method 1

Usually the original array contains repeated elements, and equal elements are generally discretized to the same value.

The method is as follows:

  1. Create a copy of the original array.

  2. Sort the values in the copy in ascending order.

  3. Remove duplicates from the sorted copy.

  4. Find the position of every element of the original array in the copy; the position is the rank, which becomes the discretized value.

// arr[i] is the initial array, the index range is [1, n]

for (int i = 1; i <= n; ++i)  // step 1
  tmp[i] = arr[i];
std::sort(tmp + 1, tmp + n + 1);                          // step 2
int len = std::unique(tmp + 1, tmp + n + 1) - (tmp + 1);  // step 3
for (int i = 1; i <= n; ++i)                              // step 4
  arr[i] = std::lower_bound(tmp + 1, tmp + len + 1, arr[i]) - tmp;

For the STL algorithms used in the reference implementation, see STL algorithms.

Likewise, we can also discretize a std::vector:

// std::vector<int> arr;
std::vector<int> tmp(arr);  // tmp is a copy of arr
std::sort(tmp.begin(), tmp.end());
tmp.erase(std::unique(tmp.begin(), tmp.end()), tmp.end());
for (int i = 0; i < n; ++i)
  arr[i] = std::lower_bound(tmp.begin(), tmp.end(), arr[i]) - tmp.begin();

Method 2

Depending on the problem requirements, equal elements are sometimes discretized to different values according to their input order.

In that case implementing it with the std::lower_bound() function becomes somewhat difficult, and a different approach is needed:

  1. Create a copy of the original array and at the same time record the position where each element occurs.

  2. Sort the copy by value in ascending order; when values are equal, sort by order of occurrence in ascending order.

  3. Put the discretized numbers back into the original array.

struct Data {
  int idx, val;

  bool operator<(const Data& o) const {
    if (val == o.val)
      return idx < o.idx;  // when values are equal, the element that appears earlier gets the smaller discretized value
    return val < o.val;
  }
} tmp[MAXN];  // std::pair can be used as well

for (int i = 1; i <= n; ++i) tmp[i] = Data{i, arr[i]};
std::sort(tmp + 1, tmp + n + 1);
for (int i = 1; i <= n; ++i) arr[tmp[i].idx] = i;

Complexity

For method 1, removing duplicates has complexity \(O(n)\), sorting has complexity \(O(n \log n)\), and the final \(n\) lookups have complexity \(O(n \log n)\).

For method 2, sorting has complexity \(O(n \log n)\).

Hence the total time complexity of both methods is \(O(n \log n)\).

The space complexity is \(O(n)\).
