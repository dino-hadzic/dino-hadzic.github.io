Uvod

Područje primjene metode viseće linije (engl. hanging line / hoverline) podskup je područja primjene monotonog stoga. Konkretno, metoda viseće linije primjenjiva je na zadatke koji zadovoljavaju sljedeće uvjete:

  • pri obilasku niza treba održavati monotonu informaciju;
  • mogu se riješiti monotonim stogom;
  • nije potrebno binarno pretraživanje po monotonom stogu.

Čini se da je metoda viseće linije zamjenjiva i da nije osobito korisna, ali je pojmovno jednostavnija od monotonog stoga, pa je prikladnija početnicima u OI-ju za razumijevanje i rješavanje zadataka kao što je najveća podmatrica.

Primjeri zadataka

SPOJ HISTOGRA - Largest Rectangle in a Histogram

Ukratko: na vodoravnoj liniji stoji \(n\) pravokutnika širine \(1\); odredite površinu najvećeg podpravokutnika sadržanog u tim pravokutnicima.

Viseća linija okomita je dužina koja ima dva svojstva – početni položaj i visinu – i može se pomicati ulijevo i udesno sve dok njezin gornji kraj ne prelazi visinu pravokutnika na trenutačnom položaju.

Za jednu viseću liniju, uz uvjet da gornji kraj ne prelazi visinu pravokutnika na trenutačnom položaju i da ne izlazi iz granica, pomičemo je ulijevo i udesno i određujemo najdalje kamo se može proširiti ulijevo i udesno; površina koju je ta viseća linija pritom prebrisala najveći je mogući pravokutnik koji sadrži tu viseću liniju. Lako se vidi da najveći podpravokutnik nužno sadrži neku viseću liniju s početnim položajem \(i\) i visinom \(h_i\). Nabrajanjem taj proces ima vremensku složenost \(O(n ^ 2)\), ali metodom viseće linije možemo ga optimizirati na \(O(n)\).

Razmotrimo kako brzo pronaći krajnji lijevi položaj do kojeg viseća linija može doći.

Postupak

Definirajmo \(l_i\) kao trenutačno pronađeni krajnji lijevi položaj do kojeg se viseća linija na položaju \(i\) može proširiti; lako se vidi da je \(l_i\) na početku jednak \(i\), a dalje treba provjeriti može li se još proširiti ulijevo.

  • Ako je trenutačno \(l_i = 1\), došli smo do granice i ne može se.
  • Ako je trenutačno \(a_i > a_{l_i - 1}\), s položaja do kojeg je viseća linija proširena ne može se dalje ulijevo.
  • Ako je trenutačno \(a_i \le a_{l_i - 1}\), viseća linija može se još proširiti ulijevo, a kamo god se ulijevo može proširiti viseća linija na položaju \(l_i - 1\), sigurno može i viseća linija na položaju \(i\); stoga \(l_i\) ažuriramo na \(l_{l_i - 1}\) i nastavljamo s provjerom.

Amortiziranom analizom može se dokazati da će svaki \(l_i\) biti posjećen najviše jednom od strane drugih \(l_j\), pa je vremenska složenost \(O(n)\).

Implementacija

Primjer koda 
#include <algorithm>
#include <iostream>
using std::max;
constexpr int N = 100010;
int n, a[N];
int l[N], r[N];
long long ans;
using std::cin;
using std::cout;

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  while (cin >> n, n) {
    ans = 0;
    for (int i = 1; i <= n; i++) cin >> a[i], l[i] = r[i] = i;
    for (int i = 1; i <= n; i++)
      while (l[i] > 1 && a[i] <= a[l[i] - 1]) l[i] = l[l[i] - 1];
    for (int i = n; i >= 1; i--)
      while (r[i] < n && a[i] <= a[r[i] + 1]) r[i] = r[r[i] + 1];
    for (int i = 1; i <= n; i++)
      ans = max(ans, (long long)(r[i] - l[i] + 1) * a[i]);
    cout << ans << '\n';
  }
  return 0;
}
UVa1619 Feel Good

Za niz duljine \(n\) pronađite podinterval takav da je umnožak najmanjeg elementa podintervala i zbroja njegovih elemenata najveći; uz najveću vrijednost ugode treba minimizirati duljinu, a uz najmanju duljinu minimizirati indeks lijevog kraja.

U ovom zadatku možemo nabrajati najmanji element: broj \(a_i\) na svakom položaju uzmemo kao najmanji element i razmotrimo proširivanje od \(i\) ulijevo i udesno, tražeći što širi interval \([l, r]\) za koji vrijedi \(\min\limits _ {j = l} ^ r a_j = a_i\). Tako se zadatak svodi na model viseće linije.

Primjer koda 
#include <cstring>
#include <iostream>
constexpr int N = 100010;
int n, a[N], l[N], r[N];
long long sum[N];
long long ans;
int ansl, ansr;
bool fir = true;
using std::cin;
using std::cout;

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  while (cin >> n) {
    memset(a, -1, sizeof(a));
    if (!fir)
      cout << '\n';
    else
      fir = false;
    ans = 0;
    ansl = ansr = 1;
    for (int i = 1; i <= n; i++) {
      cin >> a[i];
      sum[i] = sum[i - 1] + a[i];
      l[i] = r[i] = i;
    }
    for (int i = 1; i <= n; i++)
      while (a[l[i] - 1] >= a[i]) l[i] = l[l[i] - 1];
    for (int i = n; i >= 1; i--)
      while (a[r[i] + 1] >= a[i]) r[i] = r[r[i] + 1];
    for (int i = 1; i <= n; i++) {
      long long x = a[i] * (sum[r[i]] - sum[l[i] - 1]);
      if (ans < x || (ans == x && ansr - ansl > r[i] - l[i]))
        ans = x, ansl = l[i], ansr = r[i];
    }
    cout << ans << '\n' << ansl << ' ' << ansr << '\n';
  }
  return 0;
}

Najveća podmatrica

P4147 玉蟾宫 (Palača žadne žabe)

Zadana je matrica \(n \times m\) koja sadrži znakove 'F' i 'R'; odredite površinu najveće podmatrice \(\times 3\), takve da je svaki element te podmatrice 'F'.

Primjećujemo da je model ovog zadatka vrlo sličan modelu prvog zadatka. Pažljivijom analizom vidimo: ako svaki put promatramo samo sve elemente jednog retka, a kao duljinu viseće linije na položaju \((x, y)\) uzmemo udaljenost do koje se element na tom položaju može proširiti prema gore, tada je najveća podmatrica nužno jedan od najvećih pravokutnika dobivenih proširivanjem tih visećih linija ulijevo i udesno.

Primjer koda 
#include <algorithm>
#include <iostream>
int m, n, a[1010], l[1010], r[1010], ans;
using std::cin;
using std::cout;

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> n >> m;
  for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
      l[j] = r[j] = j;
    }
    char s[3];
    for (int j = 1; j <= m; j++) {
      cin >> s;
      if (s[0] == 'F')
        a[j]++;
      else if (s[0] == 'R')
        a[j] = 0;
    }
    for (int j = 1; j <= m; j++)
      while (l[j] != 1 && a[l[j] - 1] >= a[j]) l[j] = l[l[j] - 1];
    for (int j = m; j >= 1; j--)
      while (r[j] != m && a[r[j] + 1] >= a[j]) r[j] = r[r[j] + 1];
    for (int j = 1; j <= m; j++) ans = std::max(ans, (r[j] - l[j] + 1) * a[j]);
  }
  cout << ans * 3;
  return 0;
}

Introduction

The scope of the hanging line method (also "hoverline") is a subset of that of the monotonic stack. Specifically, the hanging line method can be applied to problems that satisfy the following conditions:

  • monotonic information needs to be maintained while scanning a sequence;
  • they can be solved with a monotonic stack;
  • no binary search on the monotonic stack is needed.

It seems the hanging line method can be replaced and is not very useful, but its concept is simpler than that of the monotonic stack, so it is more suitable for beginners in OI to understand and solve problems such as the largest submatrix.

Example problems

SPOJ HISTOGRA - Largest Rectangle in a Histogram

In short: there are \(n\) rectangles of width \(1\) on a horizontal line; find the area of the largest sub-rectangle contained in these rectangles.

A hanging line is a vertical segment with two properties, an initial position and a height, and it can move left and right as long as its upper endpoint does not exceed the height of the rectangle at its current position.

For a hanging line, under the condition that its upper endpoint does not exceed the height of the rectangle at the current position and it does not move out of bounds, we move it left and right and find how far it can extend to the left and to the right at most; the area swept by this hanging line is then the largest possible rectangle containing this hanging line. It is easy to see that the largest sub-rectangle must contain a hanging line with initial position \(i\) and height \(h_i\). Implementing this process by enumeration has time complexity \(O(n ^ 2)\), but with the hanging line method we can optimize it to \(O(n)\).

Let us consider how to quickly find the leftmost position a hanging line can reach.

Process

Define \(l_i\) as the leftmost position found so far to which the hanging line at position \(i\) can extend; clearly \(l_i\) is initially \(i\), and we need to further check whether it can extend further to the left.

  • If currently \(l_i = 1\), we have reached the boundary and cannot.
  • If currently \(a_i > a_{l_i - 1}\), the position the current hanging line has extended to cannot extend further to the left.
  • If currently \(a_i \le a_{l_i - 1}\), the current hanging line can extend further to the left, and wherever the hanging line at position \(l_i - 1\) can extend to the left, the hanging line at position \(i\) can certainly extend as well, so we update \(l_i\) to \(l_{l_i - 1}\) and continue checking.

By amortized analysis, it can be proved that each \(l_i\) is visited at most once by other \(l_j\), so the time complexity is \(O(n)\).

UVa1619 Feel Good

For a sequence of length \(n\), find a subarray such that the product of the minimum value in the subarray and the sum of its elements is maximized; among those with the maximum comfort value minimize the length, and among those with the minimum length minimize the index of the left endpoint.

In this problem we can enumerate the minimum value: treat the number \(a_i\) at each position as the minimum, and consider extending from \(i\) to the left and right to find the widest possible range \([l, r]\) satisfying \(\min\limits _ {j = l} ^ r a_j = a_i\). Thus the problem is transformed into the hanging line model.

Largest submatrix

P4147 玉蟾宫 (Jade Toad Palace)

Given an \(n \times m\) matrix containing 'F' and 'R', find the area of its largest submatrix \(\times 3\) such that every cell of this submatrix is 'F'.

We notice that the model of this problem is very similar to the model of the first problem. On closer analysis, if we consider only all elements of one row at a time, and take the distance an element at position \((x, y)\) can extend upward as the hanging line length at that position, then the largest submatrix must be one of the largest rectangles obtained by extending these hanging lines to the left and right.

#include <iostream>
