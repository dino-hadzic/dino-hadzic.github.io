Ova stranica kratko predstavlja tehniku dvostrukih pokazivača (two pointers).

Uvod

Dvostruki pokazivači jednostavna su, a opet fleksibilna tehnika i ideja: sami lako rješavaju neke specifične probleme, a u kombinaciji s drugim algoritmima imaju raznovrsne primjene.

Kao što ime kaže, dvostruki pokazivači znače istodobnu upotrebu dvaju pokazivača; u nizovima i vezanim listama pokazuju na položaje, a u stablima i grafovima na čvorove, te se pomiču u istom smjeru ili jedan prema drugome kako bi se održavale i prikupljale informacije.

Pogledajmo sada nekoliko konkretnih načina upotrebe dvostrukih pokazivača.

Održavanje informacije o intervalu

Ako se ne kombiniraju s drugim strukturama podataka, najjednostavniji oblik održavanja informacije o intervalu dvostrukim pokazivačima jest održavanje informacije koja ima određenu monotonost i kod koje je dodavanje i uklanjanje jednog elementa lako obraditi, kao što su zbroj pozitivnih brojeva, umnožak pozitivnih cijelih brojeva itd.

Primjer 1

Primjer 1 LeetCode 713. Podnizovi s umnoškom manjim od K

Zadan je niz pozitivnih cijelih brojeva \(\mathit{nums}\) duljine \(n\) i cijeli broj \(k\); odredite broj uzastopnih podnizova tog niza čiji je umnožak manji od \(k\).

Pri tome je \(1 \leq n \leq 3 \times 10^4, 1 \leq nums[i] \leq 1000, 0 \leq k \leq 10^6\).

Postupak

Neka su dva pokazivača \(l,r\), a dodatna varijabla \(\mathit{tmp}\) pamti umnožak svih brojeva u \([l,r]\). Na početku su \(l,r\) oba skroz lijevo; prvo pomičemo \(r\) udesno dok prvi put ne otkrijemo \(\mathit{tmp}\geq k\), tada fiksiramo \(r\) i pomičemo \(l\) udesno dok ne bude \(\mathit{tmp}\lt k\). Tako je za svaki \(r\) pokazivač \(l\) lijeva granica do koje se može proširiti, a zbog monotonosti umnoška pozitivnih cijelih brojeva broj intervala s desnim krajem \(r\) koji zadovoljavaju uvjet zadatka iznosi \(r-l+1\).

Implementacija

int numSubarrayProductLessThanK(vector<int>& nums, int k) {
  long long ji = 1ll, ans = 0;
  int l = 0;
  for (int i = 0; i < nums.size(); ++i) {
    ji *= nums[i];
    while (l <= i && ji >= k) ji /= nums[l++];
    ans += i - l + 1;
  }
  return ans;
}

Održavanje informacije o intervalu dvostrukim pokazivačima može se kombinirati i s drugim strukturama podataka, poput razlika (difference array), monotonog reda, segment treea, perzistentnog segment treea itd. Osim toga, tehniku dvostrukih pokazivača u algoritam ugrađuje i Mo algoritam: u Mo algoritmu se upiti offline sortiraju, a zatim se u pravilu dvama pokazivačima bilježi interval koji se trenutačno obrađuje te se informacija o intervalu postupno ažurira kako se pokazivači korak po korak pomiču.

Primjer 2

Pogledajmo sada primjer upotrebe dvostrukih pokazivača na stablu u kombinaciji s razlikama na stablu:

Primjer 2 Luogu P3066 Running Away From the Barn G

Zadano je korijensko stablo s \(n\) čvorova, bridovi imaju težine, čvorovi su označeni brojevima od 1 do \(n\), a čvor 1 je korijen stabla. Zadan je i parametar \(t\); za svaki čvor \(u\) stabla odredite koliko čvorova u podstablu čvora \(u\) ima udaljenost do \(u\) ne veću od \(t\). Ograničenja: \(1\leq n \leq 2\times 10^5,1 \leq t \leq 10^{18},1 \leq p_i \lt i,1 \leq w_i \leq 10^{12}\)

Postupak

Od korijena DFS-om obilazimo cijelo stablo i stogom pamtimo lanac od korijena do trenutačnog čvora; jedan pokazivač \(u\) pokazuje na trenutačni čvor, a drugi pokazivač \(p\) na čvor najmanje dubine među čvorovima čija udaljenost do \(u\) nije veća od \(t\). Pamtimo udaljenosti do korijena i svaki put binarnim pretraživanjem određujemo \(p\). Tada \(u\) daje doprinos svakom čvoru na putu od \(p\) do \(u\), što se može zabilježiti razlikama na stablu.
Pazite da se \(p\) ne smije izravno pomicati grubom silom, jer bi se vremenska složenost mogla degradirati na \(O(n^2)\).

Primjer 3 LeetCode 524. Najdulja riječ iz rječnika dobivena brisanjem slova

Zadan je string \(s\) i niz stringova \(\mathit{dictionary}\) kao rječnik; pronađite i vratite najdulji string iz rječnika koji se može dobiti brisanjem nekih znakova iz \(s\).

Postupak

U ovoj vrsti problema treba usporediti stringove \(s\) i \(t\) i odrediti je li \(t\) podniz (subsequence) stringa \(s\). Za rješenje je dovoljno prvo postaviti dva pokazivača, jedan \(i\) na početak \(s\), a drugi \(j\) na početak \(t\). Ako je \(s[i]=t[j]\), to znači da je za \(j\)-ti znak stringa \(t\) pronađen prvi odgovarajući znak u \(s\) i može se nastaviti provjeravati ostatak, pa se \(i\) i \(j\) istodobno uvećaju za jedan. Ako navedena jednakost ne vrijedi, \(j\)-ti znak stringa \(t\) još nije uparen, pa se uvećava samo \(i\) i traži se dalje u ostatku stringa \(s\). Na kraju, ako je \(j\) došao do položaja iza posljednjeg znaka, cijeli se string može upariti, tj. \(t\) je podniz stringa \(s\); inače nije.

Implementacija

string findLongestWord(string s, vector<string>& dictionary) {
  sort(dictionary.begin(), dictionary.end());
  int mx = 0, r = 0;
  string ans = "";
  for (int i = dictionary.size() - 1; i >= 0; i--) {
    r = 0;
    for (int j = 0; j < s.length(); ++j) {
      if (s[j] == dictionary[i][r]) r++;
    }
    if (r == dictionary[i].length()) {
      if (r >= mx) {
        mx = r;
        ans = dictionary[i];
      }
    }
  }
  return ans;
}

Ovaj način, u kojem dva pokazivača pokazuju na različite objekte koji se zatim postupno uspoređuju, može se primijeniti i u nekim DP-ovima.

Iskorištavanje sortiranosti niza

Vrlo često dvostruki pokazivači na nizu ispravno postižu cilj upravo zbog nekih svojstava niza, a najčešće se iskorištava sortiranost niza.

Primjer 4 LeetCode 167. Zbroj dvaju brojeva II – ulazni niz je sortiran

Zadan je niz cijelih brojeva numbers sortiran uzlazno; pronađite u njemu dva broja čiji je zbroj jednak ciljnom broju target.

Postupak

I ovaj je problem klasična primjena dvostrukih pokazivača; iako je i binarno pretraživanje praktično, ono u vremenskoj složenosti ima dodatni faktor \(\log{n}\), a kod nije dovoljno sažet.

Predstavimo pristup dvostrukim pokazivačima: budući da tražimo dva broja koji ne mogu biti na istom položaju, njihovi su položaji nužno jedan lijevo, a drugi desno. Budući da je zbroj dvaju brojeva fiksan, što je manji od njih veći, to je veći od njih manji. Uzimajući u obzir ta svojstva, možemo im se približavati s obaju krajeva.

Prvo pretpostavimo da je odgovor upravo 1 i n. Ako otkrijemo \(num[1]+num[n]\gt \mathit{target}\), znači da jedan od elemenata treba smanjiti, a \(\mathit{num}[1]\) se više ne može smanjiti, pa pokazivač koji pokazuje na \(n\) umanjimo za jedan kako bi se veći broj smanjio.

Slično, ako otkrijemo \(num[1]+num[n]\lt \mathit{target}\), znači da jedan od elemenata treba povećati, a \(\mathit{num}[n]\) se više ne može povećati, pa pokazivač koji pokazuje na 1 uvećamo za jedan kako bi se manji broj povećao.

Poopćeno: ako dva pokazivača trenutačno pokazuju na \(l,r\) i vrijedi \(l\lt r\), onda ako je \(num[l]+num[r]\gt \mathit{target}\), umanjimo \(r\) za jedan, a ako je \(num[l]+num[r]\lt \mathit{target}\), uvećamo \(l\) za jedan. Tako se \(l\) stalno pomiče udesno, \(r\) stalno ulijevo i na kraju se oba približe odgovoru.

Implementacija

vector<int> twoSum(vector<int>& numbers, int target) {
  int r = numbers.size() - 1, l = 0;
  vector<int> ans;
  ans.clear();
  while (l < r) {
    if (numbers[l] + numbers[r] > target)
      r--;
    else if (numbers[l] + numbers[r] == target) {
      ans.push_back(l + 1), ans.push_back(r + 1);
      return ans;
    } else
      l++;
  }
  return ans;
}

I spajanje dvaju sortiranih nizova u vremenu \(O(n+m)\) u merge sortu primjena je dvostrukih pokazivača pod uvjetom sortiranosti nizova.

Zadaci za vježbu

LeetCode 15. Zbroj triju brojeva

Pronalaženje ciklusa u jednostruko vezanoj listi

Postupak

I za pronalaženje ciklusa u jednostruko vezanoj listi postoji više načina, ali metoda sporog i brzog pokazivača jedna je od najsažetijih; predstavljamo je u nastavku.

Najprije oba pokazivača pokazuju na glavu liste; jedan pokazivač pomiče se po jedan korak, a drugi po dva koraka. Ako se sretnu, dokazano je da ciklus postoji, inače ciklusa nema; vremenska složenost je \(O(n)\).

Ako ciklus postoji, kako pronaći njegov početak?

Zapišimo jednadžbe i promotrimo ih. Neka je u trenutku susreta spori pokazivač napravio ukupno \(k\) koraka, od toga \(l\) koraka na ciklusu (kad se brzi i spori pokazivač sretnu na ciklusu, spori sigurno nije prošao cijeli krug). Brzi pokazivač napravio je \(2k\) koraka; neka je duljina ciklusa \(C\), tada vrijedi

\[ \begin{align} & \ 2 k=n \times C+l+(k-l) \\ & \ k=n \times C \\ \end{align} \]

Pri prvom susretu \(n\) je najmanji pozitivni cijeli broj 1. Drugim riječima, \(k=C\). Koristeći tu jednakost, nakon što se dva pokazivača sretnu možemo jedan od njih premjestiti na glavu liste i oba pomicati po jedan korak; mjesto na kojem se ponovno sretnu početak je ciklusa.

Implementacija

pair<bool, vector<int>> findCycle(
    vector<int>
        nxt)  // nxt[i] je čvor na koji i pokazuje u jednostruko vezanoj listi (0-indeksirano), -1 znači da ne pokazuje ni na jedan čvor
{
  int fast = 0, slow = 0;
  do  // prvo provjeri postoji li ciklus
  {
    if (nxt[fast] == -1 || nxt[nxt[fast]] == -1) {
      return make_pair(false, vector<int>());  // nema ciklusa
    }
    fast = nxt[nxt[fast]];
    slow = nxt[slow];
  } while (fast != slow);
  slow = 0;
  while (slow != fast)  // zatim pronađi ulaz u ciklus
  {
    slow = nxt[slow];
    fast = nxt[fast];
  }
  vector<int> cycle;
  do  // na kraju pronađi cijeli ciklus
  {
    cycle.push_back(slow);
    slow = nxt[slow];
  } while (slow != fast);
  return make_pair(true, cycle);
}

Vremenska složenost je \(O(n)\).

This page briefly introduces the two-pointer technique.

Introduction

Two pointers is a simple yet flexible technique and idea: used alone it easily solves some specific problems, and combined with other algorithms it has a variety of uses.

As the name suggests, two pointers means using two pointers at the same time; in sequences and linked lists they point to positions, in trees and graphs they point to nodes, and they move either in the same direction or toward each other in order to maintain and collect information.

Let us now look at several concrete ways of using two pointers.

Maintaining information about a range

When not combined with other data structures, the simplest pattern of maintaining range information with two pointers is to maintain information that has a certain monotonicity and for which adding and removing one element is easy to handle, such as the sum of positive numbers, the product of positive integers, and so on.

Example 1

Example 1 LeetCode 713. Subarray Product Less Than K

Given an array of positive integers \(\mathit{nums}\) of length \(n\) and an integer \(k\), find the number of contiguous subarrays of the array whose product is less than \(k\).

Here \(1 \leq n \leq 3 \times 10^4, 1 \leq nums[i] \leq 1000, 0 \leq k \leq 10^6\).

Procedure

Let the two pointers be \(l,r\), and let an additional variable \(\mathit{tmp}\) record the product of all numbers in \([l,r]\). Initially \(l,r\) are both at the far left; first move \(r\) to the right until we find \(\mathit{tmp}\geq k\) for the first time, then fix \(r\) and move \(l\) to the right until \(\mathit{tmp}\lt k\). Then for each \(r\), \(l\) is the left boundary it can extend to, and by the monotonicity of the product of positive integers, the number of ranges with right endpoint \(r\) that satisfy the condition of the problem is \(r-l+1\).

Implementation

int numSubarrayProductLessThanK(vector<int>& nums, int k) {
  long long ji = 1ll, ans = 0;
  int l = 0;
  for (int i = 0; i < nums.size(); ++i) {
    ji *= nums[i];
    while (l <= i && ji >= k) ji /= nums[l++];
    ans += i - l + 1;
  }
  return ans;
}

Maintaining range information with two pointers can also be combined with other data structures such as difference arrays, monotonic queues, segment trees, persistent segment trees, and so on. Another algorithm that incorporates the two-pointer technique is Mo's algorithm: in Mo's algorithm the queries are sorted offline, and then two pointers are typically used to record the range currently being processed, with the range information gradually updated as the pointers move step by step.

Example 2

Next, let us look at an example that uses two pointers on a tree together with tree difference arrays:

Example 2 Luogu P3066 Running Away From the Barn G

Given a rooted tree with \(n\) nodes with weighted edges, the nodes are numbered from 1 to \(n\), and node 1 is the root of the tree. A parameter \(t\) is also given; for every node \(u\) of the tree, find how many nodes in the subtree of \(u\) have a distance to \(u\) not greater than \(t\). Constraints: \(1\leq n \leq 2\times 10^5,1 \leq t \leq 10^{18},1 \leq p_i \lt i,1 \leq w_i \leq 10^{12}\)

Procedure

Traverse the whole tree with DFS from the root, using a stack to record the chain from the root to the current node; let one pointer \(u\) point to the current node and another pointer \(p\) point to the node of minimum depth among the nodes whose distance to \(u\) is not greater than \(t\). Record the distances to the root and determine \(p\) by binary search each time. Then \(u\) contributes to every node on the path from \(p\) to \(u\), which can be recorded with tree difference arrays.
Note that \(p\) must not be moved directly by brute force, otherwise the time complexity may degrade to \(O(n^2)\).

Subsequence matching

Example 3 LeetCode 524. Longest Word in Dictionary through Deleting

Given a string \(s\) and an array of strings \(\mathit{dictionary}\) as a dictionary, find and return the longest string in the dictionary that can be obtained by deleting some characters of \(s\).

Procedure

This kind of problem requires matching the strings \(s\) and \(t\) and deciding whether \(t\) is a subsequence of \(s\). To solve it, first place two pointers, one \(i\) at the start of \(s\) and one \(j\) at the start of \(t\). If \(s[i]=t[j]\), the \(j\)-th character of \(t\) has found its first match in \(s\), so we can go on to check the rest, and \(i\) and \(j\) are both incremented by one. If the above equality does not hold, the \(j\)-th character of \(t\) is still unmatched, so only \(i\) is incremented and we continue searching in the remainder of \(s\). Finally, if \(j\) has moved to the past-the-end position, the whole string can be matched, i.e. \(t\) is a subsequence of \(s\); otherwise it is not.

Implementation

string findLongestWord(string s, vector<string>& dictionary) {
  sort(dictionary.begin(), dictionary.end());
  int mx = 0, r = 0;
  string ans = "";
  for (int i = dictionary.size() - 1; i >= 0; i--) {
    r = 0;
    for (int j = 0; j < s.length(); ++j) {
      if (s[j] == dictionary[i][r]) r++;
    }
    if (r == dictionary[i].length()) {
      if (r >= mx) {
        mx = r;
        ans = dictionary[i];
      }
    }
  }
  return ans;
}

This approach, where two pointers point to different objects which are then compared step by step, can also be used in some DP problems.

Exploiting the sortedness of a sequence

Very often, the reason two pointers on a sequence correctly achieve their goal is some property of the sequence, and the most common one exploited is that the sequence is sorted.

Example 4 LeetCode 167. Two Sum II - Input Array Is Sorted

Given an integer array numbers sorted in ascending order, find two numbers in the array whose sum equals the target number target.

Procedure

This problem is also a classic application of two pointers; although binary search is convenient too, it has an extra factor of \(\log{n}\) in the time complexity, and the code is not concise enough.

Here is the two-pointer approach: since we need to find two numbers, and they cannot be at the same position, one of them must be on the left and the other on the right. Since the sum of the two numbers is fixed, the larger the smaller number is, the smaller the larger number is. Taking these properties into account, we can approach them from both ends.

First assume the answer is 1 and n. If we find \(num[1]+num[n]\gt \mathit{target}\), one of the elements needs to become smaller, and \(\mathit{num}[1]\) cannot become any smaller, so we decrement the pointer pointing to \(n\) by one to make the larger number smaller.

Similarly, if we find \(num[1]+num[n]\lt \mathit{target}\), one of the elements needs to become larger, and \(\mathit{num}[n]\) cannot become any larger, so we increment the pointer pointing to 1 by one to make the smaller number larger.

Generalizing: if our two pointers currently point to \(l,r\) with \(l\lt r\), then if \(num[l]+num[r]\gt \mathit{target}\), decrement \(r\) by one, and if \(num[l]+num[r]\lt \mathit{target}\), increment \(l\) by one. In this way \(l\) keeps moving right and \(r\) keeps moving left, and in the end both converge to an answer.

Implementation

vector<int> twoSum(vector<int>& numbers, int target) {
  int r = numbers.size() - 1, l = 0;
  vector<int> ans;
  ans.clear();
  while (l < r) {
    if (numbers[l] + numbers[r] > target)
      r--;
    else if (numbers[l] + numbers[r] == target) {
      ans.push_back(l + 1), ans.push_back(r + 1);
      return ans;
    } else
      l++;
  }
  return ans;
}

In merge sort, merging two sorted arrays in \(O(n+m)\) time is also an application of the two-pointer method that relies on the arrays being sorted.

Exercises

LeetCode 15. 3Sum

Finding a cycle in a singly linked list

Procedure

There are also several ways to find a cycle in a singly linked list, but the fast and slow pointer method is one of the most concise, and we introduce it below.

First, both pointers point to the head of the list; let one pointer advance one step at a time and the other two steps at a time. If they meet, this proves there is a cycle; otherwise there is none. The time complexity is \(O(n)\).

If there is a cycle, how do we find its starting point?

Let us write out the equations and take a look. Suppose that at the moment they meet, the slow pointer has taken \(k\) steps in total, of which \(l\) steps were on the cycle (when the fast and slow pointers meet on the cycle, the slow pointer has certainly not completed a full lap). The fast pointer has taken \(2k\) steps; let the cycle length be \(C\), then

\[ \begin{align} & \ 2 k=n \times C+l+(k-l) \\ & \ k=n \times C \\ \end{align} \]

At the first meeting, \(n\) takes the smallest positive integer value 1. That is, \(k=C\). Using this equality, after the two pointers meet we can move one of them to the head of the list and advance both one step at a time; the position where they meet again is the start of the cycle.

Implementation

pair<bool, vector<int>> findCycle(
    vector<int>
        nxt)  // nxt[i] is the node that i points to in the singly linked list (0-indexed), -1 means it points to no node
{
  int fast = 0, slow = 0;
  do  // first check whether there is a cycle
  {
    if (nxt[fast] == -1 || nxt[nxt[fast]] == -1) {
      return make_pair(false, vector<int>());  // no cycle
    }
    fast = nxt[nxt[fast]];
    slow = nxt[slow];
  } while (fast != slow);
  slow = 0;
  while (slow != fast)  // then find the entry point of the cycle
  {
    slow = nxt[slow];
    fast = nxt[fast];
  }
  vector<int> cycle;
  do  // finally find the whole cycle
  {
    cycle.push_back(slow);
    slow = nxt[slow];
  } while (slow != fast);
  return make_pair(true, cycle);
}

The time complexity is \(O(n)\).
