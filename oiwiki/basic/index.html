Algoritam je, kako mu i ime kaže, postupak računanja. Algoritmi se obično koriste za rješavanje određenog računskog zadatka, no, za razliku od programa koji se može izravno izvršiti na računalu, algoritam se opisuje matematički, više je usmjeren na ideju i može se smatrati apstraktnim programom. Isti algoritam može se implementirati na mnogo različitih načina, a dva različita programa mogu koristiti isti algoritam.

Ovo poglavlje predstavlja neke osnovne algoritme. Kad je neki računski zadatak dovoljno općenit da se pojavljuje u raznim problemima, algoritam koji ga rješava pozivaju mnogi drugi algoritmi, pa je on iznimno važan i temeljan. Istodobno, što je algoritam općenitiji, to je obično sažetiji i bliži ideji nego programu. Algoritmi predstavljeni u ovom poglavlju dovoljno su elegantni i zanimljivi, a često će se pojavljivati i u naprednijem gradivu koje slijedi.

An algorithm is, as the name suggests, a method of computation. Algorithms are usually used to solve a specific computational task, but unlike a program that can be run directly on a computer, an algorithm is described mathematically, focuses more on the idea, and can be seen as an abstract program. The same algorithm can be implemented in many different ways, and two different programs may use the same algorithm.

This chapter introduces some fundamental algorithms. When a computational task is general enough to appear widely in all kinds of problems, the algorithm that solves it gets called by many other algorithms, and so it is of considerable importance and a true fundamental. At the same time, the more general an algorithm is, the more concise it usually is, and the closer it is to an idea rather than a program. The algorithms introduced in this chapter are elegant and interesting enough, and they will also appear frequently in the more advanced material that follows.
