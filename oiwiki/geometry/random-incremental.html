Uvod

Randomizirani inkrementalni algoritam važan je algoritam računalne geometrije: ne zahtijeva mnogo teorijskog znanja, ima nisku vremensku složenost i širok raspon primjena.

Ideja inkrementalnog algoritma (incremental algorithm) slična je prvom načelu matematičke indukcije; u biti se problem svodi na potproblem točno za jednu razinu manji. Nakon što riješimo potproblem, dodajemo trenutačni objekt. Zapisano kao rekurzija:

\[ T(n)=T(n-1)+g(n) \]

Inkrementalni je algoritam jednostavna oblika i može se primijeniti na mnoge geometrijske zadatke.

Inkrementalni se algoritam često kombinira s randomizacijom, čime dobivamo randomizirani inkrementalni algoritam.

Ideja randomiziranog inkrementalnog algoritma glasi: pri svakom dodavanju novog objekta, ako se odgovor promijeni, lokalno ga ponovno izračunamo. Zato randomizirani inkrementalni algoritam obično zahtijeva da se lako i brzo može provjeriti mijenja li dodavanje elementa odgovor te da je u slučajnom redoslijedu očekivani broj promjena odgovora malen.

Randomizirani inkrementalni algoritam često se koristi za rješavanje problema najmanje obuhvatne kružnice, a može se primijeniti i na presjek poluprostora, konveksnu ljusku u višim dimenzijama, randomiziranu Delaunayjevu triangulaciju i druge probleme.

Introduction

The randomized incremental algorithm is an important algorithm in computational geometry: it does not require much theoretical background, has low time complexity, and has a wide range of applications.

The idea of the incremental algorithm is similar to the first principle of mathematical induction; in essence, it reduces a problem to a subproblem exactly one level smaller. After solving the subproblem, the current object is added. Written as a recurrence:

\[ T(n)=T(n-1)+g(n) \]

The incremental algorithm has a concise form and can be applied to many geometry problems.

The incremental algorithm is often combined with randomization, giving the randomized incremental algorithm.

The idea of the randomized incremental algorithm is: each time a new object is added, if it changes the answer, recompute locally. Therefore, the randomized incremental algorithm usually requires that it be easy to quickly decide whether adding an element changes the answer, and that the expected number of answer changes under a random order be small.

The randomized incremental algorithm is commonly used to solve the smallest enclosing circle problem, and can also be used to solve half-space intersection, higher-dimensional convex hulls, randomized Delaunay triangulation, and other problems.
