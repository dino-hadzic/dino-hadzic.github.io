Uvod

Interpolacija je metoda kojom se iz poznatih, diskretnih podatkovnih točaka procjenjuju nove podatkovne točke unutar određenog raspona. Interpolacija se često koristi pri prilagodbi (fitting) funkcija.

Na primjer, za podatkovne točke:

\(x\) \(0\) \(1\) \(2\) \(3\) \(4\) \(5\) \(6\)
\(f(x)\) \(0\) \(0.8415\) \(0.9093\) \(0.1411\) \(-0.7568\) \(-0.9589\) \(-0.2794\)

gdje je \(f(x)\) nepoznata, interpolacijom se nepoznate podatkovne točke mogu procijeniti tako da se \(f(x)\) prilagodi u nekom zadanom obliku.

Na primjer, \(f(x)\) možemo prilagoditi po dijelovima linearnom funkcijom:

Takav se način interpolacije naziva linearna interpolacija.

Također možemo \(f(x)\) prilagoditi polinomom:

Takav se način interpolacije naziva polinomna interpolacija.

Opći oblik polinomne interpolacije glasi:

Polinomna interpolacija

Za poznatih \(n+1\) točaka \((x_0,y_0),(x_1,y_1),\dots,(x_n,y_n)\) pronaći polinom oblika \(f(x)=\sum_{i=0}^n a_ix^i\) koji zadovoljava

\[ f(x_i)=y_i,\qquad\forall i=0,1,\dots,n \]

to jest, traženi polinom \(f(x)\).

U nastavku predstavljamo dva načina polinomne interpolacije: Lagrangeovu interpolaciju i Newtonovu interpolaciju. Nije teško dokazati da obje metode daju jednake rezultate.

Lagrangeova interpolacija

Treba konstruirati funkciju \(f(x)\) koja prolazi točkama \(P_1(x_1, y_1), P_2(x_2,y_2),\cdots,P_n(x_n,y_n)\). Najprije neka je projekcija \(i\)-te točke na os \(x\) točka \(P_i^{\prime}(x_i,0)\).

Razmotrimo konstrukciju \(n\) funkcija \(f_1(x), f_2(x), \cdots, f_n(x)\) takvih da graf \(i\)-te funkcije \(f_i(x)\) prolazi točkama \(\begin{cases}P_j^{\prime}(x_j,0),(j\neq i)\\P_i(x_i,y_i)\end{cases}\); tada je tražena funkcija \(f(x)=\sum\limits_{i=1}^nf_i(x)\).

Možemo staviti \(f_i(x)=a\cdot\prod_{j\neq i}(x-x_j)\); uvrštavanjem točke \(P_i(x_i,y_i)\) dobivamo \(a=\dfrac{y_i}{\prod_{j\neq i} (x_i-x_j)}\), pa je

\[ f_i(x)=y_i\cdot\dfrac{\prod_{j\neq i} (x-x_j)}{\prod_{j\neq i} (x_i-x_j)}=y_i\cdot\prod_{j\neq i}\dfrac{x-x_j}{x_i-x_j} \]

Tako dobivamo oblik Lagrangeove interpolacije:

\[ f(x)=\sum_{i=1}^ny_i\cdot\prod_{j\neq i}\dfrac{x-x_j}{x_i-x_j} \]

Vremenska složenost naivne implementacije je \(O(n^2)\), a može se optimizirati na \(O(n\log^2 n)\); vidi brzu interpolaciju polinoma.

Luogu P4781【模板】拉格朗日插值 (Predložak: Lagrangeova interpolacija)

Zadano je \(n\) parova točaka \((x_i,y_i)\) i \(k\), pri čemu \(\forall i,j\) vrijedi \(i\neq j \iff x_i\neq x_j\), te \(f(x_i)\equiv y_i\pmod{998244353}\) i \(\deg(f(x)) < n\) (definiramo \(\deg(0)=-\infty\)). Izračunajte \(f(k)\bmod{998244353}\).

Rješenje

U ovom zadatku treba izračunati samo vrijednost \(f(k)\), pa pri računanju gornjeg izraza možemo izravno uvrstiti \(k\); ponekad je pak potrebno više puta računati vrijednosti ili provoditi složenije operacije, i tada treba odrediti koeficijente polinoma \(f\). Kôd daje jednu implementaciju koja računa koeficijente.

\[ f(k)=\sum_{i=1}^{n}y_i\prod_{j\neq i }\frac{k-x_j}{x_i-x_j} \]

U ovom zadatku treba računati i inverze. Ako najprije zasebno izračunamo brojnik i nazivnik, a zatim brojnik pomnožimo inverzom nazivnika i pribrojimo konačnom odgovoru, usko grlo vremenske složenosti neće biti računanje inverza, pa je vremenska složenost \(O(n^2)\).

Budući da računamo uz fiksni modul \(998244353\), vremensku složenost računanja multiplikativnog inverza ovdje privremeno smatramo konstantnom.

Implementacija 
#include <iostream>
#include <vector>

constexpr int MOD = 998244353;
using LL = long long;

int inv(int k) {
  int res = 1;
  for (int e = MOD - 2; e; e /= 2) {
    if (e & 1) res = (LL)res * k % MOD;
    k = (LL)k * k % MOD;
  }
  return res;
}

// vraća f takav da je f(x_i) = y_i
// ne računajući vrijeme za multiplikativne inverze, očito O(n^2)
std::vector<int> lagrange_interpolation(const std::vector<int> &x,
                                        const std::vector<int> &y) {
  const int n = x.size();
  std::vector<int> M(n + 1), px(n, 1), f(n);
  M[0] = 1;
  // izračunaj M(x) = prod_(i=0..n-1)(x - x_i)
  for (int i = 0; i < n; ++i) {
    for (int j = i; j >= 0; --j) {
      M[j + 1] = (M[j] + M[j + 1]) % MOD;
      M[j] = (LL)M[j] * (MOD - x[i]) % MOD;
    }
  }
  // izračunaj px_i = prod_(j=0..n-1, j!=i) (x_i - x_j)
  for (int i = 0; i < n; ++i) {
    for (int j = 0; j < n; ++j)
      if (i != j) {
        px[i] = (LL)px[i] * (x[i] - x[j] + MOD) % MOD;
      }
  }
  // složi f(x) = sum_(i=0..n-1)(y_i / px_i)(M(x) / (x - x_i))
  for (int i = 0; i < n; ++i) {
    LL t = (LL)y[i] * inv(px[i]) % MOD, k = M[n];
    for (int j = n - 1; j >= 0; --j) {
      f[j] = (f[j] + k * t) % MOD;
      k = (M[j] + k * x[i]) % MOD;
    }
  }
  return f;
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  int n, k;
  std::cin >> n >> k;
  std::vector<int> x(n), y(n);
  for (int i = 0; i < n; ++i) std::cin >> x[i] >> y[i];
  const auto f = lagrange_interpolation(x, y);
  int v = 0;
  for (int i = n - 1; i >= 0; --i) v = ((LL)v * k + f[i]) % MOD;
  std::cout << v << '\n';
  return 0;
}

Lagrangeova interpolacija kad su apscise uzastopni cijeli brojevi

Ako su apscise poznatih točaka uzastopni cijeli brojevi, interpolaciju možemo provesti u \(O(n)\).

Neka je traženi polinom \(f(x)\) i neka su poznati \(f(1),\cdots,f(n+1)\) (\(1\le i\le n+1\)); uvrstimo ih u gornju interpolacijsku formulu:

\[ \begin{aligned} f(x)&=\sum\limits_{i=1}^{n+1}y_i\prod\limits_{j\ne i}\frac{x-x_j}{x_i-x_j}\\ &=\sum\limits_{i=1}^{n+1}y_i\prod\limits_{j\ne i}\frac{x-j}{i-j} \end{aligned} \]

U produktu na kraju brojnik i nazivnik možemo promatrati zasebno; lako se dobiva da je brojnik:

\[ \dfrac{\prod\limits_{j=1}^{n+1}(x-j)}{x-i} \]

Produkt \(i-j\) u nazivniku može se rastaviti na dva faktorijela:

\[ (-1)^{n+1-i}\cdot(i-1)!\cdot(n+1-i)! \]

Tako dobivamo interpolacijsku formulu za apscise \(1,\cdots,n+1\):

\[ f(x)=\sum\limits_{i=1}^{n+1}(-1)^{n+1-i}y_i\cdot\frac{\prod\limits_{j=1}^{n+1}(x-j)}{(i-1)!(n+1-i)!(x-i)} \]

Unaprijed izračunamo prefiksne i sufiksne produkte od \((x-i)\), faktorijele i inverze faktorijela, zatim uvrstimo u ovu formulu; složenost je \(O(n)\).

Primjer zadatka CF622F The Sum of the k-th Powers

Zadani su \(n,k\); izračunajte \(\sum\limits_{i=1}^ni^k\) modulo \(10^9+7\).

Rješenje

U ovom je zadatku odgovor polinom stupnja \(k+1\), pa linearnim sitom možemo izračunati vrijednosti \(1^i,\cdots,(k+2)^i\) i zatim provesti interpolaciju u \(O(n)\).

Može se, znanjem iz kombinatorike, iz formule metode razlika izvesti i sljedeći izraz:

\[ f(x)=\sum_{i=1}^{n+1}\binom{x-1}{i-1}\sum_{j=1}^{i}(-1)^{i+j}\binom{i-1}{j-1}y_{j}=\sum\limits_{i=1}^{n+1}y_i\cdot\frac{\prod\limits_{j=1}^{n+1}(x-j)}{(x-i)\cdot(-1)^{n+1-i}\cdot(i-1)!\cdot(n+1-i)!} \]
Implementacija 
// By: Luogu@rui_er(122461)
#include <iostream>
using namespace std;
constexpr int N = 1e6 + 5, mod = 1e9 + 7;

int n, k, tab[N], p[N], pcnt, f[N], pre[N], suf[N], fac[N], inv[N], ans;

int qpow(int x, int y) {
  int ans = 1;
  for (; y; y >>= 1, x = 1LL * x * x % mod)
    if (y & 1) ans = 1LL * ans * x % mod;
  return ans;
}

void sieve(int lim) {
  f[1] = 1;
  for (int i = 2; i <= lim; i++) {
    if (!tab[i]) {
      p[++pcnt] = i;
      f[i] = qpow(i, k);
    }
    for (int j = 1; j <= pcnt && 1LL * i * p[j] <= lim; j++) {
      tab[i * p[j]] = 1;
      f[i * p[j]] = 1LL * f[i] * f[p[j]] % mod;
      if (!(i % p[j])) break;
    }
  }
  for (int i = 2; i <= lim; i++) f[i] = (f[i - 1] + f[i]) % mod;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> n >> k;
  sieve(k + 2);
  if (n <= k + 2) return cout << f[n], 0;
  pre[0] = suf[k + 3] = 1;
  for (int i = 1; i <= k + 2; i++) pre[i] = 1LL * pre[i - 1] * (n - i) % mod;
  for (int i = k + 2; i >= 1; i--) suf[i] = 1LL * suf[i + 1] * (n - i) % mod;
  fac[0] = inv[0] = fac[1] = inv[1] = 1;
  for (int i = 2; i <= k + 2; i++) {
    fac[i] = 1LL * fac[i - 1] * i % mod;
    inv[i] = 1LL * (mod - mod / i) * inv[mod % i] % mod;
  }
  for (int i = 2; i <= k + 2; i++) inv[i] = 1LL * inv[i - 1] * inv[i] % mod;
  for (int i = 1; i <= k + 2; i++) {
    int P = 1LL * pre[i - 1] * suf[i + 1] % mod;
    int Q = 1LL * inv[i - 1] * inv[k + 2 - i] % mod;
    int mul = ((k + 2 - i) & 1) ? -1 : 1;
    ans = (ans + 1LL * (Q * mul + mod) % mod * P % mod * f[i] % mod) % mod;
  }
  cout << ans << '\n';
  return 0;
}

Newtonova interpolacija

Newtonova interpolacija metoda je interpolacije zasnovana na razlikama višeg reda; njezina je prednost što podržava dodavanje nove podatkovne točke u \(O(n)\).

Da bismo ostvarili dodavanje nove podatkovne točke u \(O(n)\), stavimo:

\[ f(x)=\sum_{j=0}^n a_jn_j(x) \]

gdje se \(n_j(x):=\prod_{i=0}^{j-1}(x-x_i)\) naziva Newtonova baza (Newton basis).

Ako riješimo \(a_j\), dobivamo interpolacijski polinom \(f(x)\). Podijeljene razlike unaprijed (forward divided differences) definiramo na sljedeći način:

\[ \begin{aligned} \lbrack y_k\rbrack & := y_k, & k=0,\dots,n, \\ [y_k,\dots,y_{k+j}] & := \dfrac{[y_{k+1},\dots,y_{k+j}]-[y_k,\dots,y_{k+j-1}]}{x_{k+j}-x_k}, & k=0,\dots,n-j,~j=1,\dots,n. \end{aligned} \]

Tada je:

\[ \begin{aligned} f(x)&=[y_0]+[y_0,y_1](x-x_0)+\dots+[y_0,\dots,y_n](x-x_0)\dots(x-x_{n-1})\\ &=\sum_{j=0}^n [y_0,\dots,y_j]n_j(x) \end{aligned} \]

To je oblik Newtonove interpolacije. Vremenska složenost naivne implementacije je \(O(n^2)\).

Ako su uzorkovane točke jednako razmaknute (tj. \(x_i=x_0+ih\), \(i=1,\dots,n\)), možemo izvesti

\[ [y_k,\dots,y_{k+j}]=\frac{1}{j!h^j}\Delta^{(j)}y_k, \]

gdje su \(\Delta^{(j)}y_k\) razlike unaprijed (forward differences), definirane ovako:

\[ \begin{aligned} \Delta^{(0)}y_k & := y_k, & k=0,\dots,n, \\ \Delta^{(j)}y_k & := \Delta^{(j-1)} y_{k+1}-\Delta^{(j-1)} y_k, & k=0,\dots,n-j,~j=1,\dots,n. \end{aligned} \]

Stavimo li \(x=x_0+sh\), formula Newtonove interpolacije postaje

\[ f(x)=\sum_{j=0}^n \binom{s}{j}j!h^j[y_0,\dots,y_j]=\sum_{j=0}^n \binom{s}{j}\Delta^{(j)}y_0. \]
Implementacija (Luogu P4781【模板】拉格朗日插值 (Predložak: Lagrangeova interpolacija)) 
#include <cstdint>
#include <iostream>
#include <vector>
using namespace std;

constexpr uint32_t MOD = 998244353;

struct mint {
  uint32_t v_;

  mint() : v_(0) {}

  mint(int64_t v) {
    int64_t x = v % (int64_t)MOD;
    v_ = (uint32_t)(x + (x < 0 ? MOD : 0));
  }

  friend mint inv(mint const &x) {
    int64_t a = x.v_, b = MOD;
    if ((a %= b) == 0) return 0;
    int64_t s = b, m0 = 0;
    for (int64_t q = 0, _ = 0, m1 = 1; a;) {
      _ = s - a * (q = s / a);
      s = a;
      a = _;
      _ = m0 - m1 * q;
      m0 = m1;
      m1 = _;
    }
    return m0;
  }

  mint &operator+=(mint const &r) {
    if ((v_ += r.v_) >= MOD) v_ -= MOD;
    return *this;
  }

  mint &operator-=(mint const &r) {
    if ((v_ -= r.v_) >= MOD) v_ += MOD;
    return *this;
  }

  mint &operator*=(mint const &r) {
    v_ = (uint32_t)((uint64_t)v_ * r.v_ % MOD);
    return *this;
  }

  mint &operator/=(mint const &r) { return *this = *this * inv(r); }

  friend mint operator+(mint l, mint const &r) { return l += r; }

  friend mint operator-(mint l, mint const &r) { return l -= r; }

  friend mint operator*(mint l, mint const &r) { return l *= r; }

  friend mint operator/(mint l, mint const &r) { return l /= r; }
};

template <class T>
struct NewtonInterp {
  // {(x_0,y_0),...,(x_{n-1},y_{n-1})}
  vector<pair<T, T>> p;
  // dy[r][l] = [y_l,...,y_r]
  vector<vector<T>> dy;
  // (x-x_0)...(x-x_{n-1})
  vector<T> base;
  // [y_0]+...+[y_0,y_1,...,y_n](x-x_0)...(x-x_{n-1})
  vector<T> poly;

  void insert(T const &x, T const &y) {
    p.emplace_back(x, y);
    size_t n = p.size();
    if (n == 1) {
      base.push_back(1);
    } else {
      size_t m = base.size();
      base.push_back(0);
      for (size_t i = m; i; --i) base[i] = base[i - 1];
      base[0] = 0;
      for (size_t i = 0; i < m; ++i)
        base[i] = base[i] - p[n - 2].first * base[i + 1];
    }
    dy.emplace_back(p.size());
    dy[n - 1][n - 1] = y;
    if (n > 1) {
      for (size_t i = n - 2; ~i; --i)
        dy[n - 1][i] =
            (dy[n - 2][i] - dy[n - 1][i + 1]) / (p[i].first - p[n - 1].first);
    }
    poly.push_back(0);
    for (size_t i = 0; i < n; ++i) poly[i] = poly[i] + dy[n - 1][0] * base[i];
  }

  T eval(T const &x) {
    T ans{};
    for (auto it = poly.rbegin(); it != poly.rend(); ++it) ans = ans * x + *it;
    return ans;
  }
};

int main() {
  NewtonInterp<mint> ip;
  int n, k;
  cin >> n >> k;
  for (int i = 1, x, y; i <= n; ++i) {
    cin >> x >> y;
    ip.insert(x, y);
  }
  cout << ip.eval(k).v_;
  return 0;
}

Newtonova interpolacija kad su apscise uzastopni cijeli brojevi

Na primjer: odredite koeficijente polinoma \(f(x)=\sum_{i=0}^{3} a_ix^i\) ako su poznate vrijednosti \(f(1)\) do \(f(6)\), redom \(1, 5, 14, 30, 55, 91\).

\[ \begin{array}{cccccccccccc} 1 & & 5 & & 14 & & 30 & & 55 & & 91 & \\ & 4 & & 9 & & 16 & & 25 & & 36 & \\ & & 5 & & 7 & & 9 & & 11 & \\ & & & 2 & & 2 & & 2 & \\ \end{array} \]

Prvi redak čini prvih \(n\) uzastopnih vrijednosti od \(f(x)\); svaki sljedeći redak čine razlike susjednih parova članova prethodnog retka. Uočavamo da, ako taj postupak ponovimo dovoljno puta (pod uvjetom da je \(f(x)\) polinom), na kraju uvijek dobijemo konstantnu vrijednost.

Izračunamo da je prvi član razlika \(i-1\)-og reda \(\sum_{j=1}^{i}(-1)^{i+j}\binom{i-1}{j-1}f(j)\), a prvi član razlika \(i-1\)-og reda doprinosi vrijednosti \(f(k)\) \(\binom{k-1}{i-1}\) puta.

\[ f(k)=\sum_{i=1}^n\binom{k-1}{i-1}\sum_{j=1}^{i}(-1)^{i+j}\binom{i-1}{j-1}f(j) \]

Vremenska složenost je \(O(n^2)\).

Introduction

Interpolation is a method of estimating new data points within a certain range from known, discrete data points. Interpolation is often used in function fitting.

For example, for the data points:

\(x\) \(0\) \(1\) \(2\) \(3\) \(4\) \(5\) \(6\)
\(f(x)\) \(0\) \(0.8415\) \(0.9093\) \(0.1411\) \(-0.7568\) \(-0.9589\) \(-0.2794\)

where \(f(x)\) is unknown, interpolation can estimate the unknown data points by fitting \(f(x)\) in some prescribed form.

For example, we can fit \(f(x)\) with a piecewise linear function:

This kind of interpolation is called linear interpolation.

We can also fit \(f(x)\) with a polynomial:

This kind of interpolation is called polynomial interpolation.

The general form of polynomial interpolation is as follows:

Polynomial interpolation

Given \(n+1\) known points \((x_0,y_0),(x_1,y_1),\dots,(x_n,y_n)\), find a polynomial of the form \(f(x)=\sum_{i=0}^n a_ix^i\) satisfying

\[ f(x_i)=y_i,\qquad\forall i=0,1,\dots,n \]

that is, the polynomial \(f(x)\).

Below we introduce two ways of doing polynomial interpolation: Lagrange interpolation and Newton interpolation. It is not hard to prove that the two methods give equal results.

Lagrange interpolation

We need to construct a function \(f(x)\) passing through the points \(P_1(x_1, y_1), P_2(x_2,y_2),\cdots,P_n(x_n,y_n)\). First, let the projection of the \(i\)-th point onto the \(x\)-axis be \(P_i^{\prime}(x_i,0)\).

Consider constructing \(n\) functions \(f_1(x), f_2(x), \cdots, f_n(x)\) such that the graph of the \(i\)-th function \(f_i(x)\) passes through \(\begin{cases}P_j^{\prime}(x_j,0),(j\neq i)\\P_i(x_i,y_i)\end{cases}\); then the required function is \(f(x)=\sum\limits_{i=1}^nf_i(x)\).

We can set \(f_i(x)=a\cdot\prod_{j\neq i}(x-x_j)\); substituting the point \(P_i(x_i,y_i)\) gives \(a=\dfrac{y_i}{\prod_{j\neq i} (x_i-x_j)}\), so

\[ f_i(x)=y_i\cdot\dfrac{\prod_{j\neq i} (x-x_j)}{\prod_{j\neq i} (x_i-x_j)}=y_i\cdot\prod_{j\neq i}\dfrac{x-x_j}{x_i-x_j} \]

Thus we obtain the form of Lagrange interpolation:

\[ f(x)=\sum_{i=1}^ny_i\cdot\prod_{j\neq i}\dfrac{x-x_j}{x_i-x_j} \]

The time complexity of the naive implementation is \(O(n^2)\); it can be optimized to \(O(n\log^2 n)\), see fast polynomial interpolation.

Given \(n\) point pairs \((x_i,y_i)\) and \(k\), where \(\forall i,j\) we have \(i\neq j \iff x_i\neq x_j\), and \(f(x_i)\equiv y_i\pmod{998244353}\) and \(\deg(f(x)) < n\) (define \(\deg(0)=-\infty\)), compute \(f(k)\bmod{998244353}\).

Solution

In this problem only the value \(f(k)\) is needed, so we can substitute \(k\) directly while computing the expression above; sometimes, however, several evaluations or more complex operations are needed, in which case the coefficients of \(f\) must be found. The code gives an implementation that computes the coefficients.

\[ f(k)=\sum_{i=1}^{n}y_i\prod_{j\neq i }\frac{k-x_j}{x_i-x_j} \]

In this problem we also need to compute inverses. If we first compute the numerator and denominator separately, then multiply the numerator by the inverse of the denominator and add it to the final answer, the bottleneck of the time complexity will not be computing inverses, and the time complexity is \(O(n^2)\).

Since we work under the fixed modulus \(998244353\), we tentatively regard the time complexity of computing a multiplicative inverse as constant here.

Implementation 
#include <iostream>
#include <vector>

constexpr int MOD = 998244353;
using LL = long long;

int inv(int k) {
  int res = 1;
  for (int e = MOD - 2; e; e /= 2) {
    if (e & 1) res = (LL)res * k % MOD;
    k = (LL)k * k % MOD;
  }
  return res;
}

// returns f such that f(x_i) = y_i
// ignoring the time for multiplicative inverses, clearly O(n^2)
std::vector<int> lagrange_interpolation(const std::vector<int> &x,
                                        const std::vector<int> &y) {
  const int n = x.size();
  std::vector<int> M(n + 1), px(n, 1), f(n);
  M[0] = 1;
  // compute M(x) = prod_(i=0..n-1)(x - x_i)
  for (int i = 0; i < n; ++i) {
    for (int j = i; j >= 0; --j) {
      M[j + 1] = (M[j] + M[j + 1]) % MOD;
      M[j] = (LL)M[j] * (MOD - x[i]) % MOD;
    }
  }
  // compute px_i = prod_(j=0..n-1, j!=i) (x_i - x_j)
  for (int i = 0; i < n; ++i) {
    for (int j = 0; j < n; ++j)
      if (i != j) {
        px[i] = (LL)px[i] * (x[i] - x[j] + MOD) % MOD;
      }
  }
  // assemble f(x) = sum_(i=0..n-1)(y_i / px_i)(M(x) / (x - x_i))
  for (int i = 0; i < n; ++i) {
    LL t = (LL)y[i] * inv(px[i]) % MOD, k = M[n];
    for (int j = n - 1; j >= 0; --j) {
      f[j] = (f[j] + k * t) % MOD;
      k = (M[j] + k * x[i]) % MOD;
    }
  }
  return f;
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  int n, k;
  std::cin >> n >> k;
  std::vector<int> x(n), y(n);
  for (int i = 0; i < n; ++i) std::cin >> x[i] >> y[i];
  const auto f = lagrange_interpolation(x, y);
  int v = 0;
  for (int i = n - 1; i >= 0; --i) v = ((LL)v * k + f[i]) % MOD;
  std::cout << v << '\n';
  return 0;
}

Lagrange interpolation with consecutive integer abscissas

If the abscissas of the known points are consecutive integers, we can interpolate in \(O(n)\).

Let the required polynomial be \(f(x)\), and suppose we know \(f(1),\cdots,f(n+1)\) (\(1\le i\le n+1\)); substitute into the interpolation formula above:

\[ \begin{aligned} f(x)&=\sum\limits_{i=1}^{n+1}y_i\prod\limits_{j\ne i}\frac{x-x_j}{x_i-x_j}\\ &=\sum\limits_{i=1}^{n+1}y_i\prod\limits_{j\ne i}\frac{x-j}{i-j} \end{aligned} \]

In the product at the end, the numerator and denominator can be considered separately; it is easy to see that the numerator is:

\[ \dfrac{\prod\limits_{j=1}^{n+1}(x-j)}{x-i} \]

The product of \(i-j\) in the denominator can be split into two factorials:

\[ (-1)^{n+1-i}\cdot(i-1)!\cdot(n+1-i)! \]

Thus the interpolation formula for abscissas \(1,\cdots,n+1\) is:

\[ f(x)=\sum\limits_{i=1}^{n+1}(-1)^{n+1-i}y_i\cdot\frac{\prod\limits_{j=1}^{n+1}(x-j)}{(i-1)!(n+1-i)!(x-i)} \]

Precompute the prefix and suffix products of \((x-i)\), the factorials and the inverse factorials, then substitute into this formula; the complexity is \(O(n)\).

Example problem CF622F The Sum of the k-th Powers

Given \(n,k\), compute \(\sum\limits_{i=1}^ni^k\) modulo \(10^9+7\).

Solution

In this problem the answer is a polynomial of degree \(k+1\), so we can compute the values \(1^i,\cdots,(k+2)^i\) with a linear sieve and then interpolate in \(O(n)\).

One can also derive the following expression from the formula of the method of differences using combinatorics:

\[ f(x)=\sum_{i=1}^{n+1}\binom{x-1}{i-1}\sum_{j=1}^{i}(-1)^{i+j}\binom{i-1}{j-1}y_{j}=\sum\limits_{i=1}^{n+1}y_i\cdot\frac{\prod\limits_{j=1}^{n+1}(x-j)}{(x-i)\cdot(-1)^{n+1-i}\cdot(i-1)!\cdot(n+1-i)!} \]
Implementation 
// By: Luogu@rui_er(122461)
#include <iostream>
using namespace std;
constexpr int N = 1e6 + 5, mod = 1e9 + 7;

int n, k, tab[N], p[N], pcnt, f[N], pre[N], suf[N], fac[N], inv[N], ans;

int qpow(int x, int y) {
  int ans = 1;
  for (; y; y >>= 1, x = 1LL * x * x % mod)
    if (y & 1) ans = 1LL * ans * x % mod;
  return ans;
}

void sieve(int lim) {
  f[1] = 1;
  for (int i = 2; i <= lim; i++) {
    if (!tab[i]) {
      p[++pcnt] = i;
      f[i] = qpow(i, k);
    }
    for (int j = 1; j <= pcnt && 1LL * i * p[j] <= lim; j++) {
      tab[i * p[j]] = 1;
      f[i * p[j]] = 1LL * f[i] * f[p[j]] % mod;
      if (!(i % p[j])) break;
    }
  }
  for (int i = 2; i <= lim; i++) f[i] = (f[i - 1] + f[i]) % mod;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> n >> k;
  sieve(k + 2);
  if (n <= k + 2) return cout << f[n], 0;
  pre[0] = suf[k + 3] = 1;
  for (int i = 1; i <= k + 2; i++) pre[i] = 1LL * pre[i - 1] * (n - i) % mod;
  for (int i = k + 2; i >= 1; i--) suf[i] = 1LL * suf[i + 1] * (n - i) % mod;
  fac[0] = inv[0] = fac[1] = inv[1] = 1;
  for (int i = 2; i <= k + 2; i++) {
    fac[i] = 1LL * fac[i - 1] * i % mod;
    inv[i] = 1LL * (mod - mod / i) * inv[mod % i] % mod;
  }
  for (int i = 2; i <= k + 2; i++) inv[i] = 1LL * inv[i - 1] * inv[i] % mod;
  for (int i = 1; i <= k + 2; i++) {
    int P = 1LL * pre[i - 1] * suf[i + 1] % mod;
    int Q = 1LL * inv[i - 1] * inv[k + 2 - i] % mod;
    int mul = ((k + 2 - i) & 1) ? -1 : 1;
    ans = (ans + 1LL * (Q * mul + mod) % mod * P % mod * f[i] % mod) % mod;
  }
  cout << ans << '\n';
  return 0;
}

Newton interpolation

Newton interpolation is an interpolation method based on higher-order differences; its advantage is that it supports inserting a new data point in \(O(n)\).

To achieve \(O(n)\) insertion of a new data point, we set:

\[ f(x)=\sum_{j=0}^n a_jn_j(x) \]

where \(n_j(x):=\prod_{i=0}^{j-1}(x-x_i)\) is called the Newton basis.

If we solve for \(a_j\), we obtain the interpolation polynomial \(f(x)\). We define the forward divided differences as follows:

\[ \begin{aligned} \lbrack y_k\rbrack & := y_k, & k=0,\dots,n, \\ [y_k,\dots,y_{k+j}] & := \dfrac{[y_{k+1},\dots,y_{k+j}]-[y_k,\dots,y_{k+j-1}]}{x_{k+j}-x_k}, & k=0,\dots,n-j,~j=1,\dots,n. \end{aligned} \]

Then:

\[ \begin{aligned} f(x)&=[y_0]+[y_0,y_1](x-x_0)+\dots+[y_0,\dots,y_n](x-x_0)\dots(x-x_{n-1})\\ &=\sum_{j=0}^n [y_0,\dots,y_j]n_j(x) \end{aligned} \]

This is the form of Newton interpolation. The time complexity of the naive implementation is \(O(n^2)\).

If the sample points are equally spaced (i.e. \(x_i=x_0+ih\), \(i=1,\dots,n\)), we can derive

\[ [y_k,\dots,y_{k+j}]=\frac{1}{j!h^j}\Delta^{(j)}y_k, \]

where \(\Delta^{(j)}y_k\) are the forward differences, defined as follows:

\[ \begin{aligned} \Delta^{(0)}y_k & := y_k, & k=0,\dots,n, \\ \Delta^{(j)}y_k & := \Delta^{(j-1)} y_{k+1}-\Delta^{(j-1)} y_k, & k=0,\dots,n-j,~j=1,\dots,n. \end{aligned} \]

Setting \(x=x_0+sh\), the Newton interpolation formula becomes

\[ f(x)=\sum_{j=0}^n \binom{s}{j}j!h^j[y_0,\dots,y_j]=\sum_{j=0}^n \binom{s}{j}\Delta^{(j)}y_0. \]

#include <cstdint>
#include <iostream>
#include <vector>
using namespace std;

constexpr uint32_t MOD = 998244353;

struct mint {
  uint32_t v_;

  mint() : v_(0) {}

  mint(int64_t v) {
    int64_t x = v % (int64_t)MOD;
    v_ = (uint32_t)(x + (x < 0 ? MOD : 0));
  }

  friend mint inv(mint const &x) {
    int64_t a = x.v_, b = MOD;
    if ((a %= b) == 0) return 0;
    int64_t s = b, m0 = 0;
    for (int64_t q = 0, _ = 0, m1 = 1; a;) {
      _ = s - a * (q = s / a);
      s = a;
      a = _;
      _ = m0 - m1 * q;
      m0 = m1;
      m1 = _;
    }
    return m0;
  }

  mint &operator+=(mint const &r) {
    if ((v_ += r.v_) >= MOD) v_ -= MOD;
    return *this;
  }

  mint &operator-=(mint const &r) {
    if ((v_ -= r.v_) >= MOD) v_ += MOD;
    return *this;
  }

  mint &operator*=(mint const &r) {
    v_ = (uint32_t)((uint64_t)v_ * r.v_ % MOD);
    return *this;
  }

  mint &operator/=(mint const &r) { return *this = *this * inv(r); }

  friend mint operator+(mint l, mint const &r) { return l += r; }

  friend mint operator-(mint l, mint const &r) { return l -= r; }

  friend mint operator*(mint l, mint const &r) { return l *= r; }

  friend mint operator/(mint l, mint const &r) { return l /= r; }
};

template <class T>
struct NewtonInterp {
  // {(x_0,y_0),...,(x_{n-1},y_{n-1})}
  vector<pair<T, T>> p;
  // dy[r][l] = [y_l,...,y_r]
  vector<vector<T>> dy;
  // (x-x_0)...(x-x_{n-1})
  vector<T> base;
  // [y_0]+...+[y_0,y_1,...,y_n](x-x_0)...(x-x_{n-1})
  vector<T> poly;

  void insert(T const &x, T const &y) {
    p.emplace_back(x, y);
    size_t n = p.size();
    if (n == 1) {
      base.push_back(1);
    } else {
      size_t m = base.size();
      base.push_back(0);
      for (size_t i = m; i; --i) base[i] = base[i - 1];
      base[0] = 0;
      for (size_t i = 0; i < m; ++i)
        base[i] = base[i] - p[n - 2].first * base[i + 1];
    }
    dy.emplace_back(p.size());
    dy[n - 1][n - 1] = y;
    if (n > 1) {
      for (size_t i = n - 2; ~i; --i)
        dy[n - 1][i] =
            (dy[n - 2][i] - dy[n - 1][i + 1]) / (p[i].first - p[n - 1].first);
    }
    poly.push_back(0);
    for (size_t i = 0; i < n; ++i) poly[i] = poly[i] + dy[n - 1][0] * base[i];
  }

  T eval(T const &x) {
    T ans{};
    for (auto it = poly.rbegin(); it != poly.rend(); ++it) ans = ans * x + *it;
    return ans;
  }
};

int main() {
  NewtonInterp<mint> ip;
  int n, k;
  cin >> n >> k;
  for (int i = 1, x, y; i <= n; ++i) {
    cin >> x >> y;
    ip.insert(x, y);
  }
  cout << ip.eval(k).v_;
  return 0;
}

Newton interpolation with consecutive integer abscissas

For example: find the coefficients of the polynomial \(f(x)=\sum_{i=0}^{3} a_ix^i\), given that the values \(f(1)\) through \(f(6)\) are \(1, 5, 14, 30, 55, 91\) respectively.

\[ \begin{array}{cccccccccccc} 1 & & 5 & & 14 & & 30 & & 55 & & 91 & \\ & 4 & & 9 & & 16 & & 25 & & 36 & \\ & & 5 & & 7 & & 9 & & 11 & \\ & & & 2 & & 2 & & 2 & \\ \end{array} \]

The first row consists of the first \(n\) consecutive values of \(f(x)\); each subsequent row consists of the differences of corresponding adjacent pairs of terms in the previous row. Observe that if this operation is performed enough times (provided \(f(x)\) is a polynomial), eventually a constant value is always obtained.

We compute that the first term of the \(i-1\)-th order differences is \(\sum_{j=1}^{i}(-1)^{i+j}\binom{i-1}{j-1}f(j)\), and the first term of the \(i-1\)-th order differences contributes to \(f(k)\) \(\binom{k-1}{i-1}\) times.

\[ f(k)=\sum_{i=1}^n\binom{k-1}{i-1}\sum_{j=1}^{i}(-1)^{i+j}\binom{i-1}{j-1}f(j) \]

The time complexity is \(O(n^2)\).

Implementation in C++

Since C++20, the standard library has added the functions std::midpoint and std::lerp, used for computing the midpoint and for linear interpolation, respectively.
