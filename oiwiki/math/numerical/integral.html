Definicija određenog integrala

Jednostavno rečeno, određeni integral \(\int_{l}^{r}f(x)\mathrm{d}x\) funkcije \(f(x)\) na intervalu \([l,r]\) označava površinu područja koje \(f(x)\) na intervalu \([l,r]\) zatvara s osi \(x\) (pri čemu se dio iznad osi \(x\) računa pozitivno, a dio ispod osi \(x\) negativno).

U mnogim slučajevima trebamo učinkovito i točno izračunati približnu vrijednost nekog integrala. Simpsonova metoda, koju predstavljamo u nastavku, upravo je jedna takva metoda numeričke integracije.

Simpsonova metoda

Ideja je ove metode podijeliti interval integracije na više malih dijelova i na svakom dijelu primijeniti formulu za integral kvadratne funkcije.

Formula za integral kvadratne funkcije (Simpsonova formula)

Za kvadratnu funkciju \(f(x)=ax^2+bx+c\) vrijedi:

\[ \int_l^r f(x) {\mathrm d}x = \frac{(r-l)(f(l)+f(r)+4 f(\frac{l+r}{2}))}{6} \]

Izvod: Za kvadratnu funkciju \(f(x)=ax^2+bx+c\); integriranjem dobivamo \(F(x)=\int_0^x f(x) {\mathrm d}x = \frac{a}{3}x^3+\frac{b}{2}x^2+cx+D\), gdje je D konstanta, pa je

\[ \begin{aligned} \int_l^r f(x) {\mathrm d}x &= F(r)-F(l) \\ &= \frac{a}{3}(r^3-l^3)+\frac{b}{2}(r^2-l^2)+c(r-l) \\ &=(r-l)(\frac{a}{3}(l^2+r^2+lr)+\frac{b}{2}(l+r)+c) \\ &=\frac{r-l}{6}(2al^2+2ar^2+2alr+3bl+3br+6c)\\ &=\frac{r-l}{6}((al^2+bl+c)+(ar^2+br+c)+4(a(\frac{l+r}{2})^2+b(\frac{l+r}{2})+c)) \\ &=\frac{r-l}{6}(f(l)+f(r)+4f(\frac{l+r}{2})) \end{aligned} \]

Na temelju te Simpsonove formule najprije predstavljamo običnu Simpsonovu metodu integracije.

Obična Simpsonova metoda

Godine 1743. ta je metoda objavljena u jednom radu Thomasa Simpsona.

Opis

Za zadani prirodni broj \(n\) podijelimo interval \([l, r]\) na \(2n\) jednako dugih intervala \(x\).

\(x_i = l + i h, ~~ i = 0 \ldots 2n,\) \(h = \frac {r-l} {2n}.\)

Tada možemo izračunati vrijednost integrala na svakom malom intervalu \([x_ {2i-2}, x_ {2i}]\), \(i = 1\ldots n\); zbroj vrijednosti integrala na svim intervalima ukupni je integral.

Za jedan interval \([x_ {2i-2}, x_ {2i}]\), \(i = 1\ldots n\), odaberemo tri točke \((x_ {2i-2}, x_ {2i-1}, x_ {2i})\) u njemu; one određuju parabolu, a time i funkciju \(P(x)\), koja postoji i jedinstvena je. Računanje integrala izvorne funkcije na tom intervalu tako postaje računanje integrala nove kvadratne funkcije \(P(x)\) na tom intervalu. Njega možemo približno izračunati Simpsonovom formulom.

\(\int_{x_ {2i-2}} ^ {x_ {2i}} f (x) ~dx \approx \int_{x_ {2i-2}} ^ {x_ {2i}} P (x) ~dx = \left(f(x_{2i-2}) + 4f(x_{2i-1})+(f(x_{2i})\right)\frac {h} {3}\)

Zbrajanjem po dijelovima dobivamo sljedeći zaključak:

\(\int_l ^ r f (x) dx \approx \left(f (x_0) + 4 f (x_1) + 2 f (x_2) + 4f(x_3) + 2 f(x_4) + \ldots + 4 f(x_{2N-1}) + f(x_{2N}) \right)\frac {h} {3}\)

Pogreška

Navodimo izravno rezultat: pogreška obične Simpsonove metode iznosi:

\[ -\tfrac{1}{90} \left(\tfrac{r-l}{2}\right)^5 f^{(4)}(\xi) \]

gdje je \(\xi\) neka vrijednost iz intervala \([l,r]\).

Implementacija

constexpr int N = 1000 * 1000;

double simpson_integration(double a, double b) {
  double h = (b - a) / N;
  double s = f(a) + f(b);
  for (int i = 1; i <= N - 1; ++i) {
    double x = a + h * i;
    s += f(x) * ((i & 1) ? 4 : 2);
  }
  s *= h / 3;
  return s;
}

N = 1000 * 1000

    return s

Adaptivna Simpsonova metoda

Obična metoda, da bi osigurala točnost, vremenski je neizbježno ograničena brojem \(n\); trebali bismo pronaći prikladniju metodu.

Jedini je problem sada kako podijeliti interval. Ako je dijelova premalo, pogreška računanja je velika; ako ih je previše, vremenska je učinkovitost niska. Trebamo pronaći ravnotežu između točnosti i učinkovitosti.

Razmišljamo ovako: ako je neki dio grafa već vrlo blizu kvadratnoj funkciji, izravnim uvrštavanjem u formulu dobivamo integral vrlo visoke točnosti i taj dio ne treba dalje dijeliti.

Tako dolazimo do sljedećeg načina dijeljenja: svaki put procijenimo koliko je trenutačni dio sličan kvadratnoj funkciji; ako je dovoljno sličan, izravno ga uvrstimo u formulu, a inače trenutačni dio podijelimo na lijevi i desni dio i riješimo rekurzivno.

Preostaje još jedan problem: kako procijeniti je li neki dio sličan kvadratnoj funkciji?

Trenutačni dio izravno uvrstimo u formulu i izračunamo integral, zatim ga u polovištu podijelimo na dva dijela i oba dijela također izravno uvrstimo u formulu. Ako se integral trenutačnog dijela i zbroj integrala dvaju dijelova nakon podjele vrlo malo razlikuju, možemo smatrati da je trenutačni dio vrlo sličan kvadratnoj funkciji i ne treba ga dalje rekurzivno dijeliti.

To je ideja adaptivne Simpsonove metode. Pri odlučivanju u fazi podijeli-pa-vladaj, osim provjere točnosti, obično se prisilno izvodi i najmanji broj iteracija.

Referentni kôd:

double simpson(double l, double r) {
  double mid = (l + r) / 2;
  return (r - l) * (f(l) + 4 * f(mid) + f(r)) / 6;  // Simpsonova formula
}

double asr(double l, double r, double eps, double ans, int step) {
  double mid = (l + r) / 2;
  double fl = simpson(l, mid), fr = simpson(mid, r);
  if (abs(fl + fr - ans) <= 15 * eps && step < 0)
    return fl + fr + (fl + fr - ans) / 15;  // ako je dovoljno slično, odmah vrati rezultat
  return asr(l, mid, eps / 2, fl, step - 1) +
         asr(mid, r, eps / 2, fr, step - 1);  // inače podijeli na dva dijela i riješi rekurzivno
}

double calc(double l, double r, double eps) {
  return asr(l, r, eps, simpson(l, r), 12);
}

Definition of the definite integral

Simply put, the definite integral \(\int_{l}^{r}f(x)\mathrm{d}x\) of a function \(f(x)\) over the interval \([l,r]\) is the area of the region enclosed by \(f(x)\) and the \(x\)-axis over the interval \([l,r]\) (where the part above the \(x\)-axis counts as positive and the part below the \(x\)-axis counts as negative).

In many cases we need to compute an approximate value of an integral efficiently and accurately. Simpson's method, introduced below, is exactly such a method of numerical integration.

Simpson's method

The idea of this method is to divide the interval of integration into several small segments and apply the integral formula for a quadratic function on each segment.

Integral formula for a quadratic function (Simpson's formula)

For a quadratic function \(f(x)=ax^2+bx+c\) we have:

\[ \int_l^r f(x) {\mathrm d}x = \frac{(r-l)(f(l)+f(r)+4 f(\frac{l+r}{2}))}{6} \]

Derivation: For a quadratic function \(f(x)=ax^2+bx+c\); integrating gives \(F(x)=\int_0^x f(x) {\mathrm d}x = \frac{a}{3}x^3+\frac{b}{2}x^2+cx+D\), where D is a constant, so

\[ \begin{aligned} \int_l^r f(x) {\mathrm d}x &= F(r)-F(l) \\ &= \frac{a}{3}(r^3-l^3)+\frac{b}{2}(r^2-l^2)+c(r-l) \\ &=(r-l)(\frac{a}{3}(l^2+r^2+lr)+\frac{b}{2}(l+r)+c) \\ &=\frac{r-l}{6}(2al^2+2ar^2+2alr+3bl+3br+6c)\\ &=\frac{r-l}{6}((al^2+bl+c)+(ar^2+br+c)+4(a(\frac{l+r}{2})^2+b(\frac{l+r}{2})+c)) \\ &=\frac{r-l}{6}(f(l)+f(r)+4f(\frac{l+r}{2})) \end{aligned} \]

Based on this Simpson's formula, we first introduce the plain Simpson's method of integration.

Plain Simpson's method

In 1743, this method was published in a paper by Thomas Simpson.

Description

Given a natural number \(n\), divide the interval \([l, r]\) into \(2n\) intervals \(x\) of equal length.

\(x_i = l + i h, ~~ i = 0 \ldots 2n,\) \(h = \frac {r-l} {2n}.\)

Then we can compute the value of the integral on every small interval \([x_ {2i-2}, x_ {2i}]\), \(i = 1\ldots n\); the sum of the integral values over all intervals is the total integral.

For one interval \([x_ {2i-2}, x_ {2i}]\), \(i = 1\ldots n\), choose the three points \((x_ {2i-2}, x_ {2i-1}, x_ {2i})\) in it; they determine a parabola and hence a function \(P(x)\), which exists and is unique. Computing the integral of the original function on this interval thus becomes computing the integral of the new quadratic function \(P(x)\) on this interval. This we can approximate using Simpson's formula.

\(\int_{x_ {2i-2}} ^ {x_ {2i}} f (x) ~dx \approx \int_{x_ {2i-2}} ^ {x_ {2i}} P (x) ~dx = \left(f(x_{2i-2}) + 4f(x_{2i-1})+(f(x_{2i})\right)\frac {h} {3}\)

Summing over the segments gives the following conclusion:

\(\int_l ^ r f (x) dx \approx \left(f (x_0) + 4 f (x_1) + 2 f (x_2) + 4f(x_3) + 2 f(x_4) + \ldots + 4 f(x_{2N-1}) + f(x_{2N}) \right)\frac {h} {3}\)

Error

We state the result directly: the error of the plain Simpson's method is:

\[ -\tfrac{1}{90} \left(\tfrac{r-l}{2}\right)^5 f^{(4)}(\xi) \]

where \(\xi\) is some value in the interval \([l,r]\).

Adaptive Simpson's method

To guarantee precision, the plain method is inevitably limited in time by \(n\); we should look for a more suitable method.

The only remaining problem is how to split the interval. If there are too few segments the computational error is large; if there are too many, the time efficiency is low. We need to find a balance between accuracy and efficiency.

We reason as follows: if a segment of the graph is already very close to a quadratic function, then substituting it directly into the formula gives an integral of very high precision, and there is no need to split this segment further.

So we have the following splitting method: each time, judge how similar the current segment is to a quadratic function; if it is similar enough, substitute it directly into the formula, otherwise split the current segment into a left and a right part and solve recursively.

Only one problem remains: how to judge whether a segment is similar to a quadratic function?

We substitute the current segment directly into the formula to get its integral, then split the current segment at its midpoint into two parts and substitute both parts directly into the formula as well. If the integral of the current segment and the sum of the integrals of the two parts after splitting differ very little, we may consider the current segment very similar to a quadratic function, and there is no need to split it recursively any further.

The above is the idea of the adaptive Simpson's method. When deciding in the divide-and-conquer step, besides checking whether the precision is satisfied, a minimum number of iterations is usually enforced as well.

Reference code:

double simpson(double l, double r) {
  double mid = (l + r) / 2;
  return (r - l) * (f(l) + 4 * f(mid) + f(r)) / 6;  // Simpson's formula
}

double asr(double l, double r, double eps, double ans, int step) {
  double mid = (l + r) / 2;
  double fl = simpson(l, mid), fr = simpson(mid, r);
  if (abs(fl + fr - ans) <= 15 * eps && step < 0)
    return fl + fr + (fl + fr - ans) / 15;  // if similar enough, return directly
  return asr(l, mid, eps / 2, fl, step - 1) +
         asr(mid, r, eps / 2, fr, step - 1);  // otherwise split into two parts and solve recursively
}

double calc(double l, double r, double eps) {
  return asr(l, r, eps, simpson(l, r), 12);
}
