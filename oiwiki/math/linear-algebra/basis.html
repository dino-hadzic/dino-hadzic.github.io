Prisjetimo se pojma baznih vektora iz srednjoškolske stereometrije: u trodimenzionalnom euklidskom prostoru možemo pronaći skup baznih vektora \(\boldsymbol{i}\), \(\boldsymbol{j}\), \(\boldsymbol{k}\) pomoću kojih se zatim može prikazati svaki vektor prostora. Drugim riječima, pomoću konačno mnogo baznih vektora možemo opisati beskonačan trodimenzionalni prostor, što dovoljno govori o važnosti baznih vektora.

Trodimenzionalni euklidski prostor poseban je vektorski prostor, a bazni vektori trodimenzionalnog euklidskog prostora u vektorskom se prostoru poopćuju u linearnu bazu.

Primjene linearne baze u OI-ju u pravilu uključuju samo dvije vrste vektorskih prostora: \(n\)-dimenzionalni realni vektorski prostor \(\mathbf{R}^n\) i \(n\)-dimenzionalni vektorski prostor nad Booleovom domenom \(\mathbf{Z}_2^n\); detaljno ih obrađujemo u odjeljku Primjene. Ako vam linearna algebra nije bliska, preporučujemo da čitanje započnete od odjeljka o primjenama.

U nastavku linearnu bazu uvodimo polazeći od općeg vektorskog prostora i navodimo njezina uobičajena svojstva.

Predznanje: vektorski prostor.

Linearna baza je baza vektorskog prostora i važan je alat za proučavanje vektorskih prostora.

Definicija

Maksimalan linearno nezavisan podskup vektorskog prostora \(V\) nazivamo Hamelovom bazom ili linearnom bazom prostora \(V\), kraće bazom.

Dogovorno, baza vektorskog prostora \(\{\theta\}\) prazan je skup.

Može se dokazati da svaki vektorski prostor ima linearnu bazu1; dimenziju vektorskog prostora \(V\) definiramo kao broj elemenata (ili kardinalnost) linearne baze i označavamo \(\dim V\).

Svojstva

  1. Za konačnodimenzionalan vektorski prostor \(V\) dimenzije \(n\) vrijedi:

    1. Bilo kojih \(n+1\) vektora iz \(V\) linearno je zavisno.

    2. Bilo kojih \(n\) linearno nezavisnih vektora iz \(V\) čini bazu prostora \(V\).

    3. Ako se svaki vektor iz \(V\) može linearno izraziti pomoću skupa vektora \(a_1,a_2,\dots,a_n\), onda je taj skup baza prostora \(V\).

      Dokaz

      Uzmimo bilo koju bazu \(b_1,b_2,\dots,b_n\) prostora \(V\). Prema pretpostavci, skup vektora \(b_1,b_2,\dots,b_n\) može se linearno izraziti pomoću \(a_1,a_2,\dots,a_n\), pa je

      \[ n=\operatorname{rank}\{b_1,b_2,\dots,b_n\}\leq\operatorname{rank}\{a_1,a_2,\dots,a_n\}\leq n \]

      Stoga je \(\operatorname{rank}\{a_1,a_2,\dots,a_n\}=n\)

    4. Svaki linearno nezavisan skup vektora \(a_1,a_2,\dots,a_m\) iz \(V\) može se dodavanjem nekih vektora nadopuniti do baze prostora \(V\).

  2. (Formula za dimenziju potprostora) Neka su \(V_1,V_2\) konačnodimenzionalni vektorski prostori nad \(\Bbb{P}\) te neka su i \(V_1+V_2\) i \(V_1\cap V_2\) konačnodimenzionalni. Tada je \(\dim V_1+\dim V_2=\dim(V_1+V_2)+\dim(V_1\cap V_2)\)

    Dokaz

    Neka je \(\dim V_1=n_1\), \(\dim V_2=n_2\), \(\dim(V_1\cap V_2)=m\).

    Uzmimo bazu \(a_1,a_2,\dots,a_m\) prostora \(V_1\cap V_2\) i nadopunimo je do baze prostora \(V_1\) odnosno \(V_2\): \(a_1,a_2,\dots,a_m,b_1,b_2,\dots,b_{n_1-m}\) i \(a_1,a_2,\dots,a_m,c_1,c_2,\dots,c_{n_2-m}\).

    Preostaje samo dokazati da je skup vektora \(a_1,a_2,\dots,a_m,b_1,b_2,\dots,b_{n_1-m},c_1,c_2,\dots,c_{n_2-m}\) linearno nezavisan.

    Neka je \(\sum_{i=1}^m r_ia_i+\sum_{i=1}^{n_1-m} s_ib_i+\sum_{i=1}^{n_2-m} t_ic_i=\theta\).

    Tada je \(\sum_{i=1}^{n_2-m} t_ic_i=-\sum_{i=1}^m r_ia_i-\sum_{i=1}^{n_1-m} s_ib_i\).

    Primijetimo da je lijeva strana gornje jednakosti u \(V_2\), a desna u \(V_1\), pa su obje strane u \(V_1\cap V_2\); stoga je \(\sum_{i=1}^{n_2-m} t_ic_i=\sum_{i=1}^m k_ia_i\)

    Odatle je \(t_1=t_2=\dots=t_{n_2-m}=k_1=k_2=\dots=k_m=0\), a zatim i \(r_1=r_2=\dots=r_m=s_1=s_2=\dots=s_{n_1-m}=t_1=t_2=\dots=t_{n_2-m}=0\)

  3. Neka su \(V_1,V_2\) konačnodimenzionalni vektorski prostori nad \(\Bbb{P}\) te neka su i \(V_1+V_2\) i \(V_1\cap V_2\) konačnodimenzionalni. Tada su sljedeće tvrdnje ekvivalentne:

    1. \(V_1+V_2=V_1\oplus V_2\).

    2. \(\dim V_1+\dim V_2=\dim(V_1+V_2)\).

    3. Ako je \(a_1,a_2,\dots,a_n\) baza prostora \(V_1\), a \(b_1,b_2,\dots,b_m\) baza prostora \(V_2\), onda je \(a_1,a_2,\dots,a_n,b_1,b_2,\dots,b_m\) baza prostora \(V_1+V_2\).

    Napomena

    Tvrdnje 1 i 3 mogu se poopćiti na beskonačnodimenzionalne vektorske prostore.

Primjeri

Promotrimo baze prostora \(\Bbb{R}^2\).

  1. Kao na slici

    \(u,v\) čine bazu.

  2. Kao na slici

    \(u,v\) čine bazu.

  3. Kao na slici

    \(u,v\) ne čine bazu jer je \(u=-v\).

  4. Kao na slici

    \(u,v,w\) ne čine bazu jer je \(u+4v+6w=\theta\).

Ortogonalna i ortonormirana baza

Ako baza \(B\) vektorskog prostora \(V\) zadovoljava \(\forall b,b'\in B,~(b,b')\ne 0\iff b=b'\) (tj. vektori su u parovima ortogonalni), tu bazu nazivamo ortogonalnom bazom.

Ako ortogonalna baza \(B\) vektorskog prostora \(V\) k tome zadovoljava \(\forall b\in B,~|b|=\sqrt{(b,b)}=1\), tu bazu nazivamo ortonormiranom bazom.

Svaka baza konačnodimenzionalnog vektorskog prostora \(V\) može se Gram–Schmidtovim postupkom ortogonalizacije pretvoriti u ortogonalnu bazu.

Primjene

Prema prethodno rečenom, pomoću linearne baze možemo:

  1. odrediti rang zadanog skupa vektora;
  2. za zadani skup vektora pronaći maksimalan linearno nezavisan podskup (ili bazu vektorskog prostora koji razapinje);
  3. u zadani skup vektora umetati nove vektore i nakon umetanja pronaći maksimalan linearno nezavisan podskup (ili bazu vektorskog prostora koji razapinje);
  4. za pronađeni maksimalan linearno nezavisan podskup (ili bazu) provjeriti može li se neki vektor linearno izraziti pomoću njega;
  5. za pronađeni maksimalan linearno nezavisan podskup (ili bazu) odrediti posebne elemente vektorskog prostora koji razapinje (npr. najveći, najmanji element itd.).

U OI-ju linearnu bazu u \(n\)-dimenzionalnom realnom vektorskom prostoru \(\mathbf{R}^n\) obično nazivamo realnom linearnom bazom, a linearnu bazu u \(n\)-dimenzionalnom vektorskom prostoru nad Booleovom domenom \(\mathbf{Z}_2^n\) XOR linearnom bazom.

Savjet

U \(\mathbf{Z}_2\) zbrajanje je XOR (isključivo ili), a množenje je AND (i); može se dokazati da je \(\mathbf{Z}_2\) polje.

Može se dokazati da je algebarska struktura \((\mathbf{Z}_2^n,+,\cdot,\mathbf{Z}_2)\) vektorski prostor, pri čemu je:

\[ (a_1,\dots,a_n)+(b_1,\dots,b_n):=(a_1+b_1,\dots,a_n+b_n), \]
\[ k\cdot(a_1,\dots,a_n):=(ka_1,\dots,ka_n). \]

Dakle, zbrajanje je XOR, a množenje skalarom AND.

Na primjeru XOR linearne baze: iz zadanog skupa Booleovih nizova \(X=\{x_1,\dots,x_m\}\) možemo konstruirati XOR linearnu bazu \(B=\{b_1,\dots,b_n\}\) sa sljedećim svojstvima:

  1. XOR svakog nepraznog podskupa od \(B\) različit je od \(0\);
  2. za svaki element \(x\) iz \(X\) u \(B\) se može odabrati nekoliko elemenata čiji je XOR jednak \(x\);
  3. svaki skup \(B'\) koji zadovoljava prethodna dva svojstva nema manje elemenata od \(B\).

Pomoću XOR linearne baze možemo:

  1. provjeriti može li se neki broj prikazati kao XOR nekog podskupa zadanog skupa brojeva;
  2. odrediti broj načina na koje se neki broj može prikazati kao XOR podskupa zadanog skupa brojeva;
  3. odrediti najveći/najmanji/\(k\)-ti najveći/\(k\)-ti najmanji XOR podskupa zadanog skupa brojeva;
  4. odrediti rang (poziciju) nekog broja među XOR-ovima podskupova zadanog skupa brojeva.

Metode konstrukcije

Budući da između XOR linearne baze i realne linearne baze nema bitne razlike, u nastavku kao primjer uzimamo XOR linearnu bazu; za inačicu s realnom linearnom bazom kôd treba samo neznatno izmijeniti.

Pohlepna metoda

Svaki broj \(p\) izvornog skupa zapišemo binarno i prolazimo od najvišeg bita prema najnižem; za svaki bit \(x\) koji je \(1\): ako \(a_x\) ne postoji, postavimo \(a_x \leftarrow p\) i završimo prolaz; ako postoji, postavimo \(p\leftarrow p~\text{xor}~a_x\).

Za upit o najvećem \(\text{xor}\)-u bilo kojih nekoliko elemenata izvornog skupa dovoljno je proći linearnu bazu od najvišeg bita prema najnižem; ako se \(\text{xor}\)-anjem s trenutačnim \(a_x\) odgovor poveća, odgovor XOR-amo s \(a_x\).

Zašto to radi? Zato što pri prolasku od viših bitova prema nižima, ako smo trenutačno na \(i\)-tom bitu, možemo jamčiti da je \(i\)-ti bit odgovora \(1\), a poslije više nema prilike da se \(i\)-ti bit promijeni.

Najmanji \(\text{xor}\) bilo kojih nekoliko elemenata izvornog skupa upravo je najmanji element skupa linearne baze.

Provjera može li se neki broj dobiti kao XOR slična je umetanju: ako se broj \(p\) koji umećemo na kraju XOR-anjem svede na \(0\), taj se broj može dobiti kao XOR.

Kôd (Luogu P3812 【模板】线性基 (Predložak: linearna baza)) 
#include <algorithm>
#include <iostream>
using ull = unsigned long long;

ull p[64];

void insert(ull x) {
  for (int i = 63; ~i; --i) {
    if (!(x >> i))  // i-ti bit od x je 0
      continue;
    if (!p[i]) {
      p[i] = x;
      break;
    }
    x ^= p[i];
  }
}

using std::cin;
using std::cout;

int main() {
  int n;
  cin >> n;
  ull a;
  for (int i = 1; i <= n; ++i) {
    cin >> a;
    insert(a);
  }
  ull ans = 0;
  for (int i = 63; ~i; --i) {
    ans = std::max(ans, ans ^ p[i]);
  }
  cout << ans << '\n';
  return 0;
}

Gaussova eliminacija

Gaussova eliminacija odgovara konstrukciji linearne baze s gledišta sustava linearnih jednadžbi; ispravnost je očita.

Kôd (Luogu P3812 【模板】线性基 (Predložak: linearna baza)) 
#include <iostream>
using ull = unsigned long long;
constexpr int MAXN = 1e5 + 5;

ull deg(ull num, int deg) { return num & (1ull << deg); }

ull a[MAXN];
using std::cin;
using std::cout;

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  int n;
  cin >> n;
  for (int i = 1; i <= n; ++i) cin >> a[i];
  int row = 1;
  for (int col = 63; ~col && row <= n; --col) {
    for (int i = row; i <= n; ++i) {
      if (deg(a[i], col)) {
        std::swap(a[row], a[i]);
        break;
      }
    }
    if (!deg(a[row], col)) continue;
    for (int i = 1; i <= n; ++i) {
      if (i == row) continue;
      if (deg(a[i], col)) {
        a[i] ^= a[row];
      }
    }
    ++row;
  }
  ull ans = 0;
  for (int i = 1; i < row; ++i) {
    ans ^= a[i];
  }
  cout << ans << '\n';
  return 0;
}

Svojstva

Linearna baza konstruirana pohlepnom metodom ima sljedeća svojstva:

  • Linearna baza nema podskup čiji je XOR jednak \(0\).
  • Brojevi u linearnoj bazi imaju različite najviše (vodeće) bitove u binarnom zapisu.

Linearna baza konstruirana Gaussovom eliminacijom zadovoljava sljedeće svojstvo:

  • Matrica nakon Gaussove eliminacije je u reduciranom ešelonskom obliku (po retcima).

    Ovo svojstvo obuhvaća oba svojstva linearne baze konstruirane pohlepnom metodom

Vremenska složenost

Neka je duljina vektora \(n\), a njihov ukupan broj \(m\). Tada je vremenska složenost \(O(nm)\). Gaussova eliminacija ima nešto veću konstantu.

Za realnu linearnu bazu vremenska je složenost \(O(n^2m)\).

Spajanje linearnih baza

Spajanje linearnih baza izvodi se jednostavno grubom silom: elemente jedne od linearnih baza koje spajamo jedan po jedan umećemo u drugu linearnu bazu. Vremenska složenost jednog spajanja je \(O(n^2)\) (XOR linearna baza) odnosno \(O(n^3)\) (realna linearna baza).

Presjek linearnih baza

Presjek linearnih baza, strogo govoreći, jest linearna baza presjeka dvaju vektorskih prostora koje te baze razapinju. U ovom odjeljku opisujemo dva algoritma. Vremenska složenost jednog računanja presjeka za oba je algoritma \(O(n^2)\) (XOR linearna baza) odnosno \(O(n^3)\) (realna linearna baza).

Naivni algoritam

Neka su linearne baze čiji presjek tražimo \(\alpha\) i \(\beta\). Algoritam za presjek linearnih baza dobiva se iz algoritma za spajanje grubom silom sljedećim izmjenama (na primjeru XOR linearne baze):

  • vektore \(\beta_j\) linearne baze \(\beta\) pokušavamo pohlepnom metodom umetnuti u \(\alpha\), a presjek linearnih baza \(\gamma\) inicijaliziramo kao prazan skup;
  • pri umetanju treba za vektor koji umećemo bilježiti doprinos elemenata linearne baze \(\beta\). Konkretno, održavamo novi vektor \(b\), inicijaliziran na \(\beta_j\); ako se vektor koji upravo umećemo XOR-a s vektorom na \(x\)-toj poziciji linearne baze, onda i doprinos \(b\) treba XOR-ati s doprinosom \(b_x\) zabilježenim na \(x\)-toj poziciji;
  • ako umetanje uspije i na \(x\)-tu poziciju linearne baze umetnemo vektor \(\beta_j'\), doprinos \(b_x\) zabilježen na \(x\)-toj poziciji postavimo na doprinos \(b\) elemenata linearne baze \(\beta\) u postupku kojim je dobiven \(\beta_j'\);
  • ako umetanje ne uspije, doprinos \(b\) elemenata linearne baze \(\beta\) zabilježen tijekom postupka umetnemo u \(\gamma\).

Tako dobivena linearna baza \(\gamma\) traženi je presjek; dakako, ovaj algoritam istodobno računa i uniju linearnih baza.

Objašnjenje algoritma

Neka je spojena linearna baza \(\{\alpha_1,\cdots,\alpha_m,\beta'_{j_1},\cdots,\beta'_{j_\ell}\}\), gdje je \(\beta'_{j_k}\) vektor dobiven na kraju umetanja \(\beta_{j_k}\). Tada je i \(\{\alpha_1,\cdots,\alpha_m,\beta_{j_1},\cdots,\beta_{j_\ell}\}\) linearna baza spojenog prostora. Označimo s \(\beta^+\) skup \(\{\beta_{j_1},\cdots,\beta_{j_\ell}\}\); spojena se baza tada može zapisati kao \(\alpha\cup\beta^+\). Štoviše, svaki vektor \(c\) prostora sume može se na jedinstven način prikazati u obliku

\[ c = a\oplus b \]

gdje je \(a\in\operatorname{span}\alpha\) i \(b\in\operatorname{span}\beta^+\). Član \(b\) u ovom rastavu upravo je „doprinos elemenata linearne baze \(\beta\)” koji algoritam iz prethodnog teksta pokušava bilježiti. Strogo govoreći, to je samo doprinos onih vektora iz \(\beta\) koji su na kraju uspješno umetnuti.

Za uspješno umetanje, na kraju zabilježeni \(b\) upravo je član \(b\) tog rastava. Neka je \(\beta_j\in\beta^+\). Na početku je \(\beta_j=0\oplus\beta_j\), što je već ispravan rastav vektora \(\beta_j\) u bazi \(\alpha\cup\beta^+\). Kad \(\beta'_j=a\oplus b\) ažuriramo u \(\beta'_j\oplus c_x\), budući da je \(\beta_j'\oplus c_x=(a\oplus a_x)\oplus(b\oplus b_x)\), dovoljno je \(b\) ažurirati u \(b\oplus b_x\) da bi rastav i dalje bio ispravan. Indukcijom slijedi da je pri konačnom umetanju \(\beta'_j\) u spojenu linearnu bazu zabilježeni doprinos \(b\) upravo član \(b\) gornjeg rastava.

Za neuspješno umetanje, vektor koji umećemo na kraju nužno postaje \(0\), a tadašnji doprinos \(b\) umeće se u \(\gamma\). Ako ponovimo gornje razmatranje, vidjet ćemo da i dalje tijekom umetanja uvijek vrijedi \(\beta_j'=a\oplus b\) uz \(a\in\operatorname{span}\alpha\), samo što \(b\) više ne pripada \(\operatorname{span}\beta^+\). Razlog je taj što pri inicijalizaciji \(\beta_j=0\oplus\beta_j\) vrijedi \(\beta_j\notin\beta^+\). Osim toga, svi članovi koji se pri ažuriranju doprinosa XOR-aju pripadaju \(\operatorname{span}\beta^+\). Stoga zapravo vrijedi \(b\oplus\beta_j\in\operatorname{span}\beta^+\).

Zašto onda umetanjem svih tih \(b\) dobivenih pri neuspješnim umetanjima u \(\gamma\) dobivamo linearnu bazu presjeka? Prvo, ako umetanje \(\beta_j\) ne uspije, na kraju nužno dobivamo \(0=a\oplus b\), gdje je \(a\in\operatorname{span}\alpha\) i \(b\in\operatorname{span}(\beta^+\cup\{\beta_j\})\subseteq\operatorname{span}\beta\). Stoga \(b=a\) nužno leži u presjeku \(\operatorname{span}\alpha\cap\operatorname{span}\beta\). Obratno, neka je \(c\) bilo koji element presjeka. Budući da je \(c\in\operatorname{span}\beta\), \(c\) se može prikazati kao linearna kombinacija (XOR) elemenata iz \(\beta\):

\[ c = \bigoplus_{\beta_j\in\beta}\lambda_j\beta_j, \]

gdje je \(\lambda_j\in\{0,1\}\). Za svaki \(\beta_j\notin\beta^+\) označimo s \(b_j\) pripadni doprinos umetnut u \(\gamma\); tada je

\[ c\oplus\bigoplus_{\beta_j\notin\beta^+}\lambda_jb_j = \bigoplus_{\beta_j\in\beta^+}\lambda_j\beta_j+\bigoplus_{\beta_j\notin\beta^+}\lambda_j(\beta_j\oplus b_j), \]

Primijetimo da \(b_j\) i \(c\) leže u presjeku, pa i lijeva strana nužno leži u presjeku te se može zapisati kao linearna kombinacija elemenata iz \(\alpha\); istodobno, za svaki član desne strane ili je \(\beta_j\in\beta^+\), ili je \(\beta_j\notin\beta^+\) i \(\beta_j\oplus b_j\in\beta^+\), pa je desna strana zapravo linearna kombinacija elemenata iz \(\beta^+\). No \(\alpha\cup\beta^+\) je linearno nezavisan, pa su svi koeficijenti jednaki \(0\), odnosno \(c=\bigoplus_{\beta_j\notin\beta^+}\lambda_jb_j\in\operatorname{span}\{b_1,\cdots,b_j\}\). Time je pokazano da doprinosi \(b\) vektora koji se nisu mogli umetnuti zajedno razapinju presjek.

Prema ovom objašnjenju, svrha održavanja doprinosa \(b\) tijekom postupka zapravo je održavanje rastava \(a\oplus b\); štoviše, pri konačnom umetanju doprinosa u \(\gamma\) uvijek je \(a=b\). Stoga je rezultat ispravan bez obzira na to održavamo li doprinos elemenata iz \(\alpha\) ili iz \(\beta\) (tj. održavamo li \(a\) ili \(b\)). Ako želimo održavati doprinos elemenata linearne baze \(\alpha\), dovoljno je izmijeniti početne vrijednosti doprinosa: svaki vektor \(\alpha_i\) iz \(\alpha\) na početku ima doprinos \(\alpha_i\), a umetnuti \(\beta_j\) ima početni doprinos \(0\).

Kôd (Library Checker Intersection of \(\mathbf F_2\) vector spaces) 
#include <array>
#include <iostream>

class LinearBasis {
  static constexpr int K = 30;
  std::array<int, K> a;

  // Size of basis.
  int size() const {
    int res = 0;
    for (auto x : a) {
      if (x) {
        ++res;
      }
    }
    return res;
  }

 public:
  LinearBasis() : a{} {}

  // Insert vector x.
  void insert(int x) {
    for (int k = K - 1; ~k && x; --k) {
      if ((x >> k) & 1) {
        if (!a[k]) {
          a[k] = x;
        }
        x ^= a[k];
      }
    }
  }

  // Return a basis for *THIS intersecting RHS.
  LinearBasis intersect(const LinearBasis& rhs) const {
    LinearBasis res;
    std::array<int, K> c = a, b_parts = {};
    for (int i = K - 1; ~i; --i) {
      int x = rhs.a[i], b_part = x;
      for (int k = i; ~k && x; --k) {
        if ((x >> k) & 1) {
          if (!c[k]) {
            c[k] = x;
            b_parts[k] = b_part;
          }
          x ^= c[k];
          b_part ^= b_parts[k];
        }
      }
      res.insert(b_part);
    }
    return res;
  }

  // Output.
  void print() const {
    std::cout << size();
    for (auto x : a) {
      if (x) {
        std::cout << ' ' << x;
      }
    }
    std::cout << '\n';
  }
};

int main() {
  int t;
  std::cin >> t;
  for (; t; --t) {
    LinearBasis a, b;
    int n;
    std::cin >> n;
    for (; n; --n) {
      int x;
      std::cin >> x;
      a.insert(x);
    }
    int m;
    std::cin >> m;
    for (; m; --m) {
      int x;
      std::cin >> x;
      b.insert(x);
    }
    a.intersect(b).print();
  }
  return 0;
}

Zassenhausov algoritam

Drugi, ekvivalentan postupak jest Zassenhausov algoritam, koji također istodobno računa uniju i presjek dviju linearnih baza. Složenost je potpuno jednaka gore navedenoj.

Konkretni koraci:

  • inicijaliziramo praznu linearnu bazu \(\gamma\) vektora duljine \(2n\), čije vektore zapisujemo u obliku \((a,b)\), gdje su \(a\) i \(b\) duljine \(n\);
  • elemente \(\alpha_i\) iz \(\alpha\) umećemo u \(\gamma\) u obliku \((\alpha_i,\alpha_i)\);
  • elemente \(\beta_j\) iz \(\beta\) umećemo u \(\gamma\) u obliku \((\beta_j,0)\);
  • među svim elementima \((c_k,d_k)\) različitim od nule u konačnoj linearnoj bazi \(\gamma\), komponente \(c_k\) onih vektora kod kojih je \(c_k\) različit od nule zajedno čine linearnu bazu unije \(\alpha\) i \(\beta\), a komponente \(d_k\) onih vektora kod kojih je \(c_k\) jednak nuli zajedno čine linearnu bazu presjeka \(\alpha\) i \(\beta\).

Metoda konstrukcije linearne baze u algoritmu može biti pohlepna metoda ili Gaussova eliminacija; važno je samo da linearna baza u \(\gamma\) čini matricu u ešelonskom obliku (po retcima).

Usporedimo li korake eliminacije u Zassenhausovu algoritmu s gornjim naivnim algoritmom, lako uočavamo da Zassenhausov algoritam zasnovan na pohlepnoj metodi odgovara naivnom algoritmu koji održava doprinos elemenata iz \(\alpha\). Ako umjesto toga najprije umetnemo sve \((\alpha_i,0)\), a zatim sve \((\beta_j,\beta_j)\), Zassenhausov algoritam zasnovan na pohlepnoj metodi odgovara naivnom algoritmu koji održava doprinos elemenata iz \(\beta\). Iz ekvivalentnosti koraka eliminacije slijedi i ispravnost Zassenhausova algoritma.

Osim toga, možemo dati i neovisan, općenitiji algebarski dokaz:

Dokaz ispravnosti

Neka je \(V\) vektorski prostor s potprostorima \(U=\operatorname{span}\alpha\) i \(W=\operatorname{span}\beta\). Sam algoritam odgovara određivanju, svođenjem na ešelonski oblik, baze \(\gamma\) potprostora

\[ H = \operatorname{span}(\{(\alpha_i,\alpha_i):\alpha_i\in\alpha\}\cup\{(\beta_j,0):\beta_j\in\beta\}) \]

Na kraju algoritma elemente \((c_k,d_k)\) iz \(\gamma\) treba podijeliti u dvije klase prema tome je li \(c_k\neq 0\), pa promotrimo projekciju \(\pi:H\rightarrow V\), \(\pi(a,b)=a\). Tada je \(\pi(H)=U+W\) i lako se provjerava

\[ \begin{aligned} \ker\pi &= H\cap(\{0\}\times V) = \{0\}\times(U\times W). \end{aligned} \]

Prema teoremu o linearnim preslikavanjima vrijedi \(\dim H = \dim\pi(H)+\dim\ker\pi = \dim(U+W)+\dim(U\cap W)\).

Prvih nekoliko stupaca matrice u ešelonskom obliku i dalje čini matricu u ešelonskom obliku, pa je broj redaka s \(c_k\neq 0\) upravo jednak rangu po retcima skupa \(\alpha\cup\beta\), tj. \(\dim(U+W)\); štoviše, skup komponenata \(c_k\) tih redaka čini bazu prostora \(U+W\). Preostalih redaka različitih od nule ima točno \(\dim(U\cap W)\) i svi zadovoljavaju \(c_k=0\). Za komponente \(d_k\) tih redaka vrijedi \((0,d_k)\in\ker\pi\), pa je \(d_k\in U\cap W\); k tome su \((0,d_k)\), kao retci matrice u ešelonskom obliku, nužno linearno nezavisni, pa su i ti \(d_k\) linearno nezavisni. Sve zajedno, ti \(d_k\) čine linearno nezavisan skup veličine \(\dim(U\cap W)\) u presjeku \(U\cap W\), pa su nužno i baza tog prostora.

Proširenje: prefiksna linearna baza

U ovom odjeljku razmatramo samo slučaj XOR linearne baze te pretpostavljamo da se jedan vektor može pohraniti u \(O(1)\) prostora i da je složenost jedne operacije uvijek \(O(1)\).

Kad je potrebno više puta odgovoriti na upit o najvećem XOR-u na intervalu, uobičajen je pristup cat tree u kombinaciji s linearnom bazom, vremenske složenosti \(O(nm\log m+n^2q)\), gdje je \(n\) duljina vektora, \(m\) duljina niza, a \(q\) broj upita. Drugi mogući pristup jest prefiksna linearna baza (ili linearna baza s vremenskim oznakama), kojom se složenost može smanjiti na \(O(n(m+q))\).

Prefiksna linearna baza omogućuje da za svaki prefiks niza održavamo linearne baze svih sufiksa tog prefiksa, čime se podržava upit o linearnoj bazi svakog intervala. Primijetimo da su linearne baze svih sufiksa \([j,i]\) nekog prefiksa \([1,i]\) niza međusobno ugniježđene, tj. linearna baza intervala \([j,i]\) uvijek sadrži linearnu bazu intervala \([j+1,i]\); stoga među linearnim bazama tih sufiksa ima najviše \(n\) međusobno različitih, a sve linearne baze sufiksa od \([i,i]\) do \([1,i]\) uvijek se mogu dobiti postupnim dodavanjem novih vektora u prazan skup. Dakle, zahvaljujući toj monotonosti, dovoljno je svaki dodani vektor \(v\) označiti najvećim indeksom \(t\) na kojem se pojavljuje, pa se linearne baze svih sufiksa mogu pohraniti u \(O(n)\) prostora. Štoviše, pri upitu o linearnoj bazi intervala \([j,i]\) dovoljno je u prefiksnoj linearnoj bazi na poziciji \(i\) zadržati samo vektore s oznakom \(t\ge j\).

Oznaku \(t\) vektora \(v\) nazovimo njegovom vremenskom oznakom. Vektor \(v\) u linearnoj bazi uvijek se može prikazati kao XOR nekih elemenata izvornog niza, npr. \(v_{i_1}\oplus v_{i_2}\oplus\cdots\oplus v_{i_k}\). Među svim takvim mogućim prikazima, najveći od najmanjih indeksa upravo je \(t\), tj.

\[ t(v) = \max\{j:\exists i_1,\cdots,i_k\in[j,i]\text{ s.t. }v=v_{i_1}\oplus v_{i_2}\oplus\cdots\oplus v_{i_k}\}. \]

Ovaj izraz samo formalnim jezikom zapisuje ono što je rečeno u prethodnom odlomku. Pouka koju nam daje jest da za održavanje vremenske oznake svakog vektora \(v\) u linearnoj bazi treba samo pohlepno birati što novije vektore kojima zamjenjujemo stare.

U odnosu na gore opisanu konstrukciju linearne baze pohlepnom metodom, prefiksna linearna baza u postupku konstrukcije radi sljedeće izmjene:

  • za svaki vektor \(a_x\) zadržan u linearnoj bazi čuvamo vremensku oznaku \(t_x\), početno postavljenu na \(0\);
  • pri dodavanju \(i\)-tog vektora \(v\) niza i dalje prolazimo od viših bitova prema nižima, ali istodobno bilježimo trenutačno vrijeme \(i\);
  • ako je \(x\)-ti bit vektora \(v\) jedinica, uspoređujemo vremensku oznaku \(t_x\) postojećeg vektora \(a_x\) u linearnoj bazi s trenutačnim vremenom \(i\):
    • ako je \(i>t_x\), tj. vektor koji dodajemo je noviji, postavimo \(a_x\) na \(v\), ažuriramo vremensku oznaku na \(i\) te postupak dodavanja nastavljamo s rezultatom XOR-a starog \(a_x\) i \(v\), \(a_x\oplus v\), uz prije zabilježeno vrijeme \(t_x\);
    • ako je \(i<t_x\), tj. vektor koji dodajemo je stariji, ne ažuriramo \(a_x\) ni \(t_x\), nego \(v\) XOR-amo s \(a_x\) i nastavljamo dodavanje.

Drugim riječima, ako se trenutačni bit može prikazati novijim vektorom, izravno koristimo noviji vektor; inače zadržavamo postojeći. Pri ažuriranju vektora na poziciji \(x\) ne smijemo rezultat XOR-a \(a_x\oplus v\) pohraniti na poziciju \(x\), jer je vremenska oznaka rezultata \(a_x\oplus v\) jednaka \(\min\{t(a_x)=t(v)\}=t(a_x)\), što je manje od vremenske oznake \(t(v)\) vektora \(v\) koji dodajemo. Iz istog razloga, ažuriranje prema gore u konstrukciji linearne baze Gaussovom eliminacijom može narušiti svojstvo vremenskih oznaka, pa ona više nije prikladna za konstrukciju prefiksne linearne baze.

Kôd (Codeforces 1100F Ivan and Burgers) 
#include <algorithm>
#include <array>
#include <iostream>
#include <numeric>
#include <vector>

class LinearBasis {
  static constexpr int K = 20;
  std::array<int, K> a, t;

 public:
  LinearBasis() : a{}, t{} {}

  // Insert vector x at time i.
  void insert(int x, int i) {
    for (int k = K - 1; ~k && x; --k) {
      if (((x >> k) & 1)) {
        if (i > t[k]) {
          std::swap(a[k], x);
          std::swap(t[k], i);
        }
        x ^= a[k];
      }
    }
  }

  // Find max xor of subsets of elements from time i till now.
  int query(int i) const {
    int res = 0;
    for (int k = K - 1; ~k; --k) {
      if (t[k] >= i && (res ^ a[k]) > res) {
        res ^= a[k];
      }
    }
    return res;
  }
};

int main() {
  int n;
  std::cin >> n;
  std::vector<int> c(n + 1);
  for (int i = 1; i <= n; ++i) std::cin >> c[i];
  int q;
  std::cin >> q;
  std::vector<std::array<int, 2>> qu(q);
  for (auto& v : qu) std::cin >> v[0] >> v[1];
  std::vector<int> ids(q);
  std::iota(ids.begin(), ids.end(), 0);
  std::sort(ids.begin(), ids.end(),
            [&](int l, int r) -> bool { return qu[l][1] < qu[r][1]; });
  LinearBasis lb;
  std::vector<int> res(q);
  for (int i = 1, j = 0; i <= n; ++i) {
    lb.insert(c[i], i);
    for (; j < q && qu[ids[j]][1] == i; ++j) {
      res[ids[j]] = lb.query(qu[ids[j]][0]);
    }
  }
  for (int x : res) std::cout << x << '\n';
  return 0;
}

Recall the concept of basis vectors from high-school solid geometry: in three-dimensional Euclidean space we can find a set of basis vectors \(\boldsymbol{i}\), \(\boldsymbol{j}\), \(\boldsymbol{k}\), after which every vector in the space can be expressed in terms of these basis vectors. In other words, we can describe the infinite three-dimensional space using finitely many basis vectors, which is enough to show the importance of basis vectors.

Three-dimensional Euclidean space is a special vector space, and the basis vectors of three-dimensional Euclidean space are generalized to the linear basis in vector spaces.

Applications of the linear basis in OI generally involve only two kinds of vector spaces: the \(n\)-dimensional real vector space \(\mathbf{R}^n\) and the \(n\)-dimensional vector space over the Boolean domain \(\mathbf{Z}_2^n\); we discuss them in detail in the Applications section. If you are not familiar with linear algebra, we recommend starting from the applications part.

Below we introduce the linear basis starting from general vector spaces and give its common properties.

Prerequisites: vector space.

A linear basis is a basis of a vector space and is an important tool for studying vector spaces.

Definition

A maximal linearly independent subset of a vector space \(V\) is called a Hamel basis or linear basis of \(V\), or simply a basis.

By convention, the basis of the vector space \(\{\theta\}\) is the empty set.

It can be proved that every vector space has a linear basis1; we define the dimension of a vector space \(V\) as the number of elements (or cardinality) of a linear basis, denoted \(\dim V\).

Properties

  1. For a finite-dimensional vector space \(V\) of dimension \(n\):

    1. Any \(n+1\) vectors in \(V\) are linearly dependent.

    2. Any \(n\) linearly independent vectors in \(V\) form a basis of \(V\).

    3. If every vector in \(V\) can be linearly expressed by the set of vectors \(a_1,a_2,\dots,a_n\), then it is a basis of \(V\).

      Proof

      Take any basis \(b_1,b_2,\dots,b_n\) of \(V\). By assumption, the set of vectors \(b_1,b_2,\dots,b_n\) can be linearly expressed by \(a_1,a_2,\dots,a_n\), so

      \[ n=\operatorname{rank}\{b_1,b_2,\dots,b_n\}\leq\operatorname{rank}\{a_1,a_2,\dots,a_n\}\leq n \]

      Therefore \(\operatorname{rank}\{a_1,a_2,\dots,a_n\}=n\)

    4. Any linearly independent set of vectors \(a_1,a_2,\dots,a_m\) in \(V\) can be extended to a basis of \(V\) by inserting some vectors.

  2. (Dimension formula for subspaces) Let \(V_1,V_2\) be finite-dimensional vector spaces over \(\Bbb{P}\) such that \(V_1+V_2\) and \(V_1\cap V_2\) are also finite-dimensional. Then \(\dim V_1+\dim V_2=\dim(V_1+V_2)+\dim(V_1\cap V_2)\)

    Proof

    Let \(\dim V_1=n_1\), \(\dim V_2=n_2\), \(\dim(V_1\cap V_2)=m\).

    Take a basis \(a_1,a_2,\dots,a_m\) of \(V_1\cap V_2\) and extend it to bases of \(V_1\) and \(V_2\) respectively: \(a_1,a_2,\dots,a_m,b_1,b_2,\dots,b_{n_1-m}\) and \(a_1,a_2,\dots,a_m,c_1,c_2,\dots,c_{n_2-m}\).

    It remains only to prove that the set of vectors \(a_1,a_2,\dots,a_m,b_1,b_2,\dots,b_{n_1-m},c_1,c_2,\dots,c_{n_2-m}\) is linearly independent.

    Suppose \(\sum_{i=1}^m r_ia_i+\sum_{i=1}^{n_1-m} s_ib_i+\sum_{i=1}^{n_2-m} t_ic_i=\theta\).

    Then \(\sum_{i=1}^{n_2-m} t_ic_i=-\sum_{i=1}^m r_ia_i-\sum_{i=1}^{n_1-m} s_ib_i\).

    Note that the left-hand side is in \(V_2\) and the right-hand side is in \(V_1\), so both sides are in \(V_1\cap V_2\); hence \(\sum_{i=1}^{n_2-m} t_ic_i=\sum_{i=1}^m k_ia_i\)

    Thus \(t_1=t_2=\dots=t_{n_2-m}=k_1=k_2=\dots=k_m=0\), and consequently \(r_1=r_2=\dots=r_m=s_1=s_2=\dots=s_{n_1-m}=t_1=t_2=\dots=t_{n_2-m}=0\)

  3. Let \(V_1,V_2\) be finite-dimensional vector spaces over \(\Bbb{P}\) such that \(V_1+V_2\) and \(V_1\cap V_2\) are also finite-dimensional. Then the following statements are equivalent:

    1. \(V_1+V_2=V_1\oplus V_2\).

    2. \(\dim V_1+\dim V_2=\dim(V_1+V_2)\).

    3. If \(a_1,a_2,\dots,a_n\) is a basis of \(V_1\) and \(b_1,b_2,\dots,b_m\) is a basis of \(V_2\), then \(a_1,a_2,\dots,a_n,b_1,b_2,\dots,b_m\) is a basis of \(V_1+V_2\).

    Note

    Statements 1 and 3 can be generalized to infinite-dimensional vector spaces.

Orthogonal and orthonormal bases

If a basis \(B\) of a vector space \(V\) satisfies \(\forall b,b'\in B,~(b,b')\ne 0\iff b=b'\) (i.e. the vectors are pairwise orthogonal), the basis is called an orthogonal basis.

If an orthogonal basis \(B\) of a vector space \(V\) also satisfies \(\forall b\in B,~|b|=\sqrt{(b,b)}=1\), the basis is called an orthonormal basis.

Any basis of a finite-dimensional vector space \(V\) can be transformed into an orthogonal basis by the Gram–Schmidt process.

Applications

Based on the above, we can use a linear basis to:

  1. find the rank of a given set of vectors;
  2. for a given set of vectors, find a maximal linearly independent subset (or a basis of the vector space it spans);
  3. insert some vectors into a given set of vectors and find a maximal linearly independent subset (or a basis of the vector space it spans) of the set after the insertions;
  4. for a maximal linearly independent subset (or basis) that has been found, determine whether a given vector can be linearly expressed by it;
  5. for a maximal linearly independent subset (or basis) that has been found, find special elements of the vector space it spans (such as the maximum element, the minimum element, etc.).

In OI, a linear basis in the \(n\)-dimensional real vector space \(\mathbf{R}^n\) is usually called a real linear basis, and a linear basis in the \(n\)-dimensional vector space over the Boolean domain \(\mathbf{Z}_2^n\) is called an XOR linear basis.

Tip

In \(\mathbf{Z}_2\), addition is XOR and multiplication is AND; it can be proved that \(\mathbf{Z}_2\) is a field.

It can be proved that the algebraic structure \((\mathbf{Z}_2^n,+,\cdot,\mathbf{Z}_2)\) is a vector space, where:

\[ (a_1,\dots,a_n)+(b_1,\dots,b_n):=(a_1+b_1,\dots,a_n+b_n), \]
\[ k\cdot(a_1,\dots,a_n):=(ka_1,\dots,ka_n). \]

That is, addition is XOR and scalar multiplication is AND.

Taking the XOR linear basis as an example, from a given set of Boolean sequences \(X=\{x_1,\dots,x_m\}\) we can construct an XOR linear basis \(B=\{b_1,\dots,b_n\}\) with the following properties:

  1. The XOR of any nonempty subset of \(B\) is not \(0\);
  2. For any element \(x\) of \(X\), some elements of \(B\) can be chosen whose XOR equals \(x\);
  3. Any set \(B'\) satisfying the two properties above has no fewer elements than \(B\).

Using an XOR linear basis we can:

  1. determine whether a number can be expressed as the XOR of a subset of a given set of numbers;
  2. count the number of ways a number can be expressed as the XOR of a subset of a given set of numbers;
  3. find the maximum/minimum/\(k\)-th largest/\(k\)-th smallest XOR of a subset of a given set of numbers;
  4. find the rank of a number among the subset XORs of a given set of numbers.

Construction methods

Since there is no essential difference between the XOR linear basis and the real linear basis, we take the XOR linear basis as the example below; the real linear basis version of the code only needs a few simple modifications.

Greedy method

Convert each number \(p\) of the original set to binary and scan from the highest bit to the lowest. For each bit \(x\) that is \(1\): if \(a_x\) does not exist, set \(a_x \leftarrow p\) and end the scan; if it exists, set \(p\leftarrow p~\text{xor}~a_x\).

To query the maximum \(\text{xor}\) of any number of elements of the original set, just scan the linear basis from the highest bit to the lowest; if \(\text{xor}\)-ing the answer with the current \(a_x\) makes it larger, XOR the answer with \(a_x\).

Why does this work? Because when scanning from high bits to low bits, if we are currently at bit \(i\), it means we can guarantee that bit \(i\) of the answer is \(1\), and there is no later chance to change bit \(i\).

The minimum \(\text{xor}\) of any number of elements of the original set is simply the smallest element of the linear basis set.

Querying whether a number can be obtained as an XOR is similar to insertion: if the number \(p\) being inserted is finally XOR-ed down to \(0\), then it can be obtained as an XOR.

#include <algorithm>
#include <iostream>
using ull = unsigned long long;

ull p[64];

void insert(ull x) {
  for (int i = 63; ~i; --i) {

      continue;
    if (!p[i]) {
      p[i] = x;
      break;
    }

}

Gaussian elimination

Gaussian elimination amounts to constructing the linear basis from the viewpoint of systems of linear equations; its correctness is obvious.

Code (Luogu P3812 【模板】线性基 (Template: linear basis)) 
#include <iostream>
using ull = unsigned long long;
constexpr int MAXN = 1e5 + 5;

ull deg(ull num, int deg) { return num & (1ull << deg); }

ull a[MAXN];
using std::cin;
using std::cout;

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  int n;
  cin >> n;
  for (int i = 1; i <= n; ++i) cin >> a[i];
  int row = 1;
  for (int col = 63; ~col && row <= n; --col) {
    for (int i = row; i <= n; ++i) {
      if (deg(a[i], col)) {
        std::swap(a[row], a[i]);
        break;
      }
    }
    if (!deg(a[row], col)) continue;
    for (int i = 1; i <= n; ++i) {
      if (i == row) continue;
      if (deg(a[i], col)) {
        a[i] ^= a[row];
      }
    }
    ++row;
  }
  ull ans = 0;
  for (int i = 1; i < row; ++i) {
    ans ^= a[i];
  }
  cout << ans << '\n';
  return 0;
}

Time complexity

Let the vector length be \(n\) and the total number of vectors be \(m\). Then the time complexity is \(O(nm)\). Gaussian elimination has a slightly larger constant.

For a real linear basis, the time complexity is \(O(n^2m)\).

Merging linear bases

Merging linear bases only requires brute force, i.e. inserting the vectors of one linear basis into the other one by one. The time complexity of a single merge is \(O(n^2)\) (XOR linear basis) or \(O(n^3)\) (real linear basis).

Intersection of linear bases

The intersection of linear bases, strictly speaking, is a linear basis of the intersection of the two vector spaces they span. This section introduces two algorithms. For both algorithms, the time complexity of a single intersection is \(O(n^2)\) (XOR linear basis) or \(O(n^3)\) (real linear basis).

Naive algorithm

Let the linear bases to be intersected be \(\alpha\) and \(\beta\). The algorithm for intersecting linear bases only requires the following adjustments to the brute-force merging algorithm (taking the XOR linear basis as an example):

  • Try to insert the vectors \(\beta_j\) of the linear basis \(\beta\) into \(\alpha\) using the greedy method, and initialize the intersection \(\gamma\) of the linear bases as the empty set;
  • During insertion, record the contribution of the elements of the linear basis \(\beta\) to the vector being inserted. Specifically, maintain a new vector \(b\), initialized to \(\beta_j\); moreover, if the vector being inserted is XOR-ed with the vector at position \(x\) of the linear basis, then the contribution \(b\) must also be XOR-ed with the contribution \(b_x\) recorded at position \(x\);
  • If the insertion succeeds and the vector \(\beta_j'\) is inserted at position \(x\) of the linear basis, set the \(b_x\) recorded at position \(x\) to the contribution \(b\) of the elements of the linear basis \(\beta\) in the process of obtaining \(\beta_j'\);
  • If the insertion fails, insert the contribution \(b\) of the elements of the linear basis \(\beta\) recorded during the process into \(\gamma\).

The linear basis \(\gamma\) obtained this way is the desired intersection; of course, this algorithm also computes the union of the linear bases at the same time.

Explanation of the algorithm

Let the merged linear basis be \(\{\alpha_1,\cdots,\alpha_m,\beta'_{j_1},\cdots,\beta'_{j_\ell}\}\), where \(\beta'_{j_k}\) is the vector finally obtained when inserting \(\beta_{j_k}\). Then \(\{\alpha_1,\cdots,\alpha_m,\beta_{j_1},\cdots,\beta_{j_\ell}\}\) is also a linear basis of the merged space. Denote by \(\beta^+\) the set \(\{\beta_{j_1},\cdots,\beta_{j_\ell}\}\); then the merged basis can be written as \(\alpha\cup\beta^+\). Moreover, every vector \(c\) in the sum space can be uniquely written in the form

\[ c = a\oplus b \]

where \(a\in\operatorname{span}\alpha\) and \(b\in\operatorname{span}\beta^+\). The \(b\) in this decomposition is exactly the "contribution of the elements of the linear basis \(\beta\)" that the algorithm above attempts to record. Strictly speaking, it is only the contribution of those vectors of \(\beta\) that were finally inserted successfully.

For a successful insertion, the finally recorded \(b\) is exactly the \(b\) term of this decomposition. Let \(\beta_j\in\beta^+\). Initially, \(\beta_j=0\oplus\beta_j\), which is already the correct decomposition of \(\beta_j\) in the basis \(\alpha\cup\beta^+\). When updating \(\beta'_j=a\oplus b\) to \(\beta'_j\oplus c_x\), since \(\beta_j'\oplus c_x=(a\oplus a_x)\oplus(b\oplus b_x)\), it suffices to update \(b\) to \(b\oplus b_x\) to keep the decomposition correct. Therefore, by induction, when \(\beta'_j\) is finally inserted into the merged linear basis, the recorded contribution \(b\) is exactly the \(b\) term of the decomposition above.

For a failed insertion, the vector to be inserted eventually becomes \(0\), and the contribution \(b\) at that moment is inserted into \(\gamma\). If we repeat the argument above, we find that during the insertion it is still guaranteed that \(\beta_j'=a\oplus b\) with \(a\in\operatorname{span}\alpha\), except that \(b\) no longer belongs to \(\operatorname{span}\beta^+\). This is because at initialization, in \(\beta_j=0\oplus\beta_j\) we have \(\beta_j\notin\beta^+\). Apart from that, all terms XOR-ed in when updating the contribution belong to \(\operatorname{span}\beta^+\). So, in fact, \(b\oplus\beta_j\in\operatorname{span}\beta^+\).

Then why does inserting all these \(b\) from failed insertions into \(\gamma\) yield a linear basis of the intersection space? First, if inserting \(\beta_j\) fails, we eventually get \(0=a\oplus b\), where \(a\in\operatorname{span}\alpha\) and \(b\in\operatorname{span}(\beta^+\cup\{\beta_j\})\subseteq\operatorname{span}\beta\). Therefore \(b=a\) necessarily lies in the intersection space \(\operatorname{span}\alpha\cap\operatorname{span}\beta\). Conversely, let \(c\) be any element of the intersection space. Since \(c\in\operatorname{span}\beta\), \(c\) can be written as a linear combination (XOR sum) of elements of \(\beta\):

\[ c = \bigoplus_{\beta_j\in\beta}\lambda_j\beta_j, \]

where \(\lambda_j\in\{0,1\}\). For each \(\beta_j\notin\beta^+\), denote by \(b_j\) the corresponding contribution inserted into \(\gamma\); then

\[ c\oplus\bigoplus_{\beta_j\notin\beta^+}\lambda_jb_j = \bigoplus_{\beta_j\in\beta^+}\lambda_j\beta_j+\bigoplus_{\beta_j\notin\beta^+}\lambda_j(\beta_j\oplus b_j), \]

Note that \(b_j\) and \(c\) both lie in the intersection space, so the left-hand side must also lie in the intersection space and can therefore be written as a linear combination of elements of \(\alpha\); at the same time, for every term on the right-hand side, either \(\beta_j\in\beta^+\), or \(\beta_j\notin\beta^+\) and \(\beta_j\oplus b_j\in\beta^+\), so the right-hand side is in fact a linear combination of elements of \(\beta^+\). But \(\alpha\cup\beta^+\) is linearly independent, so all coefficients are \(0\), that is, \(c=\bigoplus_{\beta_j\notin\beta^+}\lambda_jb_j\in\operatorname{span}\{b_1,\cdots,b_j\}\). This shows that the contributions \(b\) of the vectors that could not be inserted together span the intersection space.

According to this explanation, the purpose of maintaining the contribution \(b\) during the process is in fact to maintain the decomposition \(a\oplus b\); moreover, when the contribution is finally inserted into \(\gamma\), we always have \(a=b\). Therefore, whether we maintain the contribution of the elements of \(\alpha\) or of \(\beta\) (i.e. whether we maintain \(a\) or \(b\)), the result is correct. To maintain the contribution of the elements of the linear basis \(\alpha\), it suffices to change the initial values of the contributions: each vector \(\alpha_i\) in \(\alpha\) initially has contribution \(\alpha_i\), while an inserted \(\beta_j\) has initial contribution \(0\).

class LinearBasis {

      if (x) {
        ++res;
      }
    }

    for (int k = K - 1; ~k && x; --k) {

        if (!a[k]) {
          a[k] = x;
        }
        x ^= a[k];
      }
    }

    LinearBasis res;
    std::array<int, K> c = a, b_parts = {};
    for (int i = K - 1; ~i; --i) {

      for (int k = i; ~k && x; --k) {

            c[k] = x;
            b_parts[k] = b_part;
          }
          x ^= c[k];
          b_part ^= b_parts[k];
        }
      }
      res.insert(b_part);
    }
    return res;
  }

  void print() const {
    std::cout << size();
    for (auto x : a) {
      if (x) {
        std::cout << ' ' << x;
      }
    }
    std::cout << '\n';
  }
};

Zassenhaus algorithm

Another equivalent approach is the Zassenhaus algorithm, which likewise computes the union and the intersection of two linear bases at the same time. The complexity is exactly the same as above.

The concrete steps are as follows:

  • Initialize an empty linear basis \(\gamma\) of vectors of length \(2n\), where the vectors are written in the form \((a,b)\) with \(a\) and \(b\) both of length \(n\);
  • Insert the elements \(\alpha_i\) of \(\alpha\) into \(\gamma\) in the form \((\alpha_i,\alpha_i)\);
  • Insert the elements \(\beta_j\) of \(\beta\) into \(\gamma\) in the form \((\beta_j,0)\);
  • Among all nonzero elements \((c_k,d_k)\) of the resulting linear basis \(\gamma\), the components \(c_k\) of those vectors with nonzero \(c_k\) together form a linear basis of the union of \(\alpha\) and \(\beta\), and the components \(d_k\) of those vectors with zero \(c_k\) together form a linear basis of the intersection of \(\alpha\) and \(\beta\).

The method of constructing the linear basis in the algorithm can be either the greedy method or Gaussian elimination, as long as the linear basis in \(\gamma\) forms a matrix in row echelon form.

Comparing the elimination steps in the Zassenhaus algorithm with the naive algorithm above, it is easy to see that the Zassenhaus algorithm based on the greedy method is equivalent to the naive algorithm maintaining the contribution of the elements of \(\alpha\). If instead we first insert all \((\alpha_i,0)\) and then all \((\beta_j,\beta_j)\), the Zassenhaus algorithm based on the greedy method is equivalent to the naive algorithm maintaining the contribution of the elements of \(\beta\). By the equivalence of the elimination steps, the correctness of the Zassenhaus algorithm also holds.

In addition, an independent and more general algebraic proof can be given:

Proof of correctness

Let \(V\) be a vector space with subspaces \(U=\operatorname{span}\alpha\) and \(W=\operatorname{span}\beta\). The algorithm itself amounts to finding, by reduction to row echelon form, a basis \(\gamma\) of the subspace

\[ H = \operatorname{span}(\{(\alpha_i,\alpha_i):\alpha_i\in\alpha\}\cup\{(\beta_j,0):\beta_j\in\beta\}) \]

At the end of the algorithm, the elements \((c_k,d_k)\) of \(\gamma\) need to be divided into two classes according to whether \(c_k\neq 0\), so consider the projection map \(\pi:H\rightarrow V\) with \(\pi(a,b)=a\). Then \(\pi(H)=U+W\), and it is easy to verify that

\[ \begin{aligned} \ker\pi &= H\cap(\{0\}\times V) = \{0\}\times(U\times W). \end{aligned} \]

By the theorem on linear maps, \(\dim H = \dim\pi(H)+\dim\ker\pi = \dim(U+W)+\dim(U\cap W)\).

The first few columns of a matrix in row echelon form still form a matrix in row echelon form, so the number of rows with \(c_k\neq 0\) is exactly the row rank of \(\alpha\cup\beta\), i.e. \(\dim(U+W)\); moreover, the set of \(c_k\) in these rows forms a basis of \(U+W\). The remaining nonzero rows number exactly \(\dim(U\cap W)\) and all satisfy \(c_k=0\). For the \(d_k\) in these rows, since \((0,d_k)\in\ker\pi\), we have \(d_k\in U\cap W\); moreover, the \((0,d_k)\), being rows of a matrix in row echelon form, are necessarily linearly independent, which shows that these \(d_k\) are linearly independent. Putting it all together, these \(d_k\) form a linearly independent set of size \(\dim(U\cap W)\) in the intersection space \(U\cap W\), so they must also be a basis of that space.

Extension: prefix linear basis

This section only discusses the case of the XOR linear basis, and assumes that a single vector can be stored in \(O(1)\) space and that a single operation always takes \(O(1)\) time.

When the maximum XOR on a range needs to be queried many times, a common approach is the cat tree combined with a linear basis, with time complexity \(O(nm\log m+n^2q)\), where \(n\) is the vector length, \(m\) is the sequence length and \(q\) is the number of queries. Another feasible approach is the prefix linear basis (also called the timestamped linear basis), which reduces the complexity to \(O(n(m+q))\).

The prefix linear basis allows us to maintain, for every prefix of the sequence, the linear bases of all suffixes of that prefix, so that the linear basis of every range can be queried. Note that the linear bases of all suffixes \([j,i]\) of a prefix \([1,i]\) of the sequence are nested in one another, i.e. the linear basis of \([j,i]\) always contains the linear basis of \([j+1,i]\); therefore, among the linear bases of these suffixes there are at most \(n\) distinct ones, and the linear bases of all these suffixes from \([i,i]\) to \([1,i]\) can always be obtained by gradually adding new vectors to the empty set. Hence, using this monotonicity, we only need to mark each added vector \(v\) with the largest index \(t\) at which it appears, and the linear bases of all suffixes can be stored in \(O(n)\) space. Moreover, when querying the linear basis corresponding to the range \([j,i]\), we only need to keep those vectors in the prefix linear basis at \(i\) whose mark satisfies \(t\ge j\).

Let us call the mark \(t\) of each vector \(v\) its timestamp. A vector \(v\) in the linear basis can always be expressed as the XOR of some elements of the original sequence, e.g. \(v_{i_1}\oplus v_{i_2}\oplus\cdots\oplus v_{i_k}\). Among all such possible representations, the maximum of the minimum indices is exactly \(t\), i.e.

\[ t(v) = \max\{j:\exists i_1,\cdots,i_k\in[j,i]\text{ s.t. }v=v_{i_1}\oplus v_{i_2}\oplus\cdots\oplus v_{i_k}\}. \]

This expression merely writes the description of the previous paragraph in formal language. The insight it gives us is that to maintain the timestamp of every vector \(v\) in the linear basis, we only need to greedily choose vectors that are as new as possible to replace old ones.

Based on the greedy method of constructing a linear basis mentioned above, the prefix linear basis makes the following adjustments in the construction process:

  • For every vector \(a_x\) kept in the linear basis, store a timestamp \(t_x\), initially set to \(0\);
  • To add the \(i\)-th vector \(v\) of the sequence, still scan from high bits to low bits, but also record the current time \(i\);
  • If bit \(x\) of \(v\) is one, compare the timestamp \(t_x\) of the existing vector \(a_x\) in the linear basis with the current time \(i\):
    • If \(i>t_x\), i.e. the vector being added is newer, set \(a_x\) to \(v\), update the timestamp to \(i\), and continue the adding process with the XOR of the old \(a_x\) and \(v\), \(a_x\oplus v\), using the previously recorded time \(t_x\);
    • If \(i<t_x\), i.e. the vector being added is older, do not update \(a_x\) or \(t_x\); XOR \(v\) with \(a_x\) and continue adding.

In other words, if the current bit can be represented by a newer vector, use the newer vector directly; otherwise, keep the original vector. When updating the vector at position \(x\), the XOR result \(a_x\oplus v\) must not be stored at position \(x\), because the timestamp of the XOR result \(a_x\oplus v\) is \(\min\{t(a_x)=t(v)\}=t(a_x)\), which is smaller than the timestamp \(t(v)\) of the vector \(v\) being added. For the same reason, the upward updates in the construction of a linear basis by Gaussian elimination may break the timestamp property, so it is no longer suitable for constructing a prefix linear basis.

Code (Codeforces 1100F Ivan and Burgers) 
#include <algorithm>
#include <array>
#include <iostream>
#include <numeric>
#include <vector>

class LinearBasis {
  static constexpr int K = 20;
  std::array<int, K> a, t;

 public:
  LinearBasis() : a{}, t{} {}

  // Insert vector x at time i.
  void insert(int x, int i) {
    for (int k = K - 1; ~k && x; --k) {
      if (((x >> k) & 1)) {
        if (i > t[k]) {
          std::swap(a[k], x);
          std::swap(t[k], i);
        }
        x ^= a[k];
      }
    }
  }

  // Find max xor of subsets of elements from time i till now.
  int query(int i) const {
    int res = 0;
    for (int k = K - 1; ~k; --k) {
      if (t[k] >= i && (res ^ a[k]) > res) {
        res ^= a[k];
      }
    }
    return res;
  }
};

  }
  for (int x : res) std::cout << x << '\n';
  return 0;
}

If online queries are required, one can also store the prefix linear basis at every prefix using \(O(mn)\) space and then answer queries; this can be seen as a kind of "persistent" linear basis. If the properties of a linear basis obtained by Gaussian elimination are needed, they can be handled separately at query time.
