Uvod

Teorija uređaja (order theory) grana je matematike koja pomoću binarnih relacija strogo formalizira pojam „poretka”. U nastavku uvodimo osnovne definicije te grane.

Definicije

Binarna relacija

Definicija

Binarna relacija (binary relation) \(R\) na skupovima \(X\) i \(Y\) definira se kao uređena trojka \((X,Y,G(R))\), gdje se \(X\) naziva domena (domain), \(Y\) kodomena (codomain), a \(G(R)\subseteq X\times Y=\{(x,y):x\in X,y\in Y\}\) graf (graph) binarne relacije \(R\). \(xRy\) vrijedi ako i samo ako \((x,y)\in G(R)\).

Ako je \(X=Y\), binarnu relaciju nazivamo homogenom binarnom relacijom (homogeneous relation) ili endorelacijom (endorelation).

Ako nije drukčije rečeno, sve binarne relacije u nastavku su homogene.

Na primjer, djeljivost \(\mid\) i relacija „manje ili jednako” \(\leq\) na \(\mathbf{N}_+\) binarne su relacije.

Kad proučavamo binarne relacije, često nas zanima imaju li neka posebna svojstva. Za binarnu relaciju \(R\) na skupu \(S\) definiramo sljedeća posebna svojstva:

  1. refleksivnost (reflexive): \((\forall~a \in S)~~aRa\),
  2. irefleksivnost (irreflexive, anti-reflexive): \((\forall~a \in S)~~\lnot(aRa)\),
  3. simetričnost (symmetric): \((\forall~a,b \in S)~~aRb \iff bRa\),
  4. antisimetričnost (antisymmetric): \((\forall~a,b \in S)~~(aRb \land bRa) \implies a=b\),
  5. asimetričnost (asymmetric): \((\forall~a,b \in S)~~aRb \implies \lnot(bRa)\),
  6. tranzitivnost (transitive): \((\forall~a,b,c \in S)~~(aRb \land bRc) \implies aRc\),
  7. povezanost (connected): \((\forall~a,b \in S)~~a \neq b \implies (aRb \lor bRa)\),
  8. dobra utemeljenost (well-founded): \((\exists~m \in S \neq \varnothing)~~(\forall~a \in S\setminus\{m\})~~\lnot(aRm)\) (tj. neprazan skup \(S\) ima minimalni element \(m\)),
  9. tranzitivnost neusporedivosti (transitive of incomparability): \((\forall~a,b,c \in S)~~(\lnot(aRb \lor bRa) \land \lnot(bRc \lor cRb)) \implies \lnot(aRc \lor cRa)\) (ako vrijedi \(\lnot(aRb \lor bRa)\), kažemo da su \(a\) i \(b\) neusporedivi).

Operacije s relacijama

Za binarne relacije \(R\) i \(S\) na skupovima \(X\) i \(Y\) možemo definirati sljedeće operacije:

  1. unija \(R\cup S\) relacija \(R\) i \(S\) zadovoljava \(G(R\cup S):=\{(x,y):xRy \lor xSy\}\) (npr. \(\leq\) je unija relacija \(<\) i \(=\)),
  2. presjek \(R\cap S\) relacija \(R\) i \(S\) zadovoljava \(G(R\cap S):=\{(x,y):xRy \land xSy\}\),
  3. komplement \(\bar{R}\) relacije \(R\) zadovoljava \(G(\bar{R}):=\{(x,y):\lnot(xRy)\}\),
  4. dualna (inverzna) relacija \(R^T\) relacije \(R\) zadovoljava \(G(R^T):=\{(y,x):xRy\}\).

Za binarnu relaciju \(R\) na skupovima \(X\) i \(Y\) te binarnu relaciju \(S\) na skupovima \(Y\) i \(Z\) možemo definirati njihovu kompoziciju \(S\circ R\) koja zadovoljava \(G(S\circ R):=\{(x,z):(\exists~y\in Y)~~xRy\land ySz\}\).

Parcijalno uređen skup

Definicija

Ako binarna relacija \(\preceq\) na skupu \(S\) ima svojstva refleksivnosti, antisimetričnosti i tranzitivnosti, kažemo da je \(S\) parcijalno uređen skup (partially ordered set, poset), a \(\preceq\) parcijalni uređaj (partial order) na njemu.

Ako parcijalni uređaj \(\preceq\) ima još i svojstvo povezanosti, nazivamo ga totalnim uređajem (total order), a pripadni skup totalno uređenim skupom (totally ordered set), linearno uređenim skupom (linearly ordered set, loset) ili jednostavno uređenim skupom (simply ordered set).

Lako se vidi da su \(\mathbf{N}\), \(\mathbf{Z}\), \(\mathbf{Q}\) i \(\mathbf{R}\) totalno uređeni skupovi s obzirom na \(\leq\).

Vizualizacija parcijalno uređenog skupa: Hasseov dijagram

Za konačne parcijalno uređene skupove parcijalni uređaj možemo zorno prikazati Hasseovim dijagramom.

Definicija

Za konačan parcijalno uređen skup \(S\) i parcijalni uređaj \(\preceq\) na njemu definiramo \(x\prec y\iff (x\preceq y\land x\neq y)\); pripadni Hasseov dijagram jest graf \(G=\langle V,E\rangle\) koji zadovoljava sljedeće uvjete:

  • \(V=S\),
  • \(E=\{(x,y)\in S\times S: x\prec y \land ((\nexists~z\in S)~~x\prec z\prec y)\}\)

Lanci i antilanci

Definicija

Za parcijalno uređen skup \(S\) i parcijalni uređaj \(\preceq\) na njemu, totalno uređen podskup skupa \(S\) nazivamo lancem (chain). Ako su u podskupu \(T\) skupa \(S\) svaka dva različita elementa neusporediva (tj. \((\forall~a,b \in T)~~a \neq b \implies (a \npreceq b \land b \npreceq a)\)), \(T\) nazivamo antilancem (antichain).

Za parcijalno uređen skup \(S\) i parcijalni uređaj \(\preceq\) na njemu, duljinu najduljeg antilanca parcijalno uređenog skupa \(S\) nazivamo širinom (partial order width).

Na primjer, za partitivni skup \(S\) skupa \(\{0,1,2\}\) i relaciju inkluzije skupova \(\subseteq\), \(\{\varnothing,\{1\},\{1,2\}\}\) je lanac, \(\{\{1\},\{0,2\}\}\) je antilanac, a širina skupa \(S\) iznosi \(3\).

Posebni elementi preduređenih skupova

U preduređenim skupovima možemo definirati pojmove maksimalnog (minimalnog) elementa, gornje (donje) međe, supremuma (infimuma) itd.; ti se pojmovi mogu poopćiti i na druge relacije uređaja.

Definicija

Za preduređen skup \(S\) i preduređaj \(\preceq\) na njemu uzmimo element \(m\) skupa \(S\):

  1. ako vrijedi \((\forall~a \in S\setminus\{m\})~~\lnot(m\preceq a)\), \(m\) nazivamo maksimalnim elementom (maximal element),
  2. ako za \(T \subseteq S\) vrijedi \((\forall~t\in T)~~t\preceq m\), \(m\) nazivamo gornjom međom (upper bound) skupa \(T\),
  3. ako za \(T \subseteq S\) vrijedi da je \(m\) gornja međa skupa \(T\) i da za svaku gornju među \(n\) skupa \(T\) vrijedi \(m \preceq n\), \(m\) nazivamo supremumom (supremum) skupa \(T\).

Analogno se definiraju minimalni element (minimal element), donja međa (lower bound) i infimum (infimum).

Na primjer, \(1\) je minimalni element i donja međa skupa \(\mathbf{N}_+\).

Može se dokazati:

  • U preduređenom skupu maksimalni (minimalni) element, gornja (donja) međa i supremum (infimum) ne moraju postojati, a i kad postoje, ne moraju biti jedinstveni.

  • Ako podskup \(T\) parcijalno uređenog skupa \(S\) ima supremum (infimum), on je nužno jedinstven.

    Supremum i infimum skupa \(T\) označavamo redom \(\sup T\) i \(\inf T\). Ako parcijalno uređen skup \(S\) ima i gornju i donju među, kažemo da je \(S\) omeđen.

U beskonačnom parcijalno uređenom skupu maksimalni element ne mora postojati. Postoji li maksimalni element u beskonačnom parcijalno uređenom skupu, može se utvrditi pomoću Zornove leme (Zorn's Lemma).

Zornova lema

Zornova lema, poznata i kao Kuratowski–Zornova lema, glasi: ako svaki lanac nepraznog parcijalno uređenog skupa ima gornju među, taj parcijalno uređen skup ima maksimalni element.

Zornova lema ekvivalentna je aksiomu izbora, teoremu o dobrom uređaju itd.

Usmjereni skupovi i rešetke

Znamo da je supremum (infimum) podskupa parcijalno uređenog skupa, ako postoji, nužno jedinstven. No to ne vrijedi za maksimalne (minimalne) elemente. Na primjer, promotrimo parcijalno uređen skup \(S=\{\{0\},\{1\},\{2\},\{0,1\},\{0,2\},\{1,2\}\}\) s parcijalnim uređajem \(\subseteq\); lako se vidi da on ima \(3\) maksimalna i \(3\) minimalna elementa.

Želimo parcijalno uređenom skupu dodati određene uvjete tako da maksimalni (minimalni) element, ako postoji, bude jedinstven; tada možemo definirati pojam najvećeg (najmanjeg) elementa.

Usmjereni skup

Za preduređen skup \(S\) i preduređaj \(\preceq\) na njemu, ako vrijedi \((\forall~a,b\in S)~~(\exists~c\in S)~~a\preceq c\land b\preceq c\), \(\preceq\) nazivamo smjerom (direction) skupa \(S\), a \(S\) usmjerenim skupom (directed set) ili filtriranim skupom (filtered set).

Skup \(S\) koji zadovoljava gornju definiciju ponekad se naziva i usmjerenim prema gore (upward directed set); analogno se definira skup usmjeren prema dolje (downward directed set).

Usmjereni skup može se definirati i na sljedeći način:

Ekvivalentna definicija usmjerenog skupa

Za preduređen skup \(S\) i preduređaj \(\preceq\) na njemu, ako svaki konačan podskup \(T\) skupa \(S\) ima gornju među, \(\preceq\) nazivamo smjerom skupa \(S\), a \(S\) usmjerenim skupom.

Lako se vidi:

  • Ako skup usmjeren prema gore ima maksimalni element, on je nužno jedinstven. Maksimalni element skupa usmjerenog prema gore nazivamo najvećim elementom (greatest element).
  • Ako skup usmjeren prema dolje ima minimalni element, on je nužno jedinstven. Minimalni element skupa usmjerenog prema dolje nazivamo najmanjim elementom (least element).

U parcijalno uređenom skupu sa smjerom za svaka dva elementa \(a,b\) skup \(\{a,b\}\) ima gornju među; zamijenimo li gornju među supremumom, dobivamo definiciju gornje polurešetke.

Za parcijalno uređen skup \(S\) i parcijalni uređaj \(\preceq\) na njemu:

Gornja polurešetka

Ako za svaka dva elementa \(a,b\) skupa \(S\) skup \(\{a,b\}\) ima supremum \(c\), \(S\) nazivamo gornjom polurešetkom (join-semilattice, upper semilattice), a \(c\) nazivamo spojem (join) elemenata \(a\) i \(b\) i označavamo \(a\lor b\).

Donja polurešetka

Ako za svaka dva elementa \(a,b\) skupa \(S\) skup \(\{a,b\}\) ima infimum \(c\), \(S\) nazivamo donjom polurešetkom (meet-semilattice, lower semilattice), a \(c\) nazivamo susretom (meet) elemenata \(a\) i \(b\) i označavamo \(a\land b\).

Rešetka

Ako je \(S\) i gornja i donja polurešetka, \(S\) nazivamo rešetkom (lattice).

Na primjer, skup pozitivnih djelitelja broja \(60\), \(S=\{1,2,3,4,5,6,10,12,15,20,30,60\}\), parcijalno je uređen skup s obzirom na djeljivost; za svaka dva pozitivna cijela broja \(a,b\) iz njega \(\operatorname{lcm}(a,b)\) je spoj elemenata \(a\) i \(b\), a \(\gcd(a,b)\) susret elemenata \(a\) i \(b\), pa je \(S\) rešetka.

Dualnost

U teoriji uređaja dualnost je vrlo čest pojam; primjerice, gore spomenuti maksimalni i minimalni element su dualni, gornja i donja međa su dualne, supremum i infimum su dualni.

Za parcijalno uređen skup \(P\) i parcijalni uređaj \(\preceq\) na njemu definiramo njegov dualni (dual, opposite) parcijalno uređen skup \(P^d\) koji zadovoljava: \(x \preceq y\) vrijedi u \(P\) ako i samo ako \(y \preceq x\) vrijedi u \(P^d\). Obrnemo li bridove Hasseova dijagrama skupa \(P\), dobivamo Hasseov dijagram skupa \(P^d\).

Dilworthov i Mirskyjev teorem

Za konačan parcijalno uređen skup \(S\) i parcijalni uređaj \(\preceq\) na njemu vrijedi sljedeći par dualnih teorema:

Dilworthov teorem

Širina skupa \(S\) (duljina najduljeg antilanca) jednaka je najmanjem broju lanaca koji ga pokrivaju.

Dokaz

Provodimo matematičku indukciju. Za \(|S|\leq 3\) tvrdnja očito vrijedi.

Pretpostavimo da tvrdnja vrijedi za sve parcijalno uređene skupove s manje od \(|S|\) elemenata i neka je širina skupa \(S\) jednaka \(d\). Ako su svi elementi skupa \(|S|\) međusobno neusporedivi, tvrdnja očito vrijedi; inače u \(S\) uzmimo lanac duljine veće od \(1\) te neka je \(m\) njegov najmanji, a \(M\) njegov najveći element.

Neka je \(T=S\setminus\{m,M\}\). Ako širina skupa \(T\) ne prelazi \(d-1\), po pretpostavci indukcije \(T\) se može pokriti s najviše \(d-1\) lanaca, pa se \(S\) može pokriti tim lancima i lancem \(\{m,M\}\), i tvrdnja vrijedi. Inače je širina skupa \(T\) također \(d\); neka je \(A\) najdulji antilanac u \(T\).

Promotrimo sljedeća dva skupa:

\[ S^+:=\{x\in S:(\exists~a\in A)~~a\preceq x\} \]
\[ S^-:=\{x\in S:(\exists~a\in A)~~x\preceq a\} \]

Lako uočavamo sljedeća svojstva:

  • \(S^+\cup S^-=S\),
  • \(S^+\cap S^-=A\),
  • \(|S^+|<|S|\), \(|S^-|<|S|\) (jer \(m\notin S^+\) i \(M\notin S^-\)).

Primijenimo li pretpostavku indukcije na \(S^+\) i \(S^-\), najmanji broj lanaca koji pokrivaju svaki od tih dvaju skupova jest \(d\), a svaki od tih lanaca sadrži točno jedan element \(a\) iz \(A\). Označimo te lance redom \(C_a^+\) i \(C_a^-\); tada je \(\{C_a^-\cup\{a\}\cup C_a^+\}_{a\in A}\) najmanji pokrivač skupa \(S\) lancima, čime je tvrdnja dokazana.

Mirskyjev teorem

Duljina najduljeg lanca skupa \(S\) jednaka je najmanjem broju antilanaca koji ga pokrivaju.

Dokaz

Neka je duljina najduljeg lanca skupa \(S\) jednaka \(d\); tada je po definiciji najmanji broj antilanaca u pokrivaču barem \(d\).

Neka je \(f(s)\) duljina najduljeg lanca čiji je najmanji element \(s\). Uočimo da iz \(f(s)=f(t)\) slijedi da su \(s\) i \(t\) neusporedivi, pa je \((\forall~n\in\mathbf{N})~~f^{-1}(\{n\})\) antilanac, pri čemu se \(f^{-1}(\{n\}):=\{a\in S:f(a)=n\}\) naziva razinski skup (level set).

Stoga se lako zaključuje da je \(\{f^{-1}(\{i\}):1\leq i\leq d\}\) pokrivač antilancima, pa je najmanji broj antilanaca u pokrivaču najviše \(d\).

Dilworthov teorem ekvivalentan je Hallovu teoremu o braku.

Dilworthovim teoremom možemo dokazati sljedeći teorem:

Erdős–Szekeresov teorem

Niz realnih brojeva \(\{a_i\}\) s barem \(rs+1\) elemenata ima ili nepadajući podniz duljine \(r+1\) ili nerastući podniz duljine \(s+1\).

Dokaz

Neka je duljina niza \(n\geq rs+1\). Definirajmo parcijalno uređen skup \(\{(i,a_i)\}_{i=1}^{n}\) s parcijalnim uređajem \(\preceq\) zadanim ovako:

\[ (i,a_i)\preceq (j,a_j)\iff (i\leq j\land a_i\leq a_j) \]

Pretpostavimo da širina tog parcijalno uređenog skupa ne prelazi \(s\); tada se po Dilworthovu teoremu on može pokriti s najviše \(s\) lanaca. Ako duljina nijednog od tih lanaca ne prelazi \(r\), niz ima najviše \(rs\) elemenata, što je u suprotnosti s uvjetom.

Primjeri zadataka

Luogu P1020 [NOIP1999 提高组] 导弹拦截 (Presretanje projektila)

Neka je država za obranu od neprijateljskih projektila razvila sustav za presretanje projektila. No taj sustav ima nedostatak: iako prvi hitac može dosegnuti bilo koju visinu, svaki sljedeći hitac ne može biti viši od prethodnoga. Jednog dana radar je zabilježio dolazak neprijateljskih projektila. Budući da je sustav još u pokusnoj fazi, postoji samo jedan, pa je moguće da neće moći presresti sve projektile.

Zadane su visine projektila redom kojim dolaze. Izračunajte koliko najviše projektila taj sustav može presresti i koliko je najmanje takvih sustava potrebno da bi se presreli svi projektili.

Za sve podatke visine projektila pozitivni su cijeli brojevi koji ne prelaze \(5\times 10^4\).

Rješenje

Neka ima ukupno \(n\) projektila i neka je visina \(i\)-tog projektila \(h_i\). Skup \(\{(i,h_i)\}_{i=1}^{n}\) parcijalno je uređen skup s parcijalnim uređajem \(\preceq\) zadanim ovako:

\[ (i,h_i)\preceq(j,h_j) \iff (i\leq j \land h_i\geq h_j) \]

Po Dilworthovu teoremu tada vrijedi: najmanji broj nerastućih podnizova koji pokrivaju niz jednak je duljini najduljeg rastućeg podniza. Zadatak se stoga može riješiti postupkom složenosti \(O(n\log n)\) za najdulji nepadajući podniz.

Referentni kod 
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
  vector<int> a;
  int x;
  while (cin >> x) a.push_back(x);
  vector<int> f, g;
  for (int i : a) {
    if (f.empty() || -i >= f.back())
      f.push_back(-i);
    else
      *upper_bound(f.begin(), f.end(), -i) = -i;
    if (g.empty() || i > g.back())
      g.push_back(i);
    else
      *lower_bound(g.begin(), g.end(), i) = i;
  }
  cout << f.size() << '\n' << g.size() << '\n';
  return 0;
}
[TJOI2015] 组合数学 (Kombinatorika)

Zadana je mreža s \(n\) redaka i \(m\) stupaca u čijem se svakom polju nalazi određen broj komada blaga. Svaki put krećemo iz gornjeg lijevog kuta i smijemo se kretati samo desno ili dolje; pri svakom prolasku kroz polje smijemo pokupiti najviše jedan komad blaga. Koliko je najmanje prolazaka potrebno da bi se moglo pokupiti sve blago?

\(1\le n \le 1000\), \(1\le m \le 1000\), u svakom polju ima najviše \(10^6\) komada blaga.

Rješenje

Zanemarimo li težine polja mreže, lako se vidi da je kretanje po mreži prema zadanim pravilima ekvivalentno kretanju po DAG-u, pa ga možemo promatrati kao Hasseov dijagram i tako konstruirati parcijalno uređen skup. Po Dilworthovu teoremu tada vrijedi: najmanji broj lanaca koji pokrivaju DAG jednak je veličini najvećeg nezavisnog skupa vrhova.

Stoga je u ovom zadatku traženi odgovor zbroj težina najvećeg težinskog nezavisnog skupa vrhova zadane mreže.

Neka je \(a_{ij}\) težina polja \((i,j)\) mreže, a \(f(i,j)\) odgovor za podmrežu od \((i,j)\) do \((1,m)\). Uočimo da nijedno polje nije susjedno polju gore desno od sebe, pa je jednadžba prijelaza stanja:

\[ f(i,j)=\max\{f(i-1,j),f(i,j+1),f(i-1,j+1)+a_{ij}\} \]

Odgovor je \(f(n,1)\).

    vector<vector<int64_t>> f(n, vector<int64_t>(m));
    for (int i = 0; i < n; ++i)
      for (int j = m - 1; j >= 0; --j)
        f[i][j] =
            max({(i == 0 ? 0 : f[i - 1][j]), (j == m - 1 ? 0 : f[i][j + 1]),
                 (i == 0 || j == m - 1 ? 0 : f[i - 1][j + 1]) + a[i][j]});
    cout << f[n - 1][0] << '\n';
  }
  return 0;
}

Introduction

Order theory is the branch of mathematics that uses binary relations to make the notion of "order" rigorous. Below we introduce the basic definitions of this branch.

Definitions

Binary relations

Definition

A binary relation \(R\) on sets \(X\) and \(Y\) is defined as a triple \((X,Y,G(R))\), where \(X\) is called the domain, \(Y\) the codomain, and \(G(R)\subseteq X\times Y=\{(x,y):x\in X,y\in Y\}\) the graph of the binary relation \(R\). \(xRy\) holds if and only if \((x,y)\in G(R)\).

If \(X=Y\), the binary relation is called a homogeneous relation or an endorelation.

Unless stated otherwise, all binary relations below are homogeneous.

For example, divisibility \(\mid\) and "less than or equal to" \(\leq\) on \(\mathbf{N}_+\) are binary relations.

When studying binary relations, we are often interested in whether they have certain special properties. For a binary relation \(R\) on a set \(S\), we define the following special properties:

  1. reflexive: \((\forall~a \in S)~~aRa\),
  2. irreflexive (anti-reflexive): \((\forall~a \in S)~~\lnot(aRa)\),
  3. symmetric: \((\forall~a,b \in S)~~aRb \iff bRa\),
  4. antisymmetric: \((\forall~a,b \in S)~~(aRb \land bRa) \implies a=b\),
  5. asymmetric: \((\forall~a,b \in S)~~aRb \implies \lnot(bRa)\),
  6. transitive: \((\forall~a,b,c \in S)~~(aRb \land bRc) \implies aRc\),
  7. connected: \((\forall~a,b \in S)~~a \neq b \implies (aRb \lor bRa)\),
  8. well-founded: \((\exists~m \in S \neq \varnothing)~~(\forall~a \in S\setminus\{m\})~~\lnot(aRm)\) (i.e. the nonempty set \(S\) has a minimal element \(m\)),
  9. transitive of incomparability: \((\forall~a,b,c \in S)~~(\lnot(aRb \lor bRa) \land \lnot(bRc \lor cRb)) \implies \lnot(aRc \lor cRa)\) (if \(\lnot(aRb \lor bRa)\), we say that \(a\) and \(b\) are incomparable).

We also define some special binary relations:

Operations on relations

For binary relations \(R\) and \(S\) on sets \(X\) and \(Y\), we can define the following operations:

  1. the union \(R\cup S\) of \(R\) and \(S\) satisfies \(G(R\cup S):=\{(x,y):xRy \lor xSy\}\) (e.g. \(\leq\) is the union of \(<\) and \(=\)),
  2. the intersection \(R\cap S\) of \(R\) and \(S\) satisfies \(G(R\cap S):=\{(x,y):xRy \land xSy\}\),
  3. the complement \(\bar{R}\) of \(R\) satisfies \(G(\bar{R}):=\{(x,y):\lnot(xRy)\}\),
  4. the dual (converse) \(R^T\) of \(R\) satisfies \(G(R^T):=\{(y,x):xRy\}\).

For a binary relation \(R\) on sets \(X\) and \(Y\) and a binary relation \(S\) on sets \(Y\) and \(Z\), we can define their composition \(S\circ R\), which satisfies \(G(S\circ R):=\{(x,z):(\exists~y\in Y)~~xRy\land ySz\}\).

Partially ordered sets

Definition

If a binary relation \(\preceq\) on a set \(S\) is reflexive, antisymmetric and transitive, then \(S\) is called a partially ordered set (poset) and \(\preceq\) a partial order on it.

If the partial order \(\preceq\) is also connected, it is called a total order, and the corresponding set is called a totally ordered set, a linearly ordered set (loset) or a simply ordered set.

It is easy to see that \(\mathbf{N}\), \(\mathbf{Z}\), \(\mathbf{Q}\) and \(\mathbf{R}\) are all totally ordered sets with respect to \(\leq\).

Visualizing posets: Hasse diagrams

For a finite poset, we can use a Hasse diagram to visualize the partial order on it.

Definition

For a finite poset \(S\) with partial order \(\preceq\), define \(x\prec y\iff (x\preceq y\land x\neq y)\); the corresponding Hasse diagram is the graph \(G=\langle V,E\rangle\) satisfying the following conditions:

  • \(V=S\),
  • \(E=\{(x,y)\in S\times S: x\prec y \land ((\nexists~z\in S)~~x\prec z\prec y)\}\)

Chains and antichains

Definition

For a poset \(S\) with partial order \(\preceq\), a totally ordered subset of \(S\) is called a chain. If any two distinct elements of a subset \(T\) of \(S\) are incomparable (i.e. \((\forall~a,b \in T)~~a \neq b \implies (a \npreceq b \land b \npreceq a)\)), then \(T\) is called an antichain.

For a poset \(S\) with partial order \(\preceq\), the length of the longest antichain of \(S\) is called the width (partial order width) of the poset.

For example, for the power set \(S\) of the set \(\{0,1,2\}\) and set inclusion \(\subseteq\), \(\{\varnothing,\{1\},\{1,2\}\}\) is a chain, \(\{\{1\},\{0,2\}\}\) is an antichain, and the width of \(S\) is \(3\).

Special elements of preordered sets

In a preordered set we can define the notions of maximal (minimal) element, upper (lower) bound, supremum (infimum), etc.; these notions generalize to other order relations.

Definition

For a preordered set \(S\) with preorder \(\preceq\), take an element \(m\) of \(S\):

  1. if \((\forall~a \in S\setminus\{m\})~~\lnot(m\preceq a)\), then \(m\) is called a maximal element,
  2. if for \(T \subseteq S\) we have \((\forall~t\in T)~~t\preceq m\), then \(m\) is called an upper bound of \(T\),
  3. if for \(T \subseteq S\) we have that \(m\) is an upper bound of \(T\) and \(m \preceq n\) for every upper bound \(n\) of \(T\), then \(m\) is called the supremum of \(T\).

Minimal element, lower bound and infimum are defined analogously.

For example, \(1\) is a minimal element and a lower bound of \(\mathbf{N}_+\).

It can be shown that:

  • In a preordered set, maximal (minimal) elements, upper (lower) bounds and suprema (infima) need not exist, and even if they exist they need not be unique.

  • If a subset \(T\) of a poset \(S\) has a supremum (infimum), it is necessarily unique.

    We denote the supremum and infimum of \(T\) by \(\sup T\) and \(\inf T\) respectively. If a poset \(S\) has both an upper bound and a lower bound, we say that \(S\) is bounded.

In an infinite poset, a maximal element need not exist. Zorn's Lemma can be used to decide whether an infinite poset has a maximal element.

Zorn's lemma

Zorn's lemma, also called the Kuratowski–Zorn lemma, states: if every chain of a nonempty poset has an upper bound, then the poset has a maximal element.

Zorn's lemma is equivalent to the axiom of choice, the well-ordering theorem, etc.

Directed sets and lattices

We know that if a subset of a poset has a supremum (infimum), it is necessarily unique. However, this does not hold for maximal (minimal) elements. For example, consider the poset \(S=\{\{0\},\{1\},\{2\},\{0,1\},\{0,2\},\{1,2\}\}\) with partial order \(\subseteq\); it is easy to see that it has \(3\) maximal elements and \(3\) minimal elements.

We would like to add some conditions to a poset so that a maximal (minimal) element, if it exists, is necessarily unique; then we can define the notion of a greatest (least) element.

Directed set

For a preordered set \(S\) with preorder \(\preceq\), if \((\forall~a,b\in S)~~(\exists~c\in S)~~a\preceq c\land b\preceq c\), then \(\preceq\) is called a direction on \(S\), and \(S\) is called a directed set or a filtered set.

A set \(S\) satisfying the above definition is sometimes also called an upward directed set; a downward directed set is defined analogously.

A directed set can also be defined as follows:

Equivalent definition of a directed set

For a preordered set \(S\) with preorder \(\preceq\), if every finite subset \(T\) of \(S\) has an upper bound, then \(\preceq\) is called a direction on \(S\), and \(S\) is called a directed set.

It is easy to see that:

  • If an upward directed set has a maximal element, it is necessarily unique. The maximal element of an upward directed set is called the greatest element.
  • If a downward directed set has a minimal element, it is necessarily unique. The minimal element of a downward directed set is called the least element.

In a poset with a direction, for any elements \(a,b\) the set \(\{a,b\}\) has an upper bound; if we replace "upper bound" by "supremum", we get the definition of a join-semilattice.

For a poset \(S\) with partial order \(\preceq\):

Join-semilattice

If for any elements \(a,b\) of \(S\) the set \(\{a,b\}\) has a supremum \(c\), then \(S\) is called a join-semilattice (upper semilattice), and \(c\) is called the join of \(a\) and \(b\), denoted \(a\lor b\).

Meet-semilattice

If for any elements \(a,b\) of \(S\) the set \(\{a,b\}\) has an infimum \(c\), then \(S\) is called a meet-semilattice (lower semilattice), and \(c\) is called the meet of \(a\) and \(b\), denoted \(a\land b\).

Lattice

If \(S\) is both a join-semilattice and a meet-semilattice, then \(S\) is called a lattice.

For example, the set of positive divisors of \(60\), \(S=\{1,2,3,4,5,6,10,12,15,20,30,60\}\), is a poset with respect to divisibility; for any positive integers \(a,b\) in it, \(\operatorname{lcm}(a,b)\) is the join of \(a\) and \(b\) and \(\gcd(a,b)\) is the meet of \(a\) and \(b\), so \(S\) is a lattice.

Duality

Duality is a very common notion in order theory; for instance, the maximal and minimal elements mentioned above are dual, upper and lower bounds are dual, and suprema and infima are dual.

For a poset \(P\) with partial order \(\preceq\), we define its dual (opposite) poset \(P^d\) by: \(x \preceq y\) holds in \(P\) if and only if \(y \preceq x\) holds in \(P^d\). Reversing the edges of the Hasse diagram of \(P\) gives the Hasse diagram of \(P^d\).

Dilworth's theorem and Mirsky's theorem

For a finite poset \(S\) with partial order \(\preceq\), we have the following pair of dual theorems:

Dilworth's theorem

The width of \(S\) (the length of the longest antichain) equals the minimum number of chains needed to cover it.

Proof

We use mathematical induction. For \(|S|\leq 3\) the statement obviously holds.

Assume the statement holds for all posets with fewer than \(|S|\) elements, and let the width of \(S\) be \(d\). If all elements of \(|S|\) are pairwise incomparable, the statement obviously holds; otherwise take a chain of length greater than \(1\) in \(S\), and let \(m\) be its least element and \(M\) its greatest element.

Let \(T=S\setminus\{m,M\}\). If the width of \(T\) is at most \(d-1\), then by the induction hypothesis \(T\) can be covered by at most \(d-1\) chains, so \(S\) can be covered by these chains together with the chain \(\{m,M\}\), and the statement holds. Otherwise the width of \(T\) is also \(d\); let \(A\) be a longest antichain in \(T\).

Consider the following two sets:

\[ S^+:=\{x\in S:(\exists~a\in A)~~a\preceq x\} \]
\[ S^-:=\{x\in S:(\exists~a\in A)~~x\preceq a\} \]

It is easy to see the following properties:

  • \(S^+\cup S^-=S\),
  • \(S^+\cap S^-=A\),
  • \(|S^+|<|S|\), \(|S^-|<|S|\) (because \(m\notin S^+\) and \(M\notin S^-\)).

Applying the induction hypothesis to \(S^+\) and \(S^-\), the minimum number of chains covering each of these two sets is \(d\), and each of these chains contains exactly one element \(a\) of \(A\). Denote these chains by \(C_a^+\) and \(C_a^-\) respectively; then \(\{C_a^-\cup\{a\}\cup C_a^+\}_{a\in A}\) is a minimum chain cover of \(S\), which proves the statement.

Mirsky's theorem

The length of the longest chain of \(S\) equals the minimum number of antichains needed to cover it.

Proof

Let the length of the longest chain of \(S\) be \(d\); then by definition the minimum number of antichains in a cover is at least \(d\).

Let \(f(s)\) be the length of the longest chain whose least element is \(s\). Note that if \(f(s)=f(t)\), then \(s\) and \(t\) are incomparable, so \((\forall~n\in\mathbf{N})~~f^{-1}(\{n\})\) is an antichain, where \(f^{-1}(\{n\}):=\{a\in S:f(a)=n\}\) is called a level set.

Hence it is easy to see that \(\{f^{-1}(\{i\}):1\leq i\leq d\}\) is an antichain cover, so the minimum number of antichains in a cover is at most \(d\).

Dilworth's theorem is equivalent to Hall's marriage theorem.

Dilworth's theorem can be used to prove the following theorem:

Erdős–Szekeres theorem

A sequence of real numbers \(\{a_i\}\) with at least \(rs+1\) elements has either a non-decreasing subsequence of length \(r+1\) or a non-increasing subsequence of length \(s+1\).

Proof

Let the length of the sequence be \(n\geq rs+1\). Define the poset \(\{(i,a_i)\}_{i=1}^{n}\) with partial order \(\preceq\) defined by:

\[ (i,a_i)\preceq (j,a_j)\iff (i\leq j\land a_i\leq a_j) \]

Suppose the width of this poset is at most \(s\); then by Dilworth's theorem the poset can be covered by at most \(s\) chains. If none of these chains has length greater than \(r\), then the sequence has at most \(rs\) elements, contradicting the assumption.

Example problems

Luogu P1020 [NOIP1999 提高组] 导弹拦截 (Missile Interception)

To defend against enemy missile attacks, a country has developed a missile interception system. However, this system has a flaw: although its first shot can reach any height, every subsequent shot cannot be higher than the previous one. One day, the radar detects incoming enemy missiles. Since the system is still in its trial phase, there is only one of them, so it may not be able to intercept all the missiles.

Given the heights of the missiles in the order they arrive, compute the maximum number of missiles this system can intercept, and the minimum number of such systems needed to intercept all the missiles.

For all test data, the heights of the missiles are positive integers not exceeding \(5\times 10^4\).

Solution

Let there be \(n\) missiles in total and let the height of the \(i\)-th missile be \(h_i\). The set \(\{(i,h_i)\}_{i=1}^{n}\) is a poset with partial order \(\preceq\) defined by:

\[ (i,h_i)\preceq(j,h_j) \iff (i\leq j \land h_i\geq h_j) \]

Then by Dilworth's theorem: the minimum number of non-increasing subsequences covering the sequence equals the length of the longest increasing subsequence. Hence the problem can be solved by the \(O(n\log n)\) method for the longest non-decreasing subsequence.

Reference code 
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
  vector<int> a;
  int x;
  while (cin >> x) a.push_back(x);
  vector<int> f, g;
  for (int i : a) {
    if (f.empty() || -i >= f.back())
      f.push_back(-i);
    else
      *upper_bound(f.begin(), f.end(), -i) = -i;
    if (g.empty() || i > g.back())
      g.push_back(i);
    else
      *lower_bound(g.begin(), g.end(), i) = i;
  }
  cout << f.size() << '\n' << g.size() << '\n';
  return 0;
}
[TJOI2015] 组合数学 (Combinatorics)

You are given a grid with \(n\) rows and \(m\) columns, where each cell contains some pieces of treasure. Each time you start from the top-left corner and may only move right or down; each time you pass through a cell you may pick up at most one piece of treasure. What is the minimum number of walks needed to be able to pick up all the treasure?

\(1\le n \le 1000\), \(1\le m \le 1000\), each cell contains at most \(10^6\) pieces of treasure.

Solution

Ignoring the cell weights, it is easy to see that walking on the grid according to the given rules is equivalent to walking on a DAG, so we can regard it as a Hasse diagram and construct a poset from it. Then by Dilworth's theorem: the minimum number of chains covering a DAG equals the size of the maximum independent set of vertices.

Therefore the answer to this problem is the total weight of the maximum weighted independent set of vertices of the given grid.

Let \(a_{ij}\) be the weight of the grid at cell \((i,j)\), and \(f(i,j)\) the answer for the subgrid from \((i,j)\) to \((1,m)\). Note that no cell is adjacent to the cell at its upper right, so the state transition equation is:

\[ f(i,j)=\max\{f(i-1,j),f(i,j+1),f(i-1,j+1)+a_{ij}\} \]

The answer is \(f(n,1)\).

Reference code 
#include <algorithm>
#include <cstdint>
#include <iostream>
#include <vector>
using namespace std;

int main() {
  int t = 0;
  cin >> t;
  while (t--) {
    int n, m;
    cin >> n >> m;
    vector<vector<int64_t>> a(n, vector<int64_t>(m));
    for (auto &i : a)
      for (auto &j : i) cin >> j;
    vector<vector<int64_t>> f(n, vector<int64_t>(m));
    for (int i = 0; i < n; ++i)
      for (int j = m - 1; j >= 0; --j)
        f[i][j] =
            max({(i == 0 ? 0 : f[i - 1][j]), (j == m - 1 ? 0 : f[i][j + 1]),
                 (i == 0 || j == m - 1 ? 0 : f[i - 1][j + 1]) + a[i][j]});
    cout << f[n - 1][0] << '\n';
  }
  return 0;
}

Applications in C++

See also: Sorting in the standard library - Basics of algorithms.

Order theory is applied in the algorithms and data structures of the C++ STL that require comparisons. We often need to define custom comparators in C++, and the STL requires them to be strict weak orders. Let \(<\) be a custom comparator; then we can define:

  • \(x>y\) as \(y<x\);
  • \(x \leq y\) as \(y \nless x\);
  • \(x \geq y\) as \(x \nless y\);
  • \(x=y\) as \(x \nless y\land y \nless x\).
