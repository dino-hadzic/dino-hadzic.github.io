Grayev kod (Gray code) binarni je brojevni sustav u kojem se dva susjedna broja razlikuju u samo jednom bitu. Na primjer, niz Grayevih kodova \(3\)-bitnih binarnih brojeva glasi

\[ 000,001,011,010,110,111,101,100 \]

Napomena: indekse niza brojimo od \(0\), tj. \(G(0)=000,G(4)=110\).

Grayev kod predložio je Frank Gray iz Bell Labsa 1940-ih, a patentiran je 1953.

Konstrukcija Grayeva koda (transformacija)

Postoji mnogo načina konstrukcije Grayeva koda. Najprije predstavljamo ručnu konstrukciju, a zatim dajemo kôd za konstrukciju i dokaz ispravnosti.

Ručna konstrukcija

\(k\)-bitni Grayev kod može se konstruirati na sljedeći način. Krenemo od Grayeva koda sa svim znamenkama \(0\) i primjenjujemo sljedeću strategiju:

  1. invertiramo najniži bit i dobijemo sljedeći Grayev kod (na primjer \(000\to 001\));
  2. invertiramo bit lijevo od najdesnije \(1\) i dobijemo sljedeći Grayev kod (na primjer \(001\to 011\));

Naizmjeničnom primjenom ovih strategija \(2^{k-1}\) puta dobivamo niz \(k\)-bitnih Grayevih kodova.

Zrcalna konstrukcija

\(k\)-bitni Grayev kod brzo se dobiva iz \(k-1\)-bitnoga tako da ga zrcalimo odozgo prema dolje i dodamo novi bit, kao na slici:

\[ \begin{matrix} k=1\\ 0\\ 1\\\\\\\\\\\\\\ \end{matrix} \to \begin{matrix}\\ \color{Red}0\\\color{Red}1\\\color{Blue}1\\\color{Blue}0\\\\\\\\\\ \end{matrix} \to \begin{matrix} k=2\\ {\color{Red}0}0\\{\color{Red}0}1\\{\color{Blue}1}1\\{\color{Blue}1}0\\\\\\\\\\ \end{matrix} \to \begin{matrix}\\ \color{Red}00\\\color{Red}01\\\color{Red}11\\\color{Red}10\\\color{Blue}10\\\color{Blue}11\\\color{Blue}01\\\color{Blue}00 \end{matrix} \to \begin{matrix} k=3\\ {\color{Red}0}00\\{\color{Red}0}01\\{\color{Red}0}11\\{\color{Red}0}10\\{\color{Blue}1}10\\{\color{Blue}1}11\\{\color{Blue}1}01\\{\color{Blue}1}00 \end{matrix} \]

Način izračuna

Promotrimo binarni zapis broja \(n\) i \(G(n)\). Može se uočiti da je \(i\)-ti bit od \(G(n)\) jednak \(1\) točno onda kad je \(i\)-ti bit od \(n\) jednak \(1\), a \(i+1\)-vi bit jednak \(0\), ili je \(i\)-ti bit jednak \(0\), a \(i+1\)-vi bit jednak \(1\). Stoga to možemo shvatiti kao operaciju XOR, tj.

\[ G(n)=n\oplus \left\lfloor\frac{n}{2}\right\rfloor \]
int g(int n) { return n ^ (n >> 1); }

Dokaz ispravnosti

Dokažimo sada da se u nizu Grayevih kodova dobivenih gornjom formulom dva susjedna Grayeva koda razlikuju u točno jednom bitu.

Promotrimo razliku između \(n\) i \(n+1\). Dodati \(1\) broju \(n\) znači invertirati sve uzastopne \(1\) na kraju binarnog zapisa broja \(n\), a zatim najnižu \(0\) pretvoriti u \(1\). Bitove brojeva \(n\) i \(n+1\) zapišimo ovako:

\[ \begin{aligned} (n)_2 &= \cdots0\underbrace{11\cdots11}_{k\text{ znamenaka}}\\ (n+1)_2 &= \cdots1\underbrace{00\cdots00}_{k\text{ znamenaka}} \end{aligned} \]

Dakle, pri računanju \(g(n)\) i \(g(n+1)\) zadnjih \(k\) bitova poprima oblik \(\displaystyle\underbrace{100\cdots00}_{k\text{ znamenaka}}\), a \(k+1\)-vi bit je različit, jer su \(n\) i \(n+1\) jednaki u svim bitovima osim zadnjih \(k+1\). Stoga se \(k+1\)-vi bit u oba slučaja XOR-a s \(1\) ili u oba slučaja s \(0\). U oba je slučaja \(k+1\)-vi bit različit. Na bitovima izvan zadnjih \(k+1\) provodi se ista operacija XOR, pa je rezultat isti.

Time je dokaz završen.

Konstrukcija izvornog broja iz Grayeva koda (inverzna transformacija)

Razmotrimo sada inverznu transformaciju Grayeva koda: zadan je Grayev kod \(g\), a treba pronaći izvorni broj \(n\). Prolazimo od najvišeg bita binarnog zapisa prema najnižem (najniži bit ima indeks \(1\), tj. to je bit jedinica; najviši bit ima indeks \(k\)). Tada je odnos između \(i\)-tog bita broja \(n\) i \(i\)-tog bita \(g_i\) koda \(g\) sljedeći:

\[ \begin{aligned} n_k &= g_k \\ n_{k-1} &= g_{k-1} \oplus n_k &&= g_k \oplus g_{k-1} \\ n_{k-2} &= g_{k-2} \oplus n_{k-1} &&= g_k \oplus g_{k-1} \oplus g_{k-2} \\ n_{k-3} &= g_{k-3} \oplus n_{k-2} &&= g_k \oplus g_{k-1} \oplus g_{k-2} \oplus g_{k-3} \\ &\vdots\\ n_{k-i} &=\displaystyle\bigoplus_{j=0}^ig_{k-j} \end{aligned} \]
int rev_g(int g) {
  int n = 0;
  for (; g; g >>= 1) n ^= g;
  return n;
}

Praktične primjene

Grayev kod ima nekoliko vrlo korisnih primjena, od kojih su neke neočekivane:

  • Niz Grayevih kodova \(k\)-bitnih binarnih brojeva može se promatrati kao Hamiltonov ciklus po vrhovima hiperkocke u \(k\)-dimenzionalnom prostoru (kvadrata u dvije dimenzije, jediničnog vektora u jednoj), pri čemu svaki bit Grayeva koda predstavlja koordinatu jedne dimenzije.

  • Grayev kod koristi se za smanjivanje pogrešaka u prijenosu signala digitalno-analognih pretvarača (npr. senzora), jer se svaki put mijenja samo jedan bit.

  • Grayev kod može se iskoristiti za rješavanje problema Hanojskih tornjeva.

    Neka je broj diskova \(n\). Krećemo od \(n\)-bitnog Grayeva koda \(G(0)\) sa svim znamenkama \(0\) i redom prelazimo na sljedeći Grayev kod (s \(G(i)\) na \(G(i+1)\)). \(i\)-ti bit trenutačnog Grayeva koda predstavlja \(i\)-ti disk po veličini od najmanjega.

    Budući da se svaki put mijenja samo jedan bit, kad se promijeni \(i\)-ti bit, pomičemo \(i\)-ti disk. Pri pomicanju diskova svaki disk osim najmanjega ima samo jedan mogući izbor kamo ga staviti. Pri pomicanju prvog diska uvijek imamo dva izbora. Stoga je naša strategija sljedeća:

    ako je \(n\) neparan, put pomicanja diska je \(f\to t\to r\to f\to t\to r\to\cdots\), gdje je \(f\) početni štap, \(t\) štap na koji na kraju stavljamo sve diskove, a \(r\) srednji štap;

    ako je \(n\) paran: \(f \to r \to t \to f \to r \to t \to \cdots\)

  • Grayev kod primjenjuje se i u teoriji genetskih algoritama.

Gray code is a binary numeral system in which two adjacent numbers differ in only one bit. For example, the Gray code sequence of \(3\)-bit binary numbers is

\[ 000,001,011,010,110,111,101,100 \]

Note that we index the sequence starting from \(0\), i.e. \(G(0)=000,G(4)=110\).

Gray code was proposed by Frank Gray of Bell Labs in the 1940s and patented in 1953.

Constructing the Gray code (transformation)

There are many ways to construct the Gray code. We first introduce the manual construction, and then give the code for the construction and a proof of correctness.

Manual construction

The \(k\)-bit Gray code can be constructed as follows. We start from the all-\(0\) Gray code and follow the strategy below:

  1. flip the lowest bit to get the next Gray code (for example \(000\to 001\));
  2. flip the bit to the left of the rightmost \(1\) to get the next Gray code (for example \(001\to 011\));

Alternately applying the above strategies \(2^{k-1}\) times yields the sequence of \(k\)-bit Gray codes.

Mirror construction

The \(k\)-bit Gray code can be quickly obtained from the \(k-1\)-bit Gray code by mirroring it top to bottom and adding a new bit, as shown below:

\[ \begin{matrix} k=1\\ 0\\ 1\\\\\\\\\\\\\\ \end{matrix} \to \begin{matrix}\\ \color{Red}0\\\color{Red}1\\\color{Blue}1\\\color{Blue}0\\\\\\\\\\ \end{matrix} \to \begin{matrix} k=2\\ {\color{Red}0}0\\{\color{Red}0}1\\{\color{Blue}1}1\\{\color{Blue}1}0\\\\\\\\\\ \end{matrix} \to \begin{matrix}\\ \color{Red}00\\\color{Red}01\\\color{Red}11\\\color{Red}10\\\color{Blue}10\\\color{Blue}11\\\color{Blue}01\\\color{Blue}00 \end{matrix} \to \begin{matrix} k=3\\ {\color{Red}0}00\\{\color{Red}0}01\\{\color{Red}0}11\\{\color{Red}0}10\\{\color{Blue}1}10\\{\color{Blue}1}11\\{\color{Blue}1}01\\{\color{Blue}1}00 \end{matrix} \]

Computation method

Let us look at the binary representation of \(n\) and \(G(n)\). We can see that the \(i\)-th bit of \(G(n)\) is \(1\) exactly when the \(i\)-th bit of \(n\) is \(1\) and the \(i+1\)-th bit is \(0\), or the \(i\)-th bit is \(0\) and the \(i+1\)-th bit is \(1\). So we can treat it as an XOR operation, i.e.

\[ G(n)=n\oplus \left\lfloor\frac{n}{2}\right\rfloor \]
int g(int n) { return n ^ (n >> 1); }

Proof of correctness

Next we prove that in the Gray code sequence generated by the above formula, two adjacent Gray codes differ in exactly one bit.

Consider the difference between \(n\) and \(n+1\). Adding \(1\) to \(n\) is equivalent to flipping all the trailing consecutive \(1\)s in the binary representation of \(n\), and then turning the lowest \(0\) into \(1\). We write the bits of \(n\) and \(n+1\) as follows:

\[ \begin{aligned} (n)_2 &= \cdots0\underbrace{11\cdots11}_{k\text{ digits}}\\ (n+1)_2 &= \cdots1\underbrace{00\cdots00}_{k\text{ digits}} \end{aligned} \]

So when computing \(g(n)\) and \(g(n+1)\), the last \(k\) bits both take the form \(\displaystyle\underbrace{100\cdots00}_{k\text{ digits}}\), while the \(k+1\)-th bit is different, because \(n\) and \(n+1\) are identical in all bits except the last \(k+1\). Therefore the \(k+1\)-th bit is either XORed with \(1\) in both cases or XORed with \(0\) in both cases. In both cases, the \(k+1\)-th bit is different. The bits other than the last \(k+1\) undergo the same XOR operation, so the result is the same.

This completes the proof.

Constructing the original number from the Gray code (inverse transformation)

Next we consider the inverse transformation of the Gray code: given a Gray code \(g\), find the original number \(n\). We traverse from the highest bit of the binary representation to the lowest (the lowest bit has index \(1\), i.e. the units bit; the highest bit has index \(k\)). Then the relation between the \(i\)-th bit of \(n\) and the \(i\)-th bit \(g_i\) of \(g\) is as follows:

\[ \begin{aligned} n_k &= g_k \\ n_{k-1} &= g_{k-1} \oplus n_k &&= g_k \oplus g_{k-1} \\ n_{k-2} &= g_{k-2} \oplus n_{k-1} &&= g_k \oplus g_{k-1} \oplus g_{k-2} \\ n_{k-3} &= g_{k-3} \oplus n_{k-2} &&= g_k \oplus g_{k-1} \oplus g_{k-2} \oplus g_{k-3} \\ &\vdots\\ n_{k-i} &=\displaystyle\bigoplus_{j=0}^ig_{k-j} \end{aligned} \]
int rev_g(int g) {
  int n = 0;
  for (; g; g >>= 1) n ^= g;
  return n;
}

Practical applications

Gray code has some very useful applications, some of which are unexpected:

  • The Gray code sequence of \(k\)-bit binary numbers can be regarded as a Hamiltonian cycle over the vertices of a hypercube in \(k\)-dimensional space (a square in two dimensions, a unit vector in one dimension), where each bit of the Gray code represents the coordinate of one dimension.

  • Gray code is used to minimize errors in the signal transmission of digital-to-analog converters (such as sensors), because it changes only one bit at a time.

  • Gray code can be used to solve the Tower of Hanoi problem.

    Let the number of disks be \(n\). We start from the \(n\)-bit all-\(0\) Gray code \(G(0)\) and move to the next Gray code in turn (from \(G(i)\) to \(G(i+1)\)). The \(i\)-th bit of the current Gray code represents the \(i\)-th disk in order of increasing size.

    Since only one bit changes each time, when the \(i\)-th bit changes, we move the \(i\)-th disk. In the process of moving disks, every disk other than the smallest one has only one placement choice when it is moved. When moving the first disk, we always have two placement choices. So our strategy is as follows:

    if \(n\) is odd, the movement path of the disk is \(f\to t\to r\to f\to t\to r\to\cdots\), where \(f\) is the starting peg, \(t\) is the peg where we finally place all the disks, and \(r\) is the middle peg;

    if \(n\) is even: \(f \to r \to t \to f \to r \to t \to \cdots\)

  • Gray code is also applied in the theory of genetic algorithms.
