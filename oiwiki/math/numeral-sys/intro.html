Upozorenje

Ovdje se ne raspravlja o skupovima brojeva (number system): u matematici „number system” označava klasu skupova, kao što su skup cijelih brojeva \(\mathbf{Z}\), skup kompleksnih brojeva \(\mathbf{C}\) itd.

Brojevni sustav (numeral system), koji se naziva i sustav zapisivanja brojeva, jest sustav pisanja kojim se prikazuju brojevi, na primjer indijsko-arapski brojevni sustav, rimski brojevi, suzhouski brojevi itd. Brojevni sustav alat je kojim kodiramo brojeve.

Općenito, brojka u nekom brojevnom sustavu niz je simbola, a uz to postoji skup pravila koji taj niz simbola bijektivno povezuje s odgovarajućim brojem; na primjer, rimski broj \(\text{XLII}\), binarni broj \(101010_{(2)}\) i dekadski broj \(42\) odgovaraju istom broju.

Na algoritamskim natjecanjima uglavnom nas zanimaju samo odnosi pretvorbe između različitih brojevnih sustava; podrobnije u Baza brojevnog sustava.

Warning

What is discussed here is not a number system: in mathematics, a number system refers to a class of sets, such as the set of integers \(\mathbf{Z}\), the set of complex numbers \(\mathbf{C}\), etc.

A numeral system, also called a system of numeration, is a writing system for expressing numbers, such as the Hindu–Arabic numeral system, Roman numerals, Suzhou numerals, etc. A numeral system is the tool we use to encode numbers.

Generally speaking, a numeral in a numeral system is a string of symbols, and there is a set of rules that puts such strings in one-to-one correspondence with the corresponding numbers; for example, the Roman numeral \(\text{XLII}\), the binary number \(101010_{(2)}\), and the decimal number \(42\) all correspond to the same number.

In algorithmic competitions we are generally only interested in the conversions between different numeral systems; see Base for details.
