Preduvjeti: Logičke operacije po bitovima, Cijeli brojevi i nizovi bitova.

Binarni zapis broja možemo promatrati kao skup (\(0\) znači da element nije u skupu, \(1\) da jest). Primjerice, skup \(\{1,3,4,8\}\) može se prikazati kao \((100011010)_2\). Odgovarajuće operacije po bitovima tada možemo promatrati kao operacije nad skupovima.

Operacija Skupovni zapis Zapis operacijama po bitovima
presjek \(a \cap b\) \(a \operatorname{AND} b\)
unija \(a \cup b\) \(a \operatorname{OR} b\)
komplement \(\bar{a}\) \(\operatorname{NOT} a\) (univerzalni skup ima sve bitove jednake 1)
razlika \(a \setminus b\) \(a \operatorname{AND} \operatorname{NOT} b\)
simetrična razlika \(a\triangle b\) \(a \operatorname{XOR} b\)

Prije nego što prijeđemo na obilazak podskupova skupa, pogledajmo nekoliko primjera primjene operacija po bitovima.

Modulo potencija broja 2

Uzimanje ostatka broja pri dijeljenju nenegativnom cjelobrojnom potencijom broja \(2\) ekvivalentno je uzimanju posljednjih nekoliko bitova binarnog zapisa tog broja, odnosno operaciji AND s \(mod-1\).

int modPowerOfTwo(int x, int mod) { return x & (mod - 1); }

def modPowerOfTwo(x, mod):
    return x & (mod - 1)

Odatle slijedi da nenegativna cjelobrojna potencija broja \(2\) pri dijeljenju samom sobom daje ostatak \(0\), tj. ako je \(n\) nenegativna cjelobrojna potencija broja \(2\), rezultat operacije AND nad \(n\) i \(n-1\) jest \(0\).

Zapravo, za pozitivan cijeli broj \(n\), \(n-1\) postavlja najniži bit \(1\) broja \(n\) na nulu, a sve bitove iza njega na \(1\). Stoga je AND nad \(n\) i \(n-1\) ekvivalentan brisanju najnižeg bita \(1\) broja \(n\).

Time možemo provjeriti je li broj nenegativna cjelobrojna potencija broja \(2\): \(n\) je nenegativna cjelobrojna potencija broja \(2\) ako i samo ako binarni zapis od \(n\) sadrži točno jednu jedinicu \(1\).

bool isPowerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }

def isPowerOfTwo(n):
    return n > 0 and (n & (n - 1)) == 0

Obilazak podskupova

Obilazak svih podskupova skupa prikazanog binarnim brojem ekvivalentan je nabrajanju svih podmaski maske koja odgovara tom binarnom broju.

Maska je niz bitova koji se operacijom AND primjenjuje na izvorni niz, čime se dobiva novi operand u kojem je nekoliko ulaznih bitova izvornog niza maskirano.

Maska na izvorni niz djeluje kao zaslon: bit \(1\) u maski znači da se odgovarajući bit izvornog niza zadržava, a bit \(0\) u maski znači da se odgovarajući bit izvornog niza postavlja na \(0\). Zamjenom nekoliko bitova \(1\) maske bitovima \(0\) dobivamo podmasku te maske; maska je i sama svoja podmaska.

Za zadanu masku \(m\) želimo učinkovito iterirati po svim podmaskama \(s\) maske \(m\); možemo razmotriti implementaciju zasnovanu na trikovima s operacijama po bitovima.

// obilazak nepraznih podskupova od m u silaznom poretku
int s = m;
while (s > 0) {
  // s je neprazan podskup od m
  s = (s - 1) & m;
}

Ili kompaktnijom naredbom for:

// obilazak nepraznih podskupova od m u silaznom poretku
for (int s = m; s; s = (s - 1) & m)
// s je neprazan podskup od m

Nijedan od ova dva odsječka koda ne obrađuje podmasku jednaku \(0\); želimo li obraditi i podmasku jednaku \(0\), možemo upotrijebiti druge načine, npr.:

// obilazak podskupova od m u silaznom poretku
for (int s = m;; s = (s - 1) & m) {
  // s je podskup od m
  if (s == 0) break;
}

Dokažimo sada da gornji kod posjećuje sve podmaske od \(m\), bez ponavljanja i u silaznom poretku.

Pretpostavimo da imamo trenutačnu bitovnu masku \(s\) i želimo posjetiti sljedeću bitovnu masku. Oduzimanje \(1\) od maske \(s\) ekvivalentno je uklanjanju krajnjeg desnog postavljenog bita maske \(s\) i postavljanju svih bitova desno od njega na \(1\).

Da bi \(s-1\) postao nova podmaska, treba ukloniti sve dodatne bitove \(1\) koji nisu sadržani u maski \(m\); to uklanjanje izvodi se operacijom po bitovima (s - 1) & m.

Ta su dva koraka ekvivalentna „odrezivanju” maske \(s-1\) kako bi se odredila najveća aritmetički dostižna vrijednost, tj. sljedeća podmaska nakon \(s\) u silaznom poretku.

Dakle, algoritam generira sve podmaske te maske u silaznom poretku, izvodeći u svakoj iteraciji samo dvije operacije.

Poseban je slučaj \(s=0\). Nakon izvođenja \(s-1\) dobivamo \(-1\), kojemu su svi bitovi jednaki \(1\). Nakon operacije (s - 1) & m novi \(s\) bit će jednak \(m\). Stoga, ako petlja ne završava pri \(s=0\), petlja algoritma neće se zaustaviti.

Označimo li s \(\text{popcount}(m)\) broj jedinica \(1\) u binarnom zapisu od \(m\), ovom metodom podskupove skupa \(m\) možemo obići u vremenskoj složenosti \(O(2^{\text{popcount}(m)})\).

Obilazak podmaski svih maski

U zadacima s DP-om s bitmaskama ponekad za svaku masku želimo obići sve njezine podmaske:

for (int m = 0; m < (1 << n); ++m)
  // obilazak nepraznih podskupova od m u silaznom poretku
  for (int s = m; s; s = (s - 1) & m)
// s je neprazan podskup od m

Tako obilazimo podskupove svakog podskupa skupa veličine \(n\).

Dokažimo sada da je vremenska složenost tog postupka \(O(3^n)\), gdje je \(n\) ukupan broj bitova maske, tj. ukupan broj elemenata skupa.

Promotrimo \(i\)-ti bit, tj. \(i\)-ti element skupa; postoje tri slučaja:

  • u maski \(m\) je \(0\), pa je i u podmaski \(s\) jednak \(0\), tj. element nije ni u većem ni u manjem podskupu;
  • u \(m\) je \(1\), ali u \(s\) je \(0\), tj. element je samo u većem podskupu, a ne i u manjem;
  • u \(m\) i u \(s\) je \(1\), tj. element je i u većem i u manjem podskupu.

Ukupno je \(n\) bitova, pa postoji \(3^n\) različitih kombinacija.

Postoji i drugi način dokaza:

Ako maska \(m\) ima \(k\) jedinica \(1\), onda ima \(2^k\) podmaski. Za zadani \(k\) postoji \(\dbinom{n}{k}\) odgovarajućih maski \(m\), pa je ukupan broj svih maski:

\[ \sum_{k=0}^n \dbinom{n}{k} 2^k \]

Gornja suma jednaka je razvoju \((1+2)^n\) po binomnom teoremu, pa postoji \(3^n\) različitih kombinacija.

Prerequisites: Bitwise operations, Integers and bit sequences.

The binary representation of a number can be viewed as a set (\(0\) means the element is not in the set, \(1\) means it is). For example, the set \(\{1,3,4,8\}\) can be represented as \((100011010)_2\). The corresponding bitwise operations can then be viewed as operations on sets.

Operation Set notation Bitwise notation
intersection \(a \cap b\) \(a \operatorname{AND} b\)
union \(a \cup b\) \(a \operatorname{OR} b\)
complement \(\bar{a}\) \(\operatorname{NOT} a\) (the universal set has all bits equal to 1)
difference \(a \setminus b\) \(a \operatorname{AND} \operatorname{NOT} b\)
symmetric difference \(a\triangle b\) \(a \operatorname{XOR} b\)

Before we move on to traversing the subsets of a set, let us look at some examples of applications of bitwise operations.

Modulo a power of 2

Taking a number modulo a nonnegative integer power of \(2\) is equivalent to taking the last several bits of the number's binary representation, which is equivalent to an AND with \(mod-1\).

int modPowerOfTwo(int x, int mod) { return x & (mod - 1); }

def modPowerOfTwo(x, mod):
    return x & (mod - 1)

It follows that a nonnegative integer power of \(2\) taken modulo itself gives \(0\), i.e., if \(n\) is a nonnegative integer power of \(2\), the result of the AND of \(n\) and \(n-1\) is \(0\).

In fact, for a positive integer \(n\), \(n-1\) clears the lowest \(1\) bit of \(n\) and sets all the following bits to \(1\). Therefore, the AND of \(n\) and \(n-1\) is equivalent to deleting the lowest \(1\) bit of \(n\).

This lets us check whether a number is a nonnegative integer power of \(2\): \(n\) is a nonnegative integer power of \(2\) if and only if the binary representation of \(n\) contains exactly one \(1\).

bool isPowerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }

def isPowerOfTwo(n):
    return n > 0 and (n & (n - 1)) == 0

Traversing subsets

Traversing all subsets of a set represented by a binary number is equivalent to enumerating all submasks of the mask corresponding to that binary number.

A mask is a string of bits that is ANDed with a source string to obtain a new operand in which several input bits of the source string are masked out.

A mask acts as a screen on the source string: a \(1\) bit in the mask means the corresponding bit of the source is kept, and a \(0\) bit in the mask means the corresponding bit of the source is set to \(0\). Changing several \(1\) bits of a mask to \(0\) bits gives a submask of the mask; the mask itself is also its own submask.

Given a mask \(m\), we want to efficiently iterate over all submasks \(s\) of \(m\); we can consider an implementation based on bitwise tricks.

// traverse the non-empty subsets of m in descending order
int s = m;
while (s > 0) {
  // s is a non-empty subset of m
  s = (s - 1) & m;
}

Or using a more compact for statement:

// traverse the non-empty subsets of m in descending order
for (int s = m; s; s = (s - 1) & m)
// s is a non-empty subset of m

Neither of these two pieces of code handles the submask equal to \(0\); to handle the submask equal to \(0\) other methods can be used, for example:

// traverse the subsets of m in descending order
for (int s = m;; s = (s - 1) & m) {
  // s is a subset of m
  if (s == 0) break;
}

Next we prove that the code above visits all submasks of \(m\), without repetition, and in descending order.

Suppose we have a current bitmask \(s\) and want to move on to the next bitmask. Subtracting \(1\) from the mask \(s\) is equivalent to removing the rightmost set bit of \(s\) and turning all bits to its right into \(1\).

To make \(s-1\) a new submask, we need to remove all the extra \(1\) bits not contained in the mask \(m\); this removal can be done with the bitwise operation (s - 1) & m.

These two steps are equivalent to cutting the mask \(s-1\) down to the largest value that can be reached arithmetically, i.e., the next submask after \(s\) in descending order.

Therefore, the algorithm generates all submasks of the mask in descending order, performing only two operations per iteration.

A special case is \(s=0\). After performing \(s-1\) we get \(-1\), in which all bits are \(1\). After the operation (s - 1) & m the new \(s\) will equal \(m\). Therefore, if the loop does not end at \(s=0\), the algorithm's loop will never terminate.

Letting \(\text{popcount}(m)\) denote the number of \(1\)s in the binary representation of \(m\), this method traverses the subsets of the set \(m\) in \(O(2^{\text{popcount}(m)})\) time.

Traversing the submasks of all masks

In problems using bitmask DP, we sometimes want to traverse all submasks of each mask:

for (int m = 0; m < (1 << n); ++m)
  // traverse the non-empty subsets of m in descending order
  for (int s = m; s; s = (s - 1) & m)
// s is a non-empty subset of m

This traverses the subsets of every subset of a set of size \(n\).

Next we prove that the time complexity of this operation is \(O(3^n)\), where \(n\) is the total number of bits of the mask, i.e., the total number of elements in the set.

Consider the \(i\)-th bit, i.e., the \(i\)-th element of the set; there are three cases:

  • it is \(0\) in the mask \(m\), hence \(0\) in the submask \(s\), i.e., the element is in neither the big nor the small subset;
  • it is \(1\) in \(m\) but \(0\) in \(s\), i.e., the element is only in the big subset, not in the small one;
  • it is \(1\) in both \(m\) and \(s\), i.e., the element is in both the big and the small subset.

There are \(n\) bits in total, hence \(3^n\) different combinations.

There is another way to prove it:

If the mask \(m\) has \(k\) \(1\)s, then it has \(2^k\) submasks. For a given \(k\) there are \(\dbinom{n}{k}\) corresponding masks \(m\), so the total number over all masks is:

\[ \sum_{k=0}^n \dbinom{n}{k} 2^k \]

The sum above equals the expansion of \((1+2)^n\) by the binomial theorem, hence there are \(3^n\) different combinations.
