Definicija

Powerful Number sito (u nastavku kratko PN sito) slično je Du situ, odnosno ono je proširenje Du sita, i može se koristiti za računanje prefiksnih suma nekih multiplikativnih funkcija.

Zahtjevi:

  • Postoji funkcija \(g\) koja zadovoljava:
    • \(g\) je multiplikativna funkcija.
    • Prefiksne sume \(g\) lako se računaju.
    • Za prost broj \(p\) vrijedi \(g(p) = f(p)\).

Pretpostavimo da želimo izračunati prefiksnu sumu multiplikativne funkcije \(f\), \(F(n) = \sum_{i=1}^{n} f(i)\).

Powerful Number

Definicija: Za pozitivan cijeli broj \(n\) zapišimo rastav \(n\) na proste faktore kao \(n = \prod_{i=1}^{m} p_{i}^{e_{i}}\). \(n\) je PN ako i samo ako \(\forall 1 \le i \le m, e_{i} > 1\).

Svojstvo 1: Svaki PN može se zapisati u obliku \(a^{2}b^{3}\).

Dokaz: Ako je \(e_i\) paran, \(p_{i}^{e_{i}}\) uključimo u \(a^{2}\); ako je \(e_i\) neparan, najprije \(p_{i}^{3}\) uključimo u \(b^{3}\), a zatim \(p_{i}^{e_{i}-3}\) uključimo u \(a^{2}\).

Svojstvo 2: PN-ova koji ne prelaze \(n\) ima najviše \(O(\sqrt{n})\).

Dokaz: Nabrajamo \(a\) i zatim promatramo broj odgovarajućih \(b\); broj PN-ova približno je jednak

\[ \int_{1}^{\sqrt{n}} \sqrt[3]{\frac{n}{x^2}} \mathrm{d}x = O(\sqrt{n}) \]

Kako, dakle, pronaći sve PN-ove koji ne prelaze \(n\)? Linearnim sitom pronađemo sve proste brojeve do \(\sqrt{n}\), a zatim DFS-om pretražimo eksponente pojedinih prostih brojeva. Budući da PN-ova do \(n\) ima najviše \(O(\sqrt{n})\), pretraživanje ima najviše \(O(\sqrt{n})\) koraka.

PN sito

Najprije konstruiramo multiplikativnu funkciju \(g\) čije se prefiksne sume lako računaju i koja za proste brojeve \(p\) zadovoljava \(g(p) = f(p)\). Označimo \(G(n) = \sum_{i=1}^{n} g(i)\).

Zatim konstruiramo funkciju \(h = f / g\), gdje \(/\) označava dijeljenje u smislu Dirichletove konvolucije. Prema svojstvima Dirichletove konvolucije \(h\) je također multiplikativna funkcija, pa je \(h(1) = 1\). Vrijedi \(f = g * h\), gdje \(*\) označava Dirichletovu konvoluciju.

Za prost broj \(p\) vrijedi \(f(p) = g(1)h(p) + g(p)h(1) = h(p) + g(p) \implies h(p) = 0\). Iz \(h(p)=0\) i multiplikativnosti \(h\) slijedi da za broj \(n\) koji nije PN vrijedi \(h(n) = 0\), tj. \(h\) poprima netrivijalne vrijednosti samo na PN-ovima.

Sada iz \(f = g * h\) imamo

\[ \begin{aligned} F(n) &= \sum_{i = 1}^{n} f(i)\\ &= \sum_{i = 1}^{n} \sum_{d|i} h(d) g\left(\frac{i}{d}\right)\\ &= \sum_{d=1}^{n} \sum_{i=1}^{\lfloor \frac{n}{d}\rfloor} h(d) g(i)\\ &= \sum_{d=1}^{n} h(d) \sum_{i=1}^{\lfloor \frac{n}{d}\rfloor} g(i) \\ &= \sum_{d=1}^{n} h(d) G\left(\left\lfloor \frac{n}{d}\right\rfloor\right)\\ &= \sum_{\substack{d=1 \\ d \text{ je PN}}}^{n}h(d) G\left(\left\lfloor \frac{n}{d}\right\rfloor\right) \end{aligned} \]

U \(O(\sqrt{n})\) pronađemo sve PN-ove i izračunamo sve netrivijalne vrijednosti \(h\). Za računanje netrivijalnih vrijednosti \(h\) dovoljno je izračunati sve vrijednosti \(h(p^c)\), a iz multiplikativnosti \(h\) tada slijede sve netrivijalne vrijednosti \(h\). Sada za svaku netrivijalnu vrijednost \(d\) izračunamo \(h(d)G\left(\left\lfloor \dfrac{n}{d} \right\rfloor\right)\) i zbrajanjem dobivamo \(F(n)\).

Razmotrimo sada računanje \(h(p^c)\); postoje dvije metode: prva je izravno izvesti formulu za \(h(p^c)\) koja ovisi samo o \(p, c\) te po njoj računati \(h(p^c)\); druga je iz \(f = g * h\) dobiti \(f(p^c) = \sum_{i=0}^c g(p^i)h(p^{c-i})\), odakle prebacivanjem članova slijedi \(h(p^c) = f(p^c) - \sum_{i=1}^{c}g(p^i)h(p^{c-i})\), pa sada možemo nabrajati proste brojeve \(p\) i zatim eksponente \(c\) te izračunati sve \(h(p^c)\).

Postupak

  1. Konstruiramo \(g\)
  2. Konstruiramo brz način računanja \(G\)
  3. Izračunamo \(h(p^c)\)
  4. Pretražujemo PN-ove i pritom akumuliramo odgovor
  5. Dobivamo rezultat

U 3. koraku možemo računati izravno po formuli, možemo nabrajanjem predračunati tablicu, a možemo i računati na licu mjesta kada pretraživanje dođe do odgovarajućeg broja.

Svojstva

Analizu provodimo na primjeru druge metode računanja \(h(p^c)\). Možemo je podijeliti na dva dijela: računanje \(h(p^c)\) i pretraživanje.

Za prvi dio: budući da je broj prostih brojeva do \(O(\sqrt{n})\) jednak \(O\left(\dfrac{\sqrt{n}}{\log n}\right)\), eksponent \(c\) svakog prostog broja \(p\) iznosi najviše \(\log n\), a računanje \(h(p^c)\) zahtijeva \((c - 1)\) iteracija petlje, vremenska je složenost prvog dijela \(O\left(\dfrac{\sqrt{n}}{\log n} \cdot \log n \cdot \log n\right) = O(\sqrt{n}\log{n})\), i to je labava gornja ograda. Ovisno o zadatku mogu se dodati razne optimizacije kojima se vremenska složenost prvog dijela smanjuje.

Za dio s pretraživanjem: budući da PN-ova do \(n\) ima najviše \(O(\sqrt{n})\), pretraživanje ima najviše \(O(\sqrt{n})\) koraka. Za svaki PN vremenska složenost ovisi o načinu računanja \(G\). Primjerice, ako je vremenska složenost računanja \(G\left(\left\lfloor \dfrac{n}{d}\right\rfloor\right)\) jednaka \(O(1)\), složenost drugog dijela iznosi \(O(\sqrt{n})\).

Posebno, ako \(G\left(\left\lfloor \dfrac{n}{d}\right\rfloor\right)\) računamo Du sitom, vremenska složenost drugog dijela jednaka je vremenskoj složenosti Du sita, tj. \(O(n^{\frac{2}{3}})\). Naime, ako unaprijed jednom izračunamo \(G(n)\), uz optimizaciju linearnim sitom i pamćenje većih vrijednosti u strukturi podataka s brzim slučajnim pristupom (kao što su std::map i std::unordered_map u C++-u), onda su sve vrijednosti \(G\left(\left\lfloor \dfrac{n}{d}\right\rfloor\right)\) koje se koriste u Du situ ili zapamćene linearnim sitom ili zapamćene u std::map, što se može izravno provjeriti programom.

Što se tiče prostorne složenosti, usko grlo je pohrana \(h(p^c)\). Ako koristimo dvodimenzionalni niz \(a\) u kojem \(a_{i,j}\) označava vrijednost \(h(p_i^j)\), prostorna je složenost \(O\left(\dfrac{\sqrt{n}}{\log n} \cdot \log n\right) = O(\sqrt{n})\).

Primjeri zadataka

Luogu P5325【模板】Min_25 筛 (Predložak: Min_25 sito)

Zadatak: Zadana je multiplikativna funkcija \(f(p^k) = p^k(p^k-1)\); izračunajte \(\sum_{i=1}^{n} f(i)\).

Lako se vidi \(f(p) = p(p-1) = \operatorname{id}(p)\varphi(p)\), pa konstruiramo \(g(n) = \operatorname{id}(n)\varphi(n)\).

Za računanje \(G(n)\) koristimo Du sito; iz \((\operatorname{id}\cdot \varphi) * \operatorname{id} = \operatorname{id}_2\) dobivamo \(G(n)= \sum_{i=1}^{n} i^2 - \sum_{d=2}^{n} d \cdot G\left(\left\lfloor \dfrac{n}{d} \right\rfloor\right)\).

Nakon toga vrijednosti \(h(p^k)\) možemo izračunati nabrajanjem; tu metodu ne ponavljamo.

Osim toga, u ovom zadatku možemo izravno izvesti formulu za \(h(p^k)\) koja ovisi samo o \(p, k\), i to ovako:

\[ \begin{aligned} & f(p^k) = \sum_{i=0}^{k} g(p^{k-i})h(p^i)\\ \iff & p^k(p^k-1) = \sum_{i=0}^{k} p^{k-i}\varphi(p^{k-i}) h(p^i)\\ \iff & p^k(p^k-1) = \sum_{i=0}^{k} p^{2k-2i-1}(p - 1) h(p^i)\\ \iff & p^k(p^k-1) = h(p^k) + \sum_{i=0}^{k-1} p^{2k-2i-1}(p - 1) h(p^i)\\ \iff & h(p^k) = p^k(p^k-1) - \sum_{i=0}^{k-1} p^{2k-2i-1}(p - 1) h(p^i)\\ \iff & h(p^k) - p^2h(p^{k-1}) = p^{k}(p^k-1)-p^{k+1}(p^{k-1}-1) - p(p-1)h(p^{k-1})\\ \iff & h(p^k) - ph(p^{k-1}) = p^{k+1} - p^k\\ \iff & \frac{h(p^k)}{p^k} - \frac{h(p^{k-1})}{p^{k-1}} = p - 1\\ \end{aligned} \]

Uz \(h(p) = 0\) teleskopskim zbrajanjem dobivamo \(h(p^k) = (k-1)(p-1)p^k\).

Referentni kod 
#include <iostream>
#include <map>
using namespace std;

constexpr int MOD = 1e9 + 7;

template <typename T>
int mint(T x) {
  x %= MOD;
  if (x < 0) x += MOD;
  return x;
}

int add(int x, int y) { return x + y >= MOD ? x + y - MOD : x + y; }

int mul(int x, int y) { return (long long)1 * x * y % MOD; }

int sub(int x, int y) {
  return x < y ? x - y + MOD : x - y;  // sprječava negativne brojeve
}

int qp(int x, int y) {
  int r = 1;
  for (; y; y >>= 1) {
    if (y & 1) r = mul(r, x);
    x = mul(x, x);
  }
  return r;
}

int inv(int x) { return qp(x, MOD - 2); }

namespace PNS {
constexpr int N = 2e6 + 5;
constexpr int M = 35;

long long global_n;

int g[N], sg[N];

int h[N][M];
bool vis_h[N][M];

int ans;

int pcnt, prime[N], phi[N];
bool isp[N];

void sieve(int n) {
  pcnt = 0;
  for (int i = 2; i <= n; ++i) isp[i] = true;  // niz oznaka prostih brojeva
  phi[1] = 1;
  for (int i = 2; i <= n; ++i) {
    if (isp[i]) {
      ++pcnt;
      prime[pcnt] = i;
      phi[i] = i - 1;
    }
    for (int j = 1; j <= pcnt; ++j) {  // izbacivanje složenih brojeva
      long long nxt = (long long)1 * i * prime[j];
      if (nxt > n) break;
      isp[nxt] = false;
      if (i % prime[j] == 0) {  // slučaj kada i nije prost
        phi[nxt] = phi[i] * prime[j];
        break;
      }
      phi[nxt] = phi[i] * phi[prime[j]];
    }
  }

  for (int i = 1; i <= n; ++i) g[i] = mul(i, phi[i]);

  sg[0] = 0;
  for (int i = 1; i <= n; ++i) sg[i] = add(sg[i - 1], g[i]);  // prefiksne sume funkcije g
}

int inv2, inv6;

void init() {
  sieve(N - 1);
  for (int i = 1; i <= pcnt; ++i) h[i][0] = 1, h[i][1] = 0;
  for (int i = 1; i <= pcnt; ++i) vis_h[i][0] = vis_h[i][1] = true;
  inv2 = inv(2);
  inv6 = inv(6);
}

int S1(long long n) { return mul(mul(mint(n), mint(n + 1)), inv2); }

int S2(long long n) {
  return mul(mul(mint(n), mul(mint(n + 1), mint(n * 2 + 1))), inv6);
}

map<long long, int> mp_g;

int G(long long n) {
  if (n < N) return sg[n];
  if (mp_g.count(n)) return mp_g[n];

  int ret = S2(n);
  for (long long i = 2, j; i <= n; i = j + 1) {
    j = n / (n / i);
    ret = sub(ret, mul(sub(S1(j), S1(i - 1)), G(n / i)));
  }
  mp_g[n] = ret;
  return ret;
}

void dfs(long long d, int hd, int pid) {
  ans = add(ans, mul(hd, G(global_n / d)));

  for (int i = pid; i <= pcnt; ++i) {
    if (i > 1 && d > global_n / prime[i] / prime[i]) break;  // odsijecanje

    int c = 2;
    for (long long x = d * prime[i] * prime[i]; x <= global_n;
         x *= prime[i], ++c) {  // računanje funkcija f, g
      if (!vis_h[i][c]) {
        int f = qp(prime[i], c);
        f = mul(f, sub(f, 1));
        int g = mul(prime[i], prime[i] - 1);
        int t = mul(prime[i], prime[i]);

        for (int j = 1; j <= c; ++j) {
          f = sub(f, mul(g, h[i][c - j]));
          g = mul(g, t);
        }
        h[i][c] = f;
        vis_h[i][c] = true;
      }

      if (h[i][c]) dfs(x, mul(hd, h[i][c]), i + 1);
    }
  }
}

int solve(long long n) {
  global_n = n;
  ans = 0;
  dfs(1, 1, 1);
  return ans;
}
}  // namespace PNS

int main() {
  PNS::init();
  long long n;
  cin >> n;
  cout << PNS::solve(n) << '\n';
  return 0;
}

„LOJ #6053” 简单的函数 (Jednostavna funkcija)

Zadana je \(f(n)\):

\[ f(n) = \begin{cases} 1 & n = 1 \\ p \oplus c & n=p^c \\ f(a)f(b) & n=ab \text{ i } a \perp b \end{cases} \]

Lako se vidi:

\[ f(p) = \begin{cases} p + 1 & p = 2 \\ p - 1 & \text{inače} \\ \end{cases} \]

Konstruiramo \(g\) kao

\[ g(n) = \begin{cases} 3 \varphi(n) & 2 \mid n \\ \varphi(n) & \text{inače} \\ \end{cases} \]

Lako se dokazuje da je \(g(p) = f(p)\) i da je \(g\) multiplikativna funkcija.

Razmotrimo sada računanje \(G(n)\).

\[ \begin{aligned} G(n) &= \sum_{i=1}^{n}[i \bmod 2 = 1] \varphi(i) + 3 \sum_{i=1}^{n}[i \bmod 2 = 0] \varphi(i)\\ &= \sum_{i=1}^{n} \varphi(i) + 2\sum_{i=1}^{n} [i \bmod 2 = 0]\varphi(i) \\ &= \sum_{i=1}^{n} \varphi(i) + 2\sum_{i=1}^{\lfloor \frac{n}{2} \rfloor} \varphi(2i) \end{aligned} \]

Označimo \(S_1(n) = \sum_{i=1}^{n} \varphi(i)\), \(S_2(n) = \sum_{i=1}^{n} \varphi(2i)\); tada je \(G(n) = S_1(n) + 2S_2\left(\left\lfloor \dfrac{n}{2} \right\rfloor\right)\).

Kada je \(2 \mid n\), vrijedi

\[ \begin{aligned} S_2(n) &= \sum_{i=1}^{n} \varphi(2i) \\ &= \sum_{i=1}^{\frac{n}{2}} (\varphi(2(2i-1)) + \varphi(2(2i))) \\ &= \sum_{i=1}^{\frac{n}{2}} (\varphi(2i-1) + 2\varphi(2i)) \\ &= \sum_{i=1}^{\frac{n}{2}} (\varphi(2i-1) + \varphi(2i)) + \sum_{i=1}^{\frac{n}{2}} \varphi(2i) \\ &= \sum_{i=1}^{n} \varphi(i) + S_2\left(\frac{n}{2}\right)\\ &= S_1(n) + S_2\left(\left\lfloor \frac{n}{2} \right\rfloor\right)\\ \end{aligned} \]

Kada je \(2 \nmid n\), vrijedi

\[ \begin{aligned} S_2(n) &= S_2(n-1) + \varphi(2n) \\ &= S_2(n-1) + \varphi(n) \\ &= \sum_{i=1}^{n-1} \varphi(i) + S_2\left(\frac{n-1}{2}\right) + \varphi(n)\\ &= S_1(n) + S_2\left(\left\lfloor \frac{n}{2} \right\rfloor\right)\\ \end{aligned} \]

Ukupno, vrijedi \(S_2(n) = S_1(n) + S_2\left(\left\lfloor \dfrac{n}{2} \right\rfloor\right)\).

\(S_1\) se može izračunati Du sitom, a \(S_2\) izravno po formuli, pa tako možemo izračunati i \(G\).

#include <iostream>
#include <map>
using namespace std;

constexpr int MOD = 1e9 + 7;
constexpr int inv2 = (MOD + 1) / 2;

template <typename T>
int mint(T x) {
  x %= MOD;
  if (x < 0) x += MOD;
  return x;
}

int add(int x, int y) {
  return x + y >= MOD ? x + y - MOD : x + y;  // sprječava prelazak modula
}

int mul(int x, int y) { return (long long)1 * x * y % MOD; }

int sub(int x, int y) {
  return x < y ? x - y + MOD : x - y;  // sprječava negativne brojeve
}

namespace PNS {
constexpr int N = 2e6 + 5;
constexpr int M = 35;

long long global_n;

int s1[N], s2[N];

int h[N][M];
bool vis_h[N][M];

int ans;

int pcnt, prime[N], phi[N];
bool isp[N];

void sieve(int n) {
  pcnt = 0;
  for (int i = 2; i <= n; ++i) isp[i] = true;  // niz oznaka prostih brojeva
  phi[1] = 1;
  for (int i = 2; i <= n; ++i) {
    if (isp[i]) {
      ++pcnt;
      prime[pcnt] = i;
      phi[i] = i - 1;
    }
    for (int j = 1; j <= pcnt; ++j) {  // izbacivanje složenih brojeva
      long long nxt = (long long)1 * i * prime[j];
      if (nxt > n) break;
      isp[nxt] = false;
      if (i % prime[j] == 0) {  // slučaj kada i nije prost
        phi[nxt] = phi[i] * prime[j];
        break;
      }
      phi[nxt] = phi[i] * phi[prime[j]];
    }
  }

  s1[0] = 0;
  for (int i = 1; i <= n; ++i) s1[i] = add(s1[i - 1], phi[i]);

  s2[0] = 0;
  for (int i = 1; i <= n / 2; ++i) {
    s2[i] = add(s2[i - 1], phi[2 * i]);
  }
}

void init() {
  sieve(N - 1);
  for (int i = 1; i <= pcnt; ++i) h[i][0] = 1;
  for (int i = 1; i <= pcnt; ++i) vis_h[i][0] = true;
}

map<long long, int> mp_s1;

int S1(long long n) {
  if (n < N) return s1[n];
  if (mp_s1.count(n)) return mp_s1[n];

  int ret = mul(mul(mint(n), mint(n + 1)), inv2);
  for (long long i = 2, j; i <= n; i = j + 1) {
    j = n / (n / i);
    ret = sub(ret, mul(mint(j - i + 1), S1(n / i)));
  }
  mp_s1[n] = ret;
  return ret;
}

map<long long, int> mp_s2;

int S2(long long n) {
  if (n < N / 2) return s2[n];
  if (mp_s2.count(n)) return mp_s2[n];
  int ret = add(S1(n), S2(n / 2));
  mp_s2[n] = ret;
  return ret;
}

int G(long long n) { return add(S1(n), mul(2, S2(n / 2))); }

void dfs(long long d, int hd, int pid) {
  ans = add(ans, mul(hd, G(global_n / d)));

  for (int i = pid; i <= pcnt; ++i) {
    if (i > 1 && d > global_n / prime[i] / prime[i]) break;  // odsijecanje

    int c = 2;
    for (long long x = d * prime[i] * prime[i]; x <= global_n;
         x *= prime[i], ++c) {
      if (!vis_h[i][c]) {
        int f = prime[i] ^ c, g = prime[i] - 1;

        // poseban slučaj za p = 2
        if (i == 1) g = mul(g, 3);

        for (int j = 1; j <= c; ++j) {
          f = sub(f, mul(g, h[i][c - j]));
          g = mul(g, prime[i]);
        }
        h[i][c] = f;
        vis_h[i][c] = true;
      }

      if (h[i][c]) dfs(x, mul(hd, h[i][c]), i + 1);
    }
  }
}

int solve(long long n) {
  global_n = n;
  ans = 0;
  dfs(1, 1, 1);
  return ans;
}
}  // namespace PNS

int main() {
  PNS::init();  // funkcija predračuna
  long long n;
  cin >> n;
  cout << PNS::solve(n) << '\n';
  return 0;
}

Definition

The Powerful Number sieve (abbreviated PN sieve below) is similar to Du's sieve, or rather it is an extension of Du's sieve, and can be used to compute the prefix sums of some multiplicative functions.

Requirements:

  • There exists a function \(g\) satisfying:
    • \(g\) is a multiplicative function.
    • The prefix sums of \(g\) are easy to compute.
    • For a prime \(p\), \(g(p) = f(p)\).

Suppose we want to compute the prefix sum of a multiplicative function \(f\), \(F(n) = \sum_{i=1}^{n} f(i)\).

Powerful Number

Definition: For a positive integer \(n\), write the prime factorization of \(n\) as \(n = \prod_{i=1}^{m} p_{i}^{e_{i}}\). \(n\) is a PN if and only if \(\forall 1 \le i \le m, e_{i} > 1\).

Property 1: Every PN can be written in the form \(a^{2}b^{3}\).

Proof: If \(e_i\) is even, merge \(p_{i}^{e_{i}}\) into \(a^{2}\); if \(e_i\) is odd, first merge \(p_{i}^{3}\) into \(b^{3}\), then merge \(p_{i}^{e_{i}-3}\) into \(a^{2}\).

Property 2: There are at most \(O(\sqrt{n})\) PNs not exceeding \(n\).

Proof: Enumerate \(a\) and then consider the number of valid \(b\); the number of PNs is approximately

\[ \int_{1}^{\sqrt{n}} \sqrt[3]{\frac{n}{x^2}} \mathrm{d}x = O(\sqrt{n}) \]

So how do we find all PNs not exceeding \(n\)? Find all primes up to \(\sqrt{n}\) with a linear sieve, then search the exponents of the individual primes with a DFS. Since there are at most \(O(\sqrt{n})\) PNs up to \(n\), the search takes at most \(O(\sqrt{n})\) steps.

PN sieve

First, construct a multiplicative function \(g\) whose prefix sums are easy to compute and which satisfies \(g(p) = f(p)\) for primes \(p\). Let \(G(n) = \sum_{i=1}^{n} g(i)\).

Then construct the function \(h = f / g\), where \(/\) denotes division in the sense of Dirichlet convolution. By the properties of Dirichlet convolution, \(h\) is also a multiplicative function, hence \(h(1) = 1\). We have \(f = g * h\), where \(*\) denotes Dirichlet convolution.

For a prime \(p\), \(f(p) = g(1)h(p) + g(p)h(1) = h(p) + g(p) \implies h(p) = 0\). From \(h(p)=0\) and the multiplicativity of \(h\) it follows that \(h(n) = 0\) for any \(n\) that is not a PN, i.e., \(h\) takes nontrivial values only at PNs.

Now, from \(f = g * h\) we have

\[ \begin{aligned} F(n) &= \sum_{i = 1}^{n} f(i)\\ &= \sum_{i = 1}^{n} \sum_{d|i} h(d) g\left(\frac{i}{d}\right)\\ &= \sum_{d=1}^{n} \sum_{i=1}^{\lfloor \frac{n}{d}\rfloor} h(d) g(i)\\ &= \sum_{d=1}^{n} h(d) \sum_{i=1}^{\lfloor \frac{n}{d}\rfloor} g(i) \\ &= \sum_{d=1}^{n} h(d) G\left(\left\lfloor \frac{n}{d}\right\rfloor\right)\\ &= \sum_{\substack{d=1 \\ d \text{ is PN}}}^{n}h(d) G\left(\left\lfloor \frac{n}{d}\right\rfloor\right) \end{aligned} \]

Find all PNs in \(O(\sqrt{n})\) and compute all nontrivial values of \(h\). To compute the nontrivial values of \(h\), it suffices to compute all values \(h(p^c)\); all nontrivial values of \(h\) then follow from the multiplicativity of \(h\). Now, for each nontrivial value \(d\), compute \(h(d)G\left(\left\lfloor \dfrac{n}{d} \right\rfloor\right)\) and sum them up to obtain \(F(n)\).

Now consider computing \(h(p^c)\); there are two methods: the first is to directly derive a formula for \(h(p^c)\) that depends only on \(p, c\) and then compute \(h(p^c)\) by the formula; the second is to use \(f = g * h\) to get \(f(p^c) = \sum_{i=0}^c g(p^i)h(p^{c-i})\), and rearranging gives \(h(p^c) = f(p^c) - \sum_{i=1}^{c}g(p^i)h(p^{c-i})\), so now we can enumerate primes \(p\) and then exponents \(c\) to compute all \(h(p^c)\).

Procedure

  1. Construct \(g\)
  2. Construct a fast way to compute \(G\)
  3. Compute \(h(p^c)\)
  4. Search the PNs, accumulating the answer along the way
  5. Obtain the result

For step 3, we can compute directly by the formula, precompute a table by enumeration, or compute on the fly when the search reaches the number.

Properties

We analyze using the second method of computing \(h(p^c)\) as an example. The analysis can be split into two parts: computing \(h(p^c)\) and the search.

For the first part: since the number of primes up to \(O(\sqrt{n})\) is \(O\left(\dfrac{\sqrt{n}}{\log n}\right)\), the exponent \(c\) of each prime \(p\) is at most \(\log n\), and computing \(h(p^c)\) requires \((c - 1)\) loop iterations, the time complexity of the first part is \(O\left(\dfrac{\sqrt{n}}{\log n} \cdot \log n \cdot \log n\right) = O(\sqrt{n}\log{n})\), and this is a loose upper bound. Depending on the problem, various optimizations can be added to reduce the time complexity of the first part.

For the search part: since there are at most \(O(\sqrt{n})\) PNs up to \(n\), the search takes at most \(O(\sqrt{n})\) steps. For each PN, the time complexity depends on the method used to compute \(G\). For example, if the time complexity of computing \(G\left(\left\lfloor \dfrac{n}{d}\right\rfloor\right)\) is \(O(1)\), the complexity of the second part is \(O(\sqrt{n})\).

In particular, if \(G\left(\left\lfloor \dfrac{n}{d}\right\rfloor\right)\) is computed with Du's sieve, the time complexity of the second part is that of Du's sieve, i.e., \(O(n^{\frac{2}{3}})\). This is because if \(G(n)\) is computed once in advance, with the linear-sieve optimization and with the larger values recorded in a data structure supporting fast random access (such as std::map and std::unordered_map in C++), then every \(G\left(\left\lfloor \dfrac{n}{d}\right\rfloor\right)\) used during Du's sieve is either recorded by the linear sieve or recorded in the std::map, which can be verified directly with a program.

As for the space complexity, the bottleneck is storing \(h(p^c)\). If we use a two-dimensional array \(a\) where \(a_{i,j}\) denotes the value of \(h(p_i^j)\), the space complexity is \(O\left(\dfrac{\sqrt{n}}{\log n} \cdot \log n\right) = O(\sqrt{n})\).

Example problems

Luogu P5325【模板】Min_25 筛 (Template: Min_25 sieve)

Problem: Given the multiplicative function \(f(p^k) = p^k(p^k-1)\), compute \(\sum_{i=1}^{n} f(i)\).

It is easy to see that \(f(p) = p(p-1) = \operatorname{id}(p)\varphi(p)\), so we construct \(g(n) = \operatorname{id}(n)\varphi(n)\).

We use Du's sieve to compute \(G(n)\); from \((\operatorname{id}\cdot \varphi) * \operatorname{id} = \operatorname{id}_2\) we get \(G(n)= \sum_{i=1}^{n} i^2 - \sum_{d=2}^{n} d \cdot G\left(\left\lfloor \dfrac{n}{d} \right\rfloor\right)\).

After that, the values \(h(p^k)\) can be computed by enumeration; we do not repeat this method here.

Moreover, in this problem we can also directly derive a formula for \(h(p^k)\) depending only on \(p, k\), as follows:

\[ \begin{aligned} & f(p^k) = \sum_{i=0}^{k} g(p^{k-i})h(p^i)\\ \iff & p^k(p^k-1) = \sum_{i=0}^{k} p^{k-i}\varphi(p^{k-i}) h(p^i)\\ \iff & p^k(p^k-1) = \sum_{i=0}^{k} p^{2k-2i-1}(p - 1) h(p^i)\\ \iff & p^k(p^k-1) = h(p^k) + \sum_{i=0}^{k-1} p^{2k-2i-1}(p - 1) h(p^i)\\ \iff & h(p^k) = p^k(p^k-1) - \sum_{i=0}^{k-1} p^{2k-2i-1}(p - 1) h(p^i)\\ \iff & h(p^k) - p^2h(p^{k-1}) = p^{k}(p^k-1)-p^{k+1}(p^{k-1}-1) - p(p-1)h(p^{k-1})\\ \iff & h(p^k) - ph(p^{k-1}) = p^{k+1} - p^k\\ \iff & \frac{h(p^k)}{p^k} - \frac{h(p^{k-1})}{p^{k-1}} = p - 1\\ \end{aligned} \]

Then, using \(h(p) = 0\), telescoping summation gives \(h(p^k) = (k-1)(p-1)p^k\).

#include <iostream>
#include <map>
using namespace std;

constexpr int MOD = 1e9 + 7;

template <typename T>
int mint(T x) {
  x %= MOD;
  if (x < 0) x += MOD;
  return x;
}

int add(int x, int y) { return x + y >= MOD ? x + y - MOD : x + y; }

int mul(int x, int y) { return (long long)1 * x * y % MOD; }

int sub(int x, int y) {
  return x < y ? x - y + MOD : x - y;  // prevent negative numbers
}

int qp(int x, int y) {
  int r = 1;
  for (; y; y >>= 1) {
    if (y & 1) r = mul(r, x);
    x = mul(x, x);
  }
  return r;
}

int inv(int x) { return qp(x, MOD - 2); }

namespace PNS {
constexpr int N = 2e6 + 5;
constexpr int M = 35;

long long global_n;

int g[N], sg[N];

int h[N][M];
bool vis_h[N][M];

int ans;

int pcnt, prime[N], phi[N];
bool isp[N];

void sieve(int n) {
  pcnt = 0;
  for (int i = 2; i <= n; ++i) isp[i] = true;  // primality flag array
  phi[1] = 1;
  for (int i = 2; i <= n; ++i) {
    if (isp[i]) {
      ++pcnt;
      prime[pcnt] = i;
      phi[i] = i - 1;
    }
    for (int j = 1; j <= pcnt; ++j) {  // sieve out non-primes
      long long nxt = (long long)1 * i * prime[j];
      if (nxt > n) break;
      isp[nxt] = false;
      if (i % prime[j] == 0) {  // case where i is not prime
        phi[nxt] = phi[i] * prime[j];
        break;
      }
      phi[nxt] = phi[i] * phi[prime[j]];
    }
  }

  for (int i = 1; i <= n; ++i) g[i] = mul(i, phi[i]);

  sg[0] = 0;
  for (int i = 1; i <= n; ++i) sg[i] = add(sg[i - 1], g[i]);  // prefix sums of the function g
}

int inv2, inv6;

void init() {
  sieve(N - 1);
  for (int i = 1; i <= pcnt; ++i) h[i][0] = 1, h[i][1] = 0;
  for (int i = 1; i <= pcnt; ++i) vis_h[i][0] = vis_h[i][1] = true;
  inv2 = inv(2);
  inv6 = inv(6);
}

int S1(long long n) { return mul(mul(mint(n), mint(n + 1)), inv2); }

int S2(long long n) {
  return mul(mul(mint(n), mul(mint(n + 1), mint(n * 2 + 1))), inv6);
}

map<long long, int> mp_g;

int G(long long n) {
  if (n < N) return sg[n];
  if (mp_g.count(n)) return mp_g[n];

  int ret = S2(n);
  for (long long i = 2, j; i <= n; i = j + 1) {
    j = n / (n / i);
    ret = sub(ret, mul(sub(S1(j), S1(i - 1)), G(n / i)));
  }
  mp_g[n] = ret;
  return ret;
}

void dfs(long long d, int hd, int pid) {
  ans = add(ans, mul(hd, G(global_n / d)));

  for (int i = pid; i <= pcnt; ++i) {
    if (i > 1 && d > global_n / prime[i] / prime[i]) break;  // pruning

    int c = 2;
    for (long long x = d * prime[i] * prime[i]; x <= global_n;
         x *= prime[i], ++c) {  // compute the functions f, g
      if (!vis_h[i][c]) {
        int f = qp(prime[i], c);
        f = mul(f, sub(f, 1));
        int g = mul(prime[i], prime[i] - 1);
        int t = mul(prime[i], prime[i]);

        for (int j = 1; j <= c; ++j) {
          f = sub(f, mul(g, h[i][c - j]));
          g = mul(g, t);
        }
        h[i][c] = f;
        vis_h[i][c] = true;
      }

      if (h[i][c]) dfs(x, mul(hd, h[i][c]), i + 1);
    }
  }
}

int solve(long long n) {
  global_n = n;
  ans = 0;
  dfs(1, 1, 1);
  return ans;
}
}  // namespace PNS

int main() {
  PNS::init();
  long long n;
  cin >> n;
  cout << PNS::solve(n) << '\n';
  return 0;
}

“LOJ #6053” 简单的函数 (A simple function)

Given \(f(n)\):

\[ f(n) = \begin{cases} 1 & n = 1 \\ p \oplus c & n=p^c \\ f(a)f(b) & n=ab \text{ and } a \perp b \end{cases} \]

It is easy to see that:

\[ f(p) = \begin{cases} p + 1 & p = 2 \\ p - 1 & \text{otherwise} \\ \end{cases} \]

Construct \(g\) as

\[ g(n) = \begin{cases} 3 \varphi(n) & 2 \mid n \\ \varphi(n) & \text{otherwise} \\ \end{cases} \]

It is easy to prove that \(g(p) = f(p)\) and that \(g\) is a multiplicative function.

Now consider computing \(G(n)\).

\[ \begin{aligned} G(n) &= \sum_{i=1}^{n}[i \bmod 2 = 1] \varphi(i) + 3 \sum_{i=1}^{n}[i \bmod 2 = 0] \varphi(i)\\ &= \sum_{i=1}^{n} \varphi(i) + 2\sum_{i=1}^{n} [i \bmod 2 = 0]\varphi(i) \\ &= \sum_{i=1}^{n} \varphi(i) + 2\sum_{i=1}^{\lfloor \frac{n}{2} \rfloor} \varphi(2i) \end{aligned} \]

Let \(S_1(n) = \sum_{i=1}^{n} \varphi(i)\), \(S_2(n) = \sum_{i=1}^{n} \varphi(2i)\); then \(G(n) = S_1(n) + 2S_2\left(\left\lfloor \dfrac{n}{2} \right\rfloor\right)\).

When \(2 \mid n\), we have

\[ \begin{aligned} S_2(n) &= \sum_{i=1}^{n} \varphi(2i) \\ &= \sum_{i=1}^{\frac{n}{2}} (\varphi(2(2i-1)) + \varphi(2(2i))) \\ &= \sum_{i=1}^{\frac{n}{2}} (\varphi(2i-1) + 2\varphi(2i)) \\ &= \sum_{i=1}^{\frac{n}{2}} (\varphi(2i-1) + \varphi(2i)) + \sum_{i=1}^{\frac{n}{2}} \varphi(2i) \\ &= \sum_{i=1}^{n} \varphi(i) + S_2\left(\frac{n}{2}\right)\\ &= S_1(n) + S_2\left(\left\lfloor \frac{n}{2} \right\rfloor\right)\\ \end{aligned} \]

When \(2 \nmid n\), we have

\[ \begin{aligned} S_2(n) &= S_2(n-1) + \varphi(2n) \\ &= S_2(n-1) + \varphi(n) \\ &= \sum_{i=1}^{n-1} \varphi(i) + S_2\left(\frac{n-1}{2}\right) + \varphi(n)\\ &= S_1(n) + S_2\left(\left\lfloor \frac{n}{2} \right\rfloor\right)\\ \end{aligned} \]

In summary, \(S_2(n) = S_1(n) + S_2\left(\left\lfloor \dfrac{n}{2} \right\rfloor\right)\).

\(S_1\) can be computed with Du's sieve, and \(S_2\) directly by the formula, so \(G\) can be computed as well.

#include <iostream>
#include <map>
using namespace std;

constexpr int MOD = 1e9 + 7;
constexpr int inv2 = (MOD + 1) / 2;

template <typename T>
int mint(T x) {
  x %= MOD;
  if (x < 0) x += MOD;
  return x;
}

int add(int x, int y) {
  return x + y >= MOD ? x + y - MOD : x + y;  // prevent exceeding the modulus
}

int mul(int x, int y) { return (long long)1 * x * y % MOD; }

int sub(int x, int y) {
  return x < y ? x - y + MOD : x - y;  // prevent negative numbers
}

namespace PNS {
constexpr int N = 2e6 + 5;
constexpr int M = 35;

long long global_n;

int s1[N], s2[N];

int h[N][M];
bool vis_h[N][M];

int ans;

int pcnt, prime[N], phi[N];
bool isp[N];

void sieve(int n) {
  pcnt = 0;
  for (int i = 2; i <= n; ++i) isp[i] = true;  // primality flag array
  phi[1] = 1;
  for (int i = 2; i <= n; ++i) {
    if (isp[i]) {
      ++pcnt;
      prime[pcnt] = i;
      phi[i] = i - 1;
    }
    for (int j = 1; j <= pcnt; ++j) {  // sieve out non-primes
      long long nxt = (long long)1 * i * prime[j];
      if (nxt > n) break;
      isp[nxt] = false;
      if (i % prime[j] == 0) {  // case where i is not prime
        phi[nxt] = phi[i] * prime[j];
        break;
      }
      phi[nxt] = phi[i] * phi[prime[j]];
    }
  }

  s1[0] = 0;
  for (int i = 1; i <= n; ++i) s1[i] = add(s1[i - 1], phi[i]);

  s2[0] = 0;
  for (int i = 1; i <= n / 2; ++i) {
    s2[i] = add(s2[i - 1], phi[2 * i]);
  }
}

void init() {
  sieve(N - 1);
  for (int i = 1; i <= pcnt; ++i) h[i][0] = 1;
  for (int i = 1; i <= pcnt; ++i) vis_h[i][0] = true;
}

map<long long, int> mp_s1;

int S1(long long n) {
  if (n < N) return s1[n];
  if (mp_s1.count(n)) return mp_s1[n];

  int ret = mul(mul(mint(n), mint(n + 1)), inv2);
  for (long long i = 2, j; i <= n; i = j + 1) {
    j = n / (n / i);
    ret = sub(ret, mul(mint(j - i + 1), S1(n / i)));
  }
  mp_s1[n] = ret;
  return ret;
}

map<long long, int> mp_s2;

int S2(long long n) {
  if (n < N / 2) return s2[n];
  if (mp_s2.count(n)) return mp_s2[n];
  int ret = add(S1(n), S2(n / 2));
  mp_s2[n] = ret;
  return ret;
}

int G(long long n) { return add(S1(n), mul(2, S2(n / 2))); }

void dfs(long long d, int hd, int pid) {
  ans = add(ans, mul(hd, G(global_n / d)));

  for (int i = pid; i <= pcnt; ++i) {
    if (i > 1 && d > global_n / prime[i] / prime[i]) break;  // pruning

    int c = 2;
    for (long long x = d * prime[i] * prime[i]; x <= global_n;
         x *= prime[i], ++c) {
      if (!vis_h[i][c]) {
        int f = prime[i] ^ c, g = prime[i] - 1;

        // special case for p = 2
        if (i == 1) g = mul(g, 3);

        for (int j = 1; j <= c; ++j) {
          f = sub(f, mul(g, h[i][c - j]));
          g = mul(g, prime[i]);
        }
        h[i][c] = f;
        vis_h[i][c] = true;
      }

      if (h[i][c]) dfs(x, mul(hd, h[i][c]), i + 1);
    }
  }
}

int solve(long long n) {
  global_n = n;
  ans = 0;
  dfs(1, 1, 1);
  return ans;
}
}  // namespace PNS

int main() {
  PNS::init();  // preprocessing function
  long long n;
  cin >> n;
  cout << PNS::solve(n) << '\n';
  return 0;
}
