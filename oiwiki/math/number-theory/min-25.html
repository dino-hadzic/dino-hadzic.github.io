Definicija

Prema ideji na kojoj se temelji, ova se metoda sita naziva i „Extended Eratosthenes Sieve” (prošireno Eratostenovo sito).

Budući da ju je izumio i prvi počeo koristiti Min_25, naziva se „Min_25 sito”.

Svojstva

Može riješiti problem prefiksnih suma jedne klase multiplikativnih funkcija u vremenskoj složenosti \(O\left(\frac{n^{\frac{3}{4}}}{\log{n}}\right)\) ili \(\Theta\left(n^{1 - \epsilon}\right)\).

Zahtjevi: \(f(p)\) je zbroj potpuno multiplikativnih funkcija u \(p\) koje se mogu brzo evaluirati (npr. polinom); \(f(p^{c})\) može se brzo evaluirati.

Oznake

  • Ako nije drukčije rečeno, sve varijable označene s \(p\) u ovom odjeljku poprimaju vrijednosti iz skupa svih prostih brojeva.
  • \(x / y := \left\lfloor\frac{x}{y}\right\rfloor\)
  • \(\operatorname{isprime}(n) := [ |\{d : d \mid n\}| = 2 ]\), tj. vrijednost je \(1\) ako je \(n\) prost, inače \(0\).
  • \(p_{k}\): \(k\)-ti najmanji prost broj među svim prostim brojevima (npr. \(p_{1} = 2, p_{2} = 3\)). Posebno, stavljamo \(p_{0} = 1\).
  • \(\operatorname{lpf}(n) := [1 < n] \min\{p : p \mid n\} + [1 = n]\), tj. najmanji prosti faktor broja \(n\). Posebno, za \(n=1\) vrijednost je \(1\).
  • \(F_{\mathrm{prime}}(n) := \sum_{2 \le p \le n} f(p)\)
  • \(F_{k}(n) := \sum_{i = 2}^{n} [p_{k} \le \operatorname{lpf}(i)] f(i)\)

Objašnjenje

Promotrimo li definiciju \(F_{k}(n)\), vidimo da je odgovor upravo \(F_{1}(n) + f(1) = F_{1}(n) + 1\).

Razmotrimo kako izračunati \(F_{k}(n)\). Nabrajanjem najmanjeg prostog faktora svakog \(i\) i njegova eksponenta dobivamo rekurziju:

\[ \begin{aligned} F_{k}(n) &= \sum_{i = 2}^{n} [p_{k} \le \operatorname{lpf}(i)] f(i) \\ &= \sum_{\substack{k \le i \\ p_{i}^{2} \le n}} \sum_{\substack{c \ge 1 \\ p_{i}^{c} \le n}} f\left(p_{i}^{c}\right) ([c > 1] + F_{i + 1}\left(n / p_{i}^{c}\right)) + \sum_{\substack{k \le i \\ p_{i} \le n}} f(p_{i}) \\ &= \sum_{\substack{k \le i \\ p_{i}^{2} \le n}} \sum_{\substack{c \ge 1 \\ p_{i}^{c} \le n}} f\left(p_{i}^{c}\right) ([c > 1] + F_{i + 1}\left(n / p_{i}^{c}\right)) + F_{\mathrm{prime}}(n) - F_{\mathrm{prime}}(p_{k - 1}) \\ &= \sum_{\substack{k \le i \\ p_{i}^{2} \le n}} \sum_{\substack{c \ge 1 \\ p_{i}^{c + 1} \le n}} \left(f\left(p_{i}^{c}\right) F_{i + 1}\left(n / p_{i}^{c}\right) + f\left(p_{i}^{c + 1}\right)\right) + F_{\mathrm{prime}}(n) - F_{\mathrm{prime}}(p_{k - 1}) \end{aligned} \]

Posljednji korak izvoda temelji se na sljedećoj činjenici: za \(c\) koje zadovoljava \(p_{i}^{c} \le n < p_{i}^{c + 1}\) vrijedi \(p_{i}^{c + 1} > n \iff n / p_{i}^{c} < p_{i} < p_{i + 1}\), pa je \(F_{i + 1}\left(n / p_{i}^{c}\right) = 0\).
Rubna je vrijednost \(F_{k}(n) = 0 (p_{k} > n)\).

Pretpostavimo da smo već izračunali sve \(F_{\mathrm{prime}}(n)\); tada postoje dva načina da izračunamo sve \(F_{k}(n)\):

  1. Izravno računamo po rekurziji.
  2. Nabrajamo \(p\) od najvećeg prema najmanjem i radimo prijelaze; doprinos prijelaza različit je od nule samo kad je \(p^{2} < n\), pa je dovoljno rekurziju optimizirati sufiksnim sumama.

Razmotrimo sada kako izračunati \(F_{\mathrm{prime}}{(n)}\).
Promatrajući postupak računanja \(F_{k}(n)\), lako je uočiti da su od vrijednosti \(F_{\mathrm{prime}}\) korisne jedino one u \(O(\sqrt{n})\) točaka \(1, 2, \dots, \left\lfloor\sqrt{n}\right\rfloor, n / \sqrt{n}, \dots, n / 2, n\).
U općem je slučaju \(f(p)\) polinom niskog stupnja u \(p\) i može se zapisati kao \(f(p) = \sum a_{i} p^{c_{i}}\).
Tada je za svaki \(p^{c_{i}}\) njegov doprinos u \(F_{\mathrm{prime}}(n)\) jednak \(a_{i} \sum_{2 \le p \le n} p^{c_{i}}\).
Promatramo li doprinos svakog \(p^{c_{i}}\) zasebno, problem postaje: za zadane \(n, s, g(p) = p^{s}\), za sve \(m = n / i\) izračunati \(\sum_{p \le m} g(p)\).

Napomena

\(g(p) = p^{s}\) potpuno je multiplikativna funkcija!

Stavimo stoga \(G_{k}(n) := \sum_{i = 2}^{n} \left[p_{k} < \operatorname{lpf}(i) \lor \operatorname{isprime}(i)\right] g(i)\), tj. zbroj vrijednosti \(g\) brojeva koji preostaju nakon \(k\)-tog kruga Eratostenova sita.
Za složeni broj \(x \le n\) nužno vrijedi \(\operatorname{lpf}(x) \le \sqrt{x} \le \sqrt{n}\). Neka je \(p_{\ell(n)}\) najveći prost broj koji ne prelazi \(\sqrt{n}\); tada je \(\sum_{2\le p\le n}g(p) = G_{\ell(n)}(n)\), tj. nakon \(\ell\) krugova Eratostenova sita preostaju samo prosti brojevi. Razmotrimo rubnu vrijednost \(G\); očito je \(G_{0}(n) = \sum_{i = 2}^{n} g(i)\). (Sjećate se? Posebno smo dogovorili \(p_{0} = 1\).)
Za prijelaz razmotrimo postupak Eratostenova sita i zasebno raspravimo doprinos svakog dijela:

  1. Za dio gdje je \(n < p_{k}^{2}\) vrijednost \(G\) se ne mijenja, tj. \(G_{k}(n) = G_{k - 1}(n)\).
  2. Za dio gdje je \(p_{k}^{2} \le n\) izbačeni brojevi nužno imaju prosti faktor \(p_{k}\), tj. \(-g(p_{k}) G_{k - 1}(n / p_{k})\).
  3. U drugom dijelu, budući da je \(p_{k}^{2} \le n \iff p_{k} \le n / p_{k}\), brojevi \(i\) koji zadovoljavaju \(\operatorname{lpf}(i) < p_{k}\) bit će oduzeti prekomjerno. Taj dio treba dodati natrag, tj. \(g(p_{k}) G_{k - 1}(p_{k - 1})\).

Dakle:

\[ G_{k}(n) = G_{k - 1}(n) - \left[p_{k}^{2} \le n\right] g(p_{k}) (G_{k - 1}(n / p_{k}) - G_{k - 1}(p_{k - 1})) \]

Analiza složenosti

Za računanje \(F_{k}(n)\) prvom metodom dokazana je vremenska složenost \(O\left(n^{1 - \epsilon}\right)\) (vidi rad Zhu Zhentinga iz kineskog nacionalnog pripremnog tima 《一些特殊的数论函数求和问题》 (Neki posebni problemi sumacije teorijsko-brojevnih funkcija), odjeljak 2.3);
druga je metoda u biti drugi dio Zhou sita, a spominje se i u radu Ren Zhizhoua 《积性函数求和的几种方法》 (Nekoliko metoda sumacije multiplikativnih funkcija) (6.5.4); dokazana joj je vremenska složenost \(O\left(\frac{n^{\frac{3}{4}}}{\log{n}}\right)\).

Što se tiče računanja \(F_{\mathrm{prime}}(n)\), njegova je implementacija zapravo jednaka prvom dijelu Zhou sita.
Uočimo da za svaki \(m = n / i\) vremenskoj složenosti doprinose samo prijelazi pri nabrajanju onih \(p_{k}\) koji zadovoljavaju \(p_{k}^{2} \le m\), pa se vremenska složenost može procijeniti kao:

\[ \begin{aligned} T(n) &= \sum_{i^{2} \le n} O\left(\pi\left(\sqrt{i}\right)\right) + \sum_{i^{2} \le n} O\left(\pi\left(\sqrt{\frac{n}{i}}\right)\right) \\ &= \sum_{i^{2} \le n} O\left(\frac{\sqrt{i}}{\ln{\sqrt{i}}}\right) + \sum_{i^{2} \le n} O\left(\frac{\sqrt{\frac{n}{i}}}{\ln{\sqrt{\frac{n}{i}}}}\right) \\ &= O\left(\int_{1}^{\sqrt{n}} \frac{\sqrt{\frac{n}{x}}}{\log{\sqrt{\frac{n}{x}}}} \mathrm{d} x\right) \\ &= O\left(\frac{n^{\frac{3}{4}}}{\log{n}}\right) \end{aligned} \]

Što se tiče prostorne složenosti, vidimo da i \(F_{k}\) i \(F_{\mathrm{prime}}\) poprimaju korisne vrijednosti samo u točkama \(n / i\), kojih je ukupno \(O(\sqrt{n})\); pamtimo li samo korisne vrijednosti, prostorna se složenost može optimizirati na \(O(\sqrt{n})\).

Prvo, jednim blokovskim dijeljenjem po cjelobrojnom kvocijentu možemo dobiti sve korisne vrijednosti i zapamtiti ih u nizu \(\text{lis}\) veličine \(O(\sqrt{n})\). Za korisnu vrijednost \(v\) označimo s \(\text{id}(v)\) indeks vrijednosti \(v\) u nizu \(\text{lis}\); lako se vidi da za sve korisne vrijednosti \(v\) vrijedi \(\text{id}(v) \le \sqrt{n}\).

Zatim zasebno razmotrimo korisne vrijednosti manje ili jednake \(\sqrt{n}\) i one veće od \(\sqrt{n}\): za korisnu vrijednost \(v\) manju ili jednaku \(\sqrt{n}\) njezin \(\text{id}(v)\) pamtimo u nizu \(\text{le}\), tj. \(\text{le}_v = \text{id}(v)\); za korisnu vrijednost \(v\) veću od \(\sqrt{n}\) njezin \(\text{id}(v)\) pamtimo u nizu \(\text{ge}\), a kako je \(v\) prevelik, \(\text{id}(v)\) pamtimo pomoću \(v' = n / v < \sqrt{n}\), tj. \(\text{ge}_{v'} = \text{id}(v)\).

Tako pomoću dva niza veličine \(O(\sqrt{n})\) možemo zapamtiti \(\text{id}\) svih korisnih vrijednosti i dohvaćati ih u \(O(1)\). Pri računanju \(F_{k}\) ili \(F_{\mathrm{prime}}\) kao indeks umjesto korisne vrijednosti koristimo njezin \(\text{id}\), čime se prostorna složenost optimizira na \(O(\sqrt{n})\).

Postupak

Za računanje \(F_{k}(n)\) u implementaciji obično biramo prvu metodu, koju je lakše implementirati; pri manjim veličinama ulaza ona se često ponaša bolje od druge metode.

Za računanje \(F_{\mathrm{prime}}(n)\) dovoljno je izravno implementirati rekurziju.

Za \(p_{k}^{2} \le n\) linearnim sitom možemo predračunati \(s_{k} := F_{\mathrm{prime}}(p_{k})\) i njime zamijeniti \(F_{\mathrm{prime}}(p_{k - 1})\) u rekurziji za \(F_{k}\).
Analogno, \(G_{k - 1}(p_{k - 1}) = \sum_{i = 1}^{k - 1} g(p_{i})\) u rekurziji za \(G\) također se može predračunati na isti način.

Kada Extended Eratosthenes Sieve koristimo za prefiksne sume multiplikativne funkcije \(f\), treba razjasniti sljedeće:

  • kako brzo (obično u linearnoj vremenskoj složenosti) prosijati prvih \(\sqrt{n}\) vrijednosti \(f\);
  • polinomni zapis \(f(p)\);
  • kako brzo izračunati \(f(p^{c})\).

Kad je to razjašnjeno, dovoljno je redom implementirati sljedeće dijelove:

  1. prosijati proste brojeve u \([1, \sqrt{n}]\) i prvih \(\sqrt{n}\) vrijednosti \(f\);
  2. za svaki član polinomnog zapisa \(f(p)\) prosijati odgovarajući \(G\) i spajanjem dobiti sve \(O(\sqrt{n})\) korisne vrijednosti \(F_{\mathrm{prime}}\);
  3. implementirati rekurziju prema rekurzivnoj formuli za \(F_{k}\) i izračunati \(F_{1}(n)\).

Izračunajte \(\displaystyle \sum_{i = 1}^{n} \varphi(i)\) i \(\displaystyle \sum_{i = 1}^{n} \mu(i)\).

Za prefiksnu sumu \(\mu(i)\) lako vidimo \(f(p) = -1\). Tada je \(g(p) = -1, G_{0}(n) = \sum_{i = 2}^{n} g(i) = -n + 1\). Izravnim sijanjem dobivamo sve \(O(\sqrt{n})\) potrebne vrijednosti \(F_{\mathrm{prime}}\).

LOJ 6053 简单的函数 (Jednostavna funkcija)

Zadana je \(f(n)\):

\[ f(n) = \begin{cases} 1 & n = 1 \\ p \operatorname{xor} c & n = p^{c} \\ f(a)f(b) & n = ab \land a \perp b \end{cases} \]

Izračunajte \(\displaystyle \sum_{i = 1}^{n} f(i)\).

Rješenje

Lako vidimo \(f(p) = p - 1 + 2[p = 2]\). Sijemo, dakle, kao pri sijanju \(\varphi\), uz poseban slučaj za \(2\).

Referentni kod 
/* „LOJ #6053” 简单的函数 (Jednostavna funkcija) */
#include <cmath>
#include <iostream>

constexpr int MAXS = 200000;  // 2sqrt(n)
constexpr int mod = 1000000007;

template <typename x_t, typename y_t>
void inc(x_t &x, const y_t &y) {
  x += y;
  (mod <= x) && (x -= mod);
}

template <typename x_t, typename y_t>
void dec(x_t &x, const y_t &y) {
  x -= y;
  (x < 0) && (x += mod);
}

template <typename x_t, typename y_t>
int sum(const x_t &x, const y_t &y) {
  return x + y < mod ? x + y : (x + y - mod);
}

template <typename x_t, typename y_t>
int sub(const x_t &x, const y_t &y) {
  return x < y ? x - y + mod : (x - y);
}

template <typename _Tp>
int div2(const _Tp &x) {
  return ((x & 1) ? x + mod : x) >> 1;
}

// sve gore navedeno služi sprječavanju negativnih brojeva i računanju po modulu
template <typename _Tp>
long long sqrll(const _Tp &x) {  // funkcija kvadriranja
  return (long long)x * x;
}

int pri[MAXS / 7], lpf[MAXS + 1], spri[MAXS + 1], pcnt;

void sieve(const int &n) {
  for (int i = 2; i <= n; ++i) {
    if (lpf[i] == 0) {  // zapiši prost broj
      lpf[i] = ++pcnt;
      pri[lpf[i]] = i;
      spri[pcnt] = sum(spri[pcnt - 1], i);  // prefiksna suma
    }
    for (int j = 1, v; j <= lpf[i] && (v = i * pri[j]) <= n; ++j) lpf[v] = j;
  }
}

long long global_n;
int lim;
int le[MAXS + 1],  // x <= \sqrt{n}
    ge[MAXS + 1];  // x > \sqrt{n}
#define idx(v) (v <= lim ? le[v] : ge[global_n / v])

int G[MAXS + 1][2], Fprime[MAXS + 1];
long long lis[MAXS + 1];
int cnt;

void init(const long long &n) {
  for (long long i = 1, j, v; i <= n; i = n / j + 1) {
    j = n / i;
    v = j % mod;
    lis[++cnt] = j;
    (j <= lim ? le[j] : ge[global_n / j]) = cnt;
    G[cnt][0] = sub(v, 1ll);
    G[cnt][1] = div2((long long)(v + 2ll) * (v - 1ll) % mod);
  }
}

void calcFprime() {
  for (int k = 1; k <= pcnt; ++k) {
    const int p = pri[k];
    const long long sqrp = sqrll(p);
    for (int i = 1; lis[i] >= sqrp; ++i) {
      const long long v = lis[i] / p;
      const int id = idx(v);
      dec(G[i][0], sub(G[id][0], k - 1));
      dec(G[i][1], (long long)p * sub(G[id][1], spri[k - 1]) % mod);
    }
  }
  /* F_prime = G_1 - G_0 */
  for (int i = 1; i <= cnt; ++i) Fprime[i] = sub(G[i][1], G[i][0]);
}

int f_p(const int &p, const int &c) {
  /* f(p^{c}) = p xor c */
  return p ^ c;
}

int F(const int &k, const long long &n) {
  if (n < pri[k] || n <= 1) return 0;
  const int id = idx(n);
  long long ans = Fprime[id] - (spri[k - 1] - (k - 1));
  if (k == 1) ans += 2;
  for (int i = k; i <= pcnt && sqrll(pri[i]) <= n; ++i) {
    long long pw = pri[i], pw2 = sqrll(pw);
    for (int c = 1; pw2 <= n; ++c, pw = pw2, pw2 *= pri[i])
      ans +=
          ((long long)f_p(pri[i], c) * F(i + 1, n / pw) + f_p(pri[i], c + 1)) %
          mod;
  }
  return ans % mod;
}

using std::cin;
using std::cout;

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> global_n;
  lim = sqrt(global_n);  // gornja granica

  sieve(lim + 1000);  // predračun
  init(global_n);
  calcFprime();
  cout << (F(1, global_n) + 1ll + mod) % mod << '\n';

  return 0;
}

Definition

In terms of the idea behind it, this sieve method is also called the "Extended Eratosthenes Sieve".

Since it was invented and first used by Min_25, it is called the "Min_25 sieve".

Properties

It can solve the prefix-sum problem for a class of multiplicative functions in \(O\left(\frac{n^{\frac{3}{4}}}{\log{n}}\right)\) or \(\Theta\left(n^{1 - \epsilon}\right)\) time complexity.

Requirements: \(f(p)\) is a sum of completely multiplicative functions in \(p\) that can be evaluated quickly (e.g., a polynomial); \(f(p^{c})\) can be evaluated quickly.

Notation

  • Unless stated otherwise, every variable denoted by \(p\) in this section takes values in the set of all primes.
  • \(x / y := \left\lfloor\frac{x}{y}\right\rfloor\)
  • \(\operatorname{isprime}(n) := [ |\{d : d \mid n\}| = 2 ]\), i.e., its value is \(1\) when \(n\) is prime and \(0\) otherwise.
  • \(p_{k}\): the \(k\)-th smallest prime among all primes (e.g., \(p_{1} = 2, p_{2} = 3\)). In particular, let \(p_{0} = 1\).
  • \(\operatorname{lpf}(n) := [1 < n] \min\{p : p \mid n\} + [1 = n]\), i.e., the least prime factor of \(n\). In particular, for \(n=1\) its value is \(1\).
  • \(F_{\mathrm{prime}}(n) := \sum_{2 \le p \le n} f(p)\)
  • \(F_{k}(n) := \sum_{i = 2}^{n} [p_{k} \le \operatorname{lpf}(i)] f(i)\)

Explanation

Looking at the definition of \(F_{k}(n)\), we see that the answer is exactly \(F_{1}(n) + f(1) = F_{1}(n) + 1\).

Consider how to compute \(F_{k}(n)\). By enumerating the least prime factor of each \(i\) and its exponent we obtain the recurrence:

\[ \begin{aligned} F_{k}(n) &= \sum_{i = 2}^{n} [p_{k} \le \operatorname{lpf}(i)] f(i) \\ &= \sum_{\substack{k \le i \\ p_{i}^{2} \le n}} \sum_{\substack{c \ge 1 \\ p_{i}^{c} \le n}} f\left(p_{i}^{c}\right) ([c > 1] + F_{i + 1}\left(n / p_{i}^{c}\right)) + \sum_{\substack{k \le i \\ p_{i} \le n}} f(p_{i}) \\ &= \sum_{\substack{k \le i \\ p_{i}^{2} \le n}} \sum_{\substack{c \ge 1 \\ p_{i}^{c} \le n}} f\left(p_{i}^{c}\right) ([c > 1] + F_{i + 1}\left(n / p_{i}^{c}\right)) + F_{\mathrm{prime}}(n) - F_{\mathrm{prime}}(p_{k - 1}) \\ &= \sum_{\substack{k \le i \\ p_{i}^{2} \le n}} \sum_{\substack{c \ge 1 \\ p_{i}^{c + 1} \le n}} \left(f\left(p_{i}^{c}\right) F_{i + 1}\left(n / p_{i}^{c}\right) + f\left(p_{i}^{c + 1}\right)\right) + F_{\mathrm{prime}}(n) - F_{\mathrm{prime}}(p_{k - 1}) \end{aligned} \]

The last step of the derivation is based on the following fact: for \(c\) satisfying \(p_{i}^{c} \le n < p_{i}^{c + 1}\) we have \(p_{i}^{c + 1} > n \iff n / p_{i}^{c} < p_{i} < p_{i + 1}\), hence \(F_{i + 1}\left(n / p_{i}^{c}\right) = 0\).
The boundary value is \(F_{k}(n) = 0 (p_{k} > n)\).

Suppose all \(F_{\mathrm{prime}}(n)\) have already been computed; then there are two ways to compute all \(F_{k}(n)\):

  1. Compute directly according to the recurrence.
  2. Enumerate \(p\) from largest to smallest and perform the transitions; the contribution of a transition is nonzero only when \(p^{2} < n\), so it suffices to optimize the recurrence with suffix sums.

Now consider how to compute \(F_{\mathrm{prime}}{(n)}\).
Observing the process of computing \(F_{k}(n)\), it is easy to see that the only useful values of \(F_{\mathrm{prime}}\) are those at the \(O(\sqrt{n})\) points \(1, 2, \dots, \left\lfloor\sqrt{n}\right\rfloor, n / \sqrt{n}, \dots, n / 2, n\).
In general, \(f(p)\) is a low-degree polynomial in \(p\) and can be written as \(f(p) = \sum a_{i} p^{c_{i}}\).
Then for each \(p^{c_{i}}\), its contribution to \(F_{\mathrm{prime}}(n)\) is \(a_{i} \sum_{2 \le p \le n} p^{c_{i}}\).
Considering the contribution of each \(p^{c_{i}}\) separately, the problem becomes: given \(n, s, g(p) = p^{s}\), compute \(\sum_{p \le m} g(p)\) for all \(m = n / i\).

Note

\(g(p) = p^{s}\) is a completely multiplicative function!

So let \(G_{k}(n) := \sum_{i = 2}^{n} \left[p_{k} < \operatorname{lpf}(i) \lor \operatorname{isprime}(i)\right] g(i)\), i.e., the sum of the \(g\) values of the numbers remaining after the \(k\)-th round of the sieve of Eratosthenes.
For a composite number \(x \le n\) we necessarily have \(\operatorname{lpf}(x) \le \sqrt{x} \le \sqrt{n}\). Let \(p_{\ell(n)}\) be the largest prime not exceeding \(\sqrt{n}\); then \(\sum_{2\le p\le n}g(p) = G_{\ell(n)}(n)\), i.e., after \(\ell\) rounds of the sieve of Eratosthenes only primes remain. Consider the boundary value of \(G\); obviously \(G_{0}(n) = \sum_{i = 2}^{n} g(i)\). (Remember? We specially agreed that \(p_{0} = 1\).)
For the transition, consider the process of the sieve of Eratosthenes and discuss the contribution of each part separately:

  1. For the part where \(n < p_{k}^{2}\), the value of \(G\) does not change, i.e., \(G_{k}(n) = G_{k - 1}(n)\).
  2. For the part where \(p_{k}^{2} \le n\), the sieved-out numbers necessarily have the prime factor \(p_{k}\), i.e., \(-g(p_{k}) G_{k - 1}(n / p_{k})\).
  3. In the second part, since \(p_{k}^{2} \le n \iff p_{k} \le n / p_{k}\), the numbers \(i\) satisfying \(\operatorname{lpf}(i) < p_{k}\) are subtracted in excess. This part should be added back, i.e., \(g(p_{k}) G_{k - 1}(p_{k - 1})\).

Hence:

\[ G_{k}(n) = G_{k - 1}(n) - \left[p_{k}^{2} \le n\right] g(p_{k}) (G_{k - 1}(n / p_{k}) - G_{k - 1}(p_{k - 1})) \]

Complexity analysis

For the computation of \(F_{k}(n)\), the time complexity of the first method has been proven to be \(O\left(n^{1 - \epsilon}\right)\) (see Zhu Zhenting's Chinese national training team paper 《一些特殊的数论函数求和问题》 (Some special summation problems of number-theoretic functions), section 2.3);
the second method is essentially the second part of Zhou's sieve and is also mentioned in Ren Zhizhou's paper 《积性函数求和的几种方法》 (Several methods for summing multiplicative functions) (6.5.4); its time complexity has been proven to be \(O\left(\frac{n^{\frac{3}{4}}}{\log{n}}\right)\).

As for the computation of \(F_{\mathrm{prime}}(n)\), its implementation is in fact the same as the first part of Zhou's sieve.
Note that for each \(m = n / i\), only the transitions made while enumerating the \(p_{k}\) satisfying \(p_{k}^{2} \le m\) contribute to the time complexity, so the time complexity can be estimated as:

\[ \begin{aligned} T(n) &= \sum_{i^{2} \le n} O\left(\pi\left(\sqrt{i}\right)\right) + \sum_{i^{2} \le n} O\left(\pi\left(\sqrt{\frac{n}{i}}\right)\right) \\ &= \sum_{i^{2} \le n} O\left(\frac{\sqrt{i}}{\ln{\sqrt{i}}}\right) + \sum_{i^{2} \le n} O\left(\frac{\sqrt{\frac{n}{i}}}{\ln{\sqrt{\frac{n}{i}}}}\right) \\ &= O\left(\int_{1}^{\sqrt{n}} \frac{\sqrt{\frac{n}{x}}}{\log{\sqrt{\frac{n}{x}}}} \mathrm{d} x\right) \\ &= O\left(\frac{n^{\frac{3}{4}}}{\log{n}}\right) \end{aligned} \]

As for the space complexity, we can see that both \(F_{k}\) and \(F_{\mathrm{prime}}\) take useful values only at the points \(n / i\), of which there are \(O(\sqrt{n})\) in total; by recording only the useful values, the space complexity can be optimized to \(O(\sqrt{n})\).

First, with one pass of floor-division blocks we can obtain all useful values and record them in an array \(\text{lis}\) of size \(O(\sqrt{n})\). For a useful value \(v\), let \(\text{id}(v)\) denote the index of \(v\) in \(\text{lis}\); it is easy to see that for all useful values \(v\), \(\text{id}(v) \le \sqrt{n}\).

Then consider separately the useful values less than or equal to \(\sqrt{n}\) and those greater than \(\sqrt{n}\): for a useful value \(v\) less than or equal to \(\sqrt{n}\), record its \(\text{id}(v)\) in an array \(\text{le}\), i.e., \(\text{le}_v = \text{id}(v)\); for a useful value \(v\) greater than \(\sqrt{n}\), record \(\text{id}(v)\) in an array \(\text{ge}\), and since \(v\) is too large, record \(\text{id}(v)\) using \(v' = n / v < \sqrt{n}\), i.e., \(\text{ge}_{v'} = \text{id}(v)\).

In this way, two arrays of size \(O(\sqrt{n})\) suffice to record the \(\text{id}\) of all useful values and query them in \(O(1)\). When computing \(F_{k}\) or \(F_{\mathrm{prime}}\), use the \(\text{id}\) of a useful value instead of the value itself as the index, and the space complexity is optimized to \(O(\sqrt{n})\).

Procedure

For the computation of \(F_{k}(n)\), in implementations we usually choose the first method, which is easier to implement; for smaller input sizes it often performs better than the second method.

For the computation of \(F_{\mathrm{prime}}(n)\), it suffices to implement the recurrence directly.

For \(p_{k}^{2} \le n\), we can precompute \(s_{k} := F_{\mathrm{prime}}(p_{k})\) with a linear sieve to replace \(F_{\mathrm{prime}}(p_{k - 1})\) in the recurrence for \(F_{k}\).
Correspondingly, \(G_{k - 1}(p_{k - 1}) = \sum_{i = 1}^{k - 1} g(p_{i})\) in the recurrence for \(G\) can also be precomputed in the same way.

When using the Extended Eratosthenes Sieve to compute the prefix sums of a multiplicative function \(f\), the following points should be clarified:

  • how to quickly (usually in linear time complexity) sieve the first \(\sqrt{n}\) values of \(f\);
  • the polynomial representation of \(f(p)\);
  • how to quickly compute \(f(p^{c})\).

Once these points are clear, it suffices to implement the following parts in order:

  1. sieve the primes in \([1, \sqrt{n}]\) and the first \(\sqrt{n}\) values of \(f\);
  2. for each term of the polynomial representation of \(f(p)\), sieve the corresponding \(G\) and merge them to obtain all \(O(\sqrt{n})\) useful values of \(F_{\mathrm{prime}}\);
  3. implement the recursion according to the recurrence for \(F_{k}\) and compute \(F_{1}(n)\).

Example problems

Luogu P4213【模板】杜教筛 (Template: Du's sieve)

Compute \(\displaystyle \sum_{i = 1}^{n} \varphi(i)\) and \(\displaystyle \sum_{i = 1}^{n} \mu(i)\).

Solution

For the prefix sum of \(\varphi(i)\), first it is easy to see that \(f(p) = p - 1\). For the linear term \((p)\) of \(f(p)\) we have \(g(p) = p, G_{0}(n) = \sum_{i = 2}^{n} g(i) = \frac{(n + 2) (n - 1)}{2}\); for the constant term \((-1)\) of \(f(p)\) we have \(g(p) = -1, G_{0}(n) = \sum_{i = 2}^{n} g(i) = -n + 1\). Sieve twice and add the results to obtain all \(O(\sqrt{n})\) required values of \(F_{\mathrm{prime}}\).

For the prefix sum of \(\mu(i)\), it is easy to see that \(f(p) = -1\). Then \(g(p) = -1, G_{0}(n) = \sum_{i = 2}^{n} g(i) = -n + 1\). Sieving directly gives all \(O(\sqrt{n})\) required values of \(F_{\mathrm{prime}}\).

LOJ 6053 简单的函数 (A simple function)

Given \(f(n)\):

\[ f(n) = \begin{cases} 1 & n = 1 \\ p \operatorname{xor} c & n = p^{c} \\ f(a)f(b) & n = ab \land a \perp b \end{cases} \]

Compute \(\displaystyle \sum_{i = 1}^{n} f(i)\).

Solution

It is easy to see that \(f(p) = p - 1 + 2[p = 2]\). So sieve as in the method for sieving \(\varphi\), handling \(2\) as a special case.

Reference code 
/* “LOJ #6053” 简单的函数 (A simple function) */
#include <cmath>
#include <iostream>

constexpr int MAXS = 200000;  // 2sqrt(n)
constexpr int mod = 1000000007;

template <typename x_t, typename y_t>
void inc(x_t &x, const y_t &y) {
  x += y;
  (mod <= x) && (x -= mod);
}

template <typename x_t, typename y_t>
void dec(x_t &x, const y_t &y) {
  x -= y;
  (x < 0) && (x += mod);
}

template <typename x_t, typename y_t>
int sum(const x_t &x, const y_t &y) {
  return x + y < mod ? x + y : (x + y - mod);
}

template <typename x_t, typename y_t>
int sub(const x_t &x, const y_t &y) {
  return x < y ? x - y + mod : (x - y);
}

template <typename _Tp>
int div2(const _Tp &x) {
  return ((x & 1) ? x + mod : x) >> 1;
}

// all of the above serves to prevent negative numbers and to reduce modulo
template <typename _Tp>
long long sqrll(const _Tp &x) {  // squaring function
  return (long long)x * x;
}

int pri[MAXS / 7], lpf[MAXS + 1], spri[MAXS + 1], pcnt;

void sieve(const int &n) {
  for (int i = 2; i <= n; ++i) {
    if (lpf[i] == 0) {  // record the prime
      lpf[i] = ++pcnt;
      pri[lpf[i]] = i;
      spri[pcnt] = sum(spri[pcnt - 1], i);  // prefix sum
    }
    for (int j = 1, v; j <= lpf[i] && (v = i * pri[j]) <= n; ++j) lpf[v] = j;
  }
}

long long global_n;
int lim;
int le[MAXS + 1],  // x <= \sqrt{n}
    ge[MAXS + 1];  // x > \sqrt{n}
#define idx(v) (v <= lim ? le[v] : ge[global_n / v])

int G[MAXS + 1][2], Fprime[MAXS + 1];
long long lis[MAXS + 1];
int cnt;

void init(const long long &n) {
  for (long long i = 1, j, v; i <= n; i = n / j + 1) {
    j = n / i;
    v = j % mod;
    lis[++cnt] = j;
    (j <= lim ? le[j] : ge[global_n / j]) = cnt;
    G[cnt][0] = sub(v, 1ll);
    G[cnt][1] = div2((long long)(v + 2ll) * (v - 1ll) % mod);
  }
}

void calcFprime() {
  for (int k = 1; k <= pcnt; ++k) {
    const int p = pri[k];
    const long long sqrp = sqrll(p);
    for (int i = 1; lis[i] >= sqrp; ++i) {
      const long long v = lis[i] / p;
      const int id = idx(v);
      dec(G[i][0], sub(G[id][0], k - 1));
      dec(G[i][1], (long long)p * sub(G[id][1], spri[k - 1]) % mod);
    }
  }
  /* F_prime = G_1 - G_0 */
  for (int i = 1; i <= cnt; ++i) Fprime[i] = sub(G[i][1], G[i][0]);
}

int f_p(const int &p, const int &c) {
  /* f(p^{c}) = p xor c */
  return p ^ c;
}

int F(const int &k, const long long &n) {
  if (n < pri[k] || n <= 1) return 0;
  const int id = idx(n);
  long long ans = Fprime[id] - (spri[k - 1] - (k - 1));
  if (k == 1) ans += 2;
  for (int i = k; i <= pcnt && sqrll(pri[i]) <= n; ++i) {
    long long pw = pri[i], pw2 = sqrll(pw);
    for (int c = 1; pw2 <= n; ++c, pw = pw2, pw2 *= pri[i])
      ans +=
          ((long long)f_p(pri[i], c) * F(i + 1, n / pw) + f_p(pri[i], c + 1)) %
          mod;
  }
  return ans % mod;
}

using std::cin;
using std::cout;

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> global_n;
  lim = sqrt(global_n);  // upper bound

  sieve(lim + 1000);  // preprocessing
  init(global_n);
  calcFprime();
  cout << (F(1, global_n) + 1ll + mod) % mod << '\n';

  return 0;
}
