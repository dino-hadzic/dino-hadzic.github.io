Predznanje: Faktorijel po modulu

Uvod

U ovom se članku razmatra računanje velikih binomnih koeficijenata po modulu. Binomni koeficijent (broj kombinacija) jest izraz:

\[ \binom{n}{k} = \dfrac{n!}{k!(n-k)!}. \]

Kada veličina problema nije velika, binomni se koeficijent može izračunati rekurzivnom formulom u vremenskoj složenosti \(O(nk)\); po dovoljno velikom prostom modulu \(p>n\) može se izračunati i u vremenu \(O(n)\) računanjem faktorijela u brojniku i nazivniku. No kada je veličina problema vrlo velika (\(n\sim 10^{18}\)), te metode više nisu primjenjive.

Na temelju Lucasova teorema i njegova poopćenja u ovom se članku razmatra metoda kojom se binomni koeficijent može izračunati kada modul nije prevelik (\(m \sim 10^6\)). Preciznije, metoda se može primijeniti čim je zbroj svih potencija prostih brojeva u jedinstvenom rastavu modula \(m=\prod p_i^{e_i}\) (tj. \(\sum p_i^{e_i}\)) reda veličine \(10^6\), jer pretprocesiranje algoritma odgovara otprilike toj veličini.

Lucasov teorem

Najprije razmotrimo slučaj u kojem je modul prost broj \(p\). Tada vrijedi Lucasov teorem:

Lucasov teorem

Za prost broj \(p\) vrijedi

\[ \binom{n}{k}\equiv \binom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor}\binom{n\bmod p}{k\bmod p}\pmod p. \]

Pritom se za \(n<k\) binomni koeficijent \(\dbinom{n}{k}\) po dogovoru definira kao \(0\).

Dokaz pomoću funkcija izvodnica

Promotrimo vrijednost \(\displaystyle\binom{p}{n} \bmod p\). Budući da je

\[ \binom{p}{n} = \frac{p!}{n!(p-n)!}, \]

za \(n\neq 0,p\) nazivnik ne sadrži faktor \(p\), a brojnik sadrži faktor \(p\), pa je razlomak nužno višekratnik broja \(p\) i njegov je ostatak po modulu \(p\) jednak \(0\); za \(n=0,p\) razlomak je jednak \(1\). Stoga je

\[ \binom{p}{n} \equiv [n=0\lor n=p] \pmod p. \]

Neka je \(f(x) = ax^n + bx^m\). Općenito, prema binomnom teoremu i malom Fermatovu teoremu vrijedi

\[ \begin{aligned} (f(x))^p &= \left(ax^n + bx^m\right)^p \\ &= \sum_{k=0}^p\binom{p}{k}(ax^n)^k(bx^m)^{p-k}\\ &\equiv a^px^{pn} + b^px^{pm} \\ &\equiv a(x^p)^n+b(x^p)^m\\ &= f(x^p) \pmod p. \end{aligned} \]

Ovdje kongruencija u trećem retku koristi prethodno pokazani zaključak da binomni koeficijent nije višekratnik broja \(p\) samo za \(k=0,p\).

Pomoću tog zaključka promotrimo binomni razvoj:

\[ \begin{aligned} (1+x)^n &= (1+x)^{p\lfloor n/p\rfloor}(1+x)^{n\bmod p} \\ &\equiv (1+x^p)^{\lfloor n/p\rfloor}(1+x)^{n\bmod p} \pmod p. \end{aligned} \]

Na lijevoj strani jednakosti koeficijent uz član \(x^k\) iznosi

\[ \binom{n}{k}\bmod p. \]

Izračunajmo sada koeficijent uz član \(x^k\) na desnoj strani. Stupnjevi članova prvog faktora nužno su višekratnici broja \(p\), a stupnjevi članova drugog faktora nužno su manji od \(p\); način da se \(k\) rastavi na zbroj dvaju takvih dijelova jedinstven je, a daje ga dijeljenje s ostatkom: \(k=p\lfloor k/p\rfloor +(k\bmod p)\). Stoga prvi faktor može pridonijeti samo svojim članom stupnja \(p\lfloor k/p\rfloor\), a drugi faktor samo svojim članom stupnja \(k\bmod p\). Dakle, koeficijent uz \(x^k\) na desnoj strani jednak je umnošku koeficijenata članova kojima pridonose ta dva faktora:

\[ \binom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor}\binom{n\bmod p}{k\bmod p}\bmod p. \]

Izjednačavanjem koeficijenata obiju strana dobiva se Lucasov teorem.

Dokaz pomoću rezultata o faktorijelu po modulu

Ovdje dajemo dokaz temeljen na rezultatima o faktorijelu po modulu, kako bismo uspostavili vezu s metodom iz odjeljka o algoritmu exLucas u nastavku. Znamo da je binomni koeficijent

\[ \binom{n}{k} = \dfrac{n!}{k!(n-k)!}. \]

Odvajanjem potencija broja \(p\) u faktorijelu \(n!\) od ostalih faktora dobiva se rastav:

\[ n! = p^{\nu_p(n!)}(n!)_p. \]

Odatle dobivamo izraz za binomni koeficijent:

\[ \binom{n}{k} = p^{\nu_p(n!)-\nu_p(k!)-\nu_p((n-k)!)}\dfrac{(n!)_p}{(k!)_p((n-k)!)_p}. \]

I eksponent \(\nu_p(n!)\) i ostatak faktorijela \((n!)_p\bmod p\) zadovoljavaju rekurzivne formule:

\[ \begin{aligned} \nu_p(n!) &= \lfloor n/p\rfloor+\nu_p( \lfloor n/p\rfloor!),\\ (n!)_p &\equiv (-1)^{\lfloor n/p\rfloor}\cdot (n\bmod p)!\cdot (\lfloor n/p\rfloor!)_p\pmod p. \end{aligned} \]

Prva je posljedica Legendreove formule, a druga posljedica Wilsonova teorema.

Uvrštavanjem rekurzivnih formula u izraz za binomni koeficijent i sređivanjem dobiva se:

\[ \begin{aligned} \binom{n}{k} &\equiv (-p)^{\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor}\cdot\dfrac{(n\bmod p)!}{(k\bmod p)!((n-k)\bmod p)!} \\ &\quad \cdot p^{\nu_p(\lfloor n/p\rfloor!)-\nu_p(\lfloor k/p\rfloor!)-\nu_p(\lfloor(n-k)/p\rfloor!)}\dfrac{(\lfloor n/p\rfloor!)_p}{(\lfloor k/p\rfloor!)_p(\lfloor(n-k)/p\rfloor!)_p} \pmod p. \end{aligned} \]

Promotrimo sada vrijednost izraza \(\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor\). Budući da vrijedi

\[ \begin{aligned} n &= \lfloor n/p\rfloor p + (n\bmod p),\\ k &= \lfloor k/p\rfloor p + (k\bmod p),\\ n-k &= \lfloor (n-k)/p\rfloor p + ((n-k)\bmod p),\\ \end{aligned} \]

oduzimanjem druge i treće jednakosti od prve dobivamo

\[ (\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor)p = (k\bmod p)+((n-k)\bmod p)-(n\bmod p). \]

Na desnoj strani zbroj prvih dvaju članova strogo je manji od \(2p\), a treći član \(n\bmod p\) upravo je ostatak zbroja prvih dvaju članova, pa desna strana mora biti nenegativna, ali manja od \(2p\); budući da mora biti višekratnik broja \(p\), ona je \(0\) ili \(p\). To znači da \(\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor\) može biti samo \(0\) ili \(1\):

  • Ako je \(0\), tada vrijedi i \((n\bmod p) = (k\bmod p)+((n-k)\bmod p)\). Stoga je eksponent prvog faktora u gornjem izrazu \(0\), pa je taj faktor jednak jedan; drugi je faktor upravo \(\dbinom{n\bmod p}{k\bmod p}\); a za treći se faktor iz prethodnog razvoja (uočite da je sada \(\lfloor(n-k)/p\rfloor=\lfloor n/p\rfloor-\lfloor k/p\rfloor\)) vidi da je jednak \(\dbinom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor}\). U tom slučaju Lucasov teorem vrijedi;

  • Ako je \(1\), tada je eksponent prvog faktora \(1\), pa je taj faktor jednak nuli, a time je i ostatak binomnog koeficijenta nula. Istodobno je i \(\dbinom{n\bmod p}{k\bmod p}\) na desnoj strani jednakosti koju Lucasov teorem tvrdi nužno nula, jer tada nužno vrijedi \((n\bmod p)<(k\bmod p)\); u suprotnom bismo imali

    \[ ((n-k)\bmod p) = p + (n\bmod p) - (k\bmod p) \ge p. \]

    To je očito u suprotnosti s definicijom ostatka.

Objedinjavanjem obaju slučajeva dobiva se traženi Lucasov teorem. Ovaj dokaz pokazuje da su pri računanju binomnih koeficijenata po prostom modulu rezultati dobiveni Lucasovim teoremom i algoritmom exLucas ekvivalentni.

Lucasov teorem kaže da se, kada je modul prost broj \(p\), računanje velikih binomnih koeficijenata može svesti na računanje binomnih koeficijenata manje veličine. Na desnoj strani prvi se binomni koeficijent može dalje rekurzivno računati sve dok ne bude \(k=0\); drugi se binomni koeficijent može izračunati izravno ili unaprijed pretprocesirati. Zapisano u obliku koda:

Skica 
long long Lucas(long long n, long long k, long long p) {
  if (k == 0) return 1;
  return (C(n % p, k % p, p) * Lucas(n / p, k / p, p)) % p;
}

Ovdje C(n, k, p) služi za računanje binomnih koeficijenata male veličine.

Rekurzija se izvodi najviše \(O(\log_p n)\) puta, pa je složenost algoritma \(O(f(p)+g(p)\log_p n)\), gdje je \(f(p)\) složenost pretprocesiranja binomnih koeficijenata, a \(g(p)\) složenost računanja jednog binomnog koeficijenta.

Referentna implementacija

Ovdje dana referentna implementacija u vremenu \(O(p)\) pretprocesira faktorijele do \(p\) i njihove inverze, nakon čega svaki binomni koeficijent računa u vremenu \(O(1)\):

Referentna implementacija 
#include <iostream>
#include <vector>

class BinomModPrime {
  int p;
  std::vector<int> fa, ifa;

  // Calculate binom(n, k) mod p for n, k < p.
  int calc(int n, int k) {
    if (n < k) return 0;
    long long res = fa[n];
    res = (res * ifa[k]) % p;
    res = (res * ifa[n - k]) % p;
    return res;
  }

 public:
  BinomModPrime(int p) : p(p), fa(p), ifa(p) {
    // Factorials mod p till p.
    fa[0] = 1;
    for (int i = 1; i < p; ++i) {
      fa[i] = (long long)fa[i - 1] * i % p;
    }
    // Inverse of factorials mod p till p.
    ifa[p - 1] = p - 1;  // Wilson's theorem.
    for (int i = p - 1; i; --i) {
      ifa[i - 1] = (long long)ifa[i] * i % p;
    }
  }

  // Calculate binom(n, k) mod p.
  int binomial(long long n, long long k) {
    long long res = 1;
    while (n || k) {
      res = (res * calc(n % p, k % p)) % p;
      n /= p;
      k /= p;
    }
    return res;
  }
};

int main() {
  int t, p;
  std::cin >> t >> p;
  BinomModPrime bm(p);
  for (; t; --t) {
    long long n, k;
    std::cin >> n >> k;
    std::cout << bm.binomial(n, k) << '\n';
  }
  return 0;
}

Vremenska složenost ove implementacije iznosi \(O(p+T\log_p n)\), gdje je \(T\) broj upita.

Algoritam exLucas

Lucasov teorem zahtijeva da modul \(p\) bude prost; za slučaj u kojem modul nije prost potreban je algoritam exLucas (prošireni Lucasov teorem). Unatoč imenu, taj algoritam u stvarnosti ne koristi Lucasov teorem. Njegov je ključni korak računanje faktorijela po modulu koji je potencija prostog broja. Drugi dokaz gore ukazao je na njegovu vezu s Lucasovim teoremom.

Slučaj modula koji je potencija prostog broja

Najprije razmotrimo slučaj u kojem je modul potencija prostog broja \(p^\alpha\). Odvajanjem potencija broja \(p\) u faktorijelu \(n!\) od ostalih faktora dobiva se rastav:

\[ n! = p^{\nu_p(n!)}(n!)_p. \]

Ovdje je \(\nu_p(n!)\) eksponent broja \(p\) u rastavu \(n!\) na proste faktore, a \((n!)_p\) je očito relativno prost s \(p\). Stoga se binomni koeficijent može zapisati kao:

\[ \binom{n}{k} = p^{\nu_p(n!)-\nu_p(k!)-\nu_p((n-k)!)}\dfrac{(n!)_p}{(k!)_p((n-k)!)_p}. \]

Vrijednosti \(\nu_p(n!)\) i slične u formuli mogu se izračunati Legendreovom formulom, a \((n!)_p\) i slične rekurzivnom relacijom. Budući da su potonje relativno proste s \(p^\alpha\), inverz umnoška u nazivniku može se izračunati proširenim Euklidovim algoritmom. Time je problem riješen.

Uočite: ako je eksponent \(\nu_p(n!)-\nu_p(k!)-\nu_p((n-k)!)\ge\alpha\), ostatak je nužno nula i nije potrebno dalje računati.

Slučaj općeg modula

Za slučaj u kojem je \(m\) opći složen broj dovoljno ga je najprije rastaviti na proste faktore:

\[ m = p_1^{\alpha_1}p_2^{\alpha_2}\cdots p_s^{\alpha_s}. \]

Zatim se zasebno izračunaju ostatci binomnog koeficijenta \(\dbinom{n}{k}\) po modulima \(p_i^{\alpha_i}\), čime se dobiva \(s\) kongruencija:

\[ \begin{cases} \dbinom{n}{k} \equiv r_1 &\pmod{p_1^{\alpha_1}}, \\ \dbinom{n}{k} \equiv r_2 &\pmod{p_2^{\alpha_2}}, \\ \quad\quad\cdots\\ \dbinom{n}{k} \equiv r_s &\pmod{p_s^{\alpha_s}}. \end{cases} \]

Na kraju se kineskim teoremom o ostatcima dobije ostatak po modulu \(m\).

Referentna implementacija

Na kraju dajemo referentnu implementaciju za ogledni zadatak 二项式系数 (Binomni koeficijent).

Referentna implementacija 
#include <iostream>
#include <vector>

// Extended Euclid.
void ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
  } else {
    ex_gcd(b, a % b, y, x);
    y -= a / b * x;
  }
}

// Inverse of a mod m.
int inverse(int a, int m) {
  int x, y;
  ex_gcd(a, m, x, y);
  return (x % m + m) % m;
}

// Coefficient in CRT.
int crt_coeff(int m_i, int m) {
  long long mm = m / m_i;
  mm *= inverse(mm, m_i);
  return mm % m;
}

// Binominal Coefficient Calculator Modulo Prime Power.
class BinomModPrimePower {
  int p, a, pa;
  std::vector<int> f;

  // Obtain multiplicity of p in n!.
  long long nu(long long n) {
    long long count = 0;
    do {
      n /= p;
      count += n;
    } while (n);
    return count;
  }

  // Calculate (n!)_p mod pa.
  long long fact_mod(long long n) {
    bool neg = p != 2 || pa <= 4;
    long long res = 1;
    while (n > 1) {
      if ((n / pa) & neg) res = pa - res;
      res = res * f[n % pa] % pa;
      n /= p;
    }
    return res;
  }

 public:
  BinomModPrimePower(int p, int a, int pa) : p(p), a(a), pa(pa), f(pa) {
    // Pretreatment.
    f[0] = 1;
    for (int i = 1; i < pa; ++i) {
      f[i] = i % p ? (long long)f[i - 1] * i % pa : f[i - 1];
    }
  }

  // Calculate Binom(n, k) mod pa.
  int binomial(long long n, long long k) {
    long long v = nu(n) - nu(n - k) - nu(k);
    if (v >= a) return 0;
    auto res = fact_mod(n - k) * fact_mod(k) % pa;
    res = fact_mod(n) * inverse(res, pa) % pa;
    for (; v; --v) res *= p;
    return res % pa;
  }
};

// Binominal Coefficient Calculator.
class BinomMod {
  int m;
  std::vector<BinomModPrimePower> bp;
  std::vector<long long> crt_m;

 public:
  BinomMod(int n) : m(n) {
    // Factorize.
    for (int p = 2; p * p <= n; ++p) {
      if (n % p == 0) {
        int a = 0, pa = 1;
        for (; n % p == 0; n /= p, ++a, pa *= p);
        bp.emplace_back(p, a, pa);
        crt_m.emplace_back(crt_coeff(pa, m));
      }
    }
    if (n > 1) {
      bp.emplace_back(n, 1, n);
      crt_m.emplace_back(crt_coeff(n, m));
    }
  }

  // Calculate Binom(n, k) mod m.
  int binomial(long long n, long long k) {
    long long res = 0;
    for (size_t i = 0; i != bp.size(); ++i) {
      res = (bp[i].binomial(n, k) * crt_m[i] + res) % m;
    }
    return res;
  }
};

int main() {
  int t, m;
  std::cin >> t >> m;
  BinomMod bm(m);
  for (; t; --t) {
    long long n, k;
    std::cin >> n >> k;
    std::cout << bm.binomial(n, k) << '\n';
  }
  return 0;
}

Ovaj algoritam pri pretprocesiranju rastavlja modul \(m\) na potencije prostih brojeva, a zatim za svaki \(p^\alpha\) pretprocesira umnožak svih prirodnih brojeva od \(1\) do \(p^\alpha\) koji nisu višekratnici broja \(p\), kao i pripadni koeficijent za spajanje rezultata kineskim teoremom o ostatcima. Vremenska složenost pretprocesiranja iznosi \(O(\sqrt{m}+\sum_ip_i^{\alpha_i})\). Složenost svakog upita iznosi \(O(\log m+\sum_i\log_{p_i}n)\), pri čemu su dva člana složenosti redom složenost računanja inverza te složenost računanja eksponenta i ostatka faktorijela.

Prerequisites: Factorial modulo a number

Introduction

This article discusses the computation of large binomial coefficients modulo a number. A binomial coefficient (number of combinations) is the expression:

\[ \binom{n}{k} = \dfrac{n!}{k!(n-k)!}. \]

When the problem size is not large, binomial coefficients can be computed by the recurrence in \(O(nk)\) time; modulo a sufficiently large prime \(p>n\), they can also be computed in \(O(n)\) time by computing the factorials in the numerator and the denominator. But when the problem size is very large (\(n\sim 10^{18}\)), these methods no longer apply.

Based on Lucas's theorem and its generalization, this article discusses a method that can compute binomial coefficients when the modulus is not too large (\(m \sim 10^6\)). More precisely, the method can be used as long as the sum of all prime powers in the unique factorization of the modulus \(m=\prod p_i^{e_i}\) (i.e. \(\sum p_i^{e_i}\)) is on the order of \(10^6\), because the precomputation of the algorithm is roughly of this size.

Lucas's theorem

First we discuss the case where the modulus is a prime \(p\). In this case, we have Lucas's theorem:

Lucas's theorem

For a prime \(p\), we have

\[ \binom{n}{k}\equiv \binom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor}\binom{n\bmod p}{k\bmod p}\pmod p. \]

Here, for \(n<k\) the binomial coefficient \(\dbinom{n}{k}\) is defined to be \(0\).

Proof using generating functions

Consider the value of \(\displaystyle\binom{p}{n} \bmod p\). Since

\[ \binom{p}{n} = \frac{p!}{n!(p-n)!}, \]

for \(n\neq 0,p\) the denominator contains no factor \(p\) while the numerator contains a factor \(p\), so the fraction must be a multiple of \(p\) and its remainder modulo \(p\) is \(0\); for \(n=0,p\) the fraction equals \(1\). Therefore,

\[ \binom{p}{n} \equiv [n=0\lor n=p] \pmod p. \]

Let \(f(x) = ax^n + bx^m\). In general, by the binomial theorem and Fermat's little theorem we have

\[ \begin{aligned} (f(x))^p &= \left(ax^n + bx^m\right)^p \\ &= \sum_{k=0}^p\binom{p}{k}(ax^n)^k(bx^m)^{p-k}\\ &\equiv a^px^{pn} + b^px^{pm} \\ &\equiv a(x^p)^n+b(x^p)^m\\ &= f(x^p) \pmod p. \end{aligned} \]

Here, the congruence in the third line uses the conclusion shown above, namely that the binomial coefficient is not a multiple of \(p\) only for \(k=0,p\).

Using this conclusion, consider the binomial expansion:

\[ \begin{aligned} (1+x)^n &= (1+x)^{p\lfloor n/p\rfloor}(1+x)^{n\bmod p} \\ &\equiv (1+x^p)^{\lfloor n/p\rfloor}(1+x)^{n\bmod p} \pmod p. \end{aligned} \]

On the left-hand side, the coefficient of the term \(x^k\) is

\[ \binom{n}{k}\bmod p. \]

Now we compute the coefficient of the term \(x^k\) on the right-hand side. The degrees of the terms in the first factor are necessarily multiples of \(p\), and the degrees of the terms in the second factor are necessarily less than \(p\); the way to split \(k\) into a sum of two such parts is unique, given by division with remainder: \(k=p\lfloor k/p\rfloor +(k\bmod p)\). Therefore, the first factor can only contribute its term of degree \(p\lfloor k/p\rfloor\), and the second factor can only contribute its term of degree \(k\bmod p\). So the coefficient of \(x^k\) on the right-hand side is the product of the coefficients of the terms contributed by the two factors:

\[ \binom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor}\binom{n\bmod p}{k\bmod p}\bmod p. \]

Equating the coefficients on both sides gives Lucas's theorem.

Proof using the results on factorials modulo a number

Here we give a proof based on the results on factorials modulo a number, in order to establish a connection with the method of the exLucas section below. We know that the binomial coefficient is

\[ \binom{n}{k} = \dfrac{n!}{k!(n-k)!}. \]

Separating the powers of \(p\) in the factorial \(n!\) from the other factors, we obtain the decomposition:

\[ n! = p^{\nu_p(n!)}(n!)_p. \]

This gives the expression for the binomial coefficient:

\[ \binom{n}{k} = p^{\nu_p(n!)-\nu_p(k!)-\nu_p((n-k)!)}\dfrac{(n!)_p}{(k!)_p((n-k)!)_p}. \]

Both the exponent \(\nu_p(n!)\) and the factorial remainder \((n!)_p\bmod p\) satisfy recurrences:

\[ \begin{aligned} \nu_p(n!) &= \lfloor n/p\rfloor+\nu_p( \lfloor n/p\rfloor!),\\ (n!)_p &\equiv (-1)^{\lfloor n/p\rfloor}\cdot (n\bmod p)!\cdot (\lfloor n/p\rfloor!)_p\pmod p. \end{aligned} \]

The former is a corollary of Legendre's formula, the latter a corollary of Wilson's theorem.

Substituting the recurrences into the expression for the binomial coefficient and rearranging, we obtain:

\[ \begin{aligned} \binom{n}{k} &\equiv (-p)^{\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor}\cdot\dfrac{(n\bmod p)!}{(k\bmod p)!((n-k)\bmod p)!} \\ &\quad \cdot p^{\nu_p(\lfloor n/p\rfloor!)-\nu_p(\lfloor k/p\rfloor!)-\nu_p(\lfloor(n-k)/p\rfloor!)}\dfrac{(\lfloor n/p\rfloor!)_p}{(\lfloor k/p\rfloor!)_p(\lfloor(n-k)/p\rfloor!)_p} \pmod p. \end{aligned} \]

Now consider the value of \(\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor\). Since we have

\[ \begin{aligned} n &= \lfloor n/p\rfloor p + (n\bmod p),\\ k &= \lfloor k/p\rfloor p + (k\bmod p),\\ n-k &= \lfloor (n-k)/p\rfloor p + ((n-k)\bmod p),\\ \end{aligned} \]

subtracting the latter two equations from the first gives

\[ (\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor)p = (k\bmod p)+((n-k)\bmod p)-(n\bmod p). \]

On the right-hand side, the sum of the first two terms is strictly less than \(2p\), and the third term \(n\bmod p\) is exactly the remainder of the sum of the first two terms, so the right-hand side must be nonnegative but less than \(2p\); since it must also be a multiple of \(p\), it can only be \(0\) or \(p\). This shows that \(\lfloor n/p\rfloor-\lfloor k/p\rfloor-\lfloor(n-k)/p\rfloor\) can only be \(0\) or \(1\):

  • If it is \(0\), then \((n\bmod p) = (k\bmod p)+((n-k)\bmod p)\) also holds. Therefore, the exponent of the first factor in the expression above is \(0\), so that factor equals one; the second factor is exactly \(\dbinom{n\bmod p}{k\bmod p}\); and the third factor, by the expansion above (note that now \(\lfloor(n-k)/p\rfloor=\lfloor n/p\rfloor-\lfloor k/p\rfloor\)), equals \(\dbinom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor}\). In this case Lucas's theorem holds;

  • If it is \(1\), then the exponent of the first factor is \(1\), so that factor equals zero, and hence the remainder of the binomial coefficient is zero. At the same time, \(\dbinom{n\bmod p}{k\bmod p}\) on the right-hand side of the identity claimed by Lucas's theorem must also be zero, because in this case necessarily \((n\bmod p)<(k\bmod p)\); otherwise we would have

    \[ ((n-k)\bmod p) = p + (n\bmod p) - (k\bmod p) \ge p. \]

    This obviously contradicts the definition of the remainder.

Combining the two cases, we obtain the desired Lucas's theorem. This proof shows that, when computing binomial coefficients modulo a prime, the results obtained using Lucas's theorem and using the exLucas algorithm are equivalent.

Lucas's theorem states that, when the modulus is a prime \(p\), the computation of large binomial coefficients can be reduced to the computation of binomial coefficients of smaller size. On the right-hand side, the first binomial coefficient can be computed recursively until \(k=0\); the second binomial coefficient can be computed directly or precomputed in advance. Written as code:

Sketch 
long long Lucas(long long n, long long k, long long p) {
  if (k == 0) return 1;
  return (C(n % p, k % p, p) * Lucas(n / p, k / p, p)) % p;
}

Here, C(n, k, p) is used to compute small binomial coefficients.

The recursion runs at most \(O(\log_p n)\) times, so the complexity of the algorithm is \(O(f(p)+g(p)\log_p n)\), where \(f(p)\) is the complexity of precomputing the binomial coefficients and \(g(p)\) is the complexity of computing a single binomial coefficient.

Reference implementation

The reference implementation given here precomputes the factorials up to \(p\) and their inverses in \(O(p)\) time, after which it can compute a single binomial coefficient in \(O(1)\) time:

Reference implementation 
#include <iostream>
#include <vector>

class BinomModPrime {
  int p;
  std::vector<int> fa, ifa;

  // Calculate binom(n, k) mod p for n, k < p.
  int calc(int n, int k) {
    if (n < k) return 0;
    long long res = fa[n];
    res = (res * ifa[k]) % p;
    res = (res * ifa[n - k]) % p;
    return res;
  }

 public:
  BinomModPrime(int p) : p(p), fa(p), ifa(p) {
    // Factorials mod p till p.
    fa[0] = 1;
    for (int i = 1; i < p; ++i) {
      fa[i] = (long long)fa[i - 1] * i % p;
    }
    // Inverse of factorials mod p till p.
    ifa[p - 1] = p - 1;  // Wilson's theorem.
    for (int i = p - 1; i; --i) {
      ifa[i - 1] = (long long)ifa[i] * i % p;
    }
  }

  // Calculate binom(n, k) mod p.
  int binomial(long long n, long long k) {
    long long res = 1;
    while (n || k) {
      res = (res * calc(n % p, k % p)) % p;
      n /= p;
      k /= p;
    }
    return res;
  }
};

int main() {
  int t, p;
  std::cin >> t >> p;
  BinomModPrime bm(p);
  for (; t; --t) {
    long long n, k;
    std::cin >> n >> k;
    std::cout << bm.binomial(n, k) << '\n';
  }
  return 0;
}

The time complexity of this implementation is \(O(p+T\log_p n)\), where \(T\) is the number of queries.

The exLucas algorithm

Lucas's theorem requires the modulus \(p\) to be prime; for the case where the modulus is not prime, the exLucas algorithm (extended Lucas's theorem) is needed. Despite its name, this algorithm does not actually use Lucas's theorem. Its key step is computing factorials modulo a prime power. The second proof above pointed out its connection with Lucas's theorem.

The prime power modulus case

First consider the case where the modulus is a prime power \(p^\alpha\). Separating the powers of \(p\) in the factorial \(n!\) from the other factors, we obtain the decomposition:

\[ n! = p^{\nu_p(n!)}(n!)_p. \]

Here, \(\nu_p(n!)\) is the exponent of \(p\) in the prime factorization of \(n!\), and \((n!)_p\) is obviously coprime to \(p\). Therefore, the binomial coefficient can be written as:

\[ \binom{n}{k} = p^{\nu_p(n!)-\nu_p(k!)-\nu_p((n-k)!)}\dfrac{(n!)_p}{(k!)_p((n-k)!)_p}. \]

The quantities \(\nu_p(n!)\) etc. in the formula can be computed by Legendre's formula, and \((n!)_p\) etc. by the recurrence relation. Since the latter are coprime to \(p^\alpha\), the inverse of the product in the denominator can be computed by the extended Euclidean algorithm. This solves the problem.

Note that if the exponent \(\nu_p(n!)-\nu_p(k!)-\nu_p((n-k)!)\ge\alpha\), the remainder must be zero and no further computation is needed.

The general modulus case

For the case where \(m\) is a general composite number, it suffices to first factorize it into primes:

\[ m = p_1^{\alpha_1}p_2^{\alpha_2}\cdots p_s^{\alpha_s}. \]

Then, compute separately the remainders of the binomial coefficient \(\dbinom{n}{k}\) modulo \(p_i^{\alpha_i}\), obtaining \(s\) congruences:

\[ \begin{cases} \dbinom{n}{k} \equiv r_1 &\pmod{p_1^{\alpha_1}}, \\ \dbinom{n}{k} \equiv r_2 &\pmod{p_2^{\alpha_2}}, \\ \quad\quad\cdots\\ \dbinom{n}{k} \equiv r_s &\pmod{p_s^{\alpha_s}}. \end{cases} \]

Finally, use the Chinese remainder theorem to obtain the remainder modulo \(m\).

Reference implementation

Finally, we give a reference implementation for the template problem 二项式系数 (Binomial Coefficient).

Reference implementation 
#include <iostream>
#include <vector>

// Extended Euclid.
void ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
  } else {
    ex_gcd(b, a % b, y, x);
    y -= a / b * x;
  }
}

// Inverse of a mod m.
int inverse(int a, int m) {
  int x, y;
  ex_gcd(a, m, x, y);
  return (x % m + m) % m;
}

// Coefficient in CRT.
int crt_coeff(int m_i, int m) {
  long long mm = m / m_i;
  mm *= inverse(mm, m_i);
  return mm % m;
}

// Binominal Coefficient Calculator Modulo Prime Power.
class BinomModPrimePower {
  int p, a, pa;
  std::vector<int> f;

  // Obtain multiplicity of p in n!.
  long long nu(long long n) {
    long long count = 0;
    do {
      n /= p;
      count += n;
    } while (n);
    return count;
  }

  // Calculate (n!)_p mod pa.
  long long fact_mod(long long n) {
    bool neg = p != 2 || pa <= 4;
    long long res = 1;
    while (n > 1) {
      if ((n / pa) & neg) res = pa - res;
      res = res * f[n % pa] % pa;
      n /= p;
    }
    return res;
  }

 public:
  BinomModPrimePower(int p, int a, int pa) : p(p), a(a), pa(pa), f(pa) {
    // Pretreatment.
    f[0] = 1;
    for (int i = 1; i < pa; ++i) {
      f[i] = i % p ? (long long)f[i - 1] * i % pa : f[i - 1];
    }
  }

  // Calculate Binom(n, k) mod pa.
  int binomial(long long n, long long k) {
    long long v = nu(n) - nu(n - k) - nu(k);
    if (v >= a) return 0;
    auto res = fact_mod(n - k) * fact_mod(k) % pa;
    res = fact_mod(n) * inverse(res, pa) % pa;
    for (; v; --v) res *= p;
    return res % pa;
  }
};

// Binominal Coefficient Calculator.
class BinomMod {
  int m;
  std::vector<BinomModPrimePower> bp;
  std::vector<long long> crt_m;

 public:
  BinomMod(int n) : m(n) {
    // Factorize.
    for (int p = 2; p * p <= n; ++p) {
      if (n % p == 0) {
        int a = 0, pa = 1;
        for (; n % p == 0; n /= p, ++a, pa *= p);
        bp.emplace_back(p, a, pa);
        crt_m.emplace_back(crt_coeff(pa, m));
      }
    }
    if (n > 1) {
      bp.emplace_back(n, 1, n);
      crt_m.emplace_back(crt_coeff(n, m));
    }
  }

  // Calculate Binom(n, k) mod m.
  int binomial(long long n, long long k) {
    long long res = 0;
    for (size_t i = 0; i != bp.size(); ++i) {
      res = (bp[i].binomial(n, k) * crt_m[i] + res) % m;
    }
    return res;
  }
};

int main() {
  int t, m;
  std::cin >> t >> m;
  BinomMod bm(m);
  for (; t; --t) {
    long long n, k;
    std::cin >> n >> k;
    std::cout << bm.binomial(n, k) << '\n';
  }
  return 0;
}

During precomputation, this algorithm factorizes the modulus \(m\) into prime powers, and then for every \(p^\alpha\) precomputes the product of all natural numbers from \(1\) to \(p^\alpha\) that are not multiples of \(p\), as well as the corresponding coefficient for combining the answers with the Chinese remainder theorem. The time complexity of the precomputation is \(O(\sqrt{m}+\sum_ip_i^{\alpha_i})\). The complexity of each query is \(O(\log m+\sum_i\log_{p_i}n)\), where the two terms are the complexity of computing inverses and the complexity of computing the exponents and factorial remainders, respectively.
