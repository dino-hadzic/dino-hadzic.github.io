Predznanje: Diskretni logaritam

U ovom se tekstu razmatraju ostatci višeg reda (higher-order residues) i korijeni jedinice (roots of unity) u modularnoj aritmetici te se predstavljaju algoritmi za vađenje korijena po modulu.

Ostatci višeg reda

Ostatke višeg reda u modularnoj aritmetici možemo shvatiti kao pitanje izvedivosti vađenja korijena višeg reda po modulu. To je poopćenje kvadratnih ostataka.

\(k\)-ti ostatak

Neka je \(k\geq 2\) cijeli broj te neka su cijeli broj \(a\) i pozitivan cijeli broj \(m\) relativno prosti. Ako postoji cijeli broj \(x\) takav da je

\[ x^k\equiv a\pmod m, \]

tada se \(a\) naziva \(k\)-ti ostatak (\(k\)-th residue) modulo \(m\), a \(x\) \(k\)-ti korijen (\(k\)-th root) od \(a\) modulo \(m\); inače se \(a\) naziva \(k\)-ti neostatak (\(k\)-th nonresidue) modulo \(m\).

Drugim riječima, \(k\)-ti korijen od \(a\) modulo \(m\) postoji ako i samo ako je \(a\) \(k\)-ti ostatak modulo \(m\).

Svojstva

Slično kvadratnim ostatcima, možemo razmatrati pitanja određivanja \(k\)-tih ostataka, broja korijena te broja klasa \(k\)-tih ostataka. Kao i kod drugih problema s kongruencijama, pomoću kineskog teorema o ostatcima oni se mogu svesti na slučaj modula koji je potencija prostog broja. Ovisno o tome postoji li primitivni korijen, to se dalje dijeli na slučaj potencije neparnog prostog broja i slučaj modula koji je potencija broja \(2\).

Slučaj potencije neparnog prostog broja razmjerno je jednostavan. Zapravo, za sve slučajeve u kojima postoji primitivni korijen vrijedi sljedeći zaključak:

Teorem

Neka je \(k\geq 2\) cijeli broj te neka su cijeli broj \(a\) i pozitivan cijeli broj \(m\) relativno prosti. Pretpostavimo da primitivni korijen modulo \(m\) postoji i da je \(g\) jedan primitivni korijen modulo \(m\). Označimo \(d=\gcd(k,\varphi(m))\) i \(d'=\dfrac{\varphi(m)}{d}\), gdje je \(\varphi(m)\) Eulerova funkcija. Tada vrijedi:

  1. \(a\) je \(k\)-ti ostatak modulo \(m\) ako i samo ako je

    \[ a^{d'} \equiv 1 \pmod m. \]

  2. Kad je \(a\) \(k\)-ti ostatak modulo \(m\), \(a\) ima, u smislu kongruencije, točno \(d\) međusobno različitih \(k\)-tih korijena modulo \(m\), i oni su oblika

    \[ x \equiv g^{y_0+id'}\pmod m,~0\le y_0 < d',~i=0,1,\cdots,d-1. \]

  3. Broj klasa \(k\)-tih ostataka modulo \(m\) je \(d'\), a sve one zajedno čine skup

    \[ \{g^{di}\bmod m : 0 \le i < d'\}. \]
Dokaz

Budući da je \(a\perp m\), vrijedi \(x\perp m\). Budući da je \(g\) primitivni korijen modulo \(m\), i \(x\) i \(a\) kongruentni su nekoj potenciji od \(g\). Neka je \(x\equiv g^y\pmod m\); jednadžba \(x^k\equiv a\pmod m\) tada je ekvivalentna s

\[ g^{ky} \equiv g^{\operatorname{ind}_g a}\pmod m. \]

Pritom je \(\operatorname{ind}_g a\) diskretni logaritam. Prema svojstvima reda i \(\delta_m(g)=\varphi(m)\), to je ekvivalentno kongruenciji

\[ ky \equiv \operatorname{ind}_g a \pmod{\varphi(m)}. \]

To je linearna kongruencija po \(y\). Primjenom analize strukture rješenja s te stranice zaključujemo da jednadžba ima rješenje ako i samo ako \(d\mid\operatorname{ind}_g a\), a opće je rješenje oblika

\[ y \equiv y_0 + id' \pmod{\varphi(m)},~0\le y_0 < d',~i=0,1,\cdots,d-1. \]

Odatle se dobiva gotovo cijeli sadržaj teorema; jedino što još treba objasniti jest kriterij \(a^{d'} \equiv 1 \pmod m\). Prema svojstvu reda 3 vrijedi

\[ \delta_m(a) = \delta_m(g^{\operatorname{ind}_g a}) = \dfrac{\varphi(m)}{\gcd(\varphi(m),\operatorname{ind}_g a)}. \]

Već znamo da jednadžba ima rješenje ako i samo ako \(d\mid \operatorname{ind}_g a\), odnosno \(\delta_m(a)\mid d'\). Prema svojstvu reda 2, to je ekvivalentno tom kriteriju.

Slučaj modula koji je potencija broja \(2\) nešto je posebniji. Za obradu tog slučaja potreban je jedan rezultat o strukturi reduciranog sustava ostataka modulo \(2^e\): svaki neparan broj \(a\) na jedinstven je način kongruentan nekom cijelom broju oblika \((-1)^s5^r\bmod 2^e\), gdje je \(s\in\{0,1\}\) i \(0\le r < 2^{e-2}\). Pomoću tog rezultata dobiva se sljedeći zaključak:

Teorem

Neka je \(k\ge 2\) cijeli broj, \(a\) neparan broj i \(m=2^e\) pozitivan cijeli broj uz \(e \ge 2\). Tada, kad je \(k\) neparan, vrijedi:

  1. \(a\) je uvijek \(k\)-ti ostatak modulo \(m\).
  2. \(a\) ima točno jedan \(k\)-ti korijen modulo \(m\).
  3. Broj klasa \(k\)-tih ostataka modulo \(m\) je \(2^{e-1}\), i to su upravo sve reducirane klase ostataka.

Kad je \(k\) paran, označimo \(d=\gcd(k,2^{e-2})\) i \(d'=\dfrac{2^{e-2}}{d}\); tada vrijedi:

  1. \(a\) je \(k\)-ti ostatak modulo \(m\) ako i samo ako je \(a\equiv 1\pmod 4\) i \(a^{d'}\equiv 1\pmod m\).

  2. Kad je \(a\) \(k\)-ti ostatak modulo \(m\), \(a\) ima, u smislu kongruencije, točno \(2d\) međusobno različitih \(k\)-tih korijena modulo \(m\), i oni su oblika

    \[ x \equiv \pm 5^{y_0 + id'} \pmod{2^e},~ 0 \le y_0 < d',~i = 0, 1,\cdots,d-1. \]

  3. Broj klasa \(k\)-tih ostataka modulo \(m\) je \(d'\), a sve one zajedno čine skup

    \[ \{5^{di}\bmod m : 0 \le i < d'\}. \]
Dokaz

Budući da je \(a\perp m\), vrijedi \(x\perp m\). Budući da su \(x\) i \(a\) neparni, prema gornjem rezultatu možemo pisati \(a\equiv (-1)^s5^r\pmod{2^e}\) i \(x\equiv(-1)^z5^{y}\pmod{2^e}\). Budući da je prikaz jedinstven, kongruencija \(x^k\equiv a\pmod{2^e}\) ekvivalentna je sustavu linearnih kongruencija

\[ \begin{aligned} kz &\equiv s \pmod{2},\\ ky &\equiv r \pmod{2^{e-2}}. \end{aligned} \]

U kombinaciji s analizom rješenja linearnih kongruencija s te stranice dobiva se struktura rješenja kongruencije \(x^k\equiv a\pmod{2^e}\). Ovisno o parnosti broja \(k\) razlikujemo dva slučaja:

  • Kad je \(k\) neparan, budući da je \(\gcd(k,2)=\gcd(k,2^{e-2})=1\), obje linearne kongruencije imaju rješenje za sve \(s,r\), pa polazna kongruencija uvijek ima rješenje za sve neparne \(a\).

  • Kad je \(k\) paran, prva jednadžba ima rješenje ako i samo ako \(2\mid s\), a druga ima rješenje ako i samo ako \(d=\gcd(k,2^{e-2})\mid r\). Spajanjem toga dvoga dobiva se oblik svih klasa \(k\)-tih ostataka. Izravnim računom vidi se da je prvi uvjet ekvivalentan s \(a\equiv 1\pmod 4\); ponavljanjem analize iz slučaja potencije neparnog prostog broja vidi se da je drugi uvjet ekvivalentan s \(a^{d'}\equiv 1\pmod m\). Spajanjem tih dviju točaka dobiva se kriterij iz teorema. Opća rješenja obiju linearnih kongruencija također su poznata:

    \[ \begin{aligned} z &\equiv0,1\pmod 2, \\ y &\equiv y_0 + id' \pmod{2^{e-2}},~ 0\le y_0 < d',~i=0,1,\cdots,d-1. \end{aligned} \]

    Njihovim spajanjem dobiva se opće rješenje polazne jednadžbe.

Time je problem određivanja \(k\)-tih ostataka za različite module potpuno riješen. Legendreov simbol i zakon kvadratnog reciprociteta iz teorije kvadratnih ostataka također se mogu poopćiti na ostatke višeg reda, ali to nije jednostavno i zahtijeva pojmove poput ciklotomskih polja. U algebarskoj teoriji brojeva zakon kvadratnog reciprociteta u konačnici se poopćuje do Artinova zakona reciprociteta.

Korijeni jedinice

Kao poseban slučaj \(k\)-tih korijena, u ovom odjeljku razmatramo pojam \(k\)-tog (primitivnog) korijena jedinice. Možemo ga shvatiti kao pandan pojma \(k\)-tog korijena jedinice u polju kompleksnih brojeva \(\mathbf C\) unutar reduciranog sustava ostataka \(\mathbf Z_m^*\) modulo \(m\). Kad je modul \(m\) prikladan, zamjena kompleksnog korijena \(\omega_k\) \(k\)-tim primitivnim korijenom jedinice modulo \(m\) može ubrzati računanje.

Slično kao u polju kompleksnih brojeva, imamo sljedeću definiciju:

\(k\)-ti korijen jedinice modulo \(m\)

Za modul \(m\), \(k\)-ti korijen elementa \(1\) naziva se \(k\)-ti korijen jedinice modulo \(m\) (\(k\)-th root of unity modulo \(m\)). Posebno, ako je \(x\) \(k\)-ti korijen jedinice modulo \(m\) i nije korijen jedinice modulo \(m\) ni za koji red \(k' < k\), tada se \(x\) naziva i \(k\)-ti primitivni korijen jedinice modulo \(m\) (\(k\)-th primitive root of unity modulo \(m\)).

Usporedbom s definicijom primitivnog korijena vidi se da je primitivni korijen \(g\) upravo \(\varphi(m)\)-ti primitivni korijen jedinice modulo \(m\), gdje je \(\varphi(m)\) Eulerova funkcija.

Kad \(k\)-ti primitivni korijen jedinice modulo \(m\) postoji, njegova su algebarska svojstva jednaka svojstvima \(k\)-tog primitivnog kompleksnog korijena jedinice \(\omega_k\), pa može zamijeniti \(\omega_k\) u raznim izračunima. Na primjer, primjenom u brzoj Fourierovoj transformaciji dobiva se brza teorijsko-brojevna transformacija nad konačnim poljem1.

Svojstva

U polju kompleksnih brojeva (primitivni) korijeni jedinice postoje za svaki red. U teoriji brojeva, međutim, s (primitivnim) korijenima jedinice nije tako.

Svojstva

Za modul \(m\) neka je \(\lambda(m)\) njegova Carmichaelova funkcija. Tada vrijedi:

  1. Svaki cijeli broj \(a\) relativno prost s \(m\) jest \(\delta_m(a)\)-ti primitivni korijen jedinice modulo \(m\), gdje je \(\delta_m(a)\) red od \(a\) modulo \(m\).
  2. Ako je element \(a\) \(k\)-ti korijen jedinice modulo \(m\) i \(k'\) je bilo koji višekratnik od \(k\), tada je \(a\) i \(k'\)-ti korijen jedinice modulo \(m\).
  3. Ako je element \(a\) \(k\)-ti (primitivni) korijen jedinice modulo \(m\), tada je element \(a^{\ell}\) \(\dfrac{k}{\gcd(k,\ell)}\)-ti (odgovarajuće, primitivni) korijen jedinice modulo \(m\).
  4. Kad \(k'\) prolazi djeliteljima od \(k\), svi \(k'\)-ti primitivni korijeni jedinice modulo \(m\) čine particiju skupa \(k\)-tih korijena jedinice modulo \(m\). Štoviše, za \(\ell\perp k\) preslikavanje \(x\mapsto x^\ell\) daje bijekciju među \(k\)-tim korijenima jedinice koja čuva tu particiju: primitivne korijene jedinice reda \(k'\mid k\) preslikava ponovno u \(k'\)-te primitivne korijene jedinice.
  5. \(k\)-ti primitivni korijen jedinice modulo \(m\) postoji ako i samo ako \(k\mid\lambda(m)\). Posebno, \(\lambda(m)\)-ti primitivni korijen jedinice modulo \(m\) postoji i naziva se \(\lambda\)‑primitivni korijen modulo \(m\).
  6. Element \(a\) je \(k\)-ti primitivni korijen jedinice modulo \(m\) ako i samo ako je \(a^k\equiv 1\pmod{m}\) i za svaki prosti faktor \(p\mid k\) vrijedi \(a^{k/p}\not\equiv 1\pmod{m}\).
Dokaz

Prema definiciji reda, svaki cijeli broj \(a\) relativno prost s \(m\) jest \(\delta_m(a)\)-ti primitivni korijen jedinice modulo \(m\), gdje je \(\delta_m(a)\) red od \(a\) modulo \(m\). Obratno, ako je \(a\) \(k\)-ti korijen jedinice modulo \(m\), tada je \(\gcd(a^k,m)=1\), pa je \(\gcd(a,m)=1\). Dakle, \(a\) je (primitivni) korijen jedinice modulo \(m\) ako i samo ako je \(a\) relativno prost s \(m\). To je svojstvo 1.

Izravnom provjerom definicije vidi se da se, čim \(k\mid k'\), iz \(a^k\equiv 1\pmod m\) može izvesti \(a^{k'}\equiv 1\pmod m\); to je svojstvo 2. Prema svojstvima reda vrijedi

\[ \delta_m(a^\ell) = \dfrac{\delta_m(a)}{\gcd(\delta_m(a),\ell)}. \]

Ako je \(a\) \(k\)-ti primitivni korijen jedinice modulo \(m\), tada je \(\delta_m(a)=k\), pa izravnim uvrštavanjem u gornju formulu dobivamo da je \(a^\ell\) \(\dfrac{k}{\gcd(k,\ell)}\)-ti primitivni korijen jedinice modulo \(m\). Ako je \(a\) samo \(k\)-ti korijen jedinice modulo \(m\), neka je on primitivni korijen jedinice reda \(k'\mid k\); tada je \(a^\ell\) \(\dfrac{k'}{\gcd(k',\ell)}\)-ti primitivni korijen jedinice modulo \(m\). Budući da \(k'\mid k\), vrijedi

\[ \dfrac{k'}{\gcd(k',\ell)} \mid \dfrac{k}{\gcd(k,\ell)}, \]

pa prema svojstvu 2 dobivamo da je \(a^\ell\) \(\dfrac{k}{\gcd(k,\ell)}\)-ti korijen jedinice modulo \(m\). To je svojstvo 3.

Za \(k'\mid k\), prema svojstvu 2, \(k'\)-ti primitivni korijen jedinice modulo \(m\) nužno je \(k\)-ti korijen jedinice modulo \(m\); obratno, svaki \(k\)-ti korijen jedinice \(a\) modulo \(m\) jest \(\delta_m(a)\)-ti primitivni korijen jedinice, pri čemu \(\delta_m(a)\mid k\). Ti su skupovi u parovima disjunktni, pa čine particiju. Nadalje, za \(\ell\perp k\) uvijek je \(\ell\perp k'\), pa je za \(k'\)-ti primitivni korijen jedinice \(a\) modulo \(m\) i \(a^\ell\) uvijek \(k'\)-ti primitivni korijen jedinice modulo \(m\). Uzmemo li \(\ell'=\ell^{-1}\bmod k\), može se provjeriti da su \(x\mapsto x^\ell\) i \(x\mapsto x^{\ell'}\) međusobno inverzna preslikavanja, pa je \(x\mapsto x^\ell\) bijekcija. To je svojstvo 4.

Prema svojstvima Carmichaelove funkcije, \(\lambda(m)\)-ti primitivni korijen jedinice modulo \(m\) uvijek postoji; označimo ga s \(a\), tako da je \(\delta_m(a)=\lambda(m)\). Za \(k\mid\lambda(m)\) neka je \(k'=\dfrac{\lambda(m)}{k}\); uvijek vrijedi

\[ \delta_m(a^{k'}) = \dfrac{\lambda(m)}{\gcd(\lambda(m),k')} = \dfrac{\lambda(m)}{k'} = k. \]

Dakle, \(a^{k'}\) je \(k\)-ti primitivni korijen jedinice. S druge strane, prema definiciji Carmichaelove funkcije, red svakog \(x\perp m\) djelitelj je od \(\lambda(m)\). Time dobivamo svojstvo 5.

Gotovo doslovnim ponavljanjem dokaza kriterija za primitivni korijen dobiva se svojstvo 6. Taj kriterij zapravo provjerava \(\delta_m(a)=k\).

Iz tih se svojstava vidi da \(\lambda\)‑primitivni korijen modulo \(m\) ima sličnu temeljnu ulogu kao primitivni korijen u slučaju kad on postoji. Za razliku od primitivnog korijena, potencijama \(\lambda\)‑primitivnog korijena ne mogu se generirati svi korijeni jedinice modulo \(m\). Unatoč tome, budući da gustoća \(\lambda\)‑primitivnih korijena nije mala2, ako doista treba pronaći \(k\)-ti primitivni korijen jedinice, možemo najprije nasumičnim pretraživanjem pronaći \(\lambda\)‑primitivni korijen, a zatim potenciranjem dobiti \(k\)-ti primitivni korijen jedinice.

Ako je poznat jedan \(k\)-ti korijen od \(a\) modulo \(m\), pomoću svih \(k\)-tih korijena jedinice modulo \(m\) mogu se generirati svi \(k\)-ti korijeni od \(a\) modulo \(m\).

Teorem

Neka je \(x\) jedan \(k\)-ti korijen od \(a\) modulo \(m\). Kad \(r\) prolazi svim \(k\)-tim korijenima jedinice modulo \(m\), \(xr\) prolazi svim \(k\)-tim korijenima od \(a\) modulo \(m\).

Dokaz

Za dva \(k\)-ta korijena \(x,y\) od \(a\) modulo \(m\) neka je \(r=x^{-1}y\bmod m\); tada \(r\) zadovoljava \(r^k\equiv 1\pmod m\), pa je \(k\)-ti korijen jedinice modulo \(m\). Obratno, čim je \(r\) \(k\)-ti korijen jedinice modulo \(m\), vrijedi \((xr)^{k}= x^kr^k\equiv a\pmod m\), odnosno \(xr\) je \(k\)-ti korijen od \(a\) modulo \(m\).

Generiranje svih \(k\)-tih korijena pomoću \(k\)-tih korijena jedinice slično je generiranju općeg rješenja nehomogenog sustava linearnih jednadžbi pomoću rješenja homogenog sustava.

Dosad smo razmatrali opći slučaj. Samo u slučaju kad primitivni korijen postoji struktura korijena jedinice je jednostavnija:

Teorem

Za modul \(m\) pretpostavimo da primitivni korijen modulo \(m\) postoji i da je \(a\) \(k\)-ti primitivni korijen jedinice modulo \(m\). Tada je \(b\) \(k\)-ti korijen jedinice modulo \(m\) ako i samo ako se može prikazati kao potencija od \(a\).

Dokaz

Neka je \(g\) primitivni korijen modulo \(m\); tada se svaki element relativno prost s \(m\) može prikazati kao potencija od \(g\). Tada je \(a\) \(k\)-ti primitivni korijen jedinice modulo \(m\) ako i samo ako je

\[ \delta_m(a) = \delta_m(g^{\operatorname{ind}_ga}) = \dfrac{\varphi(m)}{\gcd(\varphi(m),\operatorname{ind}_ga)} = k. \]

Slično, \(b\) je \(k\)-ti korijen jedinice modulo \(m\) ako i samo ako je

\[ \delta_m(b) = \delta_m(g^{\operatorname{ind}_gb}) = \dfrac{\varphi(m)}{\gcd(\varphi(m),\operatorname{ind}_gb)} = k' \mid k. \]

Stoga vrijedi

\[ \gcd(\varphi(m),\operatorname{ind}_ga) \mid \gcd(\varphi(m),\operatorname{ind}_gb)\mid \operatorname{ind}_gb. \]

Prema analizi linearnih kongruencija, taj je uvjet ekvivalentan tome da jednadžba

\[ (\operatorname{ind}_ga) x \equiv \operatorname{ind}_gb \pmod{\varphi(m)} \]

ima rješenje. Potenciramo li \(g\) tim uvjetom, dobivamo \(a^x\equiv b\pmod{m}\), odnosno \(b\) se može prikazati kao potencija od \(a\).

Taj teorem pokazuje da, kad primitivni korijen postoji, svi \(k\)-ti korijeni jedinice imaju strukturu cikličke grupe, a \(k\)-ti primitivni korijeni jedinice generatori su te cikličke grupe. Kasnije ćemo vidjeti da upravo to iskorištava Tonelli–Shanksov algoritam kako bi ubrzao računanje diskretnog logaritma pri vađenju korijena.

Vađenje korijena u modularnoj aritmetici

Na kraju razmatramo kako izračunati \(k\)-ti korijen. Za slučaj \(k=2\) postoji mnogo učinkovitih algoritama za vađenje kvadratnog korijena po modulu. Za opći \(k\), međutim, nije poznat algoritam polinomnog vremena. U ovom odjeljku predstavljamo dva uobičajena algoritma, koji \(k\)-ti korijen pronalaze u vremenu \(O(m^{1/2})\) odnosno \(O(m^{1/4+\varepsilon})\). Pomoću kineskog teorema o ostatcima problem se uvijek može svesti na slučaj modula koji je potencija prostog broja, pa se u ovom odjeljku uglavnom razmatra rješavanje za takve module.

Naivni algoritam

Prethodna analiza svojstava \(k\)-tih ostataka zapravo već ukazuje na jedan način računanja \(k\)-tog korijena modulo potencija prostog broja. Strogo govoreći, prethodno je riješen slučaj u kojem su radikand \(a\) i modul \(m\) relativno prosti. Postupak algoritma sažeto glasi:

  • Kad je \(m=p^e\) potencija neparnog prostog broja, neka je \(g\) jedan primitivni korijen modulo \(m\). Tada se jednadžba \(x^k\equiv a\pmod m\) može svesti na linearnu kongruenciju

    \[ ky \equiv \operatorname{ind}_g a \pmod{\varphi(m)}. \]

    Pritom se \(\operatorname{ind}_g a\) može izračunati BSGS algoritmom, a sva rješenja linearne kongruencije lako je pronaći. Odatle dobivamo sve \(k\)-te korijene \(x\equiv g^y\pmod m\) od \(a\).

    Osim toga, postoji i sličan alternativni pristup. Ponovno uz \(x\equiv g^y\pmod m\), preoblikovanjem

    \[ x^k \equiv (g^k)^y \equiv a \pmod m \]

    problem se svodi na računanje diskretnog logaritma od \(a\) s bazom \(g^k\). I to se može riješiti BSGS algoritmom, čime se dobiva jedno partikularno rješenje. Opće se rješenje može dobiti iz prethodno navedenog izraza za rješenja, odnosno množenjem partikularnog rješenja redom sa svim \(k\)-tim korijenima jedinice.

    Koji god pristup odabrali, uz poznat primitivni korijen složenost pronalaženja jednog rješenja tim algoritmom iznosi \(O(m^{1/2})\). Budući da se primitivni korijen može pronaći u vremenu \(o(m^{1/2})\), ukupna vremenska složenost i dalje je \(O(m^{1/2})\).

  • Kad je \(m=2^e\) uz \(e\in\mathbf N_+\), možemo najprije odrediti \(s,r\) u \(a\equiv (-1)^s5^r\pmod m\). Od tih dvaju eksponenata, \(s\) se može odrediti u vremenu \(O(1)\):

    \[ s = \begin{cases}0, & a\equiv 1\pmod 4, \\ 1, & a\equiv 3\pmod 4.\end{cases} \]

    A \(r=\operatorname{ind}_5((-1)^sa)\) može se BSGS algoritmom izračunati u vremenu \(O(m^{1/2})\). Zatim treba samo riješiti sustav linearnih kongruencija:

    \[ \begin{aligned} kz &\equiv s \pmod{2},\\ ky &\equiv r \pmod{2^{e-2}}. \end{aligned} \]

    Opće rješenje \((z,y)\) tog sustava linearnih kongruencija lako je pronaći, a \(x=(-1)^z5^y\) je traženi korijen. Složenost pronalaženja jednog rješenja tim algoritmom također je \(O(m^{1/2})\).

Dakako, za slučaj kad rješenja nema, to se zapravo može brzo utvrditi u vremenu \(O(\log m)\) pomoću prethodno opisanog kriterija, pa to nije potrebno provjeravati tijekom samog rješavanja.

#include <algorithm>
#include <cmath>
#include <iostream>
#include <tuple>
#include <unordered_map>
#include <vector>

struct PrimePower {
  int p, e, pe;

  PrimePower(int p, int e, int pe) : p(p), e(e), pe(pe) {}
};

// Factorization.
auto factorize(int n) {
  std::vector<PrimePower> ans;
  for (int x = 2; x * x <= n; ++x) {
    int e = 0, pe = 1;
    for (; n % x == 0; n /= x, ++e, pe *= x);
    if (e) ans.emplace_back(x, e, pe);
  }
  if (n > 1) ans.emplace_back(n, 1, n);
  return ans;
}

// Binary exponentiation.
int pow(int a, int b, int m = 0) {
  int res = 1;
  for (; b; b >>= 1) {
    if (b & 1) res = m ? (long long)res * a % m : res * a;
    a = m ? (long long)a * a % m : a * a;
  }
  return res;
}

// Find a primitive root modulo prime.
int primitive_root(int p) {
  std::vector<int> exp;
  for (auto factor : factorize(p - 1)) {
    exp.push_back((p - 1) / factor.p);
  }
  int ans = 0;
  bool succ = false;
  while (!succ) {
    ++ans;
    succ = true;
    for (int b : exp) {
      if (pow(ans, b, p) == 1) {
        succ = false;
        break;
      }
    }
  }
  return ans;
}

// Discrete logarithm. (BSGS Algorithm)
int log(int g, int a, int m) {
  int b = std::sqrt(m + 0.25l) + 1;
  std::unordered_map<int, int> mp;
  int po0 = a % m, po1 = 1;
  for (int i = 0; i < b; ++i) {
    mp[po0] = i;
    po0 = (long long)po0 * g % m;
  }
  po0 = pow(g, b, m);
  for (int j = 1; j <= b; ++j) {
    po1 = (long long)po1 * po0 % m;
    if (mp.count(po1)) return j * b - mp[po1];
  }
  return -1;
}

// Extended Euclidean Algorithm.
int ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
    return a;
  } else {
    int d = ex_gcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
  }
}

// Solves the linear congruence equation: Ax = B mod N.
// Return the least nonnegative solution and the common difference.
std::pair<int, int> solve_linear(int a, int b, int n) {
  int x, y;
  int d = ex_gcd(a, n, x, y);
  if (b % d) return {-1, -1};
  n /= d;
  x = ((long long)x * (b / d) % n + n) % n;
  return {x, n};
}

// Subroutine: Find a K-th root with a primitive root G known.
int calc(int g, int k, int a, int p) {
  int ind = log(g, a, p);
  if (ind == -1) return -1;
  int y0, d;
  std::tie(y0, d) = solve_linear(k, ind, p - 1);
  if (y0 == -1) return -1;
  return pow(g, y0, p);
}

// Find a K-th root of A modulo prime P.
int kth_roots_mod_p(int k, int a, int p) {
  a %= p;
  if (k == 0) return a == 1 ? 0 : -1;
  if (a == 0) return 0;
  return calc(primitive_root(p), k, a, p);
}

void solve() {
  int k, y, p;
  std::cin >> k >> y >> p;
  std::cout << kth_roots_mod_p(k, y, p) << '\n';
}

int main() {
  int t;
  std::cin >> t;
  for (; t; --t) {
    solve();
  }
}

Poboljšani Tonelli–Shanksov algoritam

Prikladnim poopćenjem Tonelli–Shanksova algoritma za vađenje kvadratnog korijena po modulu može se riješiti vađenje korijena modulo potencija prostog broja. Jedan razmjerno izravan način poopćenja jest Adleman–Manders–Millerov algoritam3, ali njegova složenost još uvijek nije dovoljno dobra4. U ovom odjeljku predstavljamo poboljšani Tonelli–Shanksov algoritam koji su predložili sugarknri, Min_25, 37zigen i drugi. On pronalazi jedan \(k\)-ti korijen u vremenu \(O(m^{1/4+\varepsilon})\).

Ključna je ideja Tonelli–Shanksova algoritma prebaciti računanje diskretnog logaritma u grupu reda \(2^e\) i time smanjiti vremensku složenost. Slično, diskretni logaritam u grupi čiji je red bilo koja potencija prostog broja \(p^e\) također se može razmjerno učinkovito izračunati, ali složenost algoritma iznosi \(\Omega\left(\sqrt{p}\right)\). Adleman–Manders–Millerov algoritam rastavlja računanje \(k\)-tog korijena na više računanja diskretnih logaritama u grupama reda potencije prostog broja, ali je ograničen veličinom najvećeg prostog faktora \(p_\text{max}(k)\) broja \(k\), pa složenost algoritma i dalje iznosi \(\Omega\left(\sqrt{p_\text{max}(k)}\right)\). Algoritam iz ovog odjeljka dodatno poboljšava taj postupak izbjegavajući računanje diskretnih logaritama za veće proste faktore, čime se ukupna složenost svodi na \(O(m^{1/4+\varepsilon})\).

Postupak

Razmatramo računanje \(k\)-tog korijena od \(a\) modulo potencija prostog broja \(m\), tj. rješavanje kongruencije:

\[ x^k \equiv a \pmod m. \]

Posebno, za slučaj \(m=2^e\) treba još osigurati \(a\equiv 1\pmod{4}\), tako da se \(a\) može zapisati kao potencija od \(g=5\). Slično prethodnoj raspravi, računanje \(k\)-tog korijena modulo \(2^e\) uvijek se može svesti na takav slučaj. Pri obradi slučaja modulo \(2^e\) svaki \(\varphi(m)\) spomenut u ovom odjeljku treba zamijeniti s \(\delta_m(5)=2^{e-2}\).

Najprije, problem se može svesti na slučaj u kojem red korijena dijeli \(\varphi(m)\). Neka je \(d=\gcd(k,\varphi(m))\). Tada, prema svojstvima \(k\)-tih ostataka, kad je \(a\) \(k\)-ti ostatak modulo \(m\), \(a\) je uvijek \(\dfrac{\varphi(m)}{d}\)-ti korijen jedinice modulo \(m\). Prema svojstvima korijena jedinice, za svaki \(\ell\perp\dfrac{\varphi(m)}{d}\) preslikavanje \(x\mapsto x^{\ell}\) bijekcija je na skupu \(\dfrac{\varphi(m)}{d}\)-tih korijena jedinice. Stoga možemo uzeti

\[ \ell = \left(\dfrac{k}{d}\right)^{-1}\bmod\dfrac{\varphi(m)}{d}. \]

Potenciranjem obiju strana polazne kongruencije na \(\ell\)-tu potenciju dobivamo

\[ x^d\equiv x^{k\ell} \equiv a^{\ell} =: b \pmod{m}. \]

Krajnja lijeva kongruencija koristi Eulerov teorem i sljedeću relaciju kongruencije: (\(c\in\mathbf Z\))

\[ k\ell = d\left(\frac{k}{d}\ell\right) = d\left(c\dfrac{\varphi(m)}{d}+1\right) \equiv d \pmod{\varphi(m)}. \]

Za transformirani problem razmotrimo rastav broja \(d\) na proste faktore:

\[ d = \prod_{p\in\mathbf P}p^e. \]

Počevši od \(b=a^\ell\), za svaki \(p^e\neq 1\) redom vadimo \(p^e\)-ti korijen, i na kraju dobivamo \(d\)-ti korijen od \(b\), odnosno \(k\)-ti korijen od \(a\).

Konačno, problem se svodi na to kako pronaći rješenje sljedeće jednadžbe:

\[ x^{p^e} \equiv b \pmod m. \]

Bez smanjenja općenitosti neka je \(\varphi(m)=p^sr\) uz \(p\perp r\). Neka je \(q\in\mathbf N_+\) rješenje jednadžbe \(qr\equiv -1\pmod{p^e}\). Tada, budući da je \(b\) \(rp^{s-e}\)-ti korijen jedinice, \(b^{qr}\) nužno je \(p^{s-e}\)-ti korijen jedinice. Neka je nadalje \(\zeta\) \(p^s\)-ti primitivni korijen jedinice modulo \(m\). Tada je \(\zeta^{p^e}\) \(p^{s-e}\)-ti primitivni korijen jedinice, pa postoji \(h\in\mathbf N\) takav da je \(b^{qr}\equiv \zeta^{hp^{e}}\pmod{m}\). Stoga se izravnom provjerom vidi da je

\[ x\equiv b^{(qr+1)/p^e}\zeta^{-h} \pmod{m} \]

\(p^e\)-ti korijen od \(b\) modulo \(m\).

Da bismo izračunali \(x\), treba pronaći jedan \(p\)-ti neostatak \(\eta\) modulo \(m\). Za to je, prema prethodnim svojstvima, dovoljno nasumično birati \(\eta\perp m\) i provjeriti \(\eta^{\varphi(m)/p}\bmod{m}\neq 1\). Gustoća takvih brojeva iznosi

\[ \dfrac{\varphi(m)}{m}\left(1-\dfrac{1}{p}\right) \ge \dfrac{1}{4}. \]

Dakle, očekivano je dovoljno nasumično izabrati najviše \(4\) cijela broja da bismo ga pronašli. Uočimo da je \(\eta^{rp^{s-1}}\not\equiv 1\pmod m\) i \(\eta^{rp^s}\equiv 1\pmod m\), pa ako stavimo \(\zeta=\eta^r\bmod m\) i \(\xi=\eta^{rp^{s-1}}\bmod m\), oni su redom \(p^s\)-ti i \(p\)-ti primitivni korijen jedinice.

Na kraju treba izračunati \(h\in\mathbf N\). Očito možemo uzeti \(h < p^{s-e}\). Razmotrimo zapis broja \(h\) u bazi \(p\):

\[ h = \sum_{j=0}^{s-e-1}h_jp^j = h_0 + h_1p + h_2p^2 +\cdots. \]

Te znamenke računamo jednu po jednu. Kad je prvih \(j\) znamenki izračunato, nužno vrijedi

\[ \left(b^{qr}\zeta^{-p^e(h_0+h_1p+\cdots + h_{j-1}p^{j-1})}\right)^{p^{s-e-j-1}} \equiv \zeta^{h_jp^{s-1}} \equiv \xi^{h_j} \pmod{m}. \]

Stoga se \(h_j\) može dobiti računanjem diskretnog logaritma s obzirom na \(\xi\). Za bolju vremensku složenost treba koristiti BSGS algoritam. Ukupno treba izračunati \((s-e)\) diskretnih logaritama; ako predračunamo \(B\) potencija od \(\xi\), vremenska složenost jednog računanja diskretnog logaritma iznosi \(O(p/B)\), a ukupna vremenska složenost je

\[ O\left(B+(s-e)\dfrac{p}{B}\right). \]

Uz \(B=\sqrt{(s-e)p}\) ukupna je vremenska složenost najmanja i iznosi \(O\left(\sqrt{(s-e)p}\right)\). Nakon što dobijemo \(h\), uvrštavanjem u gornji izraz za \(x\) pronalazimo jedno partikularno rješenje.

Vremenska složenost

Vremenska složenost ovog algoritma iznosi \(O(m^{1/4+\varepsilon})\). Pri razmatranju složenosti u ovom odjeljku uvijek pretpostavljamo da jedno množenje traje \(O(1)\) i da se pri računanju potencija uvijek primjenjuje Eulerov teorem za smanjenje eksponenta, pa se svaka pojedina potencija može izračunati u vremenu \(O(\log m)\).

Razmotrimo najprije računanje jednog \(p^e\)-tog korijena. Za pronalaženje \(p\)-tog neostatka treba provjeriti očekivano \(O(1)\) brojeva, pa je ukupna vremenska složenost \(O(\log m)\). Računanje svakog od \(s,r,\zeta,\eta,b^{qr}\) traje \(O(\log m)\). Pri računanju \(h\) za svaku znamenku treba \(O(\log m)\) vremena za računanje potencija, a znamenki je ukupno \((s-e)\), pa je ukupna vremenska složenost \(O((s-e)\log m)\). Već je objašnjeno da predobrada i \((s-e)\) upita u dijelu s računanjem diskretnih logaritama ukupno traju \(O\left(\sqrt{(s-e)p}\right)\). Budući da je \(s-e\in O(\log m)\), vremenska složenost računanja jednog \(p^e\)-tog korijena iznosi \(O(p^{1/2+\varepsilon})\). Posebno, kad je \(s=e\), vremenska se složenost dodatno smanjuje na \(O(\log m)\).

Sada možemo razmotriti ukupnu vremensku složenost algoritma. Vremenska složenost računanja \(\varphi(m),d,\ell\) iznosi \(O(\log m)\) za svaki. Zatim treba napraviti rastav na proste faktore \(d=\prod_p{p^e}\); taj se korak pomoću Pollardova rho algoritma može obaviti u vremenu \(O(m^{1/4})\). Konačno, ukupna vremenska složenost uzastopnog računanja \(p^e\)-tih korijena iznosi

\[ O\left(\sum_{e < s}p^{1/2+\varepsilon}\right). \]

Budući da se prosti faktor \(p\) koji zadovoljava \(e < s\) u \(\varphi(m)\) pojavljuje barem \(2\) puta, nužno je \(p < m^{1/2}\). Stoga je ukupna vremenska složenost \(O(m^{1/4+\varepsilon})\).

Zapravo, u ovoj situaciji nije nužno koristiti Pollardov rho algoritam za rastav na proste faktore, a vremenska složenost \(O(m^{1/4+\varepsilon})\) i dalje se može postići. Konkretno, dovoljno je \(d\) rastaviti grubom silom pokusnim dijeljenjem i pritom ispitivati samo proste faktore koji ne premašuju \(m^{1/4}\). Neka je \(z\) cijeli broj koji ostaje nakon uklanjanja tih malih prostih faktora. Tada za prosti faktor \(p > m^{1/4}\) broja \(z\) nužno vrijedi \(\nu_p(\varphi(m)) < 4\), gdje \(\nu_p(n)\) označava eksponent od \(p\) u rastavu broja \(n\) na proste faktore. Budući da treba razmatrati samo slučaj

\[ 1 \le e = \nu_p(d) < s = \nu_p(\varphi(m)) < 4 \]

prostih faktora \(p\) koji zadovoljavaju taj uvjet može biti najviše jedan; inače bi njihovi eksponenti u \(\varphi(m)\) svi bili barem \(2\), pa bi ukupni umnožak nužno premašio \(m\). Da bismo izdvojili taj (moguće postojeći) jedinstveni veliki prosti faktor, dovoljno je izračunati

\[ p^\star=\gcd\left(z,\dfrac{\varphi(m)}{z}\right) = \prod_{p\mid z,~\nu_p(d) < \nu_p(\varphi(m))}p^{\min\{\nu_p(d),\nu_p(\varphi(m))-\nu_p(d)\}}. \]

Ispitivanjem svih mogućnosti za \(\nu_p(d),\nu_p(\varphi(m))\) vidi se da je eksponent od \(p\) u tom umnošku nužno \(1\), pa je tako izračunata vrijednost upravo jedinstveni veliki prosti faktor \(p^\star\) (ako postoji). Što se tiče preostalog dijela \(z/p^\star\), budući da on može sadržavati samo proste faktore koji zadovoljavaju \(e=s\), nije ga potrebno dalje rastavljati.

Referentna implementacija za ogledni zadatak Library Checker - Kth Root (Mod) 
#include <algorithm>
#include <cmath>
#include <iostream>
#include <random>
#include <tuple>
#include <unordered_map>
#include <vector>

std::mt19937 rng(std::random_device{}());

// Binary exponentiation.
int pow(int a, int b, int m = 0) {
  int res = 1;
  for (; b; b >>= 1) {
    if (b & 1) res = m ? (long long)res * a % m : res * a;
    a = m ? (long long)a * a % m : a * a;
  }
  return res;
}

// Find a P-th non-residue mod M.
int non_residue(int p, int m, int phi) {
  std::uniform_int_distribution<int> dis(1, m - 1);
  while (true) {
    int c = dis(rng);
    if (pow(c, phi / p, m) != 1) return c;
  }
  return -1;
}

// Euclidean Algorithm.
int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }

// Extended Euclidean Algorithm.
int ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
    return a;
  } else {
    int d = ex_gcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
  }
}

// Returns the modular inverse of A modulo M.
// Assumes that gcd(A, M) = 1, so the inverse exists.
int inv(int a, int m) {
  int x, y;
  ex_gcd(a, m, x, y);
  return (x % m + m) % m;
}

// Subroutine: Find a P^E-th root of A mod M.
int peth_root_mod_m(int p, int e, int a, int m, int phi) {
  int s = 0, r = phi, pe = pow(p, e);
  for (; r % p == 0; r /= p, ++s);
  int q = pe - inv(r, pe);
  int ans = pow(a, ((long long)q * r + 1) / pe % phi, m);
  int eta = non_residue(p, m, phi);
  std::unordered_map<int, int> mp;
  int zeta = pow(eta, r, m);
  int xi = pow(eta, phi / p, m);
  // Precompute powers for BSGS.
  int B = std::sqrt((s - e) * p + 0.25l) + 1;
  int pB = p / B + 1;
  int po0 = pow(xi, pB, m);
  for (int j = 1, po1 = 1; j <= B; ++j) {
    po1 = (long long)po1 * po0 % m;
    mp[po1] = j;
  }
  // Compute p-adic digits of h.
  for (int j = 0; j < s - e; ++j) {
    int err = (long long)pow(ans, pe, m) * inv(a, m) % m;
    int xi_hj = pow(err, pow(p, s - e - j - 1), m);
    long long hj = 0;
    // BSGS query.
    for (int i = 1; i <= pB; ++i) {
      xi_hj = (long long)xi_hj * xi % m;
      if (mp.count(xi_hj)) {
        hj = mp[xi_hj] * pB - i;
        break;
      }
    }
    ans = (long long)ans * pow(zeta, phi - hj * pow(p, j) % phi, m) % m;
  }
  return ans;
}

// Find a K-th root of A modulo prime P.
int kth_root_mod_p(int k, int a, int p) {
  a %= p;
  if (k == 0) return a == 1 ? 0 : -1;
  if (a == 0) return 0;
  int d = gcd(k, p - 1);
  if (pow(a, (p - 1) / d, p) != 1) return -1;
  a = pow(a, inv(k / d, (p - 1) / d), p);
  for (int dp = 2; dp * dp <= d && dp * dp * dp * dp < p; ++dp) {
    if (d % dp == 0) {
      int de = 0;
      for (; d % dp == 0; d /= dp, ++de);
      a = peth_root_mod_m(dp, de, a, p, p - 1);
    }
  }
  if (d != 1) {
    int dp = gcd(d, (p - 1) / d), de = 0;
    if (dp != 1) {
      for (; d % dp == 0; d /= dp, ++de);
      a = peth_root_mod_m(dp, de, a, p, p - 1);
    }
    if (d != 1) a = peth_root_mod_m(d, 1, a, p, p - 1);
  }
  return a;
}

void solve() {
  int k, y, p;
  std::cin >> k >> y >> p;
  std::cout << kth_root_mod_p(k, y, p) << '\n';
}

int main() {
  int t;
  std::cin >> t;
  for (; t; --t) {
    solve();
  }
}

Obrada općeg slučaja

Razmotrimo opći slučaj: modul \(m\) i dalje je potencija prostog broja \(p^e\), ali je \(\gcd(a,m)>1\). Ako je \(a\equiv 0\pmod{m}\), tada su

\[ x \equiv p^{\lceil e/k \rceil}\ell\pmod{p^e},~\ell=0,1,\cdots,p^{e-\lceil e/k\rceil}-1 \]

sva rješenja polazne jednadžbe. Razmotrimo sada slučaj \(a\not\equiv 0\pmod{m}\). Neka je \(a = p^sa'\) uz \(p\perp a'\). Stavimo li \(x=p^zx'\) uz \(p\perp x'\), imamo

\[ x^k = p^{kz}(x')^k\equiv p^sa'\pmod{p^e}. \]

Budući da je \((x')^k\perp p\), ta jednakost vrijedi ako i samo ako je \(kz = s\) i \((x')^k\equiv a'\pmod{p^{e-s}}\). Prva jednadžba ima rješenje \(z=\dfrac{s}{k}\) ako i samo ako \(k\mid s\); a rješavanje druge jednadžbe već je riješeno. Treba pripaziti da se modul općeg rješenja druge jednadžbe razlikuje od modula općeg rješenja polazne jednadžbe, pa svakom rješenju \(x'\) druge jednadžbe odgovara više rješenja polazne jednadžbe:

\[ x \equiv p^{s/k}(x' + \ell p^{e-s})\pmod{p^e},~\ell = 0,1,\cdots, p^{s-s/k}-1. \]

// Factorization.
auto factorize(int n) {

  for (int x = 2; x * x <= n; ++x) {
    int e = 0, pe = 1;
    for (; n % x == 0; n /= x, ++e, pe *= x);
    if (e) ans.emplace_back(x, e, pe);

  if (n > 1) ans.emplace_back(n, 1, n);

// Binary exponentiation.
int pow(int a, int b, int m = 0) {
  int res = 1;
  for (; b; b >>= 1) {
    if (b & 1) res = m ? (long long)res * a % m : res * a;
    a = m ? (long long)a * a % m : a * a;
  }
  return res;
}

// Find a primitive root modulo odd prime power.
int primitive_root(PrimePower pp) {
  std::vector<int> exp;
  int phi = pp.pe / pp.p * (pp.p - 1);
  for (auto factor : factorize(pp.p - 1)) {
    exp.push_back(phi / factor.p);
  }
  if (pp.e != 1) exp.push_back(phi / pp.p);
  int ans = 0;
  bool succ = false;
  while (!succ) {
    ++ans;
    succ = true;
    for (int b : exp) {
      if (pow(ans, b, pp.pe) == 1) {
        succ = false;
        break;
      }
    }
  }

// Discrete logarithm. (BSGS Algorithm)
int log(int g, int a, int m) {
  int b = std::sqrt(m + 0.25l) + 1;
  std::unordered_map<int, int> mp;
  int po0 = a % m, po1 = 1;
  for (int i = 0; i < b; ++i) {
    mp[po0] = i;
    po0 = (long long)po0 * g % m;
  }
  po0 = pow(g, b, m);
  for (int j = 1; j <= b; ++j) {
    po1 = (long long)po1 * po0 % m;
    if (mp.count(po1)) return j * b - mp[po1];
  }
  return -1;
}

// Extended Euclidean Algorithm.
int ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
    return a;
  } else {
    int d = ex_gcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
  }
}

// Returns the modular inverse of A modulo M.
// Assumes that gcd(A, M) = 1, so the inverse exists.
int inv(int a, int m) {
  int x, y;
  ex_gcd(a, m, x, y);
  return (x % m + m) % m;
}

// Solves the linear congruence equation: Ax = B mod N.
// Return the least nonnegative solution and the common difference.
std::pair<int, int> solve_linear(int a, int b, int n) {
  int x, y;
  int d = ex_gcd(a, n, x, y);
  if (b % d) return {-1, -1};
  n /= d;
  x = ((long long)x * (b / d) % n + n) % n;
  return {x, n};
}

// Subroutine: Find all the K-th roots with a primitive root G known.
std::vector<int> calc(int g, int k, int a, int p, int pe) {
  int ind = log(g, a, pe);
  if (ind == -1) return {};
  int mm = p == 2 ? pe / 4 : pe / p * (p - 1);
  int y0, d;
  std::tie(y0, d) = solve_linear(k, ind, mm);
  if (y0 == -1) return {};
  int ans = pow(g, y0, pe), po = pow(g, d, pe);
  std::vector<int> res(mm / d);
  for (auto& x : res) {
    x = ans;
    ans = (long long)ans * po % pe;
  }
  return res;
}

// Find all the K-th roots of A modulo prime power P^E.
std::vector<int> kth_roots_mod_pe(int k, int a, PrimePower pp) {
  int p = pp.p, e = pp.e, pe = pp.pe;
  a %= pe;
  if (a == 0) {
    int d = pow(p, (e - 1) / k + 1);
    std::vector<int> res(pe / d);
    for (int i = 0; i < pe / d; ++i) {
      res[i] = i * d;
    }
    return res;
  }
  int s = 0;
  for (; a % p == 0; a /= p, ++s);
  if (s % k) return {};
  int psk = pow(p, s / k), pss = pow(p, s - s / k), pes = pow(p, e - s);
  std::vector<int> res;
  if (p != 2) {
    int g = primitive_root(PrimePower(p, e - s, pes));
    res = calc(g, k, a, p, pes);
  } else if (pes == 2) {
    res.push_back(a);
  } else if (k & 1) {
    int z = a % 4 == 3;
    a = z ? pes - a : a;
    res = calc(5, k, a, p, pes);
    if (z) {
      for (auto& x : res) x = pes - x;
    }
  } else {
    if (a % 4 == 3) return {};
    res = calc(5, k, a, p, pes);
    int m = res.size();
    res.reserve(m * 2);
    for (int i = 0; i < m; ++i) {
      res.push_back(pes - res[i]);
    }
  }
  int m = res.size();
  res.reserve(m * pss);
  for (int j = 1; j < pss; ++j) {
    for (int i = 0; i < m; ++i) {
      res.push_back(res.end()[-m] + pes);
    }
  }
  for (auto& x : res) x *= psk;
  return res;
}

std::vector<int> kth_roots_mod_m(int k, int a, int m) {
  auto factors = factorize(m);
  int m0 = 0;
  std::vector<std::vector<int>> sols;
  for (const auto& pp : factors) {
    sols.push_back(kth_roots_mod_pe(k, a, pp));
    if (sols.back().empty()) return {};
  }
  std::vector<int> ans;
  for (int i = 0; i < (int)factors.size(); ++i) {
    auto pp = factors[i];
    if (!i) {
      m0 = pp.pe;
      ans = sols[i];
    } else {
      long long m1 = pp.pe * inv(pp.pe, m0);
      long long m2 = m0 * inv(m0, pp.pe);
      m0 *= pp.pe;
      std::vector<int> _ans;
      _ans.reserve(ans.size() * sols[i].size());
      for (auto x : ans) {
        for (auto y : sols[i]) {
          _ans.push_back((m1 * x + m2 * y) % m0);
        }
      }
      ans.swap(_ans);
    }
  }
  return ans;
}

// Find a P-th non-residue mod M.
int non_residue(int p, int m, int phi) {
  std::uniform_int_distribution<int> dis(1, m - 1);
  while (true) {
    int c = dis(rng);
    if (gcd(c, m) == 1 && pow(c, phi / p, m) != 1) return c;
  }
  return -1;
}

// Subroutine: Find a P^E-th root of A mod M.
int peth_root_mod_m(int p, int e, int a, int m, int phi) {
  if (m == 2) return 1;
  int s = 0, r = phi, pe = pow(p, e);
  for (; r % p == 0; r /= p, ++s);
  int q = pe - inv(r, pe);
  int ans = pow(a, ((long long)q * r + 1) / pe % phi, m);
  int eta = non_residue(p, m, phi);
  std::unordered_map<int, int> mp;
  int zeta = pow(eta, r, m);
  int xi = pow(eta, phi / p, m);
  // Precompute powers for BSGS.
  int B = std::sqrt((s - e) * p + 0.25l) + 1;
  int pB = pe / B + 1;
  int po0 = pow(xi, pB, m);
  for (int j = 1, po1 = 1; j <= B; ++j) {
    po1 = (long long)po1 * po0 % m;
    mp[po1] = j;
  }
  // Compute p-adic digits of h.
  for (int j = 0; j < s - e; ++j) {
    int err = (long long)pow(ans, pe, m) * inv(a, m) % m;
    int xi_hj = pow(err, pow(p, s - e - j - 1), m);
    long long hj = 0;
    // BSGS query.
    for (int i = 1; i <= pB; ++i) {
      xi_hj = (long long)xi_hj * xi % m;
      if (mp.count(xi_hj)) {
        hj = mp[xi_hj] * pB - i;
        break;
      }
    }
    ans = (long long)ans * pow(zeta, phi - hj * pow(p, j) % phi, m) % m;
  }
  return ans;
}

// Find a K-th root of A modulo prime P^E.
int kth_root_mod_pe(int k, int a, int pe, int phi) {
  a %= pe;
  if (k == 0) return a == 1 ? 0 : -1;
  if (a == 0) return 0;
  int d = gcd(k, phi);
  if (pow(a, phi / d, pe) != 1) return -1;
  a = pow(a, inv(k / d, phi / d), pe);
  for (int dp = 2; dp * dp <= d && dp * dp * dp * dp < pe; ++dp) {
    if (d % dp == 0) {
      int de = 0;
      for (; d % dp == 0; d /= dp, ++de);
      a = peth_root_mod_m(dp, de, a, pe, phi);
    }
  }
  if (d != 1) {
    int dp = gcd(d, phi / d), de = 0;
    if (dp != 1) {
      for (; d % dp == 0; d /= dp, ++de);
      a = peth_root_mod_m(dp, de, a, pe, phi);
    }
    if (d != 1) a = peth_root_mod_m(d, 1, a, pe, phi);
  }
  return a;
}

// Subroutine: Find all the K-th roots with a primitive root G known.

Prerequisites: Discrete logarithm

This article discusses higher-order residues and roots of unity in modular arithmetic, and introduces algorithms for root extraction modulo an integer.

Higher-order residues

Higher-order residues in modular arithmetic can be thought of as the question of whether higher-order roots can be taken modulo an integer. They are a generalization of quadratic residues.

\(k\)-th residue

Let \(k\geq 2\) be an integer, and let the integer \(a\) and the positive integer \(m\) be coprime. If there exists an integer \(x\) such that

\[ x^k\equiv a\pmod m, \]

then \(a\) is called a \(k\)-th residue modulo \(m\), and \(x\) is called a \(k\)-th root of \(a\) modulo \(m\); otherwise \(a\) is called a \(k\)-th nonresidue modulo \(m\).

In other words, a \(k\)-th root of \(a\) modulo \(m\) exists if and only if \(a\) is a \(k\)-th residue modulo \(m\).

Properties

Similarly to quadratic residues, we can discuss the questions of deciding \(k\)-th residues, the number of roots, and the number of classes of \(k\)-th residues. As with other problems about congruence equations, they can be reduced to the case of a prime-power modulus via the Chinese remainder theorem. Depending on whether a primitive root exists, this is further divided into the case of an odd prime power and the case where the modulus is a power of \(2\).

The case of an odd prime power is relatively simple. In fact, for all cases where a primitive root exists, the following conclusion holds:

Theorem

Let \(k\geq 2\) be an integer, and let the integer \(a\) and the positive integer \(m\) be coprime. Suppose a primitive root modulo \(m\) exists, and let \(g\) be a primitive root modulo \(m\). Denote \(d=\gcd(k,\varphi(m))\) and \(d'=\dfrac{\varphi(m)}{d}\), where \(\varphi(m)\) is Euler's totient function. Then:

  1. \(a\) is a \(k\)-th residue modulo \(m\) if and only if

    \[ a^{d'} \equiv 1 \pmod m. \]

  2. When \(a\) is a \(k\)-th residue modulo \(m\), \(a\) has, up to congruence, exactly \(d\) pairwise distinct \(k\)-th roots modulo \(m\), and they have the form

    \[ x \equiv g^{y_0+id'}\pmod m,~0\le y_0 < d',~i=0,1,\cdots,d-1. \]

  3. The number of classes of \(k\)-th residues modulo \(m\) is \(d'\), and all of them together form the set

    \[ \{g^{di}\bmod m : 0 \le i < d'\}. \]
Proof

Since \(a\perp m\), we have \(x\perp m\). Since \(g\) is a primitive root modulo \(m\), both \(x\) and \(a\) are congruent to some power of \(g\). Let \(x\equiv g^y\pmod m\); the equation \(x^k\equiv a\pmod m\) is then equivalent to

\[ g^{ky} \equiv g^{\operatorname{ind}_g a}\pmod m. \]

Here, \(\operatorname{ind}_g a\) is the discrete logarithm. By the properties of the order and \(\delta_m(g)=\varphi(m)\), this is equivalent to the congruence

\[ ky \equiv \operatorname{ind}_g a \pmod{\varphi(m)}. \]

This is a linear congruence in \(y\). Applying the analysis of the structure of its solutions from that page, we know that the equation has a solution if and only if \(d\mid\operatorname{ind}_g a\), and the general solution has the form

\[ y \equiv y_0 + id' \pmod{\varphi(m)},~0\le y_0 < d',~i=0,1,\cdots,d-1. \]

From this, almost the entire content of the theorem follows; the only thing that still needs explanation is the criterion \(a^{d'} \equiv 1 \pmod m\). By property 3 of the order, we have

\[ \delta_m(a) = \delta_m(g^{\operatorname{ind}_g a}) = \dfrac{\varphi(m)}{\gcd(\varphi(m),\operatorname{ind}_g a)}. \]

We already know that the equation has a solution if and only if \(d\mid \operatorname{ind}_g a\), that is, \(\delta_m(a)\mid d'\). By property 2 of the order, this is equivalent to that criterion.

The case where the modulus is a power of \(2\) is somewhat special. To handle this case, we need a result about the structure of the reduced residue system modulo \(2^e\): every odd number \(a\) is uniquely congruent to an integer of the form \((-1)^s5^r\bmod 2^e\), where \(s\in\{0,1\}\) and \(0\le r < 2^{e-2}\). With this result, we obtain the following conclusion:

Theorem

Let \(k\ge 2\) be an integer, \(a\) an odd number, and \(m=2^e\) a positive integer with \(e \ge 2\). Then, when \(k\) is odd:

  1. \(a\) is always a \(k\)-th residue modulo \(m\).
  2. \(a\) has exactly one \(k\)-th root modulo \(m\).
  3. The number of classes of \(k\)-th residues modulo \(m\) is \(2^{e-1}\), and they are exactly all the reduced residue classes.

When \(k\) is even, denote \(d=\gcd(k,2^{e-2})\) and \(d'=\dfrac{2^{e-2}}{d}\); then:

  1. \(a\) is a \(k\)-th residue modulo \(m\) if and only if \(a\equiv 1\pmod 4\) and \(a^{d'}\equiv 1\pmod m\).

  2. When \(a\) is a \(k\)-th residue modulo \(m\), \(a\) has, up to congruence, exactly \(2d\) pairwise distinct \(k\)-th roots modulo \(m\), and they have the form

    \[ x \equiv \pm 5^{y_0 + id'} \pmod{2^e},~ 0 \le y_0 < d',~i = 0, 1,\cdots,d-1. \]

  3. The number of classes of \(k\)-th residues modulo \(m\) is \(d'\), and all of them together form the set

    \[ \{5^{di}\bmod m : 0 \le i < d'\}. \]
Proof

Since \(a\perp m\), we have \(x\perp m\). Since \(x\) and \(a\) are both odd, by the result above we can write \(a\equiv (-1)^s5^r\pmod{2^e}\) and \(x\equiv(-1)^z5^{y}\pmod{2^e}\). Since the representation is unique, the congruence \(x^k\equiv a\pmod{2^e}\) is equivalent to the system of linear congruences

\[ \begin{aligned} kz &\equiv s \pmod{2},\\ ky &\equiv r \pmod{2^{e-2}}. \end{aligned} \]

Combined with the analysis of the solutions of linear congruences on that page, we obtain the structure of the solutions of the congruence \(x^k\equiv a\pmod{2^e}\). Depending on the parity of \(k\), there are two cases:

  • When \(k\) is odd, since \(\gcd(k,2)=\gcd(k,2^{e-2})=1\), both linear congruences have solutions for all \(s,r\), so the original congruence always has a solution for every odd \(a\).

  • When \(k\) is even, the first equation has a solution if and only if \(2\mid s\), and the second has a solution if and only if \(d=\gcd(k,2^{e-2})\mid r\). Combining the two gives the form of all classes of \(k\)-th residues. By direct computation, the first condition is equivalent to \(a\equiv 1\pmod 4\); repeating the analysis of the odd prime power case, the second condition is equivalent to \(a^{d'}\equiv 1\pmod m\). Combining these two points gives the criterion in the theorem. The general solutions of the two linear congruences are also known:

    \[ \begin{aligned} z &\equiv0,1\pmod 2, \\ y &\equiv y_0 + id' \pmod{2^{e-2}},~ 0\le y_0 < d',~i=0,1,\cdots,d-1. \end{aligned} \]

    Combining them gives the general solution of the original equation.

This completely settles the problem of deciding \(k\)-th residues for different moduli. The Legendre symbol and the law of quadratic reciprocity from the theory of quadratic residues can also be generalized to higher-order residues, but this is not easy and requires concepts such as cyclotomic fields. In algebraic number theory, the law of quadratic reciprocity is ultimately generalized to the Artin reciprocity law.

Roots of unity

As a special case of \(k\)-th roots, this section discusses the concept of \(k\)-th (primitive) roots of unity. It can be seen as the counterpart, in the reduced residue system \(\mathbf Z_m^*\) modulo \(m\), of the concept of \(k\)-th roots of unity in the field of complex numbers \(\mathbf C\). When the modulus \(m\) is suitable, replacing the complex root \(\omega_k\) by a \(k\)-th primitive root of unity modulo \(m\) can speed up computations.

Similarly to the case of the complex numbers, we have the following definition:

\(k\)-th root of unity modulo \(m\)

For a modulus \(m\), a \(k\)-th root of the element \(1\) is called a \(k\)-th root of unity modulo \(m\). In particular, if \(x\) is a \(k\)-th root of unity modulo \(m\) and it is not a root of unity modulo \(m\) of any order \(k' < k\), then \(x\) is also called a \(k\)-th primitive root of unity modulo \(m\).

Comparing with the definition of a primitive root, a primitive root \(g\) is exactly a \(\varphi(m)\)-th primitive root of unity modulo \(m\), where \(\varphi(m)\) is Euler's totient function.

When a \(k\)-th primitive root of unity modulo \(m\) exists, its algebraic properties coincide with those of the \(k\)-th primitive complex root of unity \(\omega_k\), and it can replace \(\omega_k\) in various computations. For example, applying it to the fast Fourier transform yields the number-theoretic transform over a finite field1.

Properties

In the field of complex numbers, (primitive) roots of unity of every order exist. However, this is not the case for (primitive) roots of unity in number theory.

Properties

For a modulus \(m\), let \(\lambda(m)\) be its Carmichael function. Then:

  1. Every integer \(a\) coprime to \(m\) is a \(\delta_m(a)\)-th primitive root of unity modulo \(m\), where \(\delta_m(a)\) is the order of \(a\) modulo \(m\).
  2. If the element \(a\) is a \(k\)-th root of unity modulo \(m\) and \(k'\) is any multiple of \(k\), then \(a\) is also a \(k'\)-th root of unity modulo \(m\).
  3. If the element \(a\) is a \(k\)-th (primitive) root of unity modulo \(m\), then the element \(a^{\ell}\) is a \(\dfrac{k}{\gcd(k,\ell)}\)-th (correspondingly, primitive) root of unity modulo \(m\).
  4. As \(k'\) ranges over the divisors of \(k\), all \(k'\)-th primitive roots of unity modulo \(m\) form exactly a partition of the \(k\)-th roots of unity modulo \(m\). Moreover, for \(\ell\perp k\), the map \(x\mapsto x^\ell\) gives a bijection among the \(k\)-th roots of unity that preserves this partition: it maps primitive roots of unity of order \(k'\mid k\) again to \(k'\)-th primitive roots of unity.
  5. A \(k\)-th primitive root of unity modulo \(m\) exists if and only if \(k\mid\lambda(m)\). In particular, a \(\lambda(m)\)-th primitive root of unity modulo \(m\) exists, and it is called a \(\lambda\)‑primitive root modulo \(m\).
  6. The element \(a\) is a \(k\)-th primitive root of unity modulo \(m\) if and only if \(a^k\equiv 1\pmod{m}\) and for every prime factor \(p\mid k\) we have \(a^{k/p}\not\equiv 1\pmod{m}\).
Proof

By the definition of the order, every integer \(a\) coprime to \(m\) is a \(\delta_m(a)\)-th primitive root of unity modulo \(m\), where \(\delta_m(a)\) is the order of \(a\) modulo \(m\). Conversely, if \(a\) is a \(k\)-th root of unity modulo \(m\), then \(\gcd(a^k,m)=1\), so \(\gcd(a,m)=1\). Therefore, \(a\) is a (primitive) root of unity modulo \(m\) if and only if \(a\) is coprime to \(m\). This is property 1.

Checking the definition directly, as long as \(k\mid k'\), we can deduce \(a^{k'}\equiv 1\pmod m\) from \(a^k\equiv 1\pmod m\); this is property 2. By the properties of the order, we have

\[ \delta_m(a^\ell) = \dfrac{\delta_m(a)}{\gcd(\delta_m(a),\ell)}. \]

If \(a\) is a \(k\)-th primitive root of unity modulo \(m\), then \(\delta_m(a)=k\), and substituting directly into the formula above gives that \(a^\ell\) is a \(\dfrac{k}{\gcd(k,\ell)}\)-th primitive root of unity modulo \(m\). If \(a\) is only a \(k\)-th root of unity modulo \(m\), suppose it is a primitive root of unity of order \(k'\mid k\); then \(a^\ell\) is a \(\dfrac{k'}{\gcd(k',\ell)}\)-th primitive root of unity modulo \(m\). Since \(k'\mid k\), we have

\[ \dfrac{k'}{\gcd(k',\ell)} \mid \dfrac{k}{\gcd(k,\ell)}, \]

and then by property 2, \(a^\ell\) is a \(\dfrac{k}{\gcd(k,\ell)}\)-th root of unity modulo \(m\). This is property 3.

For \(k'\mid k\), by property 2, a \(k'\)-th primitive root of unity modulo \(m\) is necessarily a \(k\)-th root of unity modulo \(m\); conversely, every \(k\)-th root of unity \(a\) modulo \(m\) is a \(\delta_m(a)\)-th primitive root of unity, with \(\delta_m(a)\mid k\). These sets are pairwise disjoint, so they form a partition. Moreover, for \(\ell\perp k\) we always have \(\ell\perp k'\), so for a \(k'\)-th primitive root of unity \(a\) modulo \(m\), \(a^\ell\) is always a \(k'\)-th primitive root of unity modulo \(m\). Taking \(\ell'=\ell^{-1}\bmod k\), one can verify that \(x\mapsto x^\ell\) and \(x\mapsto x^{\ell'}\) are mutually inverse maps, so \(x\mapsto x^\ell\) is a bijection. This is property 4.

By the properties of the Carmichael function, a \(\lambda(m)\)-th primitive root of unity modulo \(m\) always exists; let it be \(a\), so that \(\delta_m(a)=\lambda(m)\). For \(k\mid\lambda(m)\), let \(k'=\dfrac{\lambda(m)}{k}\); we always have

\[ \delta_m(a^{k'}) = \dfrac{\lambda(m)}{\gcd(\lambda(m),k')} = \dfrac{\lambda(m)}{k'} = k. \]

Therefore, \(a^{k'}\) is a \(k\)-th primitive root of unity. On the other hand, by the definition of the Carmichael function, the order of every \(x\perp m\) is a divisor of \(\lambda(m)\). This gives property 5.

Almost repeating the proof of the primitive root criterion gives property 6. This criterion actually verifies \(\delta_m(a)=k\).

From these properties we can see that, compared to the case where a primitive root exists, the \(\lambda\)‑primitive root modulo \(m\) plays a similar fundamental role. Unlike a primitive root, the powers of a \(\lambda\)‑primitive root cannot be used to generate all roots of unity modulo \(m\). Nevertheless, since the density of \(\lambda\)‑primitive roots is not low2, if we really need to find a \(k\)-th primitive root of unity, we can first find a \(\lambda\)‑primitive root by random sampling, and then obtain a \(k\)-th primitive root of unity by taking a power.

If one \(k\)-th root of \(a\) modulo \(m\) is known, all \(k\)-th roots of \(a\) modulo \(m\) can be generated from all \(k\)-th roots of unity modulo \(m\).

Theorem

Let \(x\) be a \(k\)-th root of \(a\) modulo \(m\). As \(r\) ranges over all \(k\)-th roots of unity modulo \(m\), \(xr\) ranges over all \(k\)-th roots of \(a\) modulo \(m\).

Proof

For two \(k\)-th roots \(x,y\) of \(a\) modulo \(m\), let \(r=x^{-1}y\bmod m\); then \(r\) satisfies \(r^k\equiv 1\pmod m\), so it is a \(k\)-th root of unity modulo \(m\). Conversely, as long as \(r\) is a \(k\)-th root of unity modulo \(m\), we have \((xr)^{k}= x^kr^k\equiv a\pmod m\), that is, \(xr\) is a \(k\)-th root of \(a\) modulo \(m\).

Generating all \(k\)-th roots from the \(k\)-th roots of unity is similar to generating the general solution of a non-homogeneous system of linear equations from the solutions of the homogeneous system.

The discussion above concerns the general case. Only in the case where a primitive root exists is the structure of the roots of unity simpler:

Theorem

For a modulus \(m\), suppose a primitive root modulo \(m\) exists, and let \(a\) be a \(k\)-th primitive root of unity modulo \(m\). Then \(b\) is a \(k\)-th root of unity modulo \(m\) if and only if it can be expressed as a power of \(a\).

Proof

Let \(g\) be a primitive root modulo \(m\); then every element coprime to \(m\) can be expressed as a power of \(g\). Then \(a\) is a \(k\)-th primitive root of unity modulo \(m\) if and only if

\[ \delta_m(a) = \delta_m(g^{\operatorname{ind}_ga}) = \dfrac{\varphi(m)}{\gcd(\varphi(m),\operatorname{ind}_ga)} = k. \]

Similarly, \(b\) is a \(k\)-th root of unity modulo \(m\) if and only if

\[ \delta_m(b) = \delta_m(g^{\operatorname{ind}_gb}) = \dfrac{\varphi(m)}{\gcd(\varphi(m),\operatorname{ind}_gb)} = k' \mid k. \]

Therefore, we have

\[ \gcd(\varphi(m),\operatorname{ind}_ga) \mid \gcd(\varphi(m),\operatorname{ind}_gb)\mid \operatorname{ind}_gb. \]

By the analysis of linear congruences, this condition is equivalent to the equation

\[ (\operatorname{ind}_ga) x \equiv \operatorname{ind}_gb \pmod{\varphi(m)} \]

having a solution. Raising \(g\) to the powers in this condition, we get \(a^x\equiv b\pmod{m}\), that is, \(b\) can be expressed as a power of \(a\).

This theorem shows that, when a primitive root exists, all \(k\)-th roots of unity have the structure of a cyclic group, and the \(k\)-th primitive roots of unity are the generators of this cyclic group. We will see later that the Tonelli–Shanks algorithm exploits exactly this point to speed up the discrete logarithm part of root extraction.

Root extraction in modular arithmetic

Finally, this article discusses how to compute \(k\)-th roots. For the case \(k=2\), there are many efficient algorithms for taking square roots modulo an integer. For general \(k\), however, no polynomial-time algorithm is known. This section introduces two common algorithms, which find a \(k\)-th root in \(O(m^{1/2})\) and \(O(m^{1/4+\varepsilon})\) time, respectively. Using the Chinese remainder theorem, the problem can always be converted to the case of a prime-power modulus, so this section mainly discusses the solution for prime-power moduli.

Naive algorithm

The earlier analysis of the properties of \(k\)-th residues has in fact already pointed out a method for computing \(k\)-th roots modulo a prime power. Strictly speaking, the case solved earlier is the one where the radicand \(a\) and the modulus \(m\) are coprime. The algorithm is summarized as follows:

  • When \(m=p^e\) is an odd prime power, let \(g\) be a primitive root modulo \(m\). Then the equation \(x^k\equiv a\pmod m\) can be converted to the linear congruence

    \[ ky \equiv \operatorname{ind}_g a \pmod{\varphi(m)}. \]

    Here, \(\operatorname{ind}_g a\) can be computed with the BSGS algorithm, and all solutions of the linear congruence are easy to find. From this, we obtain all \(k\)-th roots \(x\equiv g^y\pmod m\) of \(a\).

    Besides this, there is another similar approach. Again letting \(x\equiv g^y\pmod m\), we can transform

    \[ x^k \equiv (g^k)^y \equiv a \pmod m \]

    into computing the discrete logarithm of \(a\) with base \(g^k\). This can likewise be solved with the BSGS algorithm to find a particular solution. The general solution can be obtained from the expression for the solutions given earlier, that is, by multiplying the particular solution by each of the \(k\)-th roots of unity in turn.

    Whichever approach is used, when the primitive root is known, the complexity of finding a single solution with this algorithm is \(O(m^{1/2})\). Since a primitive root can be found in \(o(m^{1/2})\) time, the total time complexity is still \(O(m^{1/2})\).

  • When \(m=2^e\) with \(e\in\mathbf N_+\), we can first find \(s,r\) in \(a\equiv (-1)^s5^r\pmod m\). Of these two exponents, \(s\) can be determined in \(O(1)\) time:

    \[ s = \begin{cases}0, & a\equiv 1\pmod 4, \\ 1, & a\equiv 3\pmod 4.\end{cases} \]

    And \(r=\operatorname{ind}_5((-1)^sa)\) can be computed with the BSGS algorithm in \(O(m^{1/2})\) time. Next, we only need to solve the system of linear congruences:

    \[ \begin{aligned} kz &\equiv s \pmod{2},\\ ky &\equiv r \pmod{2^{e-2}}. \end{aligned} \]

    The general solution \((z,y)\) of this system of linear congruences is easy to find, and \(x=(-1)^z5^y\) is the required root. The complexity of finding a single solution with this algorithm is again \(O(m^{1/2})\).

Of course, the case with no solution can in fact be quickly detected in \(O(\log m)\) time using the criterion described earlier, without needing to check during the solving process.

A reference implementation for computing \(k\)-th roots modulo a prime is as follows: (the code is only for illustration; because its time complexity is too high, it cannot pass this problem)

Reference implementation for the template problem Library Checker - Kth Root (Mod) 
// Submission (TLE): https://judge.yosupo.jp/submission/320582
#include <algorithm>
#include <cmath>
#include <iostream>
#include <tuple>
#include <unordered_map>
#include <vector>

struct PrimePower {
  int p, e, pe;

  PrimePower(int p, int e, int pe) : p(p), e(e), pe(pe) {}
};

// Factorization.
auto factorize(int n) {
  std::vector<PrimePower> ans;
  for (int x = 2; x * x <= n; ++x) {
    int e = 0, pe = 1;
    for (; n % x == 0; n /= x, ++e, pe *= x);
    if (e) ans.emplace_back(x, e, pe);
  }
  if (n > 1) ans.emplace_back(n, 1, n);
  return ans;
}

// Binary exponentiation.
int pow(int a, int b, int m = 0) {
  int res = 1;
  for (; b; b >>= 1) {
    if (b & 1) res = m ? (long long)res * a % m : res * a;
    a = m ? (long long)a * a % m : a * a;
  }
  return res;
}

// Find a primitive root modulo prime.
int primitive_root(int p) {
  std::vector<int> exp;
  for (auto factor : factorize(p - 1)) {
    exp.push_back((p - 1) / factor.p);
  }
  int ans = 0;
  bool succ = false;
  while (!succ) {
    ++ans;
    succ = true;
    for (int b : exp) {
      if (pow(ans, b, p) == 1) {
        succ = false;
        break;
      }
    }
  }
  return ans;
}

// Discrete logarithm. (BSGS Algorithm)
int log(int g, int a, int m) {
  int b = std::sqrt(m + 0.25l) + 1;
  std::unordered_map<int, int> mp;
  int po0 = a % m, po1 = 1;
  for (int i = 0; i < b; ++i) {
    mp[po0] = i;
    po0 = (long long)po0 * g % m;
  }
  po0 = pow(g, b, m);
  for (int j = 1; j <= b; ++j) {
    po1 = (long long)po1 * po0 % m;
    if (mp.count(po1)) return j * b - mp[po1];
  }
  return -1;
}

// Extended Euclidean Algorithm.
int ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
    return a;
  } else {
    int d = ex_gcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
  }
}

// Solves the linear congruence equation: Ax = B mod N.
// Return the least nonnegative solution and the common difference.
std::pair<int, int> solve_linear(int a, int b, int n) {
  int x, y;
  int d = ex_gcd(a, n, x, y);
  if (b % d) return {-1, -1};
  n /= d;
  x = ((long long)x * (b / d) % n + n) % n;
  return {x, n};
}

// Subroutine: Find a K-th root with a primitive root G known.
int calc(int g, int k, int a, int p) {
  int ind = log(g, a, p);
  if (ind == -1) return -1;
  int y0, d;
  std::tie(y0, d) = solve_linear(k, ind, p - 1);
  if (y0 == -1) return -1;
  return pow(g, y0, p);
}

// Find a K-th root of A modulo prime P.
int kth_roots_mod_p(int k, int a, int p) {
  a %= p;
  if (k == 0) return a == 1 ? 0 : -1;
  if (a == 0) return 0;
  return calc(primitive_root(p), k, a, p);
}

void solve() {
  int k, y, p;
  std::cin >> k >> y >> p;
  std::cout << kth_roots_mod_p(k, y, p) << '\n';
}

int main() {
  int t;
  std::cin >> t;
  for (; t; --t) {
    solve();
  }
}

Improved Tonelli–Shanks algorithm

By suitably generalizing the Tonelli–Shanks algorithm for taking square roots modulo an integer, root extraction modulo a prime power can be solved. A relatively direct way of generalizing is the Adleman–Manders–Miller algorithm3, but its complexity is still not good enough4. This section introduces the improved Tonelli–Shanks algorithm proposed by sugarknri, Min_25, 37zigen and others. It can find a \(k\)-th root in \(O(m^{1/4+\varepsilon})\) time.

The core idea of the Tonelli–Shanks algorithm is to move the computation of the discrete logarithm into a group of order \(2^e\), thereby reducing the time complexity. Similarly, the discrete logarithm in a group of order an arbitrary prime power \(p^e\) can also be computed fairly efficiently, but the complexity of the algorithm is \(\Omega\left(\sqrt{p}\right)\). The Adleman–Manders–Miller algorithm splits the computation of a \(k\)-th root into several computations of discrete logarithms in groups of prime-power order, but it is limited by the size of the largest prime factor \(p_\text{max}(k)\) of \(k\), so the complexity of the algorithm is still \(\Omega\left(\sqrt{p_\text{max}(k)}\right)\). The algorithm in this section further improves this process by avoiding the computation of discrete logarithms for larger prime factors, thereby bringing the overall complexity down to \(O(m^{1/4+\varepsilon})\).

Procedure

Consider computing a \(k\)-th root of \(a\) modulo a prime power \(m\), i.e. solving the congruence:

\[ x^k \equiv a \pmod m. \]

In particular, for the case \(m=2^e\), we also need to ensure \(a\equiv 1\pmod{4}\), so that \(a\) can be written as a power of \(g=5\). Similarly to the earlier discussion, the computation of \(k\)-th roots modulo \(2^e\) can always be converted to such a case. When handling the case modulo \(2^e\), every \(\varphi(m)\) mentioned in this section should be replaced by \(\delta_m(5)=2^{e-2}\).

First, the problem can be converted to the case where the order of the root divides \(\varphi(m)\). Let \(d=\gcd(k,\varphi(m))\). Then, by the properties of \(k\)-th residues, when \(a\) is a \(k\)-th residue modulo \(m\), \(a\) is always a \(\dfrac{\varphi(m)}{d}\)-th root of unity modulo \(m\). By the properties of roots of unity, for any \(\ell\perp\dfrac{\varphi(m)}{d}\), the map \(x\mapsto x^{\ell}\) is a bijection among the \(\dfrac{\varphi(m)}{d}\)-th roots of unity. Therefore, we can take

\[ \ell = \left(\dfrac{k}{d}\right)^{-1}\bmod\dfrac{\varphi(m)}{d}. \]

Raising both sides of the original congruence to the \(\ell\)-th power, we get

\[ x^d\equiv x^{k\ell} \equiv a^{\ell} =: b \pmod{m}. \]

The leftmost congruence uses Euler's theorem and the following congruence relation: (\(c\in\mathbf Z\))

\[ k\ell = d\left(\frac{k}{d}\ell\right) = d\left(c\dfrac{\varphi(m)}{d}+1\right) \equiv d \pmod{\varphi(m)}. \]

For the transformed problem, consider the prime factorization of \(d\):

\[ d = \prod_{p\in\mathbf P}p^e. \]

Starting from \(b=a^\ell\), for each \(p^e\neq 1\) we take a \(p^e\)-th root in turn, and in the end we obtain a \(d\)-th root of \(b\), that is, a \(k\)-th root of \(a\).

Finally, the problem is reduced to finding a solution of the following equation:

\[ x^{p^e} \equiv b \pmod m. \]

Without loss of generality, let \(\varphi(m)=p^sr\) with \(p\perp r\). Let \(q\in\mathbf N_+\) be a solution of the equation \(qr\equiv -1\pmod{p^e}\). Then, since \(b\) is an \(rp^{s-e}\)-th root of unity, \(b^{qr}\) must be a \(p^{s-e}\)-th root of unity. Further, let \(\zeta\) be a \(p^s\)-th primitive root of unity modulo \(m\). Then \(\zeta^{p^e}\) is a \(p^{s-e}\)-th primitive root of unity, and hence there exists \(h\in\mathbf N\) such that \(b^{qr}\equiv \zeta^{hp^{e}}\pmod{m}\). Therefore, by direct verification,

\[ x\equiv b^{(qr+1)/p^e}\zeta^{-h} \pmod{m} \]

is a \(p^e\)-th root of \(b\) modulo \(m\).

To compute \(x\), we need to find a \(p\)-th nonresidue \(\eta\) modulo \(m\). For this, by the properties above, it suffices to pick \(\eta\perp m\) at random and verify \(\eta^{\varphi(m)/p}\bmod{m}\neq 1\). The density of such numbers is

\[ \dfrac{\varphi(m)}{m}\left(1-\dfrac{1}{p}\right) \ge \dfrac{1}{4}. \]

Therefore, in expectation, picking at most \(4\) random integers suffices to find one. Note that \(\eta^{rp^{s-1}}\not\equiv 1\pmod m\) and \(\eta^{rp^s}\equiv 1\pmod m\), so if we set \(\zeta=\eta^r\bmod m\) and \(\xi=\eta^{rp^{s-1}}\bmod m\), they are a \(p^s\)-th and a \(p\)-th primitive root of unity, respectively.

Finally, we need to compute \(h\in\mathbf N\). Clearly, we can take \(h < p^{s-e}\). Consider the base-\(p\) representation of \(h\):

\[ h = \sum_{j=0}^{s-e-1}h_jp^j = h_0 + h_1p + h_2p^2 +\cdots. \]

We compute these digits one by one. When the first \(j\) digits have been computed, we necessarily have

\[ \left(b^{qr}\zeta^{-p^e(h_0+h_1p+\cdots + h_{j-1}p^{j-1})}\right)^{p^{s-e-j-1}} \equiv \zeta^{h_jp^{s-1}} \equiv \xi^{h_j} \pmod{m}. \]

Hence, \(h_j\) can be obtained by computing a discrete logarithm with respect to \(\xi\). To obtain a better time complexity, the BSGS algorithm should be used. In total, \((s-e)\) discrete logarithms need to be computed; if we precompute \(B\) powers of \(\xi\), the time complexity of a single discrete logarithm computation is \(O(p/B)\), and the total time complexity is

\[ O\left(B+(s-e)\dfrac{p}{B}\right). \]

When \(B=\sqrt{(s-e)p}\), the total time complexity is minimized, at \(O\left(\sqrt{(s-e)p}\right)\). After obtaining \(h\), substituting it into the expression for \(x\) above gives a particular solution.

Time complexity

The time complexity of this algorithm is \(O(m^{1/4+\varepsilon})\). When discussing complexity in this section, we always assume that a single multiplication takes \(O(1)\) time, and that when computing powers, Euler's theorem is always applied to reduce the exponent, so each individual power involved can always be computed in \(O(\log m)\) time.

First consider the computation of a single \(p^e\)-th root. Finding a \(p\)-th nonresidue only requires checking \(O(1)\) numbers in expectation, for a total time complexity of \(O(\log m)\). Computing each of \(s,r,\zeta,\eta,b^{qr}\) takes only \(O(\log m)\) time. When computing \(h\), each digit requires \(O(\log m)\) time to compute powers, and there are \((s-e)\) digits in total, so the total time complexity is \(O((s-e)\log m)\). As explained above, the preprocessing and the \((s-e)\) queries of the discrete logarithm part take \(O\left(\sqrt{(s-e)p}\right)\) time in total. Since \(s-e\in O(\log m)\), the time complexity of computing a single \(p^e\)-th root is \(O(p^{1/2+\varepsilon})\). In particular, when \(s=e\), the time complexity can be further reduced to \(O(\log m)\).

We can now consider the total time complexity of the algorithm. The time complexities of computing \(\varphi(m),d,\ell\) are all \(O(\log m)\). Next, the prime factorization \(d=\prod_p{p^e}\) needs to be done; this step can be completed in \(O(m^{1/4})\) time using the Pollard's rho algorithm. Finally, the total time complexity of computing the \(p^e\)-th roots in turn is

\[ O\left(\sum_{e < s}p^{1/2+\varepsilon}\right). \]

Since a prime factor \(p\) satisfying \(e < s\) appears at least \(2\) times in \(\varphi(m)\), we necessarily have \(p < m^{1/2}\). Hence, the total time complexity is \(O(m^{1/4+\varepsilon})\).

In fact, in this scenario, there is no need to use Pollard's rho algorithm for the prime factorization, and a time complexity of \(O(m^{1/4+\varepsilon})\) can still be achieved. Specifically, it suffices to factor \(d\) by brute-force trial division, enumerating only prime factors not exceeding \(m^{1/4}\). Let \(z\) be the integer obtained after removing these small prime factors. Then, for a prime factor \(p > m^{1/4}\) of \(z\), we necessarily have \(\nu_p(\varphi(m)) < 4\), where \(\nu_p(n)\) denotes the exponent of \(p\) in the prime factorization of \(n\). Since we only need to consider the case

\[ 1 \le e = \nu_p(d) < s = \nu_p(\varphi(m)) < 4 \]

there can be at most one prime factor \(p\) satisfying this condition; otherwise, their exponents in \(\varphi(m)\) would all be at least \(2\), and the total product would necessarily exceed \(m\). To separate out this (possibly existing) unique large prime factor, it suffices to compute

\[ p^\star=\gcd\left(z,\dfrac{\varphi(m)}{z}\right) = \prod_{p\mid z,~\nu_p(d) < \nu_p(\varphi(m))}p^{\min\{\nu_p(d),\nu_p(\varphi(m))-\nu_p(d)\}}. \]

Enumerating all possibilities for \(\nu_p(d),\nu_p(\varphi(m))\) shows that the exponent of \(p\) in the product is necessarily \(1\), so the value computed this way is exactly the unique large prime factor \(p^\star\) (if it exists). As for the remaining part \(z/p^\star\), since it can only contain prime factors satisfying \(e=s\), there is no need to factor it further.

// Subroutine: Find a P^E-th root of A mod M.
int peth_root_mod_m(int p, int e, int a, int m, int phi) {
  int s = 0, r = phi, pe = pow(p, e);
  for (; r % p == 0; r /= p, ++s);
  int q = pe - inv(r, pe);
  int ans = pow(a, ((long long)q * r + 1) / pe % phi, m);
  int eta = non_residue(p, m, phi);
  std::unordered_map<int, int> mp;
  int zeta = pow(eta, r, m);
  int xi = pow(eta, phi / p, m);
  // Precompute powers for BSGS.
  int B = std::sqrt((s - e) * p + 0.25l) + 1;
  int pB = p / B + 1;
  int po0 = pow(xi, pB, m);
  for (int j = 1, po1 = 1; j <= B; ++j) {
    po1 = (long long)po1 * po0 % m;
    mp[po1] = j;
  }
  // Compute p-adic digits of h.
  for (int j = 0; j < s - e; ++j) {
    int err = (long long)pow(ans, pe, m) * inv(a, m) % m;
    int xi_hj = pow(err, pow(p, s - e - j - 1), m);
    long long hj = 0;
    // BSGS query.
    for (int i = 1; i <= pB; ++i) {
      xi_hj = (long long)xi_hj * xi % m;
      if (mp.count(xi_hj)) {
        hj = mp[xi_hj] * pB - i;
        break;
      }
    }
    ans = (long long)ans * pow(zeta, phi - hj * pow(p, j) % phi, m) % m;
  }
  return ans;
}

// Find a K-th root of A modulo prime P.
int kth_root_mod_p(int k, int a, int p) {
  a %= p;
  if (k == 0) return a == 1 ? 0 : -1;
  if (a == 0) return 0;
  int d = gcd(k, p - 1);
  if (pow(a, (p - 1) / d, p) != 1) return -1;
  a = pow(a, inv(k / d, (p - 1) / d), p);
  for (int dp = 2; dp * dp <= d && dp * dp * dp * dp < p; ++dp) {
    if (d % dp == 0) {
      int de = 0;
      for (; d % dp == 0; d /= dp, ++de);
      a = peth_root_mod_m(dp, de, a, p, p - 1);
    }
  }
  if (d != 1) {
    int dp = gcd(d, (p - 1) / d), de = 0;
    if (dp != 1) {
      for (; d % dp == 0; d /= dp, ++de);
      a = peth_root_mod_m(dp, de, a, p, p - 1);
    }
    if (d != 1) a = peth_root_mod_m(d, 1, a, p, p - 1);
  }
  return a;
}

Handling the general case

Consider the general case: the modulus \(m\) is still a prime power \(p^e\), but \(\gcd(a,m)>1\). If \(a\equiv 0\pmod{m}\), then

\[ x \equiv p^{\lceil e/k \rceil}\ell\pmod{p^e},~\ell=0,1,\cdots,p^{e-\lceil e/k\rceil}-1 \]

are all solutions of the original equation. Next, consider the case \(a\not\equiv 0\pmod{m}\). Let \(a = p^sa'\) with \(p\perp a'\). Then, setting \(x=p^zx'\) with \(p\perp x'\), we have

\[ x^k = p^{kz}(x')^k\equiv p^sa'\pmod{p^e}. \]

Since \((x')^k\perp p\), this holds if and only if \(kz = s\) and \((x')^k\equiv a'\pmod{p^{e-s}}\). The first equation has the solution \(z=\dfrac{s}{k}\) if and only if \(k\mid s\); and solving the second equation has already been settled. Note that since the modulus of the general solution of the second equation differs from the modulus of the general solution of the original equation, each solution \(x'\) of the second equation corresponds to several solutions of the original equation:

\[ x \equiv p^{s/k}(x' + \ell p^{e-s})\pmod{p^e},~\ell = 0,1,\cdots, p^{s-s/k}-1. \]

// Discrete logarithm. (BSGS Algorithm)
int log(int g, int a, int m) {
  int b = std::sqrt(m + 0.25l) + 1;
  std::unordered_map<int, int> mp;
  int po0 = a % m, po1 = 1;
  for (int i = 0; i < b; ++i) {
    mp[po0] = i;
    po0 = (long long)po0 * g % m;
  }
  po0 = pow(g, b, m);
  for (int j = 1; j <= b; ++j) {
    po1 = (long long)po1 * po0 % m;
    if (mp.count(po1)) return j * b - mp[po1];
  }
  return -1;
}

// Solves the linear congruence equation: Ax = B mod N.
// Return the least nonnegative solution and the common difference.
std::pair<int, int> solve_linear(int a, int b, int n) {
  int x, y;
  int d = ex_gcd(a, n, x, y);
  if (b % d) return {-1, -1};
  n /= d;
  x = ((long long)x * (b / d) % n + n) % n;

// Subroutine: Find all the K-th roots with a primitive root G known.

  int mm = p == 2 ? pe / 4 : pe / p * (p - 1);
  int y0, d;
  std::tie(y0, d) = solve_linear(k, ind, mm);
  if (y0 == -1) return {};
  int ans = pow(g, y0, pe), po = pow(g, d, pe);
  std::vector<int> res(mm / d);
  for (auto& x : res) {
    x = ans;
    ans = (long long)ans * po % pe;
  }
  return res;
}

// Find all the K-th roots of A modulo prime power P^E.
std::vector<int> kth_roots_mod_pe(int k, int a, PrimePower pp) {
  int p = pp.p, e = pp.e, pe = pp.pe;
  a %= pe;
  if (a == 0) {
    int d = pow(p, (e - 1) / k + 1);
    std::vector<int> res(pe / d);
    for (int i = 0; i < pe / d; ++i) {
      res[i] = i * d;
    }
    return res;
  }
  int s = 0;
  for (; a % p == 0; a /= p, ++s);
  if (s % k) return {};
  int psk = pow(p, s / k), pss = pow(p, s - s / k), pes = pow(p, e - s);
  std::vector<int> res;
  if (p != 2) {
    int g = primitive_root(PrimePower(p, e - s, pes));
    res = calc(g, k, a, p, pes);
  } else if (pes == 2) {
    res.push_back(a);
  } else if (k & 1) {
    int z = a % 4 == 3;
    a = z ? pes - a : a;
    res = calc(5, k, a, p, pes);
    if (z) {
      for (auto& x : res) x = pes - x;
    }
  } else {
    if (a % 4 == 3) return {};
    res = calc(5, k, a, p, pes);
    int m = res.size();
    res.reserve(m * 2);
    for (int i = 0; i < m; ++i) {
      res.push_back(pes - res[i]);
    }
  }
  int m = res.size();
  res.reserve(m * pss);
  for (int j = 1; j < pss; ++j) {
    for (int i = 0; i < m; ++i) {
      res.push_back(res.end()[-m] + pes);
    }
  }
  for (auto& x : res) x *= psk;
  return res;
}

// Find all the K-th roots of A modulo positive integer M.
std::vector<int> kth_roots_mod_m(int k, int a, int m) {
  auto factors = factorize(m);
  int m0 = 0;
  std::vector<std::vector<int>> sols;
  for (const auto& pp : factors) {
    sols.push_back(kth_roots_mod_pe(k, a, pp));
    if (sols.back().empty()) return {};
  }
  std::vector<int> ans;
  for (int i = 0; i < (int)factors.size(); ++i) {
    auto pp = factors[i];
    if (!i) {
      m0 = pp.pe;
      ans = sols[i];
    } else {
      long long m1 = pp.pe * inv(pp.pe, m0);
      long long m2 = m0 * inv(m0, pp.pe);
      m0 *= pp.pe;
      std::vector<int> _ans;
      _ans.reserve(ans.size() * sols[i].size());
      for (auto x : ans) {
        for (auto y : sols[i]) {
          _ans.push_back((m1 * x + m2 * y) % m0);
        }
      }
      ans.swap(_ans);
    }
  }
  return ans;
}

// Subroutine: Find a P^E-th root of A mod M.
int peth_root_mod_m(int p, int e, int a, int m, int phi) {
  if (m == 2) return 1;

  for (; r % p == 0; r /= p, ++s);
  int q = pe - inv(r, pe);

  int eta = non_residue(p, m, phi);
  std::unordered_map<int, int> mp;
  int zeta = pow(eta, r, m);

    mp[po1] = j;

  if (a == 0) return 0;

  if (pow(a, phi / d, pe) != 1) return -1;
  a = pow(a, inv(k / d, phi / d), pe);
  for (int dp = 2; dp * dp <= d && dp * dp * dp * dp < pe; ++dp) {
    if (d % dp == 0) {

      for (; d % dp == 0; d /= dp, ++de);

    }
    if (d != 1) a = peth_root_mod_m(d, 1, a, pe, phi);
  }
  return a;
}

  std::vector<int> res;
  if (p != 2) {
    int g = primitive_root(PrimePower(p, e - s, pes));
    res = calc(g, k, a, p, pes);
  } else if (pes == 2) {
    res.push_back(a);
  } else if (k & 1) {
    int z = a % 4 == 3;
    a = z ? pes - a : a;
    res = calc(5, k, a, p, pes);
    if (z) {
      for (auto& x : res) x = pes - x;
    }
  } else {
    if (a % 4 == 3) return {};
    res = calc(5, k, a, p, pes);
    int m = res.size();
    res.reserve(m * 2);
    for (int i = 0; i < m; ++i) {
      res.push_back(pes - res[i]);
    }
  }
  int m = res.size();
  res.reserve(m * pss);
  for (int j = 1; j < pss; ++j) {
    for (int i = 0; i < m; ++i) {
      res.push_back(res.end()[-m] + pes);
    }
  }
  for (auto& x : res) x *= psk;
  return res;
}

// Find all the K-th roots of A modulo positive integer M.
std::vector<int> kth_roots_mod_m(int k, int a, int m) {
  auto factors = factorize(m);
  int m0 = 0;
  std::vector<std::vector<int>> sols;
  for (const auto& pp : factors) {
    sols.push_back(kth_roots_mod_pe(k, a, pp));
    if (sols.back().empty()) return {};
  }
  std::vector<int> ans;
  for (int i = 0; i < (int)factors.size(); ++i) {
    auto pp = factors[i];
    if (!i) {
      m0 = pp.pe;
      ans = sols[i];
    } else {
      long long m1 = pp.pe * inv(pp.pe, m0);
      long long m2 = m0 * inv(m0, pp.pe);
      m0 *= pp.pe;
      std::vector<int> _ans;
      _ans.reserve(ans.size() * sols[i].size());
      for (auto x : ans) {
        for (auto y : sols[i]) {
          _ans.push_back((m1 * x + m2 * y) % m0);
        }
      }
      ans.swap(_ans);
    }
  }
  return ans;
}

void solve() {
  int n, m, k;
  std::cin >> n >> m >> k;
  auto ans = kth_roots_mod_m(n, k, m);
  if (ans.empty()) {
    std::cout << 0 << '\n';
    return;
  }
  std::cout << ans.size() << '\n';
  std::sort(ans.begin(), ans.end());
  for (auto x : ans) std::cout << x << ' ';
  std::cout << '\n';
}

int main() {
  int t;
  std::cin >> t;
  for (; t; --t) {
    solve();
  }
}
