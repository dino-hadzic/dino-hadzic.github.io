U ovom se članku uvodi inverz s obzirom na množenje u modularnoj aritmetici i razmatraju se uobičajene metode njegova računanja.

Osnovni pojmovi

Multiplikativni inverz realnog broja \(a\in\mathbf R\) različitog od nule jest njegova recipročna vrijednost \(a^{-1}\). Slično, u teoriji brojeva može se definirati inverz cijelog broja \(a\) modulo \(m\), \(a^{-1}\bmod m\), ili kraće \(a^{-1}\). To je modularni inverz (modular multiplicative inverse), koji se naziva i teorijsko-brojevna recipročna vrijednost.

Inverz

Za cijeli broj \(a\) i pozitivni cijeli broj \(m\), ako postoji \(b\) takav da je \(ab\equiv 1\pmod m\), kažemo da je \(b\) inverz (inverse) od \(a\) modulo \(m\).

To znači da je \(b\) rješenje linearne kongruencije \(ax\equiv 1\pmod m\). Prema svojstvima linearnih kongruencija, inverz \(a^{-1}\bmod m\) postoji ako i samo ako je \(\gcd(a,m)=1\), tj. ako su \(a,m\) relativno prosti, i tada je jedinstven modulo \(m\).

Računanje jednog inverza

Pomoću proširenog Euklidova algoritma ili brzog potenciranja inverz jednog cijelog broja može se izračunati u vremenu \(O(\log m)\).

Prošireni Euklidov algoritam

Računanje inverza ekvivalentno je rješavanju linearne kongruencije. Stoga se inverz može izračunati proširenim Euklidovim algoritmom u vremenu \(O(\log\min\{a,m\})\). Ujedno, budući da je linearna jednadžba koja odgovara inverzu posebno jednostavna, odgovarajući se koraci mogu prikladno pojednostavniti.

Referentna implementacija 
// Extended Euclidean algorithm.
void ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
  } else {
    ex_gcd(b, a % b, y, x);
    y -= a / b * x;
  }
}

// Returns the modular inverse of a modulo m.
// Assumes that gcd(a, m) = 1, so the inverse exists.
int inverse(int a, int m) {
  int x, y;
  ex_gcd(a, m, x, y);
  return (x % m + m) % m;
}

# Extended Euclidean algorithm.
def ex_gcd(a, b):
    if b == 0:
        return 1, 0
    else:
        x1, y1 = ex_gcd(b, a % b)
        x = y1
        y = x1 - (a // b) * y1
        return x, y


# Returns the modular inverse of a modulo m.
# Assumes that gcd(a, m) = 1, so the inverse exists.
def inverse(a, m):
    x, y = ex_gcd(a, m)
    return (x % m + m) % m

Ovaj je algoritam primjenjiv u svim slučajevima u kojima inverz postoji.

Metoda brzog potenciranja

Ova se metoda uglavnom primjenjuje kad je modul prost broj \(p\). Tada prema malom Fermatovu teoremu za svaki \(a\perp p\) vrijedi

\[ a\cdot a^{p-2} = a^{p-1} \equiv 1 \pmod p. \]

Prema jedinstvenosti inverza, inverz \(a^{-1}\bmod p\) jednak je \(a^{p-2}\bmod p\), pa se može izravno izračunati brzim potenciranjem u vremenu \(O(\log p)\):

Referentna implementacija 
// Binary exponentiation.
int pow(int a, int b, int m) {
  long long res = 1, po = a;
  for (; b; b >>= 1) {
    if (b & 1) res = res * po % m;
    po = po * po % m;
  }
  return res;
}

// Returns the modular inverse of a prime modulo p.
int inverse(int a, int p) { return pow(a, p - 2, p); }

# Returns the modular inverse of a prime modulo p.
# Use built-in pow function.
def inverse(a, p):
    return pow(a, p - 2, p)

Dakako, teoretski se ova metoda pomoću Eulerova teorema može poopćiti na slučaj općeg modula \(m\), tj. inverz se može računati kao \(a^{\varphi(m)-1}\bmod m\). Međutim, jednokratno računanje Eulerove funkcije \(\varphi(m)\) nije jednostavno, pa taj algoritam u općem slučaju nije učinkovit.

Računanje više inverza

U nekim je situacijama potrebno brzo izračunati inverze više cijelih brojeva \(a_1,a_2,\cdots,a_n\) modulo \(m\). Računanje inverza jednog po jednog ukupno zahtijeva vrijeme \(O(n\log m)\). Zapravo, ako ih obradimo zajedno, inverzi svih brojeva mogu se izračunati u vremenu \(O(n+\log m)\).

Promotrimo prefiksne produkte niza \(\{a_i\}\):

\[ S_0 = 1,~ S_i = a_iS_{i-1},~ i=1,2,\cdots,n. \]

Ako je svaki \(a_i\) relativno prost s \(m\), i njihov je produkt \(S_n\) relativno prost s \(m\). Stoga se prethodno opisanim algoritmom može izračunati vrijednost \(S_n^{-1}\bmod m\). Budući da je inverz produkta jednak produktu inverza, polazeći od \(S_n^{-1}\) i prolazeći niz unatrag možemo izračunati inverz svakog \(S_i\):

\[ S_{i-1}^{-1} = a_iS_i^{-1} \bmod m,~ i = n,n-1,\cdots,1. \]

Iz toga se inverz pojedinog \(a_i\) može izračunati formulom:

\[ a_i^{-1} = S_{i-1}S_i^{-1} \bmod m,~ i = 1,2,\cdots,n. \]

Referentna implementacija slijedi:

Referentna implementacija 
// Returns the modular inverses for each x in a modulo m.
// Assume x mod m exists for each x in a.
std::vector<int> batch_inverse(const std::vector<int>& a, int m) {
  int n = a.size();
  std::vector<int> prod(n);
  long long s = 1;
  for (int i = 0; i < n; ++i) {
    // prod[i] = product of a[0...i-1]; prod[0] = 1.
    prod[i] = s;
    s = s * a[i] % m;
  }
  // s = product of all elements in a.
  s = inverse(s, m);
  std::vector<int> res(n);
  for (int i = n - 1; i >= 0; --i) {
    res[i] = s * prod[i] % m;
    s = s * a[i] % m;
  }
  return res;
}

# Returns the modular inverses for each x in a modulo m.
# Assume x mod m exists for each x in a.
def batch_inverse(a, m):
    n = len(a)
    prod = [0] * n
    s = 1
    for i in range(n):
        # prod[i] = product of a[0...i-1]; prod[0] = 1.
        prod[i] = s
        s = s * a[i] % m
    # s = product of all elements in a.
    s = inverse(s, m)
    res = [0] * n
    for i in reversed(range(n)):
        res[i] = s * prod[i] % m
        s = s * a[i] % m
    return res

U algoritmu se inverz pojedinog elementa računa samo jednom, pa je ukupna vremenska složenost \(O(n+\log m)\).

Predračunavanje inverza u linearnom vremenu

Ako treba predračunati inverze prvih \(n\) pozitivnih cijelih brojeva modulo prost broj \(p\), to se može učiniti i u vremenu \(O(n)\) pomoću rekurzivne relacije koju razmatramo u ovom odjeljku. Ta se metoda često koristi pri računanju binomnih koeficijenata za predračunavanje inverza faktorijela prvih \(n\) pozitivnih cijelih brojeva.

Za pozitivni cijeli broj \(i\) takav da je \(1< i < p\) promotrimo dijeljenje s ostatkom:

\[ p = \left\lfloor \dfrac{p}{i} \right\rfloor i + (p\bmod i). \]

Uzimajući tu jednakost modulo prost broj \(p\), dobivamo

\[ 0 \equiv \left\lfloor \dfrac{p}{i} \right\rfloor i + (p\bmod i) \pmod p. \]

Množenjem obiju strana s \(i^{-1}(p\bmod i)^{-1}\) dobivamo

\[ i^{-1} \equiv - \left\lfloor \dfrac{p}{i} \right\rfloor (p\bmod i)^{-1} \pmod p. \]

To je formula za rekurzivno računanje inverza u linearnom vremenu. Budući da je \(p\bmod i < i\), ta formula svodi problem računanja \(i^{-1}\bmod p\) na manji problem \((p\bmod i)^{-1}\bmod p\). Stoga, polazeći od \(1^{-1}\bmod p=1\) i redom primjenjujući formulu za svaki \(i\), inverzi prvih \(n\) cijelih brojeva mogu se dobiti u vremenu \(O(n)\).

Referentna implementacija slijedi:

Referentna implementacija 
// Precomputes modular inverses of all integers from 1 to n modulo prime p.
std::vector<int> precompute_inverses(int n, int p) {
  std::vector<int> res(n + 1);
  res[1] = 1;
  for (int i = 2; i <= n; ++i) {
    res[i] = (long long)(p - p / i) * res[p % i] % p;
  }
  return res;
}

# Precomputes modular inverses of all integers from 1 to n modulo prime p.
def precompute_inverses(n, p):
    res = [0] * (n + 1)
    res[1] = 1
    for i in range(2, n + 1):
        res[i] = (p - p // i) * res[p % i] % p
    return res

Ovaj je algoritam primjenjiv samo kad je modul prost broj. Kad modul \(m\) nije prost, ne može se jamčiti da je \(m\bmod i\) iz rekurzivne formule i dalje relativno prost s \(m\), pa \((m\bmod i)^{-1}\) koji rekurzija zahtijeva možda ne postoji. Jedan je takav primjer \(m=8,i=3\). Tada je \(m\bmod i = 2\), koji nema inverz modulo \(m\).

Osim toga, nakon što imamo tu rekurzivnu formulu, prirodna je ideja izravno rekurzivno računati inverz proizvoljnog broja \(a\). U svakom koraku rekurzije formula ga svodi na inverz manjeg ostatka \(p\bmod a\), dok ostatak ne postane \(1\). Složenost takvog postupka zasad nije poznata1, pa se preporučuje koristiti prethodno opisane uobičajene metode.

This article introduces the inverse with respect to multiplication in modular arithmetic and discusses common methods of computing it.

Basic concepts

The multiplicative inverse of a nonzero real number \(a\in\mathbf R\) is its reciprocal \(a^{-1}\). Similarly, in number theory one can define the inverse of an integer \(a\) modulo \(m\), \(a^{-1}\bmod m\), or simply \(a^{-1}\). This is the modular multiplicative inverse, also called the number-theoretic reciprocal.

Inverse

For an integer \(a\) and a positive integer \(m\), if there exists \(b\) such that \(ab\equiv 1\pmod m\), then \(b\) is called the inverse of \(a\) modulo \(m\).

This amounts to saying that \(b\) is a solution of the linear congruence \(ax\equiv 1\pmod m\). By the properties of linear congruences, the inverse \(a^{-1}\bmod m\) exists if and only if \(\gcd(a,m)=1\), i.e. \(a,m\) are coprime, and in that case it is unique modulo \(m\).

Computing a single inverse

Using the extended Euclidean algorithm or binary exponentiation, the inverse of a single integer can be computed in \(O(\log m)\) time.

Extended Euclidean algorithm

Computing an inverse is equivalent to solving a linear congruence. Therefore, the extended Euclidean algorithm can be used to compute the inverse in \(O(\log\min\{a,m\})\) time. At the same time, since the linear equation corresponding to the inverse is rather special, the corresponding steps can be simplified appropriately.

Reference implementation 
// Extended Euclidean algorithm.
void ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
  } else {
    ex_gcd(b, a % b, y, x);
    y -= a / b * x;
  }
}

// Returns the modular inverse of a modulo m.
// Assumes that gcd(a, m) = 1, so the inverse exists.
int inverse(int a, int m) {
  int x, y;
  ex_gcd(a, m, x, y);
  return (x % m + m) % m;
}

    return (x % m + m) % m

This algorithm applies to all cases in which the inverse exists.

Binary exponentiation method

This method mainly applies when the modulus is a prime \(p\). In that case, by Fermat's little theorem, for every \(a\perp p\) we have

\[ a\cdot a^{p-2} = a^{p-1} \equiv 1 \pmod p. \]

By the uniqueness of the inverse, the inverse \(a^{-1}\bmod p\) equals \(a^{p-2}\bmod p\), so it can be computed directly by binary exponentiation in \(O(\log p)\) time:

Reference implementation 
// Binary exponentiation.
int pow(int a, int b, int m) {
  long long res = 1, po = a;
  for (; b; b >>= 1) {
    if (b & 1) res = res * po % m;
    po = po * po % m;
  }
  return res;
}

// Returns the modular inverse of a prime modulo p.
int inverse(int a, int p) { return pow(a, p - 2, p); }

# Returns the modular inverse of a prime modulo p.
# Use built-in pow function.
def inverse(a, p):
    return pow(a, p - 2, p)

Of course, in theory this method can be generalized to the case of a general modulus \(m\) using Euler's theorem, i.e. the inverse can be computed as \(a^{\varphi(m)-1}\bmod m\). However, computing Euler's totient function \(\varphi(m)\) for a single value is not easy, so this algorithm is not efficient in the general case.

Computing several inverses

In some scenarios, it is necessary to quickly compute the inverses of several integers \(a_1,a_2,\cdots,a_n\) modulo \(m\). Computing the inverses one by one takes \(O(n\log m)\) time in total. In fact, if they are processed together, the inverses of all the integers can be computed in \(O(n+\log m)\) time.

Consider the prefix products of the sequence \(\{a_i\}\):

\[ S_0 = 1,~ S_i = a_iS_{i-1},~ i=1,2,\cdots,n. \]

As long as every \(a_i\) is coprime to \(m\), their product \(S_n\) is coprime to \(m\). Therefore, the value \(S_n^{-1}\bmod m\) can be computed by the algorithm described above. Since the inverse of a product is the product of the inverses, starting from \(S_n^{-1}\) and traversing the sequence backwards, the inverse of every \(S_i\) can be computed:

\[ S_{i-1}^{-1} = a_iS_i^{-1} \bmod m,~ i = n,n-1,\cdots,1. \]

From this, the inverse of a single \(a_i\) can be computed by the following formula:

\[ a_i^{-1} = S_{i-1}S_i^{-1} \bmod m,~ i = 1,2,\cdots,n. \]

A reference implementation follows:

Reference implementation 
// Returns the modular inverses for each x in a modulo m.
// Assume x mod m exists for each x in a.
std::vector<int> batch_inverse(const std::vector<int>& a, int m) {
  int n = a.size();
  std::vector<int> prod(n);
  long long s = 1;
  for (int i = 0; i < n; ++i) {
    // prod[i] = product of a[0...i-1]; prod[0] = 1.
    prod[i] = s;
    s = s * a[i] % m;
  }
  // s = product of all elements in a.
  s = inverse(s, m);
  std::vector<int> res(n);
  for (int i = n - 1; i >= 0; --i) {
    res[i] = s * prod[i] % m;
    s = s * a[i] % m;
  }
  return res;
}

# Returns the modular inverses for each x in a modulo m.
# Assume x mod m exists for each x in a.
def batch_inverse(a, m):
    n = len(a)
    prod = [0] * n
    s = 1
    for i in range(n):
        # prod[i] = product of a[0...i-1]; prod[0] = 1.
        prod[i] = s
        s = s * a[i] % m
    # s = product of all elements in a.
    s = inverse(s, m)
    res = [0] * n
    for i in reversed(range(n)):
        res[i] = s * prod[i] % m
        s = s * a[i] % m
    return res

In the algorithm, the inverse of a single element is computed only once, so the total time complexity is \(O(n+\log m)\).

Precomputing inverses in linear time

If the inverses of the first \(n\) positive integers modulo a prime \(p\) need to be precomputed, this can also be done in \(O(n)\) time through the recurrence discussed in this section. This method is often used in binomial coefficient computations to precompute the inverses of the factorials of the first \(n\) positive integers.

For a positive integer \(i\) with \(1< i < p\), consider division with remainder:

\[ p = \left\lfloor \dfrac{p}{i} \right\rfloor i + (p\bmod i). \]

Taking this equation modulo the prime \(p\), we get

\[ 0 \equiv \left\lfloor \dfrac{p}{i} \right\rfloor i + (p\bmod i) \pmod p. \]

Multiplying both sides by \(i^{-1}(p\bmod i)^{-1}\) gives

\[ i^{-1} \equiv - \left\lfloor \dfrac{p}{i} \right\rfloor (p\bmod i)^{-1} \pmod p. \]

This is the formula used for computing inverses recursively in linear time. Since \(p\bmod i < i\), this formula reduces the problem of computing \(i^{-1}\bmod p\) to the smaller problem \((p\bmod i)^{-1}\bmod p\). Therefore, starting from \(1^{-1}\bmod p=1\) and applying the formula to each \(i\) in turn, the inverses of the first \(n\) integers can be obtained in \(O(n)\) time.

A reference implementation follows:

Reference implementation 
// Precomputes modular inverses of all integers from 1 to n modulo prime p.
std::vector<int> precompute_inverses(int n, int p) {
  std::vector<int> res(n + 1);
  res[1] = 1;
  for (int i = 2; i <= n; ++i) {
    res[i] = (long long)(p - p / i) * res[p % i] % p;
  }
  return res;
}

# Precomputes modular inverses of all integers from 1 to n modulo prime p.
def precompute_inverses(n, p):
    res = [0] * (n + 1)
    res[1] = 1
    for i in range(2, n + 1):
        res[i] = (p - p // i) * res[p % i] % p
    return res

This algorithm applies only when the modulus is prime. When the modulus \(m\) is not prime, there is no guarantee that the \(m\bmod i\) obtained in the recurrence is still coprime to \(m\), so the \((m\bmod i)^{-1}\) required by the recurrence may not exist. One such example is \(m=8,i=3\). In that case \(m\bmod i = 2\), which has no inverse modulo \(m\).

Moreover, once this recurrence is obtained, a natural idea is to compute the inverse of an arbitrary number \(a\) directly by recursion. At each step of the recursion, the formula reduces it to the inverse of the smaller remainder \(p\bmod a\), stopping when the remainder becomes \(1\). The complexity of doing so is currently unknown1, so it is recommended to use the conventional methods described above.
