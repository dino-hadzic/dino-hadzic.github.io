U ovom se članku razmatra rješavanje linearnih kongruencija.

Osnovni pojmovi

Neka su \(a,b,n\) cijeli brojevi, a \(x\) nepoznanica. Tada se jednadžba oblika

\[ ax\equiv b\pmod n \]

naziva linearna kongruencija (linear congruence equation).

Riješiti linearnu kongruenciju znači naći sva rješenja \(x\) u intervalu \([0,n-1]\). Dakako, dodavanjem ili oduzimanjem proizvoljnog višekratnika od \(n\) i dalje dobivamo rješenja jednadžbe. Modulo \(n\) to su sva rješenja te jednadžbe.

U nastavku članka predstavljamo dva pristupa rješavanju linearnih kongruencija, koji redom koriste inverze i diofantske jednadžbe. U općem slučaju i računanje inverza i rješavanje diofantskih jednadžbi zahtijevaju prošireni Euklidov algoritam, pa su ta dva pristupa zapravo jednaka.

Rješavanje pomoću inverza

Najprije promotrimo slučaj kad su \(a\) i \(n\) relativno prosti, tj. slučaj \(\gcd(a,n)=1\). Tada možemo izračunati inverz \(a^{-1}\) broja \(a\) i pomnožiti obje strane jednadžbe s \(a^{-1}\), čime dobivamo jedinstveno rješenje jednadžbe:

\[ x \equiv ba^{-1} \pmod n. \]

Zatim promotrimo slučaj kad \(a\) i \(n\) nisu relativno prosti, tj. slučaj \(\gcd(a,n)=d>1\). Tada izvorna jednadžba ne mora imati rješenje. Na primjer, \(2x\equiv 1\pmod 4\) nema rješenja. Stoga treba razmotriti dva slučaja:

  • Kad \(d\) ne dijeli \(b\), jednadžba nema rješenja. Za svaki \(x\) lijeva strana \(ax\) višekratnik je od \(d\), ali desna strana \(b\) nije višekratnik od \(d\). Stoga se ne mogu razlikovati za višekratnik od \(n\), jer je svaki višekratnik od \(n\) ujedno višekratnik od \(d\). Dakle, jednadžba nema rješenja.

  • Kad \(d\) dijeli \(b\), parametre \(a,b,n\) jednadžbe možemo podijeliti s \(d\) i dobiti novu jednadžbu:

    \[ a'x \equiv b'\pmod{n'}. \]

    Pritom je \(\gcd(a',n')=1\), tj. \(a'\) i \(n'\) relativno su prosti. Taj je slučaj već riješen gore, pa računanjem inverza možemo dobiti najmanje nenegativno cjelobrojno rješenje \(x'\) te jednadžbe.

    Očito je \(x'\) ujedno rješenje izvorne jednadžbe. No to nije jedino rješenje izvorne jednadžbe. Budući da je skup svih rješenja transformirane jednadžbe

    \[ \{x' + kn' : k\in\mathbf Z\}. \]

    ona od tih rješenja koja padaju u interval \([0,n-1]\) upravo su sva rješenja izvorne jednadžbe u intervalu \([0,n-1]\):

    \[ x \equiv (x' + kn')\pmod{n},\quad k = 0, 1, \cdots, d-1. \]

Sažimajući oba slučaja, broj rješenja linearne kongruencije jednak je \(d=\gcd(a,n)\) ili \(0\).

Rješavanje pomoću diofantske jednadžbe

Linearna kongruencija ekvivalentna je linearnoj diofantskoj jednadžbi s dvije nepoznanice \(x,y\):

\[ ax + ny = b. \]

Prema razmatranju na navedenoj stranici, jednadžba ima rješenje ako i samo ako \(\gcd(a,n)\mid b\), a njezino je opće rješenje

\[ \begin{aligned} x &= x_0 + t\dfrac{n}{d},\\ y &= y_0 - t\dfrac{a}{d}, \end{aligned} \]

gdje je \(d=\gcd(a,n)\) njihov najveći zajednički djelitelj, a \(t\) proizvoljan cijeli broj.

Stoga je opće rješenje linearne kongruencije

\[ x \equiv \left(x_0+t\dfrac{n}{d}\right)\pmod{n},\quad t\in\mathbf Z. \]

Uzimanjem \(x_0\) modulo \(n/d\) dobivamo najmanje (nenegativno) cjelobrojno rješenje kongruencije, tj. gore spomenuti \(x'\).

Referentna implementacija

Referentna implementacija u ovom odjeljku daje najmanje nenegativno cjelobrojno rješenje kongruencije. Ako rješenje ne postoji, ispisuje \(-1\).

Referentna implementacija 
// Extended Euclidean Algorithm.
// Finds integers x, y such that a*x + b*y = gcd(a, b),
// and returns gcd(a, b).
int ex_gcd(int a, int b, int& x, int& y) {
  if (!b) {
    x = 1;
    y = 0;
    return a;
  } else {
    int d = ex_gcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
  }
}

// Solves the linear congruence equation:
//     a * x ≡ b (mod n), where n > 0.
// Returns the smallest non-negative solution x,
// or -1 if there is no solution.
int solve_linear_congruence_equation(int a, int b, int n) {
  int x, y;
  int d = ex_gcd(a, n, x, y);
  if (b % d) return -1;
  n /= d;
  return ((long long)x * (b / d) % n + n) % n;
}

def ex_gcd(a, b):
    """
    Extended Euclidean Algorithm.
    Finds integers x, y such that a*x + b*y = gcd(a, b),
    and returns (gcd, x, y).
    """
    if b == 0:
        return a, 1, 0
    d, x1, y1 = ex_gcd(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return d, x, y


def solve_linear_congruence_equation(a, b, n):
    """
    Solves the linear congruence equation:
        a * x ≡ b (mod n), where n > 0.
    Returns the smallest non-negative solution x,
    or -1 if there is no solution.
    """
    d, x, y = ex_gcd(a, n)
    if b % d != 0:
        return -1
    n //= d
    return (x * (b // d) % n + n) % n

This article discusses solving linear congruences.

Basic concepts

Let \(a,b,n\) be integers and \(x\) an unknown. Then an equation of the form

\[ ax\equiv b\pmod n \]

is called a linear congruence equation.

Solving a linear congruence means finding all solutions \(x\) in the interval \([0,n-1]\). Of course, adding or subtracting any multiple of \(n\) still gives solutions of the equation. Modulo \(n\), these are all the solutions of the equation.

The rest of this article introduces two approaches to solving linear congruences, using inverses and Diophantine equations, respectively. In the general case, both computing inverses and solving Diophantine equations require the extended Euclidean algorithm, so the two approaches are in fact the same.

Solving with inverses

First, consider the case where \(a\) and \(n\) are coprime, i.e. \(\gcd(a,n)=1\). In this case we can compute the inverse \(a^{-1}\) of \(a\) and multiply both sides of the equation by \(a^{-1}\), which gives the unique solution of the equation:

\[ x \equiv ba^{-1} \pmod n. \]

Next, consider the case where \(a\) and \(n\) are not coprime, i.e. \(\gcd(a,n)=d>1\). In this case the original equation does not necessarily have a solution. For example, \(2x\equiv 1\pmod 4\) has no solution. Therefore, two cases need to be considered:

  • When \(d\) does not divide \(b\), the equation has no solution. For any \(x\), the left-hand side \(ax\) is a multiple of \(d\), but the right-hand side \(b\) is not a multiple of \(d\). Therefore, they cannot differ by a multiple of \(n\), because any multiple of \(n\) is also a multiple of \(d\). So the equation has no solution.

  • When \(d\) divides \(b\), the parameters \(a,b,n\) of the equation can all be divided by \(d\), giving a new equation:

    \[ a'x \equiv b'\pmod{n'}. \]

    Here \(\gcd(a',n')=1\), that is, \(a'\) and \(n'\) are coprime. This case has already been solved above, so the smallest non-negative integer solution \(x'\) of the equation can be obtained by computing an inverse.

    Obviously, \(x'\) is also a solution of the original equation. But it is not the only solution of the original equation. Since the set of all solutions of the transformed equation is

    \[ \{x' + kn' : k\in\mathbf Z\}. \]

    those of these solutions that fall in the interval \([0,n-1]\) are exactly all the solutions of the original equation in the interval \([0,n-1]\):

    \[ x \equiv (x' + kn')\pmod{n},\quad k = 0, 1, \cdots, d-1. \]

Summarizing the two cases, the number of solutions of a linear congruence equals \(d=\gcd(a,n)\) or \(0\).

Solving with Diophantine equations

A linear congruence is equivalent to the linear Diophantine equation in two variables \(x,y\):

\[ ax + ny = b. \]

By the discussion on the linked page, the equation has a solution if and only if \(\gcd(a,n)\mid b\), and the general solution of the equation is

\[ \begin{aligned} x &= x_0 + t\dfrac{n}{d},\\ y &= y_0 - t\dfrac{a}{d}, \end{aligned} \]

where \(d=\gcd(a,n)\) is their greatest common divisor and \(t\) is an arbitrary integer.

Hence, the general solution of the linear congruence is

\[ x \equiv \left(x_0+t\dfrac{n}{d}\right)\pmod{n},\quad t\in\mathbf Z. \]

Taking \(x_0\) modulo \(n/d\) gives the smallest (non-negative) integer solution of the congruence, i.e. the \(x'\) above.

Reference implementation

The reference implementation given in this section finds the smallest non-negative integer solution of the congruence. If no solution exists, it outputs \(-1\).
