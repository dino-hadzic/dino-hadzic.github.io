Predznanje: blokovsko dijeljenje po cjelobrojnom kvocijentu, Dirichletova konvolucija

Möbiusova inverzija važan je dio teorije brojeva. Ako je za neku funkciju \(f(n)\) teško izravno izračunati vrijednost, a lako je izračunati zbroj po višekratnicima ili zbroj po djeliteljima \(g(n)\), Möbiusovom inverzijom može se pojednostavniti račun i dobiti vrijednost \(f(n)\).

Möbiusova funkcija

Möbiusova funkcija (Möbius function) definira se kao

\[ \mu(n)= \begin{cases} 1,&n=1,\\ 0,&n\text{ is divisible by a square }>1,\\ (-1)^k,&n\text{ is the product of }k\text{ distinct primes}.\\ \end{cases} \]

Konkretno, neka pozitivan cijeli broj \(n\) ima rastav na proste faktore \(n=\prod_{i=1}^kp_i^{e_i}\), gdje su \(p_i\) prosti brojevi, a \(e_i\) pozitivni cijeli brojevi. Tada tri slučaja redom odgovaraju sljedećem:

  1. \(\mu(1) = 1\);
  2. ako postoji \(i\) takav da je \(e_i > 1\), tj. ako se bilo koji prosti faktor pojavljuje više od jednom, onda je \(\mu(n)=0\);
  3. inače, ako je \(e_i = 1\) za sve \(i\), tj. svaki se prosti faktor pojavljuje točno jednom, onda je \(\mu(n)=(-1)^k\), gdje je \(k\) broj različitih prostih faktora.

Svojstva

Prema definiciji lako se provjerava da je Möbiusova funkcija \(\mu(n)\) multiplikativna, ali ne i potpuno multiplikativna. Osim toga, najvažnije je svojstvo sljedeći identitet:

Svojstvo

Za pozitivan cijeli broj \(n\) vrijedi

\[ \sum_{d\mid n}\mu(d) = [n = 1] = \begin{cases} 1,&n=1,\\ 0,&n\neq 1.\\ \end{cases} \]

Pritom je \([\cdot]\) Iversonova zagrada.

Dokaz

Neka je \(n=\prod_{i=1}^kp_i^{e_i}\) i neka je \(n' = \prod_{i=1}^kp_i\). Prema binomnom teoremu vrijedi

\[ \sum_{d\mid n}\mu(d) = \sum_{d\mid n'}\mu(d) = \sum_{i=0}^k\binom{k}{i}(-1)^i = (1 + (-1))^k = [k = 0] = [n = 1]. \]

Pomoću Dirichletove konvolucije ovaj se izraz može zapisati kao \(\varepsilon = 1 * \mu\). Drugim riječima, Möbiusova funkcija Dirichletov je inverz konstantne funkcije \(1\).

Ovo svojstvo ima vrlo čestu primjenu:

\[ [i\perp j] = [\gcd(i,j) = 1] = \sum_{d\mid\gcd(i,j)} \mu(d) = \sum_{d}[d\mid i][d\mid j]\mu(d). \]

Ono pretvara uvjet relativne prostosti u sumu po Möbiusovoj funkciji, što olakšava daljnje izvođenje.

Računanje

Ako treba izračunati vrijednost Möbiusove funkcije \(\mu(n)\) za jedan \(n\), može se iskoristiti njegov rastav na proste faktore. Primjerice, kada \(n\) nije prevelik, \(\mu(n)\) se može izračunati u vremenu \(O(\sqrt{n})\).

Referentna implementacija 
int mu(int n) {
  int res = 1;
  for (int i = 2; i * i <= n; ++i) {
    if (n % i == 0) {
      n /= i;
      // Check if square-free.
      if (n % i == 0) return 0;
      res = -res;
    }
  }
  // The remaining factor must be prime.
  if (n > 1) res = -res;
  return res;
}

def mu(n):
    res = 1
    i = 2
    while i * i <= n:
        if n % i == 0:
            n //= i
            # Check if square-free
            if n % i == 0:
                return 0
            res = -res
        i += 1
    # The remaining factor must be prime
    if n > 1:
        res = -res
    return res

Ako treba unaprijed izračunati vrijednosti \(\mu(n)\) za prvih \(n\) pozitivnih cijelih brojeva, može se iskoristiti to što je ona multiplikativna i izračunati ih linearnim sitom u vremenu \(O(n)\).

Referentna implementacija 
std::vector<int> get_mu(int n) {
  std::vector<int> mu(n + 1), primes;
  std::vector<bool> not_prime(n + 1);
  primes.reserve(n);
  mu[1] = 1;
  for (int x = 2; x <= n; ++x) {
    if (!not_prime[x]) {
      primes.push_back(x);
      mu[x] = -1;
    }
    for (int p : primes) {
      if (x * p > n) break;
      not_prime[x * p] = true;
      if (x % p == 0) {
        mu[x * p] = 0;
        break;
      } else {
        mu[x * p] = -mu[x];
      }
    }
  }
  return mu;
}

def get_mu(n):
    mu = [0] * (n + 1)
    primes = []
    not_prime = [False] * (n + 1)

    mu[1] = 1
    for x in range(2, n + 1):
        if not not_prime[x]:
            primes.append(x)
            mu[x] = -1
        for p in primes:
            if x * p > n:
                break
            not_prime[x * p] = True
            if x % p == 0:
                mu[x * p] = 0
                break
            else:
                mu[x * p] = -mu[x]
    return mu

Möbiusova inverzija

Najvažnija primjena Möbiusove funkcije jest Möbiusova inverzija.

Möbiusova inverzija

Neka su \(f(n),g(n)\) dvije aritmetičke funkcije. Tada vrijedi

\[ f(n) = \sum_{d\mid n}g(d) \iff g(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)f(d). \]
Dokaz 1

Izravnom provjerom dobivamo:

\[ \begin{aligned} \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)f(d) &= \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\sum_{k\mid d}g(k)\\ &= \sum_{k\mid n}g(k)\sum_d[k\mid d\mid n]\mu\left(\dfrac{n}{d}\right)\\ &= \sum_{k\mid n}g(k)\sum_{d\mid n}\left[\frac{n}{d}\mid\frac{n}{k}\right]\mu\left(\dfrac{n}{d}\right)\\ &= \sum_{k\mid n}g(k)\left[\frac{n}{k} = 1\right] \\ &= g(n). \end{aligned} \]

Ključ preoblikovanja jest zamjena redoslijeda sumiranja i opažanje da je \(k\mid d\mid n\) ekvivalentno s \(\dfrac{n}{d}\mid\dfrac{n}{k}\). Pretposljednja jednakost odgovara sumiranju Möbiusove funkcije po djeliteljima \(\dfrac{n}{d}\) broja \(\dfrac{n}{k}\), pa je jednaka \(\left[\dfrac{n}{k} = 1\right]\). Taj je izraz različit od \(0\) samo za \(n=k\), pa na kraju dobivamo \(g(n)\).

Dokaz 2

Pomoću Dirichletove konvolucije tvrdnja je ekvivalentna s

\[ f = 1 * g \iff g = \mu * f. \]

Pomoću \(1 * \mu = \varepsilon\), konvolucijom obiju strana lijeve jednakosti s \(\mu\) dobivamo

\[ f * \mu = (1 * g) * \mu = (1 * \mu) * g = \varepsilon * g = g. \]

U sumiranju aritmetičkih funkcija koje uključuje razne relacije djeljivosti Möbiusova inverzija moćan je alat za preoblikovanje.

Primjer

  1. Eulerova funkcija \(\varphi(n)\) zadovoljava relaciju \(n = \sum_{d\mid n}\varphi(d)\), tj. \(\mathrm{id}=1*\varphi\). Inverzijom dobivamo \(\varphi = \mu * \mathrm{id}\), tj.

    \[ \varphi(n) = \sum_{d\mid n}d\mu\left(\dfrac{n}{d}\right). \]

  2. Funkcija djelitelja \(\sigma_k(n) = \sum_{d\mid n}d^k\), tj. \(\sigma_k = 1 * \mathrm{id}_k\). Inverzijom dobivamo \(\mathrm{id}_k = \mu * \sigma_k\), tj.

    \[ n^k = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\sigma_k(d). \]

  3. Funkcija broja različitih prostih faktora \(\omega(n)=\sum_{d\mid n}[d\in\mathbf P]\), tj. \(\omega = 1* \mathbf{1}_{\mathbf P}\), gdje je \(\mathbf{1}_{\mathbf P}\) indikatorska funkcija skupa prostih brojeva \(\mathbf P\). Inverzijom dobivamo \(\mathbf{1}_{\mathbf P} = \mu * \omega\), tj.

    \[ [n\in\mathbf P] = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\omega(d). \]

  4. Promotrimo aritmetičku funkciju \(\Lambda(n)\) koja zadovoljava \(\log n = \sum_{d\mid n}\Lambda(d)\). To je Möbiusova inverzija logaritamske funkcije, a naziva se i von Mangoldtova funkcija:

    \[ \Lambda(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\log d = \begin{cases} \log p, & n = p^e,~p\in\mathbf P,~e\in\mathbf N_+, \\ 0, &\text{otherwise}. \end{cases} \]
Dodatak: dokaz izraza za \(\Lambda(n)\)

Za potenciju prostog broja \(n=p^e~(e\in\mathbf N_+)\) vrijedi

\[ \Lambda(n) = \sum_{i=0}^e\mu(p^{e-i})\log p^i = \log p^{e} - \log p^{e-1} = \log p. \]

Za \(n=1\) očito je \(\Lambda(n)=\log 1=0\). Za ostale složene brojeve \(n\) vrijedi

\[ \Lambda(n) = \sum_{d\mid n}\mu(d)(\log n-\log d) = \left(\sum_{d\mid n}\mu(d)\right)\log n-\sum_{d\mid n}\mu(d)\log d. \]

Prema svojstvu Möbiusove funkcije, koeficijent uz \(\log n\) jednak je \([n=1]=0\). Za drugi član, \(d\) se može dalje rastaviti na umnožak prostih faktora. Za bilo koji prost broj \(p\mid n\) neka je \(n=p^em\) i \(p\perp m\) (budući da \(n\) nije potencija prostog broja, \(m>1\)); promotrimo koeficijent uz \(\log p\) (doprinose samo \(d\) bez kvadratnih faktora):

\[ -\sum_{p\mid d\mid n}\mu(d) = -\sum_{d'\mid m}\mu(pd') = \sum_{d'\mid m}\mu(d') = [m=1]=0. \]

Stoga za složene brojeve \(n\) s više od jednog prostog faktora vrijedi \(\Lambda(n)=0\).

Prošireni oblici

Osim gornjeg osnovnog oblika, Möbiusova inverzija ima i nekoliko čestih proširenih oblika. Najprije razmotrimo njezin oblik sa zbrojem po višekratnicima.

Proširenje 1

Neka su \(f(n),g(n)\) dvije aritmetičke funkcije. Tada vrijedi

\[ f(n) = \sum_{n\mid d}g(d) \iff g(n) = \sum_{n\mid d}\mu\left(\dfrac{d}{n}\right)f(d). \]
Dokaz

Izravnom provjerom dobivamo:

\[ \begin{aligned} \sum_{n\mid d}\mu\left(\dfrac{d}{n}\right)f(d) &= \sum_{n\mid d}\mu\left(\dfrac{d}{n}\right)\sum_{d\mid k}g(k)\\ &= \sum_{n\mid k}g(k)\sum_{d}[n\mid d\mid k]\mu\left(\dfrac{d}{n}\right)\\ &= \sum_{n\mid k}g(k)\sum_{n\mid d}\left[\dfrac{d}{n}\mid\dfrac{k}{n}\right]\mu\left(\dfrac{d}{n}\right)\\ &= \sum_{n\mid k}g(k)\left[\dfrac{k}{n}=1\right]\\ &= g(n). \end{aligned} \]

To je potpuno dualno izvodu osnovnog oblika.

Drugo, Möbiusova inverzija nije ograničena na zbrajanje; ona zapravo vrijedi za operaciju u bilo kojoj Abelovoj grupi. Primjerice, ima sljedeći multiplikativni oblik:

Proširenje 2

Neka su \(f(n),g(n)\) dvije aritmetičke funkcije. Tada vrijedi

\[ f(n) = \prod_{d\mid n}g(d) \iff g(n) = \prod_{d\mid n}f(d)^{\mu(n/d)}. \]
Dokaz

Izravnom provjerom dobivamo:

\[ \begin{aligned} \prod_{d\mid n}f(d)^{\mu(n/d)} &= \prod_{d\mid n}\left(\prod_{k\mid d}g(k)\right)^{\mu(n/d)}\\ &= \prod_{k\mid n}g(k)\uparrow\left(\sum_d[k\mid d\mid n]\mu\left(\dfrac{n}{d}\right)\right)\\ &= \prod_{k\mid n}g(k)\uparrow\left(\sum_{d\mid n}\left[\frac{n}{d}\mid\frac{n}{k}\right]\mu\left(\dfrac{n}{d}\right)\right)\\ &= \prod_{k\mid n}g(k)\uparrow\left[\frac{n}{k} = 1\right] \\ &= g(n). \end{aligned} \]

Pritom je \(a\uparrow b = a^b\) Knuthova strelica. Usporedbom s dokazom osnovnog oblika vidi se da je jedina razlika to što je zbrajanje zamijenjeno množenjem, a množenje potenciranjem.

Iz perspektive Dirichletove konvolucije, Möbiusova inverzija koristi samo činjenicu da je „Möbiusova funkcija Dirichletov inverz konstantne funkcije”. Lako je zamisliti da relacije slične Möbiusovoj inverziji vrijede i za opći Dirichletov inverz.

Proširenje 3

Neka su \(f(n),g(n),\alpha(n)\) aritmetičke funkcije i neka je \(\alpha^{-1}(n)\) Dirichletov inverz od \(\alpha(n)\), tj.

\[ [n=1] = \sum_{d\mid n}\alpha\left(\dfrac{n}{d}\right)\alpha^{-1}(d). \]

Tada vrijedi

\[ f(n) = \sum_{d\mid n}\alpha\left(\dfrac{n}{d}\right)g(d) \iff g(n) = \sum_{d\mid n}\alpha^{-1}\left(\dfrac{n}{d}\right)f(d). \]
Dokaz

Izravnom provjerom dobivamo:

\[ \begin{aligned} \sum_{d\mid n}\alpha^{-1}\left(\dfrac{n}{d}\right)f(d) &= \sum_{d\mid n}\alpha^{-1}\left(\dfrac{n}{d}\right)\sum_{k\mid d}\alpha\left(\dfrac{d}{k}\right)g(k)\\ &= \sum_{k\mid n}g(k)\sum_d[k\mid d\mid n]\alpha\left(\dfrac{d}{k}\right)\alpha^{-1}\left(\dfrac{n}{d}\right)\\ &= \sum_{k\mid n}g(k)\sum_{d\mid n}\left[\frac{n}{d}\mid\frac{n}{k}\right]\alpha\left(\dfrac{d}{k}\right)\alpha^{-1}\left(\dfrac{n/k}{d/k}\right)\\ &= \sum_{k\mid n}g(k)\left[\frac{n}{k} = 1\right] \\ &= g(n). \end{aligned} \]

U usporedbi s dokazom osnovnog oblika, treba samo pretposljednju jednakost zamijeniti definicijskom formulom Dirichletova inverza.

Korolar

Neka su \(f(n),g(n)\) aritmetičke funkcije i neka je \(t(n)\) potpuno multiplikativna funkcija. Tada vrijedi

\[ f(n) = \sum_{d\mid n}t\left(\dfrac{n}{d}\right)g(d) \iff g(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)t\left(\dfrac{n}{d}\right)f(d). \]
Dokaz

Prema svojstvima Dirichletove konvolucije, Dirichletov inverz potpuno multiplikativne funkcije \(t(n)\) jest \(\mu(n)t(n)\).

Naposljetku, Möbiusova inverzija može se poopćiti i na kompleksne funkcije na \([1,+\infty)\), a ne samo na aritmetičke funkcije. Osnovni oblik Möbiusove inverzije može se shvatiti kao poseban slučaj u kojem kompleksna funkcija u svim necjelobrojnim točkama ima vrijednost nula.

Proširenje 4

Neka su \(F(x)\) i \(G(x)\) kompleksne funkcije na \([1,+\infty)\). Tada vrijedi

\[ F(x) = \sum_{n = 1}^{\lfloor x\rfloor}G\left(\dfrac{x}{n}\right) \iff G(x) = \sum_{n = 1}^{\lfloor x\rfloor}\mu(n)F\left(\dfrac{x}{n}\right). \]
Dokaz

Bez smanjenja općenitosti proširimo definicije \(F\) i \(G\) tako da za \(x < 1\) uvijek vrijedi \(F(x)=G(x)=0\). Tada je tvrdnja ekvivalentna s:

\[ F(x) = \sum_n G\left(\dfrac{x}{n}\right) \iff G(x) = \sum_n \mu(n)F\left(\dfrac{x}{n}\right). \]

Sve se ove sume uzimaju po \(n\in\mathbf N_+\).

Izravnom provjerom dobivamo:

\[ \begin{aligned} \sum_n \mu(n)F\left(\dfrac{x}{n}\right) &= \sum_n\mu(n)\sum_d G\left(\dfrac{x/n}{d}\right)\\ &= \sum_k G\left(\dfrac{x}{k}\right)\sum_{n\mid k}\mu(n)\\ &= \sum_k G\left(\dfrac{x}{k}\right)[k=1]\\ &= G(x). \end{aligned} \]

Pritom za drugu jednakost treba staviti \(k = nd\).

Korolar

Neka su \(f(n),g(n)\) aritmetičke funkcije. Tada vrijedi

\[ f(n) = \sum_{k=1}^ng\left(\left\lfloor\dfrac{n}{k}\right\rfloor\right) \iff g(n)=\sum_{k=1}^n\mu(k)f\left(\left\lfloor\dfrac{n}{k}\right\rfloor\right). \]
Dokaz

Dovoljno je uzeti \(F(x)=f(\lfloor x\rfloor)\) i \(G(x)=g(\lfloor x\rfloor)\).

Ovi se prošireni oblici mogu međusobno kombinirati, čime se dobivaju složenije relacije inverzije.

Dirichletove prefiksne sume

Predznanje: Prefiksne sume i razlike

Promotrimo osnovni oblik Möbiusove inverzije:

\[ f(n) = \sum_{d\mid n}g(d) \iff g(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)f(d). \]

U lijevoj jednakosti vrijednost \(f(n)\) zbroj je vrijednosti \(g\) u svim djeliteljima od \(n\). Ako \(a\mid b\) shvatimo kao „\(a\) je poredan prije \(b\)”, onda se \(f(n)\) može shvatiti kao prefiksna suma od \(g(n)\) u određenom smislu. Zato se u kineskoj natjecateljskoj zajednici postupak računanja \(\{f(k)\}_{k=1}^n\) iz \(\{g(k)\}_{k=1}^n\) naziva i Dirichletova prefiksna suma, a odgovarajući obrnuti postupak Dirichletova razlika. Ove se metode uglavnom pojavljuju kada treba unaprijed izračunati vrijednosti neke aritmetičke funkcije u prvih \(N\) točaka.

Razmotrimo sada računanje Dirichletovih prefiksnih suma. Ako svaki prost broj promatramo kao jednu dimenziju, riječ je o vrsti višedimenzionalnih prefiksnih suma. Prisjetimo se algoritma prefiksnih suma dimenziju po dimenziju za višedimenzionalne prefiksne sume: prolazimo redom sve dimenzije i vrijednost na svakoj poziciji pribrajamo sljedbeniku te pozicije u toj dimenziji. Za aritmetičke funkcije to znači: prolazimo sve proste brojeve \(p\) od manjih prema većima i vrijednost funkcije u \(n\) pribrajamo vrijednosti u \(np\). To je isti redoslijed obilaska kao u Eratostenovu situ. Stoga ovaj algoritam računa Dirichletovu prefiksnu sumu niza duljine \(n\) u vremenu \(O(n\log\log n)\). Slično, razlikama dimenziju po dimenziju može se u istoj vremenskoj složenosti izračunati Dirichletova razlika niza.

Referentna implementacija 
std::vector<int> dirichlet_presum(const std::vector<int>& g) {
  int n = g.size() - 1;
  std::vector<int> f(g);
  std::vector<bool> vis(n + 1);
  for (int x = 2; x <= n; ++x) {
    if (vis[x]) continue;
    for (int y = 1, xy = x; xy <= n; ++y, xy += x) {
      vis[xy] = true;
      f[xy] += f[y];
    }
  }
  return f;
}

std::vector<int> dirichlet_diff(const std::vector<int>& f) {
  int n = f.size() - 1;
  std::vector<int> g(f);
  std::vector<int> vis(n + 1);
  for (int x = 2; x <= n; ++x) {
    if (vis[x]) continue;
    for (int y = n / x, xy = x * y; y; --y, xy -= x) {
      vis[xy] = true;
      g[xy] -= g[y];
    }
  }
  return g;
}

Ova se metoda računanja može poopćiti na zbroj po višekratnicima (proširenje 1), multiplikativni oblik (proširenje 2), zamjenu konstantne funkcije potpuno multiplikativnom funkcijom (korolar proširenja 3) i druge proširene oblike.

Primjeri zadataka

Ovaj odjeljak kroz primjere zadataka pokazuje način primjene Möbiusove inverzije i neke česte tehnike preoblikovanja. Najprije se kroz jedan zadatak upoznajemo s osnovnom tehnikom obrade uvjeta s najvećim zajedničkim djeliteljem u sumama.

Luogu P2522 [HAOI 2011] Problem b

\(T\) skupova podataka. Za svaki skup izračunajte:

\[ \sum_{i=x}^{n}\sum_{j=y}^{m}[\gcd(i,j)=k]. \]

Ograničenja: \(1\le T,x,y,n,m,k\le 5\times 10^4\).

Rješenje

Prema načelu uključivanja-isključivanja, izvorni izraz može se razbiti na \(4\) dijela, a izraz svakog dijela ima oblik

\[ f(n,m,k)=\sum_{i=1}^{n}\sum_{j=1}^{m}[\gcd(i,j)=k]. \]

Za takve izraze slijedi standardni postupak izvođenja: izlučivanje zajedničkog faktora, primjena svojstva Möbiusove funkcije, zamjena redoslijeda sumiranja.

Najprije, budući da \(i,j\) mogu biti samo višekratnici od \(k\), taj se faktor može izlučiti – to odgovara uvrštavanju \(i=ki'\) i \(j=kj'\), čime dobivamo:

\[ f(n,m,k)=\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor m/k\rfloor}[\gcd(i,j)=1]. \]

Zatim prema svojstvu Möbiusove funkcije vrijedi:

\[ [\gcd(i,j)=1] = \sum_{d\mid\gcd(i,j)}\mu(d) = \sum_d[d\mid i][d\mid j]\mu(d). \]

Uvrštavanjem u izraz i zamjenom redoslijeda sumiranja dobivamo:

\[ f(n,m,k)=\sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/k\rfloor}[d\mid i]\right)\left(\sum_{j=1}^{\lfloor m/k\rfloor}[d\mid j]\right). \]

Prednost ovog postupka jest to što se, za fiksni \(d\), članovi sume koji ovise o \(i\) i o \(j\) međusobno razdvajaju pa se mogu zbrajati zasebno. Dalje, budući da je

\[ \sum_{i=1}^{\lfloor n/k\rfloor}[d\mid i] = \left\lfloor\dfrac{\lfloor n/k\rfloor}{d}\right\rfloor,~\sum_{j=1}^{\lfloor m/k\rfloor}[d\mid j]=\left\lfloor\dfrac{\lfloor m/k\rfloor}{d}\right\rfloor, \]

vrijedi

\[ f(n,m,k)=\sum_d\mu(d)\left\lfloor\dfrac{\lfloor n/k\rfloor}{d}\right\rfloor\left\lfloor\dfrac{\lfloor m/k\rfloor}{d}\right\rfloor. \]

Nakon što linearnim sitom unaprijed izračunamo \(\mu(d)\) i njegove prefiksne sume, zadatak se rješava blokovskim dijeljenjem po cjelobrojnom kvocijentu. Ukupna vremenska složenost iznosi \(O(N + T\sqrt{N})\), gdje je \(N\) gornja granica za \(n,m\), a \(T\) broj skupova podataka.

SPOJ LCMSUM

\(T\) skupova podataka. Za svaki skup izračunajte:

\[ \sum_{i=1}^n \operatorname{lcm}(i,n). \]

Ograničenja: \(1\le T\le 3\times 10^5,~1\le n\le 10^6\).

Rješenje 1

Zadatak daje najmanji zajednički višekratnik, ali je najveći zajednički djelitelj često lakše obraditi. Stoga najprije preoblikujemo:

\[ f(n)=\sum_{i=1}^n \operatorname{lcm}(i,n) = \sum_{i=1}^n \frac{i\cdot n}{\gcd(i,n)}. \]

Izlučimo \(n\) i iterirajmo po najvećem zajedničkom djelitelju \(k\):

\[ f(n)=n\sum_{k\mid n}\sum_{i=1}^n\dfrac{i}{k}[\gcd(i,n)=k]. \]

Unutarnja suma najčešći je oblik izraza s najvećim zajedničkim djeliteljem; ponavljanjem standardnog postupka dobivamo:

\[ \begin{aligned} f(n) &= n\sum_{k\mid n}\sum_{i=1}^{n/k}i\left[\gcd\left(i,\dfrac{n}{k}\right)=1\right]\\ &= n\sum_{k\mid n}\sum_{i=1}^{n/k}i\sum_d\mu(d)[d\mid i]\left[d\mid \dfrac{n}{k}\right]\\ &= n\sum_{k\mid n}\sum_d\mu(d)\left[d\mid \dfrac{n}{k}\right]\left(\sum_{i=1}^{n/k}i[d\mid i]\right). \end{aligned} \]

Ponovno se suma po \(i\) odvaja od ostatka pa se može obraditi zasebno. Posljednja suma zapravo je zbroj aritmetičkog niza (uz \(i=di'\)):

\[ \sum_{i=1}^{n/k}i[d\mid i] = d\frac{1}{2}\left(\dfrac{n}{kd}+1\right)\dfrac{n}{kd}=:dG\left(\dfrac{n}{kd}\right). \]

Time dobivamo sljedeći izraz:

\[ f(n) = n\sum_{k\mid n}\sum_d\mu(d)\left[d\mid \dfrac{n}{k}\right]dG\left(\dfrac{n}{kd}\right). \]

Nakon iteriranja po zajedničkom faktoru dvostruke sume ovakvog oblika vrlo su česte. I za njih postoji ustaljeni postupak: umnožak uvedemo kao novu varijablu \(\ell=kd\) i zatim ponovno zamijenimo redoslijed sumiranja. Budući da je \(d\mid(n/k)\) ekvivalentno s \(d\mid\ell\mid n\), izvorni se izraz pretvara u:

\[ f(n) = n\sum_{\ell\mid n}G\left(\dfrac{n}{\ell}\right)\sum_{d\mid\ell}\mu(d)d. \]

Neka je \(F(\ell)=\sum_{d\mid\ell}\mu(d)d\); tada izvorni izraz ima oblik:

\[ f(n) = n\sum_{\ell\mid n}G\left(\dfrac{n}{\ell}\right)F(\ell). \]

Budući da je \(\mu(d)d\) multiplikativna funkcija, i njezina konvolucija \(F(n)\) s konstantnom funkcijom \(1\) multiplikativna je funkcija. Iako u gornjem izrazu suma ima oblik Dirichletove konvolucije, \(G(n)\) nije multiplikativna funkcija pa ni suma u cjelini nije multiplikativna. Međutim, \(G(n)\) je polinom pa je zapravo linearna kombinacija nekoliko potpuno multiplikativnih funkcija. Stoga vrijedi

\[ f(n) = \dfrac{1}{2}n\left(\sum_{\ell\mid n}\left(\dfrac{n}{\ell}\right)^2F(\ell) + \sum_{\ell\mid n}\dfrac{n}{\ell}F(\ell)\right). \]

Oba člana (bez koeficijenata) multiplikativne su funkcije pa se mogu izravno unaprijed izračunati linearnim sitom (ili se unutarnja funkcija izračuna linearnim sitom, a zatim se Dirichletovim prefiksnim sumama sve unaprijed izračuna u vremenu \(O(N\log\log N)\)). Konkretno, neka je

\[ H_s(n) = \sum_{\ell\mid n}\left(\dfrac{n}{\ell}\right)^sF(\ell),~s=1,2. \]

Za izvođenje njihovih izraza dovoljno je odrediti njihove vrijednosti na potencijama prostih brojeva. Za prost broj \(p\) i pozitivan eksponent \(e\) vrijedi

\[ \begin{aligned} F(p^e) &= \mu(1) + \mu(p)p + \sum_{j=2}^e\mu(p^j)p^j = 1-p,\\ H_s(p^e) &= (p^e)^{s}F(1) + \sum_{j=1}^e(p^{e-j})^sF(p^j) = p^{es} + (1-p)\dfrac{1-p^{es}}{1-p^s},~s=1,2. \end{aligned} \]

Posebno, \(H_1(p^e)=1\) je konstantna funkcija, a

\[ H_2(p^e) = p^{2e} + (1-p)\dfrac{1-p^{2e}}{1-p^2} = H_2(p^{e-1}) + p^{2e} - p^{2e-1}. \]

To se lako računa linearnim sitom. Nakon što se linearnim sitom unaprijed izračuna \(H_2(n)\), pojedini se upit rješava izrazom \(f(n)=(n/2)(H_2(n)+1)\) u vremenu \(O(1)\). Ukupna vremenska složenost iznosi \(O(N+T)\), gdje je \(N\) gornja granica za \(n\), a \(T\) broj skupova podataka.

U referentnoj implementaciji, koristeći posebnost izraza u ovom zadatku, dio s linearnim sitom dodatno je izveden, što nije nužno. Samo pomoću vrijednosti na potencijama prostih brojeva predračunavanje se i dalje može obaviti u vremenu \(O(N)\). Ti su izvodi detaljno opisani u rješenju 2.

Rješenje 2

Za ovaj zadatak postoji i fleksibilniji pristup. Iz rješenja 1 vidi se da je

\[ f(n) = n\sum_{k\mid n}\sum_{i=1}^{n/k}i\left[\gcd\left(i,\dfrac{n}{k}\right)=1\right] = n\sum_{k\mid n}F\left(\dfrac{n}{k}\right). \]

Ako u ovom koraku ne nastavimo s Möbiusovom inverzijom, nego uočimo da je suma koja slijedi zapravo zbroj cijelih brojeva koji ne premašuju \(d=n/k\) i relativno su prosti s njime. Za \(d>1\), budući da se brojevi relativno prosti s \(d\) pojavljuju u parovima, tj. \(i\) i \(d-i\) nužno su istodobno relativno prosti s \(d\), vrijedi

\[ F(d)=\sum_{i=1}^{d}i[i\perp d] = \sum_{i=1}^{d}(d-i)[i\perp d] = \dfrac{1}{2}d\sum_{i=1}^{d}[i\perp d] = \dfrac{1}{2}d\varphi(d). \]

Za \(d=1\) pak vrijedi

\[ F(d)=1=\dfrac{1}{2}+\dfrac{1}{2}d\varphi(d). \]

Nadalje, izvorni se izraz može prikazati kao

\[ f(n) = \dfrac{1}{2}n\left(\sum_{d\mid n}d\varphi(d) + 1\right). \]

Budući da je \(G(n)=\sum_{d\mid n}d\varphi(d)\) Dirichletova konvolucija multiplikativne funkcije \(n\varphi(n)\) i konstantne funkcije \(1\), i ona je multiplikativna pa se može unaprijed izračunati linearnim sitom. U tu je svrhu dovoljno odrediti njezine vrijednosti na potencijama prostih brojeva. Za prost broj \(p\) i pozitivan eksponent \(e\) vrijedi

\[ G(p^e) = 1 + \sum_{i=1}^ep^i\cdot p^{i-1}(p-1) = G(p^{e-1}) + p^{2e} - p^{2e-1}. \]

Vidi se da se ovaj izraz podudara s rezultatom izvedenim u rješenju 1. Ukupna vremenska složenost ove metode i dalje je \(O(N+T)\).

Naposljetku, pomoću izraza za multiplikativnu funkciju u ovom zadatku može se dodatno optimizirati računanje u linearnom situ. Za prost broj \(p\) vrijedi

\[ G(p) = 1 - p + p^2. \]

Ključ linearnog sita jest to što za opći \(n\) treba izračunati vrijednost \(G(pn)\). To se dalje dijeli na dva slučaja. Kada je \(p\perp n\), budući da je \(G\) multiplikativna, vrijedi

\[ G(pn) = G(p)G(n). \]

Inače, kada je \(p\mid n\), neka je \(n=p^em\) uz \(p\perp m\); tada je

\[ \begin{aligned} G(pn) &= G(p^{e+1})G(m)\\ &= G(p^e)G(m) + (p^{2e+2} - p^{2e+1})G(m)\\ &= G(n) + (p^{2e+2} - p^{2e+1})G(m). \end{aligned} \]

Izravnom provjerom vidi se da ovaj izraz vrijedi i za slučaj \(p\perp n\) (tj. \(e=0\)). A kada je \(p\mid n\), vrijedi još

\[ G(n) - G\left(\dfrac{n}{p}\right) = (p^{2e}-p^{2e-1})G(m). \]

Uvrštavanjem u gornji izraz dobivamo

\[ G(pn) = G(n) + p^2\left(G(n) - G\left(\dfrac{n}{p}\right)\right). \]

To pojednostavnjuje računanje u dijelu s linearnim sitom. Dakako, ovaj izvod nije nužan; za multiplikativne funkcije bez posebnih svojstava računanje linearnim sitom može se obaviti izravno pomoću \(G(pn)=G(p^{e+1})G(m)\).

Izračunajte:

\[ \sum_{i=1}^n\sum_{j=1}^m\operatorname{lcm}(i,j)\mod{20101009}. \]

Ograničenja: \(1\le n,m\le 10^7\).

Rješenje

U izvodu zanemarujemo modul. Neka je

\[ f(n,m) = \sum_{i=1}^n\sum_{j=1}^m\operatorname{lcm}(i,j). \]

I dalje najmanji zajednički višekratnik pretvaramo u najveći zajednički djelitelj, iteriramo po zajedničkom djelitelju i primjenjujemo standardni postupak obrade, čime dobivamo

\[ \begin{aligned} f(n,m) &= \sum_k\sum_{i=1}^n\sum_{j=1}^m\dfrac{ij}{k}[\gcd(i,j)=k] \\ &= \sum_k\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor m/k\rfloor} kij[\gcd(i,j)=1]\\ &= \sum_k\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor m/k\rfloor} kij\sum_d\mu(d)[d\mid i][d\mid j]\\ &= \sum_kk\sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/k\rfloor}i[d\mid i]\right)\left(\sum_{j=1}^{\lfloor m/k\rfloor}j[d\mid j]\right). \end{aligned} \]

Ponovno se suma razdvaja po \(i\) i \(j\). Najprije izračunajmo te unutarnje sume; izlučivanjem faktora (tj. uz \(i=di'\)) dobivamo

\[ \sum_{i=1}^{\lfloor n/k\rfloor}i[d\mid i] = d\sum_{i=1}^{\lfloor\lfloor n/k\rfloor/d\rfloor}i = dG\left(\left\lfloor\dfrac{\lfloor n/k\rfloor}{d}\right\rfloor\right) = dG\left(\left\lfloor\dfrac{n}{kd}\right\rfloor\right). \]

Pritom je \(G(n)=\dfrac{1}{2}n(n+1)\) upravo zbroj aritmetičkog niza, a posljednja jednakost koristi svojstvo funkcije najvećeg cijelog. Simetrično, druga se suma računa analogno. Uvrštavanjem natrag u prethodni izraz dobivamo

\[ f(n,m) = \sum_k k\sum_{d}\mu(d)d^2G\left(\left\lfloor\dfrac{n}{kd}\right\rfloor\right)G\left(\left\lfloor\dfrac{m}{kd}\right\rfloor\right). \]

Kao i prije, za ovakve izraze s iteriranjem po zajedničkom faktoru obično treba iterirati po umnošku \(\ell = kd\) i ponovno zamijeniti redoslijed sumiranja:

\[ f(n,m) = \sum_{\ell}\left(\sum_{d\mid\ell}\mu(d)d\ell\right)G\left(\left\lfloor\dfrac{n}{\ell}\right\rfloor\right)G\left(\left\lfloor\dfrac{m}{\ell}\right\rfloor\right). \]

Neka je

\[ F(\ell) = \sum_{d\mid\ell}\mu(d)d\ell. \]

To je umnožak multiplikativne funkcije \(\ell\) i multiplikativne funkcije \(\sum_{d\mid\ell}\mu(d)d\), pa je i sama multiplikativna; može se izravno unaprijed izračunati linearnim sitom, kao i njezine prefiksne sume. Zatim se vrijednost \(f(n,m)\) računa blokovskim dijeljenjem po cjelobrojnom kvocijentu. Ukupna vremenska složenost iznosi \(O(\min\{n,m\})\).

LOJ 2185. [SDOI2015] 约数个数和 (Zbroj broja djelitelja)

\(T\) skupova podataka. Za svaki skup izračunajte:

\[ \sum_{i=1}^n\sum_{j=1}^m\sigma_0(ij). \]

Pritom \(\sigma_0(n)=\sum_{d \mid n}1\) označava broj djelitelja od \(n\).

Ograničenja: \(1\le n,m,T\le 5\times 10^4\).

Rješenje

Teškoća ovog zadatka jest pretvoriti \(\sigma_0(ij)\) u izraz s najvećim zajedničkim djeliteljem. Budući da je \(\sigma_0\) multiplikativna, najprije razmotrimo slučaj potencija prostih brojeva. Za prost broj \(p\) i nenegativne eksponente \(e_1,e_2\) neka je \(i=p^{e_1},~j=p^{e_2}\); tada je

\[ \sigma_0(ij) = 1 + e_1 + e_2 = \sum_{x\mid i}\sum_{y\mid j}[x\perp y]. \]

U općem slučaju neka je \(i=\prod_p i_p\) i \(j=\prod_p j_p\), gdje su \(i_p,j_p\) redom faktori koji su potencije prostog broja \(p\) u rastavima \(i,j\) na proste faktore. Tada vrijedi

\[ \sigma_0(ij) = \prod_p\sigma_0(i_pj_p)= \prod_p\sum_{x_p\mid i_p}\sum_{y_p\mid j_p}[x_p\perp y_p]. \]

Uočimo da je iteriranje po djeliteljima \(x_p\) svakog faktora \(i_p\) od \(i\) koji je potencija prostog broja isto što i iteriranje po djeliteljima \(x\) od \(i\) te rastavljanje svakoga na faktore \(x_p\) koji su potencije prostih brojeva; analogno za \(j\). Stoga, prema distributivnosti množenja, izraz postaje

\[ \sigma_0(ij) = \sum_{x\mid i}\sum_{y\mid j}\prod_p[x_p\perp y_p] = \sum_{x\mid i}\sum_{y\mid j}[x\perp y]. \]

Posljednji korak koristi zaključak: \(x\perp y\) ako i samo ako za svaki prosti faktor \(p\) vrijedi \(x_p\perp y_p\).

Nakon što dobijemo ovaj izraz, možemo primijeniti standardni postupak obrade:

\[ \begin{aligned} \sigma_0(ij) &= \sum_{x\mid i}\sum_{y\mid j}[x\perp y]\\ &= \sum_{x\mid i}\sum_{y\mid j}\sum_d\mu(d)[d\mid x][d\mid y]\\ &= \sum_d\mu(d)\left(\sum_{x}[d\mid x\mid i]\right)\left(\sum_{y}[d\mid y\mid j]\right)\\ &= \sum_d\mu(d)[d\mid i][d\mid j]\sigma_0\left(\dfrac{i}{d}\right)\sigma_0\left(\dfrac{j}{d}\right). \end{aligned} \]

Značenje posljednjeg koraka izvoda jest: funkcija je različita od nule samo kada je \(d\mid i\) i \(d\mid j\), a tada je iteriranje po \(x\) koji zadovoljavaju \(d\mid x\mid i\) isto što i iteriranje po djeliteljima \(\dfrac{x}{d}\) broja \(\dfrac{i}{d}\); analogno za iteriranje po \(y\) koji zadovoljavaju \(d\mid y\mid j\).

Uvrstimo ovaj izraz natrag u izvorni i zamijenimo redoslijed sumiranja:

\[ \begin{aligned} f(n,m) &= \sum_{i=1}^n\sum_{j=1}^m\sigma_0(ij)\\ &= \sum_{i=1}^n\sum_{j=1}^m\sum_d\mu(d)[d\mid i][d\mid j]\sigma_0\left(\dfrac{i}{d}\right)\sigma_0\left(\dfrac{j}{d}\right)\\ &= \sum_d\mu(d)\left(\sum_{i=1}^n[d\mid i]\sigma_0\left(\dfrac{i}{d}\right)\right)\left(\sum_{j=1}^m[d\mid j]\sigma_0\left(\dfrac{j}{d}\right)\right)\\ &= \sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/d\rfloor}\sigma_0(i)\right)\left(\sum_{j=1}^{\lfloor m/d\rfloor}\sigma_0(j)\right). \end{aligned} \]

Neka je \(G(n)=\sum_{i=1}^n\sigma_0(i)\); tada je

\[ f(n,m)=\sum_{d}\mu(d)G\left(\left\lfloor\dfrac{n}{d}\right\rfloor\right)G\left(\left\lfloor\dfrac{m}{d}\right\rfloor\right). \]

To se rješava blokovskim dijeljenjem po cjelobrojnom kvocijentu. Dovoljno je unaprijed izračunati prefiksne sume od \(\mu(n)\) i \(\sigma_0(n)\). Ukupna vremenska složenost iznosi \(O(N+T\sqrt{N})\), gdje je \(N\) gornja granica za \(n,m\), a \(T\) broj skupova podataka.

constexpr long long N = 5e4 + 5;
long long n, m, T, pr[N], mu[N], d[N], t[N],
    cnt;  // t je broj pojavljivanja najmanjeg prostog faktora od i
bool bp[N];

void prime_work(long long k) {
  bp[0] = bp[1] = true, mu[1] = 1, d[1] = 1;
  for (long long i = 2; i <= k; i++) {  // linearno sito
    if (!bp[i]) pr[++cnt] = i, mu[i] = -1, d[i] = 2, t[i] = 1;
    for (long long j = 1; j <= cnt && i * pr[j] <= k; j++) {
      bp[i * pr[j]] = true;
      if (i % pr[j] == 0) {
        mu[i * pr[j]] = 0;
        d[i * pr[j]] = d[i] / (t[i] + 1) * (t[i] + 2);
        t[i * pr[j]] = t[i] + 1;
        break;
      } else {
        mu[i * pr[j]] = -mu[i];
        d[i * pr[j]] = d[i] << 1;
        t[i * pr[j]] = 1;
      }
    }
  }
  for (long long i = 2; i <= k; i++)
    mu[i] += mu[i - 1], d[i] += d[i - 1];  // prefiksne sume
}

long long solve() {
  long long res = 0, mxi = min(n, m);
  for (long long i = 1, j; i <= mxi; i = j + 1) {  // blokovsko dijeljenje po cjelobrojnom kvocijentu
    j = min(n / (n / i), m / (m / i));
    res += d[n / i] * d[m / i] * (mu[j] - mu[i - 1]);
  }
  return res;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> T;
  prime_work(50000);  // predračunavanje
  while (T--) {
    cin >> n >> m;
    cout << solve() << '\n';
  }
  return 0;
}

Luogu P5221 Product

Izračunajte:

\[ \prod_{i=1}^n\prod_{j=1}^n\dfrac{\operatorname{lcm}(i,j)}{\gcd(i,j)}\pmod{104857601}. \]

Ograničenja: \(1\le n\le 1\times 10^6\).

Rješenje 1

U izvodu zanemarujemo modul. Neka je

\[ f(n) = \prod_{i=1}^n\prod_{j=1}^n\dfrac{\operatorname{lcm}(i,j)}{\gcd(i,j)}. \]

I dalje najmanji zajednički višekratnik pretvaramo u najveći zajednički djelitelj:

\[ f(n) = \prod_{i=1}^n\prod_{j=1}^n\dfrac{ij}{(\gcd(i,j))^2}. \]

Uočimo da su umnošci ovih faktora međusobno neovisni pa se mogu računati zasebno. Neka je

\[ g(n) = \prod_{i=1}^n\prod_{j=1}^n\gcd(i,j). \]

Izvorni je izraz tada jednak:

\[ f(n) = \dfrac{(n!)^{2n}}{g(n)^2}. \]

Ključno je riješiti računanje \(g(n)\). Postupak obrade sličan je prethodno opisanome, ali ga treba zamijeniti odgovarajućom multiplikativnom inačicom. Najprije iteriramo po zajedničkom djelitelju i izlučimo ga:

\[ \begin{aligned} g(n) &= \prod_k\prod_{i=1}^n\prod_{j=1}^nk\uparrow[\gcd(i,j)=k]\\ &= \prod_k\prod_{i=1}^{\lfloor n/k\rfloor}\prod_{j=1}^{\lfloor n/k\rfloor}k\uparrow[\gcd(i,j)=1]. \end{aligned} \]

Pritom je \(a\uparrow b=a^b\) Knuthova strelica. Zatim uvrstimo \([\gcd(i,j)=1]=\sum_d\mu(d)[d\mid i][d\mid j]\) i sumu u eksponentu pretvorimo u umnožak potencija, čime dobivamo:

\[ g(n) = \prod_k\prod_d\prod_{i=1}^{\lfloor n/k\rfloor}\prod_{j=1}^{\lfloor n/k\rfloor}k\uparrow(\mu(d)[d\mid i][d\mid j]). \]

Dalje izlučimo faktor (tj. stavimo \(i=di'\), \(j=dj'\)) i primijenimo svojstvo funkcije najvećeg cijelog, čime dobivamo:

\[ g(n) = \prod_k\prod_d\prod_{i=1}^{\lfloor n/(kd)\rfloor}\prod_{j=1}^{\lfloor n/(kd)\rfloor}k\uparrow\mu(d). \]

Zatim razdvojimo umnoške po \(i,j\) i uočimo da izraz u umnošku ne sadrži \(i,j\), pa je to isto što i potenciranje tog izraza:

\[ g(n) = \prod_k\prod_d k\uparrow\left(\mu(d)\left\lfloor\dfrac{n}{kd}\right\rfloor^2\right). \]

Budući da smo prije iterirali po zajedničkom djelitelju, za ovaj izraz treba ponovno zamijeniti redoslijed množenja. Uz \(\ell = kd\) vrijedi:

\[ \begin{aligned} g(n) &= \prod_{\ell}\prod_{d\mid\ell}\left(\dfrac{\ell}{d}\right)\uparrow\left(\mu(d)\left\lfloor\dfrac{n}{\ell}\right\rfloor^2\right)\\ &= \prod_\ell\left(\prod_{d\mid\ell}\left(\dfrac{\ell}{d}\right)\uparrow\mu(d)\right)\uparrow\left\lfloor\dfrac{n}{\ell}\right\rfloor^2. \end{aligned} \]

Neka je

\[ F(n) = \prod_{d\mid n}\left(\dfrac{n}{d}\right)\uparrow\mu(d). \]

Lako se vidi da je to Möbiusova inverzija funkcije \(\tilde F(n)=n\) u multiplikativnom obliku. Čak i ako ne znamo njezin izraz, može se unaprijed izračunati metodom Dirichletovih razlika u vremenu \(O(n\log\log n)\). Dakako, budući da je oblik \(\tilde F(n)\) vrlo jednostavan, izraz za \(F(n)\) može se izravno odrediti:

\[ F(n) = \begin{cases} p, & n = p^e,~p\in\mathbf P,~e\in\mathbf N_+, \\ 1, &\text{otherwise}. \end{cases} \]

Von Mangoldtova funkcija upravo je njezin prirodni logaritam. Nakon što dobijemo vrijednosti \(F(n)\), izravnom primjenom multiplikativne inačice blokovskog dijeljenja po cjelobrojnom kvocijentu vrijednost \(g(n)\) računa se u vremenu \(O(\sqrt{n})\), a time i vrijednost \(f(n)\). Ukupna vremenska složenost iznosi \(O(n)\).

Vrijedi napomenuti da je pri računanju s umnošcima često potreban Eulerov teorem, pa modul koji se koristi za eksponente nije isti kao modul zadan u zadatku.

Rješenje 2

Teškoća izvoda u multiplikativnoj inačici jest to što je baratanje umnošcima i potencijama razmjerno nepoznato; stoga se kod takvih zadataka može i logaritmirati pa tek onda izvoditi. Za ovaj zadatak razmotrimo samo izvod za \(g(n)\). Nakon logaritmiranja vrijedi:

\[ \log g(n) = \sum_{i=1}^n\sum_{j=1}^n\log\gcd(i,j). \]

Za ovakve izraze s najvećim zajedničkim djeliteljem izravnom primjenom standardnog postupka izvođenja dobivamo:

\[ \begin{aligned} \log g(n) &= \sum_k\log k\sum_{i=1}^n\sum_{j=1}^n[\gcd(i,j)=k]\\ &= \sum_k\log k\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor n/k\rfloor}[\gcd(i,j)=1]\\ &= \sum_k\log k\sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/k\rfloor}[d\mid i]\right)\left(\sum_{j=1}^{\lfloor n/k\rfloor}[d\mid j]\right)\\ &= \sum_k\log k\sum_d\mu(d)\left\lfloor\dfrac{n}{kd}\right\rfloor^2\\ &= \sum_{\ell}\left(\sum_{d\mid\ell}\mu(d)\log\dfrac{\ell}{d}\right)\left\lfloor\dfrac{n}{\ell}\right\rfloor^2\\ &= \sum_{\ell}\Lambda(\ell)\left\lfloor\dfrac{n}{\ell}\right\rfloor^2. \end{aligned} \]

Pritom je \(\Lambda(n)\) von Mangoldtova funkcija. Potenciranjem ovog rezultata dobiva se rezultat iz rješenja 1.

int pow(int a, int b, int m) {
  int res = 1;
  for (int po = a; b; b >>= 1) {
    if (b & 1) res = 1LL * res * po % m;
    po = 1LL * po * po % m;
  }
  return res;
}

int main() {
  constexpr int M = 104857601;
  int n;
  std::cin >> n;
  // Get F(n), i.e., exp(Lambda(n)).
  std::vector<int> vis(n + 1), prime, pf(n + 1), rem(n + 1);
  prime.reserve(n);
  for (int x = 2; x <= n; ++x) {
    if (!vis[x]) {
      prime.emplace_back(x);
      pf[x] = x;
      rem[x] = 1;
    }
    for (int p : prime) {
      if (1LL * p * x > n) break;
      vis[x * p] = 1;
      pf[x * p] = p;
      rem[x * p] = x % p ? x : rem[x];
      if (x % p == 0) break;
    }
  }
  pf[1] = 1;
  for (int x = 2; x <= n; ++x) {
    pf[x] = rem[x] == 1 ? pf[x] : 1;
  }
  // Prefix products and their inverses.
  std::vector<int> pm(n + 1), ip(n + 1);
  pm[0] = 1;
  for (int x = 1; x <= n; ++x) {
    pm[x] = 1LL * pm[x - 1] * pf[x] % M;
  }
  int inv = pow(pm[n], M - 2, M);
  ip[0] = 1;
  for (int x = n; x >= 1; --x) {
    ip[x] = inv;
    inv = 1LL * inv * pf[x] % M;
  }
  // Calculate g(n).
  int res = 1;
  for (int l = 1, r; l <= n; l = r + 1) {
    r = n / (n / l);
    int a = 1LL * pm[r] * ip[l - 1] % M;
    int b = 1LL * (n / l) * (n / l) % (M - 1);
    res = 1LL * res * pow(a, b, M) % M;
  }
  // Take square and then inverse.
  res = pow(res, M - 3, M);
  // Get factorials.
  int fac = 1;
  for (int x = 1; x <= n; ++x) {
    fac = 1LL * fac * x % M;
  }
  // Final answer.
  res = 1LL * res * pow(fac, 2 * n, M) % M;
  std::cout << res << std::endl;
  return 0;
}

Prerequisites: floor-division blocks, Dirichlet convolution

Möbius inversion is an important topic in number theory. For some functions \(f(n)\), if it is hard to compute the value directly but easy to compute the sum over multiples or the sum over divisors \(g(n)\), Möbius inversion can simplify the computation and yield the value of \(f(n)\).

Möbius function

The Möbius function is defined as

\[ \mu(n)= \begin{cases} 1,&n=1,\\ 0,&n\text{ is divisible by a square }>1,\\ (-1)^k,&n\text{ is the product of }k\text{ distinct primes}.\\ \end{cases} \]

Concretely, suppose the positive integer \(n\) has the prime factorization \(n=\prod_{i=1}^kp_i^{e_i}\), where the \(p_i\) are primes and the \(e_i\) are positive integers. Then the three cases correspond to:

  1. \(\mu(1) = 1\);
  2. if there is an \(i\) with \(e_i > 1\), i.e. some prime factor appears more than once, then \(\mu(n)=0\);
  3. otherwise, if \(e_i = 1\) for all \(i\), i.e. every prime factor appears exactly once, then \(\mu(n)=(-1)^k\), where \(k\) is the number of distinct prime factors.

Properties

From the definition it is easy to verify that the Möbius function \(\mu(n)\) is multiplicative but not completely multiplicative. Apart from that, the most important property is the following identity:

Property

For a positive integer \(n\),

\[ \sum_{d\mid n}\mu(d) = [n = 1] = \begin{cases} 1,&n=1,\\ 0,&n\neq 1.\\ \end{cases} \]

Here \([\cdot]\) is the Iverson bracket.

Proof

Let \(n=\prod_{i=1}^kp_i^{e_i}\) and set \(n' = \prod_{i=1}^kp_i\). By the binomial theorem,

\[ \sum_{d\mid n}\mu(d) = \sum_{d\mid n'}\mu(d) = \sum_{i=0}^k\binom{k}{i}(-1)^i = (1 + (-1))^k = [k = 0] = [n = 1]. \]

Using the Dirichlet convolution, this expression can be written as \(\varepsilon = 1 * \mu\). In other words, the Möbius function is the Dirichlet inverse of the constant function \(1\).

This property has a very common application:

\[ [i\perp j] = [\gcd(i,j) = 1] = \sum_{d\mid\gcd(i,j)} \mu(d) = \sum_{d}[d\mid i][d\mid j]\mu(d). \]

It turns the coprimality condition into a sum involving the Möbius function, which makes further derivations easier.

Computation

If the value of the Möbius function \(\mu(n)\) is needed for a single \(n\), its prime factorization can be used. For example, when \(n\) is not too large, \(\mu(n)\) can be computed in \(O(\sqrt{n})\) time.

int mu(int n) {
  int res = 1;
  for (int i = 2; i * i <= n; ++i) {
    if (n % i == 0) {
      n /= i;
      // Check if square-free.
      if (n % i == 0) return 0;
      res = -res;

  }
  // The remaining factor must be prime.
  if (n > 1) res = -res;
  return res;
}

Möbius inversion

The most important application of the Möbius function is Möbius inversion.

Möbius inversion

Let \(f(n),g(n)\) be two arithmetic functions. Then

\[ f(n) = \sum_{d\mid n}g(d) \iff g(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)f(d). \]
Proof 1

By direct verification:

\[ \begin{aligned} \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)f(d) &= \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\sum_{k\mid d}g(k)\\ &= \sum_{k\mid n}g(k)\sum_d[k\mid d\mid n]\mu\left(\dfrac{n}{d}\right)\\ &= \sum_{k\mid n}g(k)\sum_{d\mid n}\left[\frac{n}{d}\mid\frac{n}{k}\right]\mu\left(\dfrac{n}{d}\right)\\ &= \sum_{k\mid n}g(k)\left[\frac{n}{k} = 1\right] \\ &= g(n). \end{aligned} \]

The key to the transformation is exchanging the order of summation and noticing that \(k\mid d\mid n\) is equivalent to \(\dfrac{n}{d}\mid\dfrac{n}{k}\). The second-to-last equality amounts to summing the Möbius function over the divisors \(\dfrac{n}{d}\) of \(\dfrac{n}{k}\), so it equals \(\left[\dfrac{n}{k} = 1\right]\). This expression is different from \(0\) only at \(n=k\), so in the end we get \(g(n)\).

Proof 2

Using the Dirichlet convolution, the statement is equivalent to

\[ f = 1 * g \iff g = \mu * f. \]

Using \(1 * \mu = \varepsilon\) and convolving both sides of the left equation with \(\mu\), we get

\[ f * \mu = (1 * g) * \mu = (1 * \mu) * g = \varepsilon * g = g. \]

In sums of arithmetic functions involving various divisibility relations, Möbius inversion is a powerful transformation tool.

Examples

  1. Euler's totient function \(\varphi(n)\) satisfies the relation \(n = \sum_{d\mid n}\varphi(d)\), i.e. \(\mathrm{id}=1*\varphi\). Inverting it gives \(\varphi = \mu * \mathrm{id}\), i.e.

    \[ \varphi(n) = \sum_{d\mid n}d\mu\left(\dfrac{n}{d}\right). \]

  2. The divisor function \(\sigma_k(n) = \sum_{d\mid n}d^k\), i.e. \(\sigma_k = 1 * \mathrm{id}_k\). Inverting it gives \(\mathrm{id}_k = \mu * \sigma_k\), i.e.

    \[ n^k = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\sigma_k(d). \]

  3. The number-of-distinct-prime-factors function \(\omega(n)=\sum_{d\mid n}[d\in\mathbf P]\), i.e. \(\omega = 1* \mathbf{1}_{\mathbf P}\), where \(\mathbf{1}_{\mathbf P}\) is the indicator function of the set of primes \(\mathbf P\). Inverting it gives \(\mathbf{1}_{\mathbf P} = \mu * \omega\), i.e.

    \[ [n\in\mathbf P] = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\omega(d). \]

  4. Consider the arithmetic function \(\Lambda(n)\) satisfying \(\log n = \sum_{d\mid n}\Lambda(d)\). It is the Möbius inversion of the logarithm function, also called the von Mangoldt function:

    \[ \Lambda(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)\log d = \begin{cases} \log p, & n = p^e,~p\in\mathbf P,~e\in\mathbf N_+, \\ 0, &\text{otherwise}. \end{cases} \]
Appendix: proof of the expression for \(\Lambda(n)\)

For a prime power \(n=p^e~(e\in\mathbf N_+)\),

\[ \Lambda(n) = \sum_{i=0}^e\mu(p^{e-i})\log p^i = \log p^{e} - \log p^{e-1} = \log p. \]

For \(n=1\), clearly \(\Lambda(n)=\log 1=0\). For other composite \(n\),

\[ \Lambda(n) = \sum_{d\mid n}\mu(d)(\log n-\log d) = \left(\sum_{d\mid n}\mu(d)\right)\log n-\sum_{d\mid n}\mu(d)\log d. \]

By the property of the Möbius function, the coefficient of the \(\log n\) term is \([n=1]=0\). For the latter term, \(d\) can be further decomposed into a product of prime factors. For any prime \(p\mid n\), let \(n=p^em\) with \(p\perp m\) (since \(n\) is not a prime power, \(m>1\)), and consider the coefficient of \(\log p\) (only squarefree \(d\) contribute):

\[ -\sum_{p\mid d\mid n}\mu(d) = -\sum_{d'\mid m}\mu(pd') = \sum_{d'\mid m}\mu(d') = [m=1]=0. \]

Hence, for composite \(n\) with more than one prime factor, \(\Lambda(n)=0\).

Extended forms

Besides the basic form above, Möbius inversion has several common extended forms. First, consider its sum-over-multiples form.

Extension 1

Let \(f(n),g(n)\) be two arithmetic functions. Then

\[ f(n) = \sum_{n\mid d}g(d) \iff g(n) = \sum_{n\mid d}\mu\left(\dfrac{d}{n}\right)f(d). \]
Proof

By direct verification:

\[ \begin{aligned} \sum_{n\mid d}\mu\left(\dfrac{d}{n}\right)f(d) &= \sum_{n\mid d}\mu\left(\dfrac{d}{n}\right)\sum_{d\mid k}g(k)\\ &= \sum_{n\mid k}g(k)\sum_{d}[n\mid d\mid k]\mu\left(\dfrac{d}{n}\right)\\ &= \sum_{n\mid k}g(k)\sum_{n\mid d}\left[\dfrac{d}{n}\mid\dfrac{k}{n}\right]\mu\left(\dfrac{d}{n}\right)\\ &= \sum_{n\mid k}g(k)\left[\dfrac{k}{n}=1\right]\\ &= g(n). \end{aligned} \]

This is completely dual to the derivation of the basic form.

Second, Möbius inversion is not limited to addition; it actually holds for the operation of any abelian group. For example, it has the following multiplicative form:

Extension 2

Let \(f(n),g(n)\) be two arithmetic functions. Then

\[ f(n) = \prod_{d\mid n}g(d) \iff g(n) = \prod_{d\mid n}f(d)^{\mu(n/d)}. \]
Proof

By direct verification:

\[ \begin{aligned} \prod_{d\mid n}f(d)^{\mu(n/d)} &= \prod_{d\mid n}\left(\prod_{k\mid d}g(k)\right)^{\mu(n/d)}\\ &= \prod_{k\mid n}g(k)\uparrow\left(\sum_d[k\mid d\mid n]\mu\left(\dfrac{n}{d}\right)\right)\\ &= \prod_{k\mid n}g(k)\uparrow\left(\sum_{d\mid n}\left[\frac{n}{d}\mid\frac{n}{k}\right]\mu\left(\dfrac{n}{d}\right)\right)\\ &= \prod_{k\mid n}g(k)\uparrow\left[\frac{n}{k} = 1\right] \\ &= g(n). \end{aligned} \]

Here \(a\uparrow b = a^b\) is Knuth's arrow. Comparing with the proof of the basic form, the only difference is that addition is replaced by multiplication, and multiplication by exponentiation.

From the viewpoint of the Dirichlet convolution, Möbius inversion only uses the fact that "the Möbius function is the Dirichlet inverse of the constant function". It is easy to imagine that relations similar to Möbius inversion also hold for a general Dirichlet inverse.

Extension 3

Let \(f(n),g(n),\alpha(n)\) be arithmetic functions, and let \(\alpha^{-1}(n)\) be the Dirichlet inverse of \(\alpha(n)\), i.e.

\[ [n=1] = \sum_{d\mid n}\alpha\left(\dfrac{n}{d}\right)\alpha^{-1}(d). \]

Then

\[ f(n) = \sum_{d\mid n}\alpha\left(\dfrac{n}{d}\right)g(d) \iff g(n) = \sum_{d\mid n}\alpha^{-1}\left(\dfrac{n}{d}\right)f(d). \]
Proof

By direct verification:

\[ \begin{aligned} \sum_{d\mid n}\alpha^{-1}\left(\dfrac{n}{d}\right)f(d) &= \sum_{d\mid n}\alpha^{-1}\left(\dfrac{n}{d}\right)\sum_{k\mid d}\alpha\left(\dfrac{d}{k}\right)g(k)\\ &= \sum_{k\mid n}g(k)\sum_d[k\mid d\mid n]\alpha\left(\dfrac{d}{k}\right)\alpha^{-1}\left(\dfrac{n}{d}\right)\\ &= \sum_{k\mid n}g(k)\sum_{d\mid n}\left[\frac{n}{d}\mid\frac{n}{k}\right]\alpha\left(\dfrac{d}{k}\right)\alpha^{-1}\left(\dfrac{n/k}{d/k}\right)\\ &= \sum_{k\mid n}g(k)\left[\frac{n}{k} = 1\right] \\ &= g(n). \end{aligned} \]

Compared with the proof of the basic form, one only needs to replace the second-to-last equality with the defining formula of the Dirichlet inverse.

Corollary

Let \(f(n),g(n)\) be arithmetic functions and let \(t(n)\) be a completely multiplicative function. Then

\[ f(n) = \sum_{d\mid n}t\left(\dfrac{n}{d}\right)g(d) \iff g(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)t\left(\dfrac{n}{d}\right)f(d). \]
Proof

By the properties of the Dirichlet convolution, the Dirichlet inverse of a completely multiplicative function \(t(n)\) is \(\mu(n)t(n)\).

Finally, Möbius inversion can also be generalized to complex-valued functions on \([1,+\infty)\), not just arithmetic functions. The basic form of Möbius inversion can be viewed as the special case in which the complex-valued function is zero at all non-integer points.

Extension 4

Let \(F(x)\) and \(G(x)\) be complex-valued functions on \([1,+\infty)\). Then

\[ F(x) = \sum_{n = 1}^{\lfloor x\rfloor}G\left(\dfrac{x}{n}\right) \iff G(x) = \sum_{n = 1}^{\lfloor x\rfloor}\mu(n)F\left(\dfrac{x}{n}\right). \]
Proof

Without loss of generality, extend the definitions of \(F\) and \(G\) so that \(F(x)=G(x)=0\) whenever \(x < 1\). Then the statement is equivalent to:

\[ F(x) = \sum_n G\left(\dfrac{x}{n}\right) \iff G(x) = \sum_n \mu(n)F\left(\dfrac{x}{n}\right). \]

All these sums are over \(n\in\mathbf N_+\).

By direct verification:

\[ \begin{aligned} \sum_n \mu(n)F\left(\dfrac{x}{n}\right) &= \sum_n\mu(n)\sum_d G\left(\dfrac{x/n}{d}\right)\\ &= \sum_k G\left(\dfrac{x}{k}\right)\sum_{n\mid k}\mu(n)\\ &= \sum_k G\left(\dfrac{x}{k}\right)[k=1]\\ &= G(x). \end{aligned} \]

Here, to obtain the second equality, set \(k = nd\).

Corollary

Let \(f(n),g(n)\) be arithmetic functions. Then

\[ f(n) = \sum_{k=1}^ng\left(\left\lfloor\dfrac{n}{k}\right\rfloor\right) \iff g(n)=\sum_{k=1}^n\mu(k)f\left(\left\lfloor\dfrac{n}{k}\right\rfloor\right). \]
Proof

Just take \(F(x)=f(\lfloor x\rfloor)\) and \(G(x)=g(\lfloor x\rfloor)\).

These extended forms can be combined with each other to obtain more complex inversion relations.

Dirichlet prefix sums

Prerequisites: Prefix sums and difference arrays

Consider the basic form of the Möbius inversion relation:

\[ f(n) = \sum_{d\mid n}g(d) \iff g(n) = \sum_{d\mid n}\mu\left(\dfrac{n}{d}\right)f(d). \]

In the left equation, the value \(f(n)\) is the sum of the values of \(g\) at all divisors of \(n\). If we interpret \(a\mid b\) as "\(a\) comes before \(b\)", then \(f(n)\) can be understood as a prefix sum of \(g(n)\) in a certain sense. Therefore, in the Chinese competitive programming community, the process of computing \(\{f(k)\}_{k=1}^n\) from \(\{g(k)\}_{k=1}^n\) is also called the Dirichlet prefix sum, and the corresponding inverse process is called the Dirichlet difference. These methods mostly appear when the values of some arithmetic function at the first \(N\) points need to be precomputed.

Next, we discuss the computation of Dirichlet prefix sums. If each prime is regarded as a dimension, this is a kind of multidimensional prefix sum. Recall the dimension-by-dimension prefix sum algorithm for multidimensional prefix sums: iterate over all dimensions one by one, and add the value at each position to its successor position in that dimension. For arithmetic functions, this amounts to iterating over all primes \(p\) from small to large and adding the function value at \(n\) to the value at \(np\). This is the same traversal order as in the sieve of Eratosthenes. Therefore, this algorithm computes the Dirichlet prefix sum of a sequence of length \(n\) in \(O(n\log\log n)\) time. Similarly, dimension-by-dimension differences compute the Dirichlet difference of a sequence within the same time complexity.

Reference implementation 
std::vector<int> dirichlet_presum(const std::vector<int>& g) {
  int n = g.size() - 1;
  std::vector<int> f(g);
  std::vector<bool> vis(n + 1);
  for (int x = 2; x <= n; ++x) {
    if (vis[x]) continue;
    for (int y = 1, xy = x; xy <= n; ++y, xy += x) {
      vis[xy] = true;
      f[xy] += f[y];
    }
  }
  return f;
}

std::vector<int> dirichlet_diff(const std::vector<int>& f) {
  int n = f.size() - 1;
  std::vector<int> g(f);
  std::vector<int> vis(n + 1);
  for (int x = 2; x <= n; ++x) {
    if (vis[x]) continue;
    for (int y = n / x, xy = x * y; y; --y, xy -= x) {
      vis[xy] = true;
      g[xy] -= g[y];
    }
  }
  return g;
}

This computation method can be generalized to the sum-over-multiples form (Extension 1), the multiplicative form (Extension 2), replacing the constant function by a completely multiplicative function (the corollary of Extension 3), and other extended forms.

Example problems

This section uses example problems to show how to apply Möbius inversion, along with some common transformation techniques. First, one example problem introduces the basic technique for handling greatest-common-divisor conditions in sums.

Luogu P2522 [HAOI 2011] Problem b

\(T\) test cases. For each test case, evaluate:

\[ \sum_{i=x}^{n}\sum_{j=y}^{m}[\gcd(i,j)=k]. \]

Constraints: \(1\le T,x,y,n,m,k\le 5\times 10^4\).

Solution

By inclusion-exclusion, the original expression can be split into \(4\) parts, and the expression of each part has the form

\[ f(n,m,k)=\sum_{i=1}^{n}\sum_{j=1}^{m}[\gcd(i,j)=k]. \]

For such expressions, what follows is a standard derivation procedure: factor out the common divisor, apply the property of the Möbius function, and exchange the order of summation.

First, since \(i,j\) can only take multiples of \(k\), this factor can be extracted first – this amounts to substituting \(i=ki'\) and \(j=kj'\), which gives:

\[ f(n,m,k)=\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor m/k\rfloor}[\gcd(i,j)=1]. \]

Then, by the property of the Möbius function:

\[ [\gcd(i,j)=1] = \sum_{d\mid\gcd(i,j)}\mu(d) = \sum_d[d\mid i][d\mid j]\mu(d). \]

Substituting this into the expression and exchanging the order of summation gives:

\[ f(n,m,k)=\sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/k\rfloor}[d\mid i]\right)\left(\sum_{j=1}^{\lfloor m/k\rfloor}[d\mid j]\right). \]

The benefit of this manipulation is that, for fixed \(d\), the terms involving \(i\) and \(j\) in the sum separate from each other and can be summed independently. Next, since

\[ \sum_{i=1}^{\lfloor n/k\rfloor}[d\mid i] = \left\lfloor\dfrac{\lfloor n/k\rfloor}{d}\right\rfloor,~\sum_{j=1}^{\lfloor m/k\rfloor}[d\mid j]=\left\lfloor\dfrac{\lfloor m/k\rfloor}{d}\right\rfloor, \]

we have

\[ f(n,m,k)=\sum_d\mu(d)\left\lfloor\dfrac{\lfloor n/k\rfloor}{d}\right\rfloor\left\lfloor\dfrac{\lfloor m/k\rfloor}{d}\right\rfloor. \]

After precomputing \(\mu(d)\) with a linear sieve, together with its prefix sums, the problem can be solved with floor-division blocks. The total time complexity is \(O(N + T\sqrt{N})\), where \(N\) is the upper bound of \(n,m\) and \(T\) is the number of test cases.

Reference code 
#include <algorithm>
#include <iostream>
using namespace std;
constexpr int N = 50000;
int mu[N + 5], p[N + 5];
bool flg[N + 5];

void init() {
  int tot = 0;
  mu[1] = 1;
  for (int i = 2; i <= N; ++i) {
    if (!flg[i]) {
      p[++tot] = i;
      mu[i] = -1;
    }
    for (int j = 1; j <= tot && i * p[j] <= N; ++j) {
      flg[i * p[j]] = true;
      if (i % p[j] == 0) {
        mu[i * p[j]] = 0;
        break;
      }
      mu[i * p[j]] = -mu[i];
    }
  }
  for (int i = 1; i <= N; ++i) mu[i] += mu[i - 1];
}

int solve(int n, int m) {
  int res = 0;
  for (int i = 1, j; i <= min(n, m); i = j + 1) {
    j = min(n / (n / i), m / (m / i));
    res += (mu[j] - mu[i - 1]) * (n / i) * (m / i);  // plug in the derived formula
  }
  return res;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  int T, a, b, c, d, k;
  init();  // precompute the mu array
  cin >> T;
  for (int i = 1; i <= T; i++) {
    cin >> a >> b >> c >> d >> k;
    // By inclusion-exclusion, from the number of answers in the range 1<=x<=b&&1<=y<=d subtract the number of answers in the range 1<=x<=b&&1<=y<=c-1 and
    //   the number of answers in the range 1<=x<=a-1&&1<=y<=d, then add the number of answers in the range 1<=x<=a-1&&1<=y<=c-1
    //   to obtain the number of answers in the range a<=x<=b&&c<=y<=d
    // if this step is unclear, draw a coordinate diagram to understand it
    cout << solve(b / k, d / k) - solve(b / k, (c - 1) / k) -
                solve((a - 1) / k, d / k) + solve((a - 1) / k, (c - 1) / k)
         << '\n';
  }
  return 0;
}

The next two example problems show how to handle enumeration of a common divisor, and how to compute the values of general multiplicative functions with a sieve.

SPOJ LCMSUM

\(T\) test cases. For each test case, evaluate:

\[ \sum_{i=1}^n \operatorname{lcm}(i,n). \]

Constraints: \(1\le T\le 3\times 10^5,~1\le n\le 10^6\).

Solution 1

The problem gives the least common multiple, but the greatest common divisor is usually easier to handle. So first transform:

\[ f(n)=\sum_{i=1}^n \operatorname{lcm}(i,n) = \sum_{i=1}^n \frac{i\cdot n}{\gcd(i,n)}. \]

Factor out \(n\) and enumerate the greatest common divisor \(k\):

\[ f(n)=n\sum_{k\mid n}\sum_{i=1}^n\dfrac{i}{k}[\gcd(i,n)=k]. \]

The inner sum is the most common form involving a greatest common divisor; repeating the standard procedure gives:

\[ \begin{aligned} f(n) &= n\sum_{k\mid n}\sum_{i=1}^{n/k}i\left[\gcd\left(i,\dfrac{n}{k}\right)=1\right]\\ &= n\sum_{k\mid n}\sum_{i=1}^{n/k}i\sum_d\mu(d)[d\mid i]\left[d\mid \dfrac{n}{k}\right]\\ &= n\sum_{k\mid n}\sum_d\mu(d)\left[d\mid \dfrac{n}{k}\right]\left(\sum_{i=1}^{n/k}i[d\mid i]\right). \end{aligned} \]

Once again, the sum over \(i\) separates from the rest and can be handled on its own. The last sum is in fact the sum of an arithmetic progression (taking \(i=di'\)):

\[ \sum_{i=1}^{n/k}i[d\mid i] = d\frac{1}{2}\left(\dfrac{n}{kd}+1\right)\dfrac{n}{kd}=:dG\left(\dfrac{n}{kd}\right). \]

This yields the following expression:

\[ f(n) = n\sum_{k\mid n}\sum_d\mu(d)\left[d\mid \dfrac{n}{k}\right]dG\left(\dfrac{n}{kd}\right). \]

After enumerating a common divisor, double sums of this form are very common. There is likewise a fixed way to handle them: set the product as a new variable \(\ell=kd\), then exchange the order of summation again. Since \(d\mid(n/k)\) is equivalent to \(d\mid\ell\mid n\), the original expression becomes:

\[ f(n) = n\sum_{\ell\mid n}G\left(\dfrac{n}{\ell}\right)\sum_{d\mid\ell}\mu(d)d. \]

Let \(F(\ell)=\sum_{d\mid\ell}\mu(d)d\); then the original expression has the form:

\[ f(n) = n\sum_{\ell\mid n}G\left(\dfrac{n}{\ell}\right)F(\ell). \]

Since \(\mu(d)d\) is multiplicative, its convolution \(F(n)\) with the constant function \(1\) is also multiplicative. Although the sum in the above expression has the form of a Dirichlet convolution, \(G(n)\) is not multiplicative, so the sum as a whole is not multiplicative. However, \(G(n)\) is a polynomial, so it is actually a linear combination of several completely multiplicative functions. Therefore,

\[ f(n) = \dfrac{1}{2}n\left(\sum_{\ell\mid n}\left(\dfrac{n}{\ell}\right)^2F(\ell) + \sum_{\ell\mid n}\dfrac{n}{\ell}F(\ell)\right). \]

Both terms (without the coefficients) are multiplicative functions and can be precomputed directly with a linear sieve (or alternatively, the inner function can be computed with a linear sieve and then everything precomputed with Dirichlet prefix sums in \(O(N\log\log N)\) time). Concretely, let

\[ H_s(n) = \sum_{\ell\mid n}\left(\dfrac{n}{\ell}\right)^sF(\ell),~s=1,2. \]

To derive their expressions, it suffices to determine their values at prime powers. For a prime \(p\) and a positive exponent \(e\),

\[ \begin{aligned} F(p^e) &= \mu(1) + \mu(p)p + \sum_{j=2}^e\mu(p^j)p^j = 1-p,\\ H_s(p^e) &= (p^e)^{s}F(1) + \sum_{j=1}^e(p^{e-j})^sF(p^j) = p^{es} + (1-p)\dfrac{1-p^{es}}{1-p^s},~s=1,2. \end{aligned} \]

In particular, \(H_1(p^e)=1\) is the constant function, while

\[ H_2(p^e) = p^{2e} + (1-p)\dfrac{1-p^{2e}}{1-p^2} = H_2(p^{e-1}) + p^{2e} - p^{2e-1}. \]

This is easy to compute with a linear sieve. After precomputing \(H_2(n)\) with a linear sieve, each query can be answered in \(O(1)\) time via \(f(n)=(n/2)(H_2(n)+1)\). The total time complexity is \(O(N+T)\), where \(N\) is the upper bound of \(n\) and \(T\) is the number of test cases.

In the reference implementation, the linear sieve part is derived further using the special form of the expression in this problem; this is not necessary. Using only the values at prime powers, the precomputation can still be done in \(O(N)\) time. These derivations are described in detail in Solution 2.

Solution 2

For this problem there is a more flexible approach. From Solution 1 we see that

\[ f(n) = n\sum_{k\mid n}\sum_{i=1}^{n/k}i\left[\gcd\left(i,\dfrac{n}{k}\right)=1\right] = n\sum_{k\mid n}F\left(\dfrac{n}{k}\right). \]

If at this step we do not continue with Möbius inversion but observe that the subsequent sum is actually the sum of the integers not exceeding \(d=n/k\) that are coprime to it. For \(d>1\), since the integers coprime to \(d\) come in pairs, i.e. \(i\) and \(d-i\) are necessarily coprime to \(d\) at the same time, we have

\[ F(d)=\sum_{i=1}^{d}i[i\perp d] = \sum_{i=1}^{d}(d-i)[i\perp d] = \dfrac{1}{2}d\sum_{i=1}^{d}[i\perp d] = \dfrac{1}{2}d\varphi(d). \]

For \(d=1\), on the other hand,

\[ F(d)=1=\dfrac{1}{2}+\dfrac{1}{2}d\varphi(d). \]

Hence, the original expression can be written as

\[ f(n) = \dfrac{1}{2}n\left(\sum_{d\mid n}d\varphi(d) + 1\right). \]

Since \(G(n)=\sum_{d\mid n}d\varphi(d)\) is the Dirichlet convolution of the multiplicative function \(n\varphi(n)\) and the constant function \(1\), it is also multiplicative and can be precomputed with a linear sieve. To this end, it suffices to determine its values at prime powers. For a prime \(p\) and a positive exponent \(e\),

\[ G(p^e) = 1 + \sum_{i=1}^ep^i\cdot p^{i-1}(p-1) = G(p^{e-1}) + p^{2e} - p^{2e-1}. \]

We can see that this expression agrees with the result derived in Solution 1. The total time complexity of this method is still \(O(N+T)\).

Finally, using the expression of the multiplicative function in this problem, the computation in the linear sieve can be optimized further. For a prime \(p\),

\[ G(p) = 1 - p + p^2. \]

The key to the linear sieve is that, for a general \(n\), we need to compute the value \(G(pn)\). This further splits into two cases. When \(p\perp n\), since \(G\) is multiplicative,

\[ G(pn) = G(p)G(n). \]

Otherwise, when \(p\mid n\), let \(n=p^em\) with \(p\perp m\); then

\[ \begin{aligned} G(pn) &= G(p^{e+1})G(m)\\ &= G(p^e)G(m) + (p^{2e+2} - p^{2e+1})G(m)\\ &= G(n) + (p^{2e+2} - p^{2e+1})G(m). \end{aligned} \]

A direct check shows that this expression also holds for the case \(p\perp n\) (i.e. \(e=0\)). And when \(p\mid n\), we also have

\[ G(n) - G\left(\dfrac{n}{p}\right) = (p^{2e}-p^{2e-1})G(m). \]

Substituting into the above expression gives

\[ G(pn) = G(n) + p^2\left(G(n) - G\left(\dfrac{n}{p}\right)\right). \]

This simplifies the computation in the linear sieve part. Of course, this derivation is not necessary; for multiplicative functions without special properties, the linear sieve computation can be done directly using \(G(pn)=G(p^{e+1})G(m)\).

Reference code

BZOJ 2154 [国家集训队] Crash 的数字表格 (Crash's number table)

Evaluate:

\[ \sum_{i=1}^n\sum_{j=1}^m\operatorname{lcm}(i,j)\mod{20101009}. \]

Constraints: \(1\le n,m\le 10^7\).

Solution

We ignore the modulus during the derivation. Let

\[ f(n,m) = \sum_{i=1}^n\sum_{j=1}^m\operatorname{lcm}(i,j). \]

As before, convert the least common multiple into the greatest common divisor, enumerate the common divisor, and apply the standard procedure, which gives

\[ \begin{aligned} f(n,m) &= \sum_k\sum_{i=1}^n\sum_{j=1}^m\dfrac{ij}{k}[\gcd(i,j)=k] \\ &= \sum_k\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor m/k\rfloor} kij[\gcd(i,j)=1]\\ &= \sum_k\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor m/k\rfloor} kij\sum_d\mu(d)[d\mid i][d\mid j]\\ &= \sum_kk\sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/k\rfloor}i[d\mid i]\right)\left(\sum_{j=1}^{\lfloor m/k\rfloor}j[d\mid j]\right). \end{aligned} \]

Once again, the sum separates in \(i\) and \(j\). First compute these inner sums; extracting the factor (i.e. taking \(i=di'\)) gives

\[ \sum_{i=1}^{\lfloor n/k\rfloor}i[d\mid i] = d\sum_{i=1}^{\lfloor\lfloor n/k\rfloor/d\rfloor}i = dG\left(\left\lfloor\dfrac{\lfloor n/k\rfloor}{d}\right\rfloor\right) = dG\left(\left\lfloor\dfrac{n}{kd}\right\rfloor\right). \]

Here \(G(n)=\dfrac{1}{2}n(n+1)\) is just the sum of an arithmetic progression, and the last equality uses the property of the floor function. Symmetrically, the other sum can be computed in the same way. Substituting back into the earlier expression gives

\[ f(n,m) = \sum_k k\sum_{d}\mu(d)d^2G\left(\left\lfloor\dfrac{n}{kd}\right\rfloor\right)G\left(\left\lfloor\dfrac{m}{kd}\right\rfloor\right). \]

As before, for such expressions that enumerate a common divisor, one usually needs to enumerate the product \(\ell = kd\) and exchange the order of summation again:

\[ f(n,m) = \sum_{\ell}\left(\sum_{d\mid\ell}\mu(d)d\ell\right)G\left(\left\lfloor\dfrac{n}{\ell}\right\rfloor\right)G\left(\left\lfloor\dfrac{m}{\ell}\right\rfloor\right). \]

Let

\[ F(\ell) = \sum_{d\mid\ell}\mu(d)d\ell. \]

This is the product of the multiplicative function \(\ell\) and the multiplicative function \(\sum_{d\mid\ell}\mu(d)d\), so it is also multiplicative; it can be precomputed directly with a linear sieve, along with its prefix sums. Then the value of \(f(n,m)\) can be computed with floor-division blocks. The total time complexity is \(O(\min\{n,m\})\).

Reference code 
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
  constexpr int M = 20101009;
  int n, m;
  std::cin >> n >> m;
  if (n > m) std::swap(n, m);
  std::vector<int> f(n + 1), vis(n + 1), prime;
  prime.reserve(n);
  f[1] = 1;
  for (int x = 2; x <= n; ++x) {
    if (!vis[x]) {
      prime.emplace_back(x);
      f[x] = 1 - x;
    }
    for (int p : prime) {
      if (1LL * p * x > n) break;
      vis[x * p] = 1;
      f[x * p] = x % p ? (1 - p) * f[x] : f[x];
      if (x % p == 0) break;
    }
  }
  for (int x = 1; x <= n; ++x) {
    f[x] = 1LL * x * f[x] % M + M;
    f[x] = (f[x] + f[x - 1]) % M;
  }
  long long res = 0;
  for (int l = 1, r; l <= n; l = r + 1) {
    int nn = n / l, mm = m / l;
    r = std::min(n / nn, m / mm);
    int g_n = (1LL * nn * (nn + 1) / 2) % M;
    int g_m = (1LL * mm * (mm + 1) / 2) % M;
    res += 1LL * g_n * g_m % M * (f[r] - f[l - 1] + M) % M;
  }
  std::cout << (res % M) << '\n';
  return 0;
}

The next example problem is somewhat special: it requires transforming the divisor-counting function of a product.

LOJ 2185. [SDOI2015] 约数个数和 (Sum of the number of divisors)

\(T\) test cases. For each test case, evaluate:

\[ \sum_{i=1}^n\sum_{j=1}^m\sigma_0(ij). \]

Here \(\sigma_0(n)=\sum_{d \mid n}1\) denotes the number of divisors of \(n\).

Constraints: \(1\le n,m,T\le 5\times 10^4\).

Solution

The difficulty of this problem is to transform \(\sigma_0(ij)\) into an expression involving the greatest common divisor. Since \(\sigma_0\) is multiplicative, first consider the case of prime powers. For a prime \(p\) and non-negative exponents \(e_1,e_2\), let \(i=p^{e_1},~j=p^{e_2}\); then

\[ \sigma_0(ij) = 1 + e_1 + e_2 = \sum_{x\mid i}\sum_{y\mid j}[x\perp y]. \]

For the general case, let \(i=\prod_p i_p\) and \(j=\prod_p j_p\), where \(i_p,j_p\) are the prime-power factors corresponding to \(p\) in the prime factorizations of \(i,j\) respectively. Then

\[ \sigma_0(ij) = \prod_p\sigma_0(i_pj_p)= \prod_p\sum_{x_p\mid i_p}\sum_{y_p\mid j_p}[x_p\perp y_p]. \]

Note that enumerating the divisors \(x_p\) of each prime-power factor \(i_p\) of \(i\) is the same as enumerating the divisors \(x\) of \(i\) and then decomposing each into its prime-power factors \(x_p\); similarly for \(j\). Therefore, by the distributive law of multiplication, the expression becomes

\[ \sigma_0(ij) = \sum_{x\mid i}\sum_{y\mid j}\prod_p[x_p\perp y_p] = \sum_{x\mid i}\sum_{y\mid j}[x\perp y]. \]

The last step uses the fact that \(x\perp y\) if and only if \(x_p\perp y_p\) for every prime factor \(p\).

Having obtained this expression, we can apply the standard procedure:

\[ \begin{aligned} \sigma_0(ij) &= \sum_{x\mid i}\sum_{y\mid j}[x\perp y]\\ &= \sum_{x\mid i}\sum_{y\mid j}\sum_d\mu(d)[d\mid x][d\mid y]\\ &= \sum_d\mu(d)\left(\sum_{x}[d\mid x\mid i]\right)\left(\sum_{y}[d\mid y\mid j]\right)\\ &= \sum_d\mu(d)[d\mid i][d\mid j]\sigma_0\left(\dfrac{i}{d}\right)\sigma_0\left(\dfrac{j}{d}\right). \end{aligned} \]

The meaning of the last step is: the function is nonzero only when \(d\mid i\) and \(d\mid j\), and in that case enumerating \(x\) with \(d\mid x\mid i\) is the same as enumerating the divisors \(\dfrac{x}{d}\) of \(\dfrac{i}{d}\); similarly for enumerating \(y\) with \(d\mid y\mid j\).

Substitute this expression back into the original one and exchange the order of summation:

\[ \begin{aligned} f(n,m) &= \sum_{i=1}^n\sum_{j=1}^m\sigma_0(ij)\\ &= \sum_{i=1}^n\sum_{j=1}^m\sum_d\mu(d)[d\mid i][d\mid j]\sigma_0\left(\dfrac{i}{d}\right)\sigma_0\left(\dfrac{j}{d}\right)\\ &= \sum_d\mu(d)\left(\sum_{i=1}^n[d\mid i]\sigma_0\left(\dfrac{i}{d}\right)\right)\left(\sum_{j=1}^m[d\mid j]\sigma_0\left(\dfrac{j}{d}\right)\right)\\ &= \sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/d\rfloor}\sigma_0(i)\right)\left(\sum_{j=1}^{\lfloor m/d\rfloor}\sigma_0(j)\right). \end{aligned} \]

Let \(G(n)=\sum_{i=1}^n\sigma_0(i)\); then

\[ f(n,m)=\sum_{d}\mu(d)G\left(\left\lfloor\dfrac{n}{d}\right\rfloor\right)G\left(\left\lfloor\dfrac{m}{d}\right\rfloor\right). \]

This can be solved with floor-division blocks. It suffices to precompute the prefix sums of \(\mu(n)\) and \(\sigma_0(n)\). The total time complexity is \(O(N+T\sqrt{N})\), where \(N\) is the upper bound of \(n,m\) and \(T\) is the number of test cases.

Reference code 
#include <algorithm>
#include <iostream>
using namespace std;
constexpr long long N = 5e4 + 5;
long long n, m, T, pr[N], mu[N], d[N], t[N],
    cnt;  // t is the number of times the smallest prime factor of i appears
bool bp[N];

void prime_work(long long k) {
  bp[0] = bp[1] = true, mu[1] = 1, d[1] = 1;
  for (long long i = 2; i <= k; i++) {  // linear sieve
    if (!bp[i]) pr[++cnt] = i, mu[i] = -1, d[i] = 2, t[i] = 1;
    for (long long j = 1; j <= cnt && i * pr[j] <= k; j++) {
      bp[i * pr[j]] = true;
      if (i % pr[j] == 0) {
        mu[i * pr[j]] = 0;
        d[i * pr[j]] = d[i] / (t[i] + 1) * (t[i] + 2);
        t[i * pr[j]] = t[i] + 1;
        break;
      } else {
        mu[i * pr[j]] = -mu[i];
        d[i * pr[j]] = d[i] << 1;
        t[i * pr[j]] = 1;
      }
    }
  }
  for (long long i = 2; i <= k; i++)
    mu[i] += mu[i - 1], d[i] += d[i - 1];  // prefix sums
}

long long solve() {
  long long res = 0, mxi = min(n, m);
  for (long long i = 1, j; i <= mxi; i = j + 1) {  // floor-division blocks
    j = min(n / (n / i), m / (m / i));
    res += d[n / i] * d[m / i] * (mu[j] - mu[i - 1]);
  }
  return res;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> T;
  prime_work(50000);  // precomputation
  while (T--) {
    cin >> n >> m;
    cout << solve() << '\n';
  }
  return 0;
}

The last example problem shows how to apply the multiplicative version of Möbius inversion.

Luogu P5221 Product

Evaluate:

\[ \prod_{i=1}^n\prod_{j=1}^n\dfrac{\operatorname{lcm}(i,j)}{\gcd(i,j)}\pmod{104857601}. \]

Constraints: \(1\le n\le 1\times 10^6\).

Solution 1

We ignore the modulus during the derivation. Let

\[ f(n) = \prod_{i=1}^n\prod_{j=1}^n\dfrac{\operatorname{lcm}(i,j)}{\gcd(i,j)}. \]

As before, convert the least common multiple into the greatest common divisor:

\[ f(n) = \prod_{i=1}^n\prod_{j=1}^n\dfrac{ij}{(\gcd(i,j))^2}. \]

Note that the products of these factors are independent of each other and can be computed separately. Let

\[ g(n) = \prod_{i=1}^n\prod_{j=1}^n\gcd(i,j). \]

The original expression then equals:

\[ f(n) = \dfrac{(n!)^{2n}}{g(n)^2}. \]

The key is to compute \(g(n)\). The procedure for handling it is similar to the one described above, but it must be replaced by the corresponding multiplicative version. First, enumerate and extract the common divisor:

\[ \begin{aligned} g(n) &= \prod_k\prod_{i=1}^n\prod_{j=1}^nk\uparrow[\gcd(i,j)=k]\\ &= \prod_k\prod_{i=1}^{\lfloor n/k\rfloor}\prod_{j=1}^{\lfloor n/k\rfloor}k\uparrow[\gcd(i,j)=1]. \end{aligned} \]

Here \(a\uparrow b=a^b\) is Knuth's arrow. Then substitute \([\gcd(i,j)=1]=\sum_d\mu(d)[d\mid i][d\mid j]\) and convert the sum in the exponent into a product of powers, obtaining:

\[ g(n) = \prod_k\prod_d\prod_{i=1}^{\lfloor n/k\rfloor}\prod_{j=1}^{\lfloor n/k\rfloor}k\uparrow(\mu(d)[d\mid i][d\mid j]). \]

Further extract the factor (i.e. set \(i=di'\), \(j=dj'\)) and apply the property of the floor function, obtaining:

\[ g(n) = \prod_k\prod_d\prod_{i=1}^{\lfloor n/(kd)\rfloor}\prod_{j=1}^{\lfloor n/(kd)\rfloor}k\uparrow\mu(d). \]

Then separate the products over \(i,j\) and notice that the factor does not involve \(i,j\), so this amounts to raising the factor to a power:

\[ g(n) = \prod_k\prod_d k\uparrow\left(\mu(d)\left\lfloor\dfrac{n}{kd}\right\rfloor^2\right). \]

Since we enumerated a common divisor earlier, the order of the product in this expression needs to be exchanged again. Setting \(\ell = kd\), we have:

\[ \begin{aligned} g(n) &= \prod_{\ell}\prod_{d\mid\ell}\left(\dfrac{\ell}{d}\right)\uparrow\left(\mu(d)\left\lfloor\dfrac{n}{\ell}\right\rfloor^2\right)\\ &= \prod_\ell\left(\prod_{d\mid\ell}\left(\dfrac{\ell}{d}\right)\uparrow\mu(d)\right)\uparrow\left\lfloor\dfrac{n}{\ell}\right\rfloor^2. \end{aligned} \]

Let

\[ F(n) = \prod_{d\mid n}\left(\dfrac{n}{d}\right)\uparrow\mu(d). \]

It is easy to see that this is the multiplicative-form Möbius inversion of \(\tilde F(n)=n\). Even without knowing its expression, it can be precomputed with the Dirichlet difference method in \(O(n\log\log n)\) time. Of course, since the form of \(\tilde F(n)\) is very simple, the expression of \(F(n)\) can be found directly:

\[ F(n) = \begin{cases} p, & n = p^e,~p\in\mathbf P,~e\in\mathbf N_+, \\ 1, &\text{otherwise}. \end{cases} \]

The von Mangoldt function is exactly its natural logarithm. After obtaining the values of \(F(n)\), directly applying the product version of floor-division blocks computes \(g(n)\) in \(O(\sqrt{n})\) time, and hence \(f(n)\). The total time complexity is \(O(n)\).

It is worth noting that computations involving products often require Euler's theorem, so the modulus used for the exponents is not the same as the modulus given in the problem.

Solution 2

The difficulty of the multiplicative-version derivation is that handling products and powers is relatively unfamiliar; therefore, for such problems one can also take logarithms first and then derive. For this problem, we only consider the derivation of \(g(n)\). Taking logarithms gives:

\[ \log g(n) = \sum_{i=1}^n\sum_{j=1}^n\log\gcd(i,j). \]

For such expressions involving the greatest common divisor, directly applying the standard derivation procedure gives:

\[ \begin{aligned} \log g(n) &= \sum_k\log k\sum_{i=1}^n\sum_{j=1}^n[\gcd(i,j)=k]\\ &= \sum_k\log k\sum_{i=1}^{\lfloor n/k\rfloor}\sum_{j=1}^{\lfloor n/k\rfloor}[\gcd(i,j)=1]\\ &= \sum_k\log k\sum_d\mu(d)\left(\sum_{i=1}^{\lfloor n/k\rfloor}[d\mid i]\right)\left(\sum_{j=1}^{\lfloor n/k\rfloor}[d\mid j]\right)\\ &= \sum_k\log k\sum_d\mu(d)\left\lfloor\dfrac{n}{kd}\right\rfloor^2\\ &= \sum_{\ell}\left(\sum_{d\mid\ell}\mu(d)\log\dfrac{\ell}{d}\right)\left\lfloor\dfrac{n}{\ell}\right\rfloor^2\\ &= \sum_{\ell}\Lambda(\ell)\left\lfloor\dfrac{n}{\ell}\right\rfloor^2. \end{aligned} \]

Here \(\Lambda(n)\) is the von Mangoldt function. Exponentiating this result gives the result of Solution 1.

#include <algorithm>
#include <iostream>
#include <vector>

int pow(int a, int b, int m) {
  int res = 1;
  for (int po = a; b; b >>= 1) {
    if (b & 1) res = 1LL * res * po % m;
    po = 1LL * po * po % m;
  }
  return res;
}

int main() {
  constexpr int M = 104857601;
  int n;
  std::cin >> n;
  // Get F(n), i.e., exp(Lambda(n)).
  std::vector<int> vis(n + 1), prime, pf(n + 1), rem(n + 1);
  prime.reserve(n);
  for (int x = 2; x <= n; ++x) {
    if (!vis[x]) {
      prime.emplace_back(x);
      pf[x] = x;
      rem[x] = 1;
    }
    for (int p : prime) {
      if (1LL * p * x > n) break;
      vis[x * p] = 1;
      pf[x * p] = p;
      rem[x * p] = x % p ? x : rem[x];
      if (x % p == 0) break;
    }
  }
  pf[1] = 1;
  for (int x = 2; x <= n; ++x) {
    pf[x] = rem[x] == 1 ? pf[x] : 1;
  }
  // Prefix products and their inverses.
  std::vector<int> pm(n + 1), ip(n + 1);
  pm[0] = 1;
  for (int x = 1; x <= n; ++x) {
    pm[x] = 1LL * pm[x - 1] * pf[x] % M;
  }
  int inv = pow(pm[n], M - 2, M);
  ip[0] = 1;
  for (int x = n; x >= 1; --x) {
    ip[x] = inv;
    inv = 1LL * inv * pf[x] % M;
  }
  // Calculate g(n).
  int res = 1;
  for (int l = 1, r; l <= n; l = r + 1) {
    r = n / (n / l);
    int a = 1LL * pm[r] * ip[l - 1] % M;
    int b = 1LL * (n / l) * (n / l) % (M - 1);
    res = 1LL * res * pow(a, b, M) % M;
  }
  // Take square and then inverse.
  res = pow(res, M - 3, M);
  // Get factorials.
  int fac = 1;
  for (int x = 1; x <= n; ++x) {
    fac = 1LL * fac * x % M;
  }
  // Final answer.
  res = 1LL * res * pow(fac, 2 * n, M) % M;
  std::cout << res << std::endl;
  return 0;
}
