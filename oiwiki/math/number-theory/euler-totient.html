Definicija

Eulerova funkcija (Euler's totient function), tj. \(\varphi(n)\), označava broj brojeva manjih ili jednakih \(n\) koji su relativno prosti s \(n\).

Na primjer, \(\varphi(1) = 1\).

Kad je \(n\) prost, očito je \(\varphi(n) = n - 1\).

Svojstva

  • Eulerova funkcija je multiplikativna funkcija.

    Odnosno, za sve cijele brojeve \(a,b\) za koje je \(\gcd(a, b) = 1\) vrijedi \(\varphi(ab) = \varphi(a)\varphi(b)\).

    Posebno, kad je \(n\) neparan, vrijedi \(\varphi(2n) = \varphi(n)\).

    Dokaz vidi u Kompoziciji sustava ostataka.

  • \(n = \sum_{d \mid n}{\varphi(d)}\).

    Dokaz

    Može se izvesti pomoću znanja o Möbiusovoj inverziji.

    Može se razmišljati i ovako: ako je \(\gcd(k, n) = d\), onda je \(\gcd(\dfrac{k}{d},\dfrac{n}{d}) = 1, ( k < n )\).

    Ako s \(f(x)\) označimo broj brojeva za koje je \(\gcd(k, n) = x\), onda je \(n = \sum_{i = 1}^n{f(i)}\).

    Prema gornjem dokazu uočavamo da je \(f(x) = \varphi(\dfrac{n}{x})\), pa je \(n = \sum_{d \mid n}\varphi(\dfrac{n}{d})\). Primijetimo da su djelitelji \(d\) i \(\dfrac{n}{d}\) simetrični, pa se gornja formula svodi na \(n = \sum_{d \mid n}\varphi(d)\).

  • Ako je \(n = p^k\), gdje je \(p\) prost, onda je \(\varphi(n) = p^k - p^{k - 1}\). (slijedi iz definicije)

  • Po osnovnom teoremu aritmetike, neka je \(n = \prod_{i=1}^{s}p_i^{k_i}\), gdje su \(p_i\) prosti; tada je \(\varphi(n) = n \times \prod_{i = 1}^s{\dfrac{p_i - 1}{p_i}}\).

    Dokaz

    • Lema: neka je \(p\) bilo koji prost broj; tada je \(\varphi(p^k)=p^{k-1}\times(p-1)\).

      Dokaz: očito su među svim brojevima od \(1\) do \(p^k\) svi osim \(p^{k-1}\) višekratnika broja \(p\) relativno prosti s \(p^k\), pa je \(\varphi(p^k)=p^k-p^{k-1}=p^{k-1}\times(p-1)\), što je i trebalo dokazati.

    Sada dokazujemo \(\varphi(n) = n \times \prod_{i = 1}^s{\dfrac{p_i - 1}{p_i}}\). Iz osnovnog teorema aritmetike i multiplikativnosti funkcije \(\varphi(x)\) slijedi

    \[ \begin{aligned} \varphi(n) &= \prod_{i=1}^{s} \varphi(p_i^{k_i}) \\ &= \prod_{i=1}^{s} (p_i-1)\times {p_i}^{k_i-1}\\ &=\prod_{i=1}^{s} {p_i}^{k_i} \times(1 - \frac{1}{p_i})\\ &=n~ \prod_{i=1}^{s} (1- \frac{1}{p_i}) &\square \end{aligned} \]

  • Za sve pozitivne cijele brojeve \(m,n\) vrijedi \(\varphi(mn)\varphi(\gcd(m,n))=\varphi(m)\varphi(n)\gcd(m,n)\).

    Slijedi izravnim računom iz prethodnog svojstva.

Implementacija

Ako trebamo vrijednost Eulerove funkcije samo za jedan broj, računamo je izravno po definiciji, usporedno s rastavom na proste faktore. Taj se postupak može ubrzati algoritmom Pollard rho.

Referentna implementacija 
#include <cmath>

int euler_phi(int n) {
  int ans = n;
  for (int i = 2; i * i <= n; i++)
    if (n % i == 0) {
      ans = ans / i * (i - 1);
      while (n % i == 0) n /= i;
    }
  if (n > 1) ans = ans / n * (n - 1);
  return ans;
}

import math


def euler_phi(n):
    ans = n
    for i in range(2, math.isqrt(n) + 1):
        if n % i == 0:
            ans = ans // i * (i - 1)
            while n % i == 0:
                n = n // i
    if n > 1:
        ans = ans // n * (n - 1)
    return ans

Ako trebamo vrijednosti Eulerove funkcije za više brojeva, možemo ih izračunati linearnim sitom, koje će biti opisano kasnije.

Detalje vidi u: Računanje Eulerove funkcije sitom

Primjene

Eulerova funkcija često se koristi za pojednostavljivanje zbroja niza najvećih zajedničkih djelitelja. U nekim kineskim člancima to se naziva Eulerovom inverzijom1.

Uvrstimo li u tvrdnju

\[ n=\sum_{d \mid n}\varphi(d) \]

\(n=\gcd(a,b)\), dobivamo

\[ \gcd(a,b) = \sum_{d \mid \gcd(a,b)}\varphi(d) = \sum_d [d \mid a][d \mid b]\varphi(d), \]

gdje je \([\cdot]\) Iversonova zagrada. Sumiranjem gornje formule dobivamo

\[ \sum_{i=1}^n\gcd(i,n)=\sum_{d}\sum_{i=1}^n[d \mid i][d \mid n]\varphi(d)=\sum_d\left\lfloor\frac{n}{d}\right\rfloor[d \mid n]\varphi(d)=\sum_{d \mid n}\left\lfloor\frac{n}{d}\right\rfloor\varphi(d). \]

Ključno je opažanje \(\sum_{i=1}^n[d \mid i]=\lfloor\frac{n}{d}\rfloor\), tj. broj brojeva \(i\) između \(1\) i \(n\) djeljivih s \(d\) jednak je \(\lfloor\frac{n}{d}\rfloor\).

Pomoću te formule zbroj možemo izračunati prolaskom kroz djelitelje. Kad ima više upita, možemo unaprijed izračunati prefiksne sume Eulerove funkcije i odgovarati blokovskim dijeljenjem po cjelobrojnom kvocijentu (数论分块).

GCD SUM

Zadan je \(n\le 100000\); izračunajte

\[ \sum_{i=1}^n\sum_{j=1}^n\gcd(i,j). \]
Ideja

Po uzoru na gornje izvođenje dobivamo

\[ \sum_{i=1}^n\sum_{j=1}^n\gcd(i,j) = \sum_{d=1}^n\left\lfloor\frac{n}{d}\right\rfloor^2\varphi(d). \]

Ovdje treba izračunati Eulerovu funkciju za sve brojeve od \(1\) do \(n\); linearnim sitom odgovor dobivamo u \(O(n)\).

Eulerov teorem

Teorem usko povezan s Eulerovom funkcijom jest Eulerov teorem. Glasi ovako:

Ako je \(\gcd(a, m) = 1\), onda je \(a^{\varphi(m)} \equiv 1 \pmod{m}\).

Prošireni Eulerov teorem

Naravno, postoji i prošireni Eulerov teorem, koji se bavi slučajem općih \(a\) i \(m\).

\[ a^b\equiv \begin{cases} a^{b\bmod\varphi(m)},\,&\gcd(a,\,m)=1\\ a^b,&\gcd(a,\,m)\ne1,\,b<\varphi(m)\\ a^{b\bmod\varphi(m)+\varphi(m)},&\gcd(a,\,m)\ne1,\,b\ge\varphi(m) \end{cases} \pmod m \]

Dokaz i zadatke vidi u Eulerovu teoremu.

Definition

Euler's totient function, i.e., \(\varphi(n)\), denotes the number of integers less than or equal to \(n\) that are coprime to \(n\).

For example, \(\varphi(1) = 1\).

When \(n\) is prime, obviously \(\varphi(n) = n - 1\).

Properties

  • Euler's totient function is a multiplicative function.

    That is, for any integers \(a,b\) with \(\gcd(a, b) = 1\), we have \(\varphi(ab) = \varphi(a)\varphi(b)\).

    In particular, when \(n\) is odd, \(\varphi(2n) = \varphi(n)\).

    For a proof, see Composition of residue systems.

  • \(n = \sum_{d \mid n}{\varphi(d)}\).

    Proof

    This can be derived using knowledge of Möbius inversion.

    One can also think of it this way: if \(\gcd(k, n) = d\), then \(\gcd(\dfrac{k}{d},\dfrac{n}{d}) = 1, ( k < n )\).

    If we let \(f(x)\) denote the number of integers with \(\gcd(k, n) = x\), then \(n = \sum_{i = 1}^n{f(i)}\).

    By the proof above, we find that \(f(x) = \varphi(\dfrac{n}{x})\), hence \(n = \sum_{d \mid n}\varphi(\dfrac{n}{d})\). Note that the divisors \(d\) and \(\dfrac{n}{d}\) are symmetric, so the formula above becomes \(n = \sum_{d \mid n}\varphi(d)\).

  • If \(n = p^k\), where \(p\) is prime, then \(\varphi(n) = p^k - p^{k - 1}\). (follows from the definition)

  • By the fundamental theorem of arithmetic, let \(n = \prod_{i=1}^{s}p_i^{k_i}\), where the \(p_i\) are primes; then \(\varphi(n) = n \times \prod_{i = 1}^s{\dfrac{p_i - 1}{p_i}}\).

    Proof

    • Lemma: let \(p\) be any prime; then \(\varphi(p^k)=p^{k-1}\times(p-1)\).

      Proof: obviously, among all the numbers from \(1\) to \(p^k\), all except the \(p^{k-1}\) multiples of \(p\) are coprime to \(p^k\), so \(\varphi(p^k)=p^k-p^{k-1}=p^{k-1}\times(p-1)\), which completes the proof.

    Next we prove \(\varphi(n) = n \times \prod_{i = 1}^s{\dfrac{p_i - 1}{p_i}}\). By the fundamental theorem of arithmetic and the multiplicativity of the function \(\varphi(x)\),

    \[ \begin{aligned} \varphi(n) &= \prod_{i=1}^{s} \varphi(p_i^{k_i}) \\ &= \prod_{i=1}^{s} (p_i-1)\times {p_i}^{k_i-1}\\ &=\prod_{i=1}^{s} {p_i}^{k_i} \times(1 - \frac{1}{p_i})\\ &=n~ \prod_{i=1}^{s} (1- \frac{1}{p_i}) &\square \end{aligned} \]

  • For any positive integers \(m,n\), \(\varphi(mn)\varphi(\gcd(m,n))=\varphi(m)\varphi(n)\gcd(m,n)\).

    This follows by direct computation from the previous property.

Implementation

If only the totient of a single number is needed, just compute it directly from the definition while doing the prime factorization. This process can be optimized with the Pollard rho algorithm.

Reference implementation 
#include <cmath>

int euler_phi(int n) {
  int ans = n;
  for (int i = 2; i * i <= n; i++)
    if (n % i == 0) {
      ans = ans / i * (i - 1);
      while (n % i == 0) n /= i;
    }
  if (n > 1) ans = ans / n * (n - 1);
  return ans;
}

If the totients of several numbers are needed, they can be computed with the linear sieve, which will be introduced later.

Applications

Euler's totient function is often used to simplify a sum of greatest common divisors. Some Chinese articles call this Euler inversion1.

Substituting \(n=\gcd(a,b)\) into the result

\[ n=\sum_{d \mid n}\varphi(d) \]

we get

\[ \gcd(a,b) = \sum_{d \mid \gcd(a,b)}\varphi(d) = \sum_d [d \mid a][d \mid b]\varphi(d), \]

where \([\cdot]\) is the Iverson bracket. Summing the formula above, we obtain

\[ \sum_{i=1}^n\gcd(i,n)=\sum_{d}\sum_{i=1}^n[d \mid i][d \mid n]\varphi(d)=\sum_d\left\lfloor\frac{n}{d}\right\rfloor[d \mid n]\varphi(d)=\sum_{d \mid n}\left\lfloor\frac{n}{d}\right\rfloor\varphi(d). \]

The key observation here is \(\sum_{i=1}^n[d \mid i]=\lfloor\frac{n}{d}\rfloor\), i.e., the number of integers \(i\) between \(1\) and \(n\) divisible by \(d\) is \(\lfloor\frac{n}{d}\rfloor\).

Using this formula, we can compute the sum by iterating over the divisors. When multiple queries are needed, we can precompute the prefix sums of Euler's totient function and answer queries with floor-division blocks (number-theoretic blocking).

GCD SUM

Given \(n\le 100000\), compute

\[ \sum_{i=1}^n\sum_{j=1}^n\gcd(i,j). \]
Idea

Following the derivation above, we obtain

\[ \sum_{i=1}^n\sum_{j=1}^n\gcd(i,j) = \sum_{d=1}^n\left\lfloor\frac{n}{d}\right\rfloor^2\varphi(d). \]

Here we need the totients of all numbers from \(1\) to \(n\); using the linear sieve, the answer is obtained in \(O(n)\).

Euler's theorem

A theorem closely related to Euler's totient function is Euler's theorem. It states the following:

If \(\gcd(a, m) = 1\), then \(a^{\varphi(m)} \equiv 1 \pmod{m}\).

Extended Euler's theorem

Of course, there is also the extended Euler's theorem, which handles the case of general \(a\) and \(m\).

\[ a^b\equiv \begin{cases} a^{b\bmod\varphi(m)},\,&\gcd(a,\,m)=1\\ a^b,&\gcd(a,\,m)\ne1,\,b<\varphi(m)\\ a^{b\bmod\varphi(m)+\varphi(m)},&\gcd(a,\,m)\ne1,\,b\ge\varphi(m) \end{cases} \pmod m \]

For the proof and exercises, see Euler's theorem.
