Uvod

Brzo potenciranje (fast exponentiation), poznato i kao binarno potenciranje (binary exponentiation) ili potenciranje kvadriranjem (exponentiation by squaring), mali je trik kojim se \(a^n\) računa u vremenu \(\Theta(\log n)\), dok naivno računanje zahtijeva vrijeme \(\Theta(n)\).

Trik se može primijeniti u svakoj situaciji u kojoj je množenje za \(a\) asocijativno, npr. pri potenciranju u modularnoj aritmetici, potenciranju matrica itd.; pojedinosti vidi u odjeljku Primjene u nastavku.

Postupak

Računanje \(n\)-te potencije broja \(a\) znači množenje \(n\) kopija broja \(a\): \(a^{n} = \underbrace{a \times a \cdots \times a}_{n\text{ faktora a}}\). Međutim, kad je \(n\) prevelik ili je jedno množenje preskupo, taj način nije prikladan. Ideja binarnog potenciranja jest razbiti zadatak potenciranja na manje zadatke prema binarnom zapisu eksponenta.

Primjer

Pretpostavimo da treba izračunati \(3^{13}\). Ako to raspišemo kao umnožak, treba \(13-1=12\) množenja. Međutim, budući da je

\[ 3^{13} = 3^{(1101)_2} = 3^8 \times 3^4 \times 3^1, \]

dovoljno je brzo izračunati \(3^{1},3^{2},3^{4},3^{8}\) pa vrijednost \(3^{13}\) dobivamo s \(2\) množenja. Dakle, treba samo znati brz način za računanje gornjeg niza potencija broja \(3\) s eksponentima \(2^k\). To je lako, jer je svaki element niza (osim prvog) kvadrat prethodnog.

Iz te analize dobivamo sljedeći postupak računanja \(3^{13}\):

\[ \begin{aligned} 3^1 &= 3, \\ 3^2 &= \left(3^1\right)^2 = 3^2 = 9, \\ 3^4 &= \left(3^2\right)^2 = 9^2 = 81, \\ 3^8 &= \left(3^4\right)^2 = 81^2 = 6561, \\ 3^{13} &= 6561 \times 81 \times 3 = 1594323. \end{aligned} \]

U postupku je izvedeno samo \(5\) množenja.

To je osnovna ideja brzog potenciranja. Što se tiče konkretne implementacije, postoje dvije uobičajene inačice.

Iterativna inačica

Neka je binarni zapis broja \(n\) jednak \((n_tn_{t-1}\cdots n_1n_0)_2\), tj. vrijedi

\[ n = n_t2^t + n_{t-1}2^{t-1} + \cdots + n_12^1 + n_02^0, \]

gdje je \(n_i\in\{0,1\}\). Tada je

\[ \begin{aligned} a^n & = a^{n_t2^t + n_{t-1}2^{t-1} + \cdots + n_12^1 + n_02^0}\\ & = a^{n_0 2^0} \times a^{n_1 2^1}\times \cdots \times a^{n_{t-1}2^{t-1}} \times a^{n_t2^t}. \end{aligned} \]

Uočimo da se u računanju umnoška zapravo pojavljuju samo članovi s \(n_i=1\).

Prema tom izrazu možemo najprije u vremenu \(\Theta(\log n)\) izračunati vrijednosti \(\Theta(\log n)\) potencija broja \(a\) s eksponentima \(2^k\), a zatim u vremenu \(\Theta(\log n)\) odabrati potencije koje odgovaraju bitovima jednakim \(1\) i pomnožiti ih u konačni rezultat. To je iterativna implementacija brzog potenciranja.

Pseudokod je sljedeći:

\[ \begin{array}{l} \textbf{Algorithm }\text{FastPow}(a, n): \\ \textbf{Input. }\text{Base }a\text{ and exponent }n.\\ \textbf{Output. }\text{Power }a^n.\\ \textbf{Method.}\\ \begin{array}{ll} 1 & \textit{result}\gets\mathrm{Id}\\ 2 & \textbf{while }n > 0\textbf{ do}\\ 3 & \qquad \textbf{if }n \bmod 2 = 1\textbf{ then}\\ 4 & \qquad \qquad \textit{result} \gets \textit{result}\cdot a\\ 5 & \qquad \textbf{end if}\\ 6 & \qquad a \gets a \cdot a\\ 7 & \qquad n \gets n / 2\\ 8 & \textbf{end while}\\ 9 & \textbf{return }\textit{result} \end{array} \end{array} \]

Računanje brzog potenciranja tom metodom zahtijeva \(\Theta(\log n)\) množenja.

Rekurzivna inačica

Taj se postupak može implementirati i rekurzivno. Uočimo da se binarni razvoj eksponenta \(n\) može rekurzivno zapisati kao

\[ (n_tn_{t-1}\cdots n_1n_0)_2 = 2 \times (n_tn_{t-1}\cdots n_1)_2 + n_0. \]

Stoga se potencija \(a^n\) može rekurzivno računati kao

\[ a^n = \begin{cases} 1, & n = 0,\\ (a^{\lfloor n/2\rfloor})^2, & n > 0 \text{ and }n\text{ is even},\\ (a^{\lfloor n/2\rfloor})^2\cdot a, & n > 0 \text{ and }n\text{ is odd}.\\ \end{cases} \]

To je rekurzivna implementacija brzog potenciranja.

Pseudokod je sljedeći:

\[ \begin{array}{l} \textbf{Algorithm }\text{FastPow}(a, n): \\ \textbf{Input. }\text{Base }a\text{ and exponent }n.\\ \textbf{Output. }\text{Power }a^n.\\ \textbf{Method.}\\ \begin{array}{ll} 1 & \textbf{if }n = 0\textbf{ then}\\ 2 & \qquad \textbf{return }\mathrm{Id}\\ 3 & \textbf{end if}\\ 4 & \textit{result} \gets \text{FastPow}(a, n / 2) \\ 5 & \textbf{if }n\bmod 2 = 0\textbf{ then}\\ 6 & \qquad \textbf{return }\textit{result}\cdot\textit{result}\\ 7 & \textbf{else}\\ 8 & \qquad \textbf{return }\textit{result}\cdot\textit{result}\cdot a\\ 9 & \textbf{end if} \end{array} \end{array} \]

Računanje brzog potenciranja tom metodom zahtijeva \(\Theta(\log n)\) rekurzivnih poziva i također \(\Theta(\log n)\) množenja. Iako je složenost ista, zbog određenog troška same rekurzije iterativna je inačica u praksi brža.

Primjene

Modularno potenciranje

Luogu P1226【模板】快速幂 (Predložak: brzo potenciranje)

Zadana su tri cijela broja \(a,b,p\); izračunajte \(a^b\bmod p\), pri čemu je \(p\ge 2\).

Ovo je vrlo česta primjena; npr. može se koristiti za računanje multiplikativnog inverza u modularnoj aritmetici. Budući da znamo da uzimanje ostatka ne smeta množenju, dovoljno je uzimati ostatak tijekom računanja.

Najprije možemo izravno implementirati gornju rekurzivnu metodu:

Referentna implementacija 
long long binpow(long long a, long long b, long long p) {
  if (b == 0) return 1;
  long long res = binpow(a, b / 2, p);
  if (b % 2)
    return res * res % p * a % p;
  else
    return res * res % p;
}

def binpow(a, b, p):
    if b == 0:
        return 1
    res = binpow(a, b // 2, p)
    if (b % 2) == 1:
        return res * res * a % p
    else:
        return res * res % p

Druga je implementacija nerekurzivna. Tijekom petlje potencije koje odgovaraju bitovima jednakim 1 množi u odgovor. Iako je teorijska složenost obiju implementacija ista, druga je u praksi brža od prve jer rekurzija ima određeni trošak.

Referentna implementacija 
long long binpow(long long a, long long b, long long p) {
  long long res = 1;
  while (b > 0) {
    if (b & 1) res = res * a % p;
    a = a * a % p;
    b >>= 1;
  }
  return res;
}

def binpow(a, b, p):
    res = 1
    while b > 0:
        if b & 1:
            res = res * a % p
        a = a * a % p
        b >>= 1
    return res
Napomena
  • Modul je u pravilu veći od \(1\). U vrlo posebnim slučajevima modul \(p\) može biti jednak \(1\); tada treba posebno razmotriti slučaj \(b=0\).
  • Kad je eksponent vrlo velik, treba ga smanjiti pomoću proširenog Eulerova teorema pa tek onda računati.

Računanje Fibonaccijevih brojeva

Prema rekurziji Fibonaccijeva niza \(F_n = F_{n-1} + F_{n-2}\) možemo sastaviti matricu \(2\times 2\) koja opisuje prijelaz iz \(F_i,F_{i+1}\) u \(F_{i+1},F_{i+2}\). Pri računanju \(n\)-te potencije te matrice primjenjujemo ideju brzog potenciranja i rezultat dobivamo u vremenu \(\Theta(\log n)\). Više pojedinosti vidi u Fibonaccijev niz, a implementaciju brzog potenciranja matrica u Ubrzavanje rekurzija matricama.

Višestruka primjena permutacije

Opis problema

Zadan je niz duljine \(n\) i permutacija; primijenite tu permutaciju na niz \(k\) puta.

Dovoljno je permutaciju potencirati na \(k\)-tu potenciju i zatim je primijeniti na niz. Vremenska složenost je \(O(n \log k)\). Više pojedinosti vidi u Kompozicija permutacija.

Napomena

Ako od permutacije izgradimo graf i na svakom ciklusu zasebno izračunamo \(k\)-tu potenciju (što je zapravo ekvivalentno uzimanju \(k\) modulo duljina ciklusa), problem se može riješiti u vremenskoj složenosti \(O(n)\).

Ubrzavanje operacija nad skupom točaka u geometriji

HDU 4087 A Letter to Programmers

Zadano je \(n\) točaka \(p_i\) u trodimenzionalnom prostoru; na te točke treba primijeniti svih \(m\) operacija. Postoje 3 vrste operacija:

  1. pomak točke duž nekog vektora (Shift),
  2. skaliranje koordinata točke zadanim faktorom (Scale),
  3. rotacija oko nekog pravca (Rotate).

Postoji i posebna operacija koja neki niz operacija ponavlja \(k\) puta (Repeat); operacije Repeat mogu biti ugniježđene. Ispišite koordinate svake točke nakon završetka svih operacija.

Prema sadržaju stranice Vektori i matrice, svaka se operacija može prikazati matricom transformacije, a niz uzastopnih transformacija umnoškom matrica. Jedna operacija Repeat odgovara \(k\)-toj potenciji matrice. Tako u vremenu \(O(m \log k)\) možemo izračunati matricu koju na kraju tvori cijeli niz transformacija. Na kraju je primijenimo na \(n\) točaka; ukupna složenost je \(O(n + m \log k)\).

Prebrojavanje puteva fiksne duljine

Opis problema

Zadan je usmjereni graf (težine bridova su 1); za svaki par vrhova \(u,v\) odredite broj puteva duljine \(k\) od \(u\) do \(v\).

Matricu susjedstva \(M\) tog grafa potenciramo na \(k\)-tu potenciju; tada \(M_{i,j}\) predstavlja broj puteva duljine \(k\) od \(i\) do \(j\). Složenost tog algoritma je \(O(n^3 \log k)\). Pojedinosti o algoritmu vidi na stranici Matrice.

Modularno množenje cijelih brojeva

Opis problema

Zadani su nenegativni cijeli brojevi \(a,b\) i pozitivan cijeli broj \(m\); izračunajte \(a\times b\bmod m\), pri čemu je \(a,b\le m\le 10^{18}\).

Istom idejom kao kod binarnog potenciranja, ovaj put jedan od faktora prikazujemo kao zbroj nekoliko cjelobrojnih potencija broja 2. Naime, množenje broja s 2 uz uzimanje ostatka možemo svesti na zbrajanje i oduzimanje te tako spriječiti prelijevanje cijelih brojeva. Tako problem rješavamo u vremenskoj složenosti \(O (\log m)\). Rekurzivna metoda je sljedeća:

\[ a \cdot b = \begin{cases} 0 &\text{if }a = 0 \\ 2 \cdot \frac{a}{2} \cdot b &\text{if }a > 0 \text{ and }a \text{ even} \\ 2 \cdot \frac{a-1}{2} \cdot b + b &\text{if }a > 0 \text{ and }a \text{ odd} \end{cases} \]

No u praksi ta metoda zbog veće računske složenosti nije vremenski učinkovita. U stvarnom programiranju za množenje s modulom u rasponu long long obično se koristi brzo množenje.

Brzo potenciranje velikih brojeva

Preduvjet: Množenje velikih brojeva

Luogu P1045 [NOIP 2003 普及组] 麦森数 (Mersenneovi brojevi)

Zadan je cijeli broj \(P\) (\(1000 < P < 3100000\)); izračunajte broj znamenki broja \(2^P−1\) i njegovih posljednjih \(500\) znamenki (u dekadskom zapisu); ako ima manje od \(500\) znamenki, dopunite ga nulama 0 na višim mjestima.

Implementacija 
#include <cmath>
#include <cstring>
#include <iostream>
using namespace std;

const int M = 500;

int a[505], b[505], t[505];

// množenje velikih brojeva
void mult(int x[], int y[]) {
  memset(t, 0, sizeof(t));
  for (int i = 1; i <= x[0]; i++) {
    for (int j = 1; j <= y[0]; j++) {
      if (i + j - 1 > M) continue;
      t[i + j - 1] += x[i] * y[j];
      t[i + j] += t[i + j - 1] / 10;
      t[i + j - 1] %= 10;
      t[0] = i + j;
    }
  }
  memcpy(b, t, sizeof(b));
}

// brzo potenciranje
void binpow(int p) {
  if (p == 1) {
    memcpy(b, a, sizeof(b));
    return;
  }
  binpow(p / 2);  // (2^(p/2))^2=2^p
  mult(b, b);     // kvadriraj b
  if (p % 2 == 1) mult(b, a);
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  int p;
  cin >> p;
  a[0] = 1;  // broj znamenki u nizu a
  a[1] = 2;  // kvadriramo broj 2
  b[0] = 1;  // broj znamenki u nizu b
  b[1] = 1;  // niz s rezultatom
  binpow(p);
  cout << (int)(log10(2) * p) + 1 << '\n';
  b[1] -= 1;  // oduzmi 1 od posljednje znamenke
  for (int i = M; i >= 1; i--) {
    cout << b[i];
    if ((i - 1) % 50 == 0) {
      cout << '\n';
    }
  }
}

Brzo potenciranje s fiksnom bazom i pretprocesiranjem

Kad je baza \(a\) fiksna, možemo iskoristiti ideju dekompozicije na blokove: nakon određenog vremena pretprocesiranja na upit o potenciji odgovaramo u vremenu \(O(1)\). Taj se algoritam često naziva i „svjetlosno brzim potenciranjem” (光速幂). Postupak je sljedeći:

  1. Odaberemo broj \(s\), pretprocesiranjem izračunamo vrijednosti \(a^0,a^1,\cdots,a^{s-1}\) i \(a^0,a^s,\cdots,a^{\lfloor p/s\rfloor s}\) te ih pohranimo u dva niza;
  2. Za svaki upit \(a^b\) rastavimo \(b\) na \(\lfloor b/s\rfloor s+(b\bmod s)\); tada je \(a^b=a^{\lfloor b/s\rfloor s}\cdot a^{b\bmod s}\), pa odgovor dobivamo u \(O(1)\).

Pretpostavimo da je raspon eksponenta \(b\) jednak \([0,n]\); tada se za duljinu bloka \(s\) često bira \(\sqrt{n}\) ili njemu bliska potencija broja \(2\). Izbor \(\sqrt{n}\) daje optimalnu složenost pretprocesiranja \(O(\sqrt{n})\), a izbor potencije broja \(2\) omogućuje pojednostavljenje računanja bitovnim operacijama.

Posebno, pri računanju potencija u modularnoj aritmetici jednaka baza \(a\) implicitno zahtijeva i jednak modul \(m\). Zbog proširenog Eulerova teorema, za proizvoljan modul \(m\) gornja granica raspona eksponenata koje treba pretprocesirati jest \(n = 2\varphi(m)\); za prost modul \(p\) gornja granica jest \(n = p - 1\). U oba je slučaja složenost pretprocesiranja \(O(\sqrt{m})\).

Referentni kod 
int a, mod, pow1[65536], pow2[65536];

void preproc() {
  pow1[0] = pow2[0] = 1;
  for (int i = 1; i < 65536; i++) pow1[i] = 1LL * pow1[i - 1] * a % mod;
  int pow65536 = 1LL * pow1[65535] * a % mod;
  for (int i = 1; i < 65536; i++) pow2[i] = 1LL * pow2[i - 1] * pow65536 % mod;
}

int query(int pows) {
  return 1LL * pow1[pows & 65535] * pow2[pows >> 16] % mod;
}

Introduction

Fast exponentiation, also called binary exponentiation or exponentiation by squaring, is a small trick for computing \(a^n\) in \(\Theta(\log n)\) time, whereas the brute-force computation takes \(\Theta(n)\) time.

This trick can be applied in any setting where the multiplication of \(a\) is associative, e.g., modular exponentiation, matrix powers, etc.; see the Applications section below for details.

Procedure

Computing the \(n\)-th power of \(a\) means multiplying \(n\) copies of \(a\) together: \(a^{n} = \underbrace{a \times a \cdots \times a}_{n\text{ copies of a}}\). However, when \(n\) is too large or a single multiplication is too expensive, this method is not very suitable. The idea of binary exponentiation is to split the task of exponentiation into smaller tasks according to the binary representation of the exponent.

Example

Suppose we want to compute \(3^{13}\). If we expand it as a product, \(13-1=12\) multiplications are needed. However, since

\[ 3^{13} = 3^{(1101)_2} = 3^8 \times 3^4 \times 3^1, \]

as long as we can quickly compute \(3^{1},3^{2},3^{4},3^{8}\), we can obtain the value of \(3^{13}\) with \(2\) multiplications. So we only need a fast way to compute the sequence of powers of \(3\) with exponents \(2^k\) above. This is easy, because every element of the sequence (except the first) is the square of the previous one.

From this analysis, the computation of \(3^{13}\) proceeds as follows:

\[ \begin{aligned} 3^1 &= 3, \\ 3^2 &= \left(3^1\right)^2 = 3^2 = 9, \\ 3^4 &= \left(3^2\right)^2 = 9^2 = 81, \\ 3^8 &= \left(3^4\right)^2 = 81^2 = 6561, \\ 3^{13} &= 6561 \times 81 \times 3 = 1594323. \end{aligned} \]

Only \(5\) multiplications were performed in the process.

This is the basic idea of binary exponentiation. As for the concrete implementation, there are two common versions.

Iterative version

Let the binary representation of \(n\) be \((n_tn_{t-1}\cdots n_1n_0)_2\), that is,

\[ n = n_t2^t + n_{t-1}2^{t-1} + \cdots + n_12^1 + n_02^0, \]

where \(n_i\in\{0,1\}\). Then we have

\[ \begin{aligned} a^n & = a^{n_t2^t + n_{t-1}2^{t-1} + \cdots + n_12^1 + n_02^0}\\ & = a^{n_0 2^0} \times a^{n_1 2^1}\times \cdots \times a^{n_{t-1}2^{t-1}} \times a^{n_t2^t}. \end{aligned} \]

Note that only the terms with \(n_i=1\) actually appear in the computation of the product.

According to this expression, we can first compute the values of the \(\Theta(\log n)\) powers of \(a\) with exponents \(2^k\) in \(\Theta(\log n)\) time, and then spend \(\Theta(\log n)\) time selecting the powers corresponding to the binary digits equal to \(1\) and multiplying them into the final result. This is the iterative implementation of binary exponentiation.

The pseudocode is as follows:

\[ \begin{array}{l} \textbf{Algorithm }\text{FastPow}(a, n): \\ \textbf{Input. }\text{Base }a\text{ and exponent }n.\\ \textbf{Output. }\text{Power }a^n.\\ \textbf{Method.}\\ \begin{array}{ll} 1 & \textit{result}\gets\mathrm{Id}\\ 2 & \textbf{while }n > 0\textbf{ do}\\ 3 & \qquad \textbf{if }n \bmod 2 = 1\textbf{ then}\\ 4 & \qquad \qquad \textit{result} \gets \textit{result}\cdot a\\ 5 & \qquad \textbf{end if}\\ 6 & \qquad a \gets a \cdot a\\ 7 & \qquad n \gets n / 2\\ 8 & \textbf{end while}\\ 9 & \textbf{return }\textit{result} \end{array} \end{array} \]

Computing the power with this method requires \(\Theta(\log n)\) multiplications.

Recursive version

This procedure can also be implemented recursively. Note that the binary expansion of the exponent \(n\) can be written recursively as

\[ (n_tn_{t-1}\cdots n_1n_0)_2 = 2 \times (n_tn_{t-1}\cdots n_1)_2 + n_0. \]

Therefore, the power \(a^n\) can be computed recursively as

\[ a^n = \begin{cases} 1, & n = 0,\\ (a^{\lfloor n/2\rfloor})^2, & n > 0 \text{ and }n\text{ is even},\\ (a^{\lfloor n/2\rfloor})^2\cdot a, & n > 0 \text{ and }n\text{ is odd}.\\ \end{cases} \]

This is the recursive implementation of binary exponentiation.

The pseudocode is as follows:

\[ \begin{array}{l} \textbf{Algorithm }\text{FastPow}(a, n): \\ \textbf{Input. }\text{Base }a\text{ and exponent }n.\\ \textbf{Output. }\text{Power }a^n.\\ \textbf{Method.}\\ \begin{array}{ll} 1 & \textbf{if }n = 0\textbf{ then}\\ 2 & \qquad \textbf{return }\mathrm{Id}\\ 3 & \textbf{end if}\\ 4 & \textit{result} \gets \text{FastPow}(a, n / 2) \\ 5 & \textbf{if }n\bmod 2 = 0\textbf{ then}\\ 6 & \qquad \textbf{return }\textit{result}\cdot\textit{result}\\ 7 & \textbf{else}\\ 8 & \qquad \textbf{return }\textit{result}\cdot\textit{result}\cdot a\\ 9 & \textbf{end if} \end{array} \end{array} \]

Computing the power with this method requires \(\Theta(\log n)\) recursive calls and likewise \(\Theta(\log n)\) multiplications. Although the complexity is the same, since recursion itself has some overhead, the iterative version is faster in practice.

Applications

Modular exponentiation

Luogu P1226【模板】快速幂 (Template: Binary Exponentiation)

Given three integers \(a,b,p\), compute \(a^b\bmod p\), where \(p\ge 2\).

This is a very common application; for example, it can be used to compute modular multiplicative inverses. Since we know that taking the remainder does not interfere with multiplication, we only need to take the remainder during the computation.

First, we can implement the recursive method above directly:

Reference implementation 
long long binpow(long long a, long long b, long long p) {
  if (b == 0) return 1;
  long long res = binpow(a, b / 2, p);
  if (b % 2)
    return res * res % p * a % p;
  else
    return res * res % p;
}

def binpow(a, b, p):
    if b == 0:
        return 1
    res = binpow(a, b // 2, p)
    if (b % 2) == 1:
        return res * res * a % p
    else:
        return res * res % p

The second implementation is non-recursive. During the loop, it multiplies the powers corresponding to the binary digits equal to 1 into the answer. Although the theoretical complexity of both is the same, the second is faster than the first in practice, because recursion incurs some overhead.

Reference implementation 
long long binpow(long long a, long long b, long long p) {
  long long res = 1;
  while (b > 0) {
    if (b & 1) res = res * a % p;
    a = a * a % p;
    b >>= 1;
  }
  return res;
}

def binpow(a, b, p):
    res = 1
    while b > 0:
        if b & 1:
            res = res * a % p
        a = a * a % p
        b >>= 1
    return res
Note
  • The modulus is usually greater than \(1\). In very special cases the modulus \(p\) may equal \(1\); then the case \(b=0\) needs special consideration.
  • When the exponent is very large, it must be reduced using the extended Euler's theorem before computing.

Computing Fibonacci numbers

From the recurrence of the Fibonacci sequence \(F_n = F_{n-1} + F_{n-2}\), we can build a \(2\times 2\) matrix representing the transition from \(F_i,F_{i+1}\) to \(F_{i+1},F_{i+2}\). Then, when computing the \(n\)-th power of this matrix, we use the idea of binary exponentiation and obtain the result in \(\Theta(\log n)\) time. For more details see Fibonacci sequence; for the implementation of matrix exponentiation see the implementation in Accelerating recurrences with matrices.

Applying a permutation multiple times

Problem statement

You are given a sequence of length \(n\) and a permutation; apply the permutation to the sequence \(k\) times.

Simply raise the permutation to the \(k\)-th power and then apply it to the sequence. The time complexity is \(O(n \log k)\). For more details see Composition of permutations.

Note

By building a graph from the permutation and computing the \(k\)-th power separately on each cycle (which is in fact equivalent to taking \(k\) modulo the cycle length), the problem can be solved in \(O(n)\) time.

Speeding up operations on a set of points in geometry

HDU 4087 A Letter to Programmers

Given \(n\) points \(p_i\) in three-dimensional space, apply all \(m\) operations to these points. There are 3 kinds of operations:

  1. Move the point along some vector (Shift).
  2. Scale the coordinates of the point by a factor (Scale).
  3. Rotate around some line (Rotate).

There is also a special operation that repeats a sequence of operations \(k\) times (Repeat); Repeat operations can be nested. Output the coordinates of every point after all operations are finished.

Referring to Vectors and matrices, each kind of operation can be represented by a transformation matrix, and a series of consecutive transformations can be represented by a product of matrices. A Repeat operation amounts to taking the \(k\)-th power of a matrix. In this way the matrix formed by the whole sequence of transformations can be computed in \(O(m \log k)\) time. Finally, apply it to the \(n\) points; the total complexity is \(O(n + m \log k)\).

Counting paths of fixed length

Problem statement

Given a directed graph (with edge weights 1), for any two vertices \(u,v\) find the number of paths of length \(k\) from \(u\) to \(v\).

We raise the adjacency matrix \(M\) of the graph to the \(k\)-th power; then \(M_{i,j}\) represents the number of paths of length \(k\) from \(i\) to \(j\). The complexity of this algorithm is \(O(n^3 \log k)\). For details of this algorithm see the Matrix page.

Modular integer multiplication

Problem statement

Given nonnegative integers \(a,b\) and a positive integer \(m\), compute \(a\times b\bmod m\), where \(a,b\le m\le 10^{18}\).

With the same idea as binary exponentiation, this time we represent one of the factors as a sum of several integer powers of 2. Because when multiplying a number by 2 and taking the remainder we can convert it into additions and subtractions to prevent integer overflow. In this way the problem can be solved in \(O (\log m)\) time. The recursive method is as follows:

\[ a \cdot b = \begin{cases} 0 &\text{if }a = 0 \\ 2 \cdot \frac{a}{2} \cdot b &\text{if }a > 0 \text{ and }a \text{ even} \\ 2 \cdot \frac{a-1}{2} \cdot b + b &\text{if }a > 0 \text{ and }a \text{ odd} \end{cases} \]

In actual use, however, this method is not time-efficient because it introduces a larger computational complexity. In practical programming, fast multiplication is usually used for multiplication with a modulus in the long long range.

Binary exponentiation with big integers

Prerequisite: Big integer multiplication

Luogu P1045 [NOIP 2003 普及组] 麦森数 (Mersenne Numbers)

Given an integer \(P\) (\(1000 < P < 3100000\)), compute the number of digits of \(2^P−1\) and its last \(500\) digits (in decimal); if there are fewer than \(500\) digits, pad with 0 in the high positions.

Implementation 
#include <cmath>
#include <cstring>
#include <iostream>
using namespace std;

const int M = 500;

int a[505], b[505], t[505];

// big integer multiplication
void mult(int x[], int y[]) {
  memset(t, 0, sizeof(t));
  for (int i = 1; i <= x[0]; i++) {
    for (int j = 1; j <= y[0]; j++) {
      if (i + j - 1 > M) continue;
      t[i + j - 1] += x[i] * y[j];
      t[i + j] += t[i + j - 1] / 10;
      t[i + j - 1] %= 10;
      t[0] = i + j;
    }
  }
  memcpy(b, t, sizeof(b));
}

// binary exponentiation
void binpow(int p) {
  if (p == 1) {
    memcpy(b, a, sizeof(b));
    return;
  }
  binpow(p / 2);  // (2^(p/2))^2=2^p
  mult(b, b);     // square b
  if (p % 2 == 1) mult(b, a);
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  int p;
  cin >> p;
  a[0] = 1;  // number of digits in array a
  a[1] = 2;  // the 2 that gets squared
  b[0] = 1;  // number of digits in array b
  b[1] = 1;  // result array
  binpow(p);
  cout << (int)(log10(2) * p) + 1 << '\n';
  b[1] -= 1;  // subtract 1 from the last digit
  for (int i = M; i >= 1; i--) {
    cout << b[i];
    if ((i - 1) % 50 == 0) {
      cout << '\n';
    }
  }
}

Precomputed exponentiation with a fixed base

When the base \(a\) is fixed, we can use the idea of sqrt decomposition: after some preprocessing time, each power query is answered in \(O(1)\) time. This algorithm is also often called "light-speed exponentiation" (光速幂). The procedure is as follows:

  1. Choose a number \(s\), precompute the values \(a^0,a^1,\cdots,a^{s-1}\) and \(a^0,a^s,\cdots,a^{\lfloor p/s\rfloor s}\) and store them in two arrays;
  2. For each query \(a^b\), split \(b\) into \(\lfloor b/s\rfloor s+(b\bmod s)\); then \(a^b=a^{\lfloor b/s\rfloor s}\cdot a^{b\bmod s}\), so the answer is obtained in \(O(1)\).

Suppose the range of the exponent \(b\) is \([0,n]\); then the block length \(s\) is often chosen as \(\sqrt{n}\) or a power of \(2\) close to it. Choosing \(\sqrt{n}\) gives the optimal preprocessing complexity \(O(\sqrt{n})\), while choosing a power of \(2\) allows the computation to be simplified with bit operations.

In particular, for modular exponentiation, the same base \(a\) implicitly requires the same modulus \(m\) as well. By the extended Euler's theorem, for an arbitrary modulus \(m\) the upper bound of the exponent range to precompute is \(n = 2\varphi(m)\); for a prime modulus \(p\) the upper bound is \(n = p - 1\). In both cases the preprocessing complexity is \(O(\sqrt{m})\).

Reference code 
int a, mod, pow1[65536], pow2[65536];

void preproc() {
  pow1[0] = pow2[0] = 1;
  for (int i = 1; i < 65536; i++) pow1[i] = 1LL * pow1[i - 1] * a % mod;
  int pow65536 = 1LL * pow1[65535] * a % mod;
  for (int i = 1; i < 65536; i++) pow2[i] = 1LL * pow2[i - 1] * pow65536 % mod;
}

int query(int pows) {
  return 1LL * pow1[pows & 65535] * pow2[pows >> 16] % mod;
}
