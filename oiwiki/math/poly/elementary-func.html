Elementarne i neelementarne funkcije

Elementarne funkcije definiraju se ovako1:

Ako u polju \(F\) postoji preslikavanje \(u\to \partial u\) koje zadovoljava:

  1. \(\partial(u+v)=\partial u+\partial v\)
  2. \(\partial(uv)=u\partial v+v\partial u\)

tada to polje nazivamo diferencijalnim poljem.

Ako funkcija \(u\) nad diferencijalnim poljem \(F\) zadovoljava bilo koji od sljedećih uvjeta, funkciju \(u\) nazivamo elementarnom funkcijom:

  1. \(u\) je algebarska funkcija nad \(F\).
  2. \(u\) je eksponencijalnog tipa nad \(F\), tj. postoji \(a\in F\) takav da je \(\partial u=u\partial a\).
  3. \(u\) je logaritamskog tipa nad \(F\), tj. postoji \(a\in F\) takav da je \(\partial u=\frac{\partial a}{a}\).

Uobičajene elementarne funkcije su:

  1. algebarske funkcije: funkcije \(f(x)\) za koje postoji polinom konačnog stupnja \(P\) takav da je \(P(f(x))=0\), npr. \(2x+1\),\(\sqrt{x}\),\((1+x^2)^{-1}\),\(|x|\).
  2. eksponencijalne funkcije
  3. logaritamske funkcije
  4. trigonometrijske funkcije
  5. inverzne trigonometrijske funkcije
  6. hiperbolne funkcije
  7. inverzne hiperbolne funkcije

  8. kompozicije gornjih funkcija, npr.:

    \[ \frac{\mathrm{e}^{\tan x}}{1+x^2}\sin\left(\sqrt{1+\ln^2 x}\right) \]
    \[ -\mathrm{i} \ln\left(x+\mathrm{i}\sqrt{1-x^2}\right) \]

Uobičajene neelementarne funkcije su:

  1. funkcija pogreške:

    \[ \operatorname{erf}(x):=\frac{2}{\sqrt{\pi}}\int_{0}^{x}\exp\left(-t^2\right)\mathrm{d}t \]

Inverz polinoma

Zadan je polinom \(f\left(x\right)\); treba odrediti \(f^{-1}\left(x\right)\).

Rješenje

Metoda udvostručavanja

Najprije, očito je

\[ \left[x^{0}\right]f^{-1}\left(x\right)=\left(\left[x^{0}\right]f\left(x\right)\right)^{-1} \]

Pretpostavimo da smo već odredili inverz \(f^{-1}_{0}\left(x\right)\) polinoma \(f\left(x\right)\) modulo \(x^{\left\lceil\frac{n}{2}\right\rceil}\). Vrijedi:

\[ \begin{aligned} f\left(x\right)f^{-1}_{0}\left(x\right)&\equiv 1 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ f\left(x\right)f^{-1}\left(x\right)&\equiv 1 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ f^{-1}\left(x\right)-f^{-1}_{0}\left(x\right)&\equiv 0 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}} \end{aligned} \]

Kvadriranjem obiju strana dobivamo:

\[ f^{-2}\left(x\right)-2f^{-1}\left(x\right)f^{-1}_{0}\left(x\right)+f^{-2}_{0}\left(x\right)\equiv 0 \pmod{x^{n}} \]

Množenjem obiju strana s \(f\left(x\right)\) i prebacivanjem članova dobivamo:

\[ f^{-1}\left(x\right)\equiv f^{-1}_{0}\left(x\right)\left(2-f\left(x\right)f^{-1}_{0}\left(x\right)\right) \pmod{x^{n}} \]

Dovoljno je računati rekurzivno.

Vremenska složenost

\[ T\left(n\right)=T\left(\frac{n}{2}\right)+O\left(n\log{n}\right)=O\left(n\log{n}\right) \]

Graeffeova metoda

Želimo li odrediti \(f^{-1}(x)\bmod x^{2n}\), promotrimo

\[ \begin{aligned} f^{-1}(x)\bmod x^{2n}&= f(-x)(f(x)f(-x))^{-1}\bmod x^{2n}\\ &=f(-x)g^{-1}(x^2)\bmod x^{2n} \end{aligned} \]

Dovoljno je odrediti \(g^{-1}(x)\bmod x^n\) pa iz toga rekonstruirati \(g^{-1}(x^2)\bmod x^{2n}\), jer je \(f(x)f(-x)\) parna funkcija; vremenska složenost ista je kao gore.

Inverz polinoma 
constexpr int MAXN = 262144;
constexpr int mod = 998244353;

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void polyinv(const poly &h, const int n, poly &f) {
  /* f = 1 / h = f_0 (2 - f_0 h) */
  static poly_t inv_t;
  std::fill(f, f + n + n, 0);
  f[0] = fpow(h[0], mod - 2);
  for (int t = 2; t <= n; t <<= 1) {
    const int t2 = t << 1;
    std::copy(h, h + t, inv_t);
    std::fill(inv_t + t, inv_t + t2, 0);

    DFT(f, t2);
    DFT(inv_t, t2);
    for (int i = 0; i != t2; ++i)
      f[i] = (i64)f[i] * sub(2, (i64)f[i] * inv_t[i] % mod) % mod;
    IDFT(f, t2);

    std::fill(f + t, f + t2, 0);
  }
}

Korijen polinoma

Zadan je polinom \(g\left(x\right)\); treba odrediti \(f\left(x\right)\) takav da vrijedi:

\[ f^{2}\left(x\right)\equiv g\left(x\right) \pmod{x^{n}} \]

Rješenje

Metoda udvostručavanja

Najprije razmotrimo slučaj kada \(\left[x^0\right]g(x)\) nije \(0\).

Očito je:

\[ \left[x^0\right]f(x) = \sqrt{\left[x^0\right]g(x)} \]

Ako \(\left[x^0\right]g(x)\) nema kvadratni korijen, ni polinom \(g(x)\) nema kvadratni korijen.

\(\left[x^0\right]g(x)\) može imati više kvadratnih korijena; odabirom različitih korijena dobivaju se različiti \(f(x)\).

Pretpostavimo da smo već odredili kvadratni korijen \(f_{0}\left(x\right)\) polinoma \(g\left(x\right)\) modulo \(x^{\left\lceil\frac{n}{2}\right\rceil}\); tada vrijedi:

\[ \begin{aligned} f_{0}^{2}\left(x\right)&\equiv g\left(x\right) &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ f_{0}^{2}\left(x\right)-g\left(x\right)&\equiv 0 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ \left(f_{0}^{2}\left(x\right)-g\left(x\right)\right)^{2}&\equiv 0 &\pmod{x^{n}}\\ \left(f_{0}^{2}\left(x\right)+g\left(x\right)\right)^{2}&\equiv 4f_{0}^{2}\left(x\right)g\left(x\right) &\pmod{x^{n}}\\ \left(\frac{f_{0}^{2}\left(x\right)+g\left(x\right)}{2f_{0}\left(x\right)}\right)^{2}&\equiv g\left(x\right) &\pmod{x^{n}}\\ \frac{f_{0}^{2}\left(x\right)+g\left(x\right)}{2f_{0}\left(x\right)}&\equiv f\left(x\right) &\pmod{x^{n}}\\ 2^{-1}f_{0}\left(x\right)+2^{-1}f_{0}^{-1}\left(x\right)g\left(x\right)&\equiv f\left(x\right) &\pmod{x^{n}} \end{aligned} \]

Dovoljno je računati udvostručavanjem.

Vremenska složenost

\[ T\left(n\right)=T\left(\frac{n}{2}\right)+O\left(n\log{n}\right)=O\left(n\log{n}\right) \]

Postoji i varijanta s manjom konstantom: tijekom udvostručavanja uz \(f\left(x\right)\) istodobno održavamo i \(f^{-1}\left(x\right)\) umjesto da svaki put iznova računamo inverz.

Kada je \(\left[x^{0}\right]g\left(x\right)\neq 1\), za izračun \(\left[x^{0}\right]f\left(x\right)\) možda će trebati kvadratni ostaci.

Gornja metoda zahtijeva poznavanje inverza od \(f_{0}(x)\), pa slobodni član ne smije biti \(0\).

Ako je \(\left[x^0\right]g(x) = 0\), rastavimo \(g(x)\) na \(x^{k}h(x)\), pri čemu je \(\left[x^0\right]h(x) \not = 0\).

  • Ako je \(k\) neparan, \(g(x)\) nema kvadratni korijen.

  • Ako je \(k\) paran, odredimo kvadratni korijen \(\sqrt{h(x)}\) polinoma \(h(x)\) i dobivamo \(f(x) \equiv x^{k/2} \sqrt{h(x)} \pmod{x^{n}}\).

Referentni kôd za Luogu predložak P5205【模板】多项式开根 (Predložak: korijen polinoma) 
#include <algorithm>
#include <iostream>
using namespace std;

constexpr int MAXN = 1 << 20, mod = 998244353;

int a[MAXN], b[MAXN], g[MAXN], gg[MAXN];

int qpow(int x, int y) {  // brzo potenciranje
  int ans = 1;

  while (y) {
    if (y & 1) {
      ans = (long long)1 * ans * x % mod;
    }
    x = (long long)1 * x * x % mod;
    y >>= 1;
  }
  return ans;
}

int inv2 = qpow(2, mod - 2);  // inverz

void change(int *f, int len) {
  for (int i = 1, j = len / 2; i < len - 1; i++) {
    if (i < j) {
      swap(f[i], f[j]);
    }

    int k = len / 2;
    while (j >= k) {
      j -= k;
      k /= 2;
    }
    if (j < k) {
      j += k;
    }
  }
}

void NTT(int *f, int len, int type) {  // NTT
  change(f, len);

  for (int q = 2; q <= len; q <<= 1) {
    int nxt = qpow(3, (mod - 1) / q);
    for (int i = 0; i < len; i += q) {
      int w = 1;

      for (int k = i; k < i + (q >> 1); k++) {
        int x = f[k];
        int y = (long long)1 * w * f[k + (q / 2)] % mod;

        f[k] = (x + y) % mod;
        f[k + (q / 2)] = (x - y + mod) % mod;
        w = (long long)1 * w * nxt % mod;
      }
    }
  }

  if (type == -1) {
    reverse(f + 1, f + len);
    int iv = qpow(len, mod - 2);

    for (int i = 0; i < len; i++) {
      f[i] = (long long)1 * f[i] * iv % mod;
    }
  }
}

void inv(int deg, int *f, int *h) {  // računanje inverza
  if (deg == 1) {
    h[0] = qpow(f[0], mod - 2);
    return;
  }

  inv((deg + 1) >> 1, f, h);

  int len = 1;
  while (len < deg * 2) {  // udvostručavanje
    len *= 2;
  }

  copy(f, f + deg, gg);
  fill(gg + deg, gg + len, 0);

  NTT(gg, len, 1);
  NTT(h, len, 1);
  for (int i = 0; i < len; i++) {
    h[i] = (long long)1 * (2 - (long long)1 * gg[i] * h[i] % mod + mod) % mod *
           h[i] % mod;
  }

  NTT(h, len, -1);
  fill(h + deg, h + len, 0);
}

int n, t[MAXN];

// deg: stupanj
// f: polje iz kojeg vadimo korijen
// h: polje rezultata
void sqrt(int deg, int *f, int *h) {
  if (deg == 1) {
    h[0] = 1;
    return;
  }

  sqrt((deg + 1) >> 1, f, h);

  int len = 1;
  while (len < deg * 2) {  // udvostručavanje
    len *= 2;
  }
  fill(g, g + len, 0);
  inv(deg, h, g);
  copy(f, f + deg, t);
  fill(t + deg, t + len, 0);
  NTT(t, len, 1);
  NTT(g, len, 1);
  NTT(h, len, 1);

  for (int i = 0; i < len; i++) {
    h[i] = (long long)1 * inv2 *
           ((long long)1 * h[i] % mod + (long long)1 * g[i] * t[i] % mod) % mod;
  }
  NTT(h, len, -1);
  fill(h + deg, h + len, 0);
}

int main() {
  cin >> n;

  for (int i = 0; i < n; i++) {
    cin >> a[i];
  }
  sqrt(n, a, b);

  for (int i = 0; i < n; i++) {
    cout << b[i] << ' ';
  }

  return 0;
}

Dijeljenje i ostatak polinoma

Zadani su polinomi \(f\left(x\right),g\left(x\right)\); treba odrediti kvocijent \(Q\left(x\right)\) i ostatak \(R\left(x\right)\) pri dijeljenju \(f\left(x\right)\) s \(g\left(x\right)\).

Rješenje

Primjećujemo da bismo, kad bismo mogli ukloniti utjecaj \(R\left(x\right)\), zadatak mogli izravno riješiti inverzom polinoma.

Razmotrimo transformaciju

\[ f^{R}\left(x\right)=x^{\operatorname{deg}{f}}f\left(\frac{1}{x}\right) \]

Promatranjem vidimo da ona zapravo obrće redoslijed koeficijenata polinoma \(f\left(x\right)\).

Neka je \(n=\operatorname{deg}{f},m=\operatorname{deg}{g}\).

U \(f\left(x\right)=Q\left(x\right)g\left(x\right)+R\left(x\right)\) zamijenimo \(x\) s \(\frac{1}{x}\) i obje strane pomnožimo s \(x^{n}\); dobivamo:

\[ \begin{aligned} x^{n}f\left(\frac{1}{x}\right)&=x^{n-m}Q\left(\frac{1}{x}\right)x^{m}g\left(\frac{1}{x}\right)+x^{n-m+1}x^{m-1}R\left(\frac{1}{x}\right)\\ f^{R}\left(x\right)&=Q^{R}\left(x\right)g^{R}\left(x\right)+x^{n-m+1}R^{R}\left(x\right) \end{aligned} \]

Uočimo da je u gornjem izrazu koeficijent uz \(R^{R}\left(x\right)\) jednak \(x^{n-m+1}\), pa ako sve promatramo modulo \(x^{n-m+1}\), uklanjamo utjecaj \(R^{R}\left(x\right)\).

Budući da je stupanj \(Q^{R}\left(x\right)\) jednak \(\left(n-m\right)<\left(n-m+1\right)\), \(Q^{R}\left(x\right)\) time nije pogođen.

Dakle:

\[ f^{R}\left(x\right)\equiv Q^{R}\left(x\right)g^{R}\left(x\right)\pmod{x^{n-m+1}} \]

Inverzom polinoma odredimo \(Q\left(x\right)\), a uvrštavanjem natrag dobivamo \(R\left(x\right)\).

Vremenska složenost \(O\left(n\log{n}\right)\).

Logaritam i eksponencijalna funkcija polinoma

Zadan je polinom \(f(x)\); treba odrediti \(\ln{f(x)}\) i \(\exp{f(x)}\) modulo \(x^{n}\).

Rješenje

Obična metoda

Najprije, ako za polinom \(f(x)\) postoji \(\ln{f(x)}\), tada po definiciji mora vrijediti:

\[ [x^{0}]f(x)=1 \]

Deriviranjem pa integriranjem \(\ln{f(x)}\) dobivamo:

\[ \begin{aligned} \frac{\mathrm{d} \ln{f(x)}}{\mathrm{d} x} & \equiv \frac{f'(x)}{f(x)} & \pmod{x^{n}} \\ \ln{f(x)} & \equiv \int \mathrm{d} \ln{f(x)} \equiv \int\frac{f'(x)}{f(x)} \mathrm{d} x & \pmod{x^{n}} \end{aligned} \]

Deriviranje i integriranje polinoma imaju vremensku složenost \(O(n)\), a inverz \(O(n\log{n})\), pa je vremenska složenost računanja \(\ln\) polinoma \(O(n\log{n})\).

Najprije, ako za polinom \(f(x)\) postoji \(\exp{f(x)}\), tada mora vrijediti:

\[ [x^{0}]f(x)=0 \]

U suprotnom slobodni član od \(\exp{f(x)}\) ne konvergira.

Deriviranjem \(\exp{f(x)}\) dobivamo:

\[ \frac{\mathrm{d} \exp{f(x)}}{\mathrm{d} x} \equiv \exp{f(x)}f'(x)\pmod{x^{n}} \]

Usporedbom koeficijenata na obje strane dobivamo:

\[ [x^{n-1}]\frac{\mathrm{d} \exp{f(x)}}{\mathrm{d} x} = \sum_{i = 0}^{n - 1} \left([x^{i}]\exp{f(x)}\right) \left([x^{n-i-1}]f'(x)\right) \]
\[ n[x^{n}]\exp{f(x)} = \sum_{i = 0}^{n - 1} \left([x^{i}]\exp{f(x)}\right) \left((n - i)[x^{n - i}]f(x)\right) \]

To se rješava FFT-om s podjelom (divide and conquer FFT).

Vremenska složenost \(O(n\log^{2}{n})\).

Newtonova metoda

Newtonovom metodom \(\exp\) polinoma može se izračunati u vremenskoj složenosti \(O(n\log{n})\).

Kôd

ln/exp polinoma 
constexpr int MAXN = 262144;
constexpr int mod = 998244353;

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void derivative(const poly &h, const int n, poly &f) {
  for (int i = 1; i != n; ++i) f[i - 1] = (i64)h[i] * i % mod;
  f[n - 1] = 0;
}

void integrate(const poly &h, const int n, poly &f) {
  for (int i = n - 1; i; --i) f[i] = (i64)h[i - 1] * inv[i] % mod;
  f[0] = 0; /* C */
}

void polyln(const poly &h, const int n, poly &f) {
  /* f = ln h = ∫ h' / h dx */
  assert(h[0] == 1);
  static poly_t ln_t;
  const int t = n << 1;

  derivative(h, n, ln_t);
  std::fill(ln_t + n, ln_t + t, 0);
  polyinv(h, n, f);

  DFT(ln_t, t);
  DFT(f, t);
  for (int i = 0; i != t; ++i) ln_t[i] = (i64)ln_t[i] * f[i] % mod;
  IDFT(ln_t, t);

  integrate(ln_t, n, f);
}

void polyexp(const poly &h, const int n, poly &f) {
  /* f = exp(h) = f_0 (1 - ln f_0 + h) */
  assert(h[0] == 0);
  static poly_t exp_t;
  std::fill(f, f + n + n, 0);
  f[0] = 1;
  for (int t = 2; t <= n; t <<= 1) {
    const int t2 = t << 1;

    polyln(f, t, exp_t);
    exp_t[0] = sub(pls(h[0], 1), exp_t[0]);
    for (int i = 1; i != t; ++i) exp_t[i] = sub(h[i], exp_t[i]);
    std::fill(exp_t + t, exp_t + t2, 0);

    DFT(f, t2);
    DFT(exp_t, t2);
    for (int i = 0; i != t2; ++i) f[i] = (i64)f[i] * exp_t[i] % mod;
    IDFT(f, t2);

    std::fill(f + t, f + t2, 0);
  }
}

Primjeri zadataka

  1. Izračunati \(f^{k}(x)\)

    Uobičajeni pristup je brzo potenciranje polinoma, vremenske složenosti \(O(n\log{n}\log{k})\).

    Kada je \([x^{0}]f(x)=1\), vrijedi:

    \[ f^{k}(x)=\exp{\left(k\ln{f(x)}\right)} \]

    Kada je \([x^{0}]f(x)\neq 1\), neka je \(f_{i}x^{i}\) član najnižeg stupnja polinoma \(f(x)\); tada je:

    \[ f^{k}(x)=f_{i}^{k}x^{ik}\exp{\left(k\ln{\frac{f(x)}{f_{i}x^{i}}}\right)} \]

    Vremenska složenost \(O(n\log{n})\).

Trigonometrijske funkcije polinoma

Zadan je polinom \(f\left(x\right)\); treba odrediti \(\sin{f\left(x\right)}, \cos{f\left(x\right)}\) i \(\tan{f\left(x\right)}\) modulo \(x^{n}\).

Rješenje

Najprije iz Eulerove formule \(\left(\mathrm{e}^{\mathrm{i}x} = \cos{x} + \mathrm{i}\sin{x}\right)\) dobivamo drugi zapis trigonometrijskih funkcija:

\[ \begin{aligned} \sin{x} &= \frac{\mathrm{e}^{\mathrm{i}x} - \mathrm{e}^{-\mathrm{i}x}}{2\mathrm{i}} \\ \cos{x} &= \frac{\mathrm{e}^{\mathrm{i}x} + \mathrm{e}^{-\mathrm{i}x}}{2} \end{aligned} \]

Uvrštavanjem \(f\left(x\right)\) dobivamo:

\[ \begin{aligned} \sin{f\left(x\right)} &= \frac{\exp{\left(\mathrm{i}f\left(x\right)\right)} - \exp{\left(-\mathrm{i}f\left(x\right)\right)}}{2\mathrm{i}} \\ \cos{f\left(x\right)} &= \frac{\exp{\left(\mathrm{i}f\left(x\right)\right)} + \exp{\left(-\mathrm{i}f\left(x\right)\right)}}{2} \end{aligned} \]

Program napisan izravno po gornjim izrazima daje \(\sin{f\left(x\right)}\) i \(\cos{f\left(x\right)}\) modulo \(x^{n}\). Zatim iz \(\tan{f\left(x\right)} = \frac{\sin{f\left(x\right)}}{\cos{f\left(x\right)}}\) dobivamo \(\tan{f\left(x\right)}\).

Trigonometrijske funkcije polinoma

Uočimo da NTT radimo nad \(\mathbb{Z}_{998244353}\), pa u skladu s tim imaginarnu jedinicu \(\mathrm{i}\) treba zamijeniti s \(86583718\) ili \(911660635\):

\[ \begin{aligned} & \mathrm{i} = \sqrt{-1} \equiv \sqrt{998244352} \pmod{998244353} \\ \implies & \phantom{\text{or}} \quad \mathrm{i} \equiv 86583718 \pmod{998244353} \\ & \text{or} \quad \mathrm{i} \equiv 911660635 \pmod{998244353} \end{aligned} \]
constexpr int MAXN = 262144;
constexpr int mod = 998244353;
constexpr int imgunit = 86583718; /* sqrt(-1) = sqrt(998233452) */

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void polytri(const poly &h, const int n, poly &sin_t, poly &cos_t) {
  /* sin(f) = (exp(i * f) - exp(- i * f)) / 2i */
  /* cos(f) = (exp(i * f) + exp(- i * f)) / 2 */
  /* tan(f) = sin(f) / cos(f) */
  assert(h[0] == 0);
  static poly_t tri1_t, tri2_t;

  for (int i = 0; i != n; ++i) tri2_t[i] = (i64)h[i] * imgunit % mod;
  polyexp(tri2_t, n, tri1_t);
  polyinv(tri1_t, n, tri2_t);

  if (sin_t != nullptr) {
    const int invi = fpow(pls(imgunit, imgunit), mod - 2);
    for (int i = 0; i != n; ++i)
      sin_t[i] = (i64)(tri1_t[i] - tri2_t[i] + mod) * invi % mod;
  }
  if (cos_t != nullptr) {
    for (int i = 0; i != n; ++i) cos_t[i] = div2(pls(tri1_t[i], tri2_t[i]));
  }
}

Inverzne trigonometrijske funkcije polinoma

Zadan je polinom \(f\left(x\right)\); treba odrediti \(\arcsin{f\left(x\right)}, \arccos{f\left(x\right)}\) i \(\arctan{f\left(x\right)}\) modulo \(x^{n}\).

Rješenje

Po uzoru na računanje \(\ln\) polinoma, deriviranjem pa integriranjem inverznih trigonometrijskih funkcija dobivamo:

\[ \begin{aligned} \frac{\mathrm{d}}{\mathrm{d} x} \arcsin{x} &= \frac{1}{\sqrt{1 - x^{2}}} \\ \arcsin{x} &= \int \frac{1}{\sqrt{1 - x^{2}}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arccos{x} &= - \frac{1}{\sqrt{1 - x^{2}}} \\ \arccos{x} &= - \int \frac{1}{\sqrt{1 - x^{2}}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arctan{x} &= \frac{1}{1 + x^{2}} \\ \arctan{x} &= \int \frac{1}{1 + x^{2}} \mathrm{d} x \end{aligned} \]

Uvrštavanjem \(f\left(x\right)\) dobivamo:

\[ \begin{aligned} \frac{\mathrm{d}}{\mathrm{d} x} \arcsin{f\left(x\right)} &= \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \\ \arcsin{f\left(x\right)} &= \int \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arccos{f\left(x\right)} &= - \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \\ \arccos{f\left(x\right)} &= - \int \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arctan{f\left(x\right)} &= \frac{f'\left(x\right)}{1 + f^{2}\left(x\right)} \\ \arctan{f\left(x\right)} &= \int \frac{f'\left(x\right)}{1 + f^{2}\left(x\right)} \mathrm{d} x \end{aligned} \]

Dovoljno je računati izravno po formulama.

constexpr int mod = 998244353;

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void derivative(const poly &h, const int n, poly &f) {
  for (int i = 1; i != n; ++i) f[i - 1] = (i64)h[i] * i % mod;
  f[n - 1] = 0;
}

void integrate(const poly &h, const int n, poly &f) {
  for (int i = n - 1; i; --i) f[i] = (i64)h[i - 1] * inv[i] % mod;
  f[0] = 0; /* C */
}

void polyarcsin(const poly &h, const int n, poly &f) {
  /* arcsin(f) = ∫ f' / sqrt(1 - f^2) dx  */
  static poly_t arcsin_t;
  const int t = n << 1;
  std::copy(h, h + n, arcsin_t);
  std::fill(arcsin_t + n, arcsin_t + t, 0);

  DFT(arcsin_t, t);
  for (int i = 0; i != t; ++i) arcsin_t[i] = sqr(arcsin_t[i]);
  IDFT(arcsin_t, t);

  arcsin_t[0] = sub(1, arcsin_t[0]);
  for (int i = 1; i != n; ++i)
    arcsin_t[i] = arcsin_t[i] ? mod - arcsin_t[i] : 0;

  polysqrt(arcsin_t, n, f);
  polyinv(f, n, arcsin_t);
  derivative(h, n, f);

  DFT(f, t);
  DFT(arcsin_t, t);
  for (int i = 0; i != t; ++i) arcsin_t[i] = (i64)f[i] * arcsin_t[i] % mod;
  IDFT(arcsin_t, t);

  integrate(arcsin_t, n, f);
}

void polyarccos(const poly &h, const int n, poly &f) {
  /* arccos(f) = - ∫ f' / sqrt(1 - f^2) dx  */
  polyarcsin(h, n, f);
  for (int i = 0; i != n; ++i) f[i] = f[i] ? mod - f[i] : 0;
}

void polyarctan(const poly &h, const int n, poly &f) {
  /* arctan(f) = ∫ f' / (1 + f^2) dx  */
  static poly_t arctan_t;
  const int t = n << 1;
  std::copy(h, h + n, arctan_t);
  std::fill(arctan_t + n, arctan_t + t, 0);

  DFT(arctan_t, t);
  for (int i = 0; i != t; ++i) arctan_t[i] = sqr(arctan_t[i]);
  IDFT(arctan_t, t);

  inc(arctan_t[0], 1);
  std::fill(arctan_t + n, arctan_t + t, 0);

  polyinv(arctan_t, n, f);
  derivative(h, n, arctan_t);

  DFT(f, t);
  DFT(arctan_t, t);
  for (int i = 0; i != t; ++i) arctan_t[i] = (i64)f[i] * arctan_t[i] % mod;
  IDFT(arctan_t, t);

  integrate(arctan_t, n, f);
}

Elementary and non-elementary functions

Elementary functions are defined as follows1:

If a field \(F\) has a map \(u\to \partial u\) satisfying:

  1. \(\partial(u+v)=\partial u+\partial v\)
  2. \(\partial(uv)=u\partial v+v\partial u\)

then the field is called a differential field.

If a function \(u\) over a differential field \(F\) satisfies any one of the following conditions, the function \(u\) is called an elementary function:

  1. \(u\) is an algebraic function over \(F\).
  2. \(u\) is exponential over \(F\), i.e. there exists \(a\in F\) such that \(\partial u=u\partial a\).
  3. \(u\) is logarithmic over \(F\), i.e. there exists \(a\in F\) such that \(\partial u=\frac{\partial a}{a}\).

Common elementary functions are:

  1. algebraic functions: functions \(f(x)\) for which there exists a polynomial \(P\) of finite degree such that \(P(f(x))=0\), e.g. \(2x+1\),\(\sqrt{x}\),\((1+x^2)^{-1}\),\(|x|\).
  2. exponential functions
  3. logarithmic functions
  4. trigonometric functions
  5. inverse trigonometric functions
  6. hyperbolic functions
  7. inverse hyperbolic functions

  8. compositions of the functions above, e.g.:

    \[ \frac{\mathrm{e}^{\tan x}}{1+x^2}\sin\left(\sqrt{1+\ln^2 x}\right) \]
    \[ -\mathrm{i} \ln\left(x+\mathrm{i}\sqrt{1-x^2}\right) \]

Common non-elementary functions are:

  1. the error function:

    \[ \operatorname{erf}(x):=\frac{2}{\sqrt{\pi}}\int_{0}^{x}\exp\left(-t^2\right)\mathrm{d}t \]

Polynomial inverse

Given a polynomial \(f\left(x\right)\), find \(f^{-1}\left(x\right)\).

Solution

Doubling method

First, it is easy to see that

\[ \left[x^{0}\right]f^{-1}\left(x\right)=\left(\left[x^{0}\right]f\left(x\right)\right)^{-1} \]

Suppose we have already found the inverse \(f^{-1}_{0}\left(x\right)\) of \(f\left(x\right)\) modulo \(x^{\left\lceil\frac{n}{2}\right\rceil}\). We have:

\[ \begin{aligned} f\left(x\right)f^{-1}_{0}\left(x\right)&\equiv 1 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ f\left(x\right)f^{-1}\left(x\right)&\equiv 1 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ f^{-1}\left(x\right)-f^{-1}_{0}\left(x\right)&\equiv 0 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}} \end{aligned} \]

Squaring both sides gives:

\[ f^{-2}\left(x\right)-2f^{-1}\left(x\right)f^{-1}_{0}\left(x\right)+f^{-2}_{0}\left(x\right)\equiv 0 \pmod{x^{n}} \]

Multiplying both sides by \(f\left(x\right)\) and rearranging gives:

\[ f^{-1}\left(x\right)\equiv f^{-1}_{0}\left(x\right)\left(2-f\left(x\right)f^{-1}_{0}\left(x\right)\right) \pmod{x^{n}} \]

It suffices to compute this recursively.

Time complexity

\[ T\left(n\right)=T\left(\frac{n}{2}\right)+O\left(n\log{n}\right)=O\left(n\log{n}\right) \]

Newton's method

See Newton's method.

Graeffe's method

To find \(f^{-1}(x)\bmod x^{2n}\), consider

\[ \begin{aligned} f^{-1}(x)\bmod x^{2n}&= f(-x)(f(x)f(-x))^{-1}\bmod x^{2n}\\ &=f(-x)g^{-1}(x^2)\bmod x^{2n} \end{aligned} \]

It suffices to find \(g^{-1}(x)\bmod x^n\) and recover \(g^{-1}(x^2)\bmod x^{2n}\) from it, because \(f(x)f(-x)\) is an even function; the time complexity is the same as above.

constexpr int MAXN = 262144;
constexpr int mod = 998244353;

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void polyinv(const poly &h, const int n, poly &f) {
  /* f = 1 / h = f_0 (2 - f_0 h) */
  static poly_t inv_t;
  std::fill(f, f + n + n, 0);
  f[0] = fpow(h[0], mod - 2);
  for (int t = 2; t <= n; t <<= 1) {
    const int t2 = t << 1;
    std::copy(h, h + t, inv_t);
    std::fill(inv_t + t, inv_t + t2, 0);

    DFT(f, t2);
    DFT(inv_t, t2);
    for (int i = 0; i != t2; ++i)
      f[i] = (i64)f[i] * sub(2, (i64)f[i] * inv_t[i] % mod) % mod;
    IDFT(f, t2);

    std::fill(f + t, f + t2, 0);
  }
}

Polynomial square root

Given a polynomial \(g\left(x\right)\), find \(f\left(x\right)\) satisfying:

\[ f^{2}\left(x\right)\equiv g\left(x\right) \pmod{x^{n}} \]

Solution

Doubling method

First we discuss the case where \(\left[x^0\right]g(x)\) is not \(0\).

It is easy to see that:

\[ \left[x^0\right]f(x) = \sqrt{\left[x^0\right]g(x)} \]

If \(\left[x^0\right]g(x)\) has no square root, then the polynomial \(g(x)\) has no square root.

\(\left[x^0\right]g(x)\) may have several square roots; choosing different roots yields different \(f(x)\).

Suppose we have already found the square root \(f_{0}\left(x\right)\) of \(g\left(x\right)\) modulo \(x^{\left\lceil\frac{n}{2}\right\rceil}\); then we have:

\[ \begin{aligned} f_{0}^{2}\left(x\right)&\equiv g\left(x\right) &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ f_{0}^{2}\left(x\right)-g\left(x\right)&\equiv 0 &\pmod{x^{\left\lceil\frac{n}{2}\right\rceil}}\\ \left(f_{0}^{2}\left(x\right)-g\left(x\right)\right)^{2}&\equiv 0 &\pmod{x^{n}}\\ \left(f_{0}^{2}\left(x\right)+g\left(x\right)\right)^{2}&\equiv 4f_{0}^{2}\left(x\right)g\left(x\right) &\pmod{x^{n}}\\ \left(\frac{f_{0}^{2}\left(x\right)+g\left(x\right)}{2f_{0}\left(x\right)}\right)^{2}&\equiv g\left(x\right) &\pmod{x^{n}}\\ \frac{f_{0}^{2}\left(x\right)+g\left(x\right)}{2f_{0}\left(x\right)}&\equiv f\left(x\right) &\pmod{x^{n}}\\ 2^{-1}f_{0}\left(x\right)+2^{-1}f_{0}^{-1}\left(x\right)g\left(x\right)&\equiv f\left(x\right) &\pmod{x^{n}} \end{aligned} \]

It suffices to compute this by doubling.

Time complexity

\[ T\left(n\right)=T\left(\frac{n}{2}\right)+O\left(n\log{n}\right)=O\left(n\log{n}\right) \]

There is also a variant with a smaller constant: while maintaining \(f\left(x\right)\) during the doubling, also maintain \(f^{-1}\left(x\right)\) instead of computing the inverse from scratch every time.

When \(\left[x^{0}\right]g\left(x\right)\neq 1\), quadratic residues may be needed to compute \(\left[x^{0}\right]f\left(x\right)\).

The method above needs the inverse of \(f_{0}(x)\), so the constant term must not be \(0\).

If \(\left[x^0\right]g(x) = 0\), factor \(g(x)\) as \(x^{k}h(x)\), where \(\left[x^0\right]h(x) \not = 0\).

  • If \(k\) is odd, \(g(x)\) has no square root.

  • If \(k\) is even, find the square root \(\sqrt{h(x)}\) of \(h(x)\), and then obtain \(f(x) \equiv x^{k/2} \sqrt{h(x)} \pmod{x^{n}}\).

#include <algorithm>
#include <iostream>
using namespace std;

constexpr int MAXN = 1 << 20, mod = 998244353;

int a[MAXN], b[MAXN], g[MAXN], gg[MAXN];

int qpow(int x, int y) {  // fast exponentiation
  int ans = 1;

  while (y) {
    if (y & 1) {
      ans = (long long)1 * ans * x % mod;
    }
    x = (long long)1 * x * x % mod;
    y >>= 1;
  }
  return ans;
}

int inv2 = qpow(2, mod - 2);  // inverse

void change(int *f, int len) {
  for (int i = 1, j = len / 2; i < len - 1; i++) {
    if (i < j) {
      swap(f[i], f[j]);
    }

    int k = len / 2;
    while (j >= k) {
      j -= k;
      k /= 2;
    }
    if (j < k) {
      j += k;
    }
  }
}

void NTT(int *f, int len, int type) {  // NTT
  change(f, len);

  for (int q = 2; q <= len; q <<= 1) {
    int nxt = qpow(3, (mod - 1) / q);
    for (int i = 0; i < len; i += q) {
      int w = 1;

      for (int k = i; k < i + (q >> 1); k++) {
        int x = f[k];
        int y = (long long)1 * w * f[k + (q / 2)] % mod;

        f[k] = (x + y) % mod;
        f[k + (q / 2)] = (x - y + mod) % mod;
        w = (long long)1 * w * nxt % mod;
      }
    }
  }

  if (type == -1) {
    reverse(f + 1, f + len);
    int iv = qpow(len, mod - 2);

    for (int i = 0; i < len; i++) {
      f[i] = (long long)1 * f[i] * iv % mod;
    }
  }
}

void inv(int deg, int *f, int *h) {  // compute the inverse
  if (deg == 1) {
    h[0] = qpow(f[0], mod - 2);
    return;
  }

  inv((deg + 1) >> 1, f, h);

  int len = 1;
  while (len < deg * 2) {  // doubling
    len *= 2;
  }

  copy(f, f + deg, gg);
  fill(gg + deg, gg + len, 0);

  NTT(gg, len, 1);
  NTT(h, len, 1);
  for (int i = 0; i < len; i++) {
    h[i] = (long long)1 * (2 - (long long)1 * gg[i] * h[i] % mod + mod) % mod *
           h[i] % mod;
  }

  NTT(h, len, -1);
  fill(h + deg, h + len, 0);
}

int n, t[MAXN];

// deg: degree
// f: array to take the square root of
// h: result array
void sqrt(int deg, int *f, int *h) {
  if (deg == 1) {
    h[0] = 1;
    return;
  }

  sqrt((deg + 1) >> 1, f, h);

  int len = 1;
  while (len < deg * 2) {  // doubling
    len *= 2;
  }
  fill(g, g + len, 0);
  inv(deg, h, g);
  copy(f, f + deg, t);
  fill(t + deg, t + len, 0);
  NTT(t, len, 1);
  NTT(g, len, 1);
  NTT(h, len, 1);

  for (int i = 0; i < len; i++) {
    h[i] = (long long)1 * inv2 *
           ((long long)1 * h[i] % mod + (long long)1 * g[i] * t[i] % mod) % mod;
  }
  NTT(h, len, -1);
  fill(h + deg, h + len, 0);
}

  cin >> n;

  for (int i = 0; i < n; i++) {
    cin >> a[i];
  }
  sqrt(n, a, b);

  for (int i = 0; i < n; i++) {
    cout << b[i] << ' ';
  }

  return 0;
}

Polynomial division and modulo

Given polynomials \(f\left(x\right),g\left(x\right)\), find the quotient \(Q\left(x\right)\) and the remainder \(R\left(x\right)\) of \(f\left(x\right)\) divided by \(g\left(x\right)\).

Solution

Notice that if we could eliminate the influence of \(R\left(x\right)\), the problem could be solved directly by polynomial inverse.

Consider the transformation

\[ f^{R}\left(x\right)=x^{\operatorname{deg}{f}}f\left(\frac{1}{x}\right) \]

Looking closely, it essentially reverses the coefficients of \(f\left(x\right)\).

Let \(n=\operatorname{deg}{f},m=\operatorname{deg}{g}\).

In \(f\left(x\right)=Q\left(x\right)g\left(x\right)+R\left(x\right)\) replace \(x\) with \(\frac{1}{x}\) and multiply both sides by \(x^{n}\); we get:

\[ \begin{aligned} x^{n}f\left(\frac{1}{x}\right)&=x^{n-m}Q\left(\frac{1}{x}\right)x^{m}g\left(\frac{1}{x}\right)+x^{n-m+1}x^{m-1}R\left(\frac{1}{x}\right)\\ f^{R}\left(x\right)&=Q^{R}\left(x\right)g^{R}\left(x\right)+x^{n-m+1}R^{R}\left(x\right) \end{aligned} \]

Note that in the expression above the coefficient of \(R^{R}\left(x\right)\) is \(x^{n-m+1}\), so working modulo \(x^{n-m+1}\) eliminates the influence of \(R^{R}\left(x\right)\).

Since the degree of \(Q^{R}\left(x\right)\) is \(\left(n-m\right)<\left(n-m+1\right)\), \(Q^{R}\left(x\right)\) is not affected.

Therefore:

\[ f^{R}\left(x\right)\equiv Q^{R}\left(x\right)g^{R}\left(x\right)\pmod{x^{n-m+1}} \]

Using polynomial inverse we find \(Q\left(x\right)\), and substituting back gives \(R\left(x\right)\).

Time complexity \(O\left(n\log{n}\right)\).

Polynomial logarithm and exponential

Given a polynomial \(f(x)\), find \(\ln{f(x)}\) and \(\exp{f(x)}\) modulo \(x^{n}\).

Solution

Ordinary method

First, for a polynomial \(f(x)\), if \(\ln{f(x)}\) exists, then by its definition it must satisfy:

\[ [x^{0}]f(x)=1 \]

Differentiating and then integrating \(\ln{f(x)}\) gives:

\[ \begin{aligned} \frac{\mathrm{d} \ln{f(x)}}{\mathrm{d} x} & \equiv \frac{f'(x)}{f(x)} & \pmod{x^{n}} \\ \ln{f(x)} & \equiv \int \mathrm{d} \ln{f(x)} \equiv \int\frac{f'(x)}{f(x)} \mathrm{d} x & \pmod{x^{n}} \end{aligned} \]

Differentiating and integrating a polynomial take \(O(n)\) time and the inverse takes \(O(n\log{n})\), so computing \(\ln\) of a polynomial takes \(O(n\log{n})\) time.

First, for a polynomial \(f(x)\), if \(\exp{f(x)}\) exists, then it must satisfy:

\[ [x^{0}]f(x)=0 \]

Otherwise the constant term of \(\exp{f(x)}\) does not converge.

Differentiating \(\exp{f(x)}\) gives:

\[ \frac{\mathrm{d} \exp{f(x)}}{\mathrm{d} x} \equiv \exp{f(x)}f'(x)\pmod{x^{n}} \]

Comparing coefficients on both sides gives:

\[ [x^{n-1}]\frac{\mathrm{d} \exp{f(x)}}{\mathrm{d} x} = \sum_{i = 0}^{n - 1} \left([x^{i}]\exp{f(x)}\right) \left([x^{n-i-1}]f'(x)\right) \]
\[ n[x^{n}]\exp{f(x)} = \sum_{i = 0}^{n - 1} \left([x^{i}]\exp{f(x)}\right) \left((n - i)[x^{n - i}]f(x)\right) \]

This can be solved with divide and conquer FFT.

Time complexity \(O(n\log^{2}{n})\).

Newton's method

Using Newton's method, the polynomial \(\exp\) can be computed in \(O(n\log{n})\) time.

void polyln(const poly &h, const int n, poly &f) {
  /* f = ln h = ∫ h' / h dx */
  assert(h[0] == 1);
  static poly_t ln_t;
  const int t = n << 1;

  derivative(h, n, ln_t);
  std::fill(ln_t + n, ln_t + t, 0);
  polyinv(h, n, f);

  DFT(ln_t, t);
  DFT(f, t);
  for (int i = 0; i != t; ++i) ln_t[i] = (i64)ln_t[i] * f[i] % mod;
  IDFT(ln_t, t);

  integrate(ln_t, n, f);
}

void polyexp(const poly &h, const int n, poly &f) {
  /* f = exp(h) = f_0 (1 - ln f_0 + h) */
  assert(h[0] == 0);
  static poly_t exp_t;
  std::fill(f, f + n + n, 0);
  f[0] = 1;
  for (int t = 2; t <= n; t <<= 1) {
    const int t2 = t << 1;

    polyln(f, t, exp_t);
    exp_t[0] = sub(pls(h[0], 1), exp_t[0]);
    for (int i = 1; i != t; ++i) exp_t[i] = sub(h[i], exp_t[i]);
    std::fill(exp_t + t, exp_t + t2, 0);

    DFT(f, t2);
    DFT(exp_t, t2);
    for (int i = 0; i != t2; ++i) f[i] = (i64)f[i] * exp_t[i] % mod;
    IDFT(f, t2);

    std::fill(f + t, f + t2, 0);
  }
}

Polynomial trigonometric functions

Given a polynomial \(f\left(x\right)\), find \(\sin{f\left(x\right)}, \cos{f\left(x\right)}\) and \(\tan{f\left(x\right)}\) modulo \(x^{n}\).

Solution

First, from Euler's formula \(\left(\mathrm{e}^{\mathrm{i}x} = \cos{x} + \mathrm{i}\sin{x}\right)\) we obtain another expression of the trigonometric functions:

\[ \begin{aligned} \sin{x} &= \frac{\mathrm{e}^{\mathrm{i}x} - \mathrm{e}^{-\mathrm{i}x}}{2\mathrm{i}} \\ \cos{x} &= \frac{\mathrm{e}^{\mathrm{i}x} + \mathrm{e}^{-\mathrm{i}x}}{2} \end{aligned} \]

Substituting \(f\left(x\right)\) gives:

\[ \begin{aligned} \sin{f\left(x\right)} &= \frac{\exp{\left(\mathrm{i}f\left(x\right)\right)} - \exp{\left(-\mathrm{i}f\left(x\right)\right)}}{2\mathrm{i}} \\ \cos{f\left(x\right)} &= \frac{\exp{\left(\mathrm{i}f\left(x\right)\right)} + \exp{\left(-\mathrm{i}f\left(x\right)\right)}}{2} \end{aligned} \]

Writing the program directly from the expressions above gives \(\sin{f\left(x\right)}\) and \(\cos{f\left(x\right)}\) modulo \(x^{n}\). Then from \(\tan{f\left(x\right)} = \frac{\sin{f\left(x\right)}}{\cos{f\left(x\right)}}\) we obtain \(\tan{f\left(x\right)}\).

Polynomial trigonometric functions

Note that we perform the NTT over \(\mathbb{Z}_{998244353}\), so accordingly the imaginary unit \(\mathrm{i}\) should be replaced by \(86583718\) or \(911660635\):

\[ \begin{aligned} & \mathrm{i} = \sqrt{-1} \equiv \sqrt{998244352} \pmod{998244353} \\ \implies & \phantom{\text{or}} \quad \mathrm{i} \equiv 86583718 \pmod{998244353} \\ & \text{or} \quad \mathrm{i} \equiv 911660635 \pmod{998244353} \end{aligned} \]
constexpr int MAXN = 262144;
constexpr int mod = 998244353;
constexpr int imgunit = 86583718; /* sqrt(-1) = sqrt(998233452) */

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void polytri(const poly &h, const int n, poly &sin_t, poly &cos_t) {
  /* sin(f) = (exp(i * f) - exp(- i * f)) / 2i */
  /* cos(f) = (exp(i * f) + exp(- i * f)) / 2 */
  /* tan(f) = sin(f) / cos(f) */
  assert(h[0] == 0);
  static poly_t tri1_t, tri2_t;

  for (int i = 0; i != n; ++i) tri2_t[i] = (i64)h[i] * imgunit % mod;
  polyexp(tri2_t, n, tri1_t);
  polyinv(tri1_t, n, tri2_t);

  if (sin_t != nullptr) {
    const int invi = fpow(pls(imgunit, imgunit), mod - 2);
    for (int i = 0; i != n; ++i)
      sin_t[i] = (i64)(tri1_t[i] - tri2_t[i] + mod) * invi % mod;
  }
  if (cos_t != nullptr) {
    for (int i = 0; i != n; ++i) cos_t[i] = div2(pls(tri1_t[i], tri2_t[i]));
  }
}

Polynomial inverse trigonometric functions

Given a polynomial \(f\left(x\right)\), find \(\arcsin{f\left(x\right)}, \arccos{f\left(x\right)}\) and \(\arctan{f\left(x\right)}\) modulo \(x^{n}\).

Solution

Following the method for the polynomial \(\ln\), differentiating and then integrating the inverse trigonometric functions gives:

\[ \begin{aligned} \frac{\mathrm{d}}{\mathrm{d} x} \arcsin{x} &= \frac{1}{\sqrt{1 - x^{2}}} \\ \arcsin{x} &= \int \frac{1}{\sqrt{1 - x^{2}}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arccos{x} &= - \frac{1}{\sqrt{1 - x^{2}}} \\ \arccos{x} &= - \int \frac{1}{\sqrt{1 - x^{2}}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arctan{x} &= \frac{1}{1 + x^{2}} \\ \arctan{x} &= \int \frac{1}{1 + x^{2}} \mathrm{d} x \end{aligned} \]

Substituting \(f\left(x\right)\) gives:

\[ \begin{aligned} \frac{\mathrm{d}}{\mathrm{d} x} \arcsin{f\left(x\right)} &= \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \\ \arcsin{f\left(x\right)} &= \int \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arccos{f\left(x\right)} &= - \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \\ \arccos{f\left(x\right)} &= - \int \frac{f'\left(x\right)}{\sqrt{1 - f^{2}\left(x\right)}} \mathrm{d} x \\ \frac{\mathrm{d}}{\mathrm{d} x} \arctan{f\left(x\right)} &= \frac{f'\left(x\right)}{1 + f^{2}\left(x\right)} \\ \arctan{f\left(x\right)} &= \int \frac{f'\left(x\right)}{1 + f^{2}\left(x\right)} \mathrm{d} x \end{aligned} \]

It suffices to compute directly from the formulas.

constexpr int MAXN = 262144;
constexpr int mod = 998244353;

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void derivative(const poly &h, const int n, poly &f) {
  for (int i = 1; i != n; ++i) f[i - 1] = (i64)h[i] * i % mod;
  f[n - 1] = 0;
}

void integrate(const poly &h, const int n, poly &f) {
  for (int i = n - 1; i; --i) f[i] = (i64)h[i - 1] * inv[i] % mod;
  f[0] = 0; /* C */
}

void polyarcsin(const poly &h, const int n, poly &f) {
  /* arcsin(f) = ∫ f' / sqrt(1 - f^2) dx  */
  static poly_t arcsin_t;
  const int t = n << 1;
  std::copy(h, h + n, arcsin_t);
  std::fill(arcsin_t + n, arcsin_t + t, 0);

  DFT(arcsin_t, t);
  for (int i = 0; i != t; ++i) arcsin_t[i] = sqr(arcsin_t[i]);
  IDFT(arcsin_t, t);

  arcsin_t[0] = sub(1, arcsin_t[0]);
  for (int i = 1; i != n; ++i)
    arcsin_t[i] = arcsin_t[i] ? mod - arcsin_t[i] : 0;

  polysqrt(arcsin_t, n, f);
  polyinv(f, n, arcsin_t);
  derivative(h, n, f);

  DFT(f, t);
  DFT(arcsin_t, t);
  for (int i = 0; i != t; ++i) arcsin_t[i] = (i64)f[i] * arcsin_t[i] % mod;
  IDFT(arcsin_t, t);

  integrate(arcsin_t, n, f);
}

void polyarccos(const poly &h, const int n, poly &f) {
  /* arccos(f) = - ∫ f' / sqrt(1 - f^2) dx  */
  polyarcsin(h, n, f);
  for (int i = 0; i != n; ++i) f[i] = f[i] ? mod - f[i] : 0;
}

void polyarctan(const poly &h, const int n, poly &f) {
  /* arctan(f) = ∫ f' / (1 + f^2) dx  */
  static poly_t arctan_t;
  const int t = n << 1;
  std::copy(h, h + n, arctan_t);
  std::fill(arctan_t + n, arctan_t + t, 0);

  DFT(arctan_t, t);
  for (int i = 0; i != t; ++i) arctan_t[i] = sqr(arctan_t[i]);
  IDFT(arctan_t, t);

  inc(arctan_t[0], 1);
  std::fill(arctan_t + n, arctan_t + t, 0);

  polyinv(arctan_t, n, f);
  derivative(h, n, arctan_t);

  DFT(f, t);
  DFT(arctan_t, t);
  for (int i = 0; i != t; ++i) arctan_t[i] = (i64)f[i] * arctan_t[i] % mod;
  IDFT(arctan_t, t);

  integrate(arctan_t, n, f);
}
