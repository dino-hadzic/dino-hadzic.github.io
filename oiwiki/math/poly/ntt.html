Uvod

Teorijsko-brojevna transformacija (number-theoretic transform, NTT) implementacija je diskretne Fourierove transformacije (DFT) na teorijsko-brojevnoj osnovi; brza teorijsko-brojevna transformacija (fast number-theoretic transform, FNTT) implementacija je brze Fourierove transformacije (FFT) na teorijsko-brojevnoj osnovi.

Teorijsko-brojevna transformacija brz je algoritam za računanje konvolucije (convolution). Među najčešće korištene algoritme spada i već spomenuta brza Fourierova transformacija. Međutim, brza Fourierova transformacija ima neke implementacijske nedostatke: primjerice, vektor podataka mora se pomnožiti matricom s kompleksnim koeficijentima, a realni i imaginarni dio svakog kompleksnog koeficijenta vrijednosti su funkcija sinus i kosinus, pa je većina koeficijenata zapisana u pomičnom zarezu; drugim riječima, moraju se izvoditi kompleksne operacije, i to u pomičnom zarezu, zbog čega je količina računanja veća, a i pogreška nastala računanjem u pomičnom zarezu veća je.

NTT rješava slučaj množenja polinoma s modulom; može se reći da je donekle ograničena modulom, a i brojevi su veći. Trenutačno je najčešći modul 998244353.

Predznanje

Za učenje teorijsko-brojevne transformacije potrebno je predznanje: diskretna Fourierova transformacija, generirane podgrupe, primitivni korijen, diskretni logaritam. Ta se znanja mogu naučiti na odgovarajućim stranicama pa ih ovdje ne ponavljamo.

Definicija

Teorijsko-brojevna transformacija

U matematici je NTT diskretna Fourierova transformacija (DFT) nad proizvoljnim prstenom. U slučaju konačnog polja obično se naziva teorijsko-brojevnom transformacijom (NTT).

Teorijsko-brojevna transformacija (NTT) dobiva se prenošenjem diskretne Fourierove transformacije u \(F={\mathbb {Z}/p}\), cijele brojeve modulo prost broj \(p\). To je konačno polje, i čim \(n\) dijeli \(p-1\), postoji primitivni \(n\)-ti korijen jedinice, pa imamo \(p=\xi n+1\) za neki pozitivan cijeli broj \(ξ\). Konkretno, za prost broj \(p=qn+1, (n=2^m)\) primitivni korijen \(g\) zadovoljava \(g^{qn} \equiv 1 \pmod p\); promatramo li \(g_n=g^q\pmod p\) kao ekvivalent od \(\omega_n\), on zadovoljava slična svojstva, npr. \(g_n^n \equiv 1 \pmod p, g_n^{n/2} \equiv -1 \pmod p\).

Budući da je ovdje riječ o teorijsko-brojevnoj transformaciji, \(N\) (da bismo ga razlikovali od \(n\) u FFT-u, ovdašnji \(n\) zovemo \(N\)) može biti veći od \(n\) u FFT-u, ali dovoljno je \(\frac{qN}{n}\) promatrati kao ovdašnji \(q\) i problem veličine je izbjegnut.

Uobičajeni su:

\[ p = 167772161 = 5 \times 2^{25}+1, g=3 \]
\[ p = 469762049 = 7 \times 2^{26}+1, g=3 \]
\[ p = 754974721 = 3^2 \times 5 \times 2^{24}+1, g=11 \]
\[ p = 998244353 = 7 \times 17 \times 2^{23}+1, g=3 \]
\[ p = 1004535809 = 479 \times 2^{21}+1, g=3 \]

Riječ je upravo o ekvivalentu \(\mathrm{e}^{2\pi \mathrm{i} n}\) za \(g^{qn}\).

Kad iteracija dođe do duljine \(l\), vrijedi \(g_l = g^{\frac{p-1}{l}}\), odnosno \(\omega_n = g_l = g_N^{\frac{N}{l}} = g_N^{\frac{p-1}{l}}\).

Brza teorijsko-brojevna transformacija

Brza teorijsko-brojevna transformacija (FNTT) brz je algoritam koji nastaje dodavanjem postupka „podijeli pa vladaj” teorijsko-brojevnoj transformaciji (NTT).

Postupak podjele koji koristi brza teorijsko-brojevna transformacija potpuno je jednak onom koji koristi brza Fourierova transformacija. To znači da je dovoljno jednostavno izmijeniti kod brze Fourierove transformacije da bi se dobio kod brze teorijsko-brojevne transformacije.

Pojam NTT koji se često spominje na algoritamskim natjecanjima zapravo se najčešće odnosi na brzu teorijsko-brojevnu transformaciju; obično se podrazumijeva da „teorijsko-brojevna transformacija” znači „brza teorijsko-brojevna transformacija”.

Logika te kratice slična je onoj kod brze Fourierove transformacije. Zapravo se pojam „brza Fourierova transformacija” (FFT) odnosi na „brzu diskretnu Fourierovu transformaciju” (FDFT), ali budući da se „brza” može odnositi samo na diskretnu, štoviše samo na poseban slučaj u kojem je red primitivnog korijena jedinice potencija broja \(2\), a ne može na kontinuiranu, riječ „diskretna” se izostavlja, FDFT postaje FFT, tj. FFT se uvijek odnosi na poseban diskretni slučaj.

Teorijsko-brojevna transformacija, odnosno brza teorijsko-brojevna transformacija, operacija je koja se izvodi modulo neki broj; kontinuirani slučaj ne postoji, uvijek je diskretna, pa naravno nema potrebe spominjati riječ „diskretna”.

U području algoritama operacije bez ubrzanja nemaju smisla. Pojam DFT uveden je kod brze Fourierove transformacije zato što DFT ima i druge konkretne primjene u obradi signala i obradi slika, a ujedno je DFT načelo, odnosno predznanje, za FFT.

Kad ne dovodi do zabune, NTT se često koristi kao oznaka za FNTT. Da u daljnjem izlaganju ne bi došlo do zabune, u nastavku su pojmovi NTT i FNTT razdvojeni.

Konkretan odnos DFT-a, FFT-a, NTT-a i FNTT-a jest:

  • Dodavanjem postupka podjele DFT-u i NTT-u dobivaju se FFT i FNTT. Postupak i načelo podjele mogu se vidjeti u članku o brzoj Fourierovoj transformaciji.

  • Zamjenom kompleksnog zbrajanja i kompleksnog množenja u DFT-u i FFT-u zbrajanjem i množenjem modulo \(p\), pri čemu se veličine obično ograničavaju na raspon od \(0\) do \(p-1\), te zamjenom primitivnog korijena jedinice primitivnim korijenom jedinice istog reda modulo \(p\), gdje je red potencija broja \(2\), dobivaju se NTT i FNTT.

Budući da zamijenjene operacije uključuju samo zbrajanje i množenje, DFT, FFT, NTT i FNTT imaju isto načelo; svi se izvode nad prstenom koji ima zbrajanje i množenje, bez strožeg uvjeta polja da mora biti definirano i dijeljenje.

Zapravo, čim postoji primitivni korijen, tj. generator u smislu teorije grupa, NTT ili FNTT za taj modul može se provesti. Budući da su moduli \(1\), \(2\) i \(4\) premali da bi imali praktično značenje, za neparan prost broj \(p\) i pozitivan cijeli broj \(\alpha\) dovoljno je zadati primitivni korijen \(g\) za module \(p^\alpha\) i \(2p^\alpha\) te se na isti način NTT ili FNTT i dalje može provesti.

Predložak

Library Checker - Convolution 
#include <algorithm>
#include <cstdio>
using namespace std;

constexpr int N = 1 << 20, P = 998244353;

int qpow(int x, int y) {
  int res = 1;
  while (y) {
    if (y & 1) res = 1ll * res * x % P;
    x = 1ll * x * x % P;
    y >>= 1;
  }
  return res;
}

int r[N];

void ntt(int *x, int lim, int opt) {
  for (int i = 0; i < lim; ++i)
    if (r[i] < i) swap(x[i], x[r[i]]);
  for (int m = 2; m <= lim; m <<= 1) {
    int k = m >> 1;
    int gn = qpow(3, (P - 1) / m);
    for (int i = 0; i < lim; i += m) {
      int g = 1;
      for (int j = 0; j < k; ++j, g = 1ll * g * gn % P) {
        int tmp = 1ll * x[i + j + k] * g % P;
        x[i + j + k] = (x[i + j] - tmp + P) % P;
        x[i + j] = (x[i + j] + tmp) % P;
      }
    }
  }
  if (opt == -1) {
    reverse(x + 1, x + lim);
    int inv = qpow(lim, P - 2);
    for (int i = 0; i < lim; ++i) x[i] = 1ll * x[i] * inv % P;
  }
}

int A[N], B[N], C[N];

int main() {
  int n, m;
  scanf("%d %d", &n, &m);
  for (int i = 0; i < n; i++) scanf("%d", &A[i]);
  for (int i = 0; i < m; i++) scanf("%d", &B[i]);
  int N = max(n, m), lim = 1;
  while (lim < (N << 1)) lim <<= 1;
  for (int i = 0; i < lim; ++i) r[i] = (i & 1) * (lim >> 1) + (r[i >> 1] >> 1);
  ntt(A, lim, 1);
  ntt(B, lim, 1);
  for (int i = 0; i < lim; ++i) C[i] = 1ll * A[i] * B[i] % P;
  ntt(C, lim, -1);
  for (int i = 0; i < n + m - 1; i++)
    printf("%d%c", C[i], " \n"[i == n + m - 2]);
  return 0;
}

Introduction

The number-theoretic transform (NTT) is an implementation of the discrete Fourier transform (DFT) on a number-theoretic basis; the fast number-theoretic transform (FNTT) is an implementation of the fast Fourier transform (FFT) on a number-theoretic basis.

The number-theoretic transform is a fast algorithm for computing convolutions. The most commonly used algorithms include the fast Fourier transform mentioned earlier. However, the fast Fourier transform has some implementation drawbacks: for example, the data vector has to be multiplied by a matrix with complex coefficients, and the real and imaginary parts of each complex coefficient are values of sine and cosine functions, so most of the coefficients are floating-point numbers. In other words, complex and floating-point arithmetic is required, which makes the amount of computation larger, and the error produced by floating-point arithmetic is larger as well.

The NTT handles polynomial multiplication with a modulus; it can be said to be somewhat restricted by the modulus, and the numbers are also larger. Currently the most common modulus is 998244353.

Prerequisites

Learning the number-theoretic transform requires the following prerequisites: the discrete Fourier transform, generated subgroups, primitive roots, and the discrete logarithm. This knowledge can be learned on the corresponding pages and is not repeated here.

Definition

Number-theoretic transform

In mathematics, the NTT is the discrete Fourier transform (DFT) over an arbitrary ring. In the case of a finite field it is usually called the number-theoretic transform (NTT).

The number-theoretic transform (NTT) is obtained by carrying the discrete Fourier transform over to \(F={\mathbb {Z}/p}\), the integers modulo a prime \(p\). This is a finite field, and as long as \(n\) divides \(p-1\), a primitive \(n\)-th root of unity exists, so we have \(p=\xi n+1\) for a positive integer \(ξ\). Concretely, for a prime \(p=qn+1, (n=2^m)\), the primitive root \(g\) satisfies \(g^{qn} \equiv 1 \pmod p\); if we regard \(g_n=g^q\pmod p\) as the equivalent of \(\omega_n\), it satisfies similar properties, e.g. \(g_n^n \equiv 1 \pmod p, g_n^{n/2} \equiv -1 \pmod p\).

Since we are dealing with a number-theoretic transform here, \(N\) (to distinguish it from the \(n\) in the FFT, we call the \(n\) here \(N\)) can be larger than the \(n\) in the FFT, but it suffices to regard \(\frac{qN}{n}\) as the \(q\) here, which avoids the size problem.

Common choices are:

\[ p = 167772161 = 5 \times 2^{25}+1, g=3 \]
\[ p = 469762049 = 7 \times 2^{26}+1, g=3 \]
\[ p = 754974721 = 3^2 \times 5 \times 2^{24}+1, g=11 \]
\[ p = 998244353 = 7 \times 17 \times 2^{23}+1, g=3 \]
\[ p = 1004535809 = 479 \times 2^{21}+1, g=3 \]

This is exactly the equivalent \(\mathrm{e}^{2\pi \mathrm{i} n}\) of \(g^{qn}\).

When the iteration reaches length \(l\), we have \(g_l = g^{\frac{p-1}{l}}\), or \(\omega_n = g_l = g_N^{\frac{N}{l}} = g_N^{\frac{p-1}{l}}\).

Fast number-theoretic transform

The fast number-theoretic transform (FNTT) is the fast algorithm obtained by adding a divide-and-conquer step to the number-theoretic transform (NTT).

The divide-and-conquer approach used by the fast number-theoretic transform is exactly the same as the one used by the fast Fourier transform. This means that a simple modification of the fast Fourier transform code is enough to obtain the code of the fast number-theoretic transform.

The term NTT often mentioned in algorithm competitions usually actually refers to the fast number-theoretic transform; by default, "number-theoretic transform" is taken to mean "fast number-theoretic transform".

The logic of this abbreviation is similar to that of the fast Fourier transform. In fact, the term "fast Fourier transform" (FFT) refers to the "fast discrete Fourier transform" (FDFT), but since "fast" can only apply to the discrete case, and even only to the special case where the order of the primitive root of unity is a power of \(2\), and cannot apply to the continuous case, the word "discrete" is omitted, FDFT becomes FFT, i.e. FFT always refers to the special discrete case.

The number-theoretic transform, or the fast number-theoretic transform, is an operation performed modulo a number; there is no continuous case, it is always discrete, so naturally there is no need to mention the word "discrete".

In the field of algorithms, an operation without a speed-up is meaningless. The term DFT is introduced in the fast Fourier transform article because the DFT also has other concrete applications in signal processing and image processing, and at the same time the DFT is the principle behind, or the prerequisite for, the FFT.

When no confusion arises, NTT is often used to denote the FNTT. To avoid confusion in the further explanation below, the two terms NTT and FNTT are kept separate in what follows.

The concrete relationship between DFT, FFT, NTT, and FNTT is:

  • Adding a divide-and-conquer step to the DFT and the NTT gives the FFT and the FNTT. The method and principle of the divide-and-conquer step can be found in the fast Fourier transform article.

  • Replacing complex addition and complex multiplication in the DFT and the FFT by addition and multiplication modulo \(p\), with the magnitudes usually restricted to the range from \(0\) to \(p-1\), and replacing the primitive root of unity by a primitive root of unity of the same order modulo \(p\), the order being a power of \(2\), gives the NTT and the FNTT.

Since the replaced operations only involve addition and multiplication, DFT, FFT, NTT, and FNTT share the same principle; all of them are carried out over a ring with addition and multiplication, without the stricter field requirement that division be defined.

In fact, as long as a primitive root exists, i.e. a generator in the sense of group theory, the NTT or FNTT for that modulus can be carried out. Considering that the moduli \(1\), \(2\), and \(4\) are too small to be of practical significance, for an odd prime \(p\) and a positive integer \(\alpha\) it suffices to give a primitive root \(g\) for the moduli \(p^\alpha\) and \(2p^\alpha\), and using the same method the NTT or FNTT can still be carried out.

#include <algorithm>
#include <cstdio>
using namespace std;

constexpr int N = 1 << 20, P = 998244353;

int qpow(int x, int y) {
  int res = 1;
  while (y) {
    if (y & 1) res = 1ll * res * x % P;
    x = 1ll * x * x % P;
    y >>= 1;
  }
  return res;
}

int r[N];

void ntt(int *x, int lim, int opt) {
  for (int i = 0; i < lim; ++i)
    if (r[i] < i) swap(x[i], x[r[i]]);
  for (int m = 2; m <= lim; m <<= 1) {
    int k = m >> 1;
    int gn = qpow(3, (P - 1) / m);
    for (int i = 0; i < lim; i += m) {
      int g = 1;
      for (int j = 0; j < k; ++j, g = 1ll * g * gn % P) {
        int tmp = 1ll * x[i + j + k] * g % P;
        x[i + j + k] = (x[i + j] - tmp + P) % P;
        x[i + j] = (x[i + j] + tmp) % P;
      }
    }
  }
  if (opt == -1) {
    reverse(x + 1, x + lim);
    int inv = qpow(lim, P - 2);
    for (int i = 0; i < lim; ++i) x[i] = 1ll * x[i] * inv % P;
  }
}

  int n, m;
  scanf("%d %d", &n, &m);

  ntt(C, lim, -1);
  for (int i = 0; i < n + m - 1; i++)
